Safety rules

什么会自动继续

不是“所有失败都重试”。

结构化配额错误
Claude 的 errorKind: rate_limit 或 Codex 的 usageLimitExceeded，不解析文案。
还没产生任何输出或工具调用
一旦有 ACP 输出或工具活动，就不进入自动重放。
有可信 reset
匹配机器、账号和模型；多个窗口都耗尽时等到最晚的那个。
原目标仍可用
机器、Provider、模型、模式、Role、MCP 选择都保留；缺任何一个就停下。
到点后重新校验
仍被限制就顺延 deadline，不形成紧凑重试循环。
不会在已有输出后重放
不会猜 reset 或切换 Provider / 机器 / 模型
不会把“没有本地输出”当成“Provider 没做事”
Durable record

deferredTurn 保存 session、user turn、machine、provider scope、deadline、generation。没有第二套 prompt 投递路径。

队列是 #361 的投影，不是页面状态 · 页面不拥有 timer 或调度权 不确定就停下 · 可取消、可打开，不自动猜测
