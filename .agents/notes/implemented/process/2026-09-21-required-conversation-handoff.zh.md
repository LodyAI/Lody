# 强制交代会话分享状态

Status: implemented
Translation: current

[English](2026-09-21-required-conversation-handoff.md)

## 摘要

外部 PR 原本可以省略撰写会话，不交代是否询问分享或用户是否拒绝。此次已采纳的
调整要求明确分享状态，并提供公开链接或具体原因。用户拒绝时，还需在原始 prompt
旁单独逐字保留其回复。公开会话仍是自愿行为，自动检查无法证明披露的真实性。

## 决定与依据

[PR #829](https://github.com/LodyAI/Lody/pull/829) 删除了分享小节，却通过原有正文校验。
本次部分取代[可选分享的决定](2026-09-17-shared-conversation-pr-handoff.zh.md)：保留
原始 prompt 和由用户控制发布的原则，但删除整个分享小节不再满足外部贡献要求。
仅加强 Agent 提醒，仍然无法看出分享流程是否被跳过。

[契约草案](../../../../specs/pr-conversation-handoff.zh.md) 定义四种状态与拒绝证据。
模板负责贡献者填写说明，局部 Agent 规则负责开 PR 前的交互，正文校验器通过既有
协调器报告问题。公开会话链接不再限定 Lody。已有外部 PR 在下次协调检查时适用相同规则。

实现 PR: [#855](https://github.com/LodyAI/Lody/pull/855).

## 验证与限制

行为测试覆盖完整披露、缺失披露、所有状态分支、无效链接与原因、拒绝证据缺失或
位置错误，以及协调器的待处理状态。测试数据均为合成数据，没有提交真实会话。
已尝试完整工作区检查和格式化，但无依赖的 worktree 缺少 `tsgo` 和 `oxfmt`，无法完成。
变更文件另行运行格式化。链接可访问性和拒绝真实性仍由评审者判断；未增加网络访问
或自动发布。
