# 让提及描述利用可用空间

Status: implemented
Translation: current

[English](2026-10-20-mention-description-space.md)

## 摘要

Skill 描述在五行后被截断，即使详情栏仍有空白。现在详情栏为标题、元信息和底部信息（包括路径）
保留空间，把剩余高度交给说明。可见行数随可用空间变化，超出的文字以省略号结尾。
详情栏不会滚动，也不会撑高菜单。

## 决策与范围

这仅替代[提及菜单设计](../feature/2026-09-25-composer-mention-menu-v2.zh.md#设计评审第二轮)
中对描述最多五行的限制，以及普通详情栏的滚动布局。详情栏仍由候选列表决定高度。
内容采用有界的纵向 flex 布局：固定的标题和元信息、可伸缩的说明、固定的底部信息。
ResizeObserver 测量说明区域的高度，再除以实际行高，决定能显示的完整行数，随字号和列表高度变化更新。
溢出裁剪使详情栏在滚轮操作下保持静止。独立的 Role 详情栏保留自己的布局。

## 验证

已有提及菜单的 42 项测试、相关文件的 Oxfmt、Oxlint 和组件类型检查均通过。
所属 Playwright 套件补充了短、长 Skill 列表在 12px、14px、18px 字号下的验证：路径保持可见，
说明不越出分配的区域，较高列表可以展示超过五行，滚轮不能滚动详情栏。该回归测试通过。
实际详情组件的独立浏览器渲染也通过九种高度、字号组合（详情栏高度 168/300/440px，字号设置 12/14/18px）。
