# Composer 和待发送消息排版

Status: implemented
Translation: current

[English](2026-11-02-composer-queue-typography.md)

## 摘要

待发送消息在不同展示状态下字号不一致，Composer 运行配置的字重也比相邻的上下文标签更粗。队列消息和编辑器现在使用与输入框相同、可缩放的正文字号和行高，覆盖准备中和定时消息。Composer 工具栏标签使用常规字重，分组标题保留层级强调。浏览器和设备上的实际效果仍需在完整检出环境中验证。

## 决策

所有队列状态中的用户消息使用现有的正文设计变量，前置序号和操作区使用相同行高对齐。机器、项目、分支和 worktree 的上下文标签共享可缩放的次级正文字号、行高和常规字重。次要标签保持较小字号，标题保持中字重，以维持层次而不让同级控件过粗。配置标签的字重由共享工具栏触发器负责。
