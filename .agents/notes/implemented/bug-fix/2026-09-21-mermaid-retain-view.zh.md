# Mermaid 内嵌图失活后保留视图

Status: implemented
Translation: current

[English](2026-09-21-mermaid-retain-view.md)

## 摘要

离开 Mermaid 内嵌画布会重置平移和缩放，丢掉读者正在查看的位置。现在失活只停止输入，保留
渲染后 SVG 的视图，激活也不再添加描边。保留范围限于该 SVG 的生命周期，不新增会话持久化状态。

## 决策

本次部分替代[点击激活](../feature/2026-09-10-mermaid-click-to-activate.zh.md)中的退出重置和激活描边决策。
当前意图由[视图契约](../../../../specs/mermaid-inline-view.zh.md)维护。

以 SVG 为键的弱映射独立于当前激活画布保留变换。重新激活恢复对应数值，避免下一次手势跳动。
退出也会释放指针捕获并清除拖拽状态。全屏查看器接收清除变换的副本及未缩放尺寸，无需临时
重置内嵌视图。替换后的 SVG 从初始状态开始，避免沿用其他内容的几何状态。

## 验证与限制

既有 Mermaid 测试覆盖 Escape 后保留拖拽位置，点击外部、失焦、Enter 和查看器操作后保留视图，
未激活时的滚轮行为，以及重新激活后继续缩放。当前工作树和主目录均无可用 Vitest 安装，测试
未能执行；浏览器视觉验证也尚未执行。
