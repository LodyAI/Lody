# 移动端新对话显示可读的分支名称

Status: implemented
Translation: current

[English](2026-10-28-mobile-local-branch-label.md)

## 摘要

移动端新对话在关闭 worktree 时显示了 `lody:branch:local:main` 这样的内部选择标识。
这个路径直接读取当前检出的分支，漏用了已有的名称格式化方法。现在通过共用的显示解析方法，
先根据直接使用目录或 worktree 选择对应分支，再格式化名称；启动时仍保留完整标识。
GitHub 分支名按原样显示。

## 决定与证据

这是对[移动端新对话页](../feature/2026-10-28-mobile-new-chat-page.zh.md)分支行的修正。
直接使用目录时显示目录当前检出的分支；启用 worktree 时显示用户选择的基础分支。
两种情况都使用 `getLocalProjectBranchLabel`，解码名称并附上本地化的本地或远程标记。
数据暂缺时使用已有占位文字。直接使用目录时，分支控件仍为只读。

之前的真实组件示例使用普通 `main` 值，掩盖了这个问题。现在示例使用编码后的本地分支标识，
与生产代码共用显示解析方法。单元测试覆盖当前分支与选择分支的区别、远程分支、旧版普通名称、
缺失数据和类似内部标识的 GitHub 名称。浏览器测试选择另一 worktree 基础分支后，关闭
worktree 检查当前检出分支，再开启检查原选择仍在。现有浅深色画板截图直接更新，不保留旧示例。

## 验证限制

19 个单元测试、5 个 Chromium 场景和 WebKit 的 worktree 切换检查通过，
组件类型检查、带类型的 lint、格式化与翻译键检查通过。Ryugi 无布局警告。根检查仍受未初始化的
ACP 扩展和缺失文档链接限制。iOS Debug `0.107.2 (20261028.7)` 构建、严格签名检查通过，
并已安装到实体手机。安装验证交付，不代表真机交互验收。
隔离的手机构建保留之前的原生与云端依赖基线，只应用这次产品补丁，并非完整最新 main 的集成构建。
