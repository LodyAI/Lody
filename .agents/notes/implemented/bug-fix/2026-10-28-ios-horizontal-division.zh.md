# 移动端聊天适配横向折痕

Status: implemented
Translation: current

[English](2026-10-28-ios-horizontal-division.md)

## 摘要

UIKit 报告横贯视图的横向分隔区域时，手机聊天把消息流限制在上半屏，把输入框
及相关控件放在下半屏。停靠键盘出现时，由原有原生键盘偏移接管布局，使输入框
移到键盘上方。两种切换都保留组件树及未发送草稿；任一侧空间不足或折痕消失时
恢复普通布局。

首页的活动对话标签将原有第一组放在上半屏，其余组放在下半屏；保留分组、
打开关系树、预览数量、行操作和折叠状态，不重复显示对话。出现键盘、搜索、
归档同样将完整分组放在上下两个首页滚动区，使用同一个列表组件管理选择、全选和删除确认，不重复显示对话。搜索、键盘显示、分组不足两个或两侧空间不足时恢复普通列表。项目标签在有最近
项目时把快捷入口及本地/GitHub 选择放在上半屏，所选列表放在下半屏；搜索、
键盘出现或没有最近项目时恢复普通布局。首页定时任务列表即使视口超过桌面
CSS 断点也采用紧凑行布局，确保运行目标及操作可见。设置分类首页上半屏将账户和当前工作区的图标与名称放在同一卡片中，并与最近 7 天的 Token 和预估费用并排，
全部设置分类放在下半屏；复用设置页的用量缓存和能力开关，区分加载中与零用量，
将真实逐时数据按 UTC 日汇总绘制紧凑柱状图和模型占比环，点击进入同样默认按周显示的完整用量页，
保留统一键盘焦点范围，两侧可分别滚动，并在页面进入动画结束后重新测量。用量详情把时间范围和并排的用量数字放在上半屏、图表放在下半屏；工作区详情把工作区信息放在上半屏、成员及其他设置放在下半屏。键盘出现时恢复普通滚动，页面组件和状态保持不变。

聊天操作和会话标签等弹层分别在下半屏滚动；没有可用折痕时保留各自原来的高度限制。

设置页外层滚动区在折叠和普通布局中保持挂载；只有存在可用折痕时才交由内部
面板分别滚动；折叠时内容高度受视口约束，避免下半屏内容延伸到屏幕之外。
筛选弹层仅在原生 iOS 中关闭 Vaul 的输入框重定位，由原生键盘
偏移接管；浏览器和 Android 保留 Vaul 的可视视口处理。

## 证据与范围

iOS 27.1 已登录模拟器中，系统键盘位于下半屏，输入框位于折痕上方；无键盘时
聊天和输入框分别位于折痕两侧，已有会话在展开和半折间保持可见。测试覆盖几何、
键盘切换和草稿保留，也渲染了真实弹层。其他设置详情、普通对话框及真机验收不在本次范围，
它们仍可能跨过横向折痕。几何来自 UIKit，不依赖机型或固定尺寸。

## 后续设置与弹层

账户设置将个人资料放在上半屏，设备等账户资源放在下半屏；外观设置将主题、语言和字号放在上方，渲染与图标放在下方；偏好设置将通知及输入放在上方，会话选项放在下方。两个区域各自滚动，折叠或键盘变化不重新挂载内容。工作区切换和项目技能弹层不含输入框，也限制在可用下半屏。模拟器和真机验收范围按实际结果记录。

项目详情设置上方放项目编辑及 Worktree，下方放技能和其他项目设置，并为底部导航留出空间。关于页面上方显示版本和构建信息，下方显示链接与可选开发者设置，折叠切换时保留开发者模式解锁状态。GitHub 设置上方显示连接与身份，下方显示仓库列表及搜索，键盘与折叠状态变化时保留输入框。Agents 页有远程机器时，上方为机器选择，下方为供应商列表；其他情况保留普通滚动。会话历史弹层也限制在下半屏。新建对话的全屏页面将目标选择放在上方、输入框放在下方。筛选、运行配置、Worktree 编辑及工作区创建/删除弹层在键盘收起时适配下半屏；键盘出现后切回共享的键盘避让及可视范围限制，保持输入内容。根级确认框在键盘收起时位于下半屏，嵌套弹窗仍由所属容器定位。其他设置详情和普通对话框仍需按实际内容处理。
