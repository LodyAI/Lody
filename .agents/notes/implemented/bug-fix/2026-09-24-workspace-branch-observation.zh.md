# 将工作目录分支观测与 GitHub 解耦

Status: implemented
Translation: current
PR: [#953](https://github.com/LodyAI/Lody/pull/953)

[English](2026-09-24-workspace-branch-observation.md)

## 摘要

本地 Git 对话可能没有分支展示，因为分支同步只在 GitHub 回合收尾中执行。
独立的工作目录分支服务现在负责 Git 观测与所属会话元数据发布，不再依赖 PR 处理。
Agent 绑定、回合终止，以及已授权的工作目录激活／显式根目录刷新共用同一个串行服务。
保留最近已知分支的现有语义；本次不提供空闲时持续监听 HEAD 的保证。

## 决策

界面已经消费本地项目的分支元数据。新增界面 Git 读取会重复状态，并把机器文件系统
知识带入渲染层。仅放宽 GitHub 条件仍会漏掉初始、取消和空闲恢复会话，因此将观测
从回合后处理提取，并注入执行层与工作目录激活／显式刷新边界。

```text
执行绑定／回合终止 ─┐
已授权工作目录刷新 ─┴─> WorkspaceGitService
                          └─> 所属会话 branchName → 现有界面
GitHub PR 检测继续作为独立的可选消费者。
```

服务按所属会话串行执行 Git 读取和元数据写入，包括子标签页。启动与文件快照不等待
观测完成。发布不依赖文件索引行发生变化，避免仅分支变化被忽略。失败按尽力而为
处理，不虚构分支，也不丢弃恢复所需的身份。没有增加协议字段、渲染层读取、轮询循环
或 GitHub 依赖。

既有[渲染成本说明](../../../docs/sessions-render-cost.md)继续约束分支标签。
[约定](../../../../specs/workspace-branch-state.zh.md)记录观测时机与最近已知分支语义。
尚无提交的分支也是有效分支；Detached HEAD、不可读或非 Git 目录不覆盖已有元数据。

## 验证

分支观测、执行、后处理、Code Collab 和 MessageHandler 集成套件初次验证共 200 项通过。真实临时 Git
仓库覆盖无远端／尚无提交分支、分支切换、Worktree 和 Detached HEAD。确定性屏障
覆盖父子会话并发观测及不阻塞工作目录激活。执行测试验证提示开始前、本地回合结束
后及收尾取消后的分支状态。CLI 类型、修改文件格式与文档检查通过。修改范围的
类型感知静态检查没有错误，新增服务及测试没有警告。未启动桌面界面进行手动验收。

空闲时外部切换但没有工作目录刷新，不保证实时更新。本次不包含界面重设计或发布。

创建 PR 前，全仓库 `pnpm check` 和 `pnpm format` 也已通过。

## 审查后收敛

独立审查未发现 P0/P1 阻塞问题，但指出执行收尾同时刷新 Code Collab，以及普通文件
监听事件会重复探测分支。将注入接口收窄为激活与显式根目录刷新时的分支观测；回合
终止观测由执行层负责。失败状态发布不再等待这一可选探测。工作目录解析抛错也会
被捕获并保留最近分支。行为回归覆盖排除监听／回合差异刷新、不阻塞失败落状态，
以及目录不可用的情况。

审查后验证：187 项定向回归、全量 `pnpm check`、`pnpm format` 与
`pnpm run docs check` 均通过。
