# 移除分享任务提议并保留发布凭据

Status: implemented
Translation: current

[English](2026-09-13-share-proposal-and-credential-boundaries.md)

## 摘要

登录后的分享预览继承了工作区任务操作；最终发布请求期间关闭窗口，又可能丢弃唯一的读者凭据。
现在冻结时排除任务提议显示块，读取器拒绝这类数据。新发布在上传和提交前可靠保存并验证读者凭据，
服务端完成不再依赖窗口仍挂载。存储失败会停止发布，不再静默依赖组件临时状态。

[静态分享设计](../../proposed/architecture/2026-09-12-static-session-sharing.md)的其他部分保持不变。
只排除 `system_notice/task_proposal`，保留子 Agent 记录、文本和不透明工具数据作为参考资料。
投影与读取校验共用显示容器遍历，绝不修改原历史。已有包含提议的分享包需重新部署才能读取；
本功能未发布，不提供兼容路径。

待发布状态保留完整 begin 响应用于重试。存储须返回 `stored` 且读回同一密钥，不能覆盖较新的凭据版本。
生命周期检查阻止关闭后尚未提交的工作；已经开始的提交即使晚到成功，也不再需要额外保存凭据。
仅禁止关闭弹窗不足以解决刷新或导航卸载，因此未采用。上传凭据和现有重置链接行为不变。

确定性测试覆盖源数据不变、附件读取前排除提议、拒绝嵌套提议、保留子 Agent/工具数据、
提交期间关闭后的凭据恢复、存储失败与重试、较新版本保护。不代表完成托管部署验收。
