# Lody Light 侧边栏墨色对比度

Status: implemented
Translation: current

[English](2026-10-18-sidebar-ink-contrast.md)

## 摘要

在[中性灰](2026-10-17-neutral-light-grays.zh.md)改动之后，对浅色侧边栏截图的测量显示它仍是一片灰雾：导航图标对侧边栏只有 2.7:1，机器名 1.9:1，禁用的前进箭头 1.8:1，选中会话的底色与侧边栏只差 1.18:1。侧边栏现在用五档墨色而不是七档：选中文字、行文字、一档 muted（`#6B6B6B`，4.7:1，用于图标、细节和 Offline 胶囊）、分组标签一档（该 muted 的 80%，3.2:1），以及 muted 的 60% 用于禁用控件。选中底色加深为 `#D6D6D6`（1.28:1），项目文件夹图标改用与导航图标相同的笔画粗细和静止墨色。没有实际渲染：这些数值是计算出的对比度，不是视觉评审结论。

## 发现

- `--sidebar-foreground-muted` 取自 `sideBarSectionHeader.foreground`（`#939393`），所有 muted 元素都约为 2.7:1。分组标签再淡化到 70%（约 1.9:1），禁用的顶栏按钮淡化到 40%。
- 导航图标静止时是 muted 墨色，而项目文件夹图标用行墨色和 lucide 默认的 2px 笔画，相距几像素的两列图标粗细和颜色都不同。
- Offline 胶囊用的是产品的 `muted-foreground` 和 `foreground/12%` 边框，而不是侧边栏自己的墨色。
- 灰色中性化之后，页面卡片阴影仍带蓝色（`hsl(225 10% 11%)`），且在 1.08:1 的明度差上很淡。
- 导航、项目和仓库行的文字列在代码中一致（9px 内缩，文字距行边缘 31px）。测量中 2–6px 的偏差来自字形侧距和图标绘制，因此没有仅凭这一证据改动几何。

## 决定

| 墨色     | 值（Lody Light）                            | 用途                            |
| -------- | ------------------------------------------- | ------------------------------- |
| 选中     | `--sidebar-selection-foreground`            | 选中行                          |
| 行       | `--sidebar-row-foreground`（上限 10:1）     | 标题、导航和项目标签            |
| Muted    | `#6B6B6B`，侧边栏上 4.7:1，选中底色上 3.7:1 | 图标、细节、Offline             |
| 分组标签 | muted 的 80%，约 `#868686`，3.2:1           | 机器名、GitHub Worktrees、Chats |
| 禁用     | muted 的 60%，约 2.3:1                      | 无历史时的后退 / 前进           |

分组标签最初用完整的 muted 墨色。经负责这项工作的人评审，这使机器名与周围的图标和细节同色，只比项目行浅一档，不再像标题。现在它比 muted 浅一档（仍为 12px、500），导航与第一个分组之间的间距从 8px 增至 12px，用位置而不只是颜色标出分组；下方各组之间本已相隔 16px。代价是标签低于正文 4.5:1 的建议。此前的 70%（1.9:1）因看起来像禁用而被否决；更深更重的标题因会让侧边栏显得沉重而被否决。

底色：悬停 `#E2E2E2`（不变，1.14:1），选中 `#D6D6D6`（原 `#DEDEDE`），悬停与选中仍可区分（1.12:1）。未加载主题时的 Tailwind 回退值同步（muted 42%，选中 84%）。页面卡片保留中性阴影，并新增一条使用主题 border 色 60% 透明度的浅色 1px 描边，让边缘更清楚，同时不形成厚重边框或多层描边。

随后将浅色画布和侧栏底色分别设为 `#F9F9FA` 与 `#EFEFF0`。两者计算对比度为 1.09:1，差异仍很轻；内缩、阴影和低对比度描边共同勾勒页面卡片。现有 `#6B6B6B` muted 墨色在侧栏底色上仍为 4.64:1。Vesper 深色调色板不变。这是源码颜色计算，更新后的表面仍需实际渲染检查。

未改动：仅 Web 显示的 `Lody` 字标保留品牌字体，因为字标是品牌决定而非界面字体；顶栏箭头保留 lucide 原图形，其箭头在同一 16px 框内本就比面板图标窄；其他间距待渲染评审后再定。

## 验证限制

编写环境没有 Node 或 pnpm，因此没有运行 `pnpm check`、`pnpm format`、测试、Storybook 和 `pnpm run docs check`，也没有在屏幕上查看。对比度按上表 sRGB 值计算。合并前请在浅色和深色下查看 `LoroSidebar` stories（深色主题的 muted 墨色未变），包含选中会话、离线机器和禁用的前进按钮。
