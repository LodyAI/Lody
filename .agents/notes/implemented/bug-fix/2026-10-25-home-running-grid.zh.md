# 首页运行标记与侧栏保持一致

Status: implemented
Translation: current

[English](2026-10-25-home-running-grid.md)

PR: [#1883](https://github.com/LodyAI/Lody/pull/1883)

## 摘要

首页原先用单个强调色圆点表示运行中的会话，而侧栏使用动态点阵。
现在「现在」摘要和运行中列表统一复用 `WorkingGrid`，保留原有的 14px 图标槽。
这让首页沿用侧栏动画，无需引入另一套动画系统，也不改变会话分类。
运行数为零时使用暗淡的静态点阵；减少动态效果模式下，非零状态的点阵也保持静止。

## 决策与证据

[`now-board.tsx`](../../../../packages/components/src/components/chat/home/now-board.tsx)
在原有槽位内居中放置默认的 12px 点阵，并使用首页强调色。
摘要和会话行共用一个局部封装；展开列表沿用同一个行渲染器。
运行数为零时，在原有淡化摘要内使用次级文字色，并关闭缩放和透明度动画。
恢复到正数时重新启用共享动画和强调色。三项摘要计数全为零时，仍沿用原有的安静提示语。
可见性观察、共享动画时钟和减少动态效果行为
仍由点阵组件负责，见[点阵最初决策](../feature/2026-09-24-sidebar-working-grid.zh.md)。
这项调整替换了[首页决策](../feature/2026-10-16-home-week-tiles.zh.md)中的单圆点展示。

## 验证

Playwright 使用相同的模拟故事数据、深色主题和 1600×1000、2 倍像素密度视口，
截取修改前后的完整工作区。截图包含生产代码中的侧栏、首页和输入框组件，
验证范围是组件预览，并非打包后的 Electron 会话。
现有首页过渡测试只结束有限动画，避免持续运行的点阵动画干扰过渡验证。

21 项首页组件测试、包级类型检查和定向 lint 均通过。浏览器检查验证了
12px 点阵四周的 1px 居中间距、展开后的全部六条运行记录，以及减少动态
效果模式下的静态点阵，页面没有运行错误。两项既有过渡布局断言在原始和
修改后的渲染器上同样失败，另外两项浏览器测试通过。仓库文档检查报告了
84 项既有错误，本记录没有错误。验证使用已安装的 Node 26.11.1，低于
仓库要求的运行时下限。根目录 `pnpm format` 通过；`pnpm check` 在 CLI
类型检查阶段因当前检出缺少 ACP 扩展子模块清单和 Claude 模块而中断。

工作区故事提供运行中和已完成的模拟状态。Playwright 录屏展示完整工作区、
展开的运行列表、运行数归零及恢复运行。浏览器断言确认零状态保留九个暗淡的
静态格子，恢复运行后重新启用动画，页面没有运行错误。
