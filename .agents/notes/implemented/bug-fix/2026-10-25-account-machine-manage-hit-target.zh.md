# 让账号页机器管理按钮避开原生返回手势区

Status: implemented
Translation: current

[English](2026-10-25-account-machine-manage-hit-target.md)

## 摘要

在窄屏原生外壳中，点击账号页机器「管理」按钮的中心可能停留在原页。共享下钻布局左侧宽 48px 的透明返回手势区覆盖了按钮，普通网页则不挂载这层。现在将操作放到原有行的末端，保留手势区域与导航回调。浏览器验证使用合成数据和共享原生标记，不代表私有 iOS 外壳已验收。

## 发现与决策

[Issue #1864](https://github.com/LodyAI/Lody/issues/1864) 跟踪公开组件缺陷。在 393×852 中文布局中，原按钮位于 x=16..61.74，其中心 x=38.87 被 `MobileEdgeBackSwipeZone` 覆盖。命中测试返回透明覆盖层；中心点击停留在账号页，未被遮挡的右缘可以进入详情。已有仅验证回调的测试绕过了浏览器命中测试。

由 `AccountMachinesOverviewView` 负责操作位置。添加具有自动行首外边距的 flex 容器，使 `CompactRow` 在堆叠控件时也将按钮放到行末；宽行原本就在行末对齐。不改变机器数据、权限、RPC 或路由契约。移动这一个操作避免缩窄手势区，也避免跨设置页及动画滚动容器调整全局层叠关系。其他左缘控件不在本次修复范围内。

## 验证与边界

新增原生标记的 Storybook 场景，用合成机器组合真实账号机器列表、设置布局和机器详情面板。浏览器回归检查整个管理按钮避开手势区，手势区仍能在其他位置接收触摸，并验证点击管理和返回会切换可见页面，以及原生左缘滑动仍可从详情返回。中英文用例在原 x=16 位置失败，在行末对齐后通过。已有账号列表及机器详情单元测试通过（10 项）。本修复不包含实体 iPhone 验收，也不处理独立观察到的远端资源采样等待。

`pnpm format` 和 `pnpm docs check` 通过（73 项已有文档警告，无新增）。全仓类型与静态检查通过。`pnpm check` 停在五项 CLI 测试失败：本机会话目录 `ENOTDIR`、macOS 临时路径规范化、两项子模块身份检查和并发工作区超时。这些失败不在修改的 UI 范围内，其余聚合门禁未完成。
