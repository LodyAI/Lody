# 连续且紧凑的登录切换

Status: implemented
Translation: current

[English](2026-10-18-login-view-switching.md)

## 摘要

在第三方登录与保留的邮箱注册模式之间切换时，可见内容被立即放入更矮的容器，产生了 64px 跳动。统一预留最大表单高度会让登录多出空白，而整块淡出、调整高度再淡入又失去了交互需要的连续性。当前实现保持两个面板挂载，在横向滑动的同时适配实际高度；邮箱登录与注册共用真实输入节点，只对发生变化的行展开、收起。切换过程中内容持续可见，控件不缩放，登录也不再预留姓名栏。

## 结构与决定

本次细化[登录视觉记录](../feature/2026-10-17-login-inset-visual-last-used.zh.md)中的切换决定。之前的检查遗漏了退出后重新进入保留注册模式的情况。`popLayout` 立即移除了旧表单对布局的贡献，使其在更矮的容器内重新定位。已安装的 Motion 12.43.0 源码也确认，`wait` 负责等待退出，而不会协调独立变化的父子尺寸。当时官网访问失败，机制核对采用了已安装版本源码。

两个中间方案已被否定：固定最大高度让登录留白；整块场景淡出则在调整高度期间隐藏内容。两者都不能满足连续、紧凑的切换。

```text
底部锚定的登录主体（仅首次进场）
└─ 普通文档流，间距 24px
   ├─ 持续挂载的标题区：展开的返回行、标题、描述
   ├─ 可选错误提示
   ├─ LoginViewSlot：裁剪视口，实际高度插值
   │  └─ 横向轨道：同一进度值，不缩放、不做透明度动画
   │     ├─ 第三方登录／桌面入口面板（保持挂载）
   │     └─ 邮箱面板（保持挂载）
   │        └─ 持续挂载的表单：展开的姓名、邮箱、密码、
   │           收起的忘记密码、提交、模式切换
   └─ 可选法律说明
```

`login-page.tsx` 持有认证状态与草稿。邮箱模式变化时更新同一表单树，不用 key 替换表单。姓名输入框保持挂载，但收起时禁用、取消必填、设为 inert，并从无障碍树隐藏。屏幕外的面板同样 inert，且排除在无障碍树之外。邮箱在滑动结束后使用 `preventScroll` 聚焦；模式切换保留当前焦点，不重新聚焦。

`login-view-slot.tsx` 使用一个从 0 到 1 的数值 MotionValue，同时驱动横向位移和两个面板实际高度之间的插值。轨道宽度为 200%，到达邮箱面板时位移为 -50%。视口裁掉相邻面板，同时保留焦点环的内边距。两个面板一直挂载，重新进入时保留输入节点与浏览器状态。高度与位移共用 320ms、控制点为 (0.4, 0, 0.2, 1) 的缓动。反向切换停止旧动画，从当前进度继续。

展开行用相同节奏对测得的文档流高度做数值动画，避免反向切换时触发 `height: auto` 关键帧测量。行写入高度后，Motion 的 post-render 测量在同一帧调整外层视口，不再叠加第二个补偿动画。ResizeObserver 同时跟踪字体和窗口变化。标题区的返回行与变化的文案都有文档流高度动画，也覆盖窄屏说明换行数不同的情况；文字仍原位更新。减少动态效果模式直接写入最终数值。抖动视觉保留原有窄屏折叠行为，页面保留首次进场动画。

停止动画时先保存上一帧的数值，再启动替代动画；Motion 的停止操作可能补采样到该帧之后的时间，因此必须保留原值，避免取消时出现小幅位移。

## 验证

现有浏览器套件覆盖 1000px、850px、390px 布局，登录与注册的紧凑高度、保留注册模式后重入、草稿值及输入节点身份。注入浏览器时钟检查滑动和展开的中间高度、输入框与标题的完整透明度、不缩放面板，以及从当前位置反向切换。另有减少动态效果用例检查直接完成布局。截图覆盖登录、注册和姓名栏展开的中间状态。

六项浏览器用例全部通过（17.5 秒，进程正常退出），包括 1000px 与 390px 下的中间帧和反向切换。已有最近登录方式和桌面交接测试全部 19 项通过。包级类型检查报告 `loro-sidebar.tsx` 和 `home-week-usage.ts` 中本次范围之外的错误。文档检查仍有六处指向缺失 ACP 子模块源文件的链接，以及三个超限规则文件；没有等待 SHA 审阅的保护主题。
