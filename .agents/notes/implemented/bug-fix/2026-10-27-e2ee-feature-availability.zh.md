# 说明加密工作区尚未支持的功能

Status: implemented
Translation: current
PR: https://github.com/LodyAI/Lody/pull/1967

[English](2026-10-27-e2ee-feature-availability.md)

## 摘要

加密工作区会主动拒绝未加密的旁路，但部分入口原先直接消失、一直加载，或显示内部错误码。
界面现在复用已有能力判断，每项功能使用统一的本地化说明。不支持的操作会在编辑或传输前
禁用或替换为说明；底层保留检查，附件被拒绝后保留草稿。本次只修复可用性，没有实现加密
RPC、在线状态、附件、共享、导出或代码协作索引。

## 决定与边界

- 复用 `workspaceSupports` 和 `useWorkspaceFeature`，不增加另一张能力表。
  `workspace-feature.ts` 统一本地化原因和可识别的拒绝错误。界面读取已准入的工作区模式；
  即使回调或深链接绕过入口，操作仍检查自己的 runtime/content。
- 桌面和触屏附件菜单保留禁用项并直接显示原因。定时消息保留普通机器和加载状态的禁用原因；
  加密定时消息使用受保护 CRDT 路径，不再显示工作区不支持提示。会话菜单说明导出、共享、远端预览与 RPC
  限制。远端机器详情/Provider 控件在挂载不支持的编辑器前显示说明。
  远端目标控制、编辑重发和原生引导入口遵守 RPC 可用性；持久化发送与取消保留已有路径。
- 在线状态使用已有状态槽，优先级低于浏览器离线与机器已移除；中性提示替代错误的机器离线
  判断。代码协作不再一直等待已禁用的索引，而是显示不可用。已确认的本机桌面文件预览保留
  provider 与 IPC 操作，索引仍禁用。
- 附件准入拒绝未加密的云端引用，并保留准备好的本机文件回执。加密附件准备现遵循[文件密钥决定](../architecture/2026-10-28-encrypted-attachments.zh.md)，上传失败保留草稿源文件。本机交接失败不能退回明文上传。
- 普通工作区能力判断和传输分支不变。这些同步检查不改变资源归属，也不需要扩展生命周期
  迁移。[M2 既有约束](../../proposed/architecture/2026-10-22-e2ee-m2-product-integration.zh.md#未加密出口)
  保持有效。

## 证据与限制

确定性测试覆盖真实菜单禁用状态、网络传输前的中英文附件拒绝说明、中英文在线状态说明、
普通定时消息加载状态、远端表单隐藏、
代码协作不可用与本机预览、真实持久化草稿 hooks，以及准备好的本机文件写入真实 Loro 历史。
撤回实现至 main 时，九项选定回归测试在预期断言处失败并正常退出；恢复后通过。普通菜单、
附件、机器详情和运行时既有测试属于定向验证范围。

Storybook 提供加密桌面/移动附件菜单、在线状态与功能说明。组件测试和故事渲染不能证明打包
Electron、移动真机或已部署加密工作区验收。完整仓库检查交给 CI；本次不新增明文上传或网络通道。
