# 未知工作区模式与正文出站

Status: implemented
Translation: current

[English](2026-10-29-unknown-workspace-egress.md)

## 摘要

临时打开的普通运行时可能在取得已认证的工作区分类之前发送正文。上传之后再拒绝，无法撤回已经发送的请求体。现在本地 Repo 仍可使用，普通传输、RPC、附件准备、分享和导出等待分类。发送接受也等待分类，避免加密结果退役普通运行时时丢失原始输入。已保留的不可变普通空间准入继续支持离线行为。

## 决定与所有权

这部分替代了[启动决定](../feature/2026-10-17-e2ee-workspace-bootstrap.zh.md#启用前不可见修正)中允许提前出站的取舍，同时保留本地可用性的理由。缓存的工作区 ID、缺少加密标记或尚未加载的列表都不是明文授权。分类来自已认证的描述或按账号与工作区保留的证明；相矛盾的加密证据仍优先。分类本身不授予设备批准、密钥或执行权限。

Provider 的一次初始化拥有模式读取及结果。临时运行时拥有可取消的出站等待。退役、关闭与认证替换使晚到结果不能恢复旧的普通路径。查找失败时，本地内容仍可读取，但不能因此放行出站。权限拒绝或传输错误只属于一次查询，不能成为运行时的永久拒绝结论。后续发送或恢复联网可以共用新的验证；同账号、同工作区新保存的普通或 legacy 证明也可以在相同证据检查后恢复准入。恢复成功后在同一个 Repo 上继续同步。准入失败尚未取得本地传输，因此可以重试连接；真正开始的连接始终保持单次运行，并由原所有者管理到结束。发送接受成功之前，源内容仍由输入框持有；待发输入不能先被消费进加密运行时无法读取的临时明文命名空间。

运行时同时限制传输连接、云端请求和本地请求，因为本地 daemon 可能继续转发普通正文。直接 HTTP 附件在自己的请求边界继续执行准入。分享在重试期间保留捕获时的运行时、账号与选择，并在每个发布边界之前重新检查。已验证的加密工作区继续使用现有保护宿主及明确的解密副本确认；分类不会建立明文回退。

让整个工作区等待网络查询会损害离线本地访问。把后端 403 当作保密边界，则请求体会先泄漏，再被拒绝。调用者提供的模式标记或仅禁用界面按钮，都不能替代操作准入。

本改动仅扩展现有 React/Promise 运行时组合的一个有限边界。外围资源与传输仍由原有所有者管理，不新增 Effect 执行边界，也不宣称完成原生迁移。

## 证据与限制

运行时生命周期测试在分类之前保留真实本地 Repo 的编辑能力，并在桌面传输边界观察文档字节。发送测试验证失败和显式重试期间的原始输入。发布测试检查加密结果、查找失败和账号替换时操作仍未发出。既有已保留证明和纯本地运行时用例维护离线行为。

这些证据来自合成组件、Repo 与适配器检查。安装后客户端、服务部署、遥测修复、原生保管与跨设备产品验收仍需分别验证。
