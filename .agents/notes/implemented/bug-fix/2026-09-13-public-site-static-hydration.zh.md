# 客户端初始化失败时保留官网静态内容

Status: implemented
Translation: current
PR: https://github.com/LodyAI/Lody/pull/677

[English](2026-09-13-public-site-static-hydration.md)

## 摘要

官网 landing、博客和文档已经输出预渲染 HTML，但路由导入失败可能将正文替换为框架
错误界面。现在客户端先准备当前路由和文章模块，再让 React 接管文档；准备失败时保留
静态内容及元信息。首页可选效果隔离自身渲染错误，原生手机导航在无 JS 时也可用。
真实生产构建通过了 258 项浏览器验证；线上部署和搜索重新索引仍未验证。

## 决策

保留枚举 URL 的静态预渲染。仅增加请求时 SSR 无法阻止客户端覆盖 HTML。
[草案 Spec](../../../../specs/public-site-static-content.zh.md)约定双语页面直接访问的
行为，以及初始化失败时可以失去 JavaScript 交互。

自定义客户端入口等待 `hydrateStart`，随后同步 invalidate 当前路由，执行包括
Fumadocs MDX 预加载在内的 loader。仅恢复服务端 loader 数据不会填充浏览器文章缓存。
这会增加一次初始化 loader 执行，其中可能读取构建生成的静态服务端函数缓存。
TanStack 懒加载组件预加载会吞掉导入拒绝，所以准备阶段还监听 Vite 预加载错误，再
决定是否 hydration。保留原有静态文档时，普通链接仍可用。

首页背景、产品演示和营销氛围效果增加局部错误边界。背景失败时保留渐变；可选演示
可以消失，但不会替换周围正文。不识别爬虫、不复制 SEO 文本、不恢复 DOM 快照，也不
引入刷新循环。hydration 成功后的任意异常和客户端路由跳转恢复不在本次修改范围内。

## 真实浏览器验证发现的其他缺陷

手机菜单原先依赖 React 才能展开，现在采用原生 `details`/`summary`，React 只增强
Escape 关闭和滚动锁定；hydration 前打开菜单也会保留展开状态。中文本地项目文档
链接到了不存在的 `cli.html`，现改为已发布 CLI 路由及已验证的标题锚点。
博客精选卡片在整张卡片链接内嵌套作者链接，导致两个语言的页面出现 React hydration
错误 #418。卡片内作者改为普通文本，文章详情的作者链接保持可点击。

## 验证与限制

在独立完整克隆中同步工作区修改，使用冻结锁文件安装依赖并初始化所需 ACP 子模块，
成功生成全部 218 个预渲染页面。因安装时跳过脚本，需显式构建 `acp-extension-core`。
较早的一次本地预渲染遇到 ECONNRESET；不改配置重试以及最后一次完整构建均成功。

可重复执行的 `site-docs/scripts/verify-static-browser.mjs` 通过 HTTP 提供真实生产
产物并阻断外部请求，Chromium 共通过 258 项验证：

- 禁用 JS 检查 216 个已发布页面：可见标题与正文、文章内容、title、description、
  canonical、语言、结构化数据及内部静态链接目标；另检查两个未知路由的 HTTP 404/noindex。
- 十个中英文首页、文档和博客路由的 30 项正常与故障场景：正常时主题切换可用且无
  未捕获页面错误；真实路由模块、文章模块或生成的静态服务端函数数据加载失败时，
  静态正文和元信息不变。
- 十项导航场景：桌面/手机无 JS 访问文档和博客文章、正常手机菜单关闭与导航、
  路由加载失败后的手机导航、hydration 前打开菜单，以及修复后的中文 CLI 锚点。

额外重跑全部 30 项正常与故障场景，并加强 React 文档所有权断言，全部通过：正常启动
接管文档，准备失败不会 hydration。验证等待可观察的导航、准备完成和 DOM 状态，
不使用固定延时。JSON 结果和截图输出到 `site-docs/out/static-verification/`。
官网 TypeScript 检查、全部 43 项既有官网测试和公共仓库边界检查均通过。之前的合成
验证站点还测试了可选组件渲染异常；完整生产站点未注入这类组件异常。

提交前在仅安装官网依赖的克隆中尝试了根目录 `pnpm check`，但在
`acp-extension-claude` 编译阶段因 SDK 依赖和 TypeScript 全局类型缺失而停止，
不能视为全仓库检查通过。

本次未部署线上。验证范围为本地 Chromium 和静态托管行为，不代表 Google 已重新索引、
线上 CDN 行为、无 JS 时所有交互控件均可用，或 hydration 成功后任意错误都可恢复。
原先爬虫资源请求失败的原因及历史搜索结果标题来源仍未确认。
