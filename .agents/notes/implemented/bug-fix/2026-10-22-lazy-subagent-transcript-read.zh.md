# 打开详情时才读取子任务正文

Status: implemented
Translation: current

[English](2026-10-22-lazy-subagent-transcript-read.md)

## 摘要

父会话按轮次加载仍会把可见轮次内全部子任务递归转成 JSON，包括未打开的任务弹窗。
Loro 显示读取现在只保留子任务信息和有界的最后一步摘要，挂载详情时才读取选中的 run。
导出、复制、重放和命令仍使用完整权威历史。本次不改持久化数据，避免打开会话时展开
全部子任务正文；完整 CRDT 快照导入和单个已打开 run 内的全部条目仍是独立内存成本。

## 读取职责

`SessionHistoryReader` 增加成对可选的 `readTurnForDisplay` 与 `readSubagentRun`。
Loro 逐层投影轮次、items、task 和 run，主会话不递归序列化 `run.items`。
预览只含最后一个有效步骤的小字段，文本最多 512 字符；旧 Text 字段使用有界切片。
摘要不读取工具 content/raw 输出。详情查找绑定所属轮次、根 ACP session 与 run id。
旧内联 JSON 仍可读取，但无法撤回其作为单个值已被解码的字节。

reader-backed view 仅在两个方法都存在时启用投影，沿用已有成员身份与内容 epoch 校验。
它在复制的 task 上附加仅供显示、不可枚举的 `history` 读取能力；函数不进入存储、
wire DTO 或完整导出。读取能力只弱引用 reader，view 释放时使其失效，避免渲染条目
缓存通过关闭的任务保留整个 CRDT 文档。其他后端和静态分享继续完整读取。
`readTurn`、`readAll`、快照复制和命令语义不变；权限、目标、定时任务与 diff 的事实
读取根条目，继续可用。

任务行用小摘要显示当前活动。仅挂载的详情活动区读取完整选中 run，流式更新时跟随新
投影来源；切换来源或卸载后忽略迟到结果。失败可重试，不能显示成空历史或完整历史。
完整 run 只保留在详情组件状态，不进入全局缓存。这里一次只读取一个 run；单个巨大
run 内逐条按视口加载留待后续处理。

同一 run 刷新时保留已挂载正文和折叠状态。读取完成后，仅在用户仍跟随末尾时滚动到底。
显示投影也会保留 `toString` 这样的未知自有字段，不会把原型方法当作字段投影器。

## 方案取舍与验证

只隐藏或虚拟化弹窗 DOM 太晚，父轮次的 `toJSON` 已分配了子任务正文。
缩小尾部轮数也无法解决单个巨大轮次。对可变 CRDT 容器使用懒 getter 会模糊快照时点，
摘要消费者也可能意外触发完整读取；显式显示/详情接口让读取动作可见。
不能在读时删除数据或把预览当作可信复制来源。新写入过滤是另一项
[决策](2026-10-22-bound-child-tool-history.zh.md)。

真实 Loro 回归禁止提前导出整轮/run 或读取其他子条目正文，验证准确归属、完整导出，
并证明读操作不产生 CRDT 操作。实际 view 测试覆盖完整 readAll、流式摘要和详情更新、
释放；React 测试覆盖未打开任务、切换选择、迟到结果和重试。
原异步 epoch 回归改为验证显示端口。操作抓取与内存测量不进入公共仓库。
这些读取测试不证明导入内存已解决，也不代表真实 iPhone 冷启动验收。
