# 保存 Agent Role 的当前选项

Status: implemented
Translation: current

[English](2026-10-14-role-save-current-options.md)

## 摘要

角色保存时会保留 `thinking` 等已经移除的选项，导致重复保存后仍有兼容性警告。
现在显式保存会根据所选 Agent 的权威编辑器控件构建选项，保留有效选择，
对无效或未设置的值使用当前默认值。打开编辑器仍保留原始草稿。
能力未知或仅有临时信息时不会删除选项，模型和模式仍由用户明确选择。

## 决策

表单到角色记录的构建函数接收编辑器当前能力快照，仅在显式保存时整理选项。
它使用与表单一致的模型相关控件，保留角色的其他字段，不修改旧记录。
现有内容比较负责版本递增和重复保存；目录的本地持久化和上传行为不变。

本次补充了[自动清理](2026-09-11-agent-role-schema-reconciliation.zh.md)：
自动清理对探测新鲜度和模型匹配的要求可能合理地延迟清理，其严格规则保持不变。
打开时直接改写草稿会在用户决定保存之前隐藏不兼容情况，因此没有采用。
当前行为见[目录配置说明](../../../docs/workspace-catalog-durability.md)。
