# 已收起侧栏的 Zen 切换应直接展开

Status: implemented
Translation: current

[English](2026-09-20-zen-collapsed-sidebars.md)

## 摘要

手动关闭左右侧栏后，Zen 切换只改变不可见的模式位，让快捷键看起来没有响应。
现在，当所有可用侧栏的已保存偏好都是关闭时，切换会直接展开它们。正常的 Zen
隐藏与恢复仍保留单侧展开布局。这里有意让全关闭状态下的显式展开更新展开偏好。

## 决策与依据

[行为草案](../../../../specs/zen-layout.zh.md)细化了此前源码规则中“每次 Zen
切换都保留偏好”的约束。在已经全关闭的布局中继续坚持该规则，会保留此次无响应问题。

已挂载的桌面会话通过 `zenRightPanelAtom` 发布右侧栏当前状态及展开动作，卸载时
检查对象身份再清理。唯一的应用命令在执行时读取它；标签选择与持久化仍由原面板
所有者管理。不需要第二个命令注册或新的存储格式。没有已挂载面板时，只展开导航栏。

所有者的情况。组件类型检查、范围内 lint、格式检查及 `git diff --check` 通过。
`pnpm run docs check` 报告了 28 个指向缺失 ACP 子模块的既有链接问题，不涉及本次
变更文档。根级 `pnpm format` 通过；完整 `pnpm check` 在文档站缺少
`fumadocs-mdx` 依赖时中断。未进行桌面界面操作验证。通过忽略的链接复用已有工作树的依赖，未修改
