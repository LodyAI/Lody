# 会话运行配置草稿在切换标签后保留

Status: implemented
Translation: current
PR: [#1287](https://github.com/LodyAI/Lody/pull/1287)

[English](2026-10-07-session-run-config-drafts.md)

## 摘要

未发送的 Fast 选择原来会在输入组件卸载后丢失。稀疏内存存储现在只保留修改字段，
在本机发送被接受时消费对应代际。远端轮次更新默认值，不清除私人修改。
收窄后的修复隔离不同提供方目标，不跟踪其元数据切换；返回同一目标时恢复自己的草稿，
应用重启则会丢失草稿。

## 决策与取舍

[草案 Spec](../../../../specs/session-run-config-drafts.zh.md) 定义约定。
字段对象身份代表每次修改的代际。挂载编辑租约阻止旧回调重建已删除意图，并在卸载时释放。
捕获回调持有最终 inputConfig 所用的渲染代际，卸载后仍能确认，且不消费较新的同值修改。
`acceptSessionUserTurn` 同时确认本地写入和等待发送准入，沿用
[等待发送边界](2026-09-30-composer-pending-send-config.zh.md)。

移除了提供方切换协调和异步目标比较：目标键已隔离配置，无需 A→B→A 清退策略。
确认删除仍清理对应草稿；元数据扫描不包含已删除条目，因此重进工作区时只检查实际有草稿
的会话。元数据缺失不能证明删除，账户生命周期隔离重新登录后的延迟清理。
保留单行 Role 防护：undefined 允许程序化继承，明确 None 则防止修改后的配置携带过期
Role 或记忆绑定。

在本地准入语义下，不再需要先前的访问会话及轮次沿革缓存。TTL/LRU 会静默丢掉真实草稿，
因此都不采用。

## 验证与限制

回归覆盖保留在所属的输入组件、运行时和清理测试中：Fast 开关切换标签后恢复、作用域
隔离、精确代际的发送准入、失败及已有删除/归档流程。删除重复的原子状态测试矩阵和
人工规模压力测试；此次裁剪不改变生产行为。验证结果在 PR 报告。本地完整 CLI 检查存在无关的沙箱用户目录、
套接字、代理及 WebRTC 限制，已在未修改的 main 复现；本文不宣称完成打包 Electron 验收。
