# 原生分享图片导出

Status: implemented
Translation: current

[English](2026-10-07-native-share-image-save.md)

## 摘要

分享卡片在原生移动壳中误走浏览器 blob 下载，即使 WKWebView 无法保存，也报告成功。
PNG 导出现在复用文件预览已有的本地缓存文件和系统分享面板通道。取消会保留预览和
已选消息，失败可重试，并清理临时文件。本次修复共享导出路由；相册权限和实际保存
目标的行为仍需原生设备验收。

## 决策与证据

[此前的移动端修复](2026-09-18-mobile-share-as-image.zh.md)让选择和预览可达，
但 `exportShareImage` 仍只有 Electron 与浏览器两个分支。已有
`session-file-download.ts` 说明了原生 WKWebView 为何需要真实本地文件，而不能依赖
指向 blob URL 的下载链接。

捕获的 PNG 复用 `shareFileBytesNatively`，保留 `.png` 后缀和清理后的显示文件名。
该辅助函数返回 `{ shared }`，区分取消与完成系统交接；已有文件预览调用方仍可忽略
返回值。PNG 对话框已有根据 `{ saved }` 决定是否结束消息选择的逻辑，因此无需新增
一套 UI 状态机。

```text
捕获 PNG
  Electron -> 原生保存对话框
  原生移动端 -> 独立缓存 PNG -> 系统分享面板 -> 清理
  浏览器 -> blob 下载
取消 -> 保留预览和选择
失败 -> 保留预览并允许重试
```

不增加相册插件，也不在原生失败后静默回退到浏览器下载。系统面板负责选择目标：
iOS 可提供「存储图像」，但完成也可能代表交给其他分享目标，不能证明写入了相册。
对话卡片与用量卡片共用此导出辅助函数。不引入私有移动端源码或云请求。

## 验证

导出测试使用真实原生辅助函数和内存文件系统、分享面板边界，检查 PNG 字节、文件名、
完成、取消、失败、清理，以及不会触发浏览器下载。原生文件测试检查分块字节、并发
隔离、取消信息变体和失败清理。保留 Electron 保存、浏览器下载及剪贴板回归覆盖。
这些检查不能替代原生设备上的系统面板与相册权限测试。
