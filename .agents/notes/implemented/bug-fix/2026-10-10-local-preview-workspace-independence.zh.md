# 会话工作区不可用时的本地预览

Status: implemented
Translation: current

[English](2026-10-10-local-preview-workspace-independence.md)

## 摘要

本机预览已有本地 IPC 通道和任意路径权限，但工作区解析可能在检查路径前就拒绝仍然
存在的绝对路径文件。现在，本地解析分别校验持久化的会话、机器和子会话归属，以及
工作区可用性。工作区不可用时，绝对路径和以主目录为根的路径仍可解析为工作区外的
只读文件，相对路径继续报错。这修复了可复现的一类失败；缺少技术详情时，不能确认
截图中的具体错误。

## 决策

此前的[冷会话修复](2026-10-09-cold-chat-file-preview-workspace.zh.md)在运行时回收后重建
已有聊天目录的路径，保留相对路径身份，但仍要求该目录存在才能读取存储在其他位置的
本地绝对路径产物。现在，本地解析明确表示工作区不可用，而不是替换成聊天目录、
主目录或进程当前目录。

`MessageHandler` 校验本机未删除、未归档的会话及父会话元数据，拒绝嵌套父会话，
然后把归属身份传给 `FilePreviewService`。服务在检查文件路径前校验调用方声明的
归属。只有工作区不可用这一结果允许无根目录解析，其他解析失败继续报错。路径策略
仅在本地任意路径能力开启时接受此状态，不增加远程协议或写权限。Electron 继续负责
内容读取、有界请求、版本检查及渲染器所属的不透明资源。远程预览和 Code Collab
保留现有工作区规则。

## 验证与限制

回归测试使用根会话或父会话目录缺失时的合成临时产物，校验本地身份和只读分类，
拒绝相对路径替代及无效归属，并确认远程读取仍失败。路径策略测试还覆盖主目录路径、
不存在的文件和目录。所属测试套件的 57 项测试全部通过；新增的三项集成用例在原始
实现上均失败。CLI 和全仓库类型检查、`pnpm format` 及 `pnpm run docs check` 均通过。
文档仍有已有警告，没有修改 SHA 保护的主题。lint、国际化和四项仓库边界／导入检查
均通过。全量 `pnpm check` 因六个未改动的 CLI 套件失败而停止（CLI 有 3678 项测试
通过）。在隔离的 CommonJS 临时目录下移除 Agent 会话 Git 包装器后复跑，四个套件
恢复通过；Roost 历史和模拟器捕获进程生命周期仍失败（49 项通过，3 项失败）。这些
未解决的检查意味着不能声称全仓库验收通过。本次没有通过完整 Electron 界面复现，
也没有检查用户的具体文件。
