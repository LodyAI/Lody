# 托管预览中的可选标注

Status: implemented
Translation: current
PR: https://github.com/LodyAI/Lody/pull/724

[English](2026-09-15-preview-optional-annotation.md)

## 摘要

托管预览在 iframe load 后三秒统一报告运行时错误，代理错误页也会触发。
运行时初始化还把上一页的 referrer 当作父窗口来源，导致导航后拒绝真实父窗口
的握手。现在控制消息绑定到真实父窗口，页面加载与代理就绪检测独立于可选标注。
这样可以保留浏览能力，但不保证每个页面都能标注。

## 决策与证据

保留消息源窗口校验和首次来源锁定，不需要完全移除来源检查。标注缺失时禁用
标注控件，并接受迟到的握手，不再延长原来的三秒超时。加载指示不再遮盖页面。
原有父窗口直接刷新 iframe 的能力继续适用于没有运行时接收者的页面。

PR 审查纠正了过度移除运行时加载报告的问题：同源页内导航不会改变父窗口的
iframe src。因此保留这些报告作为可选的工具栏提示，让“停止加载”保持可用，
但不改变 iframe 就绪状态或遮盖内容。即使运行时没有发送完成消息，原生 load
也会结束加载提示；界面测试覆盖了此回退路径。

对抗审查发现，load 前的跳转可能在新的来源绑定建立前被取消。现在通过不携带
页面数据的就绪信号提前发起握手；最近一次待处理导航等待父窗口绑定，不绕过导航策略。

代理转发响应带有独立于旧运行时标记的代理标记，仍兼容接受旧标记。
若注入增加的体积超限，则返回原始字节、保留 CSP，并且不声称已经注入运行时。

针对性测试覆盖导航 referrer、无关发送者、来源锁定、迟到和缺失的运行时消息、
刷新、体积限制和代理就绪检测。验证使用合成 DOM 事件和本地 HTTP fixture，
不代表已完成生产部署或验证所有浏览器的 CSP 行为。行为意图见
[草案 Spec](../../../../specs/preview-annotation-availability.zh.md)。
