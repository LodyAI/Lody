# 将 Agent 配置输出与启动数据分开

Status: implemented
Translation: current

[English](2026-09-30-agent-config-output.md)

## 摘要

查看 Agent 配置，甚至只用 JSON 模式重命名配置，都会打印已保存的所有环境变量值。
现在通过明确的展示契约默认隐藏所有环境变量值，修改操作返回回执而不是启动数据。
确需查看原值时，可在 show 上显式使用 `--show-secrets`。依赖完整配置响应的脚本需要
迁移；存储和启动行为保持不变，该选项不赋予额外访问权限。

## 决策

`commands/agent-config-output.ts` 负责普通文字与 JSON show 共用的允许列表投影。
`envKeys` 表达变量是否存在，避免脚本把脱敏占位符误写回配置。显示密钥选项只增加
`env` 副本，不开放任意运行时、认证或自定义启动字段。create/update 返回保存后的 ID
和初始化或请求修改的字段名。赋值解析失败只报告位置，不回显原始输入。

依赖敏感变量名黑名单会漏掉任意命名的凭据。在通用 JSON 日志函数里脱敏会漏掉普通
文字输出，还会牵连无关命令。因此策略放在配置展示边界，存储和启动继续使用真实值。
目录 list/get 已有安全摘要契约，保持不变；本次补齐查看和修改入口，与已有
[目录决策](../feature/2026-09-27-resource-discovery.zh.md) 相衔接。

范围是已存环境变量值及隐式运行时字段导出。刻意放进名称、描述或提示词等展示字段的
值不会自动分类。已有权限校验、存储保密性、历史输出清理及凭据轮换不属于本次代码修改。
