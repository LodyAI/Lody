# 从文件预览进行原生分享

Status: implemented
Translation: current

[English](2026-09-14-native-file-sharing.md)

PR: https://github.com/LodyAI/Lody/pull/685

## 摘要

移动端二进制预览此前仅提供宿主路径，即使客户端已经能够读取文件。
现在原生文件操作通过系统分享面板导出完整预览字节，并保留复制路径。
远程预览大小限制不变，大文件传输需要另行扩展协议。
原生设备上的文件交接仍需人工验证。

## 决策与证据

共享文件操作 Hook 为提示卡片和菜单统一选择平台行为。
操作使用现有已授权文件 provider，不将远程路径交给设备，并抑制重叠导出。
原生保存辅助函数复用分块缓存写入，每次使用随机目录、安全文件名，
处理取消，并在写入失败等路径上尽力清理缓存。

本次扩展[本地文件操作](../bug-fix/2026-09-09-local-file-link-actions.zh.md)。
原有附件下载器保持不变；提高预览限制或新增传输端点会扩大范围。
产品意图记录在[草案 Spec](../../../../specs/local-file-link-actions.zh.md)。

## 验证

借用已有检出的依赖后，29 项针对性测试通过，覆盖跨分块字节完整性、
空文件、同名并发隔离、取消与失败清理、文件操作路由和错误呈现。
Story 覆盖原生就绪和处理中状态。完整检查未通过：工作树缺少依赖和子模块，
借用的依赖存在工作区类型不兼容。文档检查报告已有子模块链接缺失。
iOS/Android 分享面板外观和接收应用交接尚未实测。

后续 CI 运行 34802071337 暴露了断言开销：对 3 MiB Buffer 进行通用深比较
超过 5 秒超时，是 3,624 项组件测试中唯一失败项。改用 Buffer.equals 精确比较
长度和全部字节，保持测试数据、分块边界与超时设置不变。本地原生分享套件耗时
从 4,482 ms 降到 163 ms，双 worker 下 36 项相关测试以及针对性格式和 lint
检查均通过。这些耗时是观测值，不作为测试断言。

审查后续修复：提示卡片操作构建器仅在收到带字节的二进制快照时提供原生分享。
错误卡片不传快照，保留复制与本地宿主操作；空二进制快照仍可分享。
导出锁和处理中状态仅作用于原生 App，使浏览器并发下载相互独立。
32 项相关测试通过，新增显式延迟读取覆盖浏览器并发下载与原生锁释放，
以及缺失字节和空文件的分享可用性。针对性 lint 通过；完整检查仍受此前
本地依赖和子模块缺失限制。
