# 长文本的阅读对比度

Status: implemented
Translation: current

[English](2026-09-24-reading-contrast.md)

## 摘要

在前景为纯白的深色主题中，长对话读久了很累：Vesper 里每一行正文、标题、用户气泡和侧栏标题都是 #101010 上的
#FFFFFF（19.7:1），笔画产生光晕，密集的中文发虚，也没有任何东西把阅读栏标成最亮的区域。现在主题层为正文和用户气泡
派生一个限制对比度的阅读色（深色主题 13:1，仍高于 WCAG AAA），标题和粗体保留完整前景色；未选中的侧栏文字统一限制在
5.5:1，只有选中行比正文醒目。已低于上限的主题和高对比度主题不受影响；没有加暖色调。

## 决策

- `vscode-theme-css.ts` 派生 `--reading-foreground` 和 `--sidebar-row-foreground`：把前景色向背景色移动，直到对比度
  满足上限（深色 13:1 与 5.5:1，浅色 16:1 与 8:1）。未套用主题时回退为原始前景色。
- Markdown 正文和用户气泡使用 `text-reading`；标题和 `strong` 保留 `text-foreground`，层级靠亮度体现。
- 行内代码：底色从 14% 降到 7%，文字用阅读色，不再在句子里形成亮斑。
- 未选中的会话标题、分组与项目名、分区标题以及 New chat / Search 都使用侧栏行颜色；选中行不变。悬停只改变行的背景，不改变文字颜色。行内图标和头像保持不透明：
  曾尝试压暗，看起来像被禁用或出错。
- 列表项间距 0.5rem，大于同一项折行的行距；大纲定位条静止时从 /45 降到 /32，指针移上去时变亮。

## 备选方案

- 修改内置主题颜色：主题是用户的选择，编辑器、终端等界面依赖这些值；派生的阅读色只影响长文本。
- 暖色调（例如 #151413 上的 #E4DFD6）：会改变主题的性格，保留为可选项。
- 为中文行长把阅读栏收窄到 40em：布局改动较大，本次未做。

## 验证与限制

- `tests/vscode-theme-css.test.ts`：Vesper 的阅读色不超过 13:1（前景仍为 19.7:1），侧栏文字不超过 5.5:1（高于 AA） 且低于阅读色；
  柔和主题和高对比度主题不会得到派生颜色。组件测试全部通过。
- 本地生产构建（Vesper）：正文 #D5D5D5，所有未选中的侧栏文字 #8D8D8D，悬停时不变，选中行不变。其他内置主题没有逐一检查。
- 工具卡片中的文件名等非正文界面元素仍使用完整前景色。
