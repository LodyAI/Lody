# 会话上下文兜底方案

Status: implemented
Translation: current

[English](2026-09-09-conversation-context-fallback.md)

## 摘要

Provider 原生的 fork 无法把每个会话搬到每个目标上。fork 菜单提供复制一段精确的 Markdown 历史
前缀，且不依赖原生 fork 能力。用户再把该上下文手动粘贴到自己选择的 Agent、模型或工作区。应用户
要求，自动的「粘贴文本转文件」与上传反馈已被移除；既有的粘贴与提交行为保持不变。

## 决策与归属

[Spec 草案](../../../../specs/conversation-context-copy-and-text-attachments.md)定义了边界。消息
操作通过既有的会话操作上下文共享复制回调。更早的 turn、流式回复以及不支持的 ACP provider 仍可
复制；原生 fork 目标仍保留其能力与完成度闸门。一个纯函数区间辅助会拒绝缺失的边界。Markdown 导出
保留正文，标注部分完成的回复，并披露被省略的附件字节。独立的用户图片同样会输出该提示。代码评论
与可视化批注在安全的 Markdown 围栏内复用其结构化引用格式化器，即便导出超出预算也保留用户正文、
回复与目标元数据。这避免了仅含引用的 prompt 静默消失。

桌面端用户消息的 fork 按钮遵循相邻复制/置顶的 hover 与键盘聚焦行为，并在其菜单打开时保持可见。
触摸端的操作始终可见。助手消息的 fork 按钮在元数据之前留出右边距；发送者名称继承时间戳颜色。
中文的目标提示保持简短。

此前可编辑文本文件的实验已被撤回，因为它额外引入的编辑与提交状态造成了回归。其 hook、进度状态、
输入框改动、测试与文案均已移除。原有的粘贴文本折叠、发送前展开与普通附件传输保持原样。本 PR 不
包含任何新的 wire 字段、上传生命周期或后端。

## 验证与限制

合成覆盖验证了闭区间复制、不支持 fork 的菜单、流式期间的复制入口以及原生 fork 的闸门。仅含引用的
图片、代码评论与可视化批注 fixture 覆盖了缺失正文的回归与超预算保留，其中包括含 Markdown 围栏的
评论。流式回归在此前「完成后才启用操作栏」的实现上会失败。既有的粘贴、mention 与提交套件验证了
被恢复的路径。与 PR 基线的源码对比确认被撤回的功能不再改动这些路径。

主 checkout 的完整检查因缺少 ACP adapter 依赖而受阻。组件类型检查与类型感知 lint 使用相同源码的
独立构建 checkout 完成。未验证任何真实 provider 往返。
