# 加密工作区的文件与预览可用性

Status: implemented
Translation: current

[English](2026-10-28-e2ee-file-preview-availability.md)

## 摘要

加密工作区通过现有工作区密钥、签名和同成员机器权限使用 Code Collab 与远端预览。Code Collab v2 同步文件索引和信号 Flock；正文、保存、差异和 LSP 结果通过 RPC 传输，不是同步文本 CRDT 文档。这些 Flock 现在复用普通加密文档提供器，包括快照。文件和预览 RPC 复用现有加密请求、响应和日志。公开链接分享会在工作区成员范围外发布服务器可读的静态副本，须经过[加密工作区的明确确认](2026-10-28-e2ee-share-plaintext-consent.zh.md)。

## 决策

owner 批准复用既有远端预览行为和本机导出，不引入新账本或权限模型。功能 RPC 仅允许既有 Code Collab 方法、受限 `file/preview`，以及预览创建、状态和撤销。它不能调用 `file/resolve-local`、本机端点控制或无关机器操作。原生发送端从已验证账本确定目标机器签名者；接收端复用新鲜的同成员机器授权，并在调用既有处理器前检查工作区、机器和声称的用户身份。缺失原生能力不会退到普通 RPC。

普通工作区保留既有 RPC、owner-session 信封、Flock 房间和预览证明。加密预览复用逐次检查能力的 Quick Tunnel 和回环代理；页面字节经隧道流式传输并带 `no-store`，没有新增应用服务器内容存储。这不表示预览隧道是端到端加密：隧道服务会终止其传输加密。预览控制结果和可视评论仍走加密 RPC、文档路径。

功能请求和结果的每个既有签名内容帧仍小于 1 MiB。请求将规范 JSON 分成 256 KiB 块，在既有方法体的 params 中以前置大端 uint32 块序号、总数编码；各帧保持相同请求 ID、方法和过期时间。宿主在发送前保存按长度前缀排列的完整密文原件，响应摘要绑定该组合。结果与[机器只读查询](../architecture/2026-10-28-e2ee-read-queries.zh.md)共用原生组装和严格的二进制分页元数据：uint32 总页数、总字节数，加最多 256 KiB LocalMachineRpcResponse JSON；sequence 和 progress/success 表明位置。完整 DTO 跨 IPC 前检查签名者、路由、epoch、方法、块数、精确长度、完整请求摘要及序号。请求仍最多 32 MiB，结果最多 16 MiB，超出返回明确大小错误。不完整请求合计最多 32 MiB、32 项，在后续接收或关闭时清理过期数据；不存在第二种读取请求格式。

功能通道扩展[加密派发](../architecture/2026-10-28-e2ee-streams-dispatch.zh.md)，保留其原件和执行认领。渲染进程与加密派发共享一个响应读取器；运行时关闭先取消传输并等待读取器结束，再释放 token。CLI 监听器保留四个有界接收任务，读写各有 32 个独立任务槽，关闭前等待已接纳的底层工作结束。十个审计通过的纯读取检查新鲜读权限，只保留原文，不领取执行 claim；diff、保存、索引发布和预览控制要求写权限。日志先认领请求再执行保存，持久化所有加密响应后才发布；发布失败只重放原件。已开始但结果不确定的请求不能再次保存。存储失败仅影响该请求，并由有界响应原件持有者保留；不会让其他请求退到明文。不修改账本、密钥格式或数据库版本。

## 证据与限制

使用合成真实密钥和 SQLite 验证大请求、结果分块，乱序请求重组，错误请求响应，重开后的原件不变，发布失败重放及撤权。生产 provider/preload 测试覆盖宿主转发；运行时测试打开真实 Repo 的索引和评论；宿主测试覆盖对应房间的加密更新、快照。这些检查不代表已安装桌面、真实云服务、系统密钥库或全平台验收。本机导出是独立的 [PR #2011](https://github.com/LodyAI/Lody/pull/2011)。
