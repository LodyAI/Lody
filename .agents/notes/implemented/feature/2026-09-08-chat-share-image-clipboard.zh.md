# 把选中的聊天图片复制到剪贴板

Status: implemented
Translation: current

[English](2026-09-08-chat-share-image-clipboard.md)

## 摘要

最初的「选中聊天生成图片」流程要求先保存 PNG 才能在别处分享。预览现在在导出之外提供本地的
「复制图片」操作，并复用同一套整卡 PNG 截取。Electron 通过既有的原生剪贴板桥传递 PNG 字节，
具备能力的浏览器则使用 image Clipboard API。复制失败或不受支持时，预览仍保留以便重试，且不会
发布任何会话内容。

## 决策

复制操作归属于图片预览，因为预览拥有卡片外观与 PNG 截取。它与导出互斥，使渲染出的卡片不会被
并发截取两次。Electron 在主进程保留剪贴板归属；渲染进程只在用户显式触发复制后才生成字节。浏览器
复制使用 `ClipboardItem`，并把不受支持的 API 报告为可恢复的失败，而不是静默回退为文件下载。

既有的背景选项渲染为可见的色板网格，而不是纯文本菜单。它只展示已实现的画布取值，其中包括一张
从引导欢迎背景派生、适合导出的静态图。这让选择控件与导出图片保持一致，而不会暗示存在一个并不
可用的壁纸库。

本记录扩展了此前的[图片导出决策](2026-09-08-chat-share-image.md)，并更新了
[规格草案](../../../../specs/chat-share-image.md)。

## 证据与限制

导出测试用合成 PNG blob 覆盖了原生剪贴板的成功/失败路径与浏览器剪贴板路径。它们不能证明操作
系统层面的剪贴板兼容性或像素级视觉保真度。
