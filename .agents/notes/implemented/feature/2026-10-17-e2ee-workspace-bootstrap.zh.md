# E2EE 工作区的开发者创建与账本预览

Status: implemented
Translation: current

[English](2026-10-17-e2ee-workspace-bootstrap.md)

## 摘要

核心库已合入，但产品缺少可识别的加密工作区和初始化入口。本批接入开发者选项、桌面受保护的设备初始化、独立云端创建接口和可读的完整账本页。创建先落本地密钥，再按固定请求提交创世记录；已知加密空间不能进入旧明文运行时。这个交付仅开放控制操作，不代表聊天、附件、恢复登记、全平台保管或生产上线完成。

## 决策与责任

用户要求先完成工作区模式、开发者入口、独立云端标识、首次设备密钥与账本追踪。[实施导读](../../../docs/e2ee-workspace-bootstrap.zh.md)记录代码入口和数据流。普通工作区不转换；云端工作区 ID 与 genesis 一对一绑定，设备私钥不进入云端或渲染进程。

设备初始化由桌面主进程持有，使用既有保管适配器、真实签名与 SQLite 原请求记录。关闭或取消需要等原生操作结束；未知结果保留，不生成替代身份。云端适配器校验账号归属与回执；页面按账号和请求分别保存待确认工作，成功后固定创世哈希。账本读取使用 core 的完整与增量验证，不把服务端 JSON 投影当作权限事实。

原本只靠远端模式查询会破坏离线启动，也无法阻止已固定加密身份被降为明文。因此保留不可变的账号/工作区模式证明，并优先执行本地加密约束。未登记模式的旧缓存需首次在线验证，这是保留不降级保证的限制。独立窗口不能共享可覆盖的唯一 pending 槽位。

本批不自动迁移明文，不开放缺少密钥适配器的平台创建，不连接尚未加密的数据通道。[现有核心边界](../architecture/2026-10-15-e2ee-current-decisions.zh.md)与 draft 协议仍适用；此记录不批准协议或全平台 Beta。

## 验证与限制

验证覆盖真实加密/SQLite 重启、未知创建结果、账号切换、账本篡改与分页，以及真实本地控制服务的创建、并发重试和清理。独立复核发现的多窗口请求覆盖、模式降级和明文离线回归在本批修复并加入行为覆盖。具体命令和最终结果随交付记录列出。合成保护提供者不证明用户系统密钥库、签名安装包或实际部署行为；未读取用户钥匙串或生产数据。

本批目标验证：前端 77 项、云端组合 7 项、桌面保管/初始化 26 项与 IPC 2 项通过；私有后端 726 项及真实本地 Convex 18 项通过。新的独立复核运行相关三套 36 项测试并确认源码一致，未发现剩余可证 P0/P1。浏览器验证了合成账本和创建页的桌面/手机布局。完整仓库检查及部署结果单独记录，不由这些数字推定。

仓库验证：类型检查、类型感知 lint、Effect lint、格式与文档检查通过。完整 `pnpm check` 没有全绿：未改动的 CLI 测试受到注入的 Git 环境和 macOS 进程探针期限影响。隔离到原生 Git 后 24/24 通过；Inbox 套件曾独立 60/60 通过，但重复隔离运行仍触发既有探针期限。这些是保留的验证限制，没有绕过，也不记为完整检查成功。机械 lint 调整后的最终桌面保管/初始化测试为 26/26 通过。
