# 用"共享海面"方块网格替换侧边栏的工作转圈

Status: implemented
Translation: current

[English](2026-09-24-sidebar-working-grid.md)

## 摘要

侧边栏原来用旋转的 `Loader2` 圆弧表示会话正在运行，它读起来像"加载中"，而不是"Agent 正在工作"；列表里五六个转圈还各转各的。现在的标记是 `WorkingGrid`：一个 3×3 的方块网格，随两道横跨整个页面的波起伏。每个方块按自己在页面上的位置取样，所以相邻行的图标看起来是同一片水。动画完全交给合成器：每个方块是两层嵌套的 HTML 元素，每层对应一道波，只通过 Web Animations 改变 `transform` 和 `opacity`，并把起点固定在文档时间线的原点，每帧不跑任何脚本。主要尚未测量的成本是图层数量：每个标记有 18 个小的动画图层，还没有在打包后的应用里做过性能剖析。

## 问题

- 转圈的含义是"请等我"；而会话在工作的含义是"我正在替你忙"。产品希望它更安静、更贴合品牌（水母、水），同时保持专业感。
- 同一列表里多个转圈不同步，会吸引视线。作为一个整体一起运动的标记，比各自闪动的标记更安静。
- 任何替代方案都必须遵守 [spinner 笔记](../bug-fix/2026-09-13-spinner-off-svg-retina-composite.zh.md) 和 `components/shared/AGENTS.md` 已经确立的约束：Agent 运行期间不能每帧占用主线程。

## 设计

外观是和产品负责人一起，通过独立原型反复迭代确定的：像素水母和点阵"一小块海"显得太卡通或太吵；呼吸点、圆环、气泡和点击涟漪都试过并放弃了。最终保留的形态和默认值：

- 3×3 方块，圆角为方块边长的 30%，间距为方块边长的 0.35，整体 14px。
- 两道平面波，长度 3.2 和 4.4 格（再乘以波长系数 1），周期 1.9s 和 2.7s（19:27，图案约 51 秒才重复一次），分别往右下和左下传播。方块最大为所在格子的 0.8，从中心缩放，最小到格子的 0.3；亮度随波变化，最低到 0.16 不透明度。
- 波长要和标记差不多大。波长 1.5 时，两道波的波谷可能同时盖住全部 9 个方块；对 40 行拼接后的列表做模拟，整个标记低于满亮度四分之一的时间约占 9%。波长 1 时降到约 0.9%；0.8 可以降到 0%，但图案显得杂乱。有一条测试守住默认值下的下限。速度不影响这一点。
- 整个页面是同一片海：方块的相位只取决于它在页面上的位置。在列表里会跳过行与行之间的那段海（"拼接"，`rowPitch = 28`）：14px 的标记只占 28px 行高的一半，不拼接的话，波在相邻两行之间走过不止一个波长，相邻图标看起来毫无关系。

## 实现方式

| 方案 | 结果 |
|---|---|
| rAF 循环逐帧写样式（原型的做法） | 放弃：每帧都有主线程工作和重绘，正是 spinner 修复要去掉的成本。 |
| CSS 关键帧 + 每个方块不同的 `animation-delay` | 放弃：CSS 动画从元素挂载时开始计时，不同时刻挂载的标记会落在不同的海面上。 |
| **Web Animations，`startTime = 0`，按相位计算每个方块的延迟** | 采用：由合成器驱动，并且无论何时挂载，所有循环都对齐到文档时间线。 |

两道正弦波相加无法写成一个关键帧循环，所以每个方块嵌套两层，每层对应一道波，两层的缩放和不透明度相乘。每层只覆盖完整范围的平方根，因此两个波谷叠加时正好落在最小值上。两道波相乘和原型里的相加观感一致：波峰叠波峰最大，波谷叠波谷最小。

`prefers-reduced-motion` 以及不支持 `Element.animate` 的引擎会显示静止的网格。超椭圆方块通过 CSS `corner-shape` 提供（Chromium 139+，Electron 39 自带 142）。

## 调参入口

Storybook 里的 `UI/WorkingGrid` 把所有参数都做成了控件（形状、亮度、缩放方式、最小尺寸、间距、波长、方向、拼接），另有一个按真实尺寸搭建的 `SidebarSimulation` story：28px 行高，行尾状态位在悬停时换成 Archive 按钮，工作中的标记旁边还有等待确认和未读标记。

## 验证

- `tests/working-grid.test.tsx`：延迟在任意时间线时刻都能还原出传播的波；拼接让相邻行在海面上连续；全部 18 个动画都作用在 HTML 元素上、只改 `transform`/`opacity`、`startTime` 固定为 0，并在卸载时取消；减少动态效果时保持静止；侧边栏行尾状态位在工作时显示网格。
- 在 Storybook 里渲染并截图检查过。
- 尚未完成：在打包后的 Electron 应用里、多个会话同时运行时，做一次渲染进程 CPU 和图层的性能追踪。把网格推广到其他界面之前，应该先做这项检查。
