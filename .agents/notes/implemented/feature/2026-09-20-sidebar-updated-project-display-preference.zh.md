# Updated 项目标识支持隐藏并弱化显示

Status: implemented
Translation: current

[English](2026-09-20-sidebar-updated-project-display-preference.md)

## 摘要

Updated 行新增的项目行更容易辨认来源，但也会让每一行变高，而且彩色 GitHub 头像会和会话标题争夺注意力。现在侧栏视图浮层会显示一个持久化的「显示项目」开关，默认开启；GitHub owner 头像则显示为轻量的中性灰标记。这个入口留在现有浮层里，因为它是低频的视图偏好，不是侧栏的主要操作。

## 决定

浮层保持传统菜单形态。「视图」和「任务」是两组扁平的单选菜单项，统一使用图标、文字和右侧勾选布局。「显示项目」放在两组菜单项最下面，使用独立 Switch，因为它是持久化的显示偏好，不是筛选选项。选择菜单项后浮层关闭；切换 Switch 时浮层保持打开。这个开关在 Project 模式中也保持可见，但整行处于禁用状态，并在右侧 Tooltip 中提示「仅可用于『最近更新』视图」，避免它的存在和已保存状态随着视图切换忽隐忽现。Hover 命中整行，但只改变 Switch 轨道底色，行背景、图标和文字保持不变；触摸设备点按禁用行会打开同一提示，键盘 focus 也可访问。

`sidebarUpdatedShowProjectNamesAtom` 把全局显示偏好持久化到本地存储，默认值为 `true`，延续原先的[项目上下文决定](2026-09-20-sidebar-updated-project-context.zh.md)。关闭后，Updated 模式中的普通行和置顶行都会去掉完整的第二行。嵌套的 opened Session 在两种状态下都保持单行。
项目行相对标题起点向右缩进 16px，在不改变左侧状态槽的前提下明确它是次级信息。

只有 GitHub owner 头像使用自适应明暗归一化。缓存图片加载后，通过 16px canvas 采样计算按 alpha 加权的平均亮度。不透明的深色头像逐步降低对比度、提高亮度并拉向 68% 灰；带有大面积透明背景的图标使用 76% 目标和更强的对比度压缩，让可见黑色区域接近普通头像，同时避免把完整头像洗得太浅。亮度达到 65% 的源图仍保持原始亮度和对比度，界面只去色并应用 80% 透明度。这个单向映射不会压深浅色源图。当所在行变为 active 时，filter 和透明度会用 200ms transition 恢复原始彩色；单纯 Hover 不改变头像，减少动态效果的用户则直接切换。头像以 16px 显示且不叠加底色方块。Canvas 或 CORS 失败时使用中间默认值。文件夹和 Chat 标记本来就继承弱化的前景色。这个计算保留共享头像来源和加载失败回退逻辑，不需要生成另一份图片资源。

## 备选与取舍

在侧栏行旁边常驻一个图标，会让低频偏好和导航、行操作争夺空间。把偏好嵌套在「最近更新」下面会错误暗示导航层级，也会让菜单在切换时改变形状。分段控件又会让这个小浮层更像设置面板，不像菜单。放在底部的 Switch 让显示偏好始终可见，也让它与互斥的菜单选项使用不同控件。

文案使用「显示项目」，直接表达开关动作。项目行可以表示仓库、本地文件夹或 Chats 分区；当会话没有仓库或文件夹名称时，仍会用 `Chats` 作为分区回退名称。

## 验证

筛选浮层测试覆盖两组扁平菜单项、底部 Switch、勾选状态、关闭行为和切换回调。侧栏测试覆盖隐藏 Updated 普通行和置顶行的项目行，项目上下文测试检查单向自适应明暗和 active 行样式。`Updated Mode · Show Project Overview` Storybook story 把置顶、Chats、本地项目、多种 GitHub 来源、active 行和打开的菜单放在同一画面中用于视觉检查。
