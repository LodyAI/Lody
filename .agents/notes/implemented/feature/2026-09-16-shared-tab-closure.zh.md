# 会话标签页共享关闭状态

Status: implemented
Translation: current

[English](2026-09-16-shared-tab-closure.md)

## 摘要

原先主标签无法关闭，子标签关闭时会归档或删除会话。现在使用共享的
`SessionMeta.isTabClosed` 表示标签可见性，不触发生命周期清理。
已关闭列表也包含历史归档，重新打开时执行恢复。选中状态仍为本地导航，
并能明确表示工作区内的空白会话区域。

## 决策与证据

未采用窗口本地关闭方案：工作区共享打开的对话集合。只共享关闭标记，
选中状态和排序继续由现有 URL／本地存储管理。确认关闭后才针对当前 URL
进行有限替换，缺失元数据不能被判断为关闭。这扩展了[路由约定](../../../docs/sessions-tabs-routing.md)。

归档仍是生命周期操作，目标遵循[会话关系](../../../../specs/session-relations.md)。
历史归档直接进入统一已关闭列表，不批量改写。重新打开保留恢复检查以及子会话
独立关闭标记。新的关闭写入不影响运行中的任务和 worktree。

[Spec](../../../../specs/session-tab-closure.zh.md) 保持 draft。Hook、标签、路由、移动端
测试及组件类型检查验证实现；副本测试覆盖真实 LoroRepo 元数据边界。
新旧客户端混用时无法保证一致标签体验。单元测试不能证明私有宿主字段白名单
和原生应用端到端行为。
