# PR 网络图片

Status: implemented
Translation: current

[English](2026-11-02-pr-remote-images.md)

## 摘要

PR 描述和审查内容中的 HTTPS 图片可能被桌面渲染器的图片策略拦截。
本机偏好默认关闭自动加载；用户也可逐张选择加载。隔离的沙箱文档允许
加载 HTTPS 图片，同时保持主渲染器策略不变。图片网站会收到用户的网络
请求，私有附件仍可能需要身份认证。

## 决策

直接放宽主渲染器的 HTTPS 图片策略会影响其他图片界面。只有用户明确
选择或开启自动加载后才挂载仅用于图片的沙箱文档，并通过 URL 片段传入
地址。该文档使用独立的限制性策略，不发送来源页面，仅接受 HTTPS 地址。
设置和单张授权不会向私有网站提供凭据；匿名分享内容仍遵守原有的禁止
网络图片边界。
