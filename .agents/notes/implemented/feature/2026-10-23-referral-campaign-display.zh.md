# 服务端选择的 referral 活动展示

Status: implemented
Translation: current

[English](2026-10-23-referral-campaign-display.md)

## 摘要

固定的推荐折扣和返利比例会在限时活动期间承诺错误价格。公开客户端现在根据服务端条款展示折扣、返利、首笔付款金额、活动时间和原生分享标题。订阅查询不会仅因时间流逝重新执行，因此页面在活动边界和已有结账页到期时主动刷新。已有结账页保留的优惠与新订单价格分别说明，实际扣款和奖励资格仍由云端负责。

## 决策与职责

本变更在[推荐奖励视图](2026-10-14-workspace-referral-view.zh.md)和
[统一奖励金](2026-10-18-uniform-referral-credit.zh.md)基础上，为 `@lody/cloud-api`
增加可选展示条款。旧响应仍按 10% 折扣、20% 奖励展示。客户端不接收 Coupon ID，
也不提交自行选择的返利比例。客户端开始发送 `policyRefreshKey` 前必须先部署兼容后端。

概览、结账预览、详情和分享标题使用返回的比例。推荐卡片在提升的活动比例旁用删除线展示
常规 9 折和 20% 返利；常规比例仍用普通文字。月付、年付首笔金额按对应周期价格计算，
续费仍展示常规价格。活动文案只显示按 UTC+8 计算的日期，结束日期取最后一个活动日，
不展示时刻、时区说明或付款时限提示。当前新订单价格与
已有结账页保留的优惠分别说明，因为修改套餐、席位或返回入口可能创建新订单。

共享刷新 Hook 按服务端下一时间边界刷新；若客户端时钟略快、服务端仍返回旧边界，
继续重试。页面恢复焦点或可见性时也检查；结账预览还在已有 Session 过期时刷新。
没有待处理边界时不进行固定分钟轮询。埋点附带展示中的活动 ID 和比例，保留既有事件
去重身份，也不会根据浏览器返回页面推断付款成功。

## 证据与限制

确定性 UI 测试覆盖活动年付金额、已有与新订单价格区别、时钟略快时的重试和恢复焦点。
Storybook 包含活动卡片、活动年付和保留优惠状态。金额及资格约束由后端测试负责。
代码变更不代表完成真实 Stripe 付款或生产部署。
