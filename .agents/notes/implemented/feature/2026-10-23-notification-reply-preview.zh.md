# 终态通知中的回复摘录

Status: implemented
Translation: current

[English](2026-10-23-notification-reply-preview.md)

## 摘要

终态通知原先只显示项目、PR 和任务上下文，无法直接看到 agent 的结果。现在追加已结束 assistant 轮次最后一段非空文本的摘录，最多 200 个 Unicode 码点。执行释放前冻结输出 entry ID，避免后续轮次的回复串入通知。手机摘录经过现有云端及推送商，是回复原文片段，不是脱敏或模型生成的摘要。原生设备展示尚未验证。

## 职责与取舍

本变更扩展[通知设计](../../proposed/architecture/2026-10-13-agent-native-attention.zh.md)的展示能力，包括此前手机载荷仅带名称的取舍。执行事实携带可选 `assistantTurnId`，不改变资格、收件人、投递身份、取消或生命周期。MessageHandler 在执行释放后读取确切输出，沿用已有有界来源读取；输出缺失或不可读时保留原上下文。读取最新回复会与后续执行竞态；用最初输入定位会在自动汇总时读到旧输出，因此都不采用。

`notificationReplyPreview` 兼容历史中的未知 item，只选 assistant 顶层 text，不读思考、工具或子 agent 输出。它折叠空白及控制字符，超长以省略号截断。可选 `presentation.replyPreview` 允许 400 个 UTF-16 单元以容纳 200 个 Unicode 码点。共享格式化在原上下文后换行追加摘录，无上下文时直接使用摘录。授权、提问和待处理通知忽略此字段。不新增模型调用、meta 载荷、历史扫描或重试。

最新控制投影和可选云端 DTO 携带相同摘录。云端消费者需先支持新字段，再发布 producer，不增加降级路径。Local composition 继续零云端请求。回复本身可能含路径或代码，本变更不承诺内容脱敏。本次展示改动沿用已有 backend 读取和投递所有者，不改变取消、交接与故障恢复，因此不扩展为原生 Effect 迁移。

## 证据与限制

共享通知测试覆盖文本选择、Unicode 长度、中英文格式、请求排除和空内容兜底。CLI 测试覆盖已有更新回复时仍选择本轮输出、输出缺失或不可读，以及执行身份冻结。原生系统截断、设备送达和点击需要真机验证；本变更不代表已部署。
