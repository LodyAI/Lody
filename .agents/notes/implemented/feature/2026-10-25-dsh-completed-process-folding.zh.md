## 摘要

DSH 的每段思考独立显示，却无法整体收起已完成的过程。现在复用共用的已完成过程
折叠：生成时正文保持可见，完成后收起前面的过程并保留最终回答。展开后恢复按
顺序排列的思考、正文和工具行。没有可见回答的回合仍保留共用的中断保护。

## 决策与范围

本次仅替代[独立显示决策](2026-10-22-dsh-independent-text-tool-display.zh.md)中的
外层折叠例外。保留思考与工具分组及回答排版，移除 DSH 对现有分段完成折叠策略
的豁免，不增加第二套折叠实现。最终连续回答正文和结果附件遵循共用布局约定。
搜索可同时展开外层过程与内层思考分组。耗时恢复共用的桌面折叠标题/移动端页脚
策略。Provider 传输、存储历史和其他 Provider 不变。

现有[思考可见性 Spec](../../../../specs/deepseek-thought-visibility.zh.md)同步此次
请求的行为，仍保持 draft，不宣称已获批准。

## 验证与限制

三个所属分组/行测试套件通过 32 项测试。隔离的 AST 配置加载真实行构造器及其
传递依赖声明，排除无关 UI 渲染器。覆盖完成、整体展开/收起、嵌套搜索展开、
独立开合、Provider 缓存变化、中断及既有计划分段。DSH Storybook 用例增加
收起/展开/再收起交互，并保留字体排版断言。

嵌套工作区未安装依赖，根级 `pnpm check` 和 `pnpm format` 因缺少执行程序无法
完成。借用依赖仅支持隔离验证，不代表完整应用构建或已执行 Storybook 交互测试。
未进行桌面视觉验证。

普通配置下分组套件通过 13 项测试，其余两个 UI 套件因缺少 `@pierre/highlights`
及借用的旧 UI 包缺少导出而无法加载。修改代码的定向 lint 无错误，格式化完成。
文档检查仍有缺失子模块链接错误；本次文档没有检查错误。
