# Bub 主动能力测试与安装恢复

Status: implemented
Translation: current

[English](2026-09-16-bub-capability-test.md)

PR: [#743](https://github.com/LodyAI/Lody/pull/743)

## 摘要

Bub 创建界面隐藏了能力测试入口，安装问题要离开窗口后才能看到。现在窗口提供测试
按钮，跟随持久化设置任务显示验证进度，并在配置发布后提供刷新按钮。缺少运行时
复用已有安装指引和重试界面，刷新失败也提供安装帮助。测试成功可以直接添加 provider，
关闭窗口不会取消持久化设置任务。

## 决策

本次调整了[最初 Bub 接入](2026-09-11-builtin-bub-provider.md)的创建界面选择，保留
验证成功才发布配置、由用户管理运行时的约束。行为记录在
[草案 Spec](../../../../specs/bub-provider-verification.zh.md)中。

直接显示通用测试按钮会同时启动后台设置任务和第二次 ACP 刷新。因此，创建界面观察
provider 列表使用的设置任务与已发布配置 atom。设置任务未完成时固定配置和 provider
类型，重试和删除使用已有持久化命令。配置发布后，刷新和保存使用同一配置，不再重新排队。

安装命令与指南链接提取为一个共享展示组件。设置任务保留服务端对运行时缺失与其他失败
的区分；已有 provider 刷新失败时，在原错误信息旁显示安装指南。

## 验证

现有配置窗口测试覆盖设置失败、安装指引、持久化重试、发布及后续刷新，同时覆盖已有
Bub 的刷新失败恢复和旧版 daemon 限制。设置行及写入测试覆盖复制与打开指南、持久化
取消流程。Storybook 添加 Bub 安装恢复状态。这些 UI 测试不覆盖真实 Bub 进程执行。
