# 选择聊天消息并导出为图片

Status: implemented
Translation: current

[English](2026-09-08-chat-share-image.md)

## 摘要

分享整个会话无法让用户控制哪些消息出现在会话卡片上。聊天界面现在拥有临时的消息选择，并把快照
传入独立的样式预览。选择按消息 ID 跨虚拟行跟踪，支持拖拽矩形与边缘滚动。元数据取自选中的历史
而非当前模型选择器，token 数仍是粗略的文本估算。样式化卡片可以保存为 PNG 而不对外发布。

## 决策

预览接受已经选好的消息，而不是内嵌第二个会话选择器。每条助手消息是一个选择单元，包含其折叠的
工作内容。选中的正文会被渲染，另有一个独立的数值估算涵盖存储的思考、计划、工具参数、输出与
diff。任何隐藏的工作文本都不会被复制进预览负载。

最后一条选中的助手消息提供模型标签；聚合混合模型被刻意排除。自定义 Runtime 名称从当前会话配置
解析。选择状态与预览快照都是本地 React state，不做持久化、不发起云端调用、不修改消息记录。

PNG 导出使用懒加载的 `@zumer/snapdom` 截取预览内自然尺寸的卡片，排除其缩放滚动容器。字体与图片
在截取前完成加载；二维码生成是该操作的闸门。原生保存由既有的 Electron 图片桥拥有，浏览器则下载
一个 Blob URL 并在之后释放。取消保存不算错误。对话框让导出错误保持可操作，并阻止重复请求。

## 证据与限制

[规格草案](../../../../specs/chat-share-image.md)拥有既定行为。合成测试覆盖拖拽区间、反选、边缘
滚动、元数据提取与 token 估算。`SessionConversationPage` 的分享 story 在合成历史周围组合了生产
环境的标签栏、头部菜单、消息流、选择 hook、输入框与预览对话框。它们从普通聊天开始，支持本地提交
消息，并在预览往返过程中保留草稿与选择。Storybook 还覆盖了无背景的明暗卡片。导出测试覆盖浏览器
下载清理、原生保存的取消/失败以及非法截取结果；它们 mock 了栅格化，不能证明像素保真度。未执行
自动化截图。在固定 submodule 与 Node 22 的隔离 checkout 中，工作区类型检查、lint、测试、翻译
检查、文档检查与仓库边界守卫均通过。测试需要为其临时仓库禁用 Git 提交签名，并在本地安装 Electron。
