# 附件上传期间发送消息

Status: implemented
Translation: current

[English](2026-09-21-composer-send-during-upload.md)

## 摘要

正式 Session 输入框现在用同一个提交生命周期贯穿附件上传等待和下游接收。
输入框锁住草稿，等全部选中附件就绪后，保留快捷键意图并按当前路由发送一次。
取消或失败会恢复草稿。单元测试和浏览器测试验证了前端边界；原生 provider 投递和重启恢复不在此次验证范围内。

## 决策

实现见 [PR #879](https://github.com/LodyAI/Lody/pull/879)，契约见
[草案 Spec](../../../../specs/composer-send-during-upload.zh.md)。
复用已有提交 token，在上传就绪后调用最新 committed handler。
在旧 handler 内等待会保留过期路由；由上传回调重新提交容易重复发送。
等待由事件驱动，不使用计时器。File 身份校验允许图片转换成本地文件，同时拒绝缺失或替换的附件集合。
运行配置和 Role 在实际发送时一起解析；持久 outbox 和按键时冻结配置不在范围内。
焦点交互继续遵循[已有决策](../bug-fix/2026-09-12-composer-click-focus.md)。

提交期间配置控件不可操作，防止通过当前输入框修改配置，同时保留实时路由。
父组件提供可见性，包括分享选择模式造成的隐藏；它只限制新提交，已挂载的隐藏输入框继续已有等待，卸载仍取消。实现及行为测试已进入普通源码和测试套件，
隔离 patch runner 已移除。顶层新聊天落地页仍然阻止上传期间发送。

## 边界发现

| 复现的问题 | 修正 |
| --- | --- |
| 延迟接收清空了通过公开 imperative handle 写入的新文本；原输入框已有该问题。 | 只清理仍与已接收快照一致的字段，保留替换后的内容。 |
| 隐藏输入框在没有上传时仍接受合成 Enter。 | 提交入口检查可见性；隐藏不再取消已有等待。 |
| 上传就绪清空 mutable ref 却未触发渲染，慢接收期间仍显示可点击的 Cancel。 | 用显式等待/提交阶段移除“取消发送”；延迟接收测试检查按钮和配置锁。 |
| 之前失败的普通文件立即取消了新图片的有效等待。 | 仅检查本次选中文件的失败状态，排除已经失败的普通文件。 |

先加入边界测试得到三个断言失败，修正后通过。其他覆盖包括准备/验证阶段、其他附件尚未结束时部分失败、
机器移除、历史刷新、Role 加载、轮次限制、取消后重提、A → B → A、外部文本变化、附件移除，
以及就绪 commit 内的 scope 切换。这些是前端边界验证，不表示每条路径都能通过普通实体键盘操作触发。

## 消融证据

正式接入前的隔离 worktree 实验分别移除了 12 个保护。
每个变体均收集全部 82 项测试，并让对应行为断言失败；进程或编译失败不计为检出。
这是隔离实验的历史证据，不是重新执行的正式源码消融套件。

| 移除的保护 | 失败测试数 |
| --- | ---: |
| 最新 committed 发送回调 | 3 |
| 同步提交锁 | 2 |
| 等待期间可见性取消 | 1 |
| 隐藏输入框提交入口守卫 | 1 |
| 选中附件失败后立即取消 | 1 |
| 附件集合校验 | 1 |
| 等待后的草稿身份校验 | 1 |
| 仅接收成功后清理 | 16 |
| 接收时保留新文本 | 1 |
| 排除已失败文件 | 1 |
| 保留快捷键反转意图 | 1 |
| 就绪后检查当前 token | 1 |

当前 token 消融最初通过全部 81 项测试，因为普通卸载测试同时受到等待失败结算保护。
新增确定性的父组件 layout effect 在就绪 commit 中切换 scope，暴露了遗漏的时序。
保留 token 检查时通过，移除后错误发送旧 payload；没有依赖真实 sleep、计时器、网络或机器负载。

## 结果与限制

正式源码通过 82 项测试（62 项输入框、20 项路由）和组件类型检查。
安装的 Chrome 在 390px 和 1280px 宽度下通过八项浏览器用例：Enter、Cmd+Shift+Enter、取消、上传失败。
测试使用真实 Storybook 输入框和 XMLHttpRequest 传输，拦截上传响应并延迟下游接收回调，附件为合成数据。单元回归测试先复现了失效 Cancel，再验证显式阶段修正。

原隔离实验检出全部 12 个消融，普通测试套件保留仍适用的边界用例。产品决定切 Tab 保留已提交意图后，原可见性取消用例已替换为隐藏 Tab 继续发送的覆盖。
有限消融不能证明不存在其他状态交错。daemon 投递及实体 Electron/移动设备焦点行为仍未验证。
等待仅保存在内存中，不支持重启恢复。
