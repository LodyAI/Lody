# 通过显式分享链接阅读原始会话

Status: implemented
Translation: current

[English](2026-09-09-session-sharing.md)

## 摘要

一个实时会话链接必须提供持续访问，同时不授予接收方工作区成员身份或写权限。客户端现在把显式的
目标选择器与一个隔离的、纯内存的原始 Loro 流阅读器结合起来。链接密钥属于创建它的设备，并以 bearer
凭据的形式发往分享 API。读取原始流保留了历史与实时更新，但也会暴露超出当前展示范围的已存储内容；
分享告知文案陈述了这一取舍。托管侧授权与原生设备端的接受流程仍是独立的验证责任。

## 决策与边界

[规格草案](../../../../specs/session-sharing.md)拥有既定行为；
[分享模块规则](../../../../packages/components/src/components/sharing/AGENTS.md)拥有实现不变量。
本记录与[本地图片导出](2026-09-08-chat-share-image.md)互补，后者捕获的是选定快照，而不是授权持续
的流访问。

复用原始流避免了维护第二份消息投影，并保持既有的快照与更新兼容性。它刻意放弃了字段脱敏与逐条消息
发布。相关 Tab 只是发现提示；读者能打开什么完全由显式选择与已授权 manifest 决定。独立的子链接保留
各自独立的权限。

```text
支持云端的客户端
  管理对话框 -> 公开云端 DTO -> 分享服务
  创建/重置成功 -> 设备密钥 -> 显式宿主链接

匿名阅读端
  链接 fragment -> bearer API -> 已授权 manifest
  选定目标 -> 一个内存中的 LoroDoc -> 共享消息渲染器
  附件引用 -> bearer API -> 临时 object URL
```

分享来源由宿主提供。公开包中不含托管部署默认值、后端实现或生成的后端 API。本地 composition 通过
既有的能力边界隐藏管理功能。阅读端不挂载已认证的应用，其流适配器在只允许读取的方法/路径闸门之外
独立禁用上传。

设备密钥是凭据而非可替换缓存。预期版本与身份检查可防止一个迟到的管理结果把密钥保存到另一个账号，
或接受一次过时的编辑。若成功获取的密钥未能持久化，会保留一个临时复制操作并说明之后需要重置。

## 重连相关发现

流 SDK 会重试实时读取，但初次加入失败会移除其状态监听器。仅在同一传输层上重试，可能让页面永久停在
暂停状态或丢失后续状态更新。阅读端保留原有的 LoroDoc，仅针对可重试的初次失败重建已关闭的传输层，
并使用有界退避。销毁与访问被拒会取消待重试；不可重试的失败不会启动重试循环。

## 证据与遗留限制

合成的[阅读端测试](../../../../packages/components/tests/session-share-reader.test.ts)覆盖只读传输、
快照、增量更新、失效与初次加入的恢复。
[管理测试](../../../../packages/components/tests/use-session-share-management.test.tsx)覆盖凭据
持久化、身份变更、版本冲突与显式来源注入。候选项、密钥存储、管理器与移动端菜单的测试覆盖各自的公开
客户端边界；受控的 Storybook 界面使用合成数据。

实现期间执行了本地类型检查、测试与隔离的浏览器集成；PR 闸门必须验证最终集成后的修订。公开测试无法
证明托管侧的 token 强制、服务复制、附件生命周期配置或原生设备的键盘行为。规格草案仍未获批准，其
翻译待补。实现审阅：[PR #539](https://github.com/LodyAI/Lody/pull/539)。
