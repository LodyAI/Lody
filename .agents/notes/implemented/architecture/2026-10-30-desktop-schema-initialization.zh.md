# 消息 schema 初始化内存

Status: implemented
Type: architecture
Translation: current

[English](2026-10-30-desktop-schema-initialization.md)

## 摘要

重复构造基础 Zod schema 会增加桌面启动内存。消息合约现在复用三种私有字符串规则，保留独立导出的 ID schema、字段约束和图片元数据的 null 预处理。两轮生产构建对照中，主进程和渲染器在 GC 后的存活 JS 堆合计减少 5.26–5.45 MiB。范围更广的约 20 MiB 共享实验为选型提供证据，但不是本次实现；整个应用的物理内存收益和长时间运行行为仍未证明。

## 决策

`packages/shared/src/message-schemas.ts` 在 344 处等价初始化位置复用普通字符串、可选字符串、去空白非空字符串。规则是私有常量，没有运行时缓存或构建变换。其他字符串规则、回调、refinement、其他模块中的 schema 和导出的 ID 实例保持独立。字段专用约束和元数据应从基础规则派生；Zod 的 `.register` 会修改与实例身份绑定的 registry，不能直接用于共享基础规则。解析仍使用各字段自己的 issue 路径。

临时跨模块工厂缓存曾在 57 个模块的 2,393 处源码表达式中共享 629 种封闭的基础类型与包装表达式。其更大的收益不足以支持引入自动 interning：共享身份会影响元数据和引用提取，机械替换的范围也会掩盖第一步小改动。因此实现选择单个归属模块中的显式声明。

## 测量

所有观察使用 macOS 27.2 arm64、Electron 44.9.3、Zod 4.3.6 和 Node 24.22.1 驱动。每次运行独占全新的 OSS 本地配置目录和端点，完成引导并显式执行 GC，主进程 argv 和渲染器 URL 对应实际构建。生产范围对照基于 main `39c252437a9b265d43df364baa5752ba657cac19`，基线构建替换回原始消息模块。两组使用相同的 bundled CLI，因此只测量主进程和渲染器；这一对照从不启动 Playwright tracing。

| GC 后存活 JS 堆，MiB | 原始消息规则 | 共享消息规则 |
| --- | --- | --- |
| 主进程 | 50.17–50.19 | 48.33–48.34 |
| 渲染器 | 80.28–80.33 | 76.73–76.86 |
| 配对合计减少 | — | 5.26–5.45 |

之前的广范围实验使用 `54b3f19e570c6b001e3f98ce825f85df2b38e739`，包含独立的 [MCP 入口变更](https://github.com/LodyAI/Lody/pull/2099)，在采样前关闭 Playwright tracing。跨模块共享让主进程堆从 50.14–50.22 降至 43.35–43.44 MiB，渲染器从 80.19–80.47 降至 66.88 MiB，合计减少 20.19–20.29 MiB。第一组快照中的实例数分别从 3,657 降至 2,386、从 6,290 降至 3,601。另一个对 237 处消息声明添加 pure 初始化标记的实验，主进程为 50.77–50.78 MiB、渲染器为 80.39–80.40 MiB，没有减少存活堆。

[样本与条件](assets/2026-10-30-schema-memory.json)分别保留各实验。广范围实验的主进程 footprint 为 213.6–216.3M 对 174.7–176.1M；渲染器范围重叠，为 275.1–315.8M 对 274.1–278.9M。RSS 包含共享映射；压缩、分配器状态和图形内存归属使这些样本不能换算为唯一物理内存总量。`vmmap` 无法检查 PartitionAlloc。

独立的四会话合成实验中，渲染器有 6,720 个可达 Zod 实例，主进程有 3,657 个。排除弱引用、按 Zod 根实例去重的 dominator 子图分别拥有约 32.0 和 18.2 MiB，表示归属而非全部可回收预算。八条约 128 KiB 的代码回复后返回主页，预热后的渲染器堆从 90.9 变为 101.0 MiB，DOM 从约 43,000 降至约 4,000，有界 token 缓存拥有约 9.47 MiB；关闭空闲高亮 Worker 的 footprint 差异约为 3M。这台 Mac 上的文件监听在空目录、20,000 个文件及实际仓库之间，RSS 为 61.6–61.8 MiB、footprint 为 13.1M。这些观察不足以支持修改驻留策略，独立[会话驻留提案](../../proposed/architecture/2026-10-17-session-residency.zh.md)中已撤回的历史实现与本决策无关。

## 兼容边界

归属的[消息测试](../../../../packages/shared/tests/message-schemas.test.ts)固定独立 trim、普通可选字符串与图片 null 元数据、issue 路径和 inline JSON schema 输出，现有 RPC/history 测试覆盖消费边界。178 个导出 schema 的基线比较中，默认 draft-7 输入 JSON schema 和 3,382 组有效/无效输入的解析结果相同。锁定的 MCP SDK 使用相同的默认 inline 转换。显式指定 `reused: 'ref'` 后，共享会改变引用提取结构；该选项的字节级一致不是本变更的保证。

更广的临时构建还完成了合成 ACP 配置、长回复、回主页/重开，以及真实 `machineRpc.send` 畸形 IPC 拒绝检查，但不能替代产品范围验证。打包发行版、其他平台、真实模型 runtime、启动延迟和 CLI/daemon/MCP 内存收益均未作保证。本决策不替代活跃 Note；MCP 入口和测试模块依赖图决策属于不同的加载边界。
