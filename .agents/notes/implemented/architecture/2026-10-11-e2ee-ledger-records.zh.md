## 摘要

候选账本可通过反射构造视图或注入宽松验签器接受伪造权限。本次迁入严格记录解析、签名与链检查、确定性权限回放，使用已合入的基础验签和私有状态视图。可信创世及预期链尾由调用方提供，不从 URL、快照或日志建立信任。快照背书与恢复、旧式非原子成员移除均不开放；产品接线留待后续。

## 范围与证据

基线为公共 main `2e9482723e869fca7bea52fd5f036a37c53787e1`，包含已合入的 P07-a #1405。实施前核对开放 PR，没有重复账本切片。不复制 P07-b、私有依赖、CAS、journal、恢复库、服务或生产开关。本次通过独立子入口扩展[基础提取](2026-10-10-e2ee-foundations.zh.md)，不修改根密码模块或根导出。

只读候选的原始源码和测试复制到独立临时目录并使用独立 Vitest 缓存，仅引用其已安装依赖。运行 `node node_modules/vitest/vitest.mjs run test/review2-e-api-boundary.test.ts test/review2-a.test.ts --reporter=verbose`，复现 **4 失败 / 3 通过**：

| 候选失败 | 本切片处理 |
| --- | --- |
| 反射 LedgerView 构造函数接受伪状态 | 无原型冻结视图；WeakMap 保存私有状态，复制视图不能扩展 |
| 注入 SignatureVerifier 接受零签名记录 | 固定 P07-a 严格验签，不提供可替换参数或服务 |
| Admin 快照接受没有个人设备或 R 的 Owner | 不提供快照导入或背书入口 |
| 明文 journal 可替换可信背书者 | 不提供日志恢复入口 |

这是候选既有 7 项 core 失败中的 ledger/trust 部分。信封入站/出站生命周期及换钥发布端中断恢复不在范围，继续保留；候选完整测试并未通过。没有把旧失败作为公共接口允许的行为迁入。

## 职责与取舍

解析和字节计算返回未验证值；完整验证和增量扩展在全部检查成功后才生成可信视图。持钥证明绑定可信创世及前一状态成员实例，权限按当前角色和设备种类求值。必须提供预期总记录数和链尾以检测尾部缺失，但不证明全球最新状态。检查所得 Map 的修改不影响权限，冻结条目的公开字节包装拥有副本。结构复制与反射构造不能创建权限。

保留候选已有字节域与支持的操作编号。旧 tag 2 的两步移除违反已定 D12，拒绝接受，原子替代由 P12 负责。快照迁入留后续，不开放未完成信任机制。只返回状态副本会失去安全增量起点；复制可注入验签则保留已复现绕过。本次没有选择新协议政策或新操作编码。

历史包保持已签署的 72 字节不透明值，不验证解密或承诺对应的密钥。加入期限保持可空签名字段，不新增历史回放的当前时钟规则。工作区绑定、新鲜度、在线准入、未来原子移除后的完整审计、快照信任及原生存钥仍由后续完成。
