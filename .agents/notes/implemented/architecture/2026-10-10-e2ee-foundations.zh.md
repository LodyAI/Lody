## 摘要

候选核心把字节格式与密码学连在实验账本和宿主代码中。本次提取独立公共包，
提供严格字节、规范 CBOR、内容 v0 上下文和验签。没有生产调用方、私钥操作或权限构造入口。
加解密、派生、账本策略和平台存钥仍需分别实现与验收。

## 决定与来源

从公共 main `249661be340af5a20b8d0b7334d2e923fe5b5a99` 开始，复用 Effect 4.0.2。
新包不依赖 Streams/repo；主线保持 repo 0.21.2、CRDT 0.16.2。固定候选密码学库版本，不换算法。
[来源指纹](../../../../packages/e2ee-core/provenance.json)记录候选
`bd5a9c1ec71ed7fa8085e51faec4f1e8dbe985b8`、准确源码哈希及提取调整。
候选有暂存改动，但所选源码均与该提交一致，始终只读。

整包搬运会引入无关账本和宿主职责。因此只保留一个入口和 Effect Result 返回值。
保留严格曲线点检查，不搬缓存和可注入执行器。HKDF salt 每次返回新副本，避免共享域字节被修改。
P14 可以从 `@lody/e2ee-core` 使用公钥、签名类型和验证函数；私钥及平台句柄由它负责。
[Spec](../../../../specs/e2ee-foundations.zh.md)保持 draft。

这是现有[传输契约](2026-10-10-workspace-streams-content.zh.md)下层的基础模块，
不改契约，不激活消费方。不产生持久数据，不改变普通工作区行为。
尚无消费方时，回退移除包及锁文件条目即可。

## 候选失败归属

在可丢弃副本使用候选依赖复跑原失败套件，没有改变候选源码或暂存区。
核心四套件 5 通过、7 失败；Lab review2-b-sync 12 通过、2 失败（需要回环监听权限）。
以下只确认归属，不代表接受失败：

| 候选套件 | 失败 | 负责范围 |
| --- | --- | --- |
| review2-a | 伪造 LedgerView（1） | 已验证账本权限 |
| review2-c-delivery | 读取限制、4096 信封耗尽 outbox（2） | 密钥投递 |
| review2-c-rotation | 丢失轮换发起者（1） | 换钥与恢复 |
| review2-e-api-boundary | 注入验签器、不可能的 Owner 快照、替换持久信任（3） | 账本与快照信任 |

没有迁入这些构造器、服务和策略，也不构造已验证账本视图或接受注入的签名判定。
A/R 额外扭转分量回归用例验证：即使库的带余因子方程接受构造的签名，本模块仍拒绝。

## 验证与限制

测试使用 RFC 8032 固定字节、独立原生签名的 v0 帧、CBOR 向量及负例，覆盖错组织／文档／用途、
未知版本和代次、绑定不符、篡改、字节所有权及 Effect 组合。来源内容域保持不变。
聚焦套件 42/42、类型检查和局部 lint 通过；浏览器目标 ESM 打包产物在 Node 中通过固定向量。
格式、文档（零错误）、冻结安装和边界检查通过。全仓 `pnpm check` 停在基线已有的
CLI Git 用例 `context_unreadable`：CLI 3707 通过、1 失败、4 跳过。
固定 main 的原始源码在临时目录也复现 5 通过、1 失败。此前沙箱 socket 失败在允许监听后消失，
shared 1365/1365 通过；components 5033/5033、Electron 215/215 通过。这不是全仓全绿；后续检查与 CI 记录在 PR 中。

这不是生产、平台存钥、浏览器／手机真机、AEAD、快照恢复或完整安全验收。
历史失败继续由所属模块处理。本次不发布、部署、开放功能或启用全平台 Beta。
