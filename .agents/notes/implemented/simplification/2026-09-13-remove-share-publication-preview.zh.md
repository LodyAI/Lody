# 移除发布预览

Status: implemented
Translation: current

[English](2026-09-13-remove-share-publication-preview.md)

## 摘要

发布不再包含预览步骤，Agent 请求的分享也一样。用户确认明确范围和披露说明后，
客户端冻结、上传并发布。删除独立预览消除了额外状态及其失败重试路径，
但仍要求用户确认和可靠保存读者凭据。

此决定替代[静态分享提案](../../proposed/architecture/2026-09-12-static-session-sharing.md)的预览要求。
移除预览组件、嵌入式读取模式、仅准备 Hook 操作、对应阶段、展开回调和公开的未发布历史解码器。
管理界面仅接收 `hasPending`，不再接收冻结包；内部重试身份和冲突处理仍保留。
不渲染未发布正文，仍说明图片包含、文件省略。附件查看和 OG 预览不属于此次删除范围。

测试覆盖显式 MCP 批准、冻结失败不上传、用户主动重试、复用冻结部署、关闭窗口后的凭据恢复。
明确接受的取舍是用户不再在发布前查看精确冻结字节。本记录不代表完成托管部署或视觉验收。
