## 摘要

产品移除不能等待新密钥才能撤权。原生成员管理提交普通记录，复用现有设置中的密钥更新入口。设备凭据明确确认整成员移除后，先停止并等待该工作区运行结束，再自动删除其托管本地数据。原设备核对与持久标记防止旧响应删除重新加入后的实例；这只保护诚实客户端，不是安全擦除，也不代表生产验收完成。

## 决定与职责

2026-10-27 owner 决定允许 Owner/Admin 移除成员，禁止 Admin 移除 Owner/Admin，禁止移除 Owner；仅 Owner 调整 Admin。UI 遵循这些权限，真正授权仍来自原生已验证账本。成员与密钥命令复用既有 `host.manage`、签名器和 SQLite 提交日志。只有显式 `rotate` 恢复尚未提交的换代 candidate，暂存失败不得阻挡独立移除或撤销。结果未知的 CAS 必须先按原件核实，已验证历史持久化后才确认消费；只有操作类型、成员 ID、角色（或设备目标）完整匹配，旧提交成功才能视为本次请求成功。tag10 前先声明 capability 1；旧 tag8 原子 API 保持独立。

移除保持 epoch/承诺，rotationRequired 仅提示。其余成员继续使用保留的 epoch，管理员在设置中完成密钥更新；换代失败不撤销移除、不阻塞发送。设置入口与红点由既有密钥更新实现负责，本 PR 不增加第二套换代流程。

凭据端点区分整成员移除与单设备撤销。目录/历史的通用拒绝或网络错误不得删除数据。宿主先核对发起请求的账号、工作区、创世、公钥和凭据仍对应当前本地身份，再保存终结标记、停止新运行，并在网络锁外等待工作区结束。账号协调器关闭该独立身份拥有者后取得既有独占身份租约才删除；其他进程繁忙则保留标记重试。新身份不得被删除；renderer 没有任意删文件或导出密钥接口。

已接纳的成员操作使用宿主自有的有界 history/ingest，不在注销/关闭等待该操作时重新获取账号锁。Renderer 先停止自身运行，再独立清理原账号/工作区/创世/签名公钥实例的数据：repo、游标和高水位另加窗口范围，待发送输入、跨窗口锁与广播按身份实例隔离。公开本地定位记录让冷启动直接得知移除时只找到以前安装的实例，定位缺失或不符不授权宽泛删除；全部独立存储成功前保留清理标记和单个范围内重试任务；删除不加入全局运行结束凭据，繁忙或失败不得阻止随后打开其他工作区，只有复用相同数据库的后继等待对应清理；另一账号或新邀请设备使用不同命名空间，renderer 重启后也不共用。CLI 先禁止内容操作、核对原身份并持久保存终结标记。close 排空历史/快照诊断后、释放 custody 前等待这个短本地阶段，不等待会回调父级 close 的完整删除任务；持久失败保留可观察错误，仍停止执行拥有者并通过终结关闭释放 custody/租约，不执行完整删除；回归确认父级未调用 close 时也能重新取得独占租约。执行和文档运行结束后，通过身份租约与配对互斥清理 custody、runtime，以及该账号/工作区目录下 `content/<genesis>/<signing-key>` 的原实例正文。LoroDocumentManager 持有原生共享身份租约期间打开同一路径；普通工作区路径保持。保留用户项目目录与其他工作区。新邀请/成员实例生成新设备密钥，拒绝旧成员实例配对。保留公开信任钉和很小的清理标记。离线副本只能在客户端得知移除后清理，其他已停止窗口的独立缓存在打开时自清理；不收回恶意副本、备份或既有外部副作用。

## 替代方案与组合

等待换代违背移除可用性；只按工作区编号删除会误删后来重新加入的实例；把所有无权限响应当移除会在单设备撤销、账号或网络失败时丢数据；独立成员日志会允许同一签名者并发存在未决提交；共用普通提交日志先核实 pending CAS 原件，未提交的换代 candidate 保持独立。

本独立分支合并公开 main `281f40a7`，已包含 [24-A](https://github.com/LodyAI/Lody/pull/1979) 和待定换代恢复修补 [#1987](https://github.com/LodyAI/Lody/pull/1987)。最终验证直接使用合并代码，已移除临时 core 覆盖；publisher 与 main 一致，原生回归通过共享管理入口覆盖设备撤销与成员移除。私有采用 [#3880](https://github.com/loro-dev/lody/pull/3880) 与后端移除 [#3876](https://github.com/loro-dev/lody/pull/3876) 已合入；这只证明源码组合，不代表线上产品验收。本分支组合已合入的 [#1980](https://github.com/LodyAI/Lody/pull/1980) 设置实现，已验证其管理状态看到移除提示、单一管理拥有者等待全部已接纳命令结束；共享加入接线仍需组合 review。旧 Spec 的强制原子移除和暂停发送文字按明确 MVP 决定修订，仍为 draft，不标记批准。

## 证据与限制

行为测试使用真实 crypto/原生 SQLite、确定性失败注入和完成信号，覆盖普通角色/移除记录、旧 epoch 可用、暂存失败与未知换代 CAS 的重开恢复、完整恢复意图匹配、丢 ACK 后重开复用原字节、原实例清理、凭据限定的删除信号、独占租约重试、成员历史请求期间关闭，以及 IndexedDB 删除被阻塞后其他工作区仍可用、机器执行拥有者结束后清理、新成员新钥、按范围删 IndexedDB、确认框与终结 UI。新增原生成员管理和清理测试对基线先 RED，再在本实现下 GREEN；最终组合使用已合入 main 的代码验证，无临时覆盖。旧的 CLI 工作区共用正文路径允许迟到的旧账号清理删除另一账号仍打开的数据库，关闭也可能在移除标记存在前释放 custody；两项回归在旧 head 为 RED，真实 SQLite 快照与显式信号下修补为 GREEN。Renderer 跨重启的对应命名空间问题由 IndexedDB 回归覆盖。短阶段等待保留在已登记 Legacy 入口，公开 Promise Repo 与父级生命周期回调仍是依赖，不宣称完成原生迁移。统一管理入口在实现前为 RED；撤掉完整意图匹配会使三项意图回归全部 RED。未知 CAS 回归要求暂存持续不可用时确实用原记录字节重试 CAS，随后确认成员已移除、换代仍为提示。临时恢复 #1987 前的 publisher 会使撤销与移除两项回归 RED；保持 main publisher 不变时两项 GREEN。构建后桌面 smoke 还发现移除错误类型静态引入整个云客户端，在 boot 前触发 ERR_PACKAGE_PATH_NOT_EXPORTED；错误类型现独立为宿主小模块，IPC 分类移除不会加载云传输。最终受影响测试数量和静态检查记录在 PR。

既发内容 token 按当前寿命自然过期（最多 15 分钟），主动废止 token 和断开已有长连接留作后续。真实钥匙串、Windows ACL/原生 ABI、安装应用重启、两个物理成员/设备、线上云端/gateway token 行为及 M5 执行尚未验收。未合入、部署、采用 gitlink 或发版。
