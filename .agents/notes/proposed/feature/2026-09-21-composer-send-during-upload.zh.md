# 输入框上传期间发送 POC

Status: proposed
Translation: current

[English](2026-09-21-composer-send-during-upload.md)

## 摘要

上传中提前发送，需要同一次提交生命周期覆盖等待上传与下游接受。隔离的真实输入框 POC
复现了三处边界缺陷，目前只在试验补丁中修正。最终 82 项正向测试与组件包类型检查通过，
12 项定向消融都触发行为断言失败。正式源码保持不变；本实验尚未验证实际客户端的可见性
传递、网络传输和 daemon 投递。

## 决策与隔离

遵循[草案](../../../../specs/composer-send-during-upload.zh.md)。复用现有提交 token 覆盖
两个阶段，再调用最新已提交的发送回调。直接等待旧回调会保留过期路由；上传回调重新
启动提交可能造成重复发送。等待由事件驱动，不使用定时器。File 身份核对允许图片转为
本地文件，但拒绝部分附件或被替换的选择。运行配置与 Role 在实际发送时一起解析；
持久化待发送队列和首次回车时固定配置不在本次范围。
现有[焦点决策](../../implemented/bug-fix/2026-09-12-composer-click-focus.md)继续负责焦点交互。

[运行器](../../../../packages/components/poc/send-during-upload/README.md)基于当前 HEAD
创建临时 worktree，应用一份可审查补丁。验证真实输入框、草稿缓存、提交 token 和路由
解析器，不发布试验功能，也不复制输入框实现。上传、本地文件交接和下游接受是模拟边界。
运行器复用已安装依赖，执行结束清理临时 worktree。当前工作区的正式源码、常规测试及
包清单均保持不变。

## 边界发现

| 已复现的问题 | 试验修正 |
| --- | --- |
| 输入框禁用期间，外部通过公开 imperative handle 写入的新文字被旧发送接受结果清空；此清理行为继承自现有输入框。 | 只清理仍符合已接受快照的字段，保留替换后的新字段。 |
| 隐藏输入框在没有待上传附件时仍接受程序触发的 Enter。 | 发送入口与上传等待都检查可见性。 |
| 先前失败的普通文件立即取消新图片的有效发送等待。 | 失败判断只覆盖本次选择的文件，已有失败文件仍被排除。 |

先加测试，实际出现三项断言失败；修正后扩展测试通过。进一步覆盖准备/验证阶段、
其他上传未完成时的部分失败、机器移除、历史刷新、Role 加载、轮次上限、取消后重发、
A → B → A、外部文字修改、附件删除以及就绪提交中的作用域切换。这是前端边界验证，
不代表每种情况都能由普通物理键盘操作触发。

## 消融证据

复现命令：`node packages/components/poc/send-during-upload/run.mjs --ablate`。
运行器先要求正向测试和类型检查通过，再逐项移除保护；每项之后恢复源码。
只有指定行为测试出现断言失败才算检出。进程错误或测试收集不完整属于无法判断，
不会算作成功检出。每项均收集 82 个测试。

| 移除的保护 | 失败测试数 |
| --- | ---: |
| 最新已提交发送回调 | 3 |
| 同步提交锁 | 2 |
| 等待期间的可见性取消 | 1 |
| 隐藏输入框发送入口检查 | 1 |
| 本次上传失败后立即取消 | 1 |
| 附件集合核对 | 1 |
| 等待后的草稿身份检查 | 1 |
| 仅接受成功才清空 | 16 |
| 接受后保留新文字 | 1 |
| 排除已有失败文件 | 1 |
| 保留快捷键反转意图 | 1 |
| 就绪后的 token 有效性检查 | 1 |

token 检查的消融最初逃过全部 81 项测试，因为普通卸载测试还有等待返回 false 这一层
保护。新增通过父组件 layout effect 在就绪提交中切换作用域的确定性测试后，覆盖了
缺失的顺序：完整实现通过，移除检查则发送旧消息。不使用 sleep、定时器、网络或依赖
机器负载的竞态。

## 结果与限制

最终隔离运行通过 82 项测试（输入框 62 项、路由 20 项）和组件包类型检查。
12 项消融全部被行为断言检出，没有用编译失败掩盖存活变体。根目录 `pnpm format`、运行器格式与 diff 空白检查通过。提交前的
`pnpm check` 在 `packages/ignore` 因缺少依赖和 Node 类型声明而停止，后续根目录检查未运行。文档检查仍有原有的 34 个子模块链接错误，没有新增错误。

这支持继续使用 POC，不代表可直接上线。正式应用仍阻止提前发送；新建会话入口、重启
恢复尚未实现。补丁包含父组件可见性传递，但没有在运行中的应用验证这段接线。
真实上传传输、provider 投递、Electron/移动端物理焦点交互仍需端到端验证。
有限消融集合全部通过，不证明不存在其他状态交错。
