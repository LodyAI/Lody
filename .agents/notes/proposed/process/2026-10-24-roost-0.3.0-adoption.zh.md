# 接入已发布的 Roost 0.3.0 配套包

Status: proposed
Type: process
Translation: current

[English](2026-10-24-roost-0.3.0-adoption.md)

## 摘要

Roost 消费端 PR 栈需要此前锁定的 0.2.0 包没有提供的 API。目前 SDK、Native
主包和六个平台包均已发布 0.3.0。从首个使用新 API 的 #1791 开始锁定这一配套版本，
让后续 PR 继承同一个依赖更新提交。通过真实 registry 安装验收替代本地候选链接，
此前 benchmark 数据继续作为历史结果保留。

## 范围和验收

同时更新共享 SDK catalog、CLI Native 精确版本和发布检查、八个精确发布年龄例外及锁文件。
保留其他依赖及原有 PR 的运行时代码；其他新版本继续隔离七天。已发布的 Native
版本只接受 fresh/v10；本次接入不增加迁移、旧格式读取、自动删除、部署或发布操作。

推送前检查冻结锁文件的 registry 安装、实际 Native 包与能力来源、所属集成测试，
并运行现有根目录检查、格式和文档检查。整理分支时保留草稿状态和 review base，
按照实际验证结果更新 PR 描述中过期的发包阻塞说明。

将 #1800 中已经审阅的两处压缩历史测试适配前移到这次依赖提交，使 #1791 能够
验证已发布的压缩布局。测试检查解码后的非空历史和完整收据，不再把压缩 SQL
行数等同于更新数；生产代码不变。#1800 保留对应的解释记录。
首个消费端的冻结安装、CLI 类型检查和全部 88 个后端合同测试通过；registry
安装的 darwin-arm64 addon SHA-256 与 Roost 0.3.0 最终 CI 制品相同。

完整栈的冻结安装和根目录 `pnpm check` 通过，包括 CLI 4,559 个通过、4 个原有跳过，
组件 5,962 个、shared 1,610 个、Electron 测试及全部边界检查。根目录格式检查通过，
未产生无关修改；文档检查为零错误、71 个原有警告，没有受保护主题变更。
CLI 在 2 GiB V8 heap 下编译通过；最初的完整构建在仍固定为 Native 0.2.0 的
发布检查处停止。同步这一处版本字面量后，针对同一编译产物重跑的 bundle 检查、
运行时 smoke 和剩余 WASM 复制步骤通过。桌面 CLI 暂存目录包含 Native 0.3.0，
Electron 主进程、preload 和 renderer 的完整构建通过。没有重跑或改写 benchmark 数据。
