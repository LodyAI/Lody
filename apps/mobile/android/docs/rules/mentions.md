# Mentions and prompt shortcuts (Android)

Read before changing @ references, `/` commands or prompt shortcuts in any composer. These rules bind every caller of the area, not only files in its directory.

- @ references (iOS `ChatMentionPanel`, Notion-style): `chat/MentionPanel.kt` (`MentionState` + `MentionDock`) docks under the composer, on the keyboard (the screen column's `imePadding`), in both the conversation and the new-chat page, shown while the focused prompt has a trigger at the caret (`@`, `$` skills, `/` commands at the start; `@file:` style scopes). Every category is read up front through runtime `mentionCatalog` with a `MentionSource`: the conversation (`ChatRepository.mentions`), or the new-chat page's project, computer and agent (`CreationService.mentions`, reloaded when they change). Role rows lead with the Role's emoji (runtime mention items carry `emoji`). Prompt shortcuts (`cmd` items inserting `/shortcut:<slug>`, `MentionCandidate.category` "shortcut") list as their own category; `/` offers both, shortcuts first. Root categories and typed matches lead with Agent Roles and Prompt Shortcuts, then files, skills, conversations, issues, PRs and the agent's commands (iOS order). Roles and shortcuts are workspace-wide, so `MentionState.load` shows the last accepted lists for the account/workspace (in memory) at once while each composer reads its own; a Role read made before presence is live (empty and incomplete) never replaces cached Roles. Levels are a stack (root categories or typed matches → category → folder) animated with `AnimatedContent` slides, a back header and system Back; a folder level leads with "Reference folder". Choosing a row replaces the trigger with its `insertText` (default `@path`) and a space.

- `/` lists prompt shortcuts before the agent's commands. Choosing a shortcut writes its body (web `prepareShortcutSelection`): `MentionDock(loadShortcut)` reads it through the runtime (`shortcutBody`: `promptShortcuts` list → read, `RuntimeCommand.ShortcutBody`) and `Mentions.shortcutText` turns references into tokens (files `@path`, skills `$name`, issues / PRs `#number`); a failed read inserts `/shortcut:<slug>`. Agent Roles read as emoji + name in the prompt; `MentionState.labels` maps each label to `@role:<id>` and `resolve` swaps them back when sending (chat and new chat).

- A reference in the composer reads as a chip, not tinted text alone: `MentionPresentation` styles every reference (files, skills, Agent Roles, conversations, issues, PRs) with `accentOnSubtle` medium-weight text on an `accentSubtle` background, and also styles the shortcut Role labels in `MentionState.labels` in place (they are already their shown text, so the offset mapping is unchanged). Both composers pass these colours through `MentionState.presentation`.
