# Bundled interface fonts

Geist supplies Latin and numbers; vivo Sans SC supplies covered non-Latin text.
Both ship with the application. No installed font or runtime CDN is required.
Existing user-selected families, text roles, spacing and mono stacks are unchanged.

| Boundary             | Owner                                                                                                                             | Contract                                                                     |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Default and fallback | [Shared CSS](../index.css)                                                                                                        | Geist, vivo SC, then native platform faces.                                  |
| Generation           | [Recipe](../../../scripts/prepare-interface-fonts.py)                                                                             | Official archives, pinned hashes, variable WOFF2 partitions.                 |
| Build                | [Vite plugin](../../../vite-interface-fonts.ts)                                                                                   | Prepare assets before CSS; emit complete font licenses.                      |
| Attribution          | [Notices](notices.ts)                                                                                                             | Settings → About → open-source attributions includes both full licenses.     |
| Verification         | [Outline checks](../../../scripts/test-interface-fonts.py), [browser regression](../../../tests/e2e/interface-typography.spec.ts) | Coverage, variable curves, actual browser glyphs, delay/failure, text roles. |

## Build and loading

Install [uv](https://docs.astral.sh/uv/getting-started/installation/) before a renderer
or Storybook build. The shared CI toolchain installs it. The build plugin runs Python
with `fonttools[woff]==4.61.1` and `brotli==1.2.0`. First generation downloads only
the pinned public official vivo archive and Vercel's `geist@1.7.2` npm archive.
There are no product-cloud requests or credentials. Offline builds can reuse
`.cache/interface-fonts`, or set `VIVO_FONT_ARCHIVE` / `GEIST_FONT_ARCHIVE` to
previously downloaded official archives; mismatched hashes fail the build.

Generated bytes live in ignored `generated/`, never in Git. A source/recipe/content
signature and per-file hashes validate reuse. Missing assets fail preparation;
they do not silently create a build dependent on machine-installed fonts.

The first vivo package covers every mapped non-Latin codepoint in shipped
`locales/zh_CN.json` string values. The second contains the remaining GB2312
level-one common Han. Remaining mapped characters use disjoint 512-codepoint
long-tail packages. CSS `unicode-range` requests only packages used by text:
there is no timer, whole-font lazy download, eager `FontFace.load()` loop or
preload of all partitions. Latin U+0000–024F is excluded from vivo faces.
All faces use `swap`; missing/uncovered glyphs use the existing native fallback.
The distribution includes the complete partition set for offline documents.

Preserve original `wght` 100–850 (default 400), `opsz` 10–22 (default 16), naming,
copyright records, layout features and hinting. The recipe changes only transport
representation and coverage, not type design, axis ranges or optical-sizing CSS.
Geist normal and italic WOFF2 files are unmodified official bytes.

## Licensing boundary

[vivo's official entry](https://developers.vivo.com/doc/d/314fa33cbaec4a93be351cd44757d9d9)
links the original archive. [Its complete agreement](vivo-LICENSE.txt) requires
software attribution (§2.1), forbids adaptation/secondary development (§2.2),
forbids standalone font redistribution while allowing application works (§2.3),
and requires retained copyright and agreement (§2.4).

This implementation treats lossless transport conversion and coverage partitioning
without design changes as application embedding rather than a new type design.
**The agreement does not explicitly authorize WOFF2 conversion or subsetting.**
That interpretation remains uncertain; there is no written authorization from vivo.
The implementation is for human review, not a legal assurance. Never publish the
generated fonts as a standalone font package or infer permission from another
project's MIT license. Keep notices with the application's font copies.

Geist is covered separately by the [original SIL OFL 1.1](Geist-LICENSE.txt).
The application emits both agreement files under `font-licenses/` and embeds
their complete texts in its attribution dialog.

## Verification

From the repository root, after generation:

```sh
uv run --no-project --with 'fonttools[woff]==4.61.1' --with brotli==1.2.0 python packages/components/scripts/test-interface-fonts.py
LODY_STORYBOOK_URL=http://127.0.0.1:6027 pnpm --filter @lody/components test:e2e interface-typography.spec.ts --workers=1
```

Outline checks sample every partition at both axis extremes and defaults, compare
decomposed curves and advance widths with the original, and verify complete,
disjoint mapped non-Latin coverage and retained notices. They do not constitute
an exhaustive glyph-by-glyph or continuous-axis proof. Browser checks use Chromium's
`CSS.getPlatformFontsForNode`, not computed family lists, and cover delayed/failed
loads, portals, five size tiers, light/dark palettes and a 720px window.

The dense synthetic review scene has a first-screen budget of **3 MiB and at most
three Geist/vivo resource requests**, warm cached bodies must not be retransmitted,
and initial CLS must stay below 0.05. Record actual request sizes, cache policy and
native uncovered-glyph evidence; never interpret absent timing entries as zero bytes.
Vite dev serves fonts with `no-store`, so warm navigation must be checked against
hashed build assets, not inferred from a development reload.
