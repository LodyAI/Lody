# 输入框上方的执行机器详情

Status: draft
Translation: current

[English](composer-machine-owner.md)

团队成员在发送消息前，需要辨认由哪台机器执行。桌面输入框上方保留显示器图标和
执行机器名称；手机在同一行 info bar 内保留紧凑的显示器按钮，点击展开完整设备详情。
桌面也支持悬停与键盘激活。主人姓名与头像
不占据输入框上方的常驻信息行。此修订接续此前常驻主人信息方案的撤回，视觉确认
仍待完成。

归属来自所选机器的 `ownerUserId`，不是会话创建者或可转移的会话所有者。
当前用户的机器在卡内显示“我”；归属不可用时显示“未知所有者”。离线时保留机器
入口，并用警示色提示；状态尚未解析时保持中性，在卡内显示“状态暂不可用”。
机器元数据尚未加载或已删除时，清除入口，不能保留上一台机器的信息。

机器入口独立于固定顺序的折叠项和展开项。窄窗口截断长机器名，卡内显示完整名称；
只有机器入口时使用透明背景。现有仓库、状态控件和会话菜单内的机器信息继续可用。
本改动只负责展示，不新增切换机器、后端或归属变更操作。手机控件保留在 32px 信息行内，
不增加单独的身份信息行。
手机信息行较窄时，私有权限状态可只显示锁图标，保留完整的无障碍说明及有权限时的
分享操作。
