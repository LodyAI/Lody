# 消息队列展示

Status: draft
Translation: current

[English](message-queue.md)

## 场景

Agent 工作时，待发送消息显示在输入框上方。用户可以折叠列表腾出会话空间，
展开后查看某条消息和它将如何运行，并在发送前到输入框里编辑它。

## 行为

- 标题是可通过键盘操作的折叠控件，显示包含本地附件准备中消息的总数。
  默认展开；状态仅保留在当前挂载的展示组件中，不共享，也不持久化。
- 折叠只改变展示，不发送或删除消息、不改变顺序，也不结束输入框里的编辑。
  新增消息只更新数量，不自动展开列表。
- 折叠时仍显示准备中与未发送的数量。展开后可使用原有重试、取消操作。
  本地待发送行仍不参与排序，也不增加编辑或引导操作。

## 详情

- 每一行都有详情按钮（手机上和窄于 520 px 的面板里收进“更多”）。详情显示完整
  消息、附件、发送者、排队时间和冻结的运行配置：Role、Agent、模型、推理强度、
  模式、Plan 和 Fast，并提供“编辑”入口。
- 工作区有多名成员、且这个会话里有别人排队的消息时，每一行都显示发送者头像；
  否则不显示头像列。
- 某行冻结的模型、模式、选项或 Role 与输入框当前选择不同时，显示一个说明差异的
  小标签。该行没有记录的字段跟随会话，不算不同。标签只是提示：手机上和窄于
  520 px 的面板里不显示，也不挤占消息文字。

## 在输入框中编辑

- 点“编辑”后，该行文字进入输入框，输入框进入编辑模式：输入框卡片顶部的横条（信息条仍贴在上方）说明正在编辑哪一行，
  并列出消息仍带着的图片、文件和引用（每项可移除）；发送按钮变成保存，旁边是
  取消。输入框原本未发送的草稿和运行配置选择暂存起来，编辑结束后恢复。
  同一队列同时只编辑一行。
- 运行配置从该行冻结的值开始。模型、模式、选项和 Role 可在这个会话输入框允许的
  范围内修改，也可以添加新附件。MCP 选择不属于编辑内容。
- 开始编辑只写入该行的编辑锁。内容和配置在点保存时一次写入，在同一消息 ID 和
  位置上替换该行字段。保存不走发送路由（不发送、排队、插话或打断）；发送和插话
  仍在行上。
- 没有改动就保存等同于取消：该行、作者和签名都不变。真正改动后，编辑者成为该行
  作者；加密工作区里由编辑者对新内容签名。运行配置未改时保留冻结的 Role 版本。
  由于最近一条排队消息是输入框配置的权威来源，改了队尾那条的配置，下一条新消息
  的默认配置也随之改变。
- Esc（输入框内部的提及菜单、输入法候选等都没有处理它时）和取消按钮都会结束编辑，
  队列不变。放弃修改不需要确认。
- 被编辑的行保留位置、置灰，显示“编辑中”（点它回到输入框），不能拖动、插话、
  移动或删除。
- 新附件先准备好再替换该行；期间该行显示进度，失败时显示原因、重试和放弃。

## 锁的有效期

CLI 不会启动编辑锁未满五分钟的行。只有编辑显示在屏幕上（它的会话正在显示且
窗口可见）时，编辑端才续期。离开会话、隐藏窗口或关闭应用都会停止续期，所以
无人照看的编辑最多再挡住队列五分钟。编辑本身像输入框草稿一样保留在内存里：
回来后继续编辑并重新续期。如果这期间该行已运行或被移除，编辑结束，内容作为普通
草稿留在输入框里，并给出提示。仍在准备附件的保存会续期，直到写入完成。
刷新或退出应用会像其他未发送草稿一样丢失编辑。
