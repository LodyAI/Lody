# 会话消息引用

Status: draft
Translation: current

[English](conversation-message-quotes.md)

## 场景与决策

用户选择聊天消息的一部分，在输入框中插入 inline 引用，接着写问题，并可重复多次后交给 Agent。
由 Lody 负责引用交互与可恢复的快照，跨 Agent 交付使用普通 ACP 文本。
已有实验实现；这份草案不代表人类批准或各 Agent 的运行时验收已经完成。

## 保证

选区操作入口脱离会话布局。出现或关闭不得改变视口尺寸或滚动所有权。
接受后在输入框保存的光标位置插入原子引用，问题可以位于引用前、之间或之后。
焦点交接与输入框增高按照[已有滚动契约](conversation-scroll.zh.md)保留阅读锚点。

引用是捕获时所选文字的只读快照。预览显示该快照，来源后续变化不修改它。
删除与编辑器撤销/重做将其视为单元。初期保证不包含原消息跳转。
切换 Agent 保留草稿与交互。

已接受的用户历史保存全文与经过验证的引用显示元数据。
Lody 草稿恢复及受支持的编辑重发还原引用单元，不扩大哪些 Agent 支持编辑。
恢复不改变行内间距，持久化草稿保留已提交的 mention 身份。
提交被拒绝时保留草稿，接受时只清理已提交状态。
没有 Lody 元数据的 Provider 原生导入历史仍显示可读文字，不猜测引用单元。

在 Agent 边界之前，使用一套共享、带版本的投影，按顺序包含完整快照与相邻问题。
普通 prompt、受支持的队列/steer、重试和兜底重放使用该正文，继续适用已有重放预算。
不要求 Agent 专属批注格式或回答指令。文字交付不保证模型对引文的理解。

新结构化引用输入要求目标机器声明对应版本的协议能力。
缺少支持时保留草稿并明确说明不可用，不无声降级承诺的交互。
继续适用已有历史兼容与 writer 所有权规则。
