# 语义 action 目标选择

Status: draft
Translation: current

[English](semantic-action-targeting.md)

用户在右侧打开文件后，把鼠标移回会话再按 Cmd/Ctrl+W，应关闭右侧当前标签。
无意的鼠标移动不得覆盖明确的内容操作。仅在没有明确操作拥有关闭目标时，
鼠标停在未激活的标签上才可选择该区域，而不指定关闭那个标签。开发者模式下的
「跟随操作区域关闭标签」Beta 默认关闭，仅覆盖桌面关闭路由，其他快捷键保持原样。
开发者总开关与本设备的功能开关必须同时开启；关闭任一开关立即恢复原有目标选择，
保留已保存的功能选择。

## 意图与职责

可见界面声明语义 action 作用域和支持的动作。每个窗口使用一个 resolver 选择
作用域；界面自身管理当前标签及关闭生命周期。选择不能依赖屏幕左右半区、CSS
布局或组件挂载顺序。隐藏或卸载的界面不能接收动作。

存在活动模态层或菜单时，阻止后台关闭。明确打开内容或选择标签时，选择目标内容
所在作用域，即使操作从其他区域发起。点击、键盘输入或导航以及非缩放滚轮输入
选择所属区域。明确归属持续到下一次主动操作或生命周期重置；鼠标移动和时间流逝
不能覆盖它。程序恢复焦点或滚动不取得归属，关闭组合键及单独修饰键也不改变归属。

没有明确归属时，在同一个可见区域连续悬停 250 ms 才可选择它，不移动输入光标。
路过区域不选择它，点击和键盘或滚轮输入立即生效。鼠标离开、拖动、阻挡层、
目标隐藏或移除及重置取消待确认悬停。没有已确定选择时，先使用有效焦点作用域，
再使用会话区域。异步打开仅在没有更新的主动输入、打开请求、路由变化或窗口失焦
时才能取得目标归属；销毁解析器或关闭 Beta 也使其失效。打开失败且没有创建标签
时不取得归属。

鼠标离开窗口后悬停目标失效。路由变化和窗口失焦清除临时归属。目标被移除时，
本次调用被阻止，不改投其他区域；后续主动交互可以选择新作用域。目标标签栏
应有轻量视觉提示，让用户能看出关闭将作用于哪里。

## 关闭结果

| 选中的作用域                                   | 结果                                                          |
| ---------------------------------------------- | ------------------------------------------------------------- |
| 右侧存在当前标签                               | 调用该标签现有关闭处理器。                                    |
| 可见的空右侧面板                               | 收起面板，将活动作用域交回会话；本次调用结束。                |
| 会话有多个标签                                 | 关闭当前会话标签。                                            |
| 会话仅有一个标签，且有明确归属                 | 保留[桌面窗口](desktop-windows.zh.md)中的原生关闭或隐藏行为。 |
| 会话仅有一个标签，仅由悬停、焦点或默认回退选中 | 其他关闭区域可见时阻止关窗，否则保留原生行为。                |
| 模态层、取消确认、关闭等待中或失败             | 消费或阻止，不尝试其他作用域。                                |
| Chat Landing 等无会话界面                      | 保留 shell 显式窗口关闭策略。                                 |

关闭右侧最后一个标签可以收起面板。成功收起后，视觉上明确地将活动作用域和键盘
焦点交回会话。后续关闭调用可以作用于会话，不必额外点击。正常按键重复保持原样，
本实验不添加重复抑制；每次调用只关闭选中的目标。已经隐藏的
右侧不属于可见空目标。取消或失败不转移归属。文件未保存确认、Side Chat 终止与删除继续由现有处理器
负责；语义路由不重新定义其生命周期。

原生菜单关闭与快捷键使用同一个 resolver。DevTools 保留原生关闭优先级。
原生公共浏览器只向所属 renderer 传递浏览器 id 和交互类别（移动、点击、离开、滚轮或键盘）。
移动仍是弱信号，点击、滚轮和键盘输入取得明确归属。隐藏视图
不能取得归属，关闭快捷键不覆盖更新的鼠标目标；桥接不传网页内容、坐标或按键文本。
鼠标进入 iframe 时，可在相同停留延迟后通过宿主事件选择作用域，不读取 frame 内容。跨域 Managed Preview
iframe 内部键盘交互仍需独立桥接，暂不属于本 Beta 的覆盖范围。
Web 上浏览器拥有的 Cmd+W 不属于本桌面实验。
