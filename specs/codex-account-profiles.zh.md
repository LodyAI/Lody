# Codex 账户配置

Status: draft
Translation: current

[English](codex-account-profiles.md)

用户沿用机器和提供商设置，添加名为工作、个人、自定义 API 的 Codex 配置。
ChatGPT 沿用设备登录；自定义 API 确认 Base URL，并通过现有秘密输入交互接收密钥。
本地和远程机器保留相同的设置、验证、重试、取消及会话选择流程。

## 归属和传输

执行机器拥有不透明账户标识、独立 Codex 目录及凭据。共享配置仅含账户引用、认证方式
和规范化地址。ChatGPT 使用 Codex 原生系统密钥库，不允许文件回退；API Key 使用宿主
系统凭据库。后端不可用或锁定时拒绝继续。没有账户引用的现有配置保留原生行为和历史。

远程秘密输入复用与请求绑定的加密 Machine RPC，不新增托管凭据服务或模型代理。
OSS 组合保持纯本地。API 请求经过用户执行机器上的进程级回环转发器；转发器只向已确认
地址提供真实密钥，拒绝重定向。原生进程仅接收临时访问令牌，而非上游密钥。这不构成
针对同一操作系统用户下恶意代码的沙箱。

## 身份和生命周期

一个提供商只拥有一个不可变账户绑定。改变地址或账户须新建提供商，现有会话不能悄然
切换身份。新目录不复制全局认证、历史或会话数据库。托管账户拒绝自定义运行时和改变
身份的环境变量。预备、启动、恢复、分叉、编辑重发、验证和标题回退使用同一宿主绑定。

不同账户和同一 ChatGPT 账户的多个原生进程都可并发运行。每进程使用记录仅用于在全部
原生进程退出后清理删除账户的凭据；未知孤儿进程不阻止新会话。Lody 不另加凭据刷新
协调或账户调度。重新认证不得替换已有 ChatGPT 身份；需要重新登录
时添加新提供商。

API 密钥轮换先暂存新代次，以不执行工具的合成 Responses 请求验证成功，再原子切换
生效代次。提交前失败或取消保留旧密钥；运行中进程保持原代次。宿主就绪先于目录发布，
发布失败可重试。删除记录本地移除状态，禁止新启动，并持续协调凭据清理；不删历史、
不终止正在运行的会话。

守护进程声明 `codexAuthProfiles` v1。持久化托管配置带有无效可执行路径保护标记，支持
该协议的读取方按账户契约规范化。旧客户端必须失败，不得回退至原生全局认证。
