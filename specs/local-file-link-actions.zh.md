# 本地文件链接与系统操作

Status: draft
Translation: current

[English](local-file-link-actions.md)

助手链接的源文件或构建产物可在会话右侧预览。链接使用蓝色文字和文件类型图标，
没有胶囊背景或边框；保留悬停、键盘焦点和行号导航。
点击带行号的链接时，第一次点击就应打开文件、将目标行带入视口，并显示对应行范围的高亮。
首次内容加载、语言初始化和面板展开都不应要求用户再次点击。用户滚动到其他位置后，
再次点击同一链接应返回它指定的行。

Electron 在会话所属的本机打开对话时，文件链接可预览任何可读的本机普通文件，包括
会话工作区外及其他 worktree 内的文件。不得通过剥离 worktree 前缀将链接重定向到当前
工作区；Markdown 链接和工具文件入口都遵循此规则。工作区外文件仍为只读，真正不存在
的文件仍显示找不到文件。远程预览继续受现有允许根目录的授权限制。

无法内联显示的二进制文件使用圆角提示卡片，操作按钮全宽堆叠，并提供复制文件路径。
Electron 在会话所属机器上提供使用默认应用打开和在文件管理器中显示；后者选中文件，
不启动关联应用。预览和更多菜单使用相同的系统操作与文件身份，保留本地绝对路径和
工作区外的父级相对路径。文件树和侧边面板的更多菜单将该身份拆为两个复制操作：
始终提供“复制相对路径”，仅在机器路径已知时提供“复制绝对路径”。远程会话不在查看者
机器上打开宿主路径。
点击助手链接只打开预览，打开系统应用需要另一次明确点击。

会话中的 PDF 在分页查看器中以适合宽度的缩放比例打开。工具栏支持直接输入页码、上一页和
下一页、可切换的页面缩略图侧栏、旋转 90 度并保留当前页、适合页面/适合宽度/自动及
百分比缩放，以及可展开并逐项导航结果的文本搜索。这些查看器操作不替代侧边面板已有的
文件操作，也不会修改 PDF。本机 Electron
通过经过校验的 64 KiB 字节范围读取本地 PDF 资源，不把完整文件复制到 renderer；每个
渲染页面的画布限制为 8 百万像素。读取或解析失败时回退到二进制提示卡片及其现有文件操作。
其他 provider 继续遵守现有二进制预览大小限制。

DOCX、XLSX 和 PPTX 在会话中以只读查看器打开。DOCX 支持页面缩放，XLSX 提供
虚拟化工作表网格与工作表导航，PPTX 提供幻灯片与缩略图导航。CSV 和 TSV 以
虚拟化表格打开，可搜索单元格并缩放；原有“源码”标签仍可用于文本编辑。这些预览
不新增写入或上传操作。轻量查看器入口随文件面板提供，但 Office 格式引擎和工作线程
只在对应预览激活、浏览器进入空闲期后加载。CSV/TSV 的解析与搜索在工作线程中执行；
非活动面板不启动工作线程。Office 文件读取在导入格式引擎前限制为 25 MiB。
超限或无法读取的 Office 文件显示已有文件操作的提示卡片。加载查看器前仍须遵守
provider 的授权和传输上限。

右键点击助手 Markdown 文件链接始终提供“复制路径”。仅当渲染器是 Electron、会话归属
当前机器且工作区路径已解析时，菜单额外提供“打开文件”（系统默认应用）、“在所选应用中打开”
（与会话顶部选择一致）、“打开方式”（其余可用的已配置路径启动器）以及“在 Finder 中显示”
（或宿主文件管理器）。传给剪贴板或系统的路径不含 Markdown 行号/列号后缀；普通左键仍保留
该后缀，以便在应用内预览中定位。浏览器、移动端、远程会话和本地路径尚未解析时只提供“复制路径”。
每个渲染的会话消息流都根据其自身的 Session 决定这些能力；已打开会话、子会话或侧边会话绝不继承
发起会话的工作区、机器或原生文件操作。

原生移动端在二进制提示和文件菜单中提供“分享文件”。将完整、已授权读取的预览字节
写入独立 App 缓存文件，保留扩展名，再打开系统分享面板。复制路径仍然可用。
导出期间抑制重复操作；取消不是错误，交接或失败后尽力清理缓存。
远程预览原有限制仍然适用（二进制 5 MiB），不分享超限或不可用内容。
本次不引入大文件传输协议。

失败提示应指出操作，并针对路径未解析、文件缺失、访问拒绝、桌面 IPC 不可用或编辑器
启动失败给出后续步骤。本地诊断与复制错误详情保留请求和解析路径、会话及机器身份、
系统错误。诊断不自动上传，复制由用户触发。VS Code 文件回退 URL 保持文件语义，
不添加仅适用于目录的末尾斜杠。

## Markdown 文件图片

实时 Markdown 文件预览先展示完整的可用文档内容，不等待引用图片。图片路径相对于
实际打开的文档，在文档所属机器上解析；保留绝对路径，URL 转义只解码一次。
每张图片继续遵守现有预览权限与传输大小限制。

Electron 查看本机文件时，通过本地文件资源自动加载图片。远端预览（包括移动端项目
文件浏览）为每张图片保留标明图片的紧凑占位和“加载图片”操作。点击之前不读取图片文件，
也不创建 Blob URL。加载期间保留占位，失败后提供重试，正文始终可读。
远端成功读取后通过浏览器 Blob URL 展示。离开预览时释放这些 URL，并忽略迟到的响应；
切换文档或文件读取器后，不得继承上一张图片的加载请求。

这项能力只由实时文件读取器提供。聊天 Markdown、没有文件系统读取器的独立上传
Markdown 附件以及匿名发布页不因此获得文件系统访问能力。普通网络图片 URL 保持现有行为。
