# 用量日期详情缓存

Status: draft
Translation: current

[English](usage-detail-cache.md)

在用量页面重新打开已查看的日期，应立即显示上次加载的明细。只要快照仍在有界缓存
中，切换日期、关闭详情或退出后重新进入设置都不应丢失它。快照保存到本地，使重建
应用 store 或刷新页面后仍能在同一登录会话下复用。未查看或已淘汰的日期在查询完成前
显示加载状态；用量为零的有效结果同样可以缓存。

每次成功获取后，从完成时刻起保鲜完整一小时，不受整点边界影响。一小时内打开同一
日期直接使用快照，不发起详情查询；获取成功即释放订阅。到期只意味着可以刷新，
不会删除数据。只有当前选中的过期日期需要更新，面板持续打开跨过到期时刻也会触发。
新结果返回前继续展示旧快照，避免每小时刷新时出现空白加载面板。这允许最多一小时的
客户端缓存滞后，另加查询或上报延迟；此视图不承担实时用量监控。

快照归属于一个登录会话、工作区和日期，不得向其他工作区或登录会话展示。临时认证
恢复期间可保留同一会话的数据。会话身份暂时缺失时隐藏快照但不销毁；观察到确认退出
登录或明确切换登录会话时使旧快照失效。
没有工作区或用量能力时，不展示详情，也不发起详情查询。其他查询错误沿用已有错误
处理路径，不得悄悄用缓存成功状态替代。

桌面和移动端都使用同一个详情 Hook。忽略无效的持久化数据；本地存储不可用时退回
内存缓存。显式执行缓存修复会删除持久化用量条目。纯本地平台继续不提供云端用量分析。
