# 宿主身份密钥生命周期

Status: draft
Translation: current

[English](host-identity-keys.md)

桌面关闭后，CLI 可能继续运行。两者使用独立的个人与机器身份，后台任务不能取得个人管理密钥。
可信宿主绑定账号和设备，只开放明确用途的操作。登录成功不代表持有设备密钥。

第一份接口只负责明确创建身份，或按预期 Ed25519/X25519 公钥读取已有身份。
创建只能新增，随后重新读取并核对两份公钥。缺失时不得生成替代身份。
写入结果不确定时必须核对，包括写入后取消的情况。可读取已有公钥来核对，但不因此登记或授权
设备。失败保留已有材料，不静默改存裸钥文件。
认证失败不能唯一证明锁定、拒绝或损坏；没有更强证据时，错误原因保留未知。

接口只输出公钥身份，不提供通用私钥导出或任意数据签名。
后续明确用途的密码学操作需要绑定可信协议上下文。个人锁屏行为、Scope 内操作句柄，以及明确
授权的机器无人值守运行仍待实现。仅有存储能力不能宣称这些保证或硬件执行。

密钥生命周期独立于普通缓存和退出登录。本次不增加正文与缓存的应用层加密。
接口未接产品入口，也没有满足全平台 Beta 条件。
