# iOS 模拟器预览

Status: draft
Translation: current

[English](ios-simulator-preview.md)

归属 macOS 机器的会话可以在 Browser 旁打开 iOS 模拟器面板。列表来自会话的目标机器，
不取决于观看者的操作系统。枚举是只读操作，不下载组件、启动设备或创建隧道；不可用的
runtime 和设备占用状态也应展示。未启动设备提供“启动并预览”，已启动设备提供“预览”。

面板包含设备选择器、连接状态和等比例可交互画面。连接详情提供取消、重试和停止。
隐藏地址、浏览器导航和标注；不提供分享按钮、公开链接或匿名观看。桌面第二行工具栏提供 Home、应用切换器、锁屏、旋转、摇一摇，
以及设备支持的音量与操作按钮；移动端统一放入更多菜单。显式文本输入、模拟器 Deep Link 和
明暗模式通过私有预览连接执行，不进入留存的工作区 RPC；使用独立的 `iosSimulatorControls: 1` 能力。

屏幕外优先显示 Baguette 提供的 DeviceKit 硬件外壳，资源缺失时不显示绘制外壳，匹配真实显示比例和方向；不在视频像素上叠加第二个
刘海或 Home 指示条。适应与展开属于本地界面状态。截图可以保存 PNG 或加入当前输入框草稿，
绝不自动发送；只接受绑定 iframe 与对应请求返回的有界图片。

同机 Electron 使用本地直连，支持离线。已授权会话的远端观看在后台使用 Quick Tunnel。
两条路径都验证访问权限；远端控制使用短时证明，绑定确切的会话、设备/操作、动作和
daemon 实例。OS 决定入口，机器协议能力版本决定兼容性。公开版的本地模式不发起需要
登录的产品云请求。


同一个已授权会话可以从多个设备查看同一预览操作。本地 Electron 与远端查看端按需创建
各自的入口，状态查询和启动只返回请求端对应的连接方式，准备阶段也不例外。打开另一台
设备不重启采集、不重置方向；并发连接请求合并。远端连接失败可以单独重试，不打断本地
观看。停止会结束所有设备上的共享预览操作；撤销远端权限也会关闭带远端连接的操作的
两个入口。这不允许其他会话访问设备。

机器上的每台设备只允许一个 Lody 会话控制，跨 workspace 生效。其他会话显示占用，
不能抢占；原生 Simulator 工具不受该协调机制约束。Browser 与模拟器预览独立共存。
重复启动合并。停止也取消准备，迟到结果不能恢复已取消连接。切换设备释放旧设备。
清理先关闭观看连接和所属原生进程，再释放控制权，但绝不关闭 Simulator 设备。
会话归档/删除和 daemon 退出也清理其操作。

隐藏观看界面时停止解码、输入和心跳，但不立即结束操作。没有前台心跳或有效输入一小时
后连接过期；持续视频、状态查询和探活不续期。设备列表、帧和端点属于运行时内存状态；
设备选择偏好保存在客户端，按 account/workspace/session/machine 隔离。凭据不写入会话文档。

预览优先使用 H.264 与 WebCodecs，探测实际解码配置，编解码不兼容或解码失败时回退 MJPEG。短暂传输故障先有限次重连 H.264，耗尽后显示恢复，不永久降级；隐藏预览取消恢复，任何输入和控件操作都不重放。两者均使用有界队列和接收反馈、单指输入，包含鼠标拖动以及转换为单指拖动的滚轮/触控板滚动。
滚动与指针拖动不能同时持有两次触摸；隐藏、断线或失焦时释放活动手势。
从底部边缘向上拖动传递用于返回 Home 的系统边缘手势；普通滚轮仍作为应用内手势。
多指、实体键盘转发与高级设备配置留待后续。每次新操作先确认原生竖屏基线；同一操作重连保留方向。
准备完成/传输就绪与首帧成功应分别表达。

Agent 通过独立工具 `lody_ios_simulator_preview` 预览原生应用；网页内容继续使用
`lody_report_preview_candidate`。动作包括 `list`、`start {udid}`、
`status {operationId?}` 和 `stop {operationId}`。机器和会话来自调用上下文，daemon
从活动 turn 获取请求用户并校验会话归属。工具输出不含观看凭据，也不负责构建或安装应用。
Agent 启动会异步准备设备，由第一个已授权面板选择本地或远端观看；agent 单独查询状态
不会接入 viewer 或续期。无人接入的启动一小时后过期。打开／重开面板或点击设备选择器中的
刷新会发现当前操作；准备轮询和停止仍绑定确切操作。工具不会自动打开面板。

证据：[设计说明](../.agents/notes/implemented/architecture/2026-09-27-ios-simulator-panel.zh.md)、
[CLI 边界](../apps/cli/src/ios-simulator/AGENTS.md)。说明文档记录实现和验证结果；本草案不代表
规范已获人工批准或功能已经发布。

远端 viewer 凭证加密给签名命令中绑定的临时接收公钥；其他工作区成员无法通过读取留存 RPC 流恢复凭证。撤销覆盖正在进行的授权，owner/machine 变更使现有 viewer 失效。

## 原生外观与输入

优先通过 Baguette 使用目标 Mac 的 DeviceKit 真机外壳和精确屏幕/按钮坐标，缺少资源时只显示内容。运行中的图片通过私有 viewer 传递，并校验大小和尺寸，不打包或公开发布 Apple 资源。iPhone/iPad 预览准备时修改该设备的键盘偏好，使聚焦输入框时能显示模拟器软键盘；不重启设备、不修改主机全局 Simulator 偏好。旋转发送原生设备方向事件，应用仍可限制自己支持的界面方向。桌面外壳与画布随设备转动；移动端外壳和画布保持竖放，只改变模拟器内部的界面方向。

## 开始预览前的外壳

选择设备后，通过单独协商的已授权 `exterior {udid}` 命令读取 Baguette chrome layout/composite，显示真实 DeviceKit 外壳，无需启动、占用设备、采集屏幕或建立隧道。RPC 只返回有大小限制的静态 PNG 与标准化几何数据，不传实时屏幕和输入，不公开发布资源或写入 Repo 元数据。加载中或缺少资源时只显示内容，不使用人工绘制外壳。

远端授权要求连接的 Cloud 后端识别精确签名的模拟器操作。发送前校验请求；有效请求收到 400 时提示后端协议拒绝及匹配版本更新，不降级绕过授权。

## 远端响应与诊断

慢链路根据接收端反馈降低清晰度并按字节控制发送节奏，恢复画质应缓慢进行。
MJPEG 模式下，输入和动画停止后，即使原生流不再输出新帧，也补发一张更清晰的静态画面；恢复活动时丢弃过期截图。H.264 通过视频流继续细化参考画面。
拥塞抬高的 RTT 不得扩大在途字节预算。

远端画面按可见窗口调整分辨率，并限制像素密度和发送帧率。限制尚未确认的画面，
JPEG 可替换待发帧；H.264 必须保持编码参考链，或在丢帧后放弃受影响的帧链并从关键帧恢复，上游丢帧也不例外；只允许合并已解码画面。解码确认独立于绘制节奏释放额度，最多保留一张待绘制图片。合并高频移动时保留最终坐标与抬起事件。同机预览保留原始
分辨率。媒体路径不引入新的云服务。连接状态提供数字性能诊断，通过明确复制操作
导出有界内存历史；诊断不采集输入内容或像素。断线后的旧样本应与实时测量可区分。
