# 对话图片选择与导出

Status: draft
Translation: current

[English](chat-share-image.md)

用户可以直接在会话对话中选择消息，将它们预览为一张图片卡片，再保存成 PNG。
消息选择由对话界面负责，预览负责图片捕获。此功能在本地运行，不会发布对话。

选择单位是包含正文的持久化用户或助手消息。折叠的助手轮次即使占据多个虚拟行，
也仍是一条可选消息。鼠标拖动、Shift 范围扩展、Ctrl/Command 反选和边缘滚动均
保持时间顺序。取消选择会恢复输入框；关闭预览会保留选择，便于重新打开并调整。
图片成功复制到剪贴板或写入磁盘后，预览和选择一起结束，不留下仍处于选择状态的界面。

取消保存对话框不代表分享完成，因此既不关闭预览，也不清除选择。导出结果明确报告
是否实际保存，而不是仅报告是否发生错误，避免丢失用户仍在调整的选择。

卡片显示正文，但估算 token 数包含所选消息中存储的思考、计划和文本工具输入输出。
它不是计费用量，也不能统计不可用输出或重复上下文。模型标签取自最后一条所选
助手消息记录的模型，而不是当前输入框；多模型汇总不在本规格范围内。自定义运行时
使用当前会话配置的显示名称。日期仍是会话创建日期，不显示经过的运行时长。

卡片采用固定模板。各区域、顺序、左右留白和字体比例始终相同。预览只提供四种选择：
卡片尺寸、外围留白大小、背景和配色，均不改变模板布局。配色初始值遵循应用当前外观。
所选配色覆盖整张卡片，包括 Markdown 正文、强调、引用、表格和代码，独立于应用
和系统外观。预览与导出的 PNG 使用同一配色。

卡片尺寸决定行宽：一行能放多少正文，以及代码行是否需要换行。界面因此询问图片
将分享去哪里，而不是让用户调整尺寸数字。发送到聊天线程的图片按手机内容宽度阅读；
发布到信息流、README 或幻灯片的图片需要容纳完整的正文行和代码行。这两种目标
对应两个有用的尺寸选项，无须提供连续宽度调整。

外围留白是模板唯一不固定的连续尺寸，通过像素滑块调整。这里允许输入度量值，
因为用户能边拖动边看到预览，而不必凭名称猜测 32 或 56 的区别。离散的命名档位
会替能够直接判断效果的用户做决定。选择卡片尺寸会为留白设定该尺寸的常用初始值。

留白可以为零，以便将卡片贴入文档时与图片边缘齐平。当留白不足以承载署名时，
署名移入底部说明区域，卡片阴影也消失：阴影需要落在外围背景上。

导出设备不决定图片内容。它只为初始尺寸提供一个可随时修改的猜测。直接按设备
决定尺寸会让电脑用户分享到群聊时得到过宽的卡片，也会让手机用户发布到信息流时
得到过窄的卡片，因此应由用户明确选择分享目标。

两种尺寸只在行宽和内部空间比例上不同，字体大小相同，且独立于读者的对话字体
设置。聊天卡片与帖子卡片以相同字号呈现同样的文字。

与用量卡片一样，所选背景是导出图片的一部分，而不是事后加上的边框。背景选项包括
产品标志性的深海夜色、首次启动仪式的浅水场景、三种普通渐变，以及完全不加背景。
无背景时仅导出带有自身圆角的卡片。背景不会改变卡片的阅读布局，只改变承载卡片的
底色，因此允许个人偏好。完全移除背景曾被尝试并否决：浅水背景是 DOM 捕获无法
序列化的动态场景的手工静态版本，产品中没有其他地方使用它。

所有区域共用一个水平内边距，让标题、双方消息和底部说明在同一条左边线上对齐。
任何轮次都不靠右悬挂，因为分享图片没有一个固定读者能把右侧理解为「我」。用户
提示是浅色块，助手回复是普通正文。垂直节奏承担分组职责：两组对话之间的间距是
用户提示与其回复之间间距的两倍。

来源信息集中在卡片底部的说明区域：生成对话的运行时、模型、粗略 token 估算和
绝对日期。产品署名位于卡片下方的背景上，不占用对话空间，也不会被误认为转录内容。
没有背景或留白不足以让署名远离边缘时，署名放在底部说明左栏的第二行，而不是新增
一个区域。署名颜色适配所在背景。卡片不包含二维码，因为原二维码指向产品主页，
而不是这段对话；清晰的文字标识能以更小空间表达同一信息。

代码软换行，语言标签保持清晰，并且不显示复制控件。图片没有水平滚动条，不能
换行的代码会变成读者看不到的内容；图片中的按钮也无法点击。这些规则由图片媒介
本身决定，不是可调整偏好。

卡片没有高度限制，不省略任何所选消息。较长的选择生成较长图片；需要发布整段
可阅读对话时，应使用分享链接。

PNG 导出捕获卡片和背景，不受预览滚动或缩放影响。它等待字体与图片加载，禁止
重复导出或复制操作，并提供可重试的失败提示。Electron 使用原生保存对话框，
浏览器下载文件。取消保存对话框会保留预览。

复制成功的提示显示在预览之外，因为此时预览已经关闭。保存操作有原生对话框或
浏览器下载界面作为反馈，而复制成功否则会没有任何可见提示。

预览还提供明确的「复制图片」操作。它捕获与导出相同的 PNG，只写入本地系统
剪贴板。Electron 将 PNG 字节交给原生剪贴板桥接，浏览器使用图片 Clipboard API。
不支持图片剪贴板的浏览器报告可恢复失败，复制失败会保留预览以便重试。复制不会
发布对话，也不会改变保存图片的行为。

预览不是编辑器，只包含配色切换、背景色块、尺寸切换、留白滑块和两个操作。
控件按用途排列，先控制卡片形状，再控制表面配色。没有背景时尺寸切换仍可用，
因为它仍决定卡片宽度；留白滑块禁用，因为已经没有外围背景需要调整。电脑上使用
对话框，手机上使用底部抽屉，两者提供相同的预览、控件和操作。
