# 回答权限请求

Status: draft
Translation: current

[English](permission-requests.md)

## 场景

Agent 工作途中询问：能否运行 `pnpm install`、编辑两个文件、访问
`registry.npmjs.org`，或退出计划模式？用户需要依次了解：Agent 想做什么、具体运行
什么或影响什么，以及有哪些回答。用户应能在当前操作位置回答，而且不能误批准。

## 契约

- **唯一交互入口。** 等待中的请求在替代输入框的提示中回答。对话只显示请求在回合中
  的位置（“等待你的回答”），不再提供第二组按钮。回答后保留一行选择记录；撤回的请求
  不保留记录。
- **使用提供方的表述。** Agent 提供标题和原因时直接展示；否则根据工具类型生成问题。
  选项保留 Agent 的名称与说明，不重写或合并，因为“允许，且以后不再询问 `git` 命令”
  本身解释了回答的含义。
- **准确展示操作。** 命令及目录完整展示；文件请求对每条路径展示一次；其他请求展示
  Agent 的工具标题。计划审批不重复展示操作对象，计划就在上方消息中。
- **建议选项。** 提供方标记 `defaultToNo`，或标准 ACP 选项以拒绝开头时，建议第一个
  单次拒绝；否则建议第一个单次允许。“始终”选项不能成为建议。
- **形态。** 使用输入框的尺度：问题和原因、操作对象、最后一行回答。拒绝和允许各用一个
  分裂按钮，直接显示单次回答（建议选项为主按钮），改变后续行为的回答放在菜单里，保留
  提供方措辞，例如“不再询问”“阻止此主机”。
- **键盘。** 方向键从建议选项开始遍历；Enter 或 Space 回答当前聚焦选项。Escape
  只单次拒绝，不选择“始终拒绝”；没有单次拒绝时不回答。在提示本身按 Enter 不回答，
  避免原本用于发送消息的 Enter 误批准刚替换输入框的请求。
- **焦点。** 只有用户未操作其他元素时，提示出现才获取焦点。这包括被替代输入框卸载后
  释放的焦点。
- **一次一个。** 同一会话可有多个等待请求，提示一次展示一个，显示总数和当前位置，
  可切换查看；回答一个后在原位置展示下一个。
- **失败可见。** 回答未到达 Agent 时显示错误并允许重试。工作区连接中禁用回答并说明
  原因。
- **保留退出路径。** 提示提供 Stop，因为原输入框里的 Stop 已被隐藏。
- AskUserQuestion 表单使用同一位置和队列，以问答表单代替权限选项。

## 待解决问题

- 编辑请求没有 diff 预览：历史存储前丢弃编辑 `diff` 内容，所以提示只能显示路径。
- iOS Live Activity 在存在 `allow_always` 时选择它，与“始终选项不能成为建议”不符。
- 服务端 20 分钟超时在撤回请求前没有可见提示。
