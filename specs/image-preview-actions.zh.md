# 全屏图片操作

Status: draft
Translation: current

[English](image-preview-actions.md)

查看对话图片、待发送附件或文件预览时，用户应能直接从共用查看器导出同一张图片，而不必截图。

- 单指静止长按打开复制图片、保存图片和分享操作。移动、第二个触点、取消或切换图片会取消长按。
  平移、双指缩放和图片间滑动仍由 PhotoSlider 负责。
- 菜单绑定打开时的图片。关闭菜单或取消系统操作不关闭查看器；关闭或切换图片会使菜单失效。
- 支持图片剪贴板时复制图片像素；不支持时明确显示不可用，不以复制网址或文字冒充图片复制。
- 保存保留原始字节和编码。原生端保存和分享复用文件分享面板，由用户选择目的地；完成交接不等于
  已写入相册。浏览器可下载，并在支持时分享文件。
- 桌面右键复制、保存及浏览器原生菜单回退保持不变。

## 证据与限制

需求：[#1284](https://github.com/LodyAI/Lody/issues/1284)。实现位于
`packages/components/src` 中的 `ZoomableImageViewer` 和 `lib/image-preview-export.ts`。
公开仓库未提供原生图片剪贴板桥接；浏览器能力检查不能证明 iOS/Android 的权限行为。
仍需真机验收手势与系统分享面板。
