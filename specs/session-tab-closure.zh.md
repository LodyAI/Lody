# 会话标签页共享关闭状态

Status: draft
Translation: current

[English](session-tab-closure.md)

关闭主对话或顶部子对话标签页会改变工作区共享的打开集合。其他查看者同步关闭同一标签，
但各自保留选中状态和排列顺序。当前标签关闭后，优先切换右侧可见邻居，其次左侧，
没有剩余标签时在同一 Session 工作区进入本地新对话草稿。

## 状态与生命周期

`SessionMeta.isTabClosed?: boolean` 与 `isArchived` 独立，缺失表示打开。
主 Session 的标记只关闭自身对话标签，不影响子会话、侧栏条目的存在、运行中的 Agent、
待处理工作、终端或 worktree。新关闭操作只修改该标记，已持久化的空会话也不删除。

已关闭列表包含 `isTabClosed === true || isArchived === true`，兼容历史上关闭即归档的
子标签。重新打开已归档会话先执行既有恢复检查及包含关系规则，再清除目标会话的关闭标记。
恢复根 Session 包含直接子会话，保留子会话独立关闭标记，不恢复 opened-by 后代。
恢复失败需提示并允许重试。不批量迁移历史数据，也不猜测过去归档的原因。

已关闭和已归档对话不显示未读提示，也不计入父会话汇总、项目未读数及窗口角标。
历史上已关闭的对话和关闭后继续产生的输出遵循同一规则。关闭不修改 `lastReadAt`，
也不增加状态；重新打开后恢复时间戳比较，实际查看时走正常已读回执。
主标签关闭后，仍打开的子会话继续贡献未读。运行中和等待权限提示独立保留。

## 导航与同步

元数据沿用现有 writer 与 CRDT 同步链路。离线写入使用相同字段冲突规则合并。
后台工作不会自动重新打开标签。重新打开在所有客户端增加可见标签，但只在操作方选中。
对话内用于打开子会话的卡片若指向已关闭标签，需先恢复该标签，再在当前 Session
工作区等待恢复状态投影到本地，然后选中该精确子会话。对于明确的恢复请求，不得以
其他已打开的兄弟标签作为回退目标。
切换当前 Session 会使待处理恢复失效，即使两个路由都没有 `?tab`；一个 Session 发起的
恢复不能在另一个 Session 中选中子会话。
URL 仍是选中视图的唯一依据；`tab=empty` 兼容为默认草稿入口。
元数据加载完整后复用已有本地草稿，否则创建一个，再将 URL 替换为明确的草稿地址。
确认关闭后可以替换仍指向该标签的 URL；缺失元数据保持加载态，过期异步导航丢弃。

默认草稿复用现有输入页，首次发送才创建真实 Session；仅在本地保存，保留已有输入及
已关闭列表的重新打开入口，不取消移动端 viewer 的激活状态。隐藏对话不能触发已读回执或输入框命令，
输入草稿仍为本地状态。本地未发送草稿、Side Chat、文件及工具面板保持现有生命周期。
关闭快捷键关闭当前焦点标签；关闭最后一个草稿后进入新的本地草稿。文件和工具面板保留原有关闭行为。

## 兼容性与证据

旧客户端能读取新增元数据，但不识别新标记，关闭时仍可能归档。统一体验需要客户端升级。
宿主若存在元数据字段白名单，必须保留该字段；本公开仓库不能证明私有后端兼容性。

实现归属：共享 SessionMeta、组件会话 actions、tab URL 解析、SessionDetail、
SessionTabBar 和响应式移动端标签面板。测试覆盖关闭／重开的生命周期隔离、相邻／空白选择，
以及真实 LoroRepo 副本收敛。归档目标规则见[会话关系](session-relations.md)。
