# 会话运行配置的私人草稿

Status: draft
Translation: current

[English](session-run-config-drafts.md)

## 场景

已有会话中未发送的 Fast 选择在切换标签后保留。其他设备的新轮次更新共享基线，
但不消费本机修改。这是 [PR #1287](https://github.com/LodyAI/Lody/pull/1287) 的方向；
本 Spec 仍为 draft。

## 约定

- 只保存实际修改的字段，按账户、工作区、会话及代理/提供方目标隔离。
  只读访问不保留记录；有效配置仍由修改、运行时状态、轮次偏好和能力声明派生。
- 明确关闭和重复同值选择都是新的字段代际。发送只捕获最终冻结 inputConfig
  中原样采用的代际。本地轮次写入成功或进入等待发送队列后，即使已卸载也消费
  这些代际；接受前失败及较新修改都保留。之后上传失败或重试沿用等待发送的冻结配置。
- 远端轮次不消费草稿。普通导航和可恢复归档保留草稿。不同目标的修改互相隔离，
  返回同一目标时恢复其未发送草稿；元数据变化不丢弃另一目标的修改。
- 确认删除会话、移除工作区和账户退出清理对应草稿，使旧编辑回调失效。
  延迟清理不能跨账户生命周期生效；元数据缺失不是确认删除。
- 草稿仅存内存，不保留历史轮次 ID、空访问记录，也不采用 TTL 或 LRU。
  应用重启会丢失草稿。
- Role 目录未知且有手动修改时冻结明确 None，防止程序化发送继承无法验证的
  Role 或记忆配置。
