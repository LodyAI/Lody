# 单会话访问

Status: draft
Translation: current

[English](session-access.md)

机器所有者可以将一个会话共享给团队或指定成员阅读，同时保持机器私有。接收者能阅读完整
Loro 或 Roost 历史，并在自己的会话中引用，不能发消息、执行或管理被分享的会话。普通和
加密工作区使用同一规则。2026-11-10 的 owner 决定随 PR #2487 草稿提交，待人工批准。

## 权威来源与有效权限

只有当前 `SessionMeta.machineId` 对应机器的所有者能管理分享。`SessionMeta.userId`
提供会话 owner 的只读可见性兜底，不授予管理或执行权。转移 owner 仍要求接收者已有
机器／项目访问权。

有效权限取以下来源的最大值：

| 来源 | 权限 |
| --- | --- |
| 机器主人 | 管理、编辑，始终可见 |
| 机器及会话使用的本地项目均已共享 | 编辑 |
| 匹配的团队或个人会话授权 | 只读 |
| 会话 owner | 只读；已有机器／项目权限时可编辑 |
| 无 | 隐藏 |

授权仅在授权机器等于当前 Meta 机器时有效。只有直接、同机器的包含子 Tab 和 Side Chat
继承根会话授权：缺省 `childSessionPlacement` 表示 Tab，`side-panel` 表示 Side Chat。
未知 placement、嵌套父会话或只有 opened-by 来源的会话不继承。团队和个人授权可并存，
撤销其中一项不删除另一项。只读授权不打开机器／项目执行开关；本阶段不能将已共享机器／
项目中的单个会话设为私密。

## 存储与读取准入

普通工作区机器行分别存团队会话 ID 集合及 `{sessionId, userId}` 个人只读授权。
只有当前机器所有者可修改，添加的接收者须为当前工作区成员；Convex 订阅推送变化。
公开代码只含 DTO 与能力开关后的平台调用，后端由私有 #4253 实现。

加密工作区机器所有者签名的 v3 策略使用
`sessions: [{sessionId, audience: 'team' | {userId}, level: 'read'}]`，独立于机器／项目开关。
身份有长度界限、条目规范排序，重复的会话／受众对被拒。只允许 read，以后的 write 须另行
评审。格式 current-only，无旧格式读取、迁移或重建脚本。E2EE 尚无生产数据，旧客户端
拒绝新形状；成员账本格式不变。

只验证最新原文：解密、验证曾被准入的所有者个人设备签名、资源／绑定／代次及本地 pin。
低版本或同版本不同摘要均拒绝，缺少中间策略不影响读取；父摘要只用于服务端 CAS 排序。
服务端已接受的策略在签发设备撤销后仍有效。设置和受影响的机器卡片给出非阻塞检查提醒；
当前个人设备可按原样重新签署完整机器／项目／会话清单，也可先修改。不重签不影响使用。
这依赖信任服务端在 commit 时拒绝已撤销签名者，且不隐瞒最新 head。Guest、恢复设备、
机器设备不能签署共享策略。

加密版本订阅只作失效提示，不授权；深链接强制重读策略。执行端机器授权不变。
Roost 使用单独的精确会话读取准入：普通请求只转交短期、限定用途凭证，
接收机器在线核对当前成员及实际目标元数据。CLI 凭证同时绑定凭证所属账号、声明的请求者和源机器，
双方都须有目标读取／编辑权限，且请求者仍可使用该账号所属的源机器；加密请求使用已验证设备身份和 v3 策略。包含子会话
解析到同一根。长轮询在等待前、醒来后及发送前重查授权，包括正文读取及响应加密后。加密读取将账本代次及已验证策略的有效性检查保留到整个响应结束；观察到撤销即丢弃响应。读取准入不开放写、执行、文件、终端或其他
会话；普通历史写入须另有编辑凭证。机器离线／不可用时明确显示历史不可用。Loro 沿用
文档阅读器。

## 交互

标题栏显示「私密／团队只读／团队可编辑」；只有个人授权时显示「已分享给 N 人」。
「团队访问」提供「私密／团队只读」，机器共享导致可编辑时说明原因并提供设置入口。
「成员」区始终列出会话 owner，标为 owner 且不可移除，以及单独授权的只读成员。
机器主人可添加工作区成员、移除明确授权；已有团队只读时仍可添加。非机器主人看到同一
列表，但不能操作。公开链接仍使用独立发布同意及授权。

只读页以带机器名的横幅和「在新会话中引用」替换输入框，引用预填真实会话 mention。
保留置顶、标未读、复制 Markdown 和引用；不提供停止、Steer、排队、审批／问题回复、
运行／Role 配置、重命名／归档／改 owner／共享修改、文件保存、终端输入、Commit／Push、
浏览器／模拟器预览。桌面及 mobile 列表标记只读。管理回调在写入前重查当前编辑权，
会话 owner 兜底及只读授权不能通过管理检查。

## 已接受的信任边界及后续阶段

**本阶段只防诚实成员的界面误见，不防直接改写同步数据的恶意成员。** `machineId`、
包含关系和 `userId` 是可变 CRDT 元数据；恶意成员能伪造这些字段，绕过可见性及读取路由，
包括会话 owner 兜底。owner 于 2026-11-10 接受这一边界，本阶段不做权威会话→机器登记。

**E2EE 私密只是界面隐藏，不是密码学私密。** 成员仍持有工作区内容密钥，可绕过界面恢复
内容。根治须「会话→机器权威登记 + 服务器按会话过滤下发」；每会话密钥留待后续阶段。
可写共享及其他邀请语义另行评审。
