## 1. 场景、目标与范围

玩家与 Alice、Bob 在一个像素舞台上交换秘密，尝试伪造操作，核对不同视图，再撤权、换代和恢复设备。表世界讲人物事件，随时打开的「里世界窥镜」解释同一事件的真实签名、验证、存储和网络行为。本规格取代本次教程此前的九关、Three.js 与完整小镇方案，不取代 E2EE 协议或独立 demo 的安全要求。

目标是五个工作日完成、约 10–15 分钟可玩完的本地教程；这是排期和体验目标，不是已测量结果。面向初学者，不要求阅读白皮书或操作终端，启动者仍需运行 `pnpm demo:e2ee`。不承诺已对儿童或老人完成可用性验证。

开发留在当前仓库、当前分支，包仍为 `packages/e2ee-demo`。复用真实 BrowserSession、E2EE core、Streams CRDT 与 Node/官方 SQLite Riverrun。不得新建仓库或长期开发 worktree，不接 Lody 产品，不改变密码学或授权语义。

## 2. 一屏舞台与操作模型

桌面：顶部是四关进度和重新开始入口；中央是 Alice—邮局—Bob 固定舞台；当前行动者突出；下方是两句以内的任务和一个主行动；右侧可展开窥镜。恢复时用 Carol 的新设备替换右侧座位，不再增加第三栏。

窄屏：保留单一舞台，用座位切换代替三栏；窥镜在舞台下展开。主要控件留在正常阅读顺序内，不因缩放或软键盘被遮住。中文用清晰无衬线正文，像素字仅用于极短装饰，不能用于操作、证据或错误。

主循环：提出问题 → 可选预测 → 一次真实操作 → 显示结果 → 可选窥镜 → 下一步。预测可跳过、无惩罚；错误预测解释原因，不阻断流程。机械准备可由教程执行，但必须显示哪些角色由本页代演，不能暗中把私钥交给另一角色。

玩家无需手动走路、精准拖放或同时操作两侧。盖章、信封、开锁是动作反馈；动作结束不等于操作成功。

## 3. 两种模式与信任来源

**教学双座位**是默认模式：同页驱动独立密钥的 Alice/Bob，存储按教程运行、座位与账号隔离，不接触原 demo 用户数据。清楚显示「本页扮演两人，不构成设备安全隔离」。同源脚本能够访问两边秘密，localStorage 前缀不是安全边界。

**独立设备模式**用于真实验收：不同浏览器配置、浏览器或隔离 browser contexts。另开普通窗口通常共享存储，不能标为隔离。教程显示每个座位的公开设备指纹，帮助确认没有误用同一身份。

摘要来源分为服务端、教学自动递送、用户确认的独立信道。前两者最多显示「摘要相同，尚未独立核对」；独立路径要求用户从已认证的另一成员实际取得纸条，输入不是来源可信的自动证明。不得提供把服务端纸条一键转成「独立」的按钮。

核对记录绑定 Org、位置、链头、状态摘要及对端。当前位置变化后保留「曾在位置 N 核对」，不能显示永久安全。同位置冲突不自动选边；不同位置先提示同步或核对共同位置。原始背书者的重复背书不构成额外独立见证；不要把这条规则讲成「创建者永远不可信」。

## 4. 四关剧本与完成条件

### G1 邮差偷看：批准了，为什么还打不开？

**问题：**「邮差拿到了信，就能看懂吗？」

1. 教程启动两个座位；Alice 创建房间，在日记写一句合成秘密。
2. 点邮局柜台：读取本次实际保存/转发的密文。显示大小与路由标签，说明并不隐藏全部元数据。
3. Bob 签署申请；Alice 检查申请并批准；双方从真实账本验证接纳。此时 Bob 试读仍因缺钥失败，文案为「你在名单上了，钥匙还没送到」。
4. Alice 向 Bob 的公钥发送密钥信封；Bob 解包后读出原文。不要复制 Alice 的密钥 Map 来完成效果。

**窥镜：**成员接纳、信封投递与内容可解密是不同事件；展示双方设备公钥、账本位置、信封摘要、真实读取结果。

**异常：**申请失败、CAS 冲突、信封缺失保留在当前步骤，可重试或查看原因，不以动画解锁下一关。

**完成证据：**两个客户端接受同一接纳状态，Bob 从真实数据流解密得到 Alice 的原文。邮局视图不能读取端点私钥；字符串检查只能辅助，实际加解密是必要证据。

### G2 狐狸盖假章：有效签名不等于有权限

**问题：**「盖得像，就能往签名本上写吗？」

1. 在独立合成实验房间，狐狸修改一份真实签名记录的正文后，交给原验证器。展示实际拒绝、验证状态未推进。
2. Bob 用自己的真实密钥签署越权操作，例如给自己提升角色；展示真实权限拒绝。若高层 prepare 已拒绝，就如实显示“准备操作时被拒绝”，不得伪称 HTTP 已发出；宿主攻击测试另用低层规范编码构造合法签名的不合法操作。
3. 并列展示「签名不对」与「签名正确、但没有这个权限」。印章有效不能代替角色检查。

**窥镜：**前态角色、设备资格、被签正文、拒绝边界；底层若返回统一错误码，不凭 UI 编造细分错误。

**异常：**预期拒绝与环境故障分开。网络断开不是验签成功挡住攻击；非法记录被接受则停止该关并报告实现缺陷。

**完成证据：**实际验证器拒绝两个不同原因的操作，原有权限未被提升。实验不污染主故事账本，不放开正常宿主的控制流旁路。

### G3 两张不同的纸条：邮局说一样，够了吗？

**问题：**「狐狸和邮差一起给你看假纸条，你怎么知道？」

1. 从两个真实客户端导出含位置与状态摘要的纸条。正常服务端转交可显示相同，但标记为未独立核对。
2. 在隔离的分歧视图实验中，拦截实际导出的公开纸条，修改同位置状态摘要，送入真实比较 API。窥镜明确标注“被改的是声明，不是成功制造了一条合法分叉账本”。
3. 单看一方纸条不能证明全局一致；双方经独立途径交换后，真实比较产生 conflict，显示「两边接受的声明不同，先别继续」。
4. 恢复未修改的真实纸条再比较：教学递送仅通过本关演示；独立设备模式在真实来源核对后才能显示「已在位置 N 独立核对」。

**可选预测：**两张纸条的位置不同，是否已经证明有人作恶？答案是不能；实际展示 pending-sync，不显示攻击告警。

**解释边界：**邀请者与邮局合谋背书误导状态时，新人可能被骗；没有诚实端的独立材料时可能无法发现。本周仅实现上述公开摘要分歧实验，不声称实现完整恶意权限快照背书、合法分叉或透明目录。

**完成证据：**匹配、同位置冲突、不同位置三个真实比较结果与来源标签均正确。冲突不自动选边，服务器或教学复制不获得 checked 状态。

### G4 收回权限与找回秘密

两段分别展示，不把撤权、换代与恢复同时塞进一个动作。

**G4a 换锁不抹记忆。** Bob 先读并保留一句旧秘密。Alice 移除 Bob，明确显示撤权已入账；随后按真实流程换代并确认，再写一句新秘密。Bob 的本地旧内容仍可读，只有旧钥时对新密文的真实解密失败。宿主拒绝读取与密码学无法解密是两个不同结果；后者使用实验提供的实际新密文副本验证，不能为了测试放宽正常读取权限。换代前不能亮“新内容已对旧成员保密”的盾牌。

**G4b 新电脑，不是旧电脑的复制品。** Alice 在本段当前状态创建/验证恢复材料，导出文件，明确确认“已保存”后关闭原会话，在新隔离上下文从文件和持久状态恢复。R 必须真实授权新个人设备；新设备公钥与旧设备不同，并能解密本关已有内容。新上下文不能共享旧会话密钥对象。

本周保证这条有界文件恢复演示，不新增长期云端恢复投递机制，不把“导出后立即恢复”当作“旧恢复文件能跨任意换代恢复”。目前文件格式若包含当时密钥材料，窥镜须如实展示材料类别而不泄露秘密值。旧文件跨代、R 新钥未投递、Passkey PRF、恢复后管理能力等以真实实现能力为界，未验就标“尚未接入/未验证”。

**失败：**损坏文件不能解锁；恢复失败保留已登记状态供检查，不伪造重新入群。恢复用合成可重建数据；不得模拟关闭而仍从旧实例偷取钥匙。

**完成证据：**撤权/换代不同状态可观察；旧钥打不开新代；真实新设备从文件路线恢复并读回秘密。文案说明全失设备和恢复材料可能失去旧秘密，但不阻断普通账号登录或创建新 Org；本关不实现产品登录。

## 5. 窥镜与真实证据

窥镜为固定侧栏/下方面板，不做拖动镜片、3D 剖面或通用逐帧播放器。点击物件或“看看里面”选中当前操作，关闭后回到原位置。

三层渐进展开：

1. 人话：发生了什么、现在还差什么（最多三句）。
2. 步骤：真实执行过的签名、持久保存、发送、验证、提交、接收解密。未观测内部步骤标“流程说明”，不得伪造完成时间或验签次数。
3. 证据：操作类型、公钥/签名、记录摘要、位置、HTTP 或库结果、前后状态的非敏感摘要；原始公开字节折叠。标明对应白皮书主题和当前实现入口。

建议薄事件格式：runId、actionId、actorDevice、operation、boundary、outcome、recordHash/position、publicEvidence。它是 UI 追踪标识，不修改线格式或 ledger operation ID；从真实结果产生，不用动画触发。不要把整份 Session、私钥、代次密钥、恢复文件或完整明文加入通用 trace、日志和错误上报。秘密只能在用户所属端点的场景内按需展示。

动作状态：idle → running → confirmed / rejected / unknown。成功业务可能有多个独立阶段，例如 confirmed admission 后仍 waiting-for-key。unknown 保留精确 pending 并通过既有恢复 API 确认，不因点击重试重新签名。恢复游玩进度时，以真实设备/账本/钥匙和已保留证据重算前置条件；故事勾选不能成为授权来源。

回看只展示本周已完成事件的摘要列表，不倒带数据库。重玩创建隔离合成运行；删除旧实验必须限定准确运行范围并确认，不能清除整个 origin 的所有数据。

## 6. 视觉、动效与无障碍

固定像素舞台，人物和邮局复用一套本地、许可明确的素材；信封、钥匙、印章用 SVG/CSS。React/Vite 保持；可用 Base UI 承担 Dialog、Tabs、Switch 等确有需要的原语，不为组件清单全部引入。无新增游戏引擎或 Lody UI 包。素材本地打包，运行时不依赖远程字体/CDN；许可与来源在素材目录简短记录。

纸底 `#F6F1E4`、墨色 `#1C1915`、朱红 `#C23A2B`，窥镜用深蓝制图稿的视觉层次。强调色用在当前动作与检查点，不把错误预测涂成整屏失败。对比度须实测，不凭 token 名称声明合格。代次使用颜色＋编号＋形状，不仅颜色。

只做信封送达、盖章入账、钥匙开锁三类短动效；结果未知时信封停在“待确认”。动效可以跳过，reduced-motion 下直接呈现结果。动画不暂停实际网络，也不决定最终状态。不强制拖拽或精细点击；提供键盘焦点、可读名称、错误通知和触屏按钮。

验证 390px 与 1280px 宽度、200% 缩放、键盘全流程、reduced-motion。大字号中文不截断；证据长 hash 可换行/复制，不挤走主操作。无 WebGL 依赖，不要求独立显卡。

## 7. 最小技术结构

```text
玩家操作 → tour 控制器 → BrowserSession / 实验适配器 → 原有 core + HTTP + Riverrun
                            ↓ 实际结果
                        有限公开事件
                        ├─ 像素舞台
                        ├─ 窥镜
                        └─ 关卡验收
```

在现有 `src/ui` 内按职责拆出 tour、stage、inspector、copy 和 styles 即可；文件名不是新框架要求。自由实验继续复用旧操作。只有确需桥接真实行为时才改 BrowserSession，不能在 UI 重写协议；缺少基础安全能力视为独立修复，不偷偷扩大本周实现。

故障/分歧适配器只能在隔离实验运行中启用，必须送真实字节到原验证/比较 API。URL 可控制面板显示，宿主 testMode 必须显式启动，页面参数不能开启能力；已修复的控制流 allowlist 不得回退。

同页两个 Session 只通过正常公开材料与密文交换；禁止为方便渲染让邮局视图直接读双方秘密。默认教学运行存储与原 demo 手动账号命名空间分开；跨标签并发不能靠 localStorage 前缀推断已有互斥，若不支持则明确限定一运行一个活动控制页。

稳定 id 可以保留，但只能挂在真实可见/可操作控件；禁止隐藏旧按钮给 Playwright 走后门。需要改测试时改为座位范围内的语义 locator。原始协议测试不因 UI 改写而删除，完整教学流程是必验项。

## 8. 验收标准与白皮书覆盖

| ID  | 触发与必须观察的结果                                                               |
| --- | ---------------------------------------------------------------------------------- |
| A1  | 完成 G1 时，两个独立客户端有不同设备密钥，Bob 经真实信封解密真实数据，不靠内存复制 |
| A2  | 当实际验签或权限检查拒绝时，展示真实边界，权限不提升；环境失败不冒充安全拒绝       |
| A3  | 比较来源为服务器/教学递送时，永不显示独立 checked；同位置冲突与不同位置区别显示    |
| A4  | 新代内容创建后，持旧钥端真实解密失败，旧内容仍可读；上传拒绝不代替密码学验证       |
| A5  | 原会话关闭后，在隔离上下文用文件恢复不同公钥的新设备并读回本关内容，不复用旧私钥   |
| A6  | 刷新/中断后，不丢已保存身份与 pending，不把进度勾选当权限，保存失败不发 CAS        |
| A7  | 打开窥镜时，结果来自同一次 action 的实际证据；没有私钥、恢复秘密进入通用 trace     |
| A8  | 以键盘、触屏、reduced-motion 和 200% 缩放操作，主路径可达且错误可理解              |
| A9  | 自由实验与原有测试保留；标准启动命令不变；重玩仅作用于隔离合成数据                 |
