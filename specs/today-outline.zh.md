# Today 大纲笔记（实验功能）

Status: draft
Translation: current

[English](today-outline.md)

## 场景

用户每天打开 Lody，需要一个地方临时记点东西：准备稍后发出的 prompt、备忘、正在推进的对话。
Today 是每个成员按天分页的极简大纲笔记。节点可以引用一个 Lody 对话并实时显示它的状态；
写好的 prompt 节点可以一键转换为任务发出。它以实验功能的形式挂载，可随时开关，
关闭后不影响主应用的任何既有行为。

## 行为

### 开关与入口

- 设置 →「实验功能」下单独一行「Today」开关，只存本机。开启后侧栏顶部导航出现「Today」入口；
  关闭后立即卸载入口、页面与所有订阅。开关只控制界面：数据照常同步、导出、迁移。
- 中文界面中功能名为「每日笔记」（对应英文 Today；参照 Obsidian 把短名 “Today” 译作「日记」，避开「今天」作名词的别扭和「日志」的 log 联想），
  当天的日期标题仍是「今天」，返回按钮仍是「回到今天」。
- 快捷键「打开每日笔记」默认 `⌘⇧D`（Windows/Linux 为 `Ctrl+Shift+D`，D 取 Daily，与 Roam、Tana 的每日页一致），
  桌面与网页相同，可在设置的键盘快捷键里改绑或解绑；只在实验开启时生效并出现在快捷键列表与命令面板中，
  固定时与点击侧栏入口一样只切换 Today 栏。
  悬停侧栏的「新对话」「Today」「搜索」时，行尾浮现各自当前绑定的快捷键胶囊（与按住 ⌘ 显示的 ⌘1–9 同一样式），
  按住修饰键时也一并显示。
- v1 覆盖桌面端与 Web；手机端不显示。
- Today 可以占满主区域，也可以用顶部图钉固定为左侧栏右边的一栏（布局为 左侧栏 | Today | 主区域）。
  固定栏是与主区域同样的内凹页面卡片（更深的底色、同样的圆角与描边），紧贴侧栏，与主区域卡片之间留 4px 窗口底色，
  两页分开而不连成一片（用户决定）。侧栏收起时固定栏成为窗口最左侧的一栏：侧栏开关与前进/后退按钮移到它的顶栏（排在红绿灯右侧），
  主区域不再显示它们也不再为红绿灯让位；内容左侧对齐最左的红灯（x 16–30）：小圆点中心落在红灯右缘（x=30），折叠箭头中心落在红灯左缘（x=16），
  日期标题与圆点左缘对齐，右侧留白为 16px（用户决定）。
- 折叠箭头紧贴圆点（两者中心相距 14px），只在悬停该行、键盘聚焦或正在编辑该节点时出现；折叠的节点平时以带圈的圆点提示。固定状态与栏宽只存本机，栏宽可拖动。
  取消固定时主区域保持当前内容，只收起 Today 栏。
- 占满主区域时，内容默认限制在居中的 720px 可读列内（参照 Obsidian 700px、Notion 约 708px、AFFiNE 约 752px 正文宽度），
  窗口变窄时随之收窄并保留两侧留白；嵌套缩进占用列内宽度。「更多」菜单的「全宽」开关改为铺满整个主区域，
  这是本机的全局偏好，不按日期区分。拖入对话时落在列旁空白处，也落到同一高度的那一天。固定时打开同一工作区的 Today 链接或点侧栏的 Today 入口，
  只让 Today 栏跳到对应日期，主区域同样保持当前内容。
- 桌面端在图钉旁（整页或固定栏）有一个按钮，用独立窗口打开当前显示日期的 Today，每个工作区一个窗口（再次打开只把它提到前面），
  原窗口不变。该窗口只显示日期流，其图钉改为让窗口置顶于所有窗口之上。从其中的引用（单击或 Enter）打开的对话显示在主窗口；
  转为任务后 Today 留在原处。该窗口不加载工作区外壳（侧栏、通知、角标、命令面板），也不启动对话的后台预取：
  只同步它显示的页面、元数据与实时状态。关闭实验功能时窗口随之关闭。

### 页面流与日期

- 每个成员在每个工作区每天一页。页面日期是写入者创建该页时本地时区的 `YYYY-MM-DD`，存在 docId 里，
  其他人看到的分页与之一致。页面流顶部的"今天"按查看者自己的本地日期计算，包括查看别人的 Today 时
  （主人时区不存储，跨时区最多差一天）。
- 页面纵向连续滚动：今天在最上面，往下依次是更早的非空日期，每天一个日期标题。今天即使为空也始终显示。
  空白日期被跳过；有登记但内容已清空的日期不显示，也不删除其文档。
- 未来日期不进入页面流。日历入口可跳到任意过去或未来的日期（即使为空），页面流以该日为顶部重新定位，
  下方接更早的非空日期；有登记的日期在日历上有标记（不为此加载文档判断是否为空）。非今天时浮出「回到今天」。
- 页面在当天第一次输入时创建并登记，只是查看不创建。跨午夜时顶部出现新的今天，当前滚动位置保持不动。
- 所有日期的内容都可直接编辑。
- 默认显示自己的 Today。顶部更多菜单里有「查看成员的 Today」，可切换到任何成员的 Today 并编辑，平时不占界面；
  成员列表复用工作区现有的成员来源，每个成员带头像，只有一个成员（如本地 OSS 工作区）时不显示该项。更多菜单还提供「复制链接」，
  指向某成员某天的页面。v1 不显示他人光标或在场状态，并发编辑由 CRDT 合并。

### 大纲编辑

- 节点内容是纯文本（v1 不支持粗体、链接等行内格式），可缩进、折叠、排序。Shift+Enter 在节点内换行。
- 按键（我的判断，均参照 Logseq / BlockSuite 的成熟做法）：
  - Enter 在光标处拆分；空节点在嵌套且无下一个兄弟时提一级，否则新建兄弟。
  - Tab 缩进到前一个兄弟之下（若其折叠则自动展开）；Shift+Tab 直接提级，原来后面的兄弟成为它的子节点（用户决定）。
  - 行首 Backspace 合并到上一个可见节点，子节点随之挂过去。
  - ↑/↓ 只在首行/末行跨节点，保持视觉列位置，跳过折叠的子树；在一天的首/末节点继续移动会进入相邻日期。
  - `Mod+Shift+↑/↓` 连同子节点上下移动；`Mod+↑/↓` 折叠/展开；`Esc` 进入块选择（用户决定）。
- `Mod+A` 逐级扩大选区（用户决定，参考 Logseq 与 Obsidian Outliner 插件）：编辑中先选中本节点文字；文字已全选（或为空）时选中该节点；
  之后每按一次选中父节点（多个选中节点则到它们最近的共同祖先）；到顶层时选中当天全部节点，然后不再变化。不会跨日期选择。
- 块选择：Esc，或拖选跨出一个节点时，整块选中节点；可复制、剪切、删除、拖动、缩进。选中一个节点即包含它的整棵子树，高亮也覆盖子树。
  选区跨越不同层级时，缩进与提级按每段相邻的同级节点各自执行，与逐个操作结果一致；上下移动只对同一父节点下相邻的一段生效，否则不动。
  块选择中（包括删空页面后）`Mod+Z` / `Mod+Shift+Z` 照常撤销、重做，Windows/Linux 另支持 `Ctrl+Y`。
- 编辑中按 Shift+↑/↓：不在首/末行时由浏览器在节点内扩选一行；在首/末行时先把选区扩到节点开头/末尾；选区已到节点边界时再按一次，整块选中当前节点（只选这一个）。之后 Shift+↑/↓ 以起点为定点逐个扩展或收缩，收回起点时保持块选择，可越过起点翻转；不跨日期。由此进入的块选择按 Esc 回到原来的文字选区（用户决定）。Mac 上 ⌥⇧↑/↓ 留给系统按段落选择，移动节点用 `Mod+Shift+↑/↓`。
  剪切粘贴可跨日期、跨成员的 Today。
- 粘贴多行文本按行拆成同级节点，按缩进推断层级；代码块保持为一个节点。
- 待办（用户决定）：`Mod+Enter` 让节点在 普通文本 → 待办 → 已完成 → 普通文本 之间循环；块选择时每个选中的行各自从自己的状态
  前进一步，合为一步撤销。待办节点在圆点和文字之间显示复选框，点击它在待办与已完成之间切换；已完成节点的文字加删除线并变淡。
  在待办节点里按 Enter 新建一个未勾选的待办，在空的待办上按 Enter 则变回普通文本。复制时写成 Markdown 任务标记
  （`- [ ]`、`- [x]`），粘贴时读回。
- 选择条（用户决定）：松开指针后，块选择上方浮出一个小操作条（选区顶部滚出视野时改在下方），包含待办切换、转换为任务、复制、删除。
  操作条不抢焦点，块选择的快捷键照常可用。
- 指针悬停在圆点上时显示一圈底色，提示它可点击。没有文字、没有子节点、也不是待办的空行平时隐藏圆点，
  悬停该行、正在编辑或被选中时才显示（用户决定）。
- 折叠状态存在页面文档里并随页面同步，打开页面时沿用文档里的折叠；但正在浏览该页的人不会实时被别人的折叠/展开改变视图，
  直到自己再折叠或展开这个节点（用户决定）。折叠与展开不进入撤销栈。
- 中文输入法组字期间，Enter、Tab、Backspace 与 `@` 菜单都不响应。

### 聚焦视图

- 用户决定，参考 Workflowy 与 Logseq。点击某天的日期标题只显示这一天；点击圆点（或 `⌥→`）进入该节点，只显示它和它的子树。
  此时 Today 工具栏左上角显示面包屑「每日笔记 › YYYY-MM-DD › 上级 › 本节点」，每一段都可点击返回；点「每日笔记」回到日流，
  并恢复进入前的滚动位置（以当时顶部可见的那一行为锚点，上方被别人编辑也不会错位）。超过五段时，中间的上级折叠为「…」。
- 进入节点后，节点文字作为可编辑的标题（没有圆点），子节点从第 0 层列在下面，即使该节点是折叠的。在标题里按 Enter 新建第一个子节点；
  光标、`Mod+A`、拖放、Backspace/Delete 合并以及删除后的光标落点都限制在子树内；在它自己的视图里不能缩进、反缩进、移动、合并或删除该节点，其直接子节点也不能反缩进到外面：
  在它的最后一个空子节点上按 Enter 会再新建一个子节点（与 Logseq 一致），因此连续 Enter 或 Shift+Tab 都不会让任何一行离开子树。
  节点期间被删除时显示「这个节点已被删除。」并提供返回入口。
- 进入的节点没有子节点时，指针停在正文区域上，第一个子节点圆点的位置显示「+」（触屏上一直显示）；点击它或正文的任意空白处，即新建这个子节点并把光标放进去，
  撤销一次即可撤回（用户决定，参考 Logseq 的添加按钮）。
- 快捷键：`⌥→` 进入正在编辑或选中的节点，`⌥←` 上退一级（节点、上级、当天、日流）。Windows 与 Linux 上始终生效；Mac 上 `⌥←/→`
  是按单词移动，所以只在块选择时生效，编辑时只在光标位于行尾（`⌥→`）或行首（`⌥←`）时生效。`⌘.`、`⌘,`、`⌘[` 保留应用原有功能；
  整页模式下聚焦写在路由里（`focus=day|<id>`），浏览器后退即可退出。固定栏和 Today 窗口在各自的状态里记录。
- 悬停一行时，折叠箭头左边出现「⋯」（栏贴着窗口左边缘、没有余量时改放在行尾）；点它或右键圆点打开节点菜单：进入节点、待办切换、
  转换为任务、复制、删除。菜单打开期间该节点显示为选中。

### 节点拖拽

- bullet 是拖动把手，移动超过 5px 开始拖动，否则视为点击：进入该节点（聚焦视图）。
- 落点只有一种：两个可见节点之间的插入线，层级由指针水平位置决定，线在哪一层，节点就落在哪一层。
  带子节点或折叠的节点整棵子树一起移动；拖动已选中的节点时带走全部选中块。
  落点会成为折叠节点的子节点时，停留约 0.5 秒后自动展开。
- 只能在同一天内拖动；拖到其他日期显示「不能移动到其他日期」，松手后飞回原处。拖动中 Esc 只取消拖动。
- 从左侧栏（任意分区）把对话拖到两个节点之间，新建一个只含该对话引用的节点。
- 视觉沿用置顶区的浮起卡片、5px 阈值与约 100ms 落位动画，但用插入线代替"让出空位"。

### 会话引用（mention block）

- 对话以行内 mention block 的形式出现在节点文字中，前后都可以写字。它显示链接色的实时标题，开头是状态图标。
  数据上每个引用在节点文本中占一个字符（U+FFFC），带 `mention = {kind: 'session', id}` 标记（`expand: none`）；
  不再有"整行是一个会话"的节点类型。不认识的 `kind` 显示为灰色占位，复制时原样保留。
- 插入方式：在任意位置键入 `@`（或全角 `＠`）打开会话菜单，选中后在原位插入引用，撤销一次回到 `@关键词`；
  在任意位置粘贴同一工作区可解析的 `lody://session` 链接（裸链接或 Markdown 链接）即转成引用；
  从侧栏把对话拖到两个节点之间，新建一个只含该引用的节点。
- 光标：引用占一个光标位。光标在引用右侧按 ←，先整体选中引用（高亮）；再按 ← 才移到它左侧；→ 对称。
  光标在引用右侧按退格（左侧按 Delete），第一次只选中，第二次才删除；`Alt/⌘+退格` 直接删除。
  选中整个引用时按 Enter 打开对话，与单击标题一致（固定模式在右侧主区域打开，否则跳转）。选中时直接打字替换引用。
- 状态与侧栏完全一致，复用侧栏的状态分组与未读、运行、审批信号，不在 Today 另行判断。图标优先级（统一为 12px 静态图标，除举手外均为圆形）：

  | 会话状态                       | 引用开头的图标                          |
  | ------------------------------ | --------------------------------------- |
  | 等待审批 / 提问                | 蓝色举手图标                            |
  | 运行中                         | 蓝色描边圆，右半填充（静态，不做动画）  |
  | 稍后                           | 蓝色时钟圆 + 倒计时（同色小字，同基线） |
  | 已完成（收尾）、已归档         | 淡灰对勾圆，与删除线淡化的标题同色      |
  | 未读（Agent 托管的对话不显示） | 蓝色实心小圆点，标题不加粗              |
  | 空闲                           | 蓝色虚线圆                              |

- 单击状态图标打开状态菜单，直接修改对话状态（与侧栏写同一份会话元数据）：标为未读 / 标为已读（按当前状态二选一）、
  稍后（预设时间与自定义，复用侧栏）、完成、移回进行中（仅在稍后或已完成时出现）。
- 对话已删除或当前用户无权访问时，引用显示「对话已删除 / 无权访问」，不显示标题；引用保留，由用户自行删除。
  删除引用不影响对话本身。
- 纯文本形式（复制、转换为任务的提示词）中，每个引用写成 `[@标题](lody://session/<id>?workspace=<id>)`。

### 成员引用

- `@` 菜单同时列出工作区成员（用户决定，参考飞书）：分「全部」「人」「对话」三栏；「全部」每类显示前几个匹配，人在前。
  工作区里没有其他成员时不显示人。
- 成员引用沿用同一种单字符引用，`kind: 'member'`，`id` 为成员的 userId。显示为带底色的胶囊，含成员头像和当前名字；
  点击打开该成员的 Today。已不在工作区的成员显示为「未知成员」。引用他人不发送通知。
- 纯文本形式中成员引用写成 `@名字`。不支持成员引用的旧客户端显示「不支持的引用」占位，并保留标记。

### 转换为任务

- 选中单个节点（连同子树）时，选择条上有「转换为任务」。在弹窗中打开新建对话页的同一个组件，不离开 Today，新建对话页支持的能力
  （项目组、附件、Agent Role 等）在这里都可用：
  - 提示词预填为该节点文字及全部子节点（含折叠的），按缩进拼成文本，可修改。节点有上级时，默认把它嵌在上级节点下面，
    整体拼成一个缩进列表（用户决定）；「包含上级节点」勾选项可在两种形式间切换，提示词被修改后不再切换。
  - 机器、项目、Agent 配置等默认值与新建对话页相同（上次的选择），不从大纲上下文继承。
  - 弹窗使用独立的草稿，不影响新建对话页自己的草稿。Enter 发送（输入法组字中不发送）。
- 选中的节点连同其子树一起显示为选中，表示「转换为任务」会带走的内容。
- 创建成功后，若节点文字未被改动，该行在原位变成只含新对话引用的一行，原来的子节点保留在它下面并折叠；
  若期间文字被改过，则在行首插入引用，不覆盖改动。创建失败时原节点不变。
  固定模式下新对话同时在右侧主区域打开，否则留在 Today。
- 新对话是普通对话，出现在侧栏中，没有额外标记。

## 数据归属

- 每页一个 LoroDoc。docId 为 `today-<userId>-<YYYY-MM-DD>`，映射到 Loro Stream
  `{workspaceId}:td:{userId}:{date}`。docId 是 loro-repo 里的名字（登记、本机持久化、加密绑定），
  Stream id 是网络同步地址，与会话、定时任务等现有文档的做法一致。
- docId 与 Stream id 中的 userId 一律做 `encodeURIComponent` 编码：本地工作区的 userId 形如 `local:…`，
  含冒号，不编码会破坏 Stream id 的分段。解析 docId 时从末尾取固定长度的日期。Today 使用的 userId 与
  `SessionMeta.userId` 相同。Stream id 中可读的 userId 与日期对服务端可见，这是有意接受的（加密工作区中内容仍加密）。
- 页面第一次写入时通过 `repo.upsertDocMeta` 在 meta flock 登记 `{ userId, date }`。列出某成员的日期时按 docId 前缀筛选，
  不在 meta 中存放内容或摘要。
- 登记或加入同步失败时，页面打开期间按指数退避自动重试，最长间隔 5 分钟，避免失败时给后端持续加压。
  本地编辑会立即重试登记（本地写入），但不会打断加入同步的退避。已拿到订阅但首次同步失败的房间保留订阅、由 SDK 自愈，
  与会话房间一致。打开一个有本地内容但未登记的页面时立即补登记，内容不会因一次失败只留在本机。
- 页面内容：`LoroTree` 表示大纲结构（分数索引排序），每个节点的数据里有一个 `LoroText` 存文字，
  对话引用是其中带标记的字符；折叠状态和待办状态（`todo: 'todo' | 'done'`，普通文本没有此键）与之并存。
  不认识待办键的客户端会忽略它，把节点显示为普通文本。
- 数据与工作区共享：所有成员可读写所有成员的 Today，界面和同步层都不区分页面主人。
- 加密工作区：文档类房间按 docId 自动加密，meta flock 同样受保护，Today 无需另行处理。
- 不写入 SessionMeta，不新增 Flock 行家族。

## 实现约束

- 每个节点的编辑器是 Lexical，同一时刻只挂载正在编辑的那一个，其余节点渲染为样式一致的静态文本；
  点击时按坐标计算光标位置后挂载。跨节点的光标移动和拖选在节点边界拦截后手动交接焦点。
- LoroText 与 Lexical 之间自写一个只支持纯文本的薄绑定：远端变更按 delta 原地修改并变换光标，
  组字期间缓冲；不使用 `@datalayer/lexical-loro`、`@llui/lexical-loro`，它们与本仓库的 Lexical 0.53 不兼容。
- 每页一个 Loro `UndoManager`，关闭 Lexical 自带历史；拆分、合并、多行粘贴、转换各为一次撤销步骤，
  撤销与重做恢复节点与光标。跨日期的剪切粘贴是两页各自的一步，不做联动撤销。
- 页面流按滚动懒加载，离开很远的日期释放文档；含焦点、选区或拖拽源的日期不释放。
- 性能目标（用户决定）：单日 3 万个节点、最深 7 层、约一百万字时，滚动和编辑都没有可见卡顿。可见行达到 200 行的日期只挂载视口附近的行，
  外加正在编辑的那一行（无论它在哪里；卸载会结束它的编辑器和输入法组字）。页面模型增量维护快照：打字只更新被编辑的行，
  结构变化时从树的 JS 镜像重建可见行，不逐个节点读取文档。`Today/Stress` story 保存压测用的大纲。
- 侧栏置顶对话的指针拖拽桥目前只在松手时投递，需要增加悬停回调才能画出插入线；该改动会经过置顶区拖拽，
  需一并回归。
- 新增 deeplink `lody://today/<userId>/<date>?workspace=<workspaceId>`，在 [深链接](deep-links.zh.md) 中登记；
  其中 userId 允许规范化的 `%XX` 编码，这是相对会话链接的有意例外。
- 不开放 MCP 工具，Agent 不能读写 Today。

## 不在范围内

- 行内格式、图片。隐藏或归档已完成节点；完成父节点不影响其子节点。
- 跨日期拖动、"移到某天"操作。
- 他人光标与在场状态、按页面主人限制编辑。
- Agent 读写 Today、手机端与原生客户端。
