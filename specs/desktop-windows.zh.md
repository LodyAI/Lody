# 桌面多窗口

Status: draft
Translation: current

[English](desktop-windows.md) | 中文

用户可并排查看对话和工作区，打开新窗口不改变来源窗口。

| 操作                                           | 结果           |
| ---------------------------------------------- | -------------- |
| 普通点击 Session 或切换工作区                  | 当前窗口导航   |
| macOS Command 点击、其他桌面 Control 点击      | 新窗口打开目标 |
| Session 更多或右键菜单中的“在新窗口中打开对话” | 新窗口打开对话 |

本版不支持拖出开窗；Session 拖拽仅保留原有提及交互。

工作区选择器底部展示 Command/Ctrl 点击开窗提示；右键工作区提供“在新窗口中打开”，
打开右键菜单不切换当前工作区。
侧栏会话菜单依次为：展开/收起子会话、置顶、标记未读、重命名；复制链接、复制分支、分享；
打开 PR、前往来源会话、在新窗口中打开；归档。
分组之间用分隔线，不显示组标题或空组；不可用操作按现有条件隐藏。
新窗口操作放在倒数第二项，归档最后且使用普通文字样式。

对话窗口首帧收起左侧栏，打开指定对话并一次性聚焦输入框；仍可展开侧栏。
工作区窗口使用完整导航。各窗口的导航、草稿标签和面板状态独立。

桌面窗口——桌面应用或桌面浏览器——可以缩窄到移动布局断点以下，此时仍保留桌面布局，
改为紧凑呈现。导航侧栏和会话右侧面板不再占据分栏，而是浮于内容之上直到被关闭；
重新拉宽窗口后会恢复。移动设备仍按断点选择：断点以下是移动布局，视口足够宽时是
桌面布局。

紧凑布局的导航侧栏采用模态交互。打开时焦点进入导航；Tab 和 Shift+Tab 留在导航内，
背景控件不能获得焦点或接收指针交互。Escape 先关闭最内层弹出菜单或对话框，再关闭导航。
点击导航遮罩或显式关闭导航会持久化收起状态，并将焦点恢复至打开控件；
该控件已不可用时恢复至内容焦点区域。拉宽窗口会解除模态边界。

桌面设置按面板宽度适配：窄面板把分类导航折叠为图标栏——仍是同一条侧栏列，
只是收起标签与分组标题，每行保留可访问名称与悬停提示；宽面板保留完整侧栏。
所有可用分类保持可达；选择分类或调整尺寸时，
仅滚动导航列以露出当前项，不滚动正文。调整窗口尺寸保留当前分类和打开的编辑器草稿。嵌套设置编辑器
保持焦点循环限制、Escape 返回设置，以及短窗口中可滚动的表单和可见的底部操作。

开发者选项中的窗口预热提前准备应用外壳；本地模式在选择目标之前启动隐式工作区 Runtime、
Repo 和元数据同步。领取同一工作区时保留该 Runtime，包括尚未完成的初始化。
中性路由不挂载目标会话 UI，也不写入工作区路由上下文。
本地模式的会话由一个应用级数据 renderer 持有。第二个视图读取索引投影与有限尾部内容，
不再导入一份会话文档。数据 renderer 保留 UI 作者身份、现有历史校验与存储快照来源；
CLI 仍是 agent 作者。各产品窗口保留自己的元数据 Repo、同步游标、草稿、编辑器和附件准备。

会话历史和队列命令等待文档落盘后才确认成功。关闭一个视图只释放其租约，不影响其他视图，
也不丢弃已确认的修改。退出应用时先排空数据所有者，再停止传输。所有者故障会拒绝未完成命令，
明确结果可能不确定，绝不自动重试写入；读取订阅使用新代次重新连接。
旧窗口快照合并到所有者，不能替换未同步修改或删除旧缓存。加载失败必须可见。
共享会话数据不能免除窗口内待完成附件和未保存编辑器的关闭保护。
macOS 本地模式启用该选项后，同一个备用窗口可在会话行悬停、键盘聚焦或打开会话菜单时
提前准备目标会话。主进程只保留一个隐藏视图，来源关闭或过期时回收；指针短暂离开时可在有界
宽限期内保留目标。修饰键、中键或键盘聚焦等明确意图立即开始准备，普通悬停短暂防抖，触屏移动
不触发推测准备。同一工作区内切换目标复用隐藏 renderer，以新代次撤销旧就绪状态并等待新目标；
点击领取另一个目标也可复用这条路径，不增加池大小、不复用其他工作区的内容。
显示前允许渲染和同步，但不得标记已读、领取工作区通知所有权、自动聚焦，或因打开操作刷新
外部历史。来源视图保持原样。匹配领取直接显示现有 renderer，不重新导航；实际显示后才激活
上述副作用。就绪状态须匹配目标、发送方和准备代次，内容或视口失效时撤销。
未命中或过早点击仍需等待尚未完成的准备，不保证所有打开操作瞬时完成。
其他平台保持中性外壳预热。

领取后的预热窗口保持原生隐藏，直到目标内容完成绘制：对话历史已实际加载（空会话须同步完成）、
工作区首页挂载，或该会话的元数据投影处理完毕并确认缺失。无关文档的失败不得阻止该判定。
非空会话还须等待虚拟列表加载与初始滚动位置恢复，CSS 隐藏的正文不能授权显示。
Loading、侧栏文字及仅已知历史数量均不能作为就绪信号。不使用不透明 renderer 遮罩。
主进程在五秒后仍未收到就绪信号时显示恢复界面；这不代表加载完成，也不保证瞬间打开。
隐藏准备阶段暂时关闭后台节流，显示时恢复原策略；显示之后才创建替补窗口。
分别测量点击到显示耗时和首个可见帧是否包含内容。
领取后的窗口遵循普通产品窗口的生命周期，其他窗口关闭时仍保持打开。崩溃恢复须重载
绑定目标，不得回到中性预热路由；关闭已领取窗口不得取消替补窗口的超时。

Composer 草稿归属工作区并持久化：不同工作区必须隔离，工作区窗口之间不按打开来源区分主辅。
同一工作区内的所有 Chat Landing 入口复用同一份 Composer 草稿；“新建对话”只切换目标项目，
不得清空或覆盖已有输入。只有首条消息成功写入 Session 后才清空这份草稿。
关闭其他工作区窗口不停止 CLI 或 Agent；关闭菜单和快捷键操作当前窗口。
Cmd/Ctrl+W 在对话区有多个标签时关闭当前标签，只剩一个标签（包括草稿）时关闭当前窗口，
不更改会话的共享关闭状态。侧面板有焦点时优先关闭其当前标签；显式点击标签 × 仍关闭标签。
主窗口和新开的会话窗口遵循相同规则，保留各窗口已有的原生关闭/隐藏行为。
应用内快捷键配置按设备共享，任一窗口修改后对所有已打开窗口生效；快捷键执行仍只作用于接收按键的窗口。
原始窗口保留已有的关闭/托盘行为；不自动恢复其他工作区窗口。

完整宽度的桌面布局中，隐藏侧栏保留已挂载的视图和滚动位置，但暂停侧栏驱动的会话预取；
重新打开不会重挂载列表。会话窗口将初始隐藏的侧栏延后到首次展开时挂载，此后遵循同一保留规则。侧栏与相邻的主内容区会同步在展开、收起宽度间过渡，除非用户要求减少动态效果。
紧凑布局和进入设置页仍可能卸载侧栏，返回时按工作区恢复滚动位置。
当前对话和 Tasks 页所需数据继续同步。
同一工作区只有一个窗口执行通知、角标和后台状态检查，退出后自动交接。
清缓存和登出属于应用级操作，会关闭其他窗口以释放连接。

Dock 角标是当前用户拥有的、未归档侧栏会话行中，有未读输出或有效权限请求的绝对数量，
包含其子对话。每行最多计一次，权限等待优先于未读；已关闭对话按
[标签关闭契约](session-tab-closure.zh.md)抑制未读。
持有工作区所有权的 renderer 在数量变化时立即上报，每 30 秒及窗口恢复焦点／可见时
重发完整快照，包括零值。后台计时器节流或系统休眠可能推迟定时间隔。
主进程替换各窗口的贡献值，并在 renderer 崩溃、文档导航或窗口关闭时移除旧贡献；
周期纠偏不得重复触发权限等待的 Dock 跳动。

工作区开窗使用现有平台提供的目录；公开桌面端仍是单一本地工作区。
共享 UI 的多工作区入口不得通过全局账户选择改变其他窗口的目标。

需求：[Issue #526](https://github.com/LodyAI/Lody/issues/526)。
