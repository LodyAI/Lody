# 静态对话分享

Status: draft
Translation: current

[English](session-sharing.md)

工作区写成员将选定对话及相关对话发布为独立可读副本，原内容的后续修改不会改变副本。
“更新部署”冻结新副本并原子替换当前部署，完整分享链接保持不变；失败或竞争部署不得破坏当前版本。

## 发布边界

可读取内容的客户端先加载全部选定对话，再同步分离其已保存历史，之后才进行附件 I/O。
历史保留现有 JSON，包括思考、工具输入输出、系统消息及未知内容字段。
冻结时省略实时 terminal 句柄、工具权限请求、已读/用户/运行轮次标识、fileDiff 管理数据，
以及发送、恢复和 Role 配置；保留 `inputConfig.inputBlocks` 中的历史附件、消息 `role` 和可见署名。
终端只保留命令，完整省略类型明确的终端输出块（包括退出状态）。
工具标题与第一条终端命令完全相同时，在传输格式中省略标题，读取时从该命令恢复；其他标题不变。
不按启发式规则改写不透明工具数据。不导出 Loro 操作历史，
也不导出外围文档的运行配置、排队消息、agent session 或工作区凭据。
历史本身可能含敏感文本：发布是主动披露，不是自动脱敏。

任务提议是例外：冻结时在附件读取前移除完整提议显示块及元数据，读取器拒绝未清理的提议。
子 Agent 执行记录和不透明工具输出、文本保持不变，但冻结时会将已知
`#access=v1.<64 位小写十六进制>` 凭据片段替换为 `#access=omitted`，包括工具输出中的片段。
原会话历史和返回给 agent 的完整 URL 不受影响。这防止后续分享再次发布旧分享凭据，
不是通用敏感信息检测。

版本化 manifest 描述对话、关系、不可变历史对象及复制附件。
`SESSION_SHARE_FILE_ATTACHMENTS_ENABLED` 默认关闭：读取附件前，将类型明确的 `file` 块
替换为本地化普通文本通知，同时省略这些块中的文件名、源 ID 和路径；仅复制图片及图片组。
发布端独立拒绝文件清单，不依赖客户端开关。这不是对不透明工具数据或文本的脱敏，
也不改变已经发布的版本。重新开放后，补齐此前省略的文件需要重新部署；未来付费权限不在此改动范围。
每个对象具有精确 ID、字节长度和 SHA-256 校验和。分享不授予源工作区、继承附件命名空间、
原 Stream 或 agent runtime 的权限。不可用附件必须阻止冻结或明确披露，不得静默回源。

工作区 Stream 加密属于未来独立功能：发布客户端解密后仍生成明文分享包。
分享 bearer 是访问凭据，不是解密钥匙；本版不包含分享 E2EE、加密封装或密钥托管。

格式第 2 版可在体积变小时逐份使用 Zstd 保存 history。manifest 绑定压缩字节的长度和哈希，
明确记录 `contentEncoding: zstd` 和 `decodedSizeBytes`；仍可读取第 1 版及未压缩对象。
解码前限制帧窗口和解压后长度，拒绝额外帧，并执行解压字节上限。图片不再压缩。
浏览器先验证压缩字节再解码；Agent 历史链接继续返回普通 JSON。

## 权限与管理

工作区写成员可用经认证的发布者身份发布自己可读的内容。发布者可更新、重置和撤销自己的分享。
管理员和所有者可查看工作区分享清单、撤销其他人的分享，但不能获取其链接密钥或接管发布。
源元信息不是作者身份凭证。

对话头部在后果所在之处说明发布状态：一个控件同时承载团队可见性与已发布链接，
只要存在以该对话为根的有效分享，无论它是否私密，都显示为已共享。它只反映那一个分享，
因此被发布在他人分享之内的对话仍显示为未共享；在控制面作答之前，它也不会声称「未共享」。
发布仍然只能从编辑器发起。

设置中的分享管理仅列出成功发布的分享，不显示未完成上传。普通成员看自己的分享，管理员看工作区清单。
列表分页，显示标题、状态、对话数和最近更新时间。删除源内容不删除副本或管理记录；
更新仍需源内容可读，重置和撤销不需要。

删除源内容后分享仍可读；移除发布者成员身份、删除账号或工作区会禁用访问。
重新加入不复活旧分享，重置不重新绑定所有权或成员身份。

链接为 `/s/<shareId>#access=v1.<secret>`，使用随机 32 字节 bearer。
控制面保存哈希；经用户批准的 MCP 交付还可保存面向接收方加密的密文，绝不接收原始凭据。
原始凭据仅通过 Authorization 请求头发送给分享 API，并在请求方本地解密后交给 agent。
更新保留链接，重置轮换凭据，撤销禁用全部部署；这些操作均无法收回已经下载的字节。

## 部署一致性

上传前必须冻结完整包，只有认证应用中的人类操作可以发起发布，不提供发布预览：用户确认范围后，才开始冻结并上传。
上传权限只覆盖一个不可变清单，不能执行发布；认证应用只能提交已封存的部署。
发布检查预期分享版本，begin 重试绑定完整请求身份，包括凭据和确认请求，不得静默接受参数变化。

文档获取、图片复制、历史编码和对象上传采用有限并发；完成顺序不得改变对话和附件 ID。
失败时停止新任务、取消同批 I/O，并等待已启动任务结束后才释放源租约。
全部对象完成后才能封存，不发布半成品。导出和上传仍分阶段，因为上传准入绑定完整不可变清单；
逐对话流式准入和 multipart 分片上传不属于本版。

新链接使用 begin 响应的分享 ID 和凭据版本，在上传前可靠保存并读回验证读者凭据，提交前再次验证。
存储失败则停止发布，保留同一部署供重试。最终提交期间关闭窗口不会丢失凭据，
重新打开时查询服务端状态并恢复链接；上传密钥不持久化。

访客仅解析一次当前部署，之后全部历史和附件固定读取该版本。退役部署有有限宽限期，
不得混读不同版本；重置和撤销优先于宽限期。对话身份映射在移除和旧对象清理后仍保留，
旧子对话链接不得指向另一段对话。

对象存储私有，无公开桶 URL。每次对象读取均需授权，HTTP 响应 no-store 且有有限生命周期。
旧部署和放弃的上传须通过计入配额、带执行隔离保护的垃圾回收清理。

## 访客与 agent 交互

分享页不提供登录入口，匿名访问也不显示。仅当宿主提供已确认的访客身份时，
页头才显示该身份；否则身份区域为空。

分享页保留应用所需布局：独立子对话在左侧树中，子 Tab 在主区域标签栏。
不设右侧面板，因此 side-panel 子对话也作为普通 Tab 展示，不能隐藏已发布内容。
关系来自 manifest，不依赖历史中的隐藏引用；导航不能扩大 manifest 范围。
访客已经打开过的对话再次进入时不重新拉取：已完成的固定部署读取在页面生命周期内
保留在内存中，分享的任何部分都不会写入持久化存储。

Markdown 仅在请求时使用现有对话复制构建器、范围选择、预算规则和结果提示生成。
它是可读导出，不是所有工具字段的无损序列化；新增导出元信息不包含原工作区或 agent 标识。

MCP 只能请求发布，不能批准发布。认证应用的卡片展示 agent 的用途、准确会话集合和内容披露，
并明确告知：**完整访问链接会交给请求方 agent，agent 可以使用或转发**。
用户在卡片上批准一次即开始冻结、上传和发布，无需第二个对话框或手动复制。
工具标志和历史文本不等于批准。每次请求创建独立分享，不更新或重置旧链接；
换设备批准也遵循同一规则。设置管理所有链接，标题栏优先显示最近的有效分享而非未完成草稿。

MCP 交付仅允许同一账号：CLI 凭据持有人、当前 Turn 的人类请求者和实际批准者必须是同一用户。
即使双方都是工作区写成员，服务端也拒绝跨账号请求；CLI 不得用机器所有者替换当前用户。
同一账号仍可在其他设备批准。在他人账号登录的机器上运行的 Turn，应改为在应用中手动分享，
或使用登录本人账号的机器。已有跨账号请求也不能批准、恢复、发布或领取。
这验证的是接收方账号，不是对 Session/Turn 来源的独立证明；跨账号委托需要另行设计可验证的同意契约。

请求方 CLI 在提交意图前持久保存接收私钥。应用使用请求公钥加密读取凭据，并绑定请求记录和分享域名。
Begin 将密文与不可变部署绑定；发布完成后，控制面才向原始提交方的请求会话返回密文，
并重新校验双方的原始成员身份。CLI 本地解密并返回完整 URL。
结果信箱不传输明文凭据、私钥、源内容或批准信号。

工具回显 `requestId`；`shareRequestId` 是独立的服务端记录身份。重试保持用途、目标集合和接收公钥，
同一授权会话中的后续轮次可继续领取。每次调用只等待有限时间，必要时返回 pending/confirmed；
agent 使用相同参数继续调用，无需用户再次点击。取消和过期是终态。
批准后上传窗口重置为 24 小时；成功发布后开始 24 小时的结果领取窗口。
发布回执在初始部署退役及垃圾回收后仍然有效；重置凭据、撤销或成员资格丧失会禁止领取。
接收私钥可跨 MCP 进程重启恢复，丢失后不能由服务端找回。
上传凭据仍仅临时存在于客户端；发布前关闭需要放弃未完成部署并重新请求。
失败保留卡片以供重试或放弃；没有交付同意信息的旧意图直接过期。
查询失败仅影响卡片，不能连带摧毁对话。

首版不支持 fork。未来可将可展示历史和附件导入访客工作区，新的 agent 在全新上下文中接收 Markdown，
而非恢复源 agent 线程或运行会话。

访客可在 Markdown 复制旁点击 **复制 Agent Prompt**，显式获取固定到当前部署和选中对话的短期只读链接。
Prompt 跟随访客当前 i18n 语言。索引包含现有对话关系、历史和图片地址；接收者只需 HTTP 能力，
无需 Lody 账号或 MCP，不发生工作区导入或 agent 调度。接收者可保存下载内容；
可见提示必须说明 Prompt 授予分享对话和图片的访问权。

Agent 访问最多 24 小时，且不超过版本可读期或分享撤销/重置时间；不能自续期、发布、上传或读取源资源。
资源 API 仍排除文件。宿主须按 IP 和分享限流签发及读取，不记录能力 URL，响应 private/no-store。
这是突发流量防护，不是计费配额。剪贴板拒绝时展示 Prompt 供手动复制；仅从已发布的部署签发访问链接。

## 实现状态与证据

当前仍是未发布、未完全验收的破坏性切换。可移植包、导出器、客户端及管理界面已在本地实现。
匿名读取器固定部署，不订阅 Loro，展示 opened-by 树、子 Tab 和侧对话；Markdown 按需生成，
应用和访客共享省略提示。原始远程图片不加载；类型明确的附件使用 manifest，未映射资源引用无下载权限。
MCP 经可空 cloud port 提交意图，应用显示规范请求并在最终确认时锁定选择集合；未完成部署可见且可放弃。
类型明确的资源会复制，任意 Markdown/ACP URI 保留为文本，确认前披露，绝不用工作区权限读取。
生产构建浏览器检查覆盖布局、固定版本、凭据变化、撤销和惰性媒体；服务集成独立验证，
此处不声称完成托管部署或原生设备验收。

对话头部以只读方式读取同一条管理记录来说明发布状态；该读取受能力开关约束，
本地构建不会发出这个请求。
