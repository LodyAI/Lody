# site-docs/public

`CLAUDE.md` is a symlink to this file. Edit `AGENTS.md` only.
Root `AGENTS.md` and `site-docs/AGENTS.md` also apply.

- Document images under `_docs-assets/` are tracked source files. Reference them as
  URLs, `<img src="/_docs-assets/name.png" />`, never with Markdown image syntax.
- The empty files in `.well-known/` deliberately revoke previously published
  iOS/Android app-link associations. Keep Android associations empty; the recovery
  `webcredentials` exception below permits no universal-link handling.
- `robots.txt` is owned here; the App build must not overwrite public-site SEO files.
- `sitemap.xml`, `docs-search.json`, `llms.txt`, `llms-full.txt`, `rss.xml`, and
  `rss-zh.xml` are generated by `site-docs/scripts/*` and ignored. Do not edit or
  format them by hand.
- Unmatched URLs must not SPA-fallback to the homepage: `/404` prerenders to
  `out/client/404.html`, which Cloudflare Pages serves with HTTP 404.

## Recovery passkey association exception

Owner's 2026-11-10 Web recovery direction permits
`public/.well-known/apple-app-site-association` (relative to `site-docs`) to contain
only `webcredentials.apps` for the reviewed native app identifiers. This is a
passkey-only exception to empty association revocations. Never add `applinks`,
`appclips`, universal-link handlers or Android website VIEW filters. Keep
`.well-known/assetlinks.json` as the empty array. Ordinary HTTPS links still open
in the browser; this exception grants no app-link navigation.
