오늘, 개발자가 팀과 함께 어디서나 병렬로 AI 코딩 에이전트를 실행할 수 있도록 설계된 새로운 플랫폼 Lody의 출시를 발표하게 되어 기쁩니다.

## 문제점

AI 코딩 어시스턴트가 점점 강력해지면서 개발자들은 새로운 문제에 직면하고 있습니다:

- **컨텍스트 충돌** — 동일한 코드베이스에서 여러 에이전트를 실행하면 충돌과 혼란이 발생합니다.
- **가시성 부족** — 에이전트가 실시간으로 어떤 변경 사항을 만들고 있는지 추적하기 어렵습니다.
- **데스크톱 종속** — 휴대폰에서 변경 사항을 리뷰하거나 승인할 수 없습니다.
- **단독 작업 중심 경험** — 팀원과 에이전트 컨텍스트를 공유하는 과정이 번거롭습니다.

## 해결 방안

Lody는 단순하지만 강력한 접근 방식으로 이러한 문제를 해결합니다:

### 워크트리 격리

모든 작업에는 독립적으로 격리된 git worktree가 할당됩니다. 즉, 각자 다른 기능이나 버그 수정을 담당하는 여러 에이전트를 충돌 없이 병렬로 실행할 수 있습니다.

```bash
npx lody start
```

시작하는 데 필요한 것은 이것뿐입니다. 워크트리 생성, 에이전트 오케스트레이션, 동기화는 모두 Lody가 자동으로 처리합니다.

### 실시간 동기화

모든 수정 사항이 반영되는 즉시 확인할 수 있습니다. 각 에이전트 응답에는 인컨텍스트(in-context) diff가 포함되어 있어 IDE로 돌아가지 않고도 변경 사항을 리뷰할 수 있습니다. 파일 트리도 실시간으로 동기화되므로 현재 진행 상황을 한눈에 파악할 수 있습니다.

### 모바일 퍼스트

Lody는 모바일 환경에 맞춰 제작된 네이티브 iOS 및 Android 앱을 제공합니다. 작업이 완료되면 푸시 알림을 받고, 휴대폰에서 diff를 리뷰하며, 어디서나 변경 사항을 승인할 수 있습니다. 책상을 떠난다고 해서 바이브 코딩을 멈출 필요는 없습니다.

### 팀 워크스페이스

에이전트, 스킬, 대화 컨텍스트를 팀과 공유하세요. 모두가 동일한 맥락을 유지할 수 있으며, 지식이 조직 전체에 축적됩니다.

## 앞으로의 계획

이제 막 시작했을 뿐입니다. 앞으로의 로드맵은 다음과 같습니다:

- **더 많은 에이전트 지원** — Claude Code, Codex, Gemini CLI 외에도 더 다양한 AI 코딩 에이전트 지원을 추가하고 있습니다.
- **커스텀 스킬** — 에이전트가 학습하고 적용할 수 있는 재사용 가능한 스킬을 정의할 수 있습니다.
- **CI/CD 통합** — Lody를 기존 워크플로에 연결할 수 있습니다.
