Lody가 최근 GitHub에서 스타 1,000개를 달성했습니다. 스타를 눌러주신 모든 분께 감사드립니다!

이정표에 걸맞은 기념 영상이 필요했고, 이번 영상은 모든 프레임과 사운드를 코드로 렌더링해 완성했습니다. 어떻게 만들었는지, 그 과정에 담긴 고민을 함께 공유하고자 합니다.

## 왜 코드로 영상을 만들었을까요

영상의 모든 프레임을 특정 시점에 렌더링되는 React 컴포넌트로 다룰 수 있기 때문에 [Remotion](https://remotion.dev)을 사용했습니다. 덕분에 영상 제작에서도 버전 관리, 파라미터화, 컴포넌트 재사용, 그리고 60fps 기준의 프레임 단위 정밀 제어라는 코드의 장점을 모두 누릴 수 있습니다.

카메라 움직임이 어색하다면 숫자 하나만 바꾸고 다시 렌더링하면 됩니다. 타임라인에서 요소를 끌어다 맞추느라 30분을 더 쓰는 대신, 수십 초 만에 새로운 컷을 얻을 수 있습니다. 또한 AI 친화적이기도 합니다. AI가 React 컴포넌트를 직접 생성하거나, React가 렌더링할 JSON 데이터를 출력할 수 있기 때문입니다.

전체 영상의 구조는 단순합니다.

<img src="/_docs-assets/1k-video/timeline.png" alt="영상 구조 타임라인" />

처음 7초는 GitHub 저장소 페이지를 가로지르는 3D 카메라 무빙입니다. 카메라가 안쪽으로 파고들고, 커서가 Star 버튼을 클릭하며, 카운터가 1,000까지 올라갑니다. 마지막 6초는 Lody만의 수채화 세계로 착지합니다.

제작 과정에서 가장 흥미로웠던 엔지니어링 이야기를 소개합니다.

## 1. 스크린샷 대신 GitHub 페이지 다시 그리기

처음부터 실제 스크린샷은 쓰지 말아야겠다고 생각했습니다.

카메라가 피사체로 파고드는 구도에서는 비트맵 해상도에 한계가 있습니다. AI에게 페이지 스크린샷을 찍어달라고 하면 확대하는 순간 모든 것이 뭉개지는 엣지 케이스에 부딪히기 마련입니다. 게다가 스크린샷 안의 요소는 움직일 수 없습니다.

그래서 탭 바, 버튼, 파일 목록, About 사이드바까지 페이지 전체를 DOM으로 다시 그렸고, 아이콘은 GitHub의 공식 octicons를 가져다 썼습니다.

직접 다시 그리면 보너스도 생깁니다. 각 요소가 직접 연기할 수 있다는 점입니다. 오프닝에서는 페이지의 각 섹션이 위에서 떨어져 약간의 오버슈트(overshoot)와 함께 제자리에 "도킹(dock)"하며, 마치 인터페이스가 눈앞에서 스스로 조립되는 듯한 느낌을 줍니다.

이 움직임의 핵심은 10줄도 안 되는 함수입니다.

```tsx
const dock = (delay: number): React.CSSProperties => {
  const s = spring({frame: frame - delay, fps, config: {damping: 14, mass: 0.9, stiffness: 160}});
  return {
    opacity: interpolate(s, [0, 0.45], [0, 1], {extrapolateRight: 'clamp'}),
    transform: `translateY(${interpolate(s, [0, 1], [-80, 0])}px)`,
  };
};
```

각 섹션에 `...dock(n)`을 전개하고, 위에서 아래로 `n` 값을 몇 프레임씩 시차를 두고 적용하면 페이지가 살아 숨 쉬듯 움직입니다.

커서가 Star 버튼을 클릭하는 장면에서는, 버튼이 3D 공간에서 기울어져 있기 때문에 페이지 좌표를 동일한 회전-투영(rotation-projection) 행렬에 통과시켜 화면 좌표를 역산했습니다. 덕분에 커서는 언제나 정확히 버튼의 정중앙에 착지합니다.

## 2. 카메라 같은 느낌 만들기

"카메라로 촬영한 영상"과 "움직이는 파워포인트"의 차이는 대부분 피사계 심도(depth of field)와 움직임의 연속성에서 옵니다.

피사계 심도를 구현하는 가장 단순한 방법은 전체를 크게 흐리게(blur) 처리하고 선명한 창 하나를 뚫는 것이지만, 그렇게 하면 경계가 딱딱하게 남습니다. 그래서 세 겹의 플레이트를 쌓았습니다. 맨 아래에는 강하게 흐린 전체 화면 플레이트, 중간에는 경계가 넓게 페더링(feathered)된 약한 블러 플레이트, 그리고 맨 위에는 초점면 근처에만 남는 선명한 코어 플레이트를 배치했습니다. 세 레이어 모두 넓고 부드러운 마스크를 사용해 초점에서 벗어난 거리에 따라 흐림 정도가 서서히 감소하도록 했습니다.

<img src="/_docs-assets/1k-video/dof.png" alt="세 개의 피사계 심도 플레이트" />

> 엄밀히 말하면 점진적인 피사계 심도는 광학적 결과물이므로 단순한 선형 그라데이션이 아니라 합성곱 커널(convolution kernel)이어야 합니다. 하지만 소셜 미디어 영상의 해상도와 비트레이트를 고려하면 단순한 그라데이션만으로도 충분합니다.

연속성 측면에서는 카메라 이동이 끝난 뒤 페이지가 미세하게 "숨 쉬듯" 흔들리는 효과를 넣었습니다. 첫 번째 버전에서는 카메라가 멈춘 정확한 프레임에 이 흔들림을 시작했는데, 그 시점에 사인(sine) 값이 0이 아니었기 때문에 마치 프레임이 드롭된 것처럼 겨우 느껴질 정도의 작은 "덜컹거림"이 발생했습니다.

해결 방법은 사인 파형이 영점 교차(zero crossing) 지점에서 시작하도록 맞추고, 페이드 인/페이드 아웃 엔벨로프를 곱하는 것이었습니다.

```tsx
const breathe =
  Math.sin((frame - 92) / 55) * 0.9 *
  interpolate(frame, [92, 122, 266, 296], [0, 1, 1, 0], {
    extrapolateLeft: 'clamp',
    extrapolateRight: 'clamp',
  });
```

덕분에 흔들림이 고요함 속에서 자연스럽게 커졌다가 카메라가 뒤로 빠지기 전에 조용히 잦아듭니다.

## 3. 사운드 역시 코드로 렌더링

배경 음악도 아무 스톡 트랙이나 깔아 둔 것이 아닙니다. 로열티 프리 음원을 베이스로 사용했는데, 선택한 트랙이 A 메이저(가장조)였기 때문에 모든 효과음 역시 A 메이저 음계 안에서 코드로 합성했습니다. 카운트가 올라갈 때 깔리는 라이저(riser)는 펜타토닉 스케일을 타고 올라가고, 1,000을 달성하는 순간에는 A 메이저 벨이 울리며, 콘페티(confetti)가 반짝이는 소리는 같은 조성의 하프 배음(partials)으로 만들었습니다.
