Сегодня мы рады объявить о запуске Lody — новой платформы, созданной для того, чтобы разработчики могли запускать ИИ-агентов для разработки откуда угодно, параллельно и вместе со своей командой.

## Проблема

По мере того как ИИ-ассистенты для разработки становятся мощнее, разработчики сталкиваются с новыми сложностями:

- **Конфликты контекста** — запуск нескольких агентов в одной и той же кодовой базе приводит к конфликтам и путанице.
- **Отсутствие прозрачности** — сложно отслеживать, какие изменения агенты вносят в реальном времени.
- **Привязка к компьютеру** — вы не можете просматривать или подтверждать изменения с телефона.
- **Одиночная работа** — делиться контекстом работы агента с коллегами неудобно.

## Наше решение

Lody решает эти задачи с помощью простого, но эффективного подхода:

### Изоляция через worktree

Каждая задача получает собственный изолированный git worktree. Это значит, что вы можете запускать несколько агентов параллельно — каждый будет работать над отдельной функцией или исправлением ошибки — без каких-либо конфликтов.

```bash
npx lody start
```

Это всё, что нужно для старта. Lody автоматически берёт на себя создание worktree, оркестрацию агентов и синхронизацию.

### Синхронизация в реальном времени

Наблюдайте за каждой правкой прямо в процессе работы. Каждый ответ агента включает контекстный diff, поэтому вы можете проверять изменения, не переключаясь обратно в IDE. Дерево файлов синхронизируется в реальном времени, давая вам полную картину происходящего.

### Мобильный доступ в приоритете

В Lody доступны нативные приложения для iOS и Android, созданные специально для мобильных устройств. Получайте push-уведомления о завершении задач, просматривайте diff с телефона и подтверждайте изменения откуда угодно. Вайб-кодингу не обязательно останавливаться, когда вы отходите от рабочего стола.

### Командные рабочие пространства

Делитесь агентами, навыками и контекстом диалогов со своей командой. Все остаются в курсе происходящего, а знания накапливаются во всей организации.
