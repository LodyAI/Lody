Lodyは、コーディングエージェントのためのコラボレーションワークスペースです。チームメンバー、エージェント、マシンごとに散在している会話、ランタイム状態、コード変更を1つのスペースに集約します。チームメンバーはお互いの会話を開いて、その続きから議論を進めることができます。また、ブラウザーやスマートフォンからオンラインのマシン上でタスクを開始し、実行中に指示を追加することもできます。

LodyのCLIとローカルデスクトップクライアントをオープンソースとして公開しました。ソースコードは [github.com/lodyai/lody](https://github.com/lodyai/lody) でご覧いただけます。

しかし、私たちが解決したい課題はそれだけにとどまりません。

ソフトウェアシステムの複雑さは、コードの中だけに存在するわけではありません。あるコード片の背景には、ビジネスルールや本番環境での障害対応、重要な顧客のための互換性要件、あるいは現在ではすでに解消された技術的制約などがあるかもしれません。プロジェクトが進化するにつれて、こうした意思決定が何層にも積み重なり、現在のシステムを形作っていきます。コードは結果を残しますが、それを生み出した理由まで常に残してくれるわけではありません。

そうした理由は、設計ドキュメント、プルリクエスト、Issue、ミーティング、エージェントとの会話、そしてチームメンバーの記憶の中に散らばっています。誰かがモジュールを引き継いだり、変更をレビューしたり、リファクタリングを準備したりするとき、難しいのは単にコードを読むことではない場合が多いのです。その背後にあるビジネスルール、ドメイン概念、設計上のトレードオフ、そして過去の意思決定を再構築することこそが難しいのです。

私たちはLodyを、ソフトウェアチームとコーディングエージェントのための共有理解レイヤーにしたいと考えています。会話、コード、タスク、ドキュメント、過去の意思決定を結びつけることで、なぜシステムが現在の姿になったのかをたどり、新しい変更がどの既存制約に影響を与えうるかをチームが判断できるようにするためです。

会話は、プロジェクトを理解するための出発点にすぎません。Lodyは、その理解を中心にタスク管理、ドキュメント、コードレビューの機能を展開していきます。将来的には、ユーザーがチームに合ったツールを定義し、それらのツールからのデータを他のプロジェクトコンテキストと結びつけて、チーム全体で同期し続けられるプラグインの仕組みも探求していきたいと考えています。

## Lodyの同期の仕組み

Lodyは、Loro Stack上に構築されたローカルファーストの同期エンジンを使用しています。コラボレーション状態の大部分は [Loro](https://loro.dev/) と [Flock](https://www.npmjs.com/package/@loro-dev/flock-wasm) で表現され、Loro Streamsを通じてデバイス間で同期されます。LoroとFlockはCRDTをベースにしており、各レプリカが独立して変更を加え、再接続後にマージできるようになっています。

私たちがCRDTを選んだ最大の理由は、プロジェクトコンテキストを[ローカルファースト](https://www.inkandswitch.com/essay/local-first/)にしたいからです。各デバイスが直接利用できるローカルコピーを保持し、ネットワークが復旧した後に変更を同期します。

アプリケーションは置き換わっていくものですが、データはアプリケーションよりも長く生き続けるべきです。エージェントやツールはこれからも変化し続けますが、チームが蓄積してきたプロジェクトコンテキストがそれらと一緒に失われてはなりません。オープンなデータフォーマットと実装を採用することは、そのコンテキストが単一のアプリケーションに閉じ込められてしまうリスクを減らすことにもつながります。

また、Loroの汎用的なデータ構造は、コメント、リッチテキストドキュメント、ホワイトボードなどのツールで必要とされるコラボレーション状態も表現できます。これにより、同じ同期エンジンでさまざまな形式のインタラクションをサポートできる可能性が開け、将来のコミュニティプラグインに向けた共通のデータ基盤を提供できます。

Lodyはまだエンドツーエンド暗号化に対応しておらず、デバイス間のコラボレーションは依然としてLodyのホステッド同期サービスに依存しています。現在、エンドツーエンド暗号化ワークスペースの初期設計を完了したところです。

私たちが目指しているのは、チームとエージェントが蓄積したプロジェクトコンテキストが、最終的にチーム自身の管理下に置かれ続けるようにすることです。
