本日、Lody のリリースをお知らせできることを嬉しく思います。Lody は、開発者がどこからでも、並列に、そしてチームと一緒に AI コーディングエージェントを実行できるように設計された新しいプラットフォームです。

## 課題

AI コーディングアシスタントがより強力になるにつれて、開発者は新たな課題に直面しています。

- **コンテキストの衝突** — 同じコードベース上で複数のエージェントを実行すると、コンフリクトや混乱が生じます。
- **可視性の欠如** — エージェントがどのような変更を行っているかをリアルタイムで把握することが困難です。
- **デスクトップへの制約** — スマートフォンから変更内容をレビューしたり承認したりすることができません。
- **個人完結の体験** — エージェントのコンテキストをチームメンバーと共有するのに手間がかかります。

## 私たちの解決策

Lody は、シンプルでありながら強力なアプローチでこれらの課題を解決します。

### Worktree による分離

すべてのタスクには、それぞれ独立した git worktree が割り当てられます。これにより、異なる機能開発やバグ修正を担当する複数のエージェントを、衝突を気にせず並列に実行できます。

```bash
npx lody start
```

これだけで使い始めることができます。worktree の作成、エージェントのオーケストレーション、同期はすべて Lody が自動的に処理します。

### リアルタイム同期

すべての編集内容をその場で確認できます。エージェントの応答にはコンテキスト内の差分（diff）が含まれるため、IDE に戻らなくても変更内容をレビューできます。ファイルツリーもリアルタイムで同期されるため、何が起きているかを常に完全に把握できます。

### モバイルファースト

Lody はモバイル向けに設計されたネイティブの iOS および Android アプリを提供しています。タスクが完了するとプッシュ通知が届き、スマートフォン上で差分をレビューして、どこからでも変更を承認できます。デスクを離れても、バイブコーディングを止める必要はありません。

### チームワークスペース

エージェント、スキル、会話のコンテキストをチームで共有できます。全員が同じ認識を保ちながら、組織全体で知見を蓄積していくことができます。

## 今後の展望

これはまだ始まりにすぎません。今後のロードマップの一部をご紹介します。

- **対応エージェントの拡充** — Claude Code、Codex、Gemini CLI に加えて、さらに多くの AI コーディングエージェントへの対応を進めています。
- **カスタムスキル** — エージェントが学習して適用できる、再利用可能なスキルを定義できるようにします。
- **CI/CD 連携** — Lody を既存のワークフローに接続できるようにします。
