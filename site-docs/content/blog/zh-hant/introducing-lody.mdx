今天我們非常高興宣布 Lody 正式推出 — 這是一個全新平台，專為協助開發者隨時隨地、平行且與團隊協作執行 AI 程式開發代理而打造。

## 問題所在

隨著 AI 程式開發助手變得越來越強大，開發者也面臨了新的挑戰：

- **上下文衝突** — 在同一個程式碼庫上執行多個代理，容易導致衝突與混亂。
- **缺乏可視性** — 難以即時追蹤代理正在進行哪些變更。
- **受限於桌面端** — 無法直接從手機檢視或核准變更。
- **單兵作戰體驗** — 與團隊成員分享代理的上下文相當繁瑣。

## 我們的解決方案

Lody 以簡潔卻強大的方式解決這些挑戰：

### 工作樹隔離

每項任務都擁有各自獨立的 git 工作樹。這代表您可以平行執行多個代理 — 每個代理各自處理不同的功能或錯誤修復 — 而不會產生任何衝突。

```bash
npx lody start
```

這就是開始使用所需的全部步驟。Lody 會自動處理工作樹建立、代理編排與同步。

### 即時同步

即時掌握每一次編輯。每個代理的回覆都包含上下文內的差異對比，讓您無需切回 IDE 即可審查變更。檔案樹也會即時保持同步，讓您完全掌握目前的進展。

### 行動優先

Lody 提供專為行動裝置打造的原生 iOS 與 Android 應用程式。當任務完成時接收推播通知，在手機上審查差異，並隨時隨地核准變更。即使離開書桌，Vibe Coding 也不必中斷。

### 團隊工作區

與您的團隊分享代理、技能與對話上下文。讓每個人都保持資訊同步，並讓知識在整個組織中持續累積。

## 下一步

這只是剛開始。以下是我們的產品路線圖：

- **支援更多代理** — 除了 Claude Code、Codex 和 Gemini CLI 之外，我們正持續新增對更多 AI 程式開發代理的支援。
- **自訂技能** — 定義可重複使用的技能，讓代理能夠學習並套用。
- **CI/CD 整合** — 將 Lody 串接至您現有的工作流程。
