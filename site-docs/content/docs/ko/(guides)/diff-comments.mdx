# Diff 코멘트

Diff 코멘트를 사용하면 변경이 발생한 코드 위치에서 바로 리뷰할 수 있습니다. 팀 리뷰에 활용하거나, 특정 줄을 채팅으로 다시 보내 에이전트가 설명하거나 수정하고 다시 검토하도록 할 수 있습니다.

## 코멘트 추가하기

1. 현재 턴 또는 `Changes` 사이드바에서 세션 diff를 엽니다.
2. 코멘트를 남길 수 있는 줄 위에 마우스를 올리고 줄 번호 옆의 `+`를 클릭합니다.
3. 코멘트를 작성합니다. Markdown을 지원합니다.
4. **Comment**를 클릭하거나 `Ctrl+Enter` / `Cmd+Enter`를 누릅니다.

모바일에서는 코멘트를 남길 수 있는 diff 줄을 탭하면 코멘트 입력 상자가 열립니다.

## 답글 달기 및 해결 처리

코멘트는 diff 줄 아래에 스레드 형태로 표시됩니다. 다음과 같은 작업을 할 수 있습니다.

- 같은 스레드에 답글 달기
- 본인이 작성한 코멘트 수정 또는 삭제하기
- 스레드 논의가 끝나면 **Resolve** 클릭하기
- 다시 열려면 **Unresolve** 클릭하기
- 요약만 보고 싶을 때 스레드 접기

## 에이전트에게 스레드 보내기

코멘트 스레드의 전송 버튼을 사용하면 현재 채팅에서 해당 스레드를 참조할 수 있습니다. 그런 다음 에이전트에게 코멘트 반영, 트레이드오프 설명, 또는 요청한 수정 사항 적용을 요청하세요.

## GitHub와 동기화하기

세션이 GitHub PR에 연결되어 있는 경우 **Sync to GitHub**를 활성화하면 Lody에 새로 작성한 코멘트를 GitHub PR 리뷰 줄 단위 코멘트로 동기화할 수 있습니다.

Lody는 기존의 GitHub PR 리뷰 스레드도 diff로 불러옵니다. 코드 문맥 속에서 내용을 확인하고 Lody에서 바로 답글을 달 수 있으며, 작성한 답글은 GitHub에도 게시됩니다.
