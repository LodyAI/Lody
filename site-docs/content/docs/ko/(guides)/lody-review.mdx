# Lody Review

`lody review`는 구조화된 코드 리뷰를 하나의 독립된 HTML 리포트로 변환합니다. 로컬 Git 저장소에서 실행되며 Lody 계정이 필요하지 않고, 별도의 서버를 시작하지 않고도 `file://` URL로 결과를 바로 열 수 있습니다.

## 리뷰 생성하기

가장 간단한 워크플로는 코딩 에이전트에게 전체 과정을 실행하도록 요청하는 것입니다.

```text
Use `npx lody review` to help me review <pull-request-url>.
```

내부적으로 진행되는 단계는 다음과 같습니다.

1. 공식 리뷰 형식을 출력합니다.

   ```bash
   npx lody review prompt
   ```

2. 에이전트에게 대상 브랜치나 풀 리퀘스트를 검사하고 출력된 형식에 맞는 `.review.md` 파일을 작성하도록 요청합니다.
3. 리포트를 렌더링하고 엽니다.

   ```bash
   npx lody review <name>.review.md
   ```

기본적으로 생성된 `.review.html`은 시스템 임시 디렉터리 아래에 저장되므로 실수로 저장소에 포함되지 않습니다. CLI가 파일의 절대 경로를 출력하므로 나중에 다시 열거나 이동하거나 공유할 수 있습니다.

## 리포트 구성 내용

리포트는 관련 변경 사항을 그룹화하고, 파일 diff를 렌더링하며, 지적 사항을 해당 줄에 연결하고, 심각도 수준과 리뷰 체크리스트를 지원합니다. 또한 리포트를 읽으면서 코멘트를 추가하고 Markdown으로 복사할 수 있습니다.

## 요구 사항

- 리뷰할 Git 워킹 트리 내부에서 명령을 실행하거나 `--repo <dir>` 옵션을 전달하세요.
- 리뷰에서 참조하는 커밋이 로컬에 존재해야 합니다. 렌더링하기 전에 풀 리퀘스트 브랜치를 fetch하거나 체크아웃하세요.
- `.review.md` 파일은 로컬 저장소를 기준으로 읽기 전용 모드에서 해석됩니다.
- 이전에 내보낸 `.review.json`, `.review.json.gz` 또는 `.review.json.br` 스냅샷은 자체 완결형이므로 Git 없이도 렌더링할 수 있습니다.

최초 렌더링 시 일치하는 리뷰 뷰어를 다운로드할 수 있습니다. Lody는 이를 검증한 뒤 이후 사용을 위해 로컬에 캐시합니다.

## 옵션

```bash
npx lody review <file> --repo <dir>
npx lody review <file> --output <report.html>
npx lody review <file> --no-open
```

- `--repo`는 `.review.md`를 해석할 때 사용할 저장소를 선택합니다.
- `--output`은 생성되는 HTML 경로를 재정의합니다.
- `--no-open`은 브라우저를 열지 않고 리포트만 생성합니다.
