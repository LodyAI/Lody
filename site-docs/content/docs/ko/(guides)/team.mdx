# 팀 기능

Lody는 처음부터 팀 협업을 지원해 왔습니다. 에이전트 설정과 전체 대화 컨텍스트를 팀과 공유할 수
있습니다. 앞으로 공유 문서, 멤버 멘션, 작업 관리 등 더 많은 팀 기능이 추가될 예정입니다.

단순히 대화 기록만 읽는 것이 아니라 **기존 코딩 에이전트 세션에 팀원을 초대**해 동일한 대화,
diff, 워크트리(worktree)를 이어서 작업하게 하려면
[코딩 에이전트 세션 공유](/ko/docs/session-handoff)를 참고하세요. 공유 링크는 실시간 핸드오프가 아닌 기록용입니다:
[공유 링크 vs 실시간 핸드오프](/ko/docs/compare/share-link-vs-live-handoff).

격리된 워크트리, 다양한 모델 혼합, 팀에 공개되는 세션 등 여러 에이전트를 한꺼번에 실행하려면
[병렬 코딩 에이전트](/ko/docs/parallel-agents)를 참고하세요.

## 멤버 초대

**Settings** -> **Workspace** -> **General**로 이동한 다음, **Members** 섹션에서 **Invite Member**를 클릭합니다.
초대를 보내기 전에 멤버의 이메일을 입력하고 역할을 선택하세요.

초대하면 해당 멤버에게 이메일 초대장이 발송됩니다. 초대 링크를 복사해 직접 전달할 수도 있습니다.

## 멤버 권한 변경

워크스페이스 소유자와 관리자는 멤버 목록 오른쪽의 편집 작업에서 멤버의 권한을 변경할 수 있습니다.

## 멤버 제거

워크스페이스 소유자와 관리자는 멤버 목록 오른쪽의 제거 작업을 사용해 멤버를 제거할 수 있습니다.

## 다른 멤버의 세션 보기

홈 페이지에서 사이드바 필터를 사용해 **My Tasks**와 **All Tasks**(모바일에서는 **Team Tasks**) 사이를 전환할 수 있습니다.
목록은 기본적으로 **All Tasks**로 설정되어 있습니다. 아바타를 통해 누가 각 세션을 시작했는지 확인할 수 있습니다.

## 멤버별 토큰 사용량

**Settings** -> **AI Usage**에서 전체 AI 토큰 사용량과 추이 차트를 확인할 수 있습니다.
**By member**를 사용해 멤버별 사용량 내역을 살펴보세요.

## 팀 머신 가시성

등록한 모든 머신은 **기본적으로 비공개**입니다. 다른 사람의 워크스페이스에 참여하더라도 본인의 개발
머신은 노출되지 않으며, 다른 멤버가 자신의 머신 목록에서 보거나 해당 머신에서 세션을 시작할 수 없습니다.

공유 빌드 서버나 클라우드 워커처럼 팀원이 특정 머신에 접근하도록 하려면 워크스페이스에 명시적으로
공유할 수 있습니다.

### 머신 공유하기

1. **Settings** -> **Machines**로 이동합니다.
2. **My Machines** 아래에서 머신을 찾습니다.
3. **Share machine** 토글을 켭니다.

그러면 다른 멤버에게 해당 머신이 **Team Machines** 아래에 표시되며, 세션을 생성할 때 이를 선택할 수
있습니다. 토글은 언제든 다시 끌 수 있습니다. 공유를 해제하면 다른 멤버의 머신 목록에서 해당 머신이
사라지고, 세션 사이드바에서도 해당 머신에서 실행 중인 대화를 더 이상 수신하지 않습니다.

머신의 공유 상태는 머신 소유자만 변경할 수 있습니다.

### "공유됨"의 의미

- **목록 표시**: 공유된 머신은 모든 멤버의 머신 설정 내 `Team Machines` 섹션에 표시됩니다. 공유되지 않은
  머신은 소유자의 `My Machines` 아래에만 유지됩니다.
- **세션 접근 가능성**: 세션은 생성자가 접근 권한을 가진 머신(본인의 머신 및 현재 공유된 팀 머신)에서만
  생성할 수 있습니다.
- **대화 사이드바**: 공유되지 않은 머신에서 실행 중인 세션은 다른 멤버의 사이드바로 동기화되지 않습니다.

워크스페이스 참여와 머신 접근 권한 부여는 완전히 분리되어 있으므로, 개인 노트북이 공유 워커가 될
걱정 없이 팀원을 초대할 수 있습니다.
