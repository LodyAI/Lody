# 팀원과 코딩 에이전트 세션 공유하기

Lody에서 **코딩 에이전트 세션 핸드오프(handoff)**는 팀원이 사용자가 이미 시작한 **동일한** 세션을 열어 작업을 이어가는 것을 의미합니다. 팀원은 실시간 대화 내용, 에이전트가 만든 파일 diff, 그리고 세션의 [워크트리](/ko/docs/worktrees)를 그대로 넘겨받습니다. 진행 내용을 _읽기만_ 할 수 있는 스크린샷, Markdown 내보내기, ChatGPT 스타일의 공유 링크와는 다릅니다.

이 점이 일반적인 “Claude Code 세션 공유” 방식과의 가장 큰 차이입니다. 대부분은 대화 기록(transcript)을 게시하는 데 그치지만, Lody는 기존 세션에 팀원을 초대해 직접 대화를 이어가고 에이전트를 조종할 수 있게 합니다.

[세션](/ko/docs/session), [팀 기능](/ko/docs/team), [Agent Config](/ko/docs/quickstart), 그리고 개념 차이를 다룬 [공유 링크 vs 실시간 핸드오프](/ko/docs/compare/share-link-vs-live-handoff)도 함께 참고하세요.

<Callout title="“이어서 작업하기”의 의미">
  세션을 열 수 있는 워크스페이스 멤버는 동일한 컨텍스트에서 대화를 계속 이어갈 수 있습니다.
  Lody는 세션을 읽기 전용 다시보기로 바꾸지 않습니다. 단, 공유 범위는 머신 및 프로젝트
  공개 설정을 따릅니다. 자세한 내용은 아래의 [권한](#권한)을 참고하세요.
</Callout>

## 대화 기록 링크가 핸드오프가 아닌 이유

에이전트 작업 결과를 공유하는 방법은 여러 가지가 있지만, 대부분은 “한번 보세요” 수준에서 멈춥니다. 반면 핸드오프는 “여기부터 이어서 진행하세요”입니다.

| 방식 | 받는 사람이 얻는 것 | 동일한 실시간 세션 여부 | Diff 및 워크트리 |
| --- | --- | --- | --- |
| 스크린샷 | 채팅 화면 이미지 | 아니요 | 아니요 |
| Markdown / 대화 기록 내보내기 | 다른 곳에 붙여넣을 수 있는 정적 텍스트 | 아니요 — 새 채팅을 시작해야 함 | 아니요 |
| ChatGPT 스타일 공유 링크 | 대화의 읽기 전용 스냅샷 | 아니요 | 아니요 |
| **Lody** | 기존 워크스페이스 [세션](/ko/docs/session) | **예** — 열어서 바로 이어서 진행 | **예** — 실시간 [diff](/ko/docs/diff-viewer) 및 세션 워크트리 |

공유 링크와 실시간 핸드오프의 정의 차이는 [공유 링크 vs 실시간 핸드오프](/ko/docs/compare/share-link-vs-live-handoff)에서 확인할 수 있습니다. 기록만 남기고 싶을 때는 Lody에서도 대화를 Markdown으로 내보낼 수 있으며, 이는 [대화 복사](/ko/docs/copy-md)라는 별도의 기능입니다. 세션을 공유하지 않은 채 세션 URL만 복사해 전달해도 팀원에게 접근 권한이 부여되지는 않으며, 해당 링크는 소유자에게만 계속 유효합니다.

## 세션 핸드오프 방법

### 1. 워크스페이스에 팀원 초대하기

핸드오프는 팀 워크스페이스에서 사용하는 기능입니다. 상대방이 이미 워크스페이스 멤버여야 합니다.

1. **Settings** -> **Workspace** -> **General**을 엽니다.
2. **Members** 섹션에서 **Invite Member**를 클릭합니다.
3. 팀원의 이메일을 입력하고 역할을 선택합니다.
4. 팀원이 이메일에서 초대를 수락하거나, 초대 링크를 복사해 직접 전달할 수 있습니다.

자세한 내용은 [멤버 초대](/ko/docs/team#멤버-초대)를 참고하세요.

### 2. 팀원에게 세션 공개하기

새 머신은 기본적으로 **비공개(private)** 상태로 유지됩니다. 세션은 해당 세션이 실행되는 리소스가 공유되었을 때만 팀원에게 표시됩니다.

세션 화면에서 다음 순서로 진행하세요.

1. 세션의 `...` 메뉴를 열거나, 데스크톱 세션 헤더의 **Private** 컨트롤을 클릭합니다.
2. **Share with team…**을 선택합니다(머신 또는 로컬 프로젝트 권한이 빠져 있는 경우 메뉴 이름이 **Share device with team…** 또는 **Share project with team…**으로 표시될 수 있습니다).
3. 확인을 누릅니다. Lody가 필요한 머신과 로컬 프로젝트(해당하는 경우)를 공유한 뒤 링크를 복사합니다.

공유는 **기기 소유자**만 할 수 있습니다. 기기가 팀 접근용으로 등록되어 있지 않다면 먼저 등록해야 합니다. 특정 세션을 열지 않고도 **Settings** -> **Machines** -> **Share machine**에서 머신을 바로 공유할 수 있습니다. 자세한 내용은 [팀 머신 공개 설정](/ko/docs/team#팀-머신-가시성)을 참고하세요.

<Callout type="warn" title="하나 이상의 대화가 함께 공개될 수 있습니다">
  세션을 공유하면 해당 머신 및/또는 로컬 프로젝트가 워크스페이스의 모든 멤버에게 공유될 수 있습니다.
  그 결과 같은 기기에 있는 다른 대화들도 함께 보일 수 있으며, 최종 확인 전에 확인 대화상자에서
  공유 범위를 안내해 드립니다.
</Callout>

### 3. 팀원에게 세션 안내하기

세션이 팀에 공개되면 다음 중 한 가지 방법으로 안내하세요.

- 복사된 세션 링크를 전달합니다. 또는
- 홈 페이지의 세션 목록을 열도록 안내합니다. 본인 대화만 보인다면 사이드바 필터를 **My Tasks**에서 **All Tasks**(모바일에서는 **Team Tasks**)로 전환하세요. 아바타로 각 세션을 누가 시작했는지 확인할 수 있으며, 목록의 기본값은 **All Tasks**입니다.

팀원은 포크나 새 작성기 스레드가 아니라 **바로 그** 세션을 열게 됩니다.

### 4. 작업 이어가기

세션에 들어오면 팀원은 다음 작업을 할 수 있습니다.

- 에이전트와 주고받은 전체 대화 내용 읽기
- 현재 [diff](/ko/docs/diff-viewer) 검토하기
- 동일한 [워크트리](/ko/docs/worktrees)와 브랜치에서 계속 작업하기
- 다음 프롬프트를 보내고 동일한 [에이전트 설정](/ko/docs/quickstart)을 이어서 조종하기

세션 포크(Fork)는 이와 다른 기능으로, 대화 기록을 **새** 세션으로 복사합니다. **Current workspace**는 동일한 파일을 그대로 유지하고, **New worktree**(제공되는 경우)는 커밋된 `HEAD` 기준으로 격리된 환경을 만듭니다. 포크는 팀원을 기존 세션에 참여시키는 용도가 아니라, 개인적으로 대화를 분기하고 싶을 때 사용하세요. 자세한 내용은 [세션 포크](/ko/docs/session#세션-포크)를 참고하세요.

팀 단위로 여러 개의 격리된 세션을 동시에 실행하려면 [병렬 코딩 에이전트](/ko/docs/parallel-agents)를 참고하세요.
하나의 에이전트에서 여러 대화를 조율하려면 [에이전트 세션 제어](/ko/docs/session-orchestration)를 참고하세요.

## 권한

| 제어 항목 | 적용 대상 | 동작 방식 |
| --- | --- | --- |
| 워크스페이스 멤버십 | 초대한 모든 사용자 | 팀 세션을 열기 위해 반드시 필요함 |
| 멤버 역할 | 소유자와 관리자가 멤버 관리 | 초대, 권한 수정, 제거 권한 제어 — [멤버 권한 변경](/ko/docs/team#멤버-권한-변경) 참고 |
| 머신 공유 | 머신 소유자만 가능 | 공유되지 않은 머신의 세션은 다른 멤버의 사이드바에 표시되지 않음 |
| 로컬 프로젝트 공유 | 세션이 로컬 프로젝트를 사용하는 경우 머신 소유자 | 팀원은 머신 권한뿐 아니라 프로젝트 권한도 필요함 |
| 세션 URL | 소유자는 항상 가능; 팀원은 세션이 팀에 공개된 후에만 가능 | URL을 복사하는 것은 **Share with team…**과 다름 |

워크스페이스에 참여한다고 해서 내 노트북이 바로 노출되지는 **않습니다**. 머신은 직접 공유하기 전까지 비공개 상태로 유지됩니다. 에이전트 설정(Agent Config)은 별도로 공유해 팀원이 동일한 CLI 설정으로 실행하도록 할 수 있습니다. 자세한 내용은 [Agent Config](/ko/docs/quickstart)와 [팀 기능](/ko/docs/team)을 참고하세요.

## 자주 묻는 질문

### Claude Code 세션을 공유해 팀원이 이어서 작업하게 할 수 있나요?

네, 해당 세션이 Lody 워크스페이스에서 실행 중이라면 가능합니다. 팀원을 초대하고 세션(및 필요한 머신이나 로컬 프로젝트)을 공유한 뒤, 팀원이 그 세션을 열어 대화를 이어가도록 하면 됩니다. 이는 읽기 전용 Claude Code 대화 기록 내보내기나 공개 스냅샷 링크와는 다릅니다.

### ChatGPT 공유 링크와 같은 기능인가요?

아니요. ChatGPT 공유 링크는 읽기 전용 스냅샷인 **열람용 기록**입니다. Lody는 팀 워크스페이스에서 **기존 코딩 에이전트 세션** 자체를 핸드오프하여 동일한 대화, diff, 워크트리를 그대로 이어서 작업할 수 있게 합니다. 자세한 내용은 [공유 링크 vs 실시간 핸드오프](/ko/docs/compare/share-link-vs-live-handoff)를 참고하세요.

### 팀원에게 세션이 보이지 않으면 어떻게 하나요?

세 가지를 확인해 보세요. 팀원이 워크스페이스 초대를 수락했는지, 머신(및 사용 중인 경우 로컬 프로젝트)이 공유되었는지, 그리고 사이드바 필터가 **My Tasks**가 아니라 **All Tasks**로 설정되어 있는지 확인해야 합니다. 공유되지 않은 머신의 대화는 다른 멤버의 사이드바에 동기화되지 않습니다.

### 세션 하나를 공유하면 내 머신 전체가 공유되나요?

그럴 수 있습니다. 머신이 아직 공유되지 않은 상태에서 **Share with team…**을 실행하면 팀원이 해당 기기의 대화를 열고 이어갈 수 있도록 머신이 함께 공유됩니다. 이때 같은 머신의 다른 세션도 보일 수 있습니다. 나중에 **Settings** -> **Machines**에서 **Share machine**을 다시 끌 수 있습니다.

### 대신 대화 기록만 보낼 수도 있나요?

네. 기록만 필요하다면 세션 메뉴에서 메시지를 복사하거나 **Copy as Markdown**을 사용하세요. 다만 이 방식으로는 다른 사람이 실시간 세션을 이어서 작업할 수 없습니다. 자세한 내용은 [대화 복사](/ko/docs/copy-md)를 참고하세요.
