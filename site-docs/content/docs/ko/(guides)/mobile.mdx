# 모바일 액세스

Lody는 이동 중에도 계속 코딩할 수 있도록 네이티브 iOS 및 Android 앱을 제공합니다.

## 앱 설치

### iOS

iPhone 또는 iPad에 Lody를 설치하세요:

- [App Store에서 다운로드](https://apps.apple.com/us/app/lody-run-code-agent-anywhere/id6761373528)

### Android

[다운로드 페이지](/ko/download)에서 최신 서명된 APK를 다운로드하세요.

## 기능

### iOS 실시간 현황(Live Activities)

iPhone에서는 Lody가 잠금 화면과 Dynamic Island에 실행 중인 에이전트 상태를 표시할 수 있습니다. 앱을 다시 열지 않고도 진행 상황을 추적할 수 있습니다.

에이전트가 권한을 요청할 때 Lody는 iOS에서 바로 응답할 수 있는 실행 가능한 실시간 현황(Live Activity) 알림도 보낼 수 있습니다.

### 푸시 알림

다음과 같은 경우에 알림을 받을 수 있습니다:

- 작업이 완료된 경우
- 에이전트의 승인이 필요한 경우
- PR 검토가 준비된 경우

설정 > 일반 > 푸시 알림에서 알림을 활성화하세요.

### 진행 상황 모니터링

에이전트의 작업 과정을 실시간으로 확인할 수 있습니다:

- 실시간 터미널 출력
- 파일 변경 사항
- 세션 diff 및 리뷰 코멘트
- 이미지 미리보기(길게 눌러 공유 및 저장 가능)

### 프로젝트 파일 탐색

모바일 **프로젝트** 탭에서 프로젝트를 연 다음 **파일**로 전환하면 디렉터리 트리를 탐색하고 텍스트 파일을 미리 볼 수 있습니다. 먼저 대화를 생성할 필요가 없습니다.

소유 머신이나 저장소 제공자를 사용할 수 있는 경우 로컬 프로젝트와 GitHub 저장소 모두에서 프로젝트 파일 탐색이 작동합니다. 현재 실시간 파일 편집은 데스크톱에서 지원되며, 모바일 편집 기능은 곧 제공될 예정입니다.

## 오프라인 지원

Lody 모바일 앱은 오프라인 상태에서도 다음 기능을 지원합니다:

- 캐시된 대화 보기
- 저장된 diff 검토

다시 온라인 상태가 되면 변경 사항이 자동으로 동기화됩니다.
