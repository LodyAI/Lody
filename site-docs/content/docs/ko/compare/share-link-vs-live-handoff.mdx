# 공유 링크 vs 실시간 핸드오프

“내 세션 공유하기”라고 할 때 흔히 혼동하는 두 가지 의미가 있습니다.

- **공유 링크**(또는 스크린샷, Markdown 내보내기, 아카이브)는 **기록**입니다. 다른 사람이 무슨 일이 있었는지 읽을 수 있으며, 일부 도구는 그 컨텍스트를 바탕으로 *새로운* 에이전트 실행을 시작할 수 있습니다.
- **실시간 핸드오프**는 팀원을 **동일한** 코딩 에이전트 세션으로 초대하여 계속 대화를 이어가고, diff를 검토하며, 같은 워크트리에서 작업할 수 있게 합니다.

기록은 실시간 대화, 실시간 diff, 또는 원래의 작업 디렉터리로 초대하는 것이 아닙니다.

사용 방법 및 접근 규칙: [코딩 에이전트 세션 공유](/ko/docs/session-handoff). 팀 워크스페이스: [팀 기능](/ko/docs/team).

<Callout title="정의">
스크린샷, 대화 기록, 공유 링크, 세션 아카이브는 실시간 핸드오프가 아닙니다. 열람자는 실행 중인 세션에 참여하지 못하며 원래의 워크트리도 이어받지 못합니다. 핸드오프에는 워크스페이스 멤버십과 세션 핸드오프 페이지에 안내된 머신/프로젝트 공유 규칙이 필요하며, 누구나 열 수 있는 공개 URL이 아닙니다.
</Callout>

## 서로 다른 두 가지 역할

| 작업 | 받는 사람이 할 수 있는 일 | 동일한 실시간 세션 여부 |
| --- | --- | --- |
| 스크린샷 | 채팅 화면 이미지 보기 | 아니요 |
| Markdown / 대화 기록 내보내기 | 새 채팅에 정적 텍스트 붙여넣기 | 아니요 — 처음부터 새로 시작함 |
| ChatGPT 스타일 공유 링크 | 대화 스냅샷 읽기 | 아니요 |
| 공유 링크 / 아카이브 도구(예: [Lore](https://lore.link/share) 또는 [SpecStory](https://docs.specstory.com/cloud/session-sharing)) | 렌더링된 스레드나 저장된 기록을 보거나, 해당 컨텍스트를 **새로운** 에이전트 실행으로 포크하기 | 아니요 — 열람자는 실행 중인 세션이나 원래의 워크트리에 참여하지 않음 |
| **실시간 핸드오프** | 기존 [세션](/ko/docs/session)을 열어 대화를 이어가고, 실시간 [diff](/ko/docs/diff-viewer)를 검토하며, 동일한 [워크트리](/ko/docs/worktrees)에서 계속 작업하기 | **예** |

기록만 필요할 때는 Lody에서도 [대화를 Markdown으로 복사](/ko/docs/copy-md)할 수 있습니다. 세션을 공유하지 않은 채 세션 URL만 복사해도 팀 접근 권한이 부여되지는 않으며, 해당 링크는 소유자에게만 계속 작동합니다.

이 페이지는 특정 공유 링크 제품을 평가하지 않습니다. Lore와 SpecStory는 핸드오프 페이지에 이미 언급된 기록 / 아카이브 범주의 예시로만 소개됩니다.

## 실시간 핸드오프의 실제 동작

Lody에서 세션을 열 수 있는 팀원은 동일한 컨텍스트에서 작업을 이어갑니다.

- 에이전트가 이미 진행 중인 실시간 대화
- 에이전트가 생성한 파일 diff
- 세션 워크트리와 브랜치
- 다음 프롬프트를 보낼 수 있는 동일한 [에이전트 설정](/ko/docs/quickstart)

팀원은 포크나 완전히 새로운 채팅이 아니라 **바로 그** 세션을 엽니다. 포크(Fork)는 대화 기록을 **새** 세션으로 복사하는 기능으로, 대화의 개인적인 분기를 만들고 싶을 때 사용합니다. [세션 포크](/ko/docs/session#세션-포크)를 참고하세요.

핸드오프는 팀 워크스페이스 기능입니다. 상대방이 이미 멤버여야 하며, 세션은 머신(및 해당하는 경우 로컬 프로젝트)이 공유되었을 때만 팀원에게 표시됩니다. 단계별 안내 및 예외 사례: [코딩 에이전트 세션 공유](/ko/docs/session-handoff).

## 언제 무엇을 사용할까

| 목표 | 권장 방식 |
| --- | --- |
| 누군가가 무슨 일이 있었는지 *읽기*만 하면 되는 경우 | 스크린샷, 대화 기록, 공유 링크 또는 아카이브 |
| 워크스페이스 외부에 남길 기록이 필요한 경우 | 스크린샷, 대화 기록, 공유 링크 또는 아카이브 |
| 내보낸 컨텍스트로 *새로운* 에이전트 실행을 시작하려는 경우 | 스크린샷, 대화 기록, 공유 링크 또는 아카이브 |
| 팀원이 **동일한** 코딩 에이전트 세션을 이어서 진행해야 하는 경우 | **실시간 핸드오프** |
| (재구성된 프롬프트가 아니라) 현재 diff와 동일한 워크트리가 필요한 경우 | **실시간 핸드오프** |
| 상대방이 이미 [워크스페이스](/ko/docs/team) 멤버이거나 멤버가 될 수 있는 경우 | **실시간 핸드오프** |

모델을 혼합하고 별도의 워크트리를 사용하는 등 여러 격리된 세션을 팀 단위로 실행하려면 [병렬 코딩 에이전트](/ko/docs/parallel-agents)를 참고하세요. 이는 추가 작업을 시작하는 기능이지, 하나의 세션을 핸드오프하는 것이 아닙니다.

## 권한

핸드오프는 제품 가이드와 동일한 규칙을 따릅니다. 이 페이지는 공개 공유 링크용 권한 모델을 별도로 추가하지 않습니다.

| 제어 항목 | 적용 효과 |
| --- | --- |
| 워크스페이스 멤버십 | 누구든 팀 세션을 열기 전에 반드시 필요함 |
| 멤버 역할 | 소유자와 관리자가 초대, 수정, 제거 권한을 관리 — [멤버 권한 변경](/ko/docs/team#멤버-권한-변경) 참고 |
| 머신 공유 | 공유되지 않은 머신의 세션은 다른 멤버의 사이드바에 표시되지 않습니다. 기기 소유자만 공유할 수 있습니다. |
| 로컬 프로젝트 공유 | 로컬 프로젝트의 경우 팀원은 머신 권한뿐만 아니라 프로젝트 권한도 필요함 |
| 세션 URL | 소유자는 항상 열 수 있고, 팀원은 세션이 팀에 공개된 후에만 열 수 있습니다. URL을 복사하는 것은 **Share with team…**과 다릅니다. |

워크스페이스에 참여한다고 해서 노트북이 노출되지는 **않습니다**. 머신은 직접 공유하기 전까지 비공개로 유지됩니다. 세션을 공유하면 해당 머신 및/또는 로컬 프로젝트가 워크스페이스의 모든 멤버에게 공유될 수 있으며, 그 기기의 다른 대화도 함께 보일 수 있습니다. [팀 머신 공개 설정](/ko/docs/team#팀-머신-가시성)을 참고하세요.

## 자주 묻는 질문

### 공유 링크는 코딩 에이전트 세션을 핸드오프하는 것과 같은가요?

아니요. 공유 링크, 스크린샷, 대화 기록, 아카이브는 **열람 가능한 기록**입니다. 다른 사람이 내용을 읽을 수 있고, 일부 워크플로에서는 그 컨텍스트로 *새로운* 에이전트 실행을 시작할 수도 있습니다. 하지만 원래의 실시간 세션에 참여하거나 원래의 워크트리를 넘겨받지는 못합니다. 실시간 핸드오프는 기존 워크스페이스 세션을 열어 팀원이 작업을 이어가게 합니다.

### 팀원이 공유 링크에서 내 Claude Code 세션을 이어서 진행할 수 있나요?

대화 기록, ChatGPT 스타일 스냅샷, 아카이브 뷰어에서는 불가능합니다. 세션이 Lody 워크스페이스에서 실행 중이라면 팀원을 초대하고 세션(및 필요한 머신이나 로컬 프로젝트)을 공유한 다음, **바로 그** 세션을 열도록 안내하세요. 자세한 내용: [코딩 에이전트 세션 공유](/ko/docs/session-handoff).

### 대화 기록을 공유하는 것과 실시간으로 협업하는 것의 차이는 무엇인가요?

대화 기록을 공유하는 것은 기록을 보내는 것입니다. 실시간으로 협업한다는 것은 팀원이 같은 세션 안에 있다는 뜻으로, 같은 대화, 같은 diff, 같은 워크트리를 공유합니다. Markdown을 내보내거나 URL을 복사하는 것만으로는 해당 접근 권한이 부여되지 않습니다.

### 대화 기록만 보내고 싶다면 어떻게 하나요?

세션 메뉴에서 메시지를 복사하거나 **Copy as Markdown**을 사용하세요. 이 방법으로는 실시간 접근 권한이 부여되지 않습니다. [대화 복사](/ko/docs/copy-md)를 참고하세요.

### 내가 보낸 세션 URL을 팀원이 열 수 없는 이유는 무엇인가요?

세션 URL을 복사하는 것은 세션을 공유하는 것이 아닙니다. 팀원이 워크스페이스 멤버여야 하고, 머신(및 해당하는 경우 로컬 프로젝트)이 공유되어 있어야 하며, **My Tasks**가 아니라 **All Tasks**에서 확인해야 합니다. 공유되지 않은 머신의 대화는 다른 멤버의 사이드바로 동기화되지 않습니다.
