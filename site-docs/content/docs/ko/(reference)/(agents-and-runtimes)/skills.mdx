# 스킬

Lody는 지원되는 프로젝트 및 머신 전역 스킬 디렉터리에서 Agent Skills를 검색합니다. 스킬(Skill)은 코딩 에이전트를 위한 재사용 가능한 지침이 담긴 `SKILL.md` 파일을 포함하는 디렉터리입니다.

Lody의 스킬은 읽기 전용입니다. Lody는 스킬 파일을 검색하고 표시하며 참조할 수는 있지만, 설치하거나 편집하거나 동기화하지는 않습니다.

## 스킬 탐색하기

데스크톱에서는 **Settings** -> **Projects**를 열고 프로젝트를 선택한 뒤 **Skills** 탭으로 전환합니다.

모바일에서는 프로젝트를 열고 **Settings**로 전환한 뒤 **Project skills**를 선택합니다.

목록은 소스 경로별로 그룹화되며 이름, 설명, 버전, 작성자, 범위, 심볼릭 링크 상태 등 사용 가능한 메타데이터를 표시합니다. 스킬을 열면 해당 `SKILL.md`의 렌더링된 본문을 읽을 수 있습니다.

## 프로젝트 스킬과 전역 스킬

- **프로젝트 스킬(Project Skills)**은 로컬 프로젝트 내부 또는 GitHub 프로젝트의 기본 브랜치에 있는 인식된 스킬 디렉터리에서 가져옵니다.
- **전역 스킬(Global Skills)**은 `~/.codex/skills` 또는 `~/.claude/skills`와 같이 에이전트를 실행하는 머신의 현재 OS 사용자용 인식된 디렉터리에서 가져옵니다.

전역 스킬은 머신별로 다릅니다. GitHub 프로젝트 설정에는 저장소 스킬이 표시되며, 채팅에서는 해당 세션에 선택된 머신의 호환 가능한 전역 스킬도 함께 제공할 수 있습니다.

## 스킬 멘션하기

1. 대화에 사용할 프로젝트와 Agent Config를 선택합니다.
2. 입력창에 `$`를 입력합니다.
3. 스킬 이름을 계속 입력하여 필터링합니다.
4. 방향키로 이동해 `Enter`를 누르거나 스킬을 클릭합니다.

입력창에는 읽기 쉬운 `$skill-name` 토큰이 유지됩니다. 메시지를 전송하면 Lody가 해당 참조를 관련 `SKILL.md` 경로로 확장하여, 선택된 에이전트가 이를 불러와 따를 수 있도록 합니다.

에이전트마다 디렉터리 지원 여부가 다른 경우, 메뉴는 현재 ACP 프로바이더에 맞게 필터링됩니다.

## 새로고침 및 오프라인 동작

Lody는 현재 기기에 스킬 메타데이터를 캐시하고 백그라운드에서 새로고침합니다. 프로젝트나 소유 머신을 일시적으로 사용할 수 없는 경우, 이전에 캐시된 결과가 오래됨(stale) 또는 사용 불가(unavailable) 상태로 계속 표시될 수 있습니다.

심볼릭 링크는 허용된 프로젝트 또는 사용자 홈 디렉터리 경계 내부를 가리키는 경우 지원됩니다. 안전하지 않거나 대상이 없는(dangling) 링크는 건너뜁니다.
