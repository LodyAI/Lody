# CLI 런타임 유형

Lody는 [ACP 레지스트리](https://agentclientprotocol.com/get-started/registry)에 게시된 모든 CLI 런타임을 지원합니다.
사용 가능한 런타임 목록은 레지스트리에서 불러오므로, 이 페이지에서는 벤더나 명령어의 별도 정적 목록을
유지하지 않습니다.

## 레지스트리 런타임

1. **Settings** -> **Agent Config**를 엽니다.
2. 추가 버튼을 클릭합니다.
3. 설정의 이름을 입력합니다.
4. 레지스트리 기반 선택기에서 원하는 CLI 유형을 선택합니다.
5. 필요한 환경 변수를 추가합니다.
6. 버튼이 표시되면 **Test**를 클릭합니다. 이를 통해 Lody가 런타임을 실행하고 지원 모델 및 런타임 모드를
   포함한 기능을 읽어올 수 있는지 확인합니다.
7. 설정을 저장한 다음, 대화를 생성할 때 해당 설정을 선택합니다.

레지스트리 지원 덕분에 업스트림에 새로운 ACP 런타임 항목이 추가되면 Lody도 이를 바로 따라갈 수 있습니다.
단, 호스트 머신에는 선택한 런타임의 자체 문서 안내에 따라 명령어, 로그인, 자격 증명 및 의존성이 여전히
설치되어 있어야 합니다.

## 커스텀 ACP 에이전트

사용하려는 에이전트가 ACP와 호환되지만 레지스트리에 게시되어 있지 않다면, **Settings** -> **Agent Config**에서
**Custom ACP**를 선택하세요.

1. 설정의 이름을 입력합니다.
2. **CLI Type**을 **Custom ACP**로 설정합니다.
3. **Launch command**에 stdio를 통해 에이전트를 시작하는 명령어를 입력합니다.
4. 같은 Agent Config에 필요한 환경 변수를 추가합니다.
5. **Test**를 클릭하여 Lody가 에이전트를 실행하고 지원 기능을 읽어올 수 있는지 확인합니다.
6. 설정을 저장한 다음, 대화를 생성할 때 해당 설정을 선택합니다.

실행 명령어 예시:

```bash
npx -y my-acp-agent --stdio
```

실행 명령어는 명령어와 인수로 파싱된 후 직접 스폰(spawn)됩니다. 공백이 포함된 인수에 대해서는 따옴표가
지원되지만, 파이프, 리다이렉트, 글롭(glob) 확장, `$VARS` 같은 셸 기능은 평가되지 않습니다.
환경 변수는 명령어에 넣지 말고 Agent Config에 입력해 주세요.

## 참고 사항

- 일부 레지스트리 런타임은 업스트림에서 아직 실험적(experimental) 상태일 수 있습니다.
- 사용하기 전에 Lody CLI가 실행되는 호스트에 필요한 로그인 자격 증명이 이미 구성되어 있는지 확인하세요.
- 로컬 런타임 유형을 사용하려면 해당하는 호스트 명령어가 먼저 설치되어 있어야 합니다.
- 사용 가능한 모델은 선택한 런타임, 로컬 설치 상태, 계정 권한에 따라 달라집니다.
