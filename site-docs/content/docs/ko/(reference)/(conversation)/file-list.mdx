# 파일 목록

Lody에는 두 가지 파일 영역이 있습니다.

- **프로젝트 파일**은 세션이 없어도 로컬 프로젝트나 GitHub 리포지토리를 보여줍니다.
- **세션 파일**은 에이전트가 변경한 파일을 포함하여 현재 세션 워크트리를 보여줍니다.

## 프로젝트 파일 탐색

모바일에서는 **Projects** 탭에서 프로젝트를 연 다음 **Files**로 전환합니다. 프로젝트 화면에서 바로 폴더 안으로 들어가 텍스트 파일을 열 수 있습니다. 소유 머신이나 리포지토리 제공자를 사용할 수 있는 경우 로컬 프로젝트와 GitHub 리포지토리 모두에서 동작합니다.

프로젝트 파일 탐색은 새 대화를 시작하기 전에 리포지토리를 살펴보거나, 데스크톱에서 떨어져 있을 때 파일을 찾아봐야 할 때 유용합니다.

## 세션 파일 탐색

채팅 인터페이스 오른쪽 상단의 사이드바 확장 버튼을 클릭해 파일 및 변경 사항 사이드바를 엽니다.

`Files` 탭에서 현재 대화의 전체 파일 목록을 확인할 수 있습니다. 현재 대화에서 변경된 파일은 강조 표시되므로 더 쉽게 찾을 수 있습니다.

텍스트 파일을 클릭하면 세션 내 파일 미리 보기가 열립니다. 긴 줄은 자동으로 줄 바꿈되므로 미리 보기 창에서 로그, 생성된 파일, 압축된 소스 파일을 더 읽기 쉽게 확인할 수 있습니다.

## 빠른 열기 및 검색

세션 파일 뷰어에서 파일 검색 컨트롤을 사용하면 트리를 스크롤하지 않고도 인덱싱된 파일을 찾아 바로 열 수 있습니다. 텍스트 파일이 열려 있을 때는 파일 도구 모음의 검색 아이콘을 클릭해 파일 내 검색 컨트롤을 엽니다.

## Markdown 미리 보기

Markdown 파일은 기본적으로 소스 모드로 열립니다. 파일 도구 모음의 눈 아이콘을 클릭하면 렌더링된 미리 보기로 전환되며, 다시 클릭하면 소스로 돌아갑니다. 아이콘 위에 마우스를 올리면 편집기를 벗어나지 않고 미리 보기를 살짝 확인할 수 있습니다.

## 실시간 편집

세션 파일이 실시간 공동 작업 제공자(live collaborative provider)로 지원되는 텍스트 파일이고, 사용자의 역할에 쓰기 권한이 있는 경우 파일 뷰어가 편집 가능한 상태로 전환됩니다. 편집 내용은 세션 워크트리에 저장되며 공동 작업자에게 실시간으로 동기화됩니다.

파일이 읽기 전용이거나, 과거 이력 파일이거나, 너무 크거나, 바이너리 파일이거나, 호스트 머신이 오프라인 상태인 경우 Lody는 뷰어를 읽기 전용으로 유지하고 파일 상태 표시줄에 현재 사용 가능 상태를 표시합니다.
