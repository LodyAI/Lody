# 파일 첨부

Lody는 새 대화와 기존 대화 모두에서 임의의 파일 첨부를 지원합니다. 첨부 파일은 프롬프트와 함께
전달되므로, 에이전트가 메시지 안에 내용을 붙여 넣을 필요 없이 세션 워크스페이스에서 원본 파일을
직접 읽을 수 있습니다.

## 첨부 파일 추가

1. 메시지 입력창에서 첨부 `+` 메뉴를 엽니다.
2. **Upload file**(파일 업로드)을 선택한 다음 하나 이상의 파일을 선택합니다.
3. 진행 중인 업로드가 완료될 때까지 기다린 후, 필요한 지시 사항을 추가하고 메시지를 전송합니다.

세션 인터페이스에 파일을 드래그하여 추가할 수도 있습니다. 대화를 시작할 때 대기 중인 첨부 파일은
해당 새 세션과 계속 연결된 상태로 유지됩니다.

## 미리 보기 및 다운로드

텍스트 미리 보기가 가능한 파일은 미리 보기 대화 상자에서 열립니다. 여기에서 다음 작업을 할 수
있습니다.

- 렌더링된 Markdown 또는 원본 소스 보기
- 원본 텍스트 복사
- 전체 파일 다운로드

다른 파일 형식에서는 다운로드가 기본 동작으로 제공됩니다. 네이티브 모바일 앱에서는 시스템 공유 시트를
통해 다운로드가 열리므로 파일을 저장하거나 다른 앱으로 보낼 수 있습니다.

## 에이전트가 파일을 전달받는 방식

턴이 시작되기 전에 Lody는 각 첨부 파일을 세션 워크스페이스 내 `.lody/attachments/` 경로에
생성하고 에이전트에게 파일 참조를 전달합니다. 파일 내용은 텍스트 프롬프트에 직접 삽입되지
않습니다.

에이전트도 파일과 이미지를 반환할 수 있습니다. 지원되는 ACP 출력과 Lody 업로드 도구를 사용하면
해당 파일이 일반 첨부 파일 카드로 대화에 추가됩니다.

## 제한 및 보관 기간

- 한 메시지에 최대 8개의 파일을 첨부할 수 있습니다.
- 각 파일의 최대 크기는 100 MiB입니다.
- 모든 파일 형식을 지원합니다.
- 릴레이(Relay)에 저장된 파일은 90일간 보관됩니다.

이미지는 별도의 이미지 처리 정책이 적용됩니다. 메시지당 최대 8개, 이미지당 최대 5 MiB까지 첨부할 수
있으며, 더 큰 이미지는 일반 파일로 대신 전송할 수 있습니다. 자세한 내용은
[이미지 입력](/ko/docs/image-input) 및 [이미지 출력](/ko/docs/image-output)을 참고하세요.

## 가용성

에이전트가 첨부 파일을 읽으려면 먼저 해당 세션을 소유한 머신이 첨부 파일을 가져올 수 있어야 합니다.
업로드에 실패하면 해당 첨부 파일을 다시 시도하거나 제거하세요. 성공적으로 업로드된 다른 첨부 파일은
그대로 전송할 수 있습니다.
