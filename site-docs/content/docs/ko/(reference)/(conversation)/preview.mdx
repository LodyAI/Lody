# Lody Preview

Lody Preview를 사용하면 Lody 인터페이스에서 로컬 개발 서버의 실시간 화면을 바로 열 수 있습니다. 에이전트가 UI 코드를 수정하는 동안 localhost URL을 일일이 복사하지 않고도 데스크톱, 태블릿, 모바일 또는 다른 기기에서 결과를 확인하고 싶을 때 유용합니다.

## 미리 보기 시작하기

에이전트에게 개발 서버를 시작하고 Lody Preview를 사용하도록 요청하세요. 예를 들면 다음과 같습니다.

```text
Start the Vite dev server and use Lody Preview to check the page.
```

Lody가 세션의 미리 보기 대상을 감지하면 **Preview** 탭을 여세요. 로컬 데스크톱 세션의 경우 **Design mode**를 켜면 터널이나 공유 가능한 원격 URL 없이도 로컬 미리 보기를 바로 열 수 있습니다. 원격 세션이거나 미리 보기를 공유하려는 경우에는 **Preview Remote**를 사용한 뒤 **Create connection**을 클릭하세요. 미리 보기는 미리 보기 헤더의 전원 버튼으로 종료할 수 있습니다.

## 레이아웃 점검하기

미리 보기 도구 모음에는 다음 기능이 포함되어 있습니다.

- 데스크톱, 태블릿, 모바일 뷰포트 프리셋
- 세로 및 가로 방향 회전
- 확대/축소, 화면에 맞추기, 재설정 컨트롤
- 드래그하여 화면 이동 및 핀치/Ctrl+스크롤 확대를 지원하는 손 도구(hand mode)
- 별도의 브라우저 탭이 필요한 페이지를 위한 외부 열기 작업
- 미리 보기 공유 URL 복사 버튼

이러한 컨트롤을 사용해 대화와 diff를 곁에 둔 상태에서 반응형 중단점(breakpoint), 오버플로(overflow), 탭 대상 영역, 레이아웃 변경 사항을 점검할 수 있습니다.

## 시각적 주석

주석 모드를 켜고 미리 보기에서 UI 요소를 클릭한 다음 변경해야 할 내용에 대한 코멘트를 작성하세요. Lody는 해당 코멘트를 선택한 요소에 고정(anchor)하고 그 참조를 채팅으로 다시 전송할 수 있어, 에이전트가 시각적 대상과 지시 사항을 모두 함께 전달받게 됩니다.

시각적 주석은 간격, 정렬, 문구, 색상, 반응형 레이아웃 문제와 같은 구체적인 UI 피드백에 가장 효과적입니다.

## 참고 사항

- 로컬 Design mode 미리 보기를 사용하려면 로컬 개발 서버가 계속 실행 중이어야 합니다. 원격 미리 보기를 사용하려면 세션의 머신도 온라인 상태여야 합니다.
- 일부 앱은 임베디드 미리 보기를 차단하거나, 외부 브라우저 탭에서 더 잘 동작하는 브라우저 기능을 필요로 할 수 있습니다.
- 미리 보기가 최신 상태를 반영하지 않는다면 미리 보기를 새로고침하거나 에이전트에게 개발 서버를 다시 시작해 달라고 요청하세요.
