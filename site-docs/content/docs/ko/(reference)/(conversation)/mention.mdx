# 멘션

Lody는 입력창에서 멘션 기능을 지원합니다. `@`를 입력해 멘션 메뉴를 열면 대화, 파일, Issue, Pull Request, Skill 또는 Agent Role을 선택할 수 있습니다. `$`는 Skill을 바로 불러오는 단축키로 사용할 수 있습니다.

## 대화 멘션

`@`를 입력하고 **Sessions**를 선택한 뒤 다른 대화를 골라 참조할 수 있습니다. 현재 에이전트에게 해당 세션에 연락하여 관련 컨텍스트를 읽거나, 발견한 내용을 주고받거나, 리뷰를 요청하도록 지시해 보세요. 예를 들어, 구현 세션을 멘션한 뒤 현재 에이전트에게 최신 커밋을 리뷰하고 결과를 다시 전달해 달라고 요청할 수 있습니다.

참조된 세션은 다른 에이전트를 사용하거나 연결된 다른 머신에서 실행 중일 수 있습니다. 접근 권한은 여전히 워크스페이스 권한을 따르며, 작업을 실행하려면 대상 머신이 온라인 상태여야 합니다. 멘션은 세션을 식별하는 역할을 하므로, 어떤 컨텍스트를 교환하거나 어떤 작업을 수행할지 설명하는 지시사항을 함께 포함하세요.

사용 가능한 작업은 [에이전트 세션 제어](/ko/docs/session-orchestration/)를 참고하거나, [멀티 에이전트 협업 가이드](/ko/docs/agent-collaboration/)를 따라 에이전트 및 머신 간에 컨텍스트를 교환하고 리뷰를 요청하세요.

## 파일 멘션

`@`를 입력하고 **Files**를 선택하세요. 계속 입력하면 파일 이름이나 파일 경로를 기준으로 퍼지 매칭(fuzzy-match)됩니다. 위아래 화살표 키로 선택한 다음 Enter 키를 눌러 확정하세요. 멘션된 파일은 전체 경로 형태의 프롬프트 컨텍스트로 코딩 에이전트에 전달됩니다.

## Issue 및 Pull Request 멘션

홈 페이지에서 저장소를 선택한 뒤 `@`를 입력해 멘션 메뉴를 열고, **Issues** 또는 **Pull Requests**를 선택하면 현재 저장소의 항목을 멘션할 수 있습니다.

<MentionPreview locale="ko" kind="issue" />

위아래 화살표 키로 선택한 다음 Enter 키를 눌러 확정하세요. Lody는 선택한 항목을 작성기에 `#<number>` 형식으로 입력하고 해당 컨텍스트를 프롬프트에 주입하므로, 에이전트가 `Fix #12` 또는 `Review the implementation in #56`과 같은 작업을 처리할 수 있습니다.

## Skill 멘션

`$`를 입력하면 선택한 프로젝트와 에이전트 머신에서 사용할 수 있는 Skill을 탐색할 수 있습니다. 계속 입력해 이름으로 필터링한 뒤 화살표 키와 `Enter` 키로 Skill을 선택하세요.

Lody는 작성기에 읽기 쉬운 `$skill-name` 토큰을 유지합니다. 메시지를 전송하면 해당하는 `SKILL.md` 경로가 함께 추가되어 에이전트가 해당 지침을 불러와 따를 수 있습니다.

탐색 위치, 프로젝트 및 전역 범위, 오프라인 동작에 대해서는 [Skills](/ko/docs/skills)를 참고하세요.
