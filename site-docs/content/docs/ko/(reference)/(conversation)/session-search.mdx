# 대화 내 검색

대화 내 검색을 사용하면 긴 세션에서도 이전 맥락을 빠르게 다시 찾을 수 있습니다. 사용자의
메시지, 에이전트의 답변, 사고 과정(thinking), 제안된 계획 등 대화 텍스트를 검색하며, 완료된
턴의 접힌 작업 그룹 안에 들어 있는 진행 텍스트와 사고 과정도 포함됩니다.

도구 호출(tool call)은 검색 대상이 아닙니다. 도구 호출의 제목, 파일 경로, JSON 입출력, 터미널
명령어/출력, diff는 인덱스에 포함되지 않습니다. 구조화된 계획 체크리스트, 목표(goal),
워크트리 스크립트 출력도 제외됩니다. 다만 메시지나 제안된 계획에 작성된 파일 경로 또는 코드
스니펫은 대화 텍스트로서 계속 검색할 수 있습니다.

이는 [전역 세션 탐색 검색](/ko/docs/keyboard-shortcuts#open-the-command-palette)과는 다릅니다.
사이드바의 **Search** 항목이나 `Cmd/Ctrl+K`를 누르면 명령 팔레트가 열리며, 여기에서는 제목,
프로젝트/저장소 레이블 또는 브랜치 이름으로 세션을 찾습니다. 명령 팔레트는 대화 텍스트를
검색하지 않고 세션 간을 전환하는 용도로 사용됩니다.

## 검색 열기

- 세션 메뉴를 열고 **Find in session**을 선택합니다.
- 데스크톱에서는 `Ctrl+F`, macOS에서는 `Cmd+F`를 누릅니다.

검색창은 작성기(composer)를 가리지 않고 대화 영역 위에 표시됩니다.

## 검색 결과 이동하기

- 입력하는 동안 일치하는 텍스트가 강조 표시됩니다.
- 카운터에 현재 결과 위치와 전체 일치 개수가 표시됩니다.
- `Enter`를 누르면 다음 일치 항목으로 이동합니다.
- `Shift+Enter` 또는 위쪽 화살표 키를 누르면 이전 일치 항목으로 이동합니다.
- 일치하는 항목이 없으면 카운터에 `0 / 0`이 표시됩니다.

현재 선택된 결과는 화면 안으로 스크롤되며, 일치 항목이 접힌 작업 그룹이나 사고 과정 카드 안에
있는 경우 해당 카드가 자동으로 펼쳐집니다.

## 검색어 지우기 또는 닫기

`Escape`를 한 번 누르면 현재 검색어가 지워집니다. `Escape`를 한 번 더 누르면 검색이 닫힙니다.
