# 이미지 입력

Lody는 세션 채팅에서 이미지 입력을 지원합니다. 스크린샷, UI 목업, 오류 화면 캡처 등 다양한 시각 자료를 프롬프트 컨텍스트의 일부로 전송할 수 있습니다.

<ImageInputPreview locale="ko" />

## 사용 사례

- 스크린샷을 직접 첨부해 시각적 버그를 설명합니다.
- 이미지에서 UI 세부 정보를 읽어 들이도록 AI에 요청합니다.
- 한 턴에서 이미지 자료와 코드 컨텍스트를 함께 조합해 전달합니다.

## 사용 방법

1. 세션 채팅을 엽니다.
2. 첨부 `+` 메뉴를 열어 **Upload image**(이미지 업로드)를 선택하거나, 클립보드에서 이미지를 붙여 넣거나,
   세션 인터페이스 위의 아무 곳에나 이미지 파일을 드래그합니다.
3. 지시 사항을 입력하고 전송합니다.

한 메시지에 최대 8개의 이미지를 첨부할 수 있으며, 이미지당 최대 크기는 5 MiB입니다. 더 큰 이미지는
[파일 첨부](/ko/docs/file-attachments)를 통해 일반 파일로 전송할 수 있습니다.

<Callout type="warn">

이미지 지원 여부는 현재 모델에 따라 다릅니다. 선택한 모델이 비전(vision) 입력을 지원하는지 확인하세요.

</Callout>
