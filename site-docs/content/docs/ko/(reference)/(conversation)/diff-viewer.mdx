# Diff 뷰어

Lody는 각 대화 라운드가 끝난 후 코딩 에이전트가 수정한 파일 업데이트를 실시간으로 동기화합니다.

## 현재 라운드의 Diff

AI에게 코드 편집과 파일 수정을 요청하면, Lody는 해당 대화 라운드 전후의 파일 상태를 비교합니다. 라운드가 끝나면 코딩 에이전트 메시지 말풍선 아래에 모든 파일 변경 사항과 변경된 줄 수를 표시합니다.

<ConversationDiffPreview locale="ko" />

원하는 파일을 클릭하면 diff 탭이 열리고 해당 파일로 이동합니다. 처음 클릭할 때는 데이터를 동기화하고 불러오는 데 약간의 시간이 더 걸릴 수 있습니다.

<DiffViewerPreview locale="ko" />

또한 패널의 펼치기 컨트롤을 클릭해 파일에서 변경되지 않은 부분도 확인할 수 있습니다.

## 줄 단위 코멘트

코멘트를 남길 수 있는 diff 줄 위에 마우스를 올리고 줄 번호 옆의 `+`를 클릭하면 Markdown 코멘트를 추가할 수 있습니다. 모바일에서는 코멘트를 남길 수 있는 줄을 탭해 코멘트 입력 상자를 엽니다. 코멘트는 스레드 답글, 해결/해제(resolve/unresolve), 그리고 에이전트가 처리할 수 있도록 스레드를 채팅으로 다시 보내는 기능을 지원합니다.

세션이 GitHub PR에 연결되어 있는 경우, Lody 코멘트를 GitHub PR 리뷰의 줄 단위 코멘트로 동기화할 수 있습니다. 기존의 GitHub 리뷰 스레드도 Lody diff에 함께 표시되므로 코드 문맥을 보면서 바로 답글을 달 수 있습니다.

전체 워크플로는 [Diff 코멘트](/ko/docs/diff-comments)를 참고하세요.

## 전체 대화의 Diff

라운드 단위 변경 사항 외에도 채팅 화면 오른쪽 상단의 사이드바 펼치기 버튼을 클릭해 Files and Changes 사이드바를 열 수 있습니다.

`Changes` 탭에서는 현재 대화의 모든 파일 변경 사항을 확인할 수 있습니다.

## 원격 리뷰

세션의 머신이 온라인 상태일 때, 원격 기기에서도 데스크톱 UI와 동일한 세션 파일 프로바이더(session file provider)를 통해 변경된 파일과 diff를 열 수 있습니다. diff나 파일이 아직 동기화 중이라면 Lody는 최신 워크스페이스 스냅샷을 기반으로 임의로 추측해 표시하지 않고 현재의 사용 불가 또는 로딩 상태를 보여줍니다.
