# 대화 복사

## 단일 메시지 복사

채팅 인터페이스에서 각 메시지 말풍선 아래에는 복사 버튼이 있습니다. 이 버튼을 클릭하면 해당 메시지를 복사할 수 있습니다.

## 전체 대화 복사

세션의 `...` 메뉴를 열고 **Copy**를 펼친 뒤 **Copy as Markdown**을 선택하세요. Lody가 현재 표시된 대화 기록을 재사용 가능한 Markdown 형식으로 복사합니다.

같은 하위 메뉴에서는 해당 값을 사용할 수 있을 때 세션 워크스페이스 경로나 세션 URL도 복사할 수 있습니다.

Markdown 복사는 실시간 핸드오프가 아닌 기록입니다. 세션 URL을 복사하는 것만으로는 팀 접근 권한도 부여되지 않습니다. 팀원을 같은 세션에 초대하려면 [코딩 에이전트 세션 공유](/ko/docs/session-handoff)를 참고하세요. 공유 링크와 핸드오프의 차이점은 [공유 링크 vs 실시간 핸드오프](/ko/docs/compare/share-link-vs-live-handoff)에서 확인할 수 있습니다.
