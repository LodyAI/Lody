# 이미지 출력

Lody는 세션에서 최대 8개의 이미지를 바로 반환할 수 있습니다. 에이전트에게 `프론트엔드 개발 서버를 실행하고 홈페이지가 로드될 때까지 기다린 다음 스크린샷을 보내줘.`와 같이 요청하면, Lody가 결과 이미지를 채팅에 자동으로 업로드합니다.

선택한 런타임이 Codex 이미지 생성과 같은 이미지 생성 기능을 지원하는 경우, 세션을 벗어나지 않고도 생성된 이미지를 대화창에서 바로 확인할 수 있습니다.

## 생성된 이미지

Codex 이미지 생성의 경우, Lody는 생성된 이미지를 프롬프트 및 후속 요청과 동일한 대화에 함께 유지합니다. 이를 통해 수정을 요청하거나 여러 시안을 비교하고, 나중에 생성된 애셋을 다시 참조하기가 더 쉬워집니다.

<ImageOutputPreview locale="ko" />

## 활용 사례

- 모바일에서 UI 결과를 빠르게 확인할 수 있습니다.
- 로컬 머신의 시각적 결과물을 전송해 달라고 에이전트에게 요청할 수 있습니다.
- 프롬프트 및 구현 컨텍스트와 함께 생성된 이미지를 검토할 수 있습니다.

## 사용 방법

1. 세션 채팅을 엽니다.
2. 에이전트에게 스크린샷을 찍거나 이미지를 반환하는 작업을 수행하도록 요청합니다. Lody가 해당 이미지를 대화에 자동으로 업로드합니다.
