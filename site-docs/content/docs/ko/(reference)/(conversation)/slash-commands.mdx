# 슬래시 명령어

채팅 입력창의 맨 앞에 `/`를 입력하면 현재 에이전트가 제공하는 명령어와 사용 가능한 워크스페이스 Prompt Shortcuts 메뉴가 열립니다. 연결된 에이전트가 지원하는 경우 `/review`, `/compact`, `/undo` 같은 에이전트 명령어를 예로 들 수 있습니다.

<SlashCommandsPreview locale="ko" />

에이전트 명령어는 Lody가 아니라 **에이전트에서 제공**합니다. 각 Agent Config는 기능 검색(capability discovery) 과정에서 자체 명령어 목록을 알리므로, 사용 가능한 명령어는 CLI 유형(Claude Code, Codex, Kimi, OpenCode 또는 모든 ACP 레지스트리 런타임)과 머신에 설치된 버전에 따라 달라집니다.
Prompt Shortcuts는 워크스페이스 단위로 정의되며 자체 표시 여부 및 범위 규칙을 따릅니다.

## 메뉴 열기

- 새 턴의 첫 번째 문자로 `/`를 입력합니다.
- 입력하는 동안 두 소스에서 사용 가능한 결과가 관련성 순으로 표시됩니다.
  정확히 일치하는 이름이 먼저 나오고, 그다음 접두사 일치, 단어 시작 일치, 포함 텍스트, 더 느슨한 일치 순으로 정렬됩니다.
  각 행에는 출처가 표시됩니다. `/`만 입력하면 소스별로 별도 그룹으로 구분되어 표시됩니다.
- `↑` / `↓` 키로 항목 간에 이동하고, `Home` / `End` 키로 첫 번째 또는 마지막 항목으로 이동합니다.
- `Enter` 키를 눌러 강조 표시된 명령어를 삽입하거나, `Tab` / `Escape` 키를 눌러 삽입하지 않고 메뉴를 닫습니다.

일치하는 항목이 없으면 메뉴에 해당 안내가 표시됩니다. 입력한 텍스트는 일반 내용으로 입력창에 그대로 유지됩니다.

## 명령어의 동작

명령어는 에이전트에서 제공되므로, 각 명령어의 동작은 해당 에이전트의 문서에 정의되어 있습니다.
주요 에이전트들이 일반적으로 제공하는 예시는 다음과 같습니다.

| 명령어     | 일반적인 동작                                                  |
| ---------- | -------------------------------------------------------------- |
| `/review`  | 에이전트에게 현재 diff 또는 최근 변경 사항을 검토하도록 요청합니다 |
| `/compact` | 대화를 요약하고 압축해 컨텍스트 공간을 확보합니다                 |
| `/undo`    | 에이전트가 생성한 가장 최근 변경 사항을 되돌립니다               |

전체 목록과 정확한 동작 방식은 해당 에이전트의 자체 문서를 확인하세요.

## 명령어 목록 새로고침

목록은 각 머신의 에이전트 설정(Agent Config)별로 캐시됩니다. 새 CLI 버전을 설치하거나 Agent Config의 환경을 변경한 뒤에는 캐시를 새로고쳐 새 명령어가 표시되도록 하세요.

- 웹 UI에서: **Agent Config**를 열고 해당 설정을 선택한 다음 옵션을 새로고침합니다.
- CLI에서: 사용하는 머신에서 `lody agent-config refresh-capabilities <idOrName>`을 실행합니다.

자세한 내용은 [Agent Config](/ko/docs/quickstart) 및 [CLI 명령어](/ko/docs/cli#agent-config-refresh-capabilities)를 참고하세요.
