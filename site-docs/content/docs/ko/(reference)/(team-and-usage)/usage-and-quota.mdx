# 컨텍스트, 토큰 및 할당량

Lody는 컨텍스트 윈도우 사용량, 토큰 사용량/비용, 구독 할당량을 통합된 방식으로 추적할 수 있는 기능을 제공합니다.

## 컨텍스트 윈도우 잔여 용량

세션 채팅에서는 각 AI 응답마다 남은 컨텍스트 윈도우 비율이 표시될 수 있습니다.

이 지표를 활용해 다음을 수행할 수 있습니다:

- 컨텍스트 오버플로 방지
- 요약하거나 새 세션을 시작할 시점 결정
- 장시간 실행되는 작업의 안정적인 유지

<Callout type="warn" title="컨텍스트 압축">

Claude Code 또는 Codex에서 기본 제공 `/compact` 명령을 수동으로 실행해 컨텍스트를 압축할 수 있지만, 현재 Lody에서는 관련 UI 업데이트를 지원하지 않으므로 에이전트 응답이 표시되지 않습니다.

</Callout>

## 토큰 사용량 및 예상 비용

**설정(Settings)** -> **통계(Stats)**에서 최근 24시간, 7일, 30일 또는 사용 가능한 전체 기록에 대한 토큰 사용량 추이와 예상 비용을 확인할 수 있습니다. 개요에는 활성 멤버와 사용된 모델도 표시되며, 차트에서는 모델별 및 멤버별 사용량을 세부적으로 확인할 수 있습니다. 차트 범례 항목을 선택하면 해당 데이터 계열에 집중하여 볼 수 있습니다.

## 구독 할당량 표시

**설정(Settings)** -> **에이전트 구성(Agent Config)** -> **머신(Machines)**에서 Lody는 지원되는 구독 주기(예: 5시간 및 7일 주기)에 대한 남은 할당량과 갱신 시간을 표시합니다.
