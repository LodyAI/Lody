# 구독 할당량

Lody CLI가 실행 중인 모든 머신을 보려면 **Settings** -> **Agent Config** -> **Machines**로 이동하세요.
머신에 Claude Code 또는 Codex 구독으로 로그인되어 있고 대화를 실행한 적이 있다면,
Lody가 5시간 및 1주 기간의 남은 할당량을 표시합니다.
