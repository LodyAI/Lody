# 명령 팔레트 및 키보드 단축키

Lody는 작업과 세션을 찾을 수 있는 명령 팔레트와 함께, 애플리케이션 및 시스템 전역 키보드 단축키를 사용자 지정할 수 있는 설정 페이지를 제공합니다.

## 명령 팔레트 열기

macOS에서는 `Cmd+K`를, 다른 플랫폼에서는 `Ctrl+K`를 누릅니다. `Cmd/Ctrl+Shift+P`로도 열 수 있습니다.

명령 팔레트에서는:

- 현재 화면에서 사용할 수 있는 명령을 검색합니다
- 사이드바를 사용하지 않고 전환할 수 있도록 제목, 프로젝트/리포지토리 레이블 또는 브랜치 이름으로 세션을 찾습니다
- 각 명령 옆에 현재 활성화된 키보드 바인딩을 표시합니다
- 방향키 이동, `Enter`로 실행, `Escape`로 닫기를 지원합니다

현재 화면에 해당하지 않는 명령은 숨겨집니다.

사이드바의 **Search** 항목에서도 동일한 팔레트가 열립니다. 세션 탐색 검색은 대화 본문을 검색하지 않으므로, 현재 대화 안의 텍스트를 찾으려면 [대화 내 검색](/ko/docs/session-search)을 사용하세요.

## 단축키 사용자 지정

**Settings** -> **Keyboard**를 엽니다. 단축키 행을 클릭한 다음 새 키 조합을 누릅니다.

다음과 같은 작업을 할 수 있습니다.

- 명령에 지정된 단축키 변경
- 기존 단축키 바인딩 제거
- 바인딩되지 않은 명령에 단축키 할당
- 모든 애플리케이션 단축키를 기본값으로 초기화
- 저장 전 키 충돌 확인 및 거부

애플리케이션 단축키 변경 사항은 현재 기기에만 저장되며 다른 기기와 동기화되지 않습니다.
브라우저에서 예약된 일부 키 조합은 웹 앱에서 가로챌 수 없습니다.

## 세션 탭 전환

데스크톱 앱에서는 `Cmd/Ctrl+1`부터 `Cmd/Ctrl+8`까지 눌러 해당 번호의 대화 탭으로 바로 이동할 수 있으며,
`Cmd/Ctrl+9`를 누르면 마지막 탭으로 이동합니다. 이는 브라우저의 탭 표시줄과 동일한 규칙입니다.
`Cmd/Ctrl+Shift+,`와 `Cmd/Ctrl+Shift+.`로 이전 탭과 다음 탭으로 이동할 수 있고,
`Cmd/Ctrl+T`를 누르면 새 탭이 열립니다.

## 보낸 메시지 다시 불러오기

대화 입력창(composer)이 비어 있을 때 `Up` 키를 누르면 해당 대화에서 마지막으로 보낸 메시지가 표시됩니다.
`Up`을 계속 누르면 이전 메시지로 거슬러 올라가고, `Down`을 누르면 더 최근 메시지로 이동합니다.
가장 최근 메시지 이후에 `Down`을 한 번 더 누르면 입력창이 다시 비워집니다. 이때 첨부 파일이나 참조된 코멘트는 제외되고 텍스트만 복원됩니다.

글자를 입력하거나 `Left`/`Right` 키를 누르거나 텍스트 안을 클릭하면 불러온 텍스트가 초안으로 유지된 상태에서
일반 편집 모드로 돌아갑니다. 입력창에 이미 텍스트가 들어 있는 경우에는 `Up`과 `Down` 키가 평소처럼 커서를 이동합니다.

## 데스크톱 전역 단축키

데스크톱 앱에는 Lody 창에 포커스가 없을 때도 작동하는 시스템 전역 단축키도 있습니다. 이러한 단축키는
**Global shortcuts** 섹션에 표시되며 별도로 다시 지정할 수 있습니다.

빠른 세션(Quick Session)의 기본 단축키는 `Cmd/Ctrl+Shift+N`입니다. 이 단축키는 작고 독립된 입력창을 열거나 숨겨서,
Lody 기본 창을 앞으로 가져오지 않고도 세션을 시작할 수 있게 해줍니다.

전역 바인딩에는 반드시 `Command`, `Control` 또는 `Alt`가 포함되어야 합니다. 운영 체제나 다른 앱이
이미 해당 키 조합을 사용 중인 경우, Lody는 기존 바인딩을 유지하고 충돌 사실을 알립니다.
