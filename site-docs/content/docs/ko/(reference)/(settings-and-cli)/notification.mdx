# 알림

Lody는 코딩 에이전트 대화가 완료되거나, 권한을 요청하거나, 오류가 발생할 때 기기로 푸시 알림을
보내 세션 상태를 놓치지 않고 확인할 수 있도록 해줍니다.

## 알림 활성화

### 데스크톱 브라우저

데스크톱에서는 **Settings** -> **General** -> **Push Notifications**로 이동해 알림을 활성화하세요.

클릭하면 브라우저에서 알림을 허용할지 묻습니다. **허용**을 클릭하세요.

<NotificationPreview locale="ko" variant="browser" />

### 모바일 앱

모바일에서는 먼저 [Lody 앱을 설치](/ko/docs/mobile)한 다음,
**Settings** -> **General** -> **Push Notifications**에서 알림을 활성화하세요.

<NotificationPreview locale="ko" variant="mobile" />

모바일 알림은 승인 요청, 완료된 작업, 그리고 세션을 계속하기 전에 확인해야 하는 오류를 파악하는 데
유용합니다.
