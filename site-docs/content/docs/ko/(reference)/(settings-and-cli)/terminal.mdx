# 내장 터미널

Lody 데스크톱 앱에는 로컬 세션을 위한 대화형 터미널이 내장되어 있습니다. 현재 세션의 작업 공간에서 바로 열리므로, 외부 터미널로 전환하지 않고도 테스트를 실행하거나 Git 상태를 확인하고 프로젝트 도구를 사용할 수 있습니다.

## 지원 환경

내장 터미널은 현재 다음 환경에서 지원됩니다.

- Electron 데스크톱 앱
- 로컬 머신에 속한 세션
- 작업 공간 디렉터리를 사용할 수 있는 활성 및 비활성 로컬 세션

원격 세션, 모바일 클라이언트, 웹 앱에서는 현재 대화형 터미널을 제공하지 않습니다. 보관되었거나 삭제된 세션에서는 터미널을 열 수 없습니다.

## 터미널 열기 및 관리

하단 바의 터미널 컨트롤을 사용하거나 `Ctrl+\`` 또는 `Cmd/Ctrl+J`를 누르세요. 한 세션에서 최대 8개의 터미널 탭을 열 수 있습니다.

- `+`를 클릭하면 새 터미널을 열 수 있습니다.
- 하단 터미널 바에서 탭을 전환할 수 있습니다.
- 개별 탭을 닫으면 해당 셸 프로세스가 종료됩니다.
- 패널 구분선을 드래그하여 높이를 조절할 수 있습니다.

터미널에 포커스가 있는 상태에서 `Alt+N`을 누르면 새 터미널 탭이 열립니다. 터미널에 포커스가 없을 때 같은 단축키를 누르면 새 세션 탭이 생성됩니다.

## 작업 디렉터리 및 수명 주기

Lody는 인터페이스에서 임의의 경로를 입력받는 대신 세션을 기준으로 작업 디렉터리를 결정합니다. 프로젝트 세션의 경우 세션 워크트리 또는 프로젝트 디렉터리가 작업 디렉터리가 됩니다.

터미널 프로세스는 Lody CLI 데몬이 실행 중인 동안 유지되며, 세션을 전환하거나 인터페이스를 새로고침해도 계속 사용할 수 있습니다. 세션이 보관되거나 삭제되거나 데몬이 중지되면 터미널 프로세스도 종료됩니다. 터미널 기록은 데몬 재시작 시 유지되지 않습니다.

## 테마 및 하단 바

터미널은 ANSI 색상을 포함해 현재 Lody의 라이트/다크 모드를 따릅니다. 하단 바에는 CLI 상태 컨트롤도 있으며, 이를 클릭해 CLI 출력을 표시하거나 숨길 수 있습니다. CLI 출력과 활성 터미널은 동일한 도킹 위치를 공유하며 한 번에 하나만 표시됩니다.

## 글꼴

데스크톱에서 **Settings** -> **Appearance**를 열어 Lody 인터페이스용 시스템 글꼴과 내장 터미널용 시스템 글꼴을 각각 선택할 수 있습니다. 인터페이스 글꼴은 데스크톱 앱 전체에 적용되며, 터미널 글꼴은 터미널 탭에만 적용됩니다. 각 설정을 Lody 기본 글꼴 스택으로 되돌리려면 **Default**를 선택하세요.
