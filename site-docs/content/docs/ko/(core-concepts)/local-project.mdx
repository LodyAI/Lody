# 로컬 프로젝트

Lody는 모든 로컬 작업 디렉터리를 프로젝트로 추가할 수 있도록 지원합니다. 이 작업 흐름에는 데스크톱 앱 사용을 권장합니다. 로컬 프로젝트를 추가하면 Lody가 대화 기록, 파일 diff 보기, Git 브랜치, 세션별 워크트리를 포함해 기기 간 데이터를 실시간으로 동기화합니다.

## 로컬 프로젝트 추가하기

Lody는 여러 가지 추가 방법을 지원합니다.

- 데스크톱 앱에서 `My Projects` 옆의 추가 버튼을 클릭합니다. 로컬 파일 선택기가 열리면 추가할 디렉터리를 선택할 수 있습니다.
- 서버와 같이 데스크톱 환경이 아닌 경우 `npx lody project add [path]`와 같은 [CLI 프로젝트 명령어](/ko/docs/cli#프로젝트-명령어)를 사용하세요.

## 로컬 우선 가용성

데스크톱 앱에서는 네트워크 연결이 끊겨도 로컬 머신에 이미 있는 프로젝트와 세션을 계속 사용할 수 있습니다. 로컬 워크스페이스 카탈로그에서 프로젝트와 세션을 열어 기록을 읽고 작업을 이어갈 수 있으며, 로컬에서 변경한 내용은 그대로 유지되었다가 연결이 복구되면 동기화됩니다.

다른 머신에서 프로젝트를 열거나 새로운 GitHub 데이터를 가져오는 등 클라우드 전용 작업에는 여전히 네트워크 연결이 필요합니다. 또한 다른 기기에서 프로젝트를 삭제하려면 해당 프로젝트를 소유한 머신이 온라인 상태여야 합니다.

## 로컬 프로젝트의 워크트리

이제 로컬 프로젝트도 GitHub 연동 프로젝트와 동일한 워크트리 워크플로를 사용합니다.

- 각 세션에는 필요에 따라 자동으로 생성되는 격리된 전용 워크트리가 할당됩니다.
- 세션이 보관되면 워크트리도 자동으로 회수됩니다.

전체 구조와 설계 배경은 [워크트리](/ko/docs/worktrees)를 참고하세요.

## 코드 에이전트 기록 동기화 (Codex, Claude Code 등)

로컬 프로젝트에서 Codex나 Claude Code를 직접 사용해 왔다면, Lody에서 기존 대화 기록을 가져와 어떤 기기에서든 작업을 이어갈 수 있습니다.

- **Settings → Projects**를 열고 로컬 프로젝트를 선택한 뒤 수동 동기화를 실행하면 Lody가 해당 머신에서 감지한 에이전트의 기록을 가져옵니다.
- 프로젝트가 한 번 동기화되면 Lody에서 새로 시작한 대화도 해당 CLI(Claude Code, Codex 및 기타 지원되는 ACP 기반 에이전트)에 그대로 미러링되어 양쪽 상태가 일치하게 유지됩니다.
- 가져온 대화를 열면 필요할 때마다 최신 내용을 새로고침하므로 기반 CLI에 있는 최신 상태를 항상 확인할 수 있습니다.

## GitHub 외부 프로젝트의 팀 공개 설정

로컬 프로젝트는 기본적으로 비공개이므로 워크스페이스에 참여한 후에도 본인만 볼 수 있습니다.

GitHub에 올라가 있지 않은 프로젝트에서 협업하려면 다음 단계를 따르세요.

1. **Settings → Projects**를 엽니다.
2. 로컬 프로젝트를 선택합니다.
3. 팀 공개 설정(team visibility)을 켭니다.

설정을 켜면 팀원들도 사이드바에서 해당 프로젝트를 보고 세션을 시작할 수 있습니다. [공유 머신](/ko/docs/team#팀-머신-가시성)과 마찬가지로 프로젝트 소유자만 공개 설정을 변경할 수 있으며, 설정을 끄면 다른 멤버의 화면에서 프로젝트가 즉시 숨겨집니다.

## 로컬 프로젝트 원격 액세스

다른 기기(웹, 모바일 또는 다른 데스크톱)에서도 해당 머신 앞에 직접 앉아 있지 않고 소유 머신에 있는 로컬 프로젝트를 살펴볼 수 있습니다.

- 프로젝트의 현재 Git 브랜치 상태를 탐색할 수 있습니다.
- 원격 머신에서 직접 워크트리를 시작한 뒤 어디서든 작업을 이어갈 수 있습니다.

이를 통해 모바일이나 이동 중 노트북 환경에서도 GitHub 연동 프로젝트와 동일한 방식으로 로컬 프로젝트 작업을 진행할 수 있습니다.

## 다른 기기에서 프로젝트 삭제하기

폴더가 다른 기기에 있더라도 데스크톱이나 모바일에서 내 로컬 프로젝트를 삭제할 수 있습니다.

Lody가 해당 머신으로 삭제 요청을 전송하므로 프로젝트를 소유한 기기가 온라인 상태여야 합니다. Lody는 프로젝트를 삭제하기 전에 관련 세션을 보관하고, 소유 머신에 프로젝트의 워크트리 설정을 정리하도록 요청합니다. Lody에서 프로젝트를 삭제해도 원본 프로젝트 폴더는 삭제되지 않습니다.

## 현재 제한 사항

- 로컬 프로젝트에서는 아직 원격 브랜치로 직접 푸시할 수 없지만, 에이전트에게 관련 Git 작업을 처리해 달라고 요청할 수는 있습니다.
