# 종단간 암호화 워크스페이스

종단간 암호화 워크스페이스에서는 대화, 파일, 에이전트 출력 결과를 **사용자가 승인한 기기에서만 읽을 수 있습니다**. Lody 서버는 데이터를 중계하고 저장하지만, 서버 측에서는 읽을 수 없는 암호화된 데이터만 보게 됩니다.

<Callout type="warn">
승인된 기기를 모두 분실하고 복구 파일도 없다면 워크스페이스를 다시는 열 수 없으며, Lody에서도 이를 복구해 드릴 수 없습니다. 워크스페이스를 생성한 직후 복구 파일을 미리 설정해 두세요.
</Callout>

## 일반 워크스페이스와의 차이점

| | 일반 워크스페이스 | 종단간 암호화 워크스페이스 |
| --- | --- | --- |
| 콘텐츠 열람 권한 | 접근 권한이 있는 멤버 및 Lody 서버 | 승인된 기기만 가능 |
| 새 기기 사용 | 로그인 | 로그인 후 승인된 기기에서 승인 |
| 웹 앱 | 바로 사용 가능 | 먼저 브라우저를 승인해야 함 |
| 모든 기기 분실 시 | 다시 로그인 | 복구 파일 또는 패스키 필요 |

## 일상적인 작업

<Steps>
<Step>

**암호화 워크스페이스 확인하기**: 워크스페이스 이름 옆에 자물쇠 아이콘이 표시됩니다. 자물쇠 위에 마우스를 올리면 설명을 볼 수 있습니다.

</Step>
<Step>

**팀원 초대하기**: 설정(Settings) › 일반(General) › 암호화 콘솔 열기(Open encryption console) › 멤버 및 초대(Members & invitations)에서 초대를 보냅니다. 관리자가 승인하면 해당 팀원의 기기로 키가 전달됩니다.

</Step>
<Step>

**새 기기에서 열기**: 새 기기가 자동으로 요청을 보냅니다. 승인된 컴퓨터나 스마트폰에 승인 창이 나타나면 양쪽 화면의 숫자가 일치하는지 확인한 뒤 승인(Authorize)을 선택합니다.

</Step>
<Step>

**팀원과 비교 확인하기**: 보안 코드 및 기록(Security code & history)에서 보안 코드를 비교하여 모든 구성원에게 동일한 멤버와 기기가 표시되는지 확인합니다.

</Step>
<Step>

**복구 수단 설정하기**: 복구(Recovery)에서 복구 파일을 저장하거나 패스키를 추가해 두면 모든 기기를 분실하더라도 워크스페이스를 열 수 있습니다.

</Step>
</Steps>

## 알려진 제한 사항

- 브라우저 환경에서는 Lody 웹사이트가 제공하는 코드가 변조되지 않았는지에 보안이 의존합니다. 이 부분이 중요하다면 데스크톱 또는 모바일 앱을 사용해 주세요.
- 서버에 연결할 수 없는 경우에도 보유한 머신에서는 제한된 시간 동안 계속 작업할 수 있습니다. 단, 팀원 초대, 기기 승인, 키 교체는 다시 온라인 상태가 될 때까지 대기합니다.
