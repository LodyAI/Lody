# 세션 탭

세션 탭을 사용하면 공유 컨텍스트를 잃지 않고 하나의 작업을 여러 작업 화면으로 나눌 수 있습니다. 핵심은 단순히 채팅 창을 늘리는 것이 아니라 **서로 다른 에이전트가 같은 워크스페이스를 재사용**할 수 있다는 점입니다. 각 대화는 고유한 기록을 유지하면서 동일한 파일, 브랜치, 커밋되지 않은 변경 사항을 함께 확인합니다. 메인 채팅과 하위 채팅을 열고 닫을 수 있으며, 이와 함께 파일 미리보기와 diff 보기도 사용할 수 있습니다.

## 탭을 사용하는 경우

- 메인 탭에서 구현을 계속 진행하는 동안 하위 탭에서 현재 변경 사항을 리뷰합니다.
- 코드를 읽으면서 후속 질문을 할 수 있도록 채팅 옆에 파일이나 diff를 열어 둡니다.
- “이 변경 사항 요약하기”, “위험 요소 찾기”, “PR 코멘트 수정하기”처럼 하나의 브랜치를 여러 관점으로 나누어 작업합니다.

## 하위 채팅 만들기

1. 세션을 열고 탭 표시줄에서 `+`를 클릭합니다.
2. 새 탭은 상위 세션의 머신, 프로젝트 또는 저장소, 브랜치, 에이전트 설정, 모델, 권한 기본값을 상속받습니다. 전송하기 전에 해당 머신에 바인딩된 에이전트 역할(Agent Role)을 선택할 수 있으며, 선택한 역할에 따라 초안이 다른 에이전트 유형으로 전환될 수 있습니다.
3. 새 탭에서 첫 번째 메시지를 전송합니다. Lody는 선택한 역할의 실행 설정과 지침을 적용해 하위 세션을 생성합니다. 제목은 프롬프트의 첫 번째 줄로 시작하며, 나중에 탭을 더블클릭해 이름을 변경할 수 있습니다.

하위 탭은 상위 탭과 동일한 작업 디렉터리 컨텍스트를 공유하지만, 각 탭은 고유한 대화 기록을 유지합니다. 따라서 동일한 작업을 중심으로 병렬 리뷰나 후속 작업을 진행할 때 유용합니다.

## 파일 및 diff 탭

- 대화에서 파일 경로를 클릭해 파일 미리보기 탭을 엽니다.
- 라운드 단위 diff에서 파일을 클릭해 diff 탭을 엽니다.
- `Files` 또는 `Changes` 사이드바에서 파일을 클릭해 뷰어 탭으로 엽니다.

데스크톱에서는 뷰어 탭이 분할 워크스페이스를 구성합니다. 왼쪽에는 채팅이 유지되고 오른쪽에는 활성 파일 또는 diff가 표시됩니다. 모바일에서는 작은 화면에서도 읽기 쉽도록 파일이나 diff가 포커스된 화면으로 열립니다.

## 탭 관리

- 탭을 드래그하여 순서를 변경할 수 있습니다. 변경된 순서는 현재 브라우저에 저장됩니다.
- 채팅 탭을 더블클릭해 이름을 변경할 수 있습니다.
- 메인 대화 탭과 하위 대화 탭은 닫을 수 있습니다. 닫기 상태는 워크스페이스 전체에 공유되며, 탭을 닫더라도 에이전트가 중지되거나 대화가 보관되거나 worktree가 삭제되지는 않습니다.
- 활성 대화를 닫으면 인접한 탭이 선택됩니다. 남은 탭이 없으면 같은 워크스페이스에 로컬 새 대화 초안이 열리며, 기존 초안은 입력 내용을 그대로 유지합니다. 실제 세션은 전송할 때만 생성됩니다. 닫힌 대화는 다시 열 수 있는 상태로 유지됩니다.
- 기록 버튼에는 이전에 보관된 탭을 포함해 닫힌 대화 목록이 표시됩니다. 보관된 대화를 다시 열면 보관 상태에서도 함께 복원됩니다.
- 다시 열면 탭이 모든 사람에게 표시되지만, 본인 화면에서만 해당 탭이 선택됩니다. 파일 및 diff 탭은 기존의 로컬 동작을 유지합니다.
