# Уведомления

Lody отправляет push-уведомления на ваши устройства, когда диалог с кодинг-агентом завершается, агент запрашивает разрешение или возникает ошибка, чтобы вы всегда были в курсе статуса сессии.

## Включение уведомлений

### Десктопный браузер

На компьютере перейдите в **Settings** -> **General** -> **Push Notifications**, чтобы включить уведомления.

После нажатия браузер спросит, разрешить ли показ уведомлений. Нажмите **Разрешить**.

<NotificationPreview locale="ru" variant="browser" />

### Мобильное приложение

На мобильном устройстве сначала [установите приложение Lody](/ru/docs/mobile), а затем включите уведомления в разделе
**Settings** -> **General** -> **Push Notifications**.

<NotificationPreview locale="ru" variant="mobile" />

Мобильные уведомления удобны для отслеживания запросов на подтверждение, завершённых задач и сбоев, которые нужно проверить перед продолжением сессии.
