# Палитра команд и сочетания клавиш

В Lody есть палитра команд для быстрого поиска действий и сессий, а также страница настроек, на которой можно изменить сочетания клавиш приложения и системные горячие клавиши.

## Открытие палитры команд

Нажмите `Cmd+K` на macOS или `Ctrl+K` на других платформах. Открыть её также можно сочетанием `Cmd/Ctrl+Shift+P`.

Палитра:

- ищет команды, доступные в текущем представлении
- находит сессии по названию, метке проекта/репозитория или имени ветки, чтобы вы могли переключаться между ними без боковой панели
- показывает активное сочетание клавиш рядом с каждой командой
- поддерживает навигацию клавишами со стрелками, `Enter` для запуска и `Escape` для закрытия

Команды, не применимые к текущему экрану, скрываются.

Пункт **Search** на боковой панели открывает эту же палитру. Поиск для перехода к сессиям не ищет по тексту переписки; чтобы найти текст внутри текущего диалога, используйте [Поиск по диалогу](/ru/docs/session-search).

## Настройка сочетаний клавиш

Откройте **Settings** -> **Keyboard**. Нажмите на строку с сочетанием клавиш, а затем нажмите новую комбинацию.

Вы можете:

- переназначить команду
- удалить привязку клавиш
- назначить сочетание команде, у которой его ещё нет
- сбросить все сочетания клавиш приложения к значениям по умолчанию
- увидеть конфликты и отклонить их до сохранения

Изменения сочетаний клавиш приложения сохраняются на текущем устройстве и не синхронизируются с другими устройствами. Некоторые комбинации, зарезервированные браузером, не могут быть перехвачены в веб-приложении.

## Переключение вкладок сессий

В десктопном приложении сочетания от `Cmd/Ctrl+1` до `Cmd/Ctrl+8` сразу переходят к соответствующей вкладке диалога, а `Cmd/Ctrl+9` переходит к последней вкладке — по тому же принципу, что и в панели вкладок браузеров. `Cmd/Ctrl+Shift+,` и `Cmd/Ctrl+Shift+.` переключают на предыдущую и следующую вкладку, а `Cmd/Ctrl+T` открывает новую вкладку.

## Восстановление отправленных сообщений

В поле ввода диалога нажмите `Up`, когда поле пустое, чтобы показать последнее сообщение, отправленное вами в этом диалоге. Продолжайте нажимать `Up`, чтобы вернуться к более ранним сообщениям, и `Down`, чтобы перейти вперёд; нажатие `Down` после самого нового сообщения снова очищает поле ввода. Возвращается только текст — без вложений и упомянутых комментариев.

При вводе текста, нажатии `Left`/`Right` или клике по тексту вы возвращаетесь к обычному редактированию с восстановленным текстом в качестве черновика. Когда в поле ввода уже есть текст, `Up` и `Down` перемещают курсор как обычно.

## Глобальные сочетания клавиш в десктопном приложении

В десктопном приложении также есть системные сочетания клавиш, которые работают, даже когда окно Lody не в фокусе. Они находятся в разделе **Global shortcuts** и переназначаются отдельно.

По умолчанию для Quick Session назначено сочетание `Cmd/Ctrl+Shift+N`. Оно открывает или скрывает небольшое отдельное окно ввода, чтобы вы могли запустить сессию, не выводя основное окно Lody на передний план.

Глобальные сочетания должны включать `Command`, `Control` или `Alt`. Если операционная система или другое приложение уже занимает выбранную комбинацию, Lody сохранит прежнюю привязку и сообщит о конфликте.
