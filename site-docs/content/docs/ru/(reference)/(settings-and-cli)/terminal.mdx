# Встроенный терминал

Десктопное приложение Lody включает интерактивный терминал для локальных сессий. Он открывается в
рабочем пространстве текущей сессии, поэтому вы можете запускать тесты, проверять состояние Git
или использовать инструменты проекта, не переключаясь во внешний терминал.

## Доступность

В настоящее время встроенный терминал поддерживается в:

- десктопном приложении Electron
- сессиях, принадлежащих локальной машине
- активных и неактивных локальных сессиях, для которых доступен каталог рабочего пространства

Удалённые сессии, мобильные клиенты и веб-приложение сейчас не поддерживают интерактивный
терминал. В архивированных или удалённых сессиях открыть его нельзя.

## Открытие терминалов и управление ими

Используйте элемент управления терминалом на нижней панели или нажмите `Ctrl+\`` либо
`Cmd/Ctrl+J`. В одной сессии можно открыть до 8 вкладок терминала.

- Нажмите `+`, чтобы открыть ещё один терминал.
- Переключайтесь между вкладками на нижней полосе терминала.
- Закройте отдельную вкладку, чтобы остановить её процесс оболочки (shell).
- Перетащите разделитель панели, чтобы изменить её высоту.

Когда фокус находится в терминале, сочетание `Alt+N` открывает ещё одну вкладку терминала. Это
же сочетание создаёт новую вкладку сессии, когда фокус находится вне терминала.

## Рабочий каталог и жизненный цикл

Lody определяет рабочий каталог на основе сессии, а не принимает произвольный путь из интерфейса.
Для проектной сессии это worktree сессии или каталог проекта.

Процессы терминала остаются доступными, пока работает демон Lody CLI — в том числе при
переключении сессий или перезагрузке интерфейса. Они завершаются при архивировании или удалении
сессии, а также при остановке демона. История терминала не сохраняется между перезапусками демона.

## Тема оформления и нижняя панель

Терминал следует текущему светлому или тёмному режиму Lody, включая цвета ANSI. На нижней панели
также находится элемент управления статусом CLI; нажмите на него, чтобы показать или скрыть вывод
CLI. Вывод CLI и активный терминал делят одну и ту же область закрепления и отображаются по
одному за раз.

## Шрифты

В десктопном приложении откройте **Settings** -> **Appearance**, чтобы выбрать системный шрифт для
интерфейса Lody и ещё один — для встроенного терминала. Шрифт интерфейса применяется ко всему
десктопному приложению; шрифт терминала применяется только к вкладкам терминала. Выберите
**Default**, чтобы вернуть любой из параметров к встроенному стеку шрифтов Lody.
