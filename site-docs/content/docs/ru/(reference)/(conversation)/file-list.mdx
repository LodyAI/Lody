# Список файлов

В Lody есть два представления файлов:

- **Файлы проекта** показывают локальный проект или репозиторий GitHub без необходимости запускать сессию.
- **Файлы сессии** показывают рабочее дерево текущей сессии, включая файлы, изменённые агентом.

## Просмотр файлов проекта

В мобильном приложении откройте проект на вкладке **Проекты**, затем переключитесь на **Файлы**. Вы можете открывать вложенные папки и просматривать текстовые файлы прямо на экране проекта. Это работает как для локальных проектов, так и для репозиториев GitHub, если машина-владелец или провайдер репозитория доступны.

Просмотр файлов проекта удобен, когда нужно изучить репозиторий перед началом нового диалога или быстро найти файл вдали от компьютера.

## Просмотр файлов сессии

Нажмите кнопку раскрытия боковой панели в правом верхнем углу интерфейса чата, чтобы открыть панель «Файлы и изменения».

На вкладке `Files` отображается полный список файлов текущего диалога. Файлы, изменённые в ходе текущего диалога, подсвечиваются, чтобы их было проще найти.

Нажмите на текстовый файл, чтобы открыть его предпросмотр прямо в сессии. Длинные строки переносятся автоматически — это упрощает чтение логов, сгенерированных файлов и компактных исходных файлов на панели предпросмотра.

## Быстрое открытие и поиск

В просмотре файлов сессии воспользуйтесь поиском по файлам, чтобы найти проиндексированные файлы и открыть нужный без прокрутки дерева. Когда открыт текстовый файл, нажмите на значок поиска на панели инструментов файла, чтобы открыть поиск внутри файла.

## Предпросмотр Markdown

По умолчанию файлы Markdown открываются в режиме исходного кода. Нажмите на значок глаза на панели инструментов файла, чтобы переключиться в режим отрендеренного предпросмотра; нажмите ещё раз, чтобы вернуться к исходному коду. При наведении курсора на значок можно быстро заглянуть в предпросмотр, не выходя из редактора.

## Редактирование в реальном времени

Если файл сессии обслуживается провайдером совместной работы в реальном времени, является текстовым, а у вашей роли есть права на запись, просмотрщик переходит в режим редактирования. Изменения сохраняются обратно в рабочее дерево сессии и синхронизируются с другими участниками в реальном времени.

Если файл доступен только для чтения, относится к истории, слишком велик, является бинарным или хост-машина находится офлайн, Lody оставляет просмотрщик в режиме только для чтения и отображает текущий статус доступности в строке состояния файла.
