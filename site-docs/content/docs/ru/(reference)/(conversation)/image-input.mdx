# Ввод изображений

Lody поддерживает ввод изображений в чате сессии. Вы можете отправлять скриншоты, макеты интерфейса, снимки ошибок и другие изображения как часть контекста запроса.

<ImageInputPreview locale="ru" />

## Сценарии использования

- Объясняйте визуальные баги с помощью скриншотов.
- Просите ИИ считывать детали интерфейса с изображений.
- Объединяйте визуальные материалы с контекстом кода в одном запросе.

## Как использовать

1. Откройте чат сессии.
2. Откройте меню вложений `+` и выберите **Загрузить изображение**, вставьте изображение из буфера обмена или
   перетащите файлы изображений в любое место интерфейса сессии.
3. Введите инструкцию и отправьте сообщение.

К одному сообщению можно прикрепить до 8 изображений размером не более 5 МиБ каждое. Более крупные изображения
можно отправить как обычные файлы через [Файловые вложения](/ru/docs/file-attachments).

<Callout type="warn">

Поддержка изображений зависит от текущей модели. Убедитесь, что выбранная модель поддерживает работу с изображениями.

</Callout>
