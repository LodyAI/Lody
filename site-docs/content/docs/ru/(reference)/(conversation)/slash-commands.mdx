# Слэш-команды

Введите `/` в начале поля ввода чата, чтобы открыть меню команд, которые предоставляет текущий
агент, а также доступных быстрых промптов (Prompt Shortcuts) рабочего пространства. К примерам команд
агента относятся `/review`, `/compact` и `/undo`, если подключённый агент их поддерживает.

Команды агента **предоставляются самим агентом**, а не Lody. Каждая конфигурация агента (Agent Config)
объявляет собственный список на этапе обнаружения возможностей, поэтому доступные команды зависят от
типа CLI (Claude Code, Codex, Kimi, OpenCode или любой среды выполнения из реестра ACP) и версии,
установленной на машине. Быстрые промпты (Prompt Shortcuts) задаются на уровне рабочего пространства и
подчиняются собственным правилам видимости и области действия.

## Открытие меню

- Введите `/` первым символом нового сообщения.
- По мере ввода доступные результаты из обоих источников отображаются в порядке релевантности:
  сначала точные совпадения имён, затем по префиксу, началу слов, вхождению текста и более мягкие совпадения.
  В каждой строке указан её источник. Если ввести только `/`, источники отображаются отдельными группами.
- Нажимайте `↑` / `↓` для перемещения между пунктами и `Home` / `End` для перехода к первому или последнему пункту.
- Нажмите `Enter`, чтобы вставить выделенную команду, или `Tab` / `Escape`, чтобы закрыть меню без вставки.

Если совпадений нет, меню сообщит об этом. Текст останется в поле ввода как обычное содержимое.

## Что делают команды

Поскольку команды поступают от агента, их поведение определяется документацией этого агента.
К распространённым примерам, которые поддерживают популярные агенты, относятся:

| Команда    | Типичное поведение                                                  |
| ---------- | ------------------------------------------------------------------- |
| `/review`  | Попросить агента проверить текущий diff или недавние изменения      |
| `/compact` | Сжать и суммировать диалог, чтобы освободить место в контексте      |
| `/undo`    | Откатить последнее изменение, внесённое агентом                     |

Полный список и точное поведение уточняйте в документации самого агента.

## Обновление списка команд

Список кэшируется для каждой конфигурации агента на каждой машине. После установки новой версии CLI
или изменения окружения для Agent Config обновите кэш, чтобы появились новые команды:

- Через веб-интерфейс: откройте **Agent Config**, выберите нужную конфигурацию и обновите параметры.
- Через CLI: выполните `lody agent-config refresh-capabilities <idOrName>` на используемой машине.

Подробнее см. в разделах [Конфигурация агента](/ru/docs/quickstart) и [Команды CLI](/ru/docs/cli#agent-config-refresh-capabilities).
