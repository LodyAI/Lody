# Упоминания

Lody дополняет поле ввода поддержкой упоминаний. Введите `@`, чтобы открыть меню упоминаний, где можно
выбрать диалоги, файлы, Issue, Pull Request, Skills или Agent Roles. Символ `$` по-прежнему служит прямым
быстрым способом вызова Skills.

## Упоминания диалогов

Введите `@`, выберите **Sessions** и укажите другой диалог, чтобы сослаться на него. Попросите текущего
агента связаться с этой сессией, прочитать нужный контекст, обменяться выводами или запросить ревью.
Например, упомяните сессию реализации и попросите текущего агента проверить её последний коммит и
отправить свои замечания обратно.

Упомянутая сессия может использовать другого агента или работать на другой подключённой машине. Доступ
по-прежнему определяется правами рабочего пространства, а целевая машина должна быть в сети для
выполнения работы. Упоминание лишь указывает на сессию — обязательно добавьте инструкцию, каким
контекстом нужно обменяться или какую задачу выполнить.

Доступные операции описаны в разделе [Управление сессиями агентов](/ru/docs/session-orchestration/), а
обмениваться контекстом и запрашивать ревью между агентами и машинами поможет
[руководство по совместной работе нескольких агентов](/ru/docs/agent-collaboration/).

## Упоминания файлов

Введите `@` и выберите **Files**. Продолжайте ввод для нечёткого поиска по имени файла или пути к нему.
Используйте клавиши со стрелками вверх и вниз для выбора, затем нажмите Enter для подтверждения.
Упомянутые файлы передаются кодинг-агенту в контекст промпта в виде полных путей.

## Упоминания Issue и Pull Request

После выбора репозитория на главной странице введите `@`, чтобы открыть меню упоминаний, затем выберите
**Issues** или **Pull Requests**, чтобы упомянуть элемент из текущего репозитория.

<MentionPreview locale="ru" kind="issue" />

Используйте клавиши со стрелками вверх и вниз для выбора, затем нажмите Enter для подтверждения. Lody
вставит выбранный элемент в поле ввода в виде `#<number>` и добавит его контекст в промпт, чтобы агент
мог выполнять такие задачи, как `Fix #12` или `Review the implementation in #56`.

## Упоминания Skills

Введите `$`, чтобы просмотреть Skills, доступные для выбранного проекта и машины агента. Продолжайте
ввод, чтобы отфильтровать список по имени, а затем выберите Skill с помощью клавиш со стрелками и `Enter`.

Lody сохраняет в поле ввода читаемый токен `$skill-name`. При отправке сообщения он добавляет
соответствующий путь к `SKILL.md`, чтобы агент мог загрузить эти инструкции и следовать им.

Подробнее о местах поиска, области действия на уровне проекта и на глобальном уровне, а также о работе в
офлайн-режиме см. в разделе [Skills](/ru/docs/skills).
