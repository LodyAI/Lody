# Просмотр diff

Lody синхронизирует изменения файлов, внесённые агентом разработки, в реальном времени после каждого раунда диалога.

## Diff для текущего раунда

Когда вы просите ИИ отредактировать код и изменить файлы, Lody сравнивает состояние файлов до и после этого раунда диалога. В конце раунда под облачком сообщения агента разработки отображаются все изменённые файлы и количество изменённых строк.

<ConversationDiffPreview locale="ru" />

Нажмите на любой файл, чтобы открыть вкладку с diff и перейти к нему. Первый переход может занять немного больше времени, пока данные синхронизируются и загружаются.

<DiffViewerPreview locale="ru" />

Вы также можете нажать на элемент раскрытия на панели, чтобы просмотреть неизменённые фрагменты файла.

## Комментарии к строкам

Наведите курсор на строку в diff, доступную для комментирования, и нажмите `+` рядом с номером строки, чтобы добавить комментарий в формате Markdown. На мобильных устройствах коснитесь такой строки, чтобы открыть поле ввода комментария. Комментарии поддерживают ветки ответов, отметку о решении (resolve/unresolve) и отправку всей ветки обратно в чат, чтобы агент обработал замечания.

Если сессия связана с GitHub PR, комментарии Lody можно синхронизировать как комментарии к строкам в GitHub PR Review. Существующие ветки ревью из GitHub также отображаются в diff Lody, чтобы вы могли отвечать в контексте.

Полное описание рабочего процесса см. в разделе [Комментарии к diff](/ru/docs/diff-comments).

## Diff за весь диалог

Помимо изменений за отдельный раунд, вы можете нажать кнопку раскрытия боковой панели в правом верхнем углу интерфейса чата, чтобы открыть боковую панель «Файлы и изменения» (Files and Changes).

На вкладке `Changes` можно просмотреть все изменения файлов в текущем диалоге.

## Удалённый просмотр

Когда машина, на которой запущена сессия, находится в сети, удалённые устройства могут открывать изменённые файлы и diff через тот же провайдер файлов сессии, который используется в десктопном интерфейсе. Если diff или файл ещё синхронизируется, Lody показывает текущее состояние загрузки или недоступности, не пытаясь угадать содержимое по последнему снимку рабочего пространства.
