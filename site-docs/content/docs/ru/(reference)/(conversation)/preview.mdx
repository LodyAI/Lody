# Lody Preview

Lody Preview позволяет открыть в интерфейсе Lody живой предпросмотр локального dev-сервера, запущенного в рамках сессии. Это удобно, когда агент меняет код интерфейса и вы хотите оценить результат на десктопе, планшете, смартфоне или другом устройстве, не копируя вручную URL-адреса localhost.

## Запуск предпросмотра

Попросите агента запустить dev-сервер и воспользоваться Lody Preview, например:

```text
Start the Vite dev server and use Lody Preview to check the page.
```

Когда Lody обнаружит доступный для сессии предпросмотр, откройте вкладку **Preview**. В локальной десктопной
сессии включите **Design mode**, чтобы открыть локальный предпросмотр напрямую — для него не нужен туннель или
внешний URL для совместного доступа. Для удалённой сессии или чтобы поделиться предпросмотром, выберите **Preview Remote** и
нажмите **Create connection**. Завершить предпросмотр можно кнопкой питания в шапке окна предпросмотра.

## Проверка вёрстки

На панели инструментов предпросмотра доступны:

- пресеты области просмотра для десктопа, планшета и смартфона
- переключение между портретной и альбомной ориентацией
- элементы управления масштабом, подгонкой по размеру и сбросом
- режим «рука» для панорамирования перетаскиванием и масштабирования жестом pinch или прокруткой с Ctrl
- кнопка открытия во внешнем браузере для страниц, которым нужна отдельная вкладка
- кнопка копирования ссылки для совместного доступа к предпросмотру

Используйте эти инструменты, чтобы проверять адаптивные брейкпоинты, переполнение контента, области нажатия и изменения вёрстки, оставляя диалог и diff под рукой.

## Визуальные аннотации

Включите режим аннотирования, нажмите на элемент интерфейса в предпросмотре и напишите комментарий о том, что нужно изменить. Lody привяжет комментарий к выбранному элементу и сможет отправить эту ссылку в чат, чтобы у агента были одновременно и конкретный визуальный элемент, и ваша инструкция.

Визуальные аннотации лучше всего подходят для точечной обратной связи по интерфейсу: отступов, выравнивания, текстов, цветов или проблем адаптивной вёрстки.

## Примечания

- Локальный предпросмотр в режиме Design mode требует, чтобы локальный dev-сервер продолжал работать. Для удалённых предпросмотров также необходимо,
  чтобы машина сессии оставалась в сети.
- Некоторые приложения могут блокировать встроенный предпросмотр или требовать функций браузера, которые лучше работают в отдельной вкладке.
- Если предпросмотр устарел, обновите его или попросите агента перезапустить dev-сервер.
