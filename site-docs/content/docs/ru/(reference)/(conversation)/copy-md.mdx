# Копирование диалогов

## Копирование отдельного сообщения

В интерфейсе чата под каждым блоком сообщения есть кнопка копирования. Нажмите её, чтобы скопировать это сообщение.

## Копирование всего диалога

Откройте меню сессии `...`, разверните **Copy** и выберите **Copy as Markdown**. Lody скопирует видимую историю диалога в удобном для повторного использования формате Markdown.

В этом же подменю можно скопировать путь к рабочему пространству сессии или URL сессии, если эти значения доступны.

Копирование в Markdown — это сохранение записи, а не живая передача управления. Копирование URL сессии также не предоставляет доступ команде. Чтобы пригласить коллегу в ту же сессию, см. раздел [Передача сессии агента разработки](/ru/docs/session-handoff). Разница между ссылкой для обмена и передачей управления описана в разделе [Ссылка на сессию или передача управления](/ru/docs/compare/share-link-vs-live-handoff).
