# Вывод изображений

Lody может возвращать до 8 изображений непосредственно в сессию. Вы можете попросить агента о чём-то вроде `Запустите dev-сервер фронтенда, дождитесь загрузки главной страницы и отправьте мне скриншот.` Lody автоматически загрузит полученные изображения обратно в чат.

Если выбранная среда выполнения поддерживает генерацию изображений (например, генерацию изображений в Codex), сгенерированные изображения также могут появляться в диалоге без выхода из сессии.

## Сгенерированные изображения

При генерации изображений в Codex Lody сохраняет полученное изображение в том же диалоге, где находятся исходный промпт и все последующие запросы. Это позволяет легко запрашивать правки, сравнивать варианты или вернуться к созданному изображению позже.

## Сценарии использования

- Быстро проверять результаты работы UI с мобильного устройства.
- Запрашивать у агента визуальный вывод с вашей локальной машины.
- Просматривать сгенерированные изображения рядом с промптом и контекстом реализации.

## Как использовать

1. Откройте чат сессии.
2. Попросите агента сделать скриншот или выполнить другое действие, результатом которого является изображение. Lody автоматически загрузит изображение в диалог.
