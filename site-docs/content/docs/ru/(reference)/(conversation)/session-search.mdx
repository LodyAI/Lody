# Поиск по диалогу

Поиск по диалогу помогает восстановить контекст в длинных сессиях. Он ищет по тексту
диалога: вашим сообщениям, ответам агента, его размышлениям и предложенным планам —
включая текст прогресса и размышления, скрытые внутри свёрнутой рабочей группы
завершённого раунда.

Вызовы инструментов не индексируются: их заголовки, пути к файлам, входные и выходные
данные JSON, команды и вывод терминала, а также diff в поиск не попадают.
Структурированные чек-листы планов, цели и вывод скриптов worktree также исключены.
При этом путь к файлу или фрагмент кода, написанный в сообщении или предложенном
плане, по-прежнему можно найти как текст диалога.

Этот поиск отличается от [глобального поиска для навигации по сессиям](/ru/docs/keyboard-shortcuts#открытие-палитры-команд):
пункт **Search** на боковой панели и сочетание `Cmd/Ctrl+K` открывают палитру команд,
которая ищет сессии по названию, метке проекта или репозитория и имени ветки. Она
переключает между сессиями, не выполняя поиск по тексту диалога.

## Открытие поиска

- Откройте меню сессии и выберите **Find in session**.
- На компьютере нажмите `Ctrl+F`; на macOS нажмите `Cmd+F`.

Строка поиска появится поверх диалога, не заменяя поле ввода.

## Переход по результатам

- Совпадающий текст подсвечивается по мере ввода.
- Счётчик показывает текущий результат и общее количество совпадений.
- Нажмите `Enter`, чтобы перейти к следующему совпадению.
- Нажмите `Shift+Enter` или стрелку вверх, чтобы перейти к предыдущему совпадению.
- Если ничего не найдено, счётчик показывает `0 / 0`.

Активный результат прокручивается в область видимости, а если совпадение находится
внутри свёрнутой рабочей группы или карточки размышлений, она раскрывается.

## Очистка и закрытие

Нажмите `Escape` один раз, чтобы очистить текущий запрос. Нажмите `Escape` ещё раз,
чтобы закрыть поиск.
