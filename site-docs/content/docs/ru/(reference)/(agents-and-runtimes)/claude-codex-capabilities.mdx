# Возможности Claude и Codex

Lody определяет возможности среды выполнения на основе выбранной конфигурации агента (Agent Config) и отображает поддерживаемые функции Claude Code и Codex прямо в интерфейсе диалога.

Если какая-либо возможность отсутствует после изменения настроек агента, обновите возможности этого Agent Config в разделе **Settings** -> **Agent Config** или выполните команду `lody agent-config refresh-capabilities <idOrName>` на машине, которой принадлежит эта конфигурация.

## Claude Code

### Корректировка (Steer) запущенной задачи

Пока Claude Code работает, используйте **Steer**, чтобы скорректировать направление работы, не останавливая активную задачу и не начиная всё заново. Установите **Settings** -> **General** -> **Queued message behavior** в значение **Guide**, чтобы направлять (steer) сообщения, отправленные во время занятости агента, либо выберите **Steer** для первого сообщения в очереди. Lody удерживает сообщение в ожидании, пока Claude Code не подтвердит применение новой инструкции, а затем продолжает потоковый вывод ответа в скорректированный ход.

Корректировка основной задачи не отменяет автоматически фоновые задачи Claude Code. Claude Code сам определяет, соответствуют ли эти задачи новому направлению, поэтому вы можете перенаправить основную работу, не теряя полезный параллельный прогресс.

### Слэш-команды

Claude Code может предоставлять слэш-команды, такие как `/review`, `/compact` или `/undo`. Введите `/` в начале поля ввода, чтобы просмотреть команды, доступные для текущей конфигурации.

### AskUserQuestion

Во время выполнения задачи Claude Code может задавать уточняющие вопросы. Lody отображает такие запросы в виде интерактивных карточек с выбором одного или нескольких вариантов, а также с полем для собственного ответа, после чего отправляет ваш ответ обратно агенту.

### Fast Mode

Некоторые конфигурации Claude Code предоставляют переключатель Fast Mode — кнопку с молнией (⚡) в выборе режима под полем ввода. Включите его для ускоренного профиля ответов; во всплывающей подсказке указан компромисс (примерно в 2,5 раза быстрее при более высокой стоимости за токен). Переключатель отображается только в том случае, если выбранная конфигурация поддерживает эту опцию, а ваш выбор запоминается для каждой сессии и применяется к следующему отправленному сообщению.

### Фоновые задачи

Когда Claude Code переносит часть работы в фоновые задачи — субагентов или фоновые команды оболочки — Lody отображает панель задач прямо в ленте диалога:

- Пока задачи выполняются, панель остаётся развёрнутой с индикатором загрузки и заголовком **"Waiting on N background tasks"**, поэтому чат не блокируется на время их работы.
- В каждой строке отображается исполнитель задачи (тип субагента, имя workflow или `Bash` / `Task`), опциональное описание и инструмент, который выполняется в данный момент.
- После завершения всех задач панель сворачивается в сводку **"N background tasks"**, которую можно развернуть для просмотра каждой задачи, включая использованные токены и инструменты.

Панель только отображает прогресс — она не позволяет отменять отдельные задачи.

### Запланированные задачи

Claude Code также может планировать будущие запуски и поддерживать сессию активной для их обработки. На панели над полем ввода отображается **"Session will continue · N scheduled tasks pending"**; разверните её, чтобы увидеть каждую запись:

- Время следующего запуска с обратным отсчётом в реальном времени (**"in 5 min"**, **"firing now…"**).
- Метку типа — **Wakeup** для разового возобновления или **Scheduled** для запуска по cron — а также значок **Recurring**, если расписание повторяется.
- Опциональную сводку с описанием того, что будет запущено.

Разовые пробуждения (wakeup) исчезают из списка вскоре после срабатывания; повторяющиеся расписания остаются в списке и переходят к следующему времени запуска. Панель доступна только для чтения.

## Codex

### Корректировка (Steer) запущенной задачи

Вы также можете использовать **Steer** во время работы Codex. Установите **Queued message behavior** в значение **Guide** либо выберите **Steer** для первого сообщения в очереди. Codex добавляет инструкцию в тот же активный ход вместо того, чтобы отменять его или создавать отдельный ход Codex. Lody продвигает диалог вперёд только после того, как Codex подтвердит применение корректировки.

Корректировка (steer) может ненадолго оставаться в состоянии **Pending**, пока Codex не дойдёт до точки, где сможет применить инструкцию. При этом используются модель, режим и конфигурация активного хода. Если сообщение в очереди запрашивает другие параметры, Lody оставляет его в ожидании, чтобы вы могли сохранить эти параметры и при необходимости воспользоваться действием **Interrupt and send now**.

### Слэш-команды

Codex также может предоставлять слэш-команды через обнаружение возможностей. Доступный список зависит от установленной версии Codex и выбранного Agent Config.

### Fast Mode

Fast Mode для Codex можно переключать в элементах управления сессией, когда выбранная конфигурация Codex поддерживает эту опцию. Используйте его, если хотите получить более быстрый профиль ответов для задачи.

### Генерация изображений

Когда Codex формирует сгенерированное изображение, Lody загружает его обратно в диалог, чтобы промпт, результат и дальнейшая работа оставались в одном контексте.

### Цели (Goals)

Функция Goals в Codex позволяет хранить в сессии видимую цель задачи и статус её выполнения. Сначала включите эту функцию в Codex командой:

```bash
codex features enable goals
```

После этого Lody сможет отображать статус цели в интерфейсе диалога и сессии. Каждый запуск цели также сообщает затраченное время и расход токенов, чтобы вы могли с первого взгляда оценить ресурсы, потраченные на достижение цели.
