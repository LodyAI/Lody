# Типы сред выполнения CLI

Lody поддерживает все среды выполнения CLI, опубликованные в [ACP Registry](https://agentclientprotocol.com/get-started/registry).
Список доступных сред выполнения загружается из реестра, поэтому на этой странице не поддерживается отдельный
статический список поставщиков или команд.

## Среды выполнения из реестра

1. Откройте **Settings** -> **Agent Config**.
2. Нажмите кнопку добавления.
3. Введите название конфигурации.
4. Выберите нужный тип CLI в списке выбора из реестра.
5. Добавьте все необходимые переменные окружения.
6. Нажмите **Test**, когда эта кнопка появится. Это проверит, что Lody может запустить среду выполнения и считать
   её возможности, включая поддерживаемые модели и режимы среды выполнения.
7. Сохраните конфигурацию и выберите её при создании диалога.

Поддержка реестра означает, что Lody может автоматически подхватывать новые записи сред выполнения ACP по мере их добавления в upstream. При этом на хост-машине по-прежнему должны быть настроены вход в систему и учётные данные, а также установлены команда и зависимости выбранной среды выполнения в соответствии с её собственной документацией.

## Пользовательский ACP-агент

Если ваш агент совместим с ACP, но не опубликован в реестре, выберите **Custom ACP** в разделе
**Settings** -> **Agent Config**.

1. Введите название конфигурации.
2. Укажите **Custom ACP** в поле **CLI Type**.
3. Заполните поле **Launch command** командой, которая запускает агента через stdio.
4. Добавьте все необходимые переменные окружения в той же конфигурации агента.
5. Нажмите **Test**, чтобы убедиться, что Lody может запустить агента и считать его возможности.
6. Сохраните конфигурацию и выберите её при создании диалога.

Пример команды запуска:

```bash
npx -y my-acp-agent --stdio
```

Команда запуска разбирается на исполняемую команду и аргументы и запускается напрямую. Кавычки
поддерживаются для аргументов с пробелами, однако возможности оболочки — такие как конвейеры (pipes), перенаправления, раскрытие шаблонов (glob)
и `$VARS` — не вычисляются. Вместо этого задавайте переменные окружения в конфигурации агента (Agent Config).

## Примечания

- Некоторые среды выполнения из реестра всё ещё могут находиться на экспериментальной стадии в upstream.
- Перед использованием убедитесь, что необходимые учётные данные для входа уже настроены на хосте, где
  запускается Lody CLI.
- Локальные типы сред выполнения требуют предварительной установки соответствующей команды на хосте.
- Доступность моделей зависит от выбранной среды выполнения, состояния локальной установки и прав
  учётной записи.
