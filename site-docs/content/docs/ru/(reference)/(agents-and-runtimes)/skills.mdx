# Навыки

Lody обнаруживает Agent Skills (навыки агентов) в поддерживаемых каталогах навыков проекта и глобальных каталогах на машине. Навык (Skill) представляет собой каталог с файлом `SKILL.md`, содержащим переиспользуемые инструкции для агента разработки.

Навыки в Lody доступны только для чтения: Lody может обнаруживать их, отображать и ссылаться на них, но не устанавливает, не редактирует и не синхронизирует файлы навыков.

## Просмотр навыков

На компьютере откройте **Settings** -> **Projects**, выберите проект и перейдите на вкладку **Skills**.

На мобильном устройстве откройте проект, перейдите в **Settings** и выберите **Project skills**.

Список сгруппирован по пути к источнику и отображает доступные метаданные: название, описание, версию, автора, область действия и статус символической ссылки. Откройте нужный навык, чтобы прочитать содержимое файла `SKILL.md` в отформатированном виде.

## Навыки проекта и глобальные навыки

- **Навыки проекта** считываются из распознанных каталогов навыков внутри локального проекта или в ветке по умолчанию проекта на GitHub.
- **Глобальные навыки** считываются из распознанных каталогов текущего пользователя ОС на машине, где запущен агент, например `~/.codex/skills` или `~/.claude/skills`.

Глобальные навыки привязаны к конкретной машине. В настройках проекта на GitHub отображаются навыки репозитория, тогда как в чате также могут предлагаться совместимые глобальные навыки с машины, выбранной для этой сессии.

## Упоминание навыка

1. Выберите проект и конфигурацию агента (Agent Config) для диалога.
2. Введите `$` в поле ввода.
3. Продолжайте ввод, чтобы отфильтровать список по названию навыка.
4. Выберите нужный вариант с помощью клавиш со стрелками и нажмите `Enter` или кликните по навыку.

В поле ввода сохраняется читаемый токен `$skill-name`. При отправке сообщения Lody раскрывает эту ссылку, подставляя путь к соответствующему файлу `SKILL.md`, чтобы выбранный агент мог загрузить его и следовать инструкциям.

Список в меню фильтруется с учётом текущего ACP-провайдера в тех случаях, когда поддержка каталогов у разных агентов отличается.

## Обновление и работа в офлайн-режиме

Lody кэширует метаданные навыков на текущем устройстве и обновляет их в фоновом режиме. Если проект или машина-владелец временно недоступны, ранее закэшированные результаты могут оставаться в списке с пометкой о том, что данные устарели или недоступны.

Символические ссылки поддерживаются, если они не выходят за пределы разрешённого проекта или домашнего каталога пользователя. Небезопасные или битые ссылки пропускаются.
