# Квота подписки

Откройте **Settings** -> **Agent Config** -> **Machines**, чтобы просмотреть все машины, на которых запущен Lody CLI.
Если на машине выполнен вход по подписке Claude Code или Codex и уже запускались диалоги,
Lody показывает оставшуюся квоту для 5-часового и 1-недельного окон.
