# Мобильный доступ

У Lody есть нативные приложения для iOS и Android, чтобы вы могли продолжать работу над кодом в дороге.

## Установка приложения

### iOS

Установите Lody на iPhone или iPad:

- [Скачать в App Store](https://apps.apple.com/us/app/lody-run-code-agent-anywhere/id6761373528)

### Android

Скачайте актуальный подписанный APK со [страницы загрузки](/ru/download).

## Возможности

### Live Activities на iOS

На iPhone Lody может отображать статус запущенного агента на экране блокировки и в Dynamic Island. Вы можете отслеживать прогресс, не открывая приложение заново.

Когда агент запрашивает разрешение, Lody также может отправить интерактивное уведомление Live Activity, чтобы вы могли быстро ответить прямо в iOS.

### Push-уведомления

Получайте уведомления, когда:

- Задача завершена
- Агенту требуется подтверждение
- PR готов к ревью

Включите уведомления в разделе Settings > General > Push Notifications.

### Отслеживание прогресса

Наблюдайте за работой агентов в реальном времени:

- Вывод терминала в реальном времени
- Изменения в файлах
- Диффы сессии и комментарии к ревью
- Предпросмотр изображений с возможностью поделиться или сохранить по долгому нажатию

### Просмотр файлов проекта

Откройте проект на вкладке **Projects** в мобильном приложении, затем перейдите в **Files**, чтобы просматривать дерево каталогов и текстовые файлы. Создавать диалог для этого не нужно.

Просмотр файлов проекта работает как для локальных проектов, так и для репозиториев GitHub, когда машина-владелец или провайдер репозитория доступны. Редактирование файлов в реальном времени уже доступно в десктопной версии; редактирование на мобильных устройствах появится в ближайшее время.

## Поддержка офлайн-режима

Мобильное приложение Lody работает офлайн и позволяет:

- Просматривать кешированные диалоги
- Просматривать сохранённые диффы

Изменения синхронизируются автоматически, как только вы снова окажетесь в сети.
