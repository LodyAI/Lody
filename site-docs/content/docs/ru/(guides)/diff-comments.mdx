# Комментарии к diff

Комментарии к diff позволяют проводить ревью кода прямо там, где произошло изменение. Используйте их для командного ревью или отправляйте конкретную строку обратно в чат, чтобы агент мог объяснить её, исправить код или вернуться к этому участку.

## Добавление комментария

1. Откройте diff сессии из текущего хода или на боковой панели `Changes`.
2. Наведите курсор на строку, доступную для комментирования, и нажмите `+` рядом с номером строки.
3. Напишите комментарий. Поддерживается Markdown.
4. Нажмите **Comment** или клавиши `Ctrl+Enter` / `Cmd+Enter`.

На мобильном устройстве коснитесь доступной для комментирования строки diff, чтобы открыть поле для комментария.

## Ответы и завершение обсуждений

Комментарии отображаются в виде веток обсуждения под строкой diff. Вы можете:

- отвечать в той же ветке
- редактировать или удалять собственные комментарии
- нажать **Resolve**, когда обсуждение завершено
- нажать **Unresolve**, чтобы открыть ветку снова
- свернуть ветку, если вам нужна только сводка

## Отправка ветки обсуждения агенту

Нажмите кнопку отправки в ветке комментариев, чтобы сослаться на неё в текущем чате. Затем попросите агента проработать замечание, объяснить компромиссное решение или внести запрошенное исправление.

## Синхронизация с GitHub

Когда сессия привязана к PR на GitHub, новые комментарии из Lody можно синхронизировать как строчные комментарии к ревью PR на GitHub — для этого включите **Sync to GitHub**.

Lody также загружает существующие ветки комментариев из ревью PR на GitHub прямо в diff. Вы можете читать их в контексте кода и отвечать из Lody — ответы будут отправлены обратно на GitHub.
