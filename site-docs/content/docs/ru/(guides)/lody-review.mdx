# Lody Review

`lody review` превращает структурированное ревью кода в автономный HTML-отчёт. Команда работает локально с вашим Git-репозиторием, не требует учётной записи Lody и открывает результат напрямую по URL `file://` без запуска сервера.

## Создание ревью

Самый простой способ — попросить агента для работы с кодом выполнить весь процесс целиком:

```text
Use `npx lody review` to help me review <pull-request-url>.
```

Основные шаги выглядят так:

1. Выведите эталонный формат ревью:

   ```bash
   npx lody review prompt
   ```

2. Попросите агента изучить целевую ветку или pull request и записать файл `.review.md` в соответствии с выведенным форматом.
3. Сгенерируйте и откройте отчёт:

   ```bash
   npx lody review <name>.review.md
   ```

По умолчанию сгенерированный файл `.review.html` сохраняется во временный системный каталог, чтобы случайно не попасть в репозиторий. CLI выведет его абсолютный путь — вы сможете повторно открыть, переместить или переслать этот файл.

## Что содержит отчёт

Отчёт группирует связанные изменения, отображает diff файлов, связывает замечания с соответствующими строками кода и поддерживает уровни критичности и чек-листы для ревью. Во время чтения отчёта вы также можете добавлять комментарии и копировать их в формате Markdown.

## Требования

- Запускайте команду внутри проверяемого рабочего дерева Git или передайте флаг `--repo <dir>`.
- Коммиты, на которые ссылается ревью, должны существовать локально. Перед генерацией отчёта выполните `fetch` или переключитесь на ветку pull request.
- Файл `.review.md` разрешается относительно локального репозитория в режиме только для чтения.
- Ранее экспортированный снимок `.review.json`, `.review.json.gz` или `.review.json.br` автономен и может быть отображён без Git.

При первом рендеринге может потребоваться загрузка подходящей версии просмотрщика ревью. Lody проверяет его и кэширует локально для дальнейшего использования.

## Параметры

```bash
npx lody review <file> --repo <dir>
npx lody review <file> --output <report.html>
npx lody review <file> --no-open
```

- `--repo` выбирает репозиторий, используемый для разрешения `.review.md`.
- `--output` переопределяет путь к генерируемому HTML-файлу.
- `--no-open` записывает отчёт, не открывая браузер.
