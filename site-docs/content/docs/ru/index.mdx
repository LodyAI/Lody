# Lody

Lody.ai позволяет запускать кодинг-агентов параллельно на компьютере, мобильных устройствах и в любом
браузере, а также делиться контекстом с командой. Вы можете запускать любого встроенного провайдера
Lody: Claude Code, Codex, Grok, Kimi Code, Devin, Pi, DeepSeek Harness, Bub и Dimcode; также доступны
собственные ACP-агенты и любой CLI из [реестра ACP](https://agentclientprotocol.com/get-started/registry).

## В чём сильные стороны Lody

- **Параллельная работа.** У каждой сессии свой собственный Git worktree, поэтому агенты не
  перезаписывают изменения друг друга. См. [Параллельные агенты для разработки](/ru/docs/parallel-agents).
- **Используйте агентов, которым уже доверяете.** В Lody встроено множество провайдеров, а не только
  Claude Code и Codex; также работают любая среда выполнения из реестра ACP и собственная ACP-команда.
  См. [Agent Config](/ru/docs/quickstart) и [Типы сред выполнения CLI](/ru/docs/cli-runtimes).
- **Проводите ревью во время работы агента.** Diff по каждому раунду, построчные комментарии и
  синхронизация ревью GitHub PR. См. [Просмотр diff](/ru/docs/diff-viewer) и
  [Комментарии к diff](/ru/docs/diff-comments).
- **Позвольте одному агенту координировать остальных.** Разбивайте задачу, делегируйте подзадачи и
  собирайте результаты через [Управление сессиями из агента](/ru/docs/session-orchestration) и
  [Совместную работу нескольких агентов](/ru/docs/agent-collaboration).
- **Держите команду в курсе.** Делитесь живой сессией вместо стенограммы с помощью
  [передачи сессии](/ru/docs/session-handoff) и сохраняйте прозрачность работы в
  [Командных функциях](/ru/docs/team).
- **Работайте вдали от компьютера.** Проверяйте и направляйте задачи с iOS, Android или из любого
  браузера с помощью [Мобильного доступа](/ru/docs/mobile).
- **Не прерывайте работу CLI.** Переводите длительные задачи в фоновый режим и восстанавливайте их с
  помощью [Режима демона](/ru/docs/cli#режим-демона).
