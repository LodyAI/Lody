# Локальные проекты

Lody позволяет добавить любой локальный рабочий каталог в качестве проекта. Для такого сценария мы рекомендуем использовать десктопное приложение. После добавления локального проекта Lody синхронизирует его между устройствами в реальном времени — включая историю чатов, просмотр диффов файлов, ветки Git и worktree для каждой сессии.

## Добавление локального проекта

В Lody есть несколько способов добавить проект:

- В десктопном приложении нажмите кнопку добавления рядом с `My Projects`. Откроется локальное диалоговое окно выбора файлов, где можно указать нужный каталог.
- В средах без графического интерфейса, например на серверах, используйте [команды CLI для работы с проектами](/ru/docs/cli#команды-проектов), например `npx lody project add [path]`.

## Доступность в режиме local-first

В десктопном приложении проекты и сессии, уже имеющиеся на локальной машине, остаются доступными при отсутствии сети. Вы можете открывать их из локального каталога рабочего пространства, просматривать историю и продолжать работу. Локальные изменения сохраняются и синхронизируются после восстановления подключения.

Операции, требующие облака — например, открытие проекта на другой машине или загрузка новых данных из GitHub, — по-прежнему нуждаются в подключении к сети. Для удаления проекта с другого устройства также необходимо, чтобы машина-владелец была в сети.

## Worktree в локальных проектах

Локальные проекты теперь используют тот же процесс работы с worktree, что и проекты, привязанные к GitHub:

- Каждая сессия получает собственный изолированный worktree, который автоматически создаётся по запросу.
- При архивировании сессии её worktree автоматически освобождается.

Подробную структуру и описание подхода смотрите в разделе [Worktrees](/ru/docs/worktrees).

## Синхронизация истории кодинг-агентов (Codex, Claude Code и других)

Если вы уже использовали Codex или Claude Code напрямую в локальном проекте, Lody может импортировать существующую историю диалогов, чтобы вы могли продолжить работу с любого устройства.

- Откройте **Settings → Projects**, выберите локальный проект и запустите синхронизацию вручную, чтобы импортировать историю агентов, обнаруженных Lody на этой машине.
- После синхронизации проекта новые диалоги, начатые в Lody, дублируются обратно в соответствующий CLI (Claude Code, Codex и другие поддерживаемые агенты на базе ACP), поэтому обе стороны остаются согласованными.
- При открытии импортированного диалога его содержимое обновляется по запросу, поэтому вы всегда видите актуальное состояние из базового CLI.

## Видимость для команды для проектов не из GitHub

По умолчанию локальные проекты приватны — их видите только вы, даже после присоединения к рабочему пространству.

Чтобы совместно работать над проектом, которого нет на GitHub:

1. Откройте **Settings → Projects**.
2. Выберите локальный проект.
3. Включите видимость для команды.

После этого коллеги смогут видеть проект на боковой панели и запускать в нём сессии. Как и в случае с [общими машинами](/ru/docs/team#видимость-машин-в-команде), изменять настройку видимости может только владелец проекта, а при её отключении проект сразу скрывается от остальных участников.

## Удалённый доступ к локальным проектам

С другого устройства (через веб-интерфейс, мобильное приложение или другой компьютер) вы можете просматривать локальный проект на его машине-владельце, не находясь рядом с ней:

- Просматривать текущее состояние Git-веток проекта.
- Напрямую запускать worktree на удалённой машине и продолжать работу из любого места.

Благодаря этому работа со смартфона или с ноутбука в дороге устроена для локальных проектов так же удобно, как и для проектов, связанных с GitHub.

## Удаление проекта с другого устройства

Вы можете удалить один из своих локальных проектов с десктопа или мобильного устройства, даже если папка находится на другом устройстве.

Устройство-владелец должно быть в сети, поскольку Lody отправляет запрос на удаление именно на эту машину. Перед удалением проекта Lody архивирует его сессии и запрашивает у машины-владельца очистку конфигурации worktree проекта. Удаление проекта из Lody не удаляет исходную папку проекта.

## Текущие ограничения

- Локальные проекты пока не поддерживают прямую отправку изменений (push) в удалённые ветки, однако вы по-прежнему можете попросить агента выполнить нужные операции Git за вас.
