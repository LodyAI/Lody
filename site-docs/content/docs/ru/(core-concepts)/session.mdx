# Сессии

Сессия — базовое понятие в Lody. Вы запускаете новую сессию из поля ввода на главной странице. Это аналог одного диалога в Claude Code / Codex CLI.

Перед запуском вы можете настроить сессию с помощью меню вокруг поля ввода:

- репозиторий и ветка
- конфигурация агента
- модель
- область разрешений

Lody запускает сессию с учётом этих параметров.

Сессия также может содержать несколько вкладок: основной чат, дочерние чаты, предпросмотр файлов и просмотр диффов могут оставаться в рамках одной сессии. Если вы хотите продолжать общение, параллельно изучая код, или разбить одну задачу на несколько веток ревью, см. раздел [Вкладки сессии](/ru/docs/session-tabs).

Чтобы пригласить коллегу в существующую сессию и продолжить работу с тем же диалогом, диффами и worktree, см. [Совместный доступ к сессии агента](/ru/docs/session-handoff). Описанное ниже создание форка запускает новую сессию для вас — оно не добавляет другого участника в исходную.

## Создание форка сессии

Если ваш агент поддерживает нативное создание форков сессий, под последним завершённым ответом агента отображается кнопка **Fork session**. Создание форка открывает новую сессию с историей диалога до этого ответа и позволяет продолжить работу в другом направлении, не изменяя исходную сессию.

Codex и Claude Code также умеют создавать форк от более раннего завершённого ответа агента.

В сессии на базе Git, поддерживающей создание форков worktree, **Fork session** предлагает два варианта:

- **Current workspace** — новая вкладка, которая использует те же файлы и незафиксированные изменения, что и исходная сессия
- **New worktree** — новая независимая сессия от последнего зафиксированного коммита `HEAD`; незафиксированные и неотслеживаемые файлы остаются в исходной сессии

Если вариант **New worktree** не предлагается, форк создаётся в текущем рабочем пространстве. Боковой чат (Side Chat) всегда использует общий каталог.

Функция форка доступна только тогда, когда активный агент сообщает о её нативной поддержке.

## Правая боковая панель: Browser и Side Chat

На правой боковой панели можно держать инструменты рядом с основным диалогом. Откройте **Browser** на панели инструментов сессии, чтобы просматривать веб-страницу, или используйте меню `+` на боковой панели для добавления новых панелей.

**Side Chat** создаёт форк от последнего подходящего ответа агента и открывает его как отдельный чат на правой боковой панели. Это удобно, чтобы задать уточняющий вопрос или запросить ревью, не отвлекаясь от основной сессии. Вы можете создать несколько боковых чатов, переключаться между ними на боковой панели и закрывать ненужные с помощью кнопки `X`. Функция Side Chat доступна, если активный агент поддерживает нативное создание форков сессий.

Подробности о работе с URL и удалёнными портами см. в разделе [Предпросмотр Lody](/ru/docs/preview).

## Список сессий

На левой боковой панели Lody отображает диалоги из чатов, worktree GitHub и локальных проектов. Вы можете использовать группировку по проектам (по умолчанию) или переключиться в режим **Updated**, чтобы группировать всё по времени обновления: Today, This week и Older.

У каждой сессии есть сгенерированный ИИ смысловой заголовок и текущий статус. Наведите курсор на сессию, чтобы увидеть в её информационной карточке репозиторий, ветку, статус pull request и статистику изменённых строк относительно базовой ветки.

## Действия с сессией

Нажмите правой кнопкой мыши на сессию на боковой панели, чтобы открыть контекстное меню. Из него можно переименовать, закрепить или архивировать сессию, скопировать её URL или имя текущей ветки.

Закреплённые сессии остаются вверху своего списка, чтобы важные или длительные задачи всегда были под рукой. В веб-приложении нажмите на задачу на боковой панели средней кнопкой мыши или с зажатой клавишей Cmd/Ctrl, чтобы открыть её в новой вкладке браузера.

Панель действий диалога и элементы управления информацией о сессии объединяют действия, актуальные для текущей задачи — включая операции с проектом, веткой, предпросмотром, pull request и изменениями кода, если они доступны. Благодаря этому частые действия с GitHub и проектом находятся прямо рядом с диалогом, и вам не приходится переключаться в отдельное окно.

## Быстрая сессия на компьютере

Нажмите `Cmd/Ctrl+Shift+N`, чтобы открыть отдельное окно быстрой сессии (Quick Session). Это глобальное сочетание клавиш в системе, поэтому оно работает, даже если окно Lody не в фокусе. В компактном поле ввода выберите проект, агента и модель и сразу запустите сессию, не открывая главное окно.

Сочетание клавиш можно изменить в разделе **Settings** -> **Keyboard**. Подробнее см. в разделе [Палитра команд и горячие клавиши](/ru/docs/keyboard-shortcuts).

## Открытие рабочего пространства в редакторе

В заголовке сессии в десктопном приложении используйте кнопку **Open in**, чтобы открыть текущий worktree или каталог проекта. Встроенные средства запуска поддерживают такие редакторы, как VS Code, Xcode и Sublime Text.

В разделе **Settings** -> **General** -> **Path launchers** вы можете выбрать редактор по умолчанию или добавить собственную shell-команду. Пользовательские шаблоны должны использовать `{path}` в качестве аргумента для папки сессии и сохраняются только на текущем компьютере.

Если проект уже открыт в редакторе, при повторном открытии фокус переключится на существующее окно вместо создания нового (например, в Zed).

## Архивирование сессий

Наведите курсор на сессию в списке (или нажмите на неё на мобильном устройстве), чтобы в правом нижнем углу появилась кнопка архивирования. Нажмите её, чтобы отправить сессию в архив.

Архивированные сессии перемещаются в список архива с сохранением всей истории диалога. Машина-владелец может освободить каталог worktree, управляемый Lody, ещё до окончательного удаления — при этом локальная ветка сохраняется, а незафиксированные неигнорируемые изменения предварительно коммитятся. Игнорируемые файлы могут быть удалены, а скрипт очистки может изменить файлы до создания резервной копии. Сохраните нужные файлы за пределами worktree перед архивированием. Подробности о сроках, требованиях к восстановлению и границах защиты см. в разделе [Хранение и восстановление worktree](/ru/docs/worktrees#automatic-cleanup). Для сессий, запущенных напрямую в каталоге локального проекта, этот каталог не удаляется при очистке управляемых worktree.

## Восстановление сессий из архива

В правом нижнем углу левой боковой панели нажмите кнопку списка архива, чтобы открыть архивированные сессии. Воспользуйтесь поиском и сортировкой, чтобы найти нужную сессию, а затем нажмите кнопку восстановления — сессия вернётся в активный список, и вы сможете продолжить диалог в любой момент.

## Удаление сессий

В правом нижнем углу левой боковой панели нажмите кнопку списка архива, чтобы открыть архивированные сессии. Нажмите кнопку удаления рядом с сессией, чтобы безвозвратно удалить её вместе с историей диалога. Это действие нельзя отменить. Оставшийся управляемый worktree по-прежнему подлежит очистке по [тому же правилу резервного копирования](/ru/docs/worktrees#automatic-cleanup); локальная ветка Git и коммиты сохраняются.

Для сессий без выбранного проекта удаление также стирает рабочий каталог чата, управляемый Lody, и все файлы внутри него без резервного копирования и возможности восстановления; при архивировании же освобождаются только пустые каталоги.

## Массовое восстановление и удаление

Наведите курсор на диалог и нажмите на флажок слева от него, чтобы перейти в режим множественного выбора. Затем откройте меню дополнительных действий для пакетного выбора и выберите массовое восстановление или удаление на панели управления в правом верхнем углу.
