# Accès mobile

Lody propose des applications natives pour iOS et Android afin que vous puissiez continuer à coder en déplacement.

## Installer l'application

### iOS

Installez Lody sur iPhone ou iPad :

- [Télécharger dans l'App Store](https://apps.apple.com/us/app/lody-run-code-agent-anywhere/id6761373528)

### Android

Téléchargez la dernière version signée de l'APK depuis la [page de téléchargement](/fr/download).

## Fonctionnalités

### Activités en direct sur iOS

Sur iPhone, Lody peut afficher l'état de l'agent en cours d'exécution sur l'écran verrouillé et dans Dynamic Island. Vous pouvez ainsi suivre la progression sans rouvrir l'application.

Lorsqu'un agent demande une autorisation, Lody peut également envoyer une alerte interactive sous forme d'Activité en direct pour vous permettre de répondre rapidement depuis iOS.

### Notifications push

Recevez une notification lorsque :

- Une tâche se termine
- Un agent a besoin d'une approbation
- Une PR est prête à être relue

Activez les notifications dans Settings > General > Push Notifications.

### Suivre la progression

Suivez le travail de vos agents en temps réel :

- Sortie du terminal en direct
- Modifications de fichiers
- Diffs de session et commentaires de revue
- Aperçus d'images, avec actions de partage et d'enregistrement par appui long

### Parcourir les fichiers du projet

Ouvrez un projet depuis l'onglet mobile **Projects**, puis passez à **Files** pour parcourir son arborescence de répertoires et prévisualiser les fichiers texte. Vous n'avez pas besoin de créer une conversation au préalable.

La navigation dans les fichiers du projet fonctionne pour les projets locaux et les dépôts GitHub lorsque la machine hôte ou le fournisseur du dépôt est disponible. L'édition de fichiers en temps réel est disponible dès aujourd'hui sur ordinateur ; l'édition sur mobile arrivera bientôt.

## Mode hors ligne

L'application mobile Lody fonctionne hors ligne pour :

- Consulter les conversations mises en cache
- Examiner les diffs enregistrés

Les modifications se synchronisent automatiquement lorsque vous retrouvez une connexion.
