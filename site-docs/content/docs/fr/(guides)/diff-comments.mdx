# Commentaires sur le diff

Les commentaires sur le diff vous permettent de passer en revue le code directement à l'endroit où la modification a eu lieu. Utilisez-les pour les revues en équipe, ou renvoyez une ligne précise dans la discussion afin que l'agent puisse l'expliquer, la corriger ou la retravailler.

## Ajouter un commentaire

1. Ouvrez un diff de session depuis le tour actuel ou depuis la barre latérale `Changes`.
2. Survolez une ligne commentable et cliquez sur le `+` à côté du numéro de ligne.
3. Rédigez votre commentaire. Markdown est pris en charge.
4. Cliquez sur **Comment**, ou appuyez sur `Ctrl+Enter` / `Cmd+Enter`.

Sur mobile, appuyez sur une ligne commentable du diff pour ouvrir la zone de commentaire.

## Répondre et résoudre

Les commentaires s'affichent sous forme de fils de discussion sous la ligne du diff. Vous pouvez :

- répondre dans le même fil de discussion
- modifier ou supprimer vos propres commentaires
- cliquer sur **Resolve** lorsque le fil est traité
- cliquer sur **Unresolve** pour le rouvrir
- réduire un fil de discussion lorsque vous n'avez besoin que du résumé

## Envoyer un fil de discussion à l'agent

Utilisez le bouton d'envoi sur un fil de commentaires pour le référencer dans la discussion en cours. Demandez ensuite à l'agent de traiter le commentaire, d'expliquer le compromis ou d'apporter le correctif demandé.

## Synchroniser avec GitHub

Lorsque la session est liée à une PR GitHub, les nouveaux commentaires Lody peuvent être synchronisés en tant que commentaires sur les lignes d'une revue de PR GitHub en activant **Sync to GitHub**.

Lody charge également les fils de revue de PR GitHub existants dans le diff. Vous pouvez les lire en contexte et y répondre depuis Lody ; les réponses sont publiées sur GitHub.
