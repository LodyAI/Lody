# Copier des conversations

## Copier un seul message

Dans l'interface de chat, chaque bulle de message dispose d'un bouton de copie en dessous. Cliquez
dessus pour copier ce message.

## Copier la conversation complète

Ouvrez le menu `...` de la session, développez **Copier**, puis choisissez **Copier en Markdown**.
Lody copie l'historique visible de la conversation dans un format Markdown réutilisable.

Le même sous-menu vous permet également de copier le chemin de l'espace de travail de la session ou
l'URL de la session lorsque ces valeurs sont disponibles.

La copie au format Markdown constitue un enregistrement, et non un transfert en direct. Copier
l'URL d'une session n'accorde pas non plus d'accès à l'équipe. Pour inviter un coéquipier dans la
même session, consultez [Partager une session d'agent de code](/fr/docs/session-handoff).
La différence entre lien de partage et transfert est présentée dans [Lien de partage vs transfert en direct](/fr/docs/compare/share-link-vs-live-handoff).
