# Entrée d'image

Lody prend en charge l'entrée d'image dans le chat de session. Vous pouvez envoyer des captures d'écran, des maquettes d'interface, des captures d'erreurs et d'autres éléments visuels dans le contexte du prompt.

<ImageInputPreview locale="fr" />

## Cas d'utilisation

- Expliquer des bugs visuels à l'aide de captures d'écran directes.
- Demander à l'IA de lire des détails d'interface à partir d'images.
- Combiner des preuves visuelles avec le contexte de code en un seul tour.

## Comment l'utiliser

1. Ouvrez un chat de session.
2. Ouvrez le menu `+` des pièces jointes et choisissez **Téléverser une image**, collez une image depuis le presse-papiers ou
   glissez-déposez des fichiers image n'importe où sur l'interface de la session.
3. Saisissez votre instruction et envoyez.

Vous pouvez joindre jusqu'à 8 images à un même message, avec une taille maximale de 5 Mio par image. Les images plus volumineuses
peuvent être envoyées en tant que fichiers standard via [Pièces jointes](/fr/docs/file-attachments).

<Callout type="warn">

La prise en charge des images dépend du modèle actif. Assurez-vous que le modèle sélectionné prend en charge l'entrée visuelle.

</Callout>
