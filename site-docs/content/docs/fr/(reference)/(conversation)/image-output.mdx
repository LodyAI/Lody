# Sortie d'image

Lody peut renvoyer jusqu'à 8 images directement dans une session. Vous pouvez demander à l'agent quelque chose comme `Démarrez le serveur de développement frontend, attendez que la page d'accueil se charge, puis envoyez-moi une capture d'écran.` Lody téléversera automatiquement les images obtenues dans le chat.

Lorsque le runtime sélectionné prend en charge la génération d'images, comme la génération d'images de Codex, les images générées peuvent également apparaître dans la conversation sans quitter la session.

## Images générées

Pour la génération d'images de Codex, Lody conserve l'image générée dans la même conversation que le prompt et les éventuelles demandes de suivi. Il devient ainsi plus facile de demander des révisions, de comparer des variantes ou de retrouver ultérieurement la ressource générée.

<ImageOutputPreview locale="fr" />

## Cas d'utilisation

- Examiner rapidement les résultats d'interface depuis votre mobile.
- Demander à l'agent de renvoyer des résultats visuels depuis votre machine locale.
- Examiner les images générées aux côtés du prompt et du contexte d'implémentation.

## Comment l'utiliser

1. Ouvrez un chat de session.
2. Demandez à l'agent de prendre une capture d'écran ou d'effectuer une autre action qui renvoie une image. Lody téléversera automatiquement l'image dans la conversation.
