# Quota d'abonnement

Accédez à **Paramètres** -> **Configuration d'agent** -> **Machines** pour afficher toutes les machines exécutant la CLI Lody.
Si une machine est connectée avec un abonnement Claude Code ou Codex et a exécuté des conversations,
Lody affiche le quota restant pour les fenêtres de 5 heures et d'une semaine.
