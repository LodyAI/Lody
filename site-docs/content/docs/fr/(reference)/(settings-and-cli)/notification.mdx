# Notifications

Lody envoie des notifications push sur vos appareils lorsqu'une conversation d'agent de codage se termine,
demande une autorisation ou rencontre une erreur, afin que vous puissiez suivre l'état de la session.

## Activer les notifications

### Navigateur de bureau

Sur ordinateur, accédez à **Paramètres** -> **Général** -> **Notifications push** pour activer les notifications.

Après avoir cliqué, votre navigateur vous demande si vous souhaitez autoriser les notifications. Cliquez sur **Autoriser**.

<NotificationPreview locale="fr" variant="browser" />

### Application mobile

Sur mobile, commencez par [installer l'application Lody](/fr/docs/mobile), puis activez les notifications depuis
**Paramètres** -> **Général** -> **Notifications push**.

<NotificationPreview locale="fr" variant="mobile" />

Les notifications mobiles sont utiles pour les demandes d'approbation, les tâches terminées et les échecs que vous
devez examiner avant de poursuivre une session.
