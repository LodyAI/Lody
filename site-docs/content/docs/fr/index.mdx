# Lody

Lody.ai vous permet d'exécuter des agents de code en parallèle sur ordinateur, mobile et dans n'importe quel navigateur, et de partager le contexte avec votre équipe. Vous pouvez utiliser tous les fournisseurs intégrés de Lody : Claude Code, Codex, Grok, Kimi Code, Devin, Pi, DeepSeek Harness, Bub et Dimcode ; vous pouvez également exécuter des agents ACP personnalisés et toute CLI de l'[ACP Registry](https://agentclientprotocol.com/get-started/registry).

## Les points forts de Lody

- **Exécutez vos tâches en parallèle.** Chaque session dispose de son propre worktree Git, afin que les agents ne s'écrasent pas mutuellement. Consultez [Agents de code en parallèle](/fr/docs/parallel-agents).
- **Utilisez les agents auxquels vous faites déjà confiance.** Lody intègre de nombreux fournisseurs natifs, pas uniquement Claude Code et Codex ; tout runtime de l'ACP Registry et toute commande ACP personnalisée fonctionnent également. Consultez [Configuration des agents](/fr/docs/quickstart) et [Types de runtime CLI](/fr/docs/cli-runtimes).
- **Relisez pendant que l'agent travaille.** Diffs par tour, commentaires ligne par ligne et synchronisation des revues de PR GitHub. Consultez [Visionneuse de diffs](/fr/docs/diff-viewer) et [Commentaires sur les diffs](/fr/docs/diff-comments).
- **Laissez un agent coordonner les autres.** Découpez une tâche, déléguez et rassemblez les résultats via [Contrôle des sessions d'agents](/fr/docs/session-orchestration) et [Collaboration multi-agents](/fr/docs/agent-collaboration).
- **Tenez l'équipe informée.** Partagez une session en direct plutôt qu'une transcription grâce au [transfert de session](/fr/docs/session-handoff), et gardez le travail visible dans [Fonctionnalités d'équipe](/fr/docs/team).
- **Travaillez loin de votre bureau.** Relisez et pilotez depuis iOS, Android ou n'importe quel navigateur avec l'[Accès mobile](/fr/docs/mobile).
- **Gardez la CLI active.** Exécutez les tâches longues en arrière-plan et reprenez-les avec le [Mode daemon](/fr/docs/cli#mode-daemon).
