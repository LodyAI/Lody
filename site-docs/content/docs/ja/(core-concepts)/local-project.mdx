# ローカルプロジェクト

Lody では、任意のローカル作業ディレクトリをプロジェクトとして追加できます。この操作にはデスクトップアプリのご利用をおすすめします。ローカルプロジェクトを追加すると、チャット履歴、ファイル差分ビュー、Git ブランチ、セッションごとのワークツリーなどを含む情報が、デバイス間でリアルタイムに同期されます。

## ローカルプロジェクトの追加

Lody では、次の複数の方法でプロジェクトを追加できます。

- デスクトップアプリで `My Projects` の横にある追加ボタンをクリックします。ローカルのファイルピッカーが開き、追加するディレクトリを選択できます。
- サーバーなどデスクトップ以外の環境では、`npx lody project add [path]` などの [CLI のプロジェクトコマンド](/ja/docs/cli#project-commands) を使用します。

## ローカルファーストな利用環境

デスクトップアプリでは、ネットワークに接続できない状態でも、ローカルマシンにすでに存在するプロジェクトやセッションを引き続き利用できます。ローカルのワークスペースカタログから開いて履歴を閲覧し、そのまま作業を続けることが可能です。ローカルで行った変更は保持され、接続が復旧した際に同期されます。

ただし、別のマシンでプロジェクトを開く操作や、新しい GitHub データの取得といったクラウド専用の操作にはネットワーク接続が必要です。また、別のデバイスからプロジェクトを削除する場合も、そのプロジェクトを所有するマシンがオンラインである必要があります。

## ローカルプロジェクトでのワークツリー

ローカルプロジェクトでも、GitHub 連携プロジェクトと同じワークツリーワークフローが利用できるようになりました。

- 各セッションには独立した専用のワークツリーが割り当てられ、必要に応じて自動的に作成されます。
- セッションをアーカイブすると、ワークツリーは自動的に回収されます。

構成の詳細や設計意図については、[ワークツリー](/ja/docs/worktrees) をご覧ください。

## コードエージェント履歴の同期（Codex、Claude Code など）

ローカルプロジェクト上で Codex や Claude Code を直接使用していた場合、Lody はその既存の会話履歴を取り込み、どのデバイスからでも続きの作業を行えるようにします。

- **Settings → Projects** を開いてローカルプロジェクトを選択し、手動同期を実行すると、そのマシン上で Lody が検出したエージェントの履歴がインポートされます。
- 一度プロジェクトを同期すると、Lody で新たに開始した会話も対応する CLI（Claude Code、Codex、およびその他のサポート対象 ACP ベースエージェント）にミラーリングされ、双方の状態が一致したまま保たれます。
- インポート済みの会話を開くと必要に応じて最新の内容が再読み込みされるため、基盤となる CLI 側の最新状態を常に確認できます。

## GitHub 以外のプロジェクトにおけるチーム公開設定

ローカルプロジェクトはデフォルトで非公開となっており、ワークスペースに参加した後でも自分にしか表示されません。

GitHub 上に存在しないプロジェクトで共同作業を行うには、次の手順を実行します。

1. **Settings → Projects** を開きます。
2. 対象のローカルプロジェクトを選択します。
3. チームへの公開設定（team visibility）をオンに切り替えます。

これにより、チームメンバーのサイドバーにもそのプロジェクトが表示され、セッションを開始できるようになります。[共有マシン](/ja/docs/team#team-machine-visibility) の場合と同様に、公開設定を変更できるのはプロジェクトの所有者のみで、設定をオフにすると他のメンバーからは即座に非表示になります。

## ローカルプロジェクトへのリモートアクセス

別のデバイス（Web、モバイル、または他のデスクトップ）から、マシンを直接操作することなく、所有マシン上のローカルプロジェクトを確認できます。

- プロジェクトの現在の Git ブランチの状態を参照できます。
- リモートマシン上で直接ワークツリーを起動し、どこからでも作業を続けられます。

これにより、スマートフォンを使った操作や外出先でのノート PC からの作業も、GitHub 連携プロジェクトと同じ感覚でローカルプロジェクトに対して行えます。

## 別のデバイスからのプロジェクト削除

フォルダーが別のデバイス上にある場合でも、デスクトップやモバイルから自分のローカルプロジェクトを削除できます。

削除リクエストはプロジェクトを所有するマシンに送信されるため、そのデバイスがオンラインである必要があります。プロジェクトを削除する前に、Lody は関連するセッションをアーカイブし、所有マシンに対してプロジェクトのワークツリー設定のクリーンアップを指示します。なお、Lody からプロジェクトを削除しても、元のプロジェクトフォルダー自体は削除されません。

## 現在の制限事項

- ローカルプロジェクトでは、まだリモートブランチへ直接プッシュすることはできませんが、関連する Git 操作をエージェントに依頼して実行してもらうことは可能です。
