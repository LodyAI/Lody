# セッションタブ

セッションタブを使うと、共有コンテキストを失うことなく、1つのタスクを複数の作業画面に分けて進められます。重要なのはチャットウィンドウを増やすことだけではありません。**異なるエージェントが同じワークスペースを再利用できる**ため、各会話で独自の履歴を保ちながら、同じファイル、ブランチ、未コミットの変更を参照できます。メインチャットと子チャットは自由に開閉でき、ファイルプレビューや差分ビューと並べて利用できます。

## タブを使う場面

- メインタブで実装を進めながら、子タブで現在の変更をレビューする。
- チャットの横にファイルや差分を開き、コードを読みながら追加の質問をする。
- 「この変更を要約して」「リスクを探して」「PR のコメントを修正して」のように、1つのブランチを複数の観点から切り分けて作業する。

## 子チャットを作成する

1. セッションを開き、タブバーの `+` をクリックします。
2. 新しいタブは、親セッションのマシン、プロジェクトまたはリポジトリ、ブランチ、エージェント設定、モデル、および権限のデフォルト設定を引き継ぎます。送信前であれば、そのマシンに紐付けられた任意の Agent Role を選択できます。Role によっては、下書きが別のエージェントタイプに切り替わります。
3. 新しいタブで最初のメッセージを送信します。Lody は、選択した Role の実行設定と指示内容をもとに子セッションを作成します。タイトルはプロンプトの1行目から自動的に設定され、後からタブをダブルクリックして名前を変更できます。

子タブは親タブと同じ作業ディレクトリのコンテキストを共有しますが、会話履歴はタブごとに独立して保持されます。そのため、同じタスクに関する並行レビューやフォローアップ作業に便利です。

## ファイルタブと差分タブ

- 会話内のファイルパスをクリックすると、ファイルプレビュータブが開きます。
- ラウンド単位の差分でファイルをクリックすると、差分タブが開きます。
- `Files` または `Changes` サイドバーからファイルをクリックすると、ビューアタブとして開きます。

デスクトップでは、ビューアタブを開くとワークスペースが分割され、左側にチャット、右側にアクティブなファイルまたは差分が表示されます。モバイルでは、小さな画面でも読みやすいように、ファイルまたは差分が前面のフォーカス画面として開きます。

## タブを管理する

- タブをドラッグして並べ替えます。並び順は現在のブラウザに記憶されます。
- チャットタブをダブルクリックして名前を変更します。
- メインおよび子の会話タブは閉じることができます。タブを閉じた状態はワークスペース全体で共有されますが、エージェントの停止、会話のアーカイブ、worktree の削除は行われません。
- アクティブな会話タブを閉じると、隣接するタブが選択されます。開いているタブがなくなると、同じワークスペース内にローカルの新規会話の下書きが開きます（既存の下書きがある場合は入力内容が保持されます）。実際のセッションはメッセージを送信した時点で作成され、閉じた会話はいつでも再度開くことができます。
- 履歴ボタンからは、以前にアーカイブされたタブを含め、閉じた会話の一覧を確認できます。アーカイブ済みの会話を再度開くと、アーカイブからも復元されます。
- 会話を再度開くと、そのタブは全員に表示されるようになりますが、アクティブな選択状態になるのは自分の画面だけです。ファイルタブと差分タブについては、これまでどおりローカル環境のみでの動作となります。
