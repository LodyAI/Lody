# エンドツーエンド暗号化ワークスペース

エンドツーエンド暗号化ワークスペースでは、会話、ファイル、エージェントの出力は**あなたが承認したデバイス上でのみ閲覧できます**。Lody のサーバーはデータの中継と保存を行いますが、サーバーが扱うのは読み取れないデータのみです。

<Callout type="warn">
  承認済みのデバイスをすべて紛失し、リカバリファイルもない場合、そのワークスペースは二度と開けなくなり、Lody
  でも復元できません。ワークスペースを作成したら、すぐにリカバリファイルを設定してください。
</Callout>

## 標準ワークスペースとの違い

|                                | 標準ワークスペース                               | エンドツーエンド暗号化ワークスペース         |
| ------------------------------ | ------------------------------------------------ | -------------------------------------------- |
| 内容を閲覧できる対象           | アクセス権のあるメンバー、および Lody のサーバー | 承認済みのデバイスのみ                       |
| 新しいデバイスの使用           | サインインする                                   | サインイン後、承認済みのデバイスから承認する |
| Web アプリ                     | すぐに利用できる                                 | 先にブラウザーを承認する必要がある           |
| すべてのデバイスを紛失した場合 | 再度サインインする                               | リカバリファイルまたはパスキーが必要         |

## 日常的な操作

<Steps>
<Step>

**暗号化ワークスペースを見分ける**：ワークスペース名の横に鍵アイコンが表示されます。鍵アイコンにカーソルを合わせると説明が表示されます。

</Step>
<Step>

**チームメンバーを招待する**：「設定 › 一般 › 暗号化コンソールを開く › メンバーと招待」から招待を送信します。管理者が承認すると、相手のデバイスが鍵を受け取ります。

</Step>
<Step>

**新しいデバイスで開く**：新しいデバイスから自動的にリクエストが送信され、6 桁のコードが表示されます。承認済みのパソコンやスマートフォンに承認ウィンドウが表示されるので、そのコードを入力し（スマートフォンでは新しいデバイスの画面をスキャンすることもできます）、参加させるワークスペースにチェックを入れたまま「承認」を選択します。

</Step>
<Step>

**チームメンバーと照合する**：「セキュリティコードと履歴」でセキュリティコードを比較し、全員に同じメンバーとデバイスが表示されていることを確認します。

</Step>
<Step>

**リカバリを設定する**：すべてのデバイスを紛失してもワークスペースを開けるように、「リカバリ」でリカバリファイルを保存するか、パスキーを追加します。

</Step>
</Steps>

## 既知の制限事項

- ブラウザーでは、Lody のウェブサイトから配信されるコードが改ざんされていないことが安全性の前提となります。その点が重要な場合は、デスクトップアプリまたはモバイルアプリをご利用ください。
- サーバーに到達できない間も、お使いのマシンは一定時間作業を続けられます。招待、デバイスの承認、鍵の置き換えは、オンラインに戻るまで保留されます。
