# Lody Review

`lody review` は、構造化されたコードレビューを自己完結型の HTML レポートに変換します。ローカルの Git リポジトリに対して実行され、Lody アカウントは不要で、サーバーを起動せずに `file://` URL から直接結果を開きます。

## レビューを作成する

最もシンプルなワークフローは、コーディングエージェントにプロセス全体の実行を依頼することです。

```text
Use `npx lody review` to help me review <pull-request-url>.
```

内部で行われる手順は次のとおりです。

1. 規定のレビューフォーマットを出力します。

   ```bash
   npx lody review prompt
   ```

2. 対象のブランチまたはプルリクエストを調査し、出力されたフォーマットに沿った `.review.md` ファイルを作成するようエージェントに指示します。
3. レポートをレンダリングして開きます。

   ```bash
   npx lody review <name>.review.md
   ```

デフォルトでは、生成された `.review.html` はシステムの一時ディレクトリ配下に書き出されるため、誤ってリポジトリの一部になることはありません。CLI は絶対パスを出力するため、後から再度開いたり、移動したり、共有したりできます。

## レポートの内容

レポートでは関連する変更がグループ化され、ファイルの差分（diff）が表示されるほか、指摘事項が該当行にリンクされ、重要度レベルやレビューチェックリストにも対応しています。レポートを読みながらコメントを追加し、Markdown としてコピーすることもできます。

## 要件

- レビュー対象の Git ワーキングツリー内でコマンドを実行するか、`--repo <dir>` を指定してください。
- レビューで参照されているコミットがローカルに存在する必要があります。レンダリングの前にプルリクエストのブランチを fetch またはチェックアウトしてください。
- `.review.md` ファイルは、ローカルリポジトリに対して読み取り専用モードで解決されます。
- 以前にエクスポートされた `.review.json`、`.review.json.gz`、または `.review.json.br` のスナップショットは自己完結型であり、Git なしでレンダリングできます。

初回のレンダリング時には、対応するレビュービューアーがダウンロードされる場合があります。Lody はビューアーを検証し、次回以降の使用に備えてローカルにキャッシュします。

## オプション

```bash
npx lody review <file> --repo <dir>
npx lody review <file> --output <report.html>
npx lody review <file> --no-open
```

- `--repo` は、`.review.md` の解決に使用するリポジトリを指定します。
- `--output` は、生成される HTML の出力先パスを上書きします。
- `--no-open` は、ブラウザーを開かずにレポートを書き出します。
