# チーム機能

Lody は初期バージョンからチームコラボレーションに対応しています。エージェント設定や会話の完全なコンテキストをチームと共有できます。今後は、共有ドキュメント、メンバーへのメンション、タスク管理など、さらなるチーム機能の追加を予定しています。

トランスクリプトを閲覧するだけでなく、同じ会話・差分・Worktree をそのまま引き継げるようにチームメイトを**既存のコーディングエージェントセッションに招待**したい場合は、[コーディングエージェントのセッションを共有する](/ja/docs/session-handoff) をご覧ください。共有リンクは記録を残すためのものであり、リアルタイムのハンドオフではありません。詳しくは [共有リンク vs ライブハンドオフ](/ja/docs/compare/share-link-vs-live-handoff) をご覧ください。

分離された Worktree、複数モデルの併用、チームから閲覧可能なセッションを活用して複数のエージェントを同時に実行する方法については、[並列コーディングエージェント](/ja/docs/parallel-agents) をご覧ください。

## メンバーを招待する

**Settings** -> **Workspace** -> **General** に移動し、**Members** セクションで **Invite Member** をクリックします。
招待するメンバーのメールアドレスを入力し、ロールを選択してから招待を送信します。

招待を送信すると、そのメンバーに招待メールが届きます。招待リンクをコピーして手動で共有することもできます。

## メンバーの権限を変更する

ワークスペースのオーナーと管理者は、メンバー一覧の右側にある編集アクションからメンバーの権限を変更できます。

## メンバーを削除する

ワークスペースのオーナーと管理者は、メンバー一覧の右側にある削除アクションを使ってメンバーを削除できます。

## 他のメンバーのセッションを表示する

ホームページのサイドバーにあるフィルターを使って、**My Tasks** と **All Tasks**（モバイルでは **Team Tasks**）を切り替えられます。リストのデフォルトは **All Tasks** です。アバターによって、各セッションを開始したメンバーを確認できます。

## メンバーごとのトークン使用量

**Settings** -> **AI Usage** では、AI トークンの合計使用量と推移グラフを確認できます。**By member** を使うと、メンバーごとの使用量の内訳を確認できます。

## チームでのマシン公開設定

登録したマシンはすべて**デフォルトで非公開（プライベート）**です。他のユーザーのワークスペースに参加しても、ご自身の開発マシンが公開されることはなく、他のメンバーのマシン一覧に表示されたり、そのマシン上でセッションが開始されたりすることはありません。

共有ビルドサーバーやクラウドワーカーなど、特定のマシンにチームメイトがアクセスできるようにしたい場合は、ワークスペースに対して明示的に共有できます。

### マシンを共有する

1. **Settings** -> **Machines** に移動します。
2. **My Machines** の下から対象のマシンを探します。
3. **Share machine** トグルをオンにします。

すると、他のメンバーの **Team Machines** にそのマシンが表示され、セッション作成時に選択できるようになります。トグルはいつでもオフに戻せます。共有を解除すると、他のメンバーのマシン一覧からそのマシンが消え、そのマシン上で実行中の会話も他のメンバーのセッションサイドバーに届かなくなります。

マシンの共有状態を変更できるのは、そのマシンのオーナーのみです。

### 「共有」の仕組み

- **一覧での表示**: 共有されたマシンは、すべてのメンバーのマシン設定にある `Team Machines` セクションに表示されます。共有されていないマシンは、オーナー自身の `My Machines` のみに表示されます。
- **セッションの作成可否**: セッションは、作成者がアクセス権を持つマシン（自身のマシンおよび現在共有されているチームマシン）上でのみ作成できます。
- **会話サイドバー**: 共有されていないマシン上で実行されているセッションは、他のメンバーのサイドバーには同期されません。

ワークスペースへの参加とマシンへのアクセス権の付与は完全に分離されています。そのため、個人のノート PC が共有ワーカーになってしまう心配をせずにチームメイトを招待できます。
