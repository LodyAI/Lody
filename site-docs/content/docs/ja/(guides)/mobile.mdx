# モバイルアクセス

Lody にはネイティブの iOS および Android アプリが用意されているため、外出先でもコーディングを続けられます。

## アプリのインストール

### iOS

iPhone または iPad に Lody をインストールします。

- [App Store からダウンロード](https://apps.apple.com/us/app/lody-run-code-agent-anywhere/id6761373528)

### Android

[ダウンロードページ](/ja/download)から最新の署名済み APK をダウンロードします。

## 主な機能

### iOS のライブアクティビティ

iPhone では、Lody が実行中のエージェントのステータスをロック画面や Dynamic Island に表示できます。アプリを開き直すことなく、進捗を確認できます。

エージェントが許可を求めた際には、アクション可能なライブアクティビティ通知も送信できるため、iOS から素早く応答できます。

### プッシュ通知

以下のタイミングで通知を受け取れます。

- タスクが完了したとき
- エージェントが承認を必要としているとき
- PR のレビュー準備が整ったとき

通知は Settings > General > Push Notifications から有効にできます。

### 進捗のモニタリング

エージェントの作業状況をリアルタイムで確認できます。

- リアルタイムのターミナル出力
- ファイルの変更
- セッションの diff およびレビューコメント
- 画像プレビュー（長押しでの共有・保存アクション対応）

### プロジェクトファイルの閲覧

モバイルの **Projects** タブからプロジェクトを開き、**Files** に切り替えると、ディレクトリツリーの閲覧やテキストファイルのプレビューが行えます。事前に会話を作成する必要はありません。

プロジェクトファイルの閲覧は、所有マシンまたはリポジトリプロバイダーが利用可能な場合、ローカルプロジェクトと GitHub リポジトリの両方で利用できます。リアルタイムのファイル編集は現在デスクトップ版で利用可能で、モバイル版での編集機能も近日公開予定です。

## オフラインサポート

Lody モバイルアプリは、オフライン環境でも以下の操作に対応しています。

- キャッシュされた会話の閲覧
- 保存済み diff の確認

オンラインに戻ると、変更は自動的に同期されます。
