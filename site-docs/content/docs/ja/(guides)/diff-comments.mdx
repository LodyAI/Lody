# Diff コメント

Diff コメントを使うと、変更が行われた箇所で直接コードをレビューできます。チームでのレビューに活用したり、特定の行をチャットに送り返してエージェントに説明、修正、または再確認を依頼したりできます。

## コメントの追加

1. 現在のターンまたは `Changes` サイドバーからセッションの Diff を開きます。
2. コメント可能な行にマウスカーソルを合わせ、行番号の横にある `+` をクリックします。
3. コメントを入力します。Markdown に対応しています。
4. **Comment** をクリックするか、`Ctrl+Enter` / `Cmd+Enter` を押します。

モバイル端末では、コメント可能な Diff 行をタップするとコメント入力欄が開きます。

## 返信と解決

コメントは Diff 行の下にスレッドとして表示されます。次の操作を行えます。

- 同じスレッド内で返信する
- 自分のコメントを編集または削除する
- 対応が完了したら **Resolve** をクリックする
- 再度開くには **Unresolve** をクリックする
- 要約だけを確認したいときはスレッドを折りたたむ

## スレッドをエージェントに送信

コメントスレッドにある送信ボタンを使うと、現在のチャットでそのスレッドを参照できます。その後、コメントへの対応、トレードオフの説明、または求められた修正の適用をエージェントに依頼できます。

## GitHub との同期

セッションが GitHub PR にリンクされている場合、**Sync to GitHub** を有効にすると、Lody 上の新しいコメントを GitHub PR Review の行コメントとして同期できます。

Lody は既存の GitHub PR Review スレッドも Diff 内に読み込みます。コンテキストを確認しながらその場で読み、Lody から返信することができ、返信内容は GitHub 側に投稿されます。
