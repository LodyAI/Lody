# ファイル添付

Lody は新規の会話と既存の会話の両方で、任意のファイル添付に対応しています。添付ファイルはプロンプトとともに送信されるため、メッセージ内に内容を貼り付けなくても、エージェントがセッションワークスペースから元のファイルを直接読み取ることができます。

## 添付ファイルを追加する

1. コンポーザー内の添付 `+` メニューを開きます。
2. **Upload file** を選択し、1 つ以上のファイルを選びます。
3. 進行中のアップロードが完了するまで待ち、必要な指示を入力してメッセージを送信します。

ファイルをセッション画面にドラッグ＆ドロップすることもできます。会話を新しく開始する際も、送信待ちの添付ファイルはその新しいセッションに紐付けられたまま保持されます。

## プレビューとダウンロード

テキストプレビューに対応したファイルはプレビューダイアログで開きます。プレビューダイアログでは次の操作を行えます：

- レンダリングされた Markdown と生のソースの表示切り替え
- 元のテキストのコピー
- ファイル全体のダウンロード

その他のファイル形式では、ダウンロードが主な操作になります。ネイティブモバイルアプリでは、システム共有シート経由でダウンロードが開くため、ファイルを保存したり別のアプリへ送信したりできます。

## エージェントがファイルを受け取る仕組み

ターンの開始前に、Lody は各添付ファイルをセッションワークスペース配下の `.lody/attachments/` に配置し、エージェントにファイル参照を渡します。ファイルの内容自体はテキストプロンプトに挿入されません。

エージェントからファイルや画像を返すこともできます。対応している ACP 出力および Lody のアップロードツールによって、それらのファイルは通常の添付カードとして会話に追加されます。

## 制限と保持期間

- 1 つのメッセージにつき最大 8 個のファイルを添付できます。
- 1 ファイルあたりの最大サイズは 100 MiB です。
- すべてのファイル形式を受け付けます。
- リレーに保存されたファイルは 90 日間保持されます。

画像には専用の画像処理が適用されます：1 メッセージあたり最大 8 枚、1 枚あたり最大 5 MiB までです。それより大きい画像は、通常のファイルとして送信できます。詳しくは [画像入力](/ja/docs/image-input) および [画像出力](/ja/docs/image-output) をご覧ください。

## 利用可能性

エージェントが添付ファイルを読み取るには、所有マシンがその添付ファイルを取得できる状態である必要があります。アップロードに失敗した場合は、再試行するかその添付ファイルを削除してください。他の正常にアップロードされた添付ファイルはそのまま送信できます。
