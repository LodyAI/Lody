# 画像入力

Lody はセッションチャットでの画像入力に対応しています。スクリーンショット、UI モック、エラー画面のキャプチャなどの画像を、プロンプトコンテキストの一部として送信できます。

<ImageInputPreview locale="ja" />

## ユースケース

- 実際のスクリーンショットを使って視覚的なバグを説明する。
- 画像から UI の詳細を読み取るよう AI に依頼する。
- 画像の情報とコードのコンテキストを 1 ターンで組み合わせて伝える。

## 使い方

1. セッションチャットを開きます。
2. 添付の `+` メニューを開いて **Upload image** を選択するか、クリップボードから画像を貼り付けるか、セッション画面上の任意の場所に画像ファイルをドラッグします。
3. 指示を入力して送信します。

1 つのメッセージには最大 8 枚の画像を添付でき、1 枚あたりの最大サイズは 5 MiB です。それより大きな画像は、[ファイル添付](/ja/docs/file-attachments)から通常のファイルとして送信できます。

<Callout type="warn">

画像入力への対応状況は現在使用中のモデルによって異なります。選択したモデルがビジョン入力に対応していることを確認してください。

</Callout>
