# Diff ビューアー

Lody は各会話ラウンドの終了後に、コーディングエージェントによるファイルの更新をリアルタイムで同期します。

## 現在のラウンドの Diff

AI にコードの編集やファイルの変更を依頼すると、Lody はその会話ラウンドの前後でファイルの状態を比較します。ラウンドの終了時に、コーディングエージェントのメッセージ吹き出しの下に、すべてのファイル変更と変更行数が表示されます。

<ConversationDiffPreview locale="ja" />

任意のファイルをクリックすると、Diff タブが開いてそのファイルへ移動します。最初のクリック時は、データの同期と読み込みに少し時間がかかる場合があります。

<DiffViewerPreview locale="ja" />

また、パネル内の展開コントロールをクリックすると、ファイルの未変更部分も表示できます。

## 行コメント

コメント可能な Diff 行にマウスカーソルを合わせ、行番号の横にある `+` をクリックすると、Markdown 形式のコメントを追加できます。モバイルでは、コメント可能な行をタップするとコメント入力欄が開きます。コメントはスレッドでの返信、解決（Resolve）／未解決に戻す（Unresolve）、およびエージェントに対応させるためにスレッドをチャットへ送信する操作に対応しています。

セッションが GitHub PR にリンクされている場合、Lody のコメントを GitHub PR Review の行コメントとして同期できます。既存の GitHub レビュースレッドも Lody の Diff 内に表示されるため、コンテキストを確認しながらその場で返信できます。

ワークフロー全体については、[Diff コメント](/ja/docs/diff-comments)を参照してください。

## 会話全体の Diff

ラウンド単位の変更に加えて、チャット画面の右上隅にあるサイドバー展開ボタンをクリックすると、Files および Changes サイドバーを開けます。

`Changes` タブでは、現在の会話におけるすべてのファイル変更を確認できます。

## リモートレビュー

セッションのマシンがオンラインのとき、リモートデバイスからもデスクトップ UI と同じセッションファイルプロバイダー経由で変更されたファイルや Diff を開けます。Diff またはファイルがまだ同期中の場合、Lody は最新のワークスペーススナップショットから推測して表示するのではなく、現在の利用不可または読み込み中の状態を表示します。
