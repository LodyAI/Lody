# メンション

Lody では入力ボックスでメンション機能を利用できます。`@` を入力するとメンションメニューが開き、会話、ファイル、Issue、Pull Request、Skills、またはエージェントロールを選択できます。`$` は引き続き Skills へのダイレクトショートカットとして利用できます。

## 会話メンション

`@` を入力して **Sessions** を選び、別の会話を選択するとその会話を参照できます。現在のエージェントに対して、そのセッションへの連絡、関連コンテキストの読み取り、調査結果の交換、またはレビューの依頼などを指示できます。たとえば、実装用セッションをメンションし、最新のコミットをレビューして指摘事項を返信するよう現在のエージェントに依頼できます。

参照先のセッションは、別のエージェントを使用していたり、接続された別のマシン上で実行されていたりしても構いません。アクセスは引き続きワークスペースの権限に従い、作業を実行するには対象マシンがオンラインである必要があります。メンションは対象セッションを特定するためのものですので、やり取りしたいコンテキストや実行してほしい作業を説明する指示もあわせて入力してください。

利用可能な操作については[エージェントセッション制御](/ja/docs/session-orchestration/)を、エージェントやマシンをまたいだコンテキストの共有やレビュー依頼については[マルチエージェント連携ガイド](/ja/docs/agent-collaboration/)をご覧ください。

## ファイルメンション

`@` を入力して **Files** を選びます。続けて文字を入力すると、ファイル名またはファイルパスであいまい検索（ファジーマッチ）できます。上下の矢印キーで候補を選択し、Enter キーで確定します。メンションされたファイルは、フルパスのプロンプトコンテキストとしてコーディングエージェントに送信されます。

## Issue と Pull Request のメンション

ホームページでリポジトリを選択した状態で `@` を入力してメンションメニューを開き、**Issues** または **Pull Requests** を選ぶと、現在のリポジトリから対象を選択してメンションできます。

<MentionPreview locale="ja" kind="issue" />

上下の矢印キーで選択し、Enter キーで確定します。Lody は選択された項目を `#<number>` としてコンポーザーに書き込み、そのコンテキストをプロンプトに挿入します。これにより、エージェントは `Fix #12` や `Review the implementation in #56` のようなタスクを処理できるようになります。

## Skill メンション

`$` を入力すると、選択中のプロジェクトとエージェントマシンで利用可能な Skills を一覧表示できます。続けて文字を入力して名前で絞り込み、矢印キーと `Enter` で Skill を選択してください。

コンポーザーには読みやすい `$skill-name` トークンがそのまま残ります。メッセージを送信すると、Lody が対応する `SKILL.md` のパスを自動的に追加するため、エージェントがその指示を読み込んで従うことができます。

検出場所、プロジェクトおよびグローバルスコープ、オフライン時の動作については、[Skills](/ja/docs/skills) をご覧ください。
