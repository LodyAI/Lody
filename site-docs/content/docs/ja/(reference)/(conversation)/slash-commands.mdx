# スラッシュコマンド

チャット入力欄の先頭に `/` を入力すると、現在のエージェントが公開しているコマンドとワークスペースで利用可能な Prompt Shortcuts のメニューが開きます。接続しているエージェントがサポートしている場合、`/review`、`/compact`、`/undo` などのエージェントコマンドが利用できます。

<SlashCommandsPreview locale="ja" />

エージェントコマンドは Lody ではなく**エージェントによって提供**されます。各 Agent Config は機能検出（ケイパビリティディスカバリー）時に独自のコマンド一覧を通知するため、利用可能なコマンドは CLI の種類（Claude Code、Codex、Kimi、OpenCode、または任意の ACP レジストリランタイム）やマシンにインストールされているバージョンによって異なります。Prompt Shortcuts はワークスペースごとに定義され、それぞれに設定された公開範囲やスコープのルールに従います。

## メニューを開く

- 新しいターンの最初の文字として `/` を入力します。
- 続けて文字を入力すると、両方のソースから利用可能な候補が関連度の高い順に表示されます。完全一致、前方一致（プレフィックス）、単語の先頭一致、部分一致、さらに緩やかな一致の順に並びます。各行にはソースが表示され、`/` のみを入力した場合はソースごとにグループ分けされて表示されます。
- `↑` / `↓` キーで項目間を移動し、`Home` / `End` キーで最初または最後の項目へジャンプします。
- `Enter` キーでハイライトされているコマンドを挿入し、`Tab` または `Escape` キーで何も挿入せずにメニューを閉じます。

一致する候補がない場合は、その旨がメニューに表示されます。入力したテキストは通常の入力内容として入力欄にそのまま残ります。

## コマンドの動作

コマンドはエージェント側から提供されるため、各コマンドの動作はそのエージェントのドキュメントによって定義されています。主要なエージェントでよく公開されているコマンドの例は次のとおりです。

| コマンド   | 一般的な動作                                                           |
| ---------- | ---------------------------------------------------------------------- |
| `/review`  | 現在の差分（diff）や最近の変更をレビューするようエージェントに依頼する |
| `/compact` | 会話を要約・圧縮してコンテキストの空き容量を確保する                   |
| `/undo`    | エージェントが直前に生成した変更を元に戻す                             |

すべてのコマンド一覧や正確な仕様については、各エージェント自身のドキュメントをご確認ください。

## コマンド一覧を更新する

コマンド一覧は、マシン上の Agent Config ごとにキャッシュされます。新しいバージョンの CLI をインストールしたあとや、Agent Config の環境設定を変更したあとは、新しいコマンドが表示されるようにキャッシュを更新してください。

- Web UI の場合：**Agent Config** を開き、該当する設定を選択してオプションを更新します。
- CLI の場合：使用しているマシン上で `lody agent-config refresh-capabilities <idOrName>` を実行します。

詳しくは [Agent Config](/ja/docs/quickstart) および [CLI コマンド](/ja/docs/cli#agent-config-refresh-capabilities) を参照してください。
