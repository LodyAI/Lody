# 会話のコピー

## 単一メッセージをコピーする

チャット画面では、各メッセージバブルの下にコピーボタンがあります。クリックすると、そのメッセージをコピーできます。

## 会話全体をコピーする

セッションの `...` メニューを開き、**Copy** を展開して **Copy as Markdown** を選択します。Lody は現在表示されている会話履歴を再利用しやすい Markdown 形式でコピーします。

同じサブメニューからは、利用可能な場合にセッションのワークスペースパスやセッション URL をコピーすることもできます。

Markdown としてのコピーは記録を残すためのものであり、ライブの引き継ぎ（ハンドオフ）ではありません。セッション URL をコピーするだけでは、チームへのアクセス権も付与されません。同じセッションにチームメイトを招待する方法については、[コーディングエージェントのセッションを共有する](/ja/docs/session-handoff)をご覧ください。共有リンクとハンドオフの違いについては、[共有リンク vs ライブハンドオフ](/ja/docs/compare/share-link-vs-live-handoff)をご覧ください。
