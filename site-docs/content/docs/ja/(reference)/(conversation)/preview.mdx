# Lody Preview

Lody Preview を使うと、Lody のインターフェースからローカル開発サーバーのライブビューをセッション内に開けます。エージェントが UI コードを変更しているときに、localhost の URL を手動でコピーすることなく、デスクトップ、タブレット、モバイル、または別のデバイスから結果を確認したい場合に便利です。

## プレビューを開始する

エージェントに開発サーバーを起動して Lody Preview を使うよう依頼します。例：

```text
Start the Vite dev server and use Lody Preview to check the page.
```

Lody がセッションのプレビュー候補を検出したら、**Preview** タブを開きます。ローカルのデスクトップセッションの場合は、**Design mode** をオンにするとローカルプレビューを直接開けます（トンネルや共有可能なリモート URL は不要です）。リモートセッションの場合やプレビューを共有したい場合は、**Preview Remote** を使用して **Create connection** をクリックします。プレビューは、プレビューヘッダーにある電源ボタンから終了できます。

## レイアウトを確認する

プレビューツールバーには以下の機能があります：

- デスクトップ、タブレット、モバイルのビューポートプリセット
- 縦向き・横向きの画面回転
- 拡大・縮小、画面に合わせる、リセットの操作
- ドラッグでの移動（パン）やピンチ / Ctrl＋スクロールでの拡大・縮小ができるハンドモード
- 独立したブラウザータブでの表示が必要なページ向けの外部リンクで開くアクション
- プレビュー共有 URL のコピーボタン

会話や diff をすぐそばに表示したまま、これらのコントロールを使ってレスポンシブのブレークポイント、はみ出し（オーバーフロー）、タップ領域、レイアウトの変更を確認できます。

## ビジュアルアノテーション

アノテーションモードをオンにし、プレビュー内の UI 要素をクリックして、変更したい内容についてコメントを記入します。Lody はコメントを選択した要素に固定（アンカー）し、その参照をチャットへ送り返すことができるため、エージェントは視覚的な対象と指示の両方を把握できます。

ビジュアルアノテーションは、余白、配置、文言、色、レスポンシブレイアウトの問題など、具体的な UI のフィードバックに最も適しています。

## 注意事項

- ローカルの Design mode プレビューでは、ローカル開発サーバーが稼働し続けている必要があります。リモートプレビューでは、さらにセッションのマシンがオンラインである必要があります。
- 一部のアプリでは埋め込みプレビューがブロックされる場合や、外部タブの方が適切に動作するブラウザー機能が必要になる場合があります。
- プレビューの表示が古い場合は、プレビューを再読み込みするか、エージェントに開発サーバーの再起動を依頼してください。
