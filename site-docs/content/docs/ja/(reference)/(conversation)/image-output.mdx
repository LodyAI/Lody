# 画像出力

Lody はセッション内に最大 8 枚の画像を直接返すことができます。エージェントには、`フロントエンドの開発サーバーを起動し、ホームページが読み込まれるまで待ってから、スクリーンショットを送ってください。` のように依頼できます。Lody は得られた画像を自動的にチャットへアップロードします。

選択したランタイムが Codex の画像生成などの画像生成に対応している場合、セッションを離れることなく、生成された画像を会話内に表示することもできます。

## 生成画像

Codex の画像生成では、Lody は生成された画像をプロンプトやその後の追加リクエストと同じ会話内に保持します。これにより、修正を依頼したり、バリエーションを比較したり、生成されたアセットを後から参照したりしやすくなります。

## ユースケース

- モバイルから UI の結果を素早く確認する。
- ローカルマシンから視覚的な出力を送り返すようエージェントに依頼する。
- 生成された画像をプロンプトや実装コンテキストと並べて確認する。

## 使い方

1. セッションチャットを開きます。
2. スクリーンショットの撮影や、画像を返すその他の操作を実行するようエージェントに依頼します。Lody が画像を自動的に会話へアップロードします。
