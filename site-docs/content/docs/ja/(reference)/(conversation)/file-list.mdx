# ファイル一覧

Lody には 2 つのファイルビューがあります。

- **プロジェクトファイル**は、セッションを必要とせずにローカルプロジェクトや GitHub リポジトリを表示します。
- **セッションファイル**は、エージェントが変更したファイルを含め、現在のセッションワークツリーを表示します。

## プロジェクトファイルの閲覧

モバイルでは、**Projects** タブからプロジェクトを開き、**Files** に切り替えます。プロジェクトビューから直接フォルダーを掘り下げてテキストファイルを開くことができます。これは、所有マシンまたはリポジトリプロバイダーが利用可能な場合、ローカルプロジェクトと GitHub リポジトリの両方で機能します。

プロジェクトファイルの閲覧は、新しい会話を開始する前にリポジトリを確認したい場合や、デスクトップから離れているときにファイルを参照したい場合に便利です。

## セッションファイルの閲覧

チャット画面の右上隅にあるサイドバー展開ボタンをクリックすると、Files および Changes サイドバーが開きます。

`Files` タブでは、現在の会話におけるすべてのファイル一覧を確認できます。現在の会話で変更されたファイルはハイライト表示されるため、見つけやすくなっています。

テキストファイルをクリックすると、セッション内のファイルプレビューが開きます。長い行は自動的に折り返されるため、ログや生成されたファイル、コンパクトなソースファイルもプレビューペインで読みやすくなります。

## クイックオープンと検索

セッションのファイルビューアーでは、ファイル検索コントロールを使用してインデックス済みのファイルを検索し、ツリーをスクロールせずに開くことができます。テキストファイルを開いているときにファイルツールバーの検索アイコンをクリックすると、ファイル内検索コントロールが開きます。

## Markdown プレビュー

Markdown ファイルはデフォルトでソースモードで開きます。ファイルツールバーの目のアイコンをクリックするとレンダリングされたプレビューに切り替わり、もう一度クリックするとソースに戻ります。アイコンにマウスカーソルを合わせると、エディターを離れることなくプレビューを一時表示（ピーク）できます。

## リアルタイム編集

セッションファイルがリアルタイム共同編集プロバイダーによって提供されており、テキストファイルであって、かつ自身のロールに書き込み権限がある場合、ファイルビューアーが編集可能になります。編集内容はセッションワークツリーに保存され、共同作業者にリアルタイムで同期されます。

ファイルが読み取り専用である場合、履歴ファイルである場合、サイズが大きすぎる場合、バイナリファイルである場合、またはホストマシンがオフラインである場合、Lody はビューアーを読み取り専用に保ち、現在の利用可能状態をファイルステータスバーに表示します。
