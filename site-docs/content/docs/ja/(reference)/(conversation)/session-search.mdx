# 会話内検索

会話内検索は、長くなったセッションから文脈を素早くたどり直すのに役立ちます。検索対象は会話テキスト（自分のメッセージ、エージェントの返信、思考プロセス、提案されたプラン）で、完了したターンの折りたたまれたワークグループ内に格納されている進捗テキストや思考プロセスも含まれます。

ツール呼び出しは検索対象外です。ツール呼び出しのタイトル、ファイルパス、JSON の入出力、ターミナルのコマンドや出力、および diff はインデックスに含まれません。構造化されたプランのチェックリスト、ゴール、worktree スクリプトの出力も除外されます。ただし、メッセージや提案されたプランの中に記述されたファイルパスやコードスニペットは、会話テキストとして検索できます。

これは[グローバルセッションナビゲーション検索](/ja/docs/keyboard-shortcuts#コマンドパレットを開く)とは異なります。サイドバーの **Search** 項目や `Cmd/Ctrl+K` ではコマンドパレットが開き、タイトル、プロジェクト／リポジトリのラベル、ブランチ名でセッションを検索できます。こちらは会話テキストを検索するのではなく、セッション間を切り替えるための機能です。

## 検索を開く

- セッションメニューを開き、**Find in session** を選択します。
- デスクトップでは `Ctrl+F`、macOS では `Cmd+F` を押します。

検索ボックスはコンポーザーを覆い隠すことなく、会話の上部に表示されます。

## 検索結果を移動する

- 入力に合わせて一致するテキストがハイライト表示されます。
- カウンターに現在の結果番号と一致した総数が表示されます。
- `Enter` を押すと次の一致箇所へ移動します。
- `Shift+Enter` または上矢印キーを押すと前の一致箇所へ移動します。
- 一致する箇所がない場合、カウンターには `0 / 0` と表示されます。

現在選択中の結果が表示領域内にスクロールされ、一致箇所が折りたたまれたワークグループや思考カードの中にある場合は自動的に展開されます。

## クリアまたは閉じる

現在の検索クエリをクリアするには `Escape` を 1 回押します。検索を閉じるにはもう一度 `Escape` を押します。
