# コマンドパレットとキーボードショートカット

Lody には、アクションやセッションを検索するためのコマンドパレットと、アプリケーションおよびシステム全体のキーボードショートカットをカスタマイズできる設定ページが用意されています。

## コマンドパレットを開く

macOS では `Cmd+K`、その他のプラットフォームでは `Ctrl+K` を押します。`Cmd/Ctrl+Shift+P` でも開くことができます。

パレットでは次の操作が行えます。

- 現在のビューで利用可能なコマンドを検索する
- タイトル、プロジェクト/リポジトリのラベル、またはブランチ名でセッションを検索し、サイドバーを使わずに切り替える
- 各コマンドの横に現在割り当てられているキーバインドを表示する
- 矢印キーでの移動、`Enter` での実行、`Escape` での終了に対応する

現在の画面に該当しないコマンドは非表示になります。

サイドバーの **Search**（検索）項目からも同じパレットが開きます。セッションナビゲーション検索では会話の本文は検索されません。現在の会話内のテキストを検索するには、[会話内検索](/ja/docs/session-search)を使用してください。

## ショートカットのカスタマイズ

**Settings** -> **Keyboard**（設定 -> キーボード）を開きます。ショートカットの行をクリックし、新しいキーの組み合わせを押してください。

ここでは次の操作が可能です。

- コマンドのキー割り当てを変更する
- キー割り当てを削除する
- 未割り当てのコマンドにキーを割り当てる
- すべてのアプリケーションショートカットをデフォルトにリセットする
- 保存前に競合を確認して却下する

アプリケーションショートカットの変更は現在のデバイスに保存され、他のデバイスとは同期されません。ブラウザ側で予約されている一部のキーの組み合わせは、Web アプリでは捕捉できません。

## セッションタブの切り替え

デスクトップアプリでは、`Cmd/Ctrl+1` から `Cmd/Ctrl+8` で対応する番号の会話タブに直接移動でき、`Cmd/Ctrl+9` で最後のタブに移動します。これはブラウザのタブバーと同じ操作体系です。`Cmd/Ctrl+Shift+,` と `Cmd/Ctrl+Shift+.` で前後のタブに順に移動し、`Cmd/Ctrl+T` で新しいタブを開きます。

## 送信済みメッセージの呼び出し

会話の入力欄（コンポーザー）が空の状態で `Up` を押すと、その会話で最後に送信したメッセージが表示されます。そのまま `Up` を押し続けるとさらに過去のメッセージへ遡り、`Down` を押すと新しいメッセージへ進みます。最新のメッセージを超えて `Down` を押すと、入力欄は再び空になります。復元されるのはテキストのみで、添付ファイルや参照コメントは含まれません。

文字の入力、`Left`/`Right` キーの押下、またはテキスト内のクリックを行うと、呼び出したテキストを下書きとして通常の編集に戻ります。入力欄にすでにテキストがある場合は、`Up` と `Down` は通常どおりカーソルを移動します。

## デスクトップのグローバルショートカット

デスクトップアプリには、Lody にフォーカスが当たっていないときでも動作するシステム全体のショートカットも用意されています。これらは **Global shortcuts**（グローバルショートカット）セクションに表示され、個別にキー割り当てを変更できます。

Quick Session（クイックセッション）のデフォルトのショートカットは `Cmd/Ctrl+Shift+N` です。独立した小さな入力欄を表示または非表示にするため、Lody のメインウィンドウを最前面に出さずにセッションを開始できます。

グローバルショートカットの割り当てには、`Command`、`Control`、または `Alt` のいずれかを含める必要があります。OS や他のアプリがすでにそのキーの組み合わせを使用している場合、Lody は以前の割り当てを維持し、競合を通知します。
