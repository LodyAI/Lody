# 通知

Lody は、コーディングエージェントの会話が完了したとき、権限を求めたとき、またはエラーが発生したときにデバイスへプッシュ通知を送信するため、セッションの状態を常に把握できます。

## 通知を有効にする

### デスクトップブラウザー

デスクトップでは、**Settings** -> **General** -> **Push Notifications** に移動して通知を有効にします。

クリックすると、通知を許可するかどうかをブラウザーが確認してきます。**許可**をクリックしてください。

<NotificationPreview locale="ja" variant="browser" />

### モバイルアプリ

モバイルでは、まず [Lody アプリをインストール](/ja/docs/mobile)し、**Settings** -> **General** -> **Push Notifications** から通知を有効にします。

<NotificationPreview locale="ja" variant="mobile" />

モバイル通知は、承認リクエスト、完了したタスク、およびセッションを続行する前に確認が必要なエラーを把握するのに役立ちます。
