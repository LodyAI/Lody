# 組み込みターミナル

Lody デスクトップアプリには、ローカルセッション向けの対話型ターミナルが組み込まれています。現在のセッションワークスペースで開くため、外部のターミナルに切り替えることなく、テストの実行、Git 状態の確認、プロジェクトツールの利用ができます。

## 利用可能な環境

現在、組み込みターミナルは次の環境およびセッションに対応しています。

- Electron デスクトップアプリ
- ローカルマシンが所有するセッション
- ワークスペースディレクトリが利用可能な、アクティブおよび非アクティブなローカルセッション

リモートセッション、モバイルクライアント、および Web アプリでは、現在対話型ターミナルは提供されていません。アーカイブ済みまたは削除済みのセッションでは開くことができません。

## ターミナルを開いて管理する

下部バーのターミナルコントロールを使用するか、`Ctrl+\`` または `Cmd/Ctrl+J` を押します。1 つのセッションで最大 8 個のターミナルタブを開けます。

- `+` をクリックすると、別のターミナルが開きます。
- 下部のターミナルストリップからタブを切り替えます。
- 個別のタブを閉じると、そのシェルプロセスが停止します。
- パネルの境界線をドラッグして高さを調整します。

ターミナルにフォーカスがあるときに `Alt+N` を押すと、別のターミナルタブが開きます。ターミナルにフォーカスがない場合、同じショートカットで新しいセッションタブが作成されます。

## 作業ディレクトリとライフサイクル

Lody は、インターフェースから任意のパスを受け取る代わりに、セッションから作業ディレクトリを解決します。プロジェクトセッションの場合、これはセッションのワークツリーまたはプロジェクトディレクトリになります。

ターミナルプロセスは、セッションを切り替えたりインターフェースを再読み込みしたりした場合も含め、Lody CLI デーモンが実行されている間は利用可能なまま維持されます。セッションがアーカイブまたは削除された場合、あるいはデーモンが停止した場合に終了します。デーモンの再起動をまたいでターミナル履歴は保持されません。

## テーマと下部バー

ターミナルは、ANSI カラーを含め、現在の Lody のライト／ダークモードに追従します。下部バーには CLI ステータスコントロールも含まれており、クリックすると CLI 出力の表示・非表示を切り替えられます。CLI 出力とアクティブなターミナルは同じドック位置を共有しており、一度にどちらか一方のみが表示されます。

## フォント

デスクトップでは、**Settings** -> **Appearance** を開いて、Lody インターフェース用のシステムフォントと組み込みターミナル用のシステムフォントをそれぞれ選択できます。インターフェースフォントはデスクトップアプリ全体に適用され、ターミナルフォントはターミナルタブにのみ適用されます。いずれかの設定を Lody の組み込みフォントスタックに戻すには、**Default** を選択してください。
