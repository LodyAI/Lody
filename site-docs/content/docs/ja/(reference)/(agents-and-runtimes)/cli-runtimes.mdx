# CLI ランタイムの種類

Lody は、[ACP Registry](https://agentclientprotocol.com/get-started/registry) で公開されているすべての CLI ランタイムに対応しています。
利用可能なランタイム一覧はレジストリから読み込まれるため、このページではベンダーやコマンドの静的なリストを個別に管理していません。

## レジストリランタイム

1. **Settings** -> **Agent Config** を開きます。
2. 追加ボタンをクリックします。
3. 設定名を入力します。
4. レジストリ連携ピッカーから使用する CLI タイプを選択します。
5. 必要な環境変数を追加します。
6. **Test** ボタンが表示されたらクリックします。これにより、Lody がランタイムを起動し、対応モデルやランタイムモードを含む機能情報を読み取れることを確認します。
7. 設定を保存し、会話を作成する際にその設定を選択します。

レジストリ対応により、アップストリームで新しい ACP ランタイムエントリが追加されると、Lody もそれに追従して利用できるようになります。ただし、選択したランタイム自体のドキュメントに従って、ホストマシンに必要なコマンド、ログイン、認証情報、および依存関係をあらかじめインストール・設定しておく必要があります。

## カスタム ACP エージェント

使用したいエージェントが ACP 互換であるもののレジストリに公開されていない場合は、**Settings** -> **Agent Config** で **Custom ACP** を選択してください。

1. 設定名を入力します。
2. **CLI Type** を **Custom ACP** に設定します。
3. **Launch command** に、stdio 経由でエージェントを起動するコマンドを入力します。
4. 同じ Agent Config 内に必要な環境変数を追加します。
5. **Test** をクリックして、Lody がエージェントを起動し、機能情報を読み取れることを確認します。
6. 設定を保存し、会話を作成する際にその設定を選択します。

起動コマンドの例：

```bash
npx -y my-acp-agent --stdio
```

起動コマンドはコマンドと引数に解析され、直接プロセスとして起動されます。スペースを含む引数にはクォートを使用できますが、パイプ、リダイレクト、glob 展開、`$VARS` などのシェル機能は評価されません。環境変数は代わりに Agent Config 内に設定してください。

## 注意事項

- レジストリ内の一部のランタイムは、アップストリームでまだ実験的な段階にある場合があります。
- 使用する前に、Lody CLI を実行するホスト上で必要なログイン認証情報がすでに設定されていることを確認してください。
- ローカルランタイムの種類を使用するには、対応するホストコマンドが事前にインストールされている必要があります。
- 利用可能なモデルは、選択したランタイム、ローカルへのインストール状況、およびアカウント権限によって異なります。
