# Skills

Lody は、サポートされているプロジェクトおよびマシン全体のグローバルスキルディレクトリから Agent Skills を検出します。Skill とは、コーディングエージェント向けの再利用可能な指示を記載した `SKILL.md` ファイルを含むディレクトリのことです。

Lody における Skills は読み取り専用です。Lody は Skill ファイルの検出、表示、参照を行えますが、インストール、編集、同期は行いません。

## Skills の閲覧

デスクトップでは、**Settings** -> **Projects** を開き、プロジェクトを選択して **Skills** タブに切り替えます。

モバイルでは、プロジェクトを開いて **Settings** に切り替え、**Project skills** を選択します。

一覧はソースパスごとにグループ化され、名前、説明、バージョン、作成者、スコープ、シンボリックリンクの状態といった利用可能なメタデータが表示されます。Skill を開くと、`SKILL.md` のレンダリングされた本文を読むことができます。

## プロジェクトとグローバルの Skills

- **プロジェクト Skills** は、ローカルプロジェクト内または GitHub プロジェクトのデフォルトブランチ内にある認識された Skill ディレクトリから取得されます。
- **グローバル Skills** は、エージェントを実行しているマシン上の現在の OS ユーザー向けに認識されたディレクトリ（`~/.codex/skills` や `~/.claude/skills` など）から取得されます。

グローバル Skills はマシン固有です。GitHub プロジェクトの設定画面にはリポジトリの Skills が表示され、チャットではそのセッションに選択されたマシン上の互換性のあるグローバル Skills も候補として利用できます。

## Skill をメンションする

1. 会話で使用するプロジェクトと Agent Config を選択します。
2. コンポーザーに `$` を入力します。
3. 続けて文字を入力し、Skill 名で絞り込みます。
4. 矢印キーで選択して `Enter` キーを押すか、Skill をクリックします。

コンポーザーには読みやすい `$skill-name` トークンが保持されます。メッセージが送信されると、Lody はその参照を該当する `SKILL.md` のパスへと展開し、選択されたエージェントが読み込んで指示に従えるようにします。

エージェント間でディレクトリのサポート状況が異なる場合は、現在の ACP プロバイダーに応じてメニューがフィルタリングされます。

## 更新とオフライン時の動作

Lody は現在のデバイスに Skill のメタデータをキャッシュし、バックグラウンドで更新します。プロジェクトまたは所有マシンが一時的に利用できない場合でも、以前にキャッシュされた結果が古い状態（stale）または利用不可（unavailable）のステータス付きで引き続き表示されることがあります。

シンボリックリンクは、許可されたプロジェクトまたはユーザーのホームディレクトリの境界内に収まっている場合にサポートされます。安全でないリンクやリンク切れ（dangling link）はスキップされます。
