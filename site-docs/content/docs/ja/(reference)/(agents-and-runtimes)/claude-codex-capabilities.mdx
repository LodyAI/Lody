# Claude & Codex の機能

Lody は選択された Agent Config からランタイムの機能（ケイパビリティ）を検出し、サポートされている Claude Code および Codex の機能を会話 UI に直接表示します。

エージェントの設定を変更した後に機能が表示されない場合は、**Settings** -> **Agent Config** から該当する Agent Config の機能を再読み込みするか、その設定を所有するマシン上で `lody agent-config refresh-capabilities <idOrName>` を実行してください。

## Claude Code

### 実行中タスクのステアリング

Claude Code の作業中に、実行中のタスクを停止して最初からやり直すことなく方向性を変更するには、**Steer** を使用します。エージェントの稼働中に送信したメッセージでステアリングを行うには、**Settings** -> **General** -> **Queued message behavior** を **Guide** に設定するか、キュー内の最初のメッセージで **Steer** を選択します。Lody は、Claude Code が新しい指示を適用したことを確認するまでそのメッセージを保留状態に保ち、確認後にステアされたターンへ応答を続けてストリーミングします。

メインタスクをステアリングしても、Claude Code のバックグラウンドタスクが自動的にキャンセルされることはありません。それらのタスクが新しい方針になお適合するかどうかは Claude Code 側が判断するため、有益な並列作業の進捗を失うことなくメインの作業の方向性を切り替えられます。

### スラッシュコマンド

Claude Code は `/review`、`/compact`、`/undo` などのスラッシュコマンドを公開できます。入力欄の先頭に `/` を入力すると、現在の設定で利用可能なコマンドを一覧できます。

### AskUserQuestion

Claude Code はタスクの実行中に追加の質問を行うことができます。Lody はこれらのリクエストを、単一選択・複数選択・自由記述の入力に対応したインタラクティブカードとして表示し、あなたの回答をエージェントへ返送します。

### Fast Mode

一部の Claude Code 設定では、Fast Mode の切り替えトグル（コンポーザー下部のモードセレクターにある稲妻 ⚡ ボタン）が表示されます。オンにすると高速な応答プロファイルに切り替わります。トレードオフについてはツールチップに記載されています（トークンあたりのコストは高くなりますが、約 2.5 倍の速度で応答します）。このトグルは、選択中の設定がこのオプションに対応している場合にのみ表示され、選択内容はセッションごとに記憶されて次に送信するメッセージから適用されます。

### バックグラウンドタスク

Claude Code がサブエージェントやバックグラウンドのシェルコマンドなどの作業をバックグラウンドタスクとして起動すると、Lody は会話内にタスクパネルをインラインで表示します。

- タスクの実行中、パネルは展開された状態のままスピナーと **"Waiting on N background tasks"** というヘッダーを表示するため、処理の完了を待たずにチャットを続けられます。
- 各行には、タスクの実行主体（サブエージェントの種類、ワークフロー名、または `Bash` / `Task`）、任意の説明、および現在実行中のツールが表示されます。
- すべてのタスクが完了すると、パネルは **"N background tasks"** のサマリーに折りたたまれます。展開すると、使用したトークン数やツールを含め、各タスクの詳細を確認できます。

このパネルは進捗を表示するのみであり、個々のタスクをキャンセルすることはできません。

### スケジュールタスク

Claude Code は将来の実行をスケジュールし、それを処理するためにセッションを維持することもできます。コンポーザーの上部に **"Session will continue · N scheduled tasks pending"** と表示されるパネルが現れ、展開すると各エントリの詳細を確認できます。

- 次回の実行時刻とリアルタイムのカウントダウン（**"in 5 min"**、**"firing now…"**）
- 種別ラベル（単発の再開の場合は **Wakeup**、cron 実行の場合は **Scheduled**）と、繰り返し実行される場合は **Recurring** バッジ
- 実行内容を示す任意の概要

単発のウェイクアップは実行後まもなく一覧から消去されますが、定期スケジュールは一覧に残り、次回の実行時刻へ更新されます。このパネルは読み取り専用です。

## Codex

### 実行中タスクのステアリング

Codex の作業中にも **Steer** を使用できます。**Queued message behavior** を **Guide** に設定するか、キュー内の最初のメッセージで **Steer** を選択してください。Codex は実行中のタスクをキャンセルしたり別の Codex ターンを作成したりせず、同じアクティブなターンに新しい指示を追加します。Lody は、Codex がステアの適用を完了したことを確認してから会話を先へ進めます。

Codex が指示を適用できるタイミングに到達するまで、ステアは一時的に **Pending** のままになる場合があります。ステアはアクティブなターンのモデル、モード、および設定を引き継ぎます。キュー内のメッセージで異なる設定が指定されている場合、Lody はそのメッセージを保留状態のままにするため、指定した設定を維持したまま代わりに **Interrupt and send now** を使用できます。

### スラッシュコマンド

Codex も機能検出（capability discovery）を通じてスラッシュコマンドを公開できます。利用可能なコマンドの一覧は、インストールされている Codex のバージョンと選択された Agent Config によって異なります。

### Fast Mode

選択された Codex 設定がこのオプションに対応している場合、セッションコントロールから Codex の Fast Mode を切り替えられます。タスクに対してより高速な応答プロファイルが必要な場合に使用してください。

### 画像生成

Codex が画像生成の出力を返すと、Lody は生成された画像を会話内にアップロードするため、プロンプト、生成結果、その後の修正作業をすべて同じスレッドにまとめておけます。

### Goals

Codex Goals を使用すると、セッションに可視化されたタスク目標と進捗状態を持たせることができます。まず Codex 側で次のコマンドを実行してこの機能を有効にしてください。

```bash
codex features enable goals
```

有効化すると、Lody の会話画面およびセッション UI に目標（Goal）のステータスが表示されるようになります。各 Goal の実行では経過時間とトークン使用量も報告されるため、目標達成にどれだけのリソースを消費したかを一目で確認できます。
