# サブスクリプションクォータ

**Settings** -> **Agent Config** -> **Machines** に移動すると、Lody CLI を実行しているすべてのマシンを確認できます。
マシンが Claude Code または Codex のサブスクリプションでサインインしており、会話を実行したことがある場合、
Lody は 5 時間および 1 週間ウィンドウの残りクォータを表示します。
