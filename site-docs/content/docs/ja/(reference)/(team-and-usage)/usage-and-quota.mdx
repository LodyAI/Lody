# コンテキスト、トークン、クォータ

Lody では、コンテキストウィンドウの使用状況、トークン使用量／コスト、サブスクリプションのクォータを一元的に把握できます。

## コンテキストウィンドウの残り容量

セッションチャットでは、AI の各返信にコンテキストウィンドウの残量（パーセンテージ）を表示できます。

このインジケーターを活用することで、次のことが行えます。

- コンテキストのオーバーフローを防ぐ
- 要約するタイミングや新しいセッションを開始するタイミングを判断する
- 長時間実行するタスクを安定して維持する

<Callout type="warn" title="コンテキスト圧縮">

Claude Code または Codex に組み込まれている `/compact` コマンドを手動で実行してコンテキストを圧縮することは可能ですが、Lody は現在関連する UI 更新に対応していないため、エージェントからの返信は表示されません。

</Callout>

## トークン使用量と推定コスト

**Settings** -> **Stats** では、過去 24 時間、7 日間、30 日間、または全期間のトークン使用量の推移と推定コストを確認できます。概要にはアクティブなメンバーと使用されたモデルも表示され、グラフではモデル別およびメンバー別の内訳を確認できます。グラフの凡例項目を選択すると、その系列に絞って表示できます。

## サブスクリプションクォータの表示

**Settings** -> **Agent Config** -> **Machines** では、対応しているサブスクリプション枠（たとえば 5 時間枠や 7 日間枠）の残りクォータと更新時刻が Lody に表示されます。
