# Lody

Lody.ai を使うと、デスクトップ、モバイル、あらゆるブラウザーからコーディングエージェントを並列実行し、チームとコンテキストを共有できます。Claude Code、Codex、Grok、Kimi Code、Devin、Pi、DeepSeek Harness、Bub、Dimcode といった Lody 組み込みのプロバイダーをすべて利用できるほか、カスタム ACP エージェントや [ACP Registry](https://agentclientprotocol.com/get-started/registry) にある任意の CLI も実行できます。

## Lody の主な特長

- **作業を並列で実行できます。** 各セッションには専用の Git worktree が割り当てられるため、エージェント同士が互いの変更を上書きしません。詳しくは[並列コーディングエージェント](/ja/docs/parallel-agents)を参照してください。
- **使い慣れたエージェントをそのまま使えます。** Lody には Claude Code や Codex だけでなく多くのプロバイダーが組み込まれており、ACP Registry のすべてのランタイムやカスタム ACP コマンドも動作します。詳しくは [Agent Config](/ja/docs/quickstart) および [CLI ランタイムタイプ](/ja/docs/cli-runtimes)を参照してください。
- **エージェントの作業中にレビューできます。** ラウンド単位の差分表示、行コメント、GitHub PR のレビュー同期に対応しています。詳しくは [Diff Viewer](/ja/docs/diff-viewer) および [Diff Comments](/ja/docs/diff-comments) を参照してください。
- **1 つのエージェントに他のエージェントを統括させられます。** [エージェントのセッション制御](/ja/docs/session-orchestration)や[マルチエージェントコラボレーション](/ja/docs/agent-collaboration)を通じて、タスクの分割、委任、結果の収集を行えます。
- **チームへの状況共有もスムーズです。** トランスクリプトの代わりにライブセッションを共有できる[セッションのハンドオフ](/ja/docs/session-handoff)や、[チーム機能](/ja/docs/team)で作業状況を可視化できます。
- **デスクを離れても作業を続けられます。** [モバイルアクセス](/ja/docs/mobile)を使えば、iOS、Android、または任意のブラウザーから確認や指示出しが行えます。
- **CLI を稼働させ続けられます。** [デーモンモード](/ja/docs/cli#daemon-mode)を使って長時間実行の作業をバックグラウンドで動かし、後から復帰できます。
