# Lody

Lody.ai lets you run coding agents in parallel on desktop, mobile, and in any browser, and share
context with your team. You can run every built-in Lody provider: Claude Code, Codex, Grok, Kimi
Code, Devin, Pi, DeepSeek Harness, Bub, and Dimcode; you can also run custom ACP agents and any CLI
in the [ACP Registry](https://agentclientprotocol.com/get-started/registry).

## What Lody is good at

- **Run work in parallel.** Each session gets its own Git worktree, so agents do not overwrite each
  other. See [Parallel Coding Agents](/docs/parallel-agents).
- **Use the agents you already trust.** Lody ships many built-in providers, not just Claude Code and
  Codex; every ACP Registry runtime and custom ACP command also works. See
  [Agent Config](/docs/quickstart) and [CLI Runtime Types](/docs/cli-runtimes).
- **Review while the agent works.** Round-level diffs, line comments, and GitHub PR review sync.
  See [Diff Viewer](/docs/diff-viewer) and [Diff Comments](/docs/diff-comments).
- **Let one agent coordinate the others.** Split a task, delegate, and collect results through
  [Agent Session Control](/docs/session-orchestration) and
  [Multi-Agent Collaboration](/docs/agent-collaboration).
- **Keep the team in the loop.** Share a live session instead of a transcript with
  [session handoff](/docs/session-handoff), and keep work visible in [Team Features](/docs/team).
- **Work away from the desk.** Review and steer from iOS, Android, or any browser with
  [Mobile Access](/docs/mobile).
- **Keep the CLI running.** Background long-running work and recover it with
  [Daemon Mode](/docs/cli#daemon-mode).
