# Lody

Lody.ai lets you run coding agents in parallel on desktop and mobile, and share context with your team.

- Supports Claude Code, Codex, OpenCode, Kimi, custom ACP agents, and any CLI supported by [ACP Registry](https://agentclientprotocol.com/get-started/registry)
- Uses Git worktrees and session tabs to run coding tasks efficiently in parallel
- Better GitHub integration with automatic PR binding, CI status sync, and synced review comments
- Project and session file browsing with realtime editing for live collaborative files
- Live UI preview with responsive viewports and visual annotations for agent feedback
- Native iOS and Android apps so you can keep coding from your phone
- Push notifications when conversations finish, so you do not miss updates
- Team-shared agent settings and full conversation context to keep everyone aligned, including [live session handoff](/docs/session-handoff)

## New capabilities

- [Share a Coding Agent Session](/docs/session-handoff): invite a teammate into an existing session so they continue the same conversation, diffs, and worktree.
- [Session Tabs](/docs/session-tabs): keep the main chat, child chats, files, and diffs open in one session.
- [File List](/docs/file-list): browse project files, open session files, search inside files, preview Markdown, and edit live collaborative text files.
- [Diff Comments](/docs/diff-comments): leave Markdown comments on changed lines and sync them to GitHub PR Review.
- [In-Conversation Search](/docs/session-search): search messages, tool calls, terminal output, and diffs.
- [VS Code Themes](/docs/vscode-themes): use familiar editor colors for code, diffs, and file previews.
- [Daemon Mode](/docs/cli#daemon-mode): keep the CLI running in the background and recover automatically.
- [Image Input](/docs/image-input): send images as part of your chat context.
- [Lody Preview](/docs/preview): open live UI previews, switch device viewports, and send visual annotations back to the agent.
- [Claude & Codex Capabilities](/docs/claude-codex-capabilities): steer active tasks and use runtime-specific slash commands, questions, Fast Mode, image generation, and Goals.
- [CLI Runtime Types](/docs/cli-runtimes): use ACP Registry runtimes or your own ACP-compatible launch command.
- [Worktrees](/docs/worktrees): isolate tasks and run project-specific setup or cleanup scripts.
- [Context, Token & Quota](/docs/usage-and-quota): track context window, token cost, and subscription quota in Settings.
