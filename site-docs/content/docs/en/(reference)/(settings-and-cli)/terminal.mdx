# Embedded Terminal

The Lody desktop app includes an interactive terminal for local sessions. It opens in the current
session workspace, so you can run tests, inspect Git state, or use project tools without switching
to an external terminal.

## Availability

The embedded terminal currently supports:

- the Electron desktop app
- sessions owned by the local machine
- active and inactive local sessions whose workspace directory is available

Remote sessions, mobile clients, and the web app do not currently provide an interactive terminal.
Archived or deleted sessions cannot open one.

## Open and manage terminals

Use the terminal control in the bottom bar, or press `Ctrl+\`` or `Cmd/Ctrl+J`. You can open up to
8 terminal tabs in one session.

- Click `+` to open another terminal.
- Switch tabs from the bottom terminal strip.
- Close an individual tab to stop its shell process.
- Drag the panel divider to adjust its height.

When the terminal is focused, `Alt+N` opens another terminal tab. The same shortcut creates a new
session tab when the terminal is not focused.

## Working directory and lifecycle

Lody resolves the working directory from the session instead of accepting an arbitrary path from
the interface. For a project session, this is the session worktree or project directory.

Terminal processes remain available while the Lody CLI daemon is running, including when you
switch sessions or reload the interface. They are closed when the session is archived or deleted,
or when the daemon stops. Terminal history is not preserved across daemon restarts.

## Theme and bottom bar

The terminal follows the current Lody light/dark mode and selected VS Code code theme, including
ANSI colors. The bottom bar also contains the CLI status control; click it to show or hide CLI
output. CLI output and the active terminal share the same dock position and are shown one at a
time.

## Fonts

On desktop, open **Settings** -> **Appearance** to choose a system font for the Lody interface and
another for the embedded terminal. The interface font applies across the desktop app; the terminal
font applies only to terminal tabs. Select **Default** to return either setting to Lody's built-in
font stack.
