# Notifications

Lody sends push notifications to your devices when a coding-agent conversation finishes, asks for
permission, or encounters an error, so you can stay on top of session status.

## Enable Notifications

### Desktop Browser

On desktop, go to **Settings** -> **General** -> **Push Notifications** to enable notifications.

After you click it, your browser asks whether to allow notifications. Click **Allow**.

<NotificationPreview locale="en" variant="browser" />

### Mobile App

On mobile, first [install the Lody app](/docs/mobile), then enable notifications from
**Settings** -> **General** -> **Push Notifications**.

<NotificationPreview locale="en" variant="mobile" />

Mobile notifications are useful for approval requests, completed tasks, and failures you need to
inspect before continuing a session.
