# VS Code Themes

Lody includes VS Code themes so code, diffs, file previews, terminal output, and syntax highlighting can feel closer to your editor.

## Where to change themes

Go to **Settings** -> **Appearance**:

- **Theme** controls the overall Lody interface: light, dark, or system.
- **Code theme (dark)** is used when Lody is in dark mode.
- **Code theme (light)** is used when Lody is in light mode.

If the interface follows your system theme, Lody automatically switches between your selected light and dark code themes.

## Where code themes apply

The selected code theme applies to:

- code blocks and tool output in conversations
- the diff viewer
- file previews
- terminal output
- syntax highlighting colors

Theme choices are stored locally and sync across Lody tabs in the same browser.

## Embedded terminal themes

The desktop [Embedded Terminal](/docs/terminal) uses the same interface background, foreground,
selection, and terminal ANSI palette. Changing light/dark mode or the selected VS Code theme
updates open terminals without restarting them.

## Conversation font size

Go to **Settings** -> **General** -> **Conversation font size** to choose **Small**, **Default**, or
**Large**. This adjusts message text, rendered Markdown, and conversation tool or terminal output.
The setting is available on desktop and mobile and is stored on the current device.
