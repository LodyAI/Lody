# Diff Viewer

Lody syncs file updates made by the coding agent in real time after each conversation round.

## Diffs for the Current Round

When you ask AI to edit code and modify files, Lody compares the file state before and after that
conversation round. At the end of the round, it shows all file changes and changed line counts
below the coding agent message bubble.

<img src="/_docs-assets/conversation-diff.png" alt="" />

Click any file to open a diff tab and jump to that file. The first click may take a little extra
time while data syncs and loads.

<img src="/_docs-assets/diff-viewer.png" alt="" />

You can also click the expand control in the panel to view unchanged sections of the file.

## Line Comments

Hover a commentable diff line and click the `+` beside the line number to add a Markdown comment.
On mobile, tap a commentable line to open the comment box. Comments support threaded replies,
resolve/unresolve, and sending the thread back into the chat for the agent to handle.

If the session is linked to a GitHub PR, Lody comments can be synced as GitHub PR Review line
comments. Existing GitHub review threads also appear in the Lody diff so you can reply in context.

See [Diff Comments](/docs/diff-comments) for the full workflow.

## Diffs Across the Whole Conversation

In addition to round-level changes, you can click the sidebar expand button in the top-right corner
of the chat interface to open the Files and Changes sidebar.

In the `Changes` tab, you can view all file changes in the current conversation.

## Remote Review

When the session's machine is online, remote devices can open changed files and diffs through the
same session file provider used by the desktop UI. If a diff or file is still syncing, Lody shows
the current unavailable or loading state instead of guessing from the latest workspace snapshot.
