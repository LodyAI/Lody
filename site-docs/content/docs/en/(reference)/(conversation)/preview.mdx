# Lody Preview

Lody Preview lets a session open a live view of a local dev server through the Lody interface. It is useful when an agent is changing UI code and you want to inspect the result from desktop, tablet, mobile, or another device without manually copying localhost URLs.

<img src="/_docs-assets/20260507-preview.png" alt="" />

## Start a Preview

Ask the agent to start the dev server and use Lody Preview, for example:

```text
Start the Vite dev server and use Lody Preview to check the page.
```

When Lody detects a preview candidate for the session, open the **Preview** tab. For a local desktop
session, turn on **Design mode** to open the local preview directly; it does not need a tunnel or a
shareable remote URL. For a remote session or when sharing a preview, use **Preview Remote** and
click **Create connection**. The preview can be shut down from the power button in the preview header.

## Inspect Layouts

The preview toolbar includes:

- desktop, tablet, and mobile viewport presets
- portrait and landscape rotation
- zoom, fit, and reset controls
- hand mode for drag-to-pan and pinch/Ctrl-scroll zoom
- an external-open action for pages that need a standalone browser tab
- a copy button for the preview share URL

Use these controls to check responsive breakpoints, overflow, tap targets, and layout changes while keeping the conversation and diffs nearby.

## Visual Annotations

Turn on annotation mode, click a UI element in the preview, and write a comment about what should change. Lody anchors the comment to the selected element and can send that reference back into the chat so the agent has both the visual target and your instruction.

Visual annotations work best for concrete UI feedback, such as spacing, alignment, copy, color, or responsive layout issues.

## Notes

- A local Design mode preview needs the local dev server to keep running. Remote previews also need
  the session's machine to be online.
- Some apps may block embedded previews or require browser features that work better in an external tab.
- If the preview is stale, reload the preview or ask the agent to restart the dev server.
