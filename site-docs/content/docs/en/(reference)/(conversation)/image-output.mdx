# Image Output

Lody can return up to 8 images directly in a session. You can ask the agent to do something like `Start the frontend dev server, wait for the homepage to load, then send me a screenshot.` Lody will automatically upload the resulting images back into the chat.

When the selected runtime supports image generation, such as Codex image generation, generated images can also appear in the conversation without leaving the session.

<img src="/_docs-assets/20260317-lody-image-back.png" alt="" />

## Generated Images

For Codex image generation, Lody keeps the generated image in the same conversation as the prompt and any follow-up requests. This makes it easier to ask for revisions, compare variants, or refer back to the generated asset later.

## Use cases

- Quickly review UI results from mobile.
- Ask the agent to send back visual output from your local machine.
- Review generated images alongside the prompt and implementation context.

## How to use

1. Open a session chat.
2. Ask the agent to take a screenshot or perform another action that returns an image. Lody will automatically upload the image to the conversation.
