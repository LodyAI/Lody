# File List

Lody has two file surfaces:

- **Project files** show a local project or GitHub repository without requiring a session.
- **Session files** show the current session worktree, including files changed by the agent.

## Browse Project Files

On mobile, open a project from the **Projects** tab, then switch to **Files**. You can drill into
folders and open text files directly from the project view. This works for both local projects and
GitHub repositories when the owning machine or repository provider is available.

Project file browsing is useful when you want to inspect a repository before starting a new
conversation, or when you need to look up a file while away from your desktop.

## Browse Session Files

Click the sidebar expand button in the top-right corner of the chat interface to open the Files and
Changes sidebar.

In the `Files` tab, you can view the full file list for the current conversation. Files changed in
the current conversation are highlighted, so they are easier to find.

<img src="/_docs-assets/file-list.png" width="300px" />

Click a text file to open an in-session file preview. Long lines wrap automatically, which makes
logs, generated files, and compact source files easier to read in the preview pane.

## Quick Open and Search

From a session file viewer, use the file search control to find indexed files and open one without
scrolling through the tree. When a text file is open, click the search icon in the file toolbar to
open the in-file search control.

## Markdown Preview

Markdown files open in source mode by default. Click the eye icon in the file toolbar to switch to
a rendered preview; click it again to return to source. Hovering the icon peeks at the preview
without leaving the editor.

## Realtime Editing

When a session file is backed by a live collaborative provider, the file is a text file, and your
role has write access, the file viewer becomes editable. Edits are saved back to the session
worktree and synced to collaborators in real time.

If a file is read only, historical, too large, binary, or the host machine is offline, Lody keeps
the viewer read-only and shows the current availability state in the file status bar.
