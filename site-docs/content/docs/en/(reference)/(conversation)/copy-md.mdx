# Copy Conversations

## Copy a Single Message

In the chat interface, each message bubble has a copy button below it. Click it to copy that
message.

## Copy the Full Conversation

Open the session `...` menu, expand **Copy**, then choose **Copy as Markdown**. Lody copies the
visible conversation history in a reusable Markdown format.

The same submenu also lets you copy the session workspace path or session URL when those values are
available.

Copying Markdown is a record, not a live handoff. Copying a session URL also does not grant team
access. To invite a teammate into the same session, see [Share a Coding Agent Session](/docs/session-handoff).
The share-link vs handoff contrast is in [Share Link vs Live Handoff](/docs/compare/share-link-vs-live-handoff).
