# Image Input

Lody supports image input in session chat. You can send screenshots, UI mocks, error captures, and other visuals as part of the prompt context.

<img src="/_docs-assets/0304-image-input.png" alt="" />

## Use cases

- Explain visual bugs with direct screenshots.
- Ask AI to read UI details from images.
- Combine image evidence with code context in one turn.

## How to use

1. Open a session chat.
2. Open the attachment `+` menu and choose **Upload image**, paste an image from the clipboard, or
   drag image files anywhere over the session interface.
3. Enter your instruction and send.

You can attach up to 8 images to one message, with a maximum size of 5 MiB per image. Larger images
can be sent as regular files through [File Attachments](/docs/file-attachments).

<Callout type="warn">

Image capability depends on the current model. Make sure your selected model supports vision input.

</Callout>
