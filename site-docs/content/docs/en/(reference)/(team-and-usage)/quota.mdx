# Subscription Quota

Go to **Settings** -> **Agent Config** -> **Machines** to view all machines running the Lody CLI.
If a machine is signed in with a Claude Code or Codex subscription and has run conversations,
Lody shows the remaining quota for the 5-hour and 1-week windows.
