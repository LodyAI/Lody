# Mobile Access

Lody ships native iOS and Android apps so you can keep coding on the go.

Your phone controls agents on a connected machine; it does not execute the coding runtime itself.
For a workflow overview and official alternatives, see
[Remote Control for Your Coding Agents](/coding-agent-remote-control/).

## Connect the Execution Machine

1. Follow the [Quick Start](/docs/quickstart/) on the workstation or server where the agents will run.
   The desktop app starts a local CLI daemon, or you can run `npx lody daemon start` on the target
   machine and complete sign-in.
2. Keep that machine awake, online, and running the Lody CLI. Sleeping, disconnecting, or stopping
   the CLI makes live remote work unavailable.
3. Add the project and [configure the agent](/docs/agents/) on that machine, including any required
   runtime authentication and dependencies.
4. Sign in to the same Lody workspace on mobile. Select the project, execution machine, and Agent
   Config to start or continue a conversation.

The shared workflow supports configured Codex, Claude Code, Kimi Code, GLM over Claude Code,
DeepSeek Harness, and Pi integrations. GLM is a Claude Code provider preset; DeepSeek Harness is
a separate built-in ACP provider. Models, modes, permission controls, and extensions remain
runtime-dependent. This is not a claim of end-to-end verification across all six runtimes and
every mobile device. See the [integration guide](/docs/agents/#choose-an-integration) for setup boundaries.

## Install the App

### iOS

Install Lody on iPhone or iPad:

- [Download on the App Store](https://apps.apple.com/us/app/lody-run-code-agent-anywhere/id6761373528)
- [Open in TestFlight](https://testflight.apple.com/join/cUcDcVFa) (early builds)

### Android

Download the latest signed APK from the [Download page](/download).

## Features

### Live Activities on iOS

On iPhone, Lody can show running agent status on the Lock Screen and in Dynamic Island. You can
track progress without reopening the app.

When an agent asks for permission, Lody can also send an actionable Live Activity alert so you can
respond quickly from iOS.

### Push Notifications

Get notified when:

- A task completes
- An agent needs approval
- A PR is ready for review

Enable notifications in Settings > General > Push Notifications.

### Monitor Progress

Watch your agents work in real-time:

- Live terminal output
- File changes
- Session diffs and review comments
- Image previews, with long-press share and save actions

### Browse Project Files

Open a project from the mobile **Projects** tab, then switch to **Files** to browse its directory
tree and preview text files. You do not need to create a conversation first.

Project file browsing works for local projects and GitHub repositories when the owning machine or
repository provider is available. Realtime file editing is available on desktop today; mobile
editing is coming soon.

## Offline Support

The Lody mobile app works offline for:

- Viewing cached conversations
- Reviewing saved diffs

Changes sync automatically when you're back online.
