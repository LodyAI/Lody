# Command Palette and Keyboard Shortcuts

Lody provides a command palette for finding actions and sessions, plus a settings page for
customizing application and system-wide keyboard shortcuts.

## Open the command palette

Press `Cmd+K` on macOS or `Ctrl+K` on other platforms. `Cmd/Ctrl+Shift+P` also opens it.

The palette:

- searches commands that are available in the current view
- searches sessions so you can switch without using the sidebar
- shows the active keyboard binding beside each command
- supports arrow-key navigation, `Enter` to run, and `Escape` to close

Commands that do not apply to the current screen are hidden.

## Customize shortcuts

Open **Settings** -> **Keyboard Shortcuts**. Click a shortcut row, then press the new combination.

You can:

- rebind a command
- remove its binding
- assign a binding to an unbound command
- reset all application shortcuts to their defaults
- see and reject conflicts before saving

Application shortcut changes are stored on the current device and do not sync to other devices.
Some browser-reserved combinations cannot be intercepted in the web app.

## Switch session tabs

In the desktop app, `Cmd/Ctrl+1` through `Cmd/Ctrl+8` jump straight to that conversation
tab and `Cmd/Ctrl+9` jumps to the last one — the same convention browsers use for their
tab strip. `Cmd/Ctrl+Shift+,` and `Cmd/Ctrl+Shift+.` step to the previous and next tab,
and `Cmd/Ctrl+T` opens a new tab.

## Global desktop shortcuts

The desktop app also has system-wide shortcuts that work while Lody is not focused. These appear in
the **Global shortcuts** section and can be rebound separately.

The default Quick Session shortcut is `Cmd/Ctrl+Shift+N`. It opens or hides a small standalone
composer so you can start a session without bringing the main Lody window to the front.

Global bindings must include `Command`, `Control`, or `Alt`. If the operating system or another app
already owns a combination, Lody keeps the previous binding and reports the conflict.
