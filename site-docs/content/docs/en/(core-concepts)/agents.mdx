# Agent Config

Agent Config is Lody's abstraction for different coding CLIs. Each config consists of a CLI type
(Claude Code / Codex) plus environment variables.

By default, Lody uses the Claude Code / Codex subscription login from the machine running the Lody CLI.
You can also configure non-subscription setups through environment variables.

For non-subscription logins, go to **Settings** -> **Agent Config**, click the plus icon to
create a new config, and choose **Claude** for Claude-compatible endpoints.

<img src="/_docs-assets/agent-config-select.png" width="200px" />

Below are official and third-party API key setup examples. Copy them into environment variables and
replace the placeholders with your real API keys.

For ACP-compatible agents that are not published in the ACP Registry, use **Custom ACP** and provide the
launch command yourself. See [CLI Runtime Types](/docs/cli-runtimes#custom-acp-agent) for the setup
steps and command-line rules.

Agent configs can be shared so teammates use the same CLI setup. To hand off a live session — not
just the config — see [Share a Coding Agent Session](/docs/session-handoff).

## Claude

```bash
ANTHROPIC_AUTH_TOKEN=${CLAUDE_CODE_API_KEY}
```

## DeepSeek

```bash
ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
ANTHROPIC_AUTH_TOKEN=${DEEPSEEK_API_KEY}
API_TIMEOUT_MS=600000
ANTHROPIC_MODEL=deepseek-chat
ANTHROPIC_SMALL_FAST_MODEL=deepseek-chat
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
```

[Reference docs](https://api-docs.deepseek.com/zh-cn/guides/anthropic_api)

### DeepSeek Harness

Lody includes **DeepSeek Harness** as a built-in ACP provider. Create an Agent Config and choose
DeepSeek Harness. The **DeepSeek Official** tab only needs a DeepSeek API token. The **Custom
Endpoint** tab accepts an HTTP(S) API endpoint and its API key for a Harness-compatible service.
Lody stores these values as `DEEPSEEK_BASE_URL` and `DEEPSEEK_API_KEY`; you do not need to install
the standalone `dsh` command. Saving the official tab explicitly uses `https://api.deepseek.com`,
so an ambient endpoint variable from the host machine cannot redirect the config.

> **Known delegation limitation:** When a session uses a model other than DeepSeek-V4-Pro,
> delegated subagents may still use the session's creation-time DeepSeek-V4-Pro seed instead of the
> model shown for the parent session, which can increase usage costs. Follow the
> [upstream DSH discussion](https://github.com/deepseek-ai/deepseek-harness/discussions/4065) for the
> inheritance fix.

Lody follows the standard `DSH_HOME` location, so a separately installed `dsh` may share the same
`~/.dsh/sessions` root. Harness requires one compression format per root. Lody uses upstream's
`zstd` default for empty or compressed roots and preserves `none` for an existing raw-only root. If
both `session.jsonl` and `session.jsonl.zstd` artifacts exist, Lody stops before launching Harness
and leaves every artifact unchanged. Back up and migrate the root to one format, or launch Lody
with a separate `DSH_HOME`.

Sharing the root permits the two installations to coexist; it does not make their ACP sessions
interchangeable. This provider is separate from **DeepSeek over Claude Code**, which routes Claude
Code through DeepSeek's Anthropic-compatible endpoint.

## Kimi

Lody includes **Kimi Code** as a managed Agent provider. Select it when creating or configuring an
Agent, then complete its sign-in flow. Lody manages the supported runtime for the machine, so you do
not need to install or maintain its command separately.

The following environment-variable setup remains available when you want to use Kimi through a
Claude-compatible endpoint instead:

```bash
ANTHROPIC_BASE_URL=https://api.kimi.com/coding/
ANTHROPIC_API_KEY=sk-kimi-xxxxxxxxxxxxxxxxxxxxxxxxxx  # Generated API key
```

[Reference docs](https://www.kimi.com/code/docs/en/more/third-party-agents.html)

## GLM

The fastest setup is the **GLM over Claude Code** preset in **Settings** -> **Agent Config**. Pick
the endpoint that matches your API key, then paste your GLM API key — the rest is configured
automatically.

For the Zhipu BigModel endpoint (China):

```bash
ANTHROPIC_BASE_URL=https://open.bigmodel.cn/api/anthropic
ANTHROPIC_AUTH_TOKEN=<GLM_API_KEY>
ANTHROPIC_DEFAULT_OPUS_MODEL=glm-5.2[1m]
ANTHROPIC_DEFAULT_SONNET_MODEL=glm-5.2[1m]
ANTHROPIC_DEFAULT_HAIKU_MODEL=glm-4.7
CLAUDE_CODE_AUTO_COMPACT_WINDOW=1000000
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
API_TIMEOUT_MS=3000000
```

For the international z.ai endpoint, keep everything the same and only change the base URL:

```bash
ANTHROPIC_BASE_URL=https://api.z.ai/api/anthropic
```

Create an API key from your chosen endpoint's console (open.bigmodel.cn or z.ai).

## MiniMax

The fastest setup is the **MiniMax over Claude Code** preset in **Settings** -> **Agent Config**.
Just paste your `MINIMAX_API_KEY` and the rest is configured automatically:

```bash
ANTHROPIC_BASE_URL=https://api.minimaxi.com/anthropic
ANTHROPIC_AUTH_TOKEN=<MINIMAX_API_KEY>
API_TIMEOUT_MS=3000000
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
ANTHROPIC_MODEL=MiniMax-M3
ANTHROPIC_DEFAULT_SONNET_MODEL=MiniMax-M3
ANTHROPIC_DEFAULT_OPUS_MODEL=MiniMax-M3
ANTHROPIC_DEFAULT_HAIKU_MODEL=MiniMax-M3
```

[Reference docs](https://platform.minimax.io/docs/coding-plan/claude-code)

## Xiaomi MiMo

The fastest setup is the **MiMo over Claude Code** preset in **Settings** -> **Agent Config**. It
supports both pay-as-you-go API keys and MiMo Token Plan keys.

For pay-as-you-go API keys:

```bash
ANTHROPIC_BASE_URL=https://api.xiaomimimo.com/anthropic
ANTHROPIC_AUTH_TOKEN=sk-xxxxx
ANTHROPIC_MODEL=mimo-v2.5-pro
ANTHROPIC_DEFAULT_OPUS_MODEL=mimo-v2.5-pro
ANTHROPIC_DEFAULT_SONNET_MODEL=mimo-v2.5-pro
ANTHROPIC_DEFAULT_HAIKU_MODEL=mimo-v2.5-pro
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
CLAUDE_CODE_DISABLE_NONSTREAMING_FALLBACK=1
```

For Token Plan, use the `tp-` key and the Anthropic-compatible Base URL shown on your MiMo
Subscription page, for example:

```bash
ANTHROPIC_BASE_URL=https://token-plan-cn.xiaomimimo.com/anthropic
ANTHROPIC_AUTH_TOKEN=tp-xxxxx
ANTHROPIC_MODEL=mimo-v2.5-pro
ANTHROPIC_DEFAULT_OPUS_MODEL=mimo-v2.5-pro
ANTHROPIC_DEFAULT_SONNET_MODEL=mimo-v2.5-pro
ANTHROPIC_DEFAULT_HAIKU_MODEL=mimo-v2.5-pro
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
CLAUDE_CODE_DISABLE_NONSTREAMING_FALLBACK=1
```

## Qwen

```bash
ANTHROPIC_BASE_URL=https://dashscope.aliyuncs.com/apps/anthropic
ANTHROPIC_API_KEY=YOUR_DASHSCOPE_API_KEY  # Replace with your DashScope API key
ANTHROPIC_MODEL=qwen3.5-plus # You can switch to any supported model.
```
