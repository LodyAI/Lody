# Conectar Magpie

Magpie se conecta a los proveedores de modelos. Lody crea las configuraciones de los agentes. Mantén las claves de API de origen en Magpie; no necesitas copiarlas a Lody.

## Antes de empezar

- Ejecuta Magpie y el daemon de Lody en el **mismo servidor**, con al menos un modelo habilitado en Magpie.
- Inicia sesión en Lody y conecta el servidor a tu espacio de trabajo. Consulta [Inicio de sesión de la CLI](/es/docs/cli#comandos-principales).
- Usa una CLI de Lody que sea compatible con `import-magpie`. Estos comandos usan espacios de trabajo en la nube, no el modo solo local de OSS.

En el servidor, comprueba la compatibilidad del comando, inicia el daemon y busca tu espacio de trabajo:

```bash
lody agent-config import-magpie --help
lody daemon start
lody workspace list
```

Omite el inicio del daemon si ya está en ejecución. Reemplaza `my-team` a continuación por el ID, nombre o slug de tu espacio de trabajo.

## Importar todos los proveedores

```bash
lody agent-config import-magpie --workspace my-team --json
```

De forma predeterminada, esto se conecta a `http://127.0.0.1:3425` e importa siete proveedores:

| Valor de `--targets` | Nombre de configuración |
| --- | --- |
| `claude` | Claude-magpie |
| `codex` | Codex-magpie |
| `pi` | Pi-magpie |
| `dsh` | DSH-magpie |
| `kimi` | Kimi Code-magpie |
| `grok` | Grok-magpie |
| `bub` | Bub-magpie |

El comando solo importa a la **máquina que lo ejecuta**. No hay ninguna opción `--machine`. `127.0.0.1` hace referencia a ese servidor, no a tu equipo.
Bub requiere tener preinstalados el comando `bub acp` y el plugin ACP.

### Seleccionar agentes

Separa los destinos con comas. Por ejemplo, importa solo Pi y Codex:

```bash
lody agent-config import-magpie --workspace my-team --targets pi,codex --json
```

### Usar otro puerto o un enlace de importación

Para usar un puerto de Magpie diferente, pasa la URL raíz de la puerta de enlace sin `/v1`:

```bash
lody agent-config import-magpie --workspace my-team --gateway http://127.0.0.1:4000 --json
```

Si tienes un enlace de importación de Magpie, pasa el enlace completo:

```bash
lody agent-config import-magpie --workspace my-team --link 'lody://provider/import?v=1&data=…' --json
```

Usa `--link` o `--gateway`, no ambos. Con un enlace, el comportamiento predeterminado incluye todos los destinos que ofrece ese enlace; `--targets` solo puede seleccionar entre ellos.
La puerta de enlace debe usar una dirección HTTP de bucle invertido (loopback) local: `127.0.0.1`, `localhost` o `[::1]`.

## Leer el resultado

El arreglo `providers` del JSON contiene el `agentConfigId` y el `status` de cada destino:

| Estado | Significado |
| --- | --- |
| `queued` | La configuración se ha guardado; el daemon instalará o verificará el entorno de ejecución |
| `preparing-runtime` / `verifying` | Una configuración existente se está preparando o verificando |
| `awaiting-auth` | Una configuración existente necesita autenticación |
| `created` | La configuración se ha guardado; las solicitudes de modelos aún no están verificadas |
| `existing` | Ya existe una configuración para esta puerta de enlace y tipo de agente, y se conserva |

Consulta el progreso de la configuración en la página **Proveedores** de Lody. Una vez listo, selecciona ese proveedor en el servidor al crear una sesión.
Una importación correcta no demuestra que la inferencia de origen funcione. Envía un mensaje para verificarlo.

`synced: false` significa que la configuración está guardada localmente, pero la sincronización con el espacio de trabajo no está confirmada. Restablece la conectividad y vuelve a ejecutar la importación.

Las importaciones repetidas conservan las configuraciones existentes y reintentan las configuraciones fallidas con su configuración original.
Si Pi no es compatible, actualiza Lody en el servidor y reinicia su daemon, o excluye `pi` con `--targets`.

## Actualizar modelos y configuración

Administra los modelos en Magpie. Lody lee el catálogo más reciente en los inicios posteriores; las sesiones en ejecución no se actualizan automáticamente.
Lody administra la configuración nativa generada. Las ediciones manuales pueden sobrescribirse en el siguiente inicio.

En escritorio, al abrir un enlace de importación de Magpie existente se muestra un diálogo de confirmación y se realiza la importación a ese equipo de escritorio. Para importar a un servidor, ejecuta los comandos anteriores en el servidor.
