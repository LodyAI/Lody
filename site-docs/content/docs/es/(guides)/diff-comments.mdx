# Comentarios en diffs

Los comentarios en diffs te permiten revisar código directamente donde ocurrió el cambio. Úsalos para la revisión en equipo o envía una línea específica de vuelta al chat para que el agente pueda explicarla, corregirla o revisarla de nuevo.

## Agregar un comentario

1. Abre un diff de sesión desde el turno actual o desde la barra lateral `Changes`.
2. Pasa el cursor sobre una línea que admita comentarios y haz clic en el `+` junto al número de línea.
3. Escribe tu comentario. Se admite Markdown.
4. Haz clic en **Comment**, o presiona `Ctrl+Enter` / `Cmd+Enter`.

En dispositivos móviles, toca una línea del diff que admita comentarios para abrir el cuadro de comentarios.

## Responder y resolver

Los comentarios aparecen como hilos debajo de la línea del diff. Puedes:

- responder en el mismo hilo
- editar o eliminar tus propios comentarios
- hacer clic en **Resolve** cuando el hilo esté listo
- hacer clic en **Unresolve** para volver a abrirlo
- contraer un hilo cuando solo necesites el resumen

## Enviar un hilo al agente

Usa el botón de enviar en un hilo de comentarios para referenciarlo en el chat actual. Luego pídele al agente que aborde el comentario, explique las ventajas y desventajas o realice la corrección solicitada.

## Sincronizar con GitHub

Cuando la sesión está vinculada a un PR de GitHub, los nuevos comentarios de Lody pueden sincronizarse como comentarios de línea de revisión de PR de GitHub al habilitar **Sync to GitHub**.

Lody también carga los hilos de revisión de PR de GitHub existentes en el diff. Puedes leerlos en contexto y responder desde Lody; las respuestas se publican de vuelta en GitHub.
