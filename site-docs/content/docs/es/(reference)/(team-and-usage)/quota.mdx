# Cuota de suscripción

Ve a **Configuración** -> **Configuración de agente** -> **Máquinas** para ver todas las máquinas que ejecutan la CLI de Lody.
Si una máquina ha iniciado sesión con una suscripción de Claude Code o Codex y ha ejecutado conversaciones,
Lody muestra la cuota restante para las ventanas de 5 horas y 1 semana.
