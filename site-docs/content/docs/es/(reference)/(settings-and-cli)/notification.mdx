# Notificaciones

Lody envía notificaciones push a tus dispositivos cuando una conversación de un agente de programación
finaliza, solicita permiso o encuentra un error, para que puedas mantenerte al tanto del estado de la
sesión.

## Activar notificaciones

### Navegador de escritorio

En escritorio, ve a **Configuración** -> **General** -> **Notificaciones push** para activar las notificaciones.

Después de hacer clic, el navegador te preguntará si deseas permitir las notificaciones. Haz clic en **Permitir**.

<NotificationPreview locale="es" variant="browser" />

### Aplicación móvil

En dispositivos móviles, primero [instala la aplicación de Lody](/es/docs/mobile) y luego activa las notificaciones
en **Configuración** -> **General** -> **Notificaciones push**.

<NotificationPreview locale="es" variant="mobile" />

Las notificaciones móviles son útiles para solicitudes de aprobación, tareas completadas y fallos que necesitas
revisar antes de continuar una sesión.
