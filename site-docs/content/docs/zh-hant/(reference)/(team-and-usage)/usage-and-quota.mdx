# 上下文、Token 與額度

Lody 提供統一的檢視方式，協助你追蹤上下文視窗使用狀況、Token 用量／費用，以及訂閱額度。

## 上下文視窗剩餘容量

在工作階段對話中，每則 AI 回覆旁皆可顯示上下文視窗的剩餘百分比。

你可以利用這項指標來：

- 避免上下文溢位，
- 判斷何時該進行摘要或開啟新的工作階段，
- 維持長時間執行任務的穩定性。

<Callout type="warn" title="上下文壓縮">

你可以手動執行 Claude Code 或 Codex 內建的 `/compact` 指令來壓縮上下文，但 lody 目前尚未支援對應的 UI 更新，因此你不會看到任何 agent 的回覆。

</Callout>

## Token 用量與預估費用

在 **設定** -> **統計** 頁面中，你可以檢視過去 24 小時、7 天、30 天或所有可用歷史紀錄的 Token 用量趨勢與預估費用。概覽頁面同時會顯示活躍成員與所使用的模型，而圖表則依模型與成員細分用量。選取圖表圖例項目即可聚焦檢視該資料系列。

## 訂閱額度檢視

在 **設定** -> **Agent 組態** -> **機器** 頁面中，Lody 會顯示所支援訂閱時間視窗的剩餘額度與更新時間（例如 5 小時與 7 天時間視窗）。
