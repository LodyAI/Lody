# 內嵌終端機

Lody 桌面應用程式為本機工作階段提供互動式終端機。它會在目前的工作階段工作區中開啟，因此你可以直接執行測試、檢查 Git 狀態或使用專案工具，無須切換至外部終端機。

## 可用範圍

內嵌終端機目前支援：

- Electron 桌面應用程式
- 由本機擁有的工作階段
- 工作區目錄仍然可用的使用中與非使用中本機工作階段

遠端工作階段、行動用戶端以及網頁應用程式目前不提供互動式終端機。已封存或已刪除的工作階段無法開啟終端機。

## 開啟與管理終端機

使用底部列中的終端機控制項，或按下 `Ctrl+\`` 或 `Cmd/Ctrl+J`。單一工作階段最多可開啟 8 個終端機分頁。

- 點擊 `+` 以開啟另一個終端機。
- 從底部的終端機分頁列切換分頁。
- 關閉個別分頁即可終止其 Shell 程序。
- 拖曳面板分隔線即可調整高度。

當焦點位於終端機時，`Alt+N` 會開啟另一個終端機分頁。當焦點不在終端機時，相同的快捷鍵會建立新的工作階段分頁。

## 工作目錄與生命週期

Lody 會依據工作階段解析工作目錄，而非從介面接受任意路徑。對於專案工作階段而言，這會是該工作階段的 worktree 或專案目錄。

只要 Lody CLI daemon 仍在執行，終端機程序就會維持可用，包括當你切換工作階段或重新載入介面時。當工作階段被封存或刪除，或 daemon 停止時，終端機程序會隨之關閉。Daemon 重新啟動後，系統不會保留終端機歷史紀錄。

## 主題與底部列

終端機會跟隨 Lody 目前的淺色／深色模式，包含 ANSI 色彩。底部列也包含 CLI 狀態控制項；點擊它即可顯示或隱藏 CLI 輸出。CLI 輸出與目前使用中的終端機共用相同的 Dock 位置，且同一時間只會顯示其中一項。

## 字型

在桌面版中，開啟 **設定** -> **外觀**，即可為 Lody 介面選擇一種系統字型，並為內嵌終端機選擇另一種系統字型。介面字型會套用至整個桌面應用程式；終端機字型僅會套用至終端機分頁。選擇 **預設** 即可將任一設定恢復為 Lody 的內建字型堆疊。
