# 命令面板與鍵盤快速鍵

Lody 提供用於尋找動作與工作階段的命令面板，以及用於自訂應用程式與系統層級鍵盤快速鍵的設定頁面。

## 開啟命令面板

在 macOS 上按下 `Cmd+K`，在其他平台上按下 `Ctrl+K`。按下 `Cmd/Ctrl+Shift+P` 也能開啟。

命令面板可以：

- 搜尋目前檢視中可用的指令
- 依標題、專案／儲存庫標籤或分支名稱尋找工作階段，讓你無須使用側邊欄即可切換
- 在每個指令旁顯示目前的快速鍵綁定
- 支援方向鍵導覽、按 `Enter` 執行，以及按 `Escape` 關閉

不適用於目前畫面的指令會自動隱藏。

側邊欄的 **搜尋** 項目也會開啟同一個面板。工作階段導覽搜尋不會搜尋對話內容；若要尋找目前對話中的文字，請使用[對話內搜尋](/zh-hant/docs/session-search)。

## 自訂快速鍵

開啟 **設定** -> **鍵盤**。點擊任一快速鍵列，接著按下新的按鍵組合。

你可以：

- 重新綁定指令
- 移除現有的快速鍵綁定
- 為未綁定的指令指派快速鍵
- 將所有應用程式快速鍵重設為預設值
- 在儲存前檢視並拒絕衝突的組合鍵

應用程式快速鍵的變更會儲存在目前裝置上，不會同步至其他裝置。部分由瀏覽器保留的組合鍵無法在網頁版應用程式中被攔截。

## 切換工作階段分頁

在桌面版應用程式中，`Cmd/Ctrl+1` 到 `Cmd/Ctrl+8` 可直接跳轉至對應的對話分頁，而 `Cmd/Ctrl+9` 會跳轉至最後一個分頁——與瀏覽器分頁列的慣例相同。`Cmd/Ctrl+Shift+,` 與 `Cmd/Ctrl+Shift+.` 可切換至上一個與下一個分頁，`Cmd/Ctrl+T` 則會開啟新分頁。

## 喚回已發送的訊息

當對話的輸入框為空時，按下 `Up` 可顯示你在該對話中發送的上一則訊息。持續按 `Up` 可往更早的訊息回溯，按 `Down` 則往較新的訊息移動；超過最新一則訊息後再按 `Down`，輸入框會再次清空。此操作只會帶回文字內容，不包含附件或引用的評論。

輸入文字、按 `Left`/`Right` 或在文字區域內點擊，即會回到一般編輯模式，並將喚回的文字作為草稿保留。當輸入框中已有文字時，`Up` 與 `Down` 會如常移動游標。

## 桌面版全域快速鍵

桌面版應用程式也提供系統層級的快速鍵，即使 Lody 未處於聚焦狀態也能觸發。這些項目位於 **全域快速鍵** 區段中，可個別重新綁定。

Quick Session 的預設快速鍵為 `Cmd/Ctrl+Shift+N`。它會開啟或隱藏一個獨立的小型輸入視窗，讓你無須將 Lody 主視窗切到前景即可開始新的工作階段。

全域快速鍵綁定必須包含 `Command`、`Control` 或 `Alt`。若作業系統或其他應用程式已佔用該按鍵組合，Lody 會保留先前的綁定並回報衝突。
