# 通知

當 Coding Agent 對話完成、請求權限或發生錯誤時，Lody 會向你的裝置發送推播通知，讓你隨時掌握工作階段的狀態。

## 啟用通知

### 桌面瀏覽器

在桌面版上，前往 **設定** -> **一般** -> **推播通知** 即可啟用通知。

點擊後，瀏覽器會詢問是否允許傳送通知，請點擊 **允許**。

<NotificationPreview locale="zh-hant" variant="browser" />

### 行動應用程式

在行動裝置上，請先[安裝 Lody 應用程式](/zh-hant/docs/mobile)，再前往 **設定** -> **一般** -> **推播通知** 啟用通知。

<NotificationPreview locale="zh-hant" variant="mobile" />

行動裝置通知特別適合用於核准請求、已完成的任務，以及在繼續工作階段前需要檢視的失敗狀況。
