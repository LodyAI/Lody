# 檔案附件

Lody 在新建與現有對話中皆支援任意類型的檔案附件。附件會隨 Prompt 一同傳送，因此 Agent 可以直接從工作階段工作區讀取原始檔案，無需將內容貼入訊息中。

## 新增附件

1. 開啟輸入框中的附件 `+` 選單。
2. 選擇 **上傳檔案**，然後選取一個或多個檔案。
3. 等待進行中的上傳完成後，輸入任何指示並傳送訊息。

你也可以直接將檔案拖曳到工作階段介面中。發起新對話時，待傳送的附件會與該新工作階段保持關聯。

## 預覽與下載

支援文字預覽的檔案會在預覽視窗中開啟。你可以在其中：

- 檢視渲染後的 Markdown 或原始內容
- 複製原始文字
- 下載完整檔案

其他類型的檔案則以下載作為主要操作。在原生行動版 App 上，下載項目會透過系統分享選單開啟，方便你儲存檔案或傳送至其他 App。

## Agent 如何接收檔案

在該輪次（Turn）開始前，Lody 會將每個附件寫入工作階段工作區下的 `.lody/attachments/` 目錄，並提供檔案參照給 Agent。檔案內容不會直接插入文字 Prompt 中。

Agent 也可以回傳檔案與圖片。支援的 ACP 輸出與 Lody 上傳工具會將這些檔案以一般附件卡片的形式加入對話。

## 限制與保留期限

- 單則訊息最多可附加 8 個檔案。
- 單一檔案大小上限為 100 MiB。
- 接受所有檔案類型。
- 透過中繼儲存的檔案會保留 90 天。

圖片有獨立的處理機制：單則訊息最多可附加 8 張圖片，單張上限為 5 MiB。較大的圖片可改以一般檔案方式傳送。詳情請參閱[圖片輸入](/zh-hant/docs/image-input)與[圖片輸出](/zh-hant/docs/image-output)。

## 可用性

在 Agent 讀取附件前，所屬機器必須能先取得該附件。如果某個附件上傳失敗，請重試或將其移除；其他已成功上傳的附件仍可照常傳送。
