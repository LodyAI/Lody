# 對話內搜尋

對話內搜尋能協助你從長工作階段中找回上下文。它會搜尋對話正文：你的訊息、Agent 的回覆、思考內容與提案計畫——包含已完成輪次中摺疊起來的工作群組裡的進度文字與思考內容。

工具呼叫不列入搜尋：其標題、檔案路徑、JSON 輸入／輸出、終端機指令／輸出與 diff 皆不會進入索引。結構化計畫清單、目標與 worktree 指令碼輸出同樣會被排除。不過，寫在訊息或提案計畫中的檔案路徑或程式碼片段，仍可作為對話文字被搜尋到。

這與[全域工作階段導覽搜尋](/zh-hant/docs/keyboard-shortcuts#開啟命令面板)不同：側邊欄的 **搜尋** 項目與 `Cmd/Ctrl+K` 會開啟命令面板，讓你依標題、專案／儲存庫標籤或分支名稱查找工作階段，並在各工作階段之間切換，而不會搜尋對話正文。

## 開啟搜尋

- 開啟工作階段選單，選擇 **在對話中尋找**。
- 在桌面端按下 `Ctrl+F`；在 macOS 上則按下 `Cmd+F`。

搜尋框會浮現在對話上方，不會佔用輸入框。

## 瀏覽搜尋結果

- 輸入時會即時醒目提示符合的文字。
- 計數器會顯示目前的結果位置與符合項目總數。
- 按下 `Enter` 跳至下一個符合項目。
- 按下 `Shift+Enter` 或向上方向鍵跳至上一個符合項目。
- 若沒有符合的項目，計數器會顯示 `0 / 0`。

目前選取的結果會自動捲動至可視範圍內；若符合項目位於已摺疊的工作群組或思考卡片內，系統會自動將其展開。

## 清除或關閉

按一次 `Escape` 會清除目前的搜尋關鍵字；再按一次 `Escape` 則會關閉搜尋。
