# 斜線指令

在對話輸入框開頭輸入 `/`，即可開啟選單，瀏覽目前 Agent 所提供的指令以及工作區內可用的 Prompt Shortcuts。當連線的 Agent 支援時，可使用的 Agent 指令範例包括 `/review`、`/compact` 與 `/undo`。

<SlashCommandsPreview locale="zh-hant" />

Agent 指令是**由 Agent 提供**，而非由 Lody 內建。每個 Agent Config 都會在能力探索階段回報各自的指令清單，因此實際可用的指令取決於 CLI 類型（Claude Code、Codex、Kimi、OpenCode 或任何 ACP Registry 執行時期）以及該機器上安裝的版本。Prompt Shortcuts 則由工作區自行定義，並遵循各自的可見性與作用域規則。

## 開啟選單

- 在新輪次的開頭輸入 `/` 作為第一個字元。
- 繼續輸入時，來自這兩個來源的可用結果會依相關程度排序顯示：完全符合的名稱最優先，其次是前綴符合、詞首符合、文字包含與較寬鬆的比對。每一列都會標示其來源；若只輸入 `/`，則會將不同來源維持在各自的分組中。
- 按下 `↑` / `↓` 在項目之間移動，按下 `Home` / `End` 可跳至第一項或最後一項。
- 按下 `Enter` 插入目前反白選取的指令，或按 `Tab` / `Escape` 關閉選單而不插入。

若沒有任何符合的項目，選單會顯示提示；輸入的文字則會以一般內容保留在輸入框中。

## 指令的作用

由於指令來自 Agent 本身，其具體行為以該 Agent 的官方文件定義為準。常見 Agent 所提供的指令範例如下：

| 指令       | 常見行為                                    |
| ---------- | ------------------------------------------- |
| `/review`  | 請 Agent 審查目前的 diff 或近期的變更       |
| `/compact` | 摘要並壓縮目前對話內容，以釋放 context 空間 |
| `/undo`    | 復原 Agent 最近一次產生的變更               |

完整的指令清單與確切語意，請參閱各 Agent 自己的文件。

## 重新整理指令清單

指令清單會依各台機器上的個別 Agent Config 進行快取。當你安裝新的 CLI 版本或變更某個 Agent Config 的環境設定後，請重新整理快取，讓新的指令顯示出來：

- 從網頁介面：開啟 **Agent Config**，選擇該組設定，並重新整理選項。
- 從 CLI：在所使用的機器上執行 `lody agent-config refresh-capabilities <idOrName>`。

詳細說明請參閱 [Agent Config](/zh-hant/docs/quickstart) 與 [CLI 指令](/zh-hant/docs/cli#agent-config-refresh-capabilities)。
