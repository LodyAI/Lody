# 檔案列表

Lody 提供兩種檔案介面：

- **專案檔案**無需先建立工作階段，即可顯示本機專案或 GitHub 儲存庫。
- **工作階段檔案**會顯示目前工作階段的 worktree，包含由 Agent 修改的檔案。

## 瀏覽專案檔案

在行動裝置上，從 **Projects** 分頁開啟一個專案，然後切換至 **Files**。你可以逐層進入資料夾，並直接從專案檢視畫面開啟文字檔案。只要所屬主機或儲存庫 provider 可用，本機專案與 GitHub 儲存庫皆支援此功能。

當你想在開始新對話前先檢視儲存庫，或在離開電腦時需要快速查找檔案，專案檔案瀏覽功能就會非常實用。

## 瀏覽工作階段檔案

點擊對話介面右上角的側邊欄展開按鈕，即可開啟「檔案與變更」側邊欄。

在 `Files` 分頁中，你可以檢視目前對話的完整檔案列表。目前對話中有變更的檔案會以醒目方式標示，讓你更容易找到。

點擊文字檔案即可在工作階段內開啟檔案預覽。過長的單行內容會自動換行，讓日誌、產生的檔案與精簡格式的原始碼檔案在預覽窗格中更易於閱讀。

## 快速開啟與搜尋

在工作階段檔案檢視器中，使用檔案搜尋控制項即可尋找已建立索引的檔案並直接開啟，無需手動捲動瀏覽檔案樹。開啟文字檔案後，點擊檔案工具列中的搜尋圖示，即可開啟檔案內搜尋控制項。

## Markdown 預覽

Markdown 檔案預設會以原始碼模式開啟。點擊檔案工具列中的眼睛圖示可切換至渲染預覽；再次點擊則會返回原始碼模式。將游標懸停在該圖示上，即可在不離開編輯器的情況下快速預覽渲染結果。

## 即時編輯

當工作階段檔案由即時協作 provider 支援、該檔案為文字檔案，且你的角色具備寫入權限時，檔案檢視器便會轉為可編輯狀態。編輯內容會存回工作階段的 worktree，並即時同步給其他協作者。

若檔案為唯讀、歷史快照、檔案過大、二進位檔案，或是主機處於離線狀態，Lody 會讓檢視器保持唯讀，並在檔案狀態列中顯示目前的可用狀態。
