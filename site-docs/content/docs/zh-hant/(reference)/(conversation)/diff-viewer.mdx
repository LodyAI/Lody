# 差異檢視器

Lody 會在每次對話輪次結束後，即時同步 Coding Agent 所做的檔案更新。

## 目前輪次的差異

當你請 AI 編輯程式碼並修改檔案時，Lody 會比對該對話輪次前後的檔案狀態。在該輪次結束時，Coding Agent 訊息氣泡下方會顯示所有檔案變更以及變更行數。

<ConversationDiffPreview locale="zh-hant" />

點擊任一檔案即可開啟 diff 分頁並跳轉至該檔案。首次點擊時，資料同步與載入可能會需要一點時間。

<DiffViewerPreview locale="zh-hant" />

你也可以點擊面板中的展開控制項，檢視檔案中未修改的區段。

## 行內評論

將滑鼠游標移至可評論的 diff 行上，點擊行號旁的 `+` 按鈕即可新增 Markdown 評論。在行動裝置上，直接點擊可評論的行即可開啟評論輸入框。評論支援討論串回覆、標記為已解決／重新開啟，並可將討論串傳回對話中交由 Agent 處理。

如果目前工作階段已關聯至 GitHub PR，Lody 中的評論可同步為 GitHub PR Review 行內評論。GitHub 上現有的 Review 討論串也會顯示在 Lody 的 diff 中，方便你直接在上下文中回覆。

完整工作流程請參閱[差異註解](/zh-hant/docs/diff-comments)。

## 整個對話的所有差異

除了單一輪次的變更之外，你也可以點擊對話介面右上角的側邊欄展開按鈕，開啟 Files 與 Changes 側邊欄。

在 `Changes` 分頁中，你可以檢視目前對話中的所有檔案變更。

## 遠端審查

當工作階段所屬的機器在線上時，遠端裝置也能透過與桌面版介面相同的 session 檔案 provider 開啟變更的檔案與 diff。如果某個 diff 或檔案仍在同步中，Lody 會顯示目前的無法存取或載入中狀態，而不會從最新的工作區快照中自行推測內容。
