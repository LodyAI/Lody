# 圖片輸出

Lody 支援在單一工作階段中直接回傳最多 8 張圖片。你可以請 Agent 執行類似 `啟動前端開發伺服器，等待首頁載入完成後，傳一張截圖給我。` 的任務，Lody 會自動將產生的圖片上傳回對話中。

當所選的執行環境支援圖片生成（例如 Codex 圖片生成功能）時，生成的圖片也能直接顯示於對話中，無須離開目前的工作階段。

## 生成圖片

針對 Codex 圖片生成功能，Lody 會將生成的圖片保留在同一個對話中，與提示詞及後續修改請求放在一起。這能讓你更輕鬆地要求調整、比較不同版本，或稍後再回頭檢視生成的圖片素材。

<ImageOutputPreview locale="zh-hant" />

## 適用場景

- 在行動裝置上快速檢視 UI 畫面結果。
- 請 Agent 從你的本機電腦傳回視覺化輸出結果。
- 在同一處對照檢視生成的圖片、提示詞與實作上下文。

## 使用方式

1. 開啟工作階段對話。
2. 請 Agent 擷取螢幕畫面，或執行其他會回傳圖片的操作，Lody 便會自動將圖片上傳至對話中。
