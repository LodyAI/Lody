# Lody Preview

Lody Preview 讓你能在 Lody 介面中開啟工作階段裡本地開發伺服器的即時預覽。當 Agent 正在修改 UI 程式碼時，你可以直接在桌面、平板、手機或其他裝置上檢視畫面效果，無需手動複製 localhost 網址。

## 啟動預覽

請 Agent 啟動開發伺服器並使用 Lody Preview，例如：

```text
啟動 Vite 開發伺服器，並使用 Lody Preview 檢查頁面。
```

當 Lody 在目前工作階段中偵測到可預覽的服務時，請開啟 **Preview** 分頁。如果是本機桌面端工作階段，開啟 **Design mode** 即可直接開啟本機預覽，無需建立通道或產生可分享的遠端網址。如果是遠端工作階段或需要分享預覽，請使用 **Preview Remote** 並點擊 **Create connection**。若要關閉預覽，可點擊預覽標題列上的電源按鈕。

## 檢查版面配置

預覽工具列包含：

- 桌面、平板與手機視口預設
- 直向與橫向旋轉
- 縮放、適應視窗與重設控制項
- 手形模式，支援拖曳平移與雙指／Ctrl 滾輪縮放
- 外部開啟操作，適用於需要在獨立瀏覽器分頁中顯示的頁面
- 預覽分享網址的複製按鈕

透過這些控制項，你可以一邊檢查響應式斷點、畫面溢出、點擊區域與版面變化，同時讓對話與 diff 保持在旁側方便對照。

## 視覺標註

開啟標註模式後，點擊預覽中的 UI 元素，並寫下需要修改的說明。Lody 會將評論錨定到所選元素上，並可將該參照傳回對話中，讓 Agent 同時取得視覺目標與你的修改指示。

視覺標註最適合用於具體的 UI 回饋，例如間距、對齊、文案、色彩或響應式版面問題。

## 注意事項

- 本機 Design mode 預覽需要本機開發伺服器持續執行；遠端預覽還需要工作階段所在的機器保持在線。
- 部分應用程式可能會阻擋嵌入式預覽，或需要依賴在外部瀏覽器分頁中運作更佳的瀏覽器功能。
- 若預覽內容未更新，請重新載入預覽，或請 Agent 重新啟動開發伺服器。
