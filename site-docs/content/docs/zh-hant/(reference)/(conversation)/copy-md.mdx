# 複製對話

## 複製單則訊息

在對話介面中，每則訊息氣泡下方都有一個複製按鈕。點擊即可複製該則訊息。

## 複製完整對話

開啟工作階段的 `...` 選單，展開 **複製**，再選擇 **複製為 Markdown**。Lody 會將目前可見的對話紀錄複製為可重複使用的 Markdown 格式。

當工作階段工作區路徑或工作階段 URL 可用時，你也可以在同一個子選單中複製這些資訊。

複製為 Markdown 僅是一份紀錄，並非即時交接。複製工作階段 URL 也不會授予團隊存取權限。若要邀請團隊成員加入同一個工作階段，請參閱[共享編碼 Agent 工作階段](/zh-hant/docs/session-handoff)。關於分享連結與即時交接的差異比較，請參閱 [分享連結 vs 即時交接](/zh-hant/docs/compare/share-link-vs-live-handoff)。
