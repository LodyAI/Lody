# 圖片輸入

Lody 支援在工作階段對話中輸入圖片。你可以將螢幕截圖、UI 草圖、錯誤畫面等視覺內容作為 Prompt 上下文的一部分一併傳送。

<ImageInputPreview locale="zh-hant" />

## 適用情境

- 直接透過螢幕截圖說明視覺錯誤。
- 讓 AI 從圖片中判讀 UI 細節。
- 在同一個對話回合中，將圖片佐證與程式碼上下文結合。

## 使用方式

1. 開啟一個工作階段對話。
2. 開啟附件 `+` 選單並選擇 **上傳圖片**、從剪貼簿貼上圖片，或將圖片檔案拖曳至工作階段介面的任意位置。
3. 輸入你的指令並傳送。

每則訊息最多可附加 8 張圖片，單張圖片大小上限為 5 MiB。較大的圖片可透過[檔案附件](/zh-hant/docs/file-attachments)以一般檔案形式傳送。

<Callout type="warn">

圖片輸入能力取決於目前使用的模型。請確認你所選取的模型支援視覺輸入。

</Callout>
