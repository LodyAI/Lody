# 團隊功能

Lody 從最初版本起就支援團隊協作。你可以與團隊共享 Agent 設定與完整的對話上下文。我們也計畫推出更多團隊協作功能，包括共享文件、成員提及與任務管理等。

若要邀請隊友**加入現有的 Coding Agent 工作階段**，讓對方能接著同一段對話、Diff 與 Worktree 繼續作業——而不只是閱讀對話紀錄——請參閱[分享 Coding Agent 工作階段](/zh-hant/docs/session-handoff)。分享連結只是一份靜態紀錄，而非即時交接：請參閱[分享連結 vs 即時交接](/zh-hant/docs/compare/share-link-vs-live-handoff)。

若要同時執行多個 Agent——透過隔離的 Worktree、混用不同模型，以及讓團隊成員檢視工作階段——請參閱[平行 Coding Agents](/zh-hant/docs/parallel-agents)。

## 邀請成員

前往 **設定** -> **工作區** -> **一般**，接著在 **成員** 區塊中點擊 **邀請成員**。輸入該成員的電子郵件地址並選擇其角色，然後送出邀請。

送出邀請後，該成員會收到一封邀請電子郵件。你也可以複製邀請連結並手動傳送給對方。

## 變更成員權限

工作區擁有者與管理員可以透過成員列表右側的編輯操作，變更成員的權限。

## 移除成員

工作區擁有者與管理員可以使用成員列表右側的移除操作來移除成員。

## 檢視其他成員的工作階段

在首頁中，使用側邊欄篩選器即可在 **我的任務** 與 **全部任務**（行動版為 **團隊任務**）之間切換。列表預設為 **全部任務**。頭像會顯示每個工作階段是由誰發起的。

## 依成員檢視 Token 用量

在 **設定** -> **AI 用量** 中，你可以檢視整體的 AI Token 用量與趨勢圖表。使用 **依成員** 即可檢視各成員的用量明細。

## 團隊機器可見性

你所註冊的每台機器**預設皆為私人**。加入他人的工作區不會公開你自己的開發機器，其他成員既無法在機器列表中看到它，也無法在上面啟動工作階段。

當你希望隊友能夠存取特定機器——例如共用的建置伺服器或雲端 Worker——你可以明確將它分享給該工作區。

### 分享機器

1. 前往 **設定** -> **機器**。
2. 在 **我的機器** 下方找到目標機器。
3. 開啟 **分享機器** 開關。

設定完成後，該機器就會出現在其他成員的 **Team Machines** 下方，他們在建立工作階段時便能選取這台機器。你可以隨時將開關關閉；一旦取消分享，該機器便會從其他成員的機器列表中消失，他們的工作階段側邊欄也會停止接收在這台機器上執行的對話。

只有機器的擁有者才能變更其分享狀態。

### 「分享」代表什麼

- **列表可見性**：已分享的機器會顯示在每位成員機器設定中的 `Team Machines` 區段；未分享的機器僅會保留在擁有者自己的 `My Machines` 下方。
- **工作階段可達性**：工作階段只能建立在建立者擁有存取權限的機器上——包含自己的機器，以及任何目前已分享的團隊機器。
- **對話側邊欄**：在未分享的機器上執行的工作階段，不會同步到其他成員的側邊欄中。

加入工作區與授予機器存取權是完全解耦的——你可以放心邀請隊友，不必擔心自己的個人筆記型電腦會變成共用的 Worker。
