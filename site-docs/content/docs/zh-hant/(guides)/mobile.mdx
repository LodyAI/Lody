# 行動裝置存取

Lody 提供原生的 iOS 與 Android App，讓你隨時隨地都能繼續撰寫程式碼。

## 安裝 App

### iOS

在 iPhone 或 iPad 上安裝 Lody：

- [前往 App Store 下載](https://apps.apple.com/us/app/lody-run-code-agent-anywhere/id6761373528)

### Android

從[下載頁面](/zh-hant/download)取得最新簽章的 APK 安裝檔。

## 功能

### iOS 即時動態

在 iPhone 上，Lody 可以在鎖定畫面與動態島顯示正在執行的 Agent 狀態。你無需重新開啟 App，就能追蹤進度。

當 Agent 請求權限時，Lody 也可以傳送可直接操作的即時動態提醒，讓你從 iOS 快速回應。

### 推播通知

在以下情況接收通知：

- 任務完成
- Agent 需要核准
- PR 已可審查

在「設定」>「一般」>「推播通知」中啟用通知。

### 監控進度

即時查看 Agent 的運作情況：

- 即時終端機輸出
- 檔案變更
- 工作階段 diff 與審查意見
- 圖片預覽，支援長按分享與儲存操作

### 瀏覽專案檔案

在行動裝置的 **Projects** 分頁開啟專案，接著切換至 **Files**，即可瀏覽目錄樹並預覽文字檔案。你不需要先建立對話。

只要所屬機器或儲存庫提供者可用，本機專案與 GitHub 儲存庫皆支援專案檔案瀏覽。目前桌面端已支援即時檔案編輯；行動裝置編輯功能即將推出。

## 離線支援

Lody 行動 App 在離線狀態下支援：

- 檢視快取的對話
- 檢視已儲存的 diff

恢復連線後，變更會自動同步。
