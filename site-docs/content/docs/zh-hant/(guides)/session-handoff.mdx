# 與團隊共享並交接編碼 Agent 工作階段

Lody 中的**編碼 Agent 工作階段交接**，是指讓團隊成員直接開啟你已經啟動的**同一個**工作階段並接續進行。對方能取得即時對話、Agent 產生的檔案差異，以及該工作階段的 [worktree](/zh-hant/docs/worktrees)——而不是截圖、匯出的 Markdown，或像 ChatGPT 那樣只能*閱讀*歷史內容的分享連結。

這正是它與多數「分享 Claude Code session」做法的差異所在：那些方式通常只是發佈一份對話紀錄；而 Lody 則是邀請對方進入現有工作階段，讓他們能繼續對話並引導（steer）Agent。

另請參閱[工作階段](/zh-hant/docs/session)、[團隊功能](/zh-hant/docs/team)、[Agent Config](/zh-hant/docs/quickstart)，以及[分享連結 vs 即時交接](/zh-hant/docs/compare/share-link-vs-live-handoff)中的定義對比。

<Callout title="「接續進行」代表什麼">
  能夠開啟該工作階段的工作區成員，可以在相同的上下文中延續對話。Lody
  不會把工作階段變成唯讀回放。共享範圍仍受機器與專案的可見性限制——詳見下方的[權限](#權限)。
</Callout>

## 為什麼對話紀錄連結不算交接

大家平時分享 Agent 工作成果的方式有很多，但多半只停留在「你看看這個」。交接則是「你接著做下去」。

| 做法                         | 對方會拿到什麼                                       | 是否為同一個即時工作階段？         | 檔案差異與 worktree                                                |
| ---------------------------- | ---------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------ |
| 截圖                         | 對話畫面的一張圖片                                   | 否                                 | 否                                                                 |
| Markdown / 對話紀錄匯出      | 可貼到其他地方的靜態文字                             | 否——對方必須開新對話               | 否                                                                 |
| ChatGPT 式分享連結           | 對話的唯讀快照                                       | 否                                 | 否                                                                 |
| **Lody**                     | 工作區中既有的[工作階段](/zh-hant/docs/session)      | **是**——開啟即可接續               | **是**——即時 [diff](/zh-hant/docs/diff-viewer) 與工作階段 worktree |

分享連結與即時交接的完整定義請見[分享連結 vs 即時交接](/zh-hant/docs/compare/share-link-vs-live-handoff)。若你只需要留存紀錄，Lody 依然可以將對話匯出為 Markdown，這是另一項功能：[複製對話](/zh-hant/docs/copy-md)。此外，僅複製工作階段 URL 而未將工作階段共享給團隊，並不會授予團隊存取權限——該連結仍只對擁有者有效。

## 如何交接工作階段

### 1. 邀請團隊成員加入工作區

交接屬於團隊工作區的操作，對方必須先成為工作區成員。

1. 開啟 **設定** -> **工作區** -> **一般**。
2. 在 **成員** 區塊中點擊 **邀請成員**。
3. 輸入對方的電子郵件並選擇角色。
4. 對方可透過電子郵件接受邀請，或者你也可以複製邀請連結親自傳送給對方。

詳細說明請見[邀請成員](/zh-hant/docs/team#邀請成員)。

### 2. 讓工作階段對團隊可見

新增的機器預設為**私人**。唯有當工作階段所依賴的資源已共享時，該工作階段才會對團隊可見。

在工作階段中操作：

1. 開啟工作階段的 `...` 選單，或點擊桌面版工作階段標頭中的 **Private（私人）** 控制項。
2. 選擇 **Share with team…（與團隊共享…）**（若缺少的是裝置或專案授權，選項文字可能會顯示為 **Share device with team…** 或 **Share project with team…**）。
3. 確認。Lody 會共享所需的機器，若使用的是本機專案也會一併共享該專案，接著自動複製連結。

只有**裝置擁有者**才能進行共享。若該裝置尚未註冊團隊存取權限，請先完成註冊。你也可以不開啟特定工作階段，直接前往 **設定** -> **機器** -> **共享機器** 來共享機器。請參閱[團隊機器可見性](/zh-hant/docs/team#團隊機器可見性)。

<Callout type="warn" title="共享可能會擴大其他對話的可見範圍">
  共享工作階段時，可能會將對應的機器與／或本機專案共享給工作區中的所有成員，該裝置上的其他對話也可能隨之變得可見。確認對話框會在你確認前先說明影響範圍。
</Callout>

### 3. 引導對方開啟該工作階段

當工作階段對團隊可見後：

- 傳送已複製的工作階段連結給對方，或
- 請對方開啟首頁的工作階段列表。如果對方只看到自己的對話，請將側邊欄篩選條件從 **我的任務** 切換為 **全部任務**（行動版為 **團隊任務**）。每個項目的頭像會顯示是由誰發起的。列表預設為 **全部任務**。

對方開啟的是**原本那個**工作階段——既不是 Fork 分叉，也不是重新開一條對話串。

### 4. 接續工作

進入工作階段後，對方可以：

- 閱讀 Agent 先前已進行的完整對話
- 檢視目前的 [diff](/zh-hant/docs/diff-viewer)
- 在同一個 [worktree](/zh-hant/docs/worktrees) 與分支上繼續作業
- 傳送下一則提示詞，並引導同一個 [Agent Config](/zh-hant/docs/quickstart)

Fork 工作階段是另一種功能：它會將對話紀錄複製到一個**新的**工作階段中。**目前工作區**會保留在相同的檔案上；而**新 Worktree**（在提供該選項時）則會從已提交的 `HEAD` 隔離出獨立環境。當你想自己另開一條私人對話分支時請使用 Fork；若想讓團隊成員加入原本的工作階段，則不應使用 Fork。詳見 [Fork 工作階段](/zh-hant/docs/session#fork-工作階段)。

若要以團隊形式同時執行多個彼此隔離的工作階段，請參閱[平行編碼 Agent](/zh-hant/docs/parallel-agents)。
若要由單一 Agent 協調多個對話，請參閱[Agent 工作階段控制](/zh-hant/docs/session-orchestration)。

## 權限

| 控制項目     | 適用對象                                                           | 效果                                                                                     |
| ------------ | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| 工作區成員資格 | 你邀請的所有人                                                     | 任何人開啟團隊工作階段前的必要條件                                                       |
| 成員角色     | 擁有者與管理員負責管理成員                                         | 控制誰可以邀請、編輯或移除成員——詳見[修改成員權限](/zh-hant/docs/team#變更成員權限)      |
| 機器共享     | 僅限機器擁有者                                                     | 未共享機器上的工作階段不會出現在其他成員的側邊欄中                                       |
| 本機專案共享 | 機器擁有者（當工作階段使用本機專案時）                             | 團隊成員需要同時擁有專案授權與機器授權                                                   |
| 工作階段 URL | 擁有者隨時可用；團隊成員僅在工作階段對團隊可見後可用               | 複製 URL 不等同於 **Share with team…**                                                   |

加入工作區**不會**暴露你的筆電。在你主動共享之前，機器都會保持私人狀態。Agent Config 可以另外共享，讓團隊成員使用同一套 CLI 設定；詳見 [Agent Config](/zh-hant/docs/quickstart) 與[團隊功能](/zh-hant/docs/team)。

## 常見問題

### 我可以分享 Claude Code 工作階段讓團隊成員接續進行嗎？

可以，只要該工作階段是在 Lody 工作區中執行。先邀請對方加入、共享該工作階段（以及它所需的機器或本機專案），再請對方開啟該工作階段並繼續對話即可。這並不是唯讀的 Claude Code 對話紀錄匯出，也不是公開的快照連結。

### 這和 ChatGPT 的分享連結一樣嗎？

不一樣。ChatGPT 分享連結是一份**可供檢視的紀錄**——也就是唯讀快照。Lody 交接的是團隊工作區中**既有的編碼 Agent 工作階段**：包含同一段對話、檔案差異與 worktree。詳見[分享連結 vs 即時交接](/zh-hant/docs/compare/share-link-vs-live-handoff)。

### 如果團隊成員看不到這個工作階段該怎麼辦？

請檢查三件事：對方是否已接受工作區邀請、機器（以及本機專案，如有使用）是否已共享，以及對方目前檢視的是 **全部任務** 而非 **我的任務**。未共享機器上的對話永遠不會同步到其他成員的側邊欄中。

### 共享單一工作階段會把整台機器都共享出去嗎？

有可能。如果該機器尚未共享，**Share with team…** 會將其共享出去，團隊成員才能開啟並接續該裝置上的對話。同一台機器上的其他工作階段也可能會變得可見。你之後隨時可以在 **設定** -> **機器** 中關閉 **共享機器**。

### 我可以改為只傳送對話紀錄嗎？

可以。如果只需要留存紀錄，可從工作階段選單中複製單則訊息或選擇 **Copy as Markdown**。這不會讓對方接續即時工作階段。詳見[複製對話](/zh-hant/docs/copy-md)。
