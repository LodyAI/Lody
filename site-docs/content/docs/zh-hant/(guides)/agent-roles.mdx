# Agent 角色

**Agent 角色**封裝了你*如何*使用一個 Agent：它執行在哪台機器上的哪個
[Agent 設定](/zh-hant/docs/quickstart)、使用的模型與推理強度、權限模式，以及一段
可選的預設指令。為它設定一個 emoji 與名稱，這些選項就能簡化為一次點擊。

角色並非新的 Provider，也不是常駐執行的 Agent。它不會儲存 API 金鑰或 MCP 選擇——
那些設定仍保留在 Agent 設定中。

## 建立角色

兩個入口，同一個編輯器：

- **設定** → **Agent 角色** → `+` 按鈕。
- 輸入框執行設定中的**角色**列 → **使用目前設定新建角色**。此入口會以你正要執行的設定
  預先填好表單，是保留剛調整好的一組設定最快的方式。

選取機器與 Agent 設定，再選擇該 Agent 所提供的模型、推理強度與權限，
以及可選的預設指令。新建立的角色預設僅供你個人使用，直到你開啟
**分享至工作區**為止。

## 請 Agent 建立或更新角色

在進行中的 Lody 對話裡，你可以請 Agent 建立一個新角色，或更新你所擁有角色的
名稱、說明或預設指令。Agent 會透過
`lody_agent_role` 的 `create` 或 `update` 操作顯示一張確認卡片。
檢視提案的欄位後，點擊**儲存**即可套用變更，或直接關閉該卡片。

透過這種方式建立的新角色預設為私人角色，會綁定指定的機器與 Agent 設定，
並套用該 Agent 的預設執行設定。進行更新時，未要求修改的欄位會保持不變。
模型、權限、分享設定及其他選項仍可在「設定」中編輯。
你也可以透過 [CLI](/zh-hant/docs/cli#create-and-update-agent-roles) 提交相同的提案，
支援直接傳入參數或使用 JSON 檔案。

## 開始新對話時使用角色

輸入框的執行設定中，**角色**列位於 **Agent** 上方——因為一個角色能一次決定
其下方每一列的設定。

- 在桌面端，點開輸入框底部的執行設定按鈕並將游標停留在**角色**上：清單旁
  會有一個面板，清楚列出目前反白選取的角色實際會執行哪些內容。
- 在行動端，開啟執行設定面板；**角色**即為第一列。

選取一個角色後，其下方的各列設定便會隨之同步更新。接著輸入框底部會顯示該角色的
emoji 與名稱，並在旁以較小的字級列出其設定值。你實際用來開啟過對話的角色，
也會出現在**最近使用**下方。

選擇**無**只會清除角色名稱，不會清除設定：角色所套用的各項數值現在已成為你的目前設定，
因此取消選取角色時仍會保留這些數值。

只有當目前設定仍完全符合該角色時，底部才會顯示角色名稱。只要你手動更改了模型，
角色名稱就會隨之消失——底部絕不會顯示一個與實際執行內容不符的角色。

在現有對話中開啟的空白子分頁，同樣遵循這套「新對話」規則。它的機器與工作目錄
仍會保持附屬於父工作階段，但角色清單會列出該機器上所有的角色，涵蓋各種 Agent 類型。
選取其中一個角色後，草稿會切換至該角色的 Agent 設定，並在你送出第一則訊息時，
一併凍結其執行設定、預設指令與角色來源資訊。

## 在對話中使用角色

對話一旦建立，就已經在特定機器上執行著某個 Agent，角色無法將它遷移至別處。
因此，對話內的**角色**列：

- 僅提供綁定於**相同類型** Agent 的角色，確保該 Agent 能辨識其模型、推理強度與權限值；且
- 僅套用該執行設定——角色的預設指令不會被加入到
  已經進行中的對話裡。

之後每一列仍可隨時編輯。

## 用 @ 提及角色

輸入 `@` 並在 **Agent 角色**分類下選取一個角色，即可請目前的 Agent 用它開啟一個*新*對話：

```text
@code-reviewer 檢查這個分支的 diff，並回報任何可能出錯的地方
```

新對話會在該角色的機器與 Agent 設定上啟動，並已預先套用其模型、推理強度、
權限與預設指令。你送出訊息當下該角色所設定的內容，會被凍結進該次請求中，
因此之後編輯或刪除這個角色，並不會改變已被接受的工作。

你能提及哪些角色取決於你目前所在的位置：本機專案或純聊天僅提供同一台機器上的角色；
而 GitHub 專案還能使用你其他已授權機器上的角色，因為新對話會自行複製（Clone）儲存庫。
其他提及類型請參閱[提及](/zh-hant/docs/mention)。

## 分享

角色在分享之前僅供你個人使用。開啟**分享至工作區**後，工作區內的每位成員都能
看見、提及並執行該角色。它仍會在其所屬的機器上執行，因此成員需要擁有該機器的存取權限。

「私人」代表其他成員無法透過 Lody 搜尋、提及或執行它。這並非加密機制——
這也正是角色從一開始就不儲存任何機密資料的原因。

## 當角色無法執行時

角色會精確綁定一台機器與一個 Agent 設定，絕不會悄悄替換成其他項目。如果
該機器離線，或其 Agent 設定已被刪除，該角色仍會保留在「設定」與選擇器清單中，
並標示確切原因，直到你修復問題前都無法被選取。

編輯角色只會影響之後的使用。已經透過它開啟的對話會維持原有設定
繼續執行。
