# 安全碼

安全碼是一串數字，用來確認**您與團隊成員持有同一份[權限帳本](/zh-hant/docs/encrypted-workspaces-ledger)**：相同的成員、相同的裝置，以及相同的授權。

如果您的安全碼與其他成員及您其他裝置上顯示的結果相符，即代表工作區的成員與授權資訊一致。

## 為什麼需要安全碼

帳本中的每筆紀錄皆經過簽章，因此伺服器無法偽造紀錄。然而，伺服器仍可能**向不同人顯示不同版本的帳本**，例如對您隱藏某台裝置已被撤銷的紀錄。只檢視您自己手邊的複本，並無法察覺這種情況。

由兩個人各自獨立計算並比對安全碼，就能揭露這種差異。

## 安全碼的計算依據

安全碼是針對以下所有內容共同計算出來的摘要：

- 協定版本與用途
- 工作區及其第一筆紀錄（創世紀錄，genesis）
- 帳本目前的位置（共有多少筆紀錄）與最後一筆紀錄
- **目前完整的授權狀態**：每位成員、角色、裝置與公鑰

僅比對最後一筆紀錄並不足夠：遭到竄改的狀態仍可能搭配看似正確的最後一筆紀錄。這正是安全碼將實際授權狀態納入計算的原因。

QR code 內也包含帳本位置，因此掃描時即可判斷哪一方進度落後。

## 比對結果代表什麼

| 結果 | 含義 | 該怎麼做 |
| --- | --- | --- |
| 相符 | 雙方在相同位置接受了相同的成員、裝置與授權 | 無需任何操作 |
| 其中一方尚未更新 | 一方的帳本版本較舊；截至該位置為止的內容均相同 | 雙方重新整理後再比對一次 |
| 不相符 | 相同位置，但內容不同 | 請勿邀請或核准任何人；請立即通知工作區擁有者 |

位置不同並非遭到攻擊；通常只是其中一方尚未完成同步。

## 安全碼無法證明的事

- **對方的真實身分**：安全碼只能顯示雙方的紀錄相符。請務必確認您正在與認識的團隊成員進行比對。
- **過去每項變更都合理**：它僅證明雙方接受了相同的狀態，並不代表其中的每一步操作都應該發生。
- **此後永遠安全無虞**：安全碼只涵蓋當下該位置的狀態。一旦有新紀錄寫入，安全碼就會隨之改變；在重要時刻請重新比對一次。
- **若只與邀請您的人比對，參考價值有限**：如果該成員與伺服器串通，僅與其比對相符並無法證明什麼。請至少再與另一位成員進行比對。

## 如何比對

<Steps>
<Step>

雙方都在加密主控台中開啟「安全碼與歷史紀錄」並重新整理。

</Step>
<Step>

選擇「與團隊成員比對」，並掃描對方螢幕上的 QR code，或逐組唸出數字進行核對。

</Step>
<Step>

依據比對結果採取對應行動。當面、視訊通話或電話皆可；請勿僅透過 Lody 本身互相傳送安全碼。

</Step>
</Steps>
