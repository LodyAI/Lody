# 本機專案

Lody 支援將任意本機工作目錄新增為專案，建議透過桌面版應用程式來進行此工作流程。新增本機專案後，Lody 會跨裝置即時保持同步，包含對話紀錄、檔案差異檢視、Git 分支，以及各工作階段專屬的工作樹（worktree）。

## 新增本機專案

Lody 支援多種新增方式：

- 在桌面版應用程式中，點擊 `My Projects` 旁的新增按鈕，即可開啟本機檔案選擇器，挑選要新增的目錄。
- 在伺服器等非桌面環境中，請使用 [CLI 專案指令](/zh-hant/docs/cli#project-commands)，例如 `npx lody project add [path]`。

## 本機優先與離線可用性

在桌面版應用程式中，已存在於本機上的專案與工作階段，即使在沒有網路連線時依然可以使用。您可以從本機工作區目錄開啟它們、瀏覽對話紀錄並繼續工作；在本機所做的變更都會保留，並在恢復連線後自動同步。

僅限雲端的操作（例如在其他機器上開啟專案，或擷取新的 GitHub 資料）仍需要網路連線。若要從其他裝置移除專案，該專案所屬的機器也必須處於連線狀態。

## 本機專案的工作樹

本機專案現在採用與連結 GitHub 之專案相同的工作樹工作流程：

- 每個工作階段都會依需求自動建立各自獨立的工作樹。
- 當工作階段封存時，系統會自動回收對應的工作樹。

完整的架構與設計考量請參閱[工作樹](/zh-hant/docs/worktrees)。

## 同步程式碼 Agent 紀錄（Codex、Claude Code 等）

如果您先前已直接在本機專案上使用 Codex 或 Claude Code，Lody 可以將既有的對話紀錄匯入，讓您從任何裝置接續進行。

- 開啟 **設定 → 專案**，選擇該本機專案並觸發手動同步，即可匯入 Lody 在該機器上偵測到的 Agent 對話紀錄。
- 專案完成同步後，在 Lody 中啟動的新對話也會鏡像回寫至對應的 CLI（Claude Code、Codex 及其他支援的 ACP 架構 Agent），讓雙方隨時保持同步。
- 開啟已匯入的對話時，系統會依需求重新整理最新內容，確保您看到的永遠與底層 CLI 的狀態一致。

## 非 GitHub 專案的團隊可見性

本機專案預設為私人——即使加入工作區後，也只有您自己看得到。

若要針對未託管於 GitHub 的專案進行協作：

1. 開啟 **設定 → 專案**。
2. 選擇該本機專案。
3. 開啟團隊可見性開關。

之後團隊成員就能在側邊欄看到該專案，並針對它發起工作階段。與[共享機器](/zh-hant/docs/team#team-machine-visibility)相同，只有專案擁有者可以變更可見性設定，一旦關閉，該專案會立即從其他成員的檢視畫面中隱藏。

## 遠端存取本機專案

您可以從其他裝置（網頁版、行動版或另一台桌面版裝置）檢視所屬機器上的本機專案，無須親自坐在該機器前：

- 瀏覽專案目前的 Git 分支狀態。
- 直接在遠端機器上啟動工作樹，然後無論身在何處都能接續工作。

這讓手機操作或外出攜帶筆電的工作流程，在本機專案上也能擁有與連結 GitHub 之專案一致的體驗。

## 從其他裝置移除專案

即使本機專案的資料夾位於另一台裝置上，您依然可以從桌面版或行動版將自己的本機專案移除。

專案所屬的裝置必須處於連線狀態，因為 Lody 會將刪除請求傳送至該機器。在移除專案前，Lody 會先封存其工作階段，並請所屬機器清理該專案的工作樹設定。從 Lody 移除專案並不會刪除磁碟上的原始專案資料夾。

## 目前限制

- 本機專案目前尚無法直接推送至遠端分支，但您仍可請 Agent 代為處理相關的 Git 操作。
