# 工作階段分頁

工作階段分頁能讓單一任務延伸出多個工作介面，同時不遺失共享的上下文。重點不只是多開幾個聊天視窗，而是讓**不同的 Agent 重複使用同一個工作區**，讓它們看到相同的檔案、分支與未提交的變更，同時各自保留獨立的對話歷史。你可以開啟或關閉主對話與子對話，並在旁搭配使用檔案預覽與 diff 檢視。

## 何時使用分頁

- 在主分頁持續進行實作的同時，透過子分頁審查目前的變更。
- 在對話旁開啟檔案或 diff，方便在閱讀程式碼時隨時追問。
- 將同一個分支拆分為多個切入角度，例如「摘要此次變更」、「檢查潛在風險」以及「依據 PR 評論進行修復」。

## 建立子對話

1. 開啟一個工作階段，然後點擊分頁列上的 `+`。
2. 新分頁會繼承父工作階段的機器、專案或儲存庫、分支、Agent 設定、模型與權限預設值。在送出前，你可以選擇綁定於該機器的任意 Agent 角色；該角色可能會將草稿切換為另一種 Agent 類型。
3. 在新分頁中送出第一則訊息。Lody 會使用所選角色的執行設定與指令建立一個子工作階段。標題預設取自你 prompt 的第一行，之後可隨時雙擊分頁名稱來重新命名。

子分頁與父分頁共享同一個工作目錄上下文，但每個分頁都保有各自獨立的對話歷史。這使得它們非常適合針對同一項任務進行平行審查與後續追蹤工作。

## 檔案與 diff 分頁

- 點擊對話中的檔案路徑，即可開啟檔案預覽分頁。
- 點擊單輪 diff 中的檔案，即可開啟 diff 分頁。
- 從 `Files` 或 `Changes` 側邊欄點擊檔案，即可將其作為檢視分頁開啟。

在桌面端，檢視分頁會形成分割工作區：對話保留在左側，而目前作用中的檔案或 diff 則顯示在右側。在行動裝置上，檔案或 diff 會作為聚焦介面開啟，方便在小螢幕上閱讀。

## 管理分頁

- 拖曳分頁即可重新排序，目前的瀏覽器會記住該順序。
- 雙擊對話分頁即可重新命名。
- 主對話與子對話分頁皆可關閉。關閉狀態會在工作區內共享；這不會停止 Agent、封存對話，或移除其 worktree。
- 關閉目前作用中的對話時，會自動選取相鄰的分頁。若已無其他分頁，則會在同一工作區開啟一個本地新對話草稿；既有的草稿會保留其輸入內容。只有在你實際送出訊息時，才會建立真正的工作階段。已關閉的對話仍可隨時重新開啟。
- 歷史記錄按鈕會列出已關閉的對話，包含先前已封存的分頁。重新開啟已封存的對話時，也會一併將其從封存狀態還原。
- 重新開啟後，該分頁會對所有人可見，但僅會為你選取該分頁。檔案與 diff 分頁則維持原有的本地行為。
