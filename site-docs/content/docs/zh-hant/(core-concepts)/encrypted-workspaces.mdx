# 端對端加密工作區

在端對端加密工作區中，對話、檔案與 Agent 輸出**只能在您已授權的裝置上讀取**。Lody 的伺服器負責轉發及儲存資料，但始終只會看到其無法讀取的資料。

<Callout type="warn">
如果您遺失了所有已授權的裝置且沒有復原檔案，該工作區將永遠無法再開啟，Lody 也無法為您救回。請在建立工作區後盡快設定復原檔案。
</Callout>

## 與標準工作區的差異

| | 標準工作區 | 端對端加密工作區 |
| --- | --- | --- |
| 誰能讀取內容 | 具有權限的成員，以及 Lody 伺服器 | 僅限已授權的裝置 |
| 使用新裝置 | 登入 | 登入後，再從已授權的裝置核准 |
| 網頁應用程式 | 立即可用 | 必須先授權瀏覽器 |
| 遺失所有裝置 | 重新登入 | 需要復原檔案或 passkey |

## 日常操作

<Steps>
<Step>

**辨識加密工作區**：工作區名稱旁會顯示一把鎖。將滑鼠游標停留在鎖上即可查看說明。

</Step>
<Step>

**邀請團隊成員**：前往「設定 › 一般 › 開啟加密主控台 › 成員與邀請」傳送邀請。管理員核准後，對方的裝置便會收到金鑰。

</Step>
<Step>

**在新裝置上開啟**：新裝置會自動送出請求。您已授權的電腦或手機會跳出核准視窗；請確認兩邊螢幕上的數字一致，然後選擇「授權」。

</Step>
<Step>

**與團隊成員核對**：在「安全碼與歷史紀錄」中比對安全碼，確認所有人看到的成員與裝置清單一致。

</Step>
<Step>

**設定復原方式**：在「復原」中儲存復原檔案或新增 passkey，確保即使遺失所有裝置，您仍能開啟工作區。

</Step>
</Steps>

## 已知限制

- 在瀏覽器中使用時，安全性取決於 Lody 網站所提供的程式碼未遭竄改。如果您重視這一點，請使用桌面版或行動版應用程式。
- 當伺服器無法連線時，您的機器仍可在有限時間內繼續運作；邀請成員、核准裝置與更換金鑰等操作則需等待恢復連線後再進行。
