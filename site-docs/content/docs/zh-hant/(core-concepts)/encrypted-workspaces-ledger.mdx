# 權限帳本

每個端對端加密工作區都有一份**權限帳本**。在加密主控台中，它會顯示為「變更紀錄」。這份帳本決定誰是成員、每個人擔任什麼角色，以及哪些裝置可以接收金鑰。

## 帳本記錄哪些內容

帳本是一系列依序排列的紀錄，每筆紀錄描述一次變更，例如：

- 建立工作區（第一筆紀錄，稱為「創世」）
- 接納成員、變更角色、移除成員
- 新增或撤銷裝置
- 更換工作區金鑰
- 轉移擁有權

帳本只會記錄**帳號 ID 與裝置公鑰**，絕不記錄對話或檔案。顯示名稱與頭像來自帳號個人資料，不會儲存在帳本中。

## 每筆紀錄都帶有簽章

每筆紀錄都由執行該次變更的人，在**自己已授權的個人裝置上**進行簽署。簽章涵蓋操作內容、對象與工作區；只要更動任何一點，簽章就會失效。

伺服器僅負責儲存與轉發紀錄，**並未持有任何人的簽章金鑰**，因此無法代任何人簽署，也無法私自新增成員或裝置。

## 紀錄串連成鏈

每筆紀錄都包含前一筆紀錄的雜湊值，一路回溯至創世紀錄。

- 刪除、插入或調換任何一筆紀錄的順序，都會破壞整條鏈，裝置會立刻察覺。
- 新紀錄只能附加在目前的鏈尾。如果兩個人同時送出變更，只會有一方成功；另一方則須重新整理並再次確認。
- 變更會依照送交寫入的順序生效。如果在擁有者移除 B 之前，B 先接納了 C，那麼 C 仍會是成員；如果移除操作先完成寫入，B 先前發出的邀請就會失效。

## 誰可以簽署哪些操作

針對每一次變更，裝置都會**依據該次變更發生前那一刻的帳本狀態**來檢查簽署者的權限，而不是依據簽署者當初加入時擁有的權限。

| 變更項目 | 誰可以簽署 |
| --- | --- |
| 接納成員 | 擁有者或管理員 |
| 移除成員 | 擁有者或管理員 |
| 移除管理員、變更角色 | 僅限擁有者 |
| 轉移擁有權 | 僅限擁有者；原擁有者將變為管理員 |
| 新增自己的新裝置 | 您名下已授權的裝置之一；若裝置全數遺失，則使用復原檔案 |
| 撤銷裝置 | 該裝置的擁有者，或具備管理權限的成員 |
| 更換工作區金鑰 | 擁有者或管理員 |

遠端機器與復原裝置**永遠不具備管理權限**；它們只能接收金鑰並執行工作。

## 裝置如何驗證帳本

- **現有裝置**只有在滿足三個條件時才會接受新紀錄：能與前一筆紀錄串連、簽章有效，且簽署者在該時間點具備權限。
- **新加入的裝置**不一定每次都從創世紀錄開始重播。它可以先接受由擁有者或管理員裝置簽署的「目前狀態」快照，再逐筆驗證之後的每一筆紀錄。這代表該裝置信任這份快照的簽署者。
- **當驗證失敗時**，裝置會停留在最後一筆可信的紀錄、保留相關證據，並暫停邀請與核准操作。它**絕不會自動「修復」或跳過**異常紀錄。現有的對話仍可正常閱讀。

## 撤銷與更換金鑰

- 撤銷裝置只會影響該台裝置；撤銷您的筆記型電腦，不會連帶撤銷它過去曾核准過的手機。
- 移除成員會立即切斷其名下所有裝置的存取權限。移除後請務必**更換工作區金鑰**：新金鑰只會發送給仍處於授權狀態的裝置，因此持有舊金鑰的舊裝置無法解密新內容。不過，已經下載到對方裝置上的歷史紀錄無法收回。

## 帳本所仰賴的前提

帳本能防止伺服器**偽造**任何簽章，但它無法單靠自己確保每個人手上的都是**同一份且最新的**帳本。

目前的版本假設伺服器會提供完整、未被回溯且未分叉的帳本。如果伺服器向不同的人提供不同版本的帳本，它依然無法偽造簽章，但有可能對部分成員隱瞞某次撤銷操作。

這正是[安全碼](/zh-hant/docs/encrypted-workspaces-security-code)的用途：與團隊成員比對安全碼，就能確認你們是否持有同一份帳本。
