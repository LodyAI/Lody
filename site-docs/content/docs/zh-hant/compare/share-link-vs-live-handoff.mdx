# 分享連結 vs 即時交接

「分享我的工作階段」這句話常被混為一談，其實有兩種截然不同的意思：

- **分享連結**（或截圖、Markdown 匯出、封存檔）是一份**紀錄**。對方可以閱讀發生過什麼事；部分工具也能根據這份上下文啟動一次*新的* Agent 執行。
- **即時交接**則是邀請隊友加入**同一個**編碼 Agent 工作階段，讓對方能接著對話、檢視 Diff，並在同一個 Worktree 中繼續工作。

一份紀錄並不等於邀請對方進入即時對話、即時 Diff，或原本的工作目錄。

操作步驟與存取規則請參閱[分享 Coding Agent 工作階段](/zh-hant/docs/session-handoff)。團隊工作區請參閱[團隊功能](/zh-hant/docs/team)。

<Callout title="定義">
截圖、對話紀錄、分享連結或工作階段封存檔，都不是即時交接。檢視者不會加入你正在執行的工作階段，也不會繼承原本的 Worktree。交接需要具備工作區成員身分，並遵守工作階段交接頁面上的機器／專案共享規則——它並不是任何人都能開啟的公開 URL。
</Callout>

## 兩種不同的用途

| 用途 | 接收者能做什麼 | 是否為同一個即時工作階段？ |
| --- | --- | --- |
| 截圖 | 查看對話的一張圖片 | 否 |
| Markdown／對話紀錄匯出 | 將靜態文字貼入新的對話 | 否——必須重新開始 |
| ChatGPT 式分享連結 | 閱讀對話的靜態快照 | 否 |
| 分享連結／封存工具（例如 [Lore](https://lore.link/share) 或 [SpecStory](https://docs.specstory.com/cloud/session-sharing)） | 檢視渲染後的討論串或已儲存的歷史紀錄，或是將該上下文 Fork 至一次**新的** Agent 執行 | 否——檢視者不會加入正在執行的工作階段或原本的 Worktree |
| **即時交接** | 開啟現有的[工作階段](/zh-hant/docs/session)、繼續對話、審查即時 [Diff](/zh-hant/docs/diff-viewer)，並在同一個 [Worktree](/zh-hant/docs/worktrees) 中繼續作業 | **是** |

當你只需要留存紀錄時，Lody 仍然可以[將對話複製為 Markdown](/zh-hant/docs/copy-md)。單純複製工作階段 URL 而未將工作階段共享給團隊，也不會授予團隊存取權限——該連結仍僅對擁有者有效。

本頁不對任何分享連結產品進行評測。此處提及 Lore 與 SpecStory，僅作為交接頁面中已列出的「紀錄／封存」類別範例。

## 即時交接的實際運作方式

在 Lody 中，能夠開啟該工作階段的隊友會從相同的上下文接續進行：

- Agent 正在進行的即時對話
- Agent 產生的檔案差異（Diff）
- 該工作階段的 Worktree 與分支
- 同一個 [Agent Config](/zh-hant/docs/agents)，讓對方可以發送下一則提示詞

對方開啟的是**該**工作階段本身——不是 Fork，也不是全新的對話。Fork 會將歷史紀錄複製到一個**新的**工作階段；當你想開一條私人對話分支時才使用它。請參閱 [Fork 工作階段](/zh-hant/docs/session#fork-工作階段)。

交接屬於團隊工作區的操作。對方必須已是工作區成員，且只有在該機器（以及本機專案，如有）已共享的情況下，工作階段才會對團隊可見。步驟與邊界情況請參閱[分享 Coding Agent 工作階段](/zh-hant/docs/session-handoff)。

## 何時使用哪一種方式

| 目標 | 建議方式 |
| --- | --- |
| 對方只需要*閱讀*發生過什麼事 | 截圖、對話紀錄、分享連結或封存檔 |
| 你想在工作區之外保留一份紀錄 | 截圖、對話紀錄、分享連結或封存檔 |
| 你要從匯出的上下文啟動一次*新的* Agent 執行 | 截圖、對話紀錄、分享連結或封存檔 |
| 需要讓隊友接續進行**同一個**編碼 Agent 工作階段 | **即時交接** |
| 對方需要目前的 Diff 與同一個 Worktree（而非靠提示詞重建上下文） | **即時交接** |
| 對方已經是（或可以成為）[工作區](/zh-hant/docs/team)成員 | **即時交接** |

若要以團隊形式執行多個彼此隔離的工作階段——混用不同模型、各自獨立的 Worktree——請參閱[平行 Coding Agents](/zh-hant/docs/parallel-agents)。那是啟動更多新工作，而非交接單一工作階段。

## 權限

交接遵循產品指南中的相同規則。本頁不會額外新增公開分享連結的權限模型。

| 控制項目 | 效果 |
| --- | --- |
| 工作區成員身分 | 任何人開啟團隊工作階段的必要前提 |
| 成員角色 | 擁有者與管理員可管理誰能邀請、編輯或移除成員——請參閱[變更成員權限](/zh-hant/docs/team#變更成員權限) |
| 機器共享 | 未共享機器上的工作階段不會出現在其他成員的側邊欄中。只有裝置擁有者可以進行共享。 |
| 本機專案共享 | 若為本機專案，隊友必須同時取得專案授權與機器授權 |
| 工作階段 URL | 擁有者隨時可用；隊友僅在工作階段對團隊可見後才可用。複製 URL 不等於 **Share with team…** |

加入工作區並**不會**暴露你的筆記型電腦。在你主動共享之前，機器皆保持私人狀態。共享工作階段時，可能會連帶將其機器與／或本機專案共享給工作區中的所有成員；該裝置上的其他對話也可能隨之變得可見。請參閱[團隊機器可見性](/zh-hant/docs/team#團隊機器可見性)。

## 常見問題

### 分享連結和交接編碼 Agent 工作階段是一樣的嗎？

不一樣。分享連結、截圖、對話紀錄或封存檔都只是一份**可供檢視的紀錄**。對方可以閱讀內容，部分流程也能從該上下文啟動一次*新的* Agent 執行，但他們不會加入原本的即時工作階段，也拿不到原本的 Worktree。即時交接則是開啟工作區中現有的工作階段，讓隊友接續作業。

### 隊友可以透過分享連結接續我的 Claude Code 工作階段嗎？

透過對話紀錄、ChatGPT 式快照或封存檢視器是無法做到的。如果該工作階段在 Lody 工作區中執行，請先邀請對方加入、共享該工作階段（以及它所需的機器或本機專案），再請對方開啟**該**工作階段。詳細說明請參閱[分享 Coding Agent 工作階段](/zh-hant/docs/session-handoff)。

### 分享對話紀錄和即時協作有什麼差別？

分享對話紀錄是傳送一份靜態紀錄；即時協作則是讓隊友身處同一個工作階段之中：同一段對話、同一份 Diff、同一個 Worktree。匯出 Markdown 或複製 URL 都無法授予這種存取權限。

### 如果我只想傳送一份對話紀錄怎麼辦？

從工作階段選單中複製單則訊息，或選擇 **複製為 Markdown**。這不會授予即時存取權限。請參閱[複製對話](/zh-hant/docs/copy-md)。

### 為什麼隊友打不開我傳給他的工作階段 URL？

複製工作階段 URL 並不會共享工作階段。對方必須已是工作區成員、機器（以及本機專案，如有）必須已共享，而且對方應該查看**全部任務**而非**我的任務**。未共享機器上的對話絕不會同步至其他成員的側邊欄。
