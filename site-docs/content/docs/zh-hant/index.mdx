# Lody

Lody.ai 讓你在桌面端、行動裝置和任何瀏覽器上並行執行 Coding Agents，並與團隊共享上下文。你可以執行所有 Lody 內建的 Provider：Claude Code、Codex、Grok、Kimi Code、Devin、Pi、DeepSeek Harness、Bub 和 Dimcode；也可以執行自訂 ACP Agent 以及 [ACP Registry](https://agentclientprotocol.com/get-started/registry) 中的任何 CLI。

## Lody 的核心優勢

- **並行推進任務。** 每個工作階段都有獨立的 Git worktree，Agent 之間不會互相覆蓋檔案。請參閱[並行 Coding Agents](/zh-hant/docs/parallel-agents)。
- **使用你原本信賴的 Agent。** Lody 內建多種 Provider，不僅限於 Claude Code 和 Codex；所有 ACP Registry 執行環境與自訂 ACP 指令也都能運作。請參閱 [Agent Config](/zh-hant/docs/quickstart) 與 [CLI 執行環境類型](/zh-hant/docs/cli-runtimes)。
- **邊執行邊檢閱。** 支援回合層級的 diff、行內評論，以及 GitHub PR review 同步。請參閱 [Diff 檢視器](/zh-hant/docs/diff-viewer)與 [Diff 評論](/zh-hant/docs/diff-comments)。
- **讓一個 Agent 協調其他 Agent。** 透過 [Agent 工作階段控制](/zh-hant/docs/session-orchestration)與[多 Agent 協作](/zh-hant/docs/agent-collaboration)拆分任務、委派工作並彙整結果。
- **讓團隊隨時掌握進度。** 透過[工作階段交接](/zh-hant/docs/session-handoff)直接分享即時工作階段而非靜態對話紀錄，並在[團隊功能](/zh-hant/docs/team)中保持工作透明可見。
- **離開座位也能持續工作。** 透過 iOS、Android 或任何瀏覽器檢視並引導工作階段，請參閱[行動端存取](/zh-hant/docs/mobile)。
- **讓 CLI 持續在背景運行。** 將長時間執行的任務放至背景，並透過[守護行程模式](/zh-hant/docs/cli#daemon-mode)隨時恢復連線。
