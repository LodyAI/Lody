# 上下文、Token 与额度

Lody 提供统一的数据视角，帮助你查看上下文窗口余量、Token 用量/花费，以及订阅额度。

## 上下文窗口余量

在会话聊天中，每轮 AI 回复旁可显示上下文窗口剩余百分比。

你可以据此：

- 避免上下文过载，
- 判断是否该做总结或新开会话，
- 提升长任务连续性。

<Callout type="warn" title="上下文压缩">

你可以手动执行 Claude Code 或 Codex 自带的 `/compact` 命令来压缩上下文，但 lody 目前还未支持对应的 UI 更新，你将看不到任何 agent 的回复。

</Callout>

## Token 用量与预估花费

在 **设置** -> **统计** 页面，可以查看最近 24 小时、7 天、30 天或全部历史的 Token 用量趋势和预估花费。概览同时展示活跃成员和已使用模型，图表可按模型和成员查看用量；点击图例项目可聚焦对应数据系列。

<img src="/_docs-assets/0304-token-usage.png" alt="" />

## 订阅额度查询

在 **设置** -> **Agent 配置** -> **机器** 页面，可查看支持的订阅窗口额度余量及刷新时间（例如 5 小时与 7 天窗口）。
