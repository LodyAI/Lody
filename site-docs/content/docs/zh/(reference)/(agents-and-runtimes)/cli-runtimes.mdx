# CLI 类型支持

Lody 支持 [ACP Registry](https://agentclientprotocol.com/get-started/registry) 中发布的全部 CLI 运行类型。
可选运行时会从 registry 动态加载，所以这篇文档不再单独维护一份静态厂商或命令列表。

<img src="/_docs-assets/0304-more-cli.png" alt="More CLI" />

## Registry 运行时

1. 打开 **设置** -> **Agent 配置**。
2. 点击添加按钮。
3. 填写配置名称。
4. 从 registry 支持的 CLI 类型选择器中选择需要的运行时。
5. 添加需要的环境变量。
6. 如果出现 **Test** 按钮，点击它确认 Lody 能启动该运行时并读取能力列表，包括支持的模型和运行模式。
7. 保存配置后，在创建对话时选择它。

Registry 支持意味着 Lody 可以跟随上游新增的 ACP runtime。宿主机器仍然需要按对应 runtime
自己的文档安装命令、完成登录、配置凭据和依赖。

## 自定义 ACP Agent

如果你的 Agent 兼容 ACP，但尚未发布到 registry，可以在 **设置** -> **Agent 配置** 中选择 **Custom ACP**。

1. 填写配置名称。
2. 将 **CLI Type** 设为 **Custom ACP**。
3. 在 **Launch command** 中填写通过 stdio 启动 Agent 的命令。
4. 在同一个 Agent Config 中加入需要的环境变量。
5. 点击 **Test**，确认 Lody 能启动该 Agent 并读取能力列表。
6. 保存配置后，在创建对话时选择它。

启动命令示例：

```bash
npx -y my-acp-agent --stdio
```

Launch command 会被解析成命令和参数，并直接启动进程。带空格的参数可以使用引号，但 pipes、重定向、glob 展开、`$VARS` 等 shell 语法不会被执行。需要环境变量时，请写到 Agent Config 的环境变量中。

## 注意事项

- 部分 registry runtime 在上游可能仍属于实验性能力。
- 使用前请确保在 lody CLI 运行的主机上已经配置好所需登录信息。
- 本地运行类型需要先在主机安装对应命令。
- 模型可用性取决于所选 runtime、本地安装状态和账号权限。
