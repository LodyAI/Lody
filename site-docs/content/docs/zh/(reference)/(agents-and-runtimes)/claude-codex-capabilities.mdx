# Claude & Codex 能力

Lody 会根据当前选中的 Agent Config 识别运行时能力，并把 Claude Code 与 Codex 已支持的能力直接展示在对话界面中。

如果调整 Agent 配置后没有看到对应能力，可以在 **设置**-**Agent 配置** 中刷新该配置的能力，或在对应机器上运行 `lody agent-config refresh-capabilities <idOrName>`。

## Claude Code

### Steer 运行中的任务

Claude Code 工作期间，你可以使用 **Steer** 调整方向，而不必停止当前任务并重新开始。在 **设置** ->
**通用** -> **排队消息行为** 中选择 **Guide**，忙碌期间发送的新消息就会用于 Steer；使用 Queue 时，也可以对
第一条排队消息选择 **Steer**。Lody 会让消息保持等待状态，直到 Claude Code 确认已经应用这条新指令，再把
后续响应持续写入 Steer 后的对话轮次。

Steer 主任务不会自动取消 Claude Code 的后台任务。Claude Code 会根据新方向判断这些任务是否仍然有用，因此你
可以调整主要工作，同时保留仍有价值的并行进度。

### Fast Mode

部分 Claude Code 配置会提供 Fast Mode 开关——位于输入框下方模式选择区的闪电（⚡）按钮。开启后可获得
更快的响应，悬停提示会说明其权衡（大约快 2.5 倍，但每 Token 成本更高）。只有当所选配置支持该选项时开关
才会出现，且你的选择会按会话记住，并在下一条消息发送时生效。

### 后台任务

当 Claude Code 把工作分派给后台任务（子代理或后台 Shell 命令）时，Lody 会在对话中内联展示一个任务
面板：

- 任务运行期间，面板会保持展开，显示一个加载动画和 **"Waiting on N background tasks"** 标题，让对话
  不被阻塞。
- 每一行会显示任务的执行方（子代理类型、工作流名称，或 `Bash` / `Task`）、可选的描述，以及当前正在运行
  的工具。
- 全部完成后，面板会收起为 **"N background tasks"** 摘要，你可以展开查看每个任务，包括它消耗的 Token
  和使用的工具数量。

该面板仅用于展示进度，无法取消单个任务。

### 定时任务

Claude Code 还可以安排后续运行，并让会话保持存活以处理它们。输入框上方会出现一个面板，显示
**"Session will continue · N scheduled tasks pending"**；展开后可以看到每一项：

- 下一次触发时间以及实时倒计时（**"in 5 min"**、**"firing now…"**）。
- 类型标签——一次性恢复为 **Wakeup**，定时（cron）运行为 **Scheduled**——以及在计划重复时显示的
  **Recurring** 徽标。
- 可选的摘要，说明将要运行的内容。

一次性唤醒在触发后不久会从列表中消失；周期性计划会保留并滚动到下一次触发时间。该面板为只读。

## Codex

### Steer 运行中的任务

Codex 工作期间同样可以使用 **Steer**。你可以把 **排队消息行为** 设为 **Guide**，也可以对第一条排队消息
选择 **Steer**。Codex 会把新指令加入同一个活动 Turn，而不是取消任务或创建另一个 Codex Turn。只有在 Codex
确认已经接收并提交这条 Steer 后，Lody 才会推进对话。

Codex 需要等待合适的时机应用新指令，因此 Steer 消息可能会短暂显示为 **等待中**。Steer 会沿用活动 Turn 的
模型、模式和其他配置。如果排队消息要求不同的设置，Lody 会让它继续等待，你可以改用 **中断并立即发送** 来
保留这些设置。

### Goal

Codex Goal 可以让会话携带可见的任务目标和进度状态。使用前需要先在 Codex 中开启：

```bash
codex features enable goals
```

开启后，Lody 可以在对话和会话 UI 中展示 Goal 状态。每一次 Goal 运行还会展示耗时与 Token 消耗，让
你一眼看到完成目标花费了多少资源。
