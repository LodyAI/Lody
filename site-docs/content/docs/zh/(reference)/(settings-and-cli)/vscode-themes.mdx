# VSCode 主题

Lody 支持内置 VSCode 主题，让代码块、diff、文件预览、终端和语法高亮尽量接近你编辑器里的观感。

## 设置位置

进入 **设置** → **外观**：

- **主题**：控制 Lody 整体界面，可选择浅色、深色或跟随系统。
- **代码主题（深色）**：深色模式下使用的 VSCode 主题。
- **代码主题（浅色）**：浅色模式下使用的 VSCode 主题。

如果整体主题选择“跟随系统”，Lody 会根据系统深浅色自动切换到对应的代码主题。

## 生效范围

代码主题会应用到这些位置：

- 对话中的代码块和工具输出
- diff 查看器
- 文件预览
- 终端输出
- 语法高亮相关颜色

主题选择会保存在本机浏览器或客户端中，并会在同一浏览器的多个 Lody 标签页之间同步。

## 内嵌终端主题

桌面端[内嵌终端](/zh/docs/terminal)会使用相同的界面背景、前景色、选中颜色和终端 ANSI 色板。切换深浅色
模式或所选 VSCode 主题后，已经打开的终端会直接更新，无需重启。

## 对话字号

进入 **设置** -> **通用** -> **对话字号**，可以选择 **小**、**默认** 或 **大**。该设置会调整消息
正文、Markdown 渲染结果以及对话中的工具或终端输出，在桌面端和移动端均可使用，并保存在当前设备。
