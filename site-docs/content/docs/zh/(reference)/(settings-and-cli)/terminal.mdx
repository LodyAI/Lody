# 内嵌终端

Lody 桌面端为本机会话提供交互式终端。终端会在当前 Session 的工作目录中启动，方便你运行测试、查看
Git 状态或使用项目工具，无需切换到外部终端。

## 可用范围

内嵌终端目前支持：

- Electron 桌面端
- 由当前机器拥有的 Session
- 工作目录仍然可用的活跃或非活跃本机会话

远程 Session、移动端和 Web 端目前不提供交互式终端。已归档或删除的 Session 无法打开终端。

## 打开和管理终端

使用底部栏的终端入口，或按 `Ctrl+\``、`Cmd/Ctrl+J`。每个 Session 最多可以打开 8 个终端标签。

- 点击 `+` 打开新的终端。
- 从底部终端标签栏切换终端。
- 关闭单个标签会结束对应的 Shell 进程。
- 拖动面板分隔线可以调整高度。

焦点位于终端时，`Alt+N` 会新建终端标签；焦点不在终端时，同一快捷键用于新建 Session 标签。

## 工作目录与生命周期

Lody 会根据 Session 解析终端工作目录，界面不能要求 CLI 在任意路径启动 Shell。项目 Session 会使用
对应的 Worktree 或项目目录。

只要 Lody CLI Daemon 仍在运行，切换 Session 或重新加载界面后，终端进程仍然可用。归档或删除
Session、或者 Daemon 停止时，终端会被关闭。Daemon 重启后不会保留终端进程和历史输出。

## 主题与底部状态栏

终端会跟随 Lody 当前的深浅色模式和所选 VS Code 代码主题，包括 ANSI 颜色。底部状态栏同时提供 CLI
状态入口，点击可以显示或隐藏 CLI 输出。CLI 输出与当前终端共用同一个 Dock 位置，同一时间只显示其中
一个。

## 字体

在桌面端进入 **设置** -> **外观**，可以分别为 Lody 界面和内嵌终端选择系统字体。界面字体会应用到整个桌面应用；终端字体只影响终端标签。选择 **默认** 可以恢复 Lody 的内置字体栈。
