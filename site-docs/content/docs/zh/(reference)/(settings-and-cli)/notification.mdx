# 消息通知

Lody 会在 Code Agent 对话结束，请求权限，发生错误等情况下向用户设备推送通知，以便用户及时了解当前会话的状态。

## 开启通知

### 桌面端浏览器

使用桌面端浏览器时，你可以通过 **设置**-**通用**-**推送通知** 来开启消息通知功能。

点击后浏览器会发出请求，询问你是否开启通知，请点击允许。

<img src="/_docs-assets/browser-notification.png" width="300px" />

### 移动端应用

在手机上请先[安装 Lody 移动端应用](/zh/docs/mobile)，再通过 **设置**-**通用**-**推送通知** 开启推送。
