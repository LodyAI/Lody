# 图像输入

Lody 已支持在会话中输入图像。你可以把截图、界面草图、报错画面等图片作为提示上下文的一部分发送给 AI。

<img src="/_docs-assets/0304-image-input.png" alt="" />

## 适用场景

- 用截图直接描述视觉或交互问题。
- 让 AI 基于图片识别 UI 细节。
- 将图片证据与代码上下文在同一轮对话中结合。

## 使用方式

1. 打开会话聊天窗口。
2. 打开附件 `+` 菜单并选择 **上传图片**，粘贴剪贴板中的图片，或把图片文件拖放到会话界面的任意
   位置。
3. 输入指令并发送。

每条消息最多可以附加 8 张图片，单张上限为 5 MiB。更大的图片可以通过[文件附件](/zh/docs/file-attachments)
作为普通文件发送。

<Callout type="warn">

图像能力受当前模型能力影响，使用前请确保模型支持视觉模态。

</Callout>
