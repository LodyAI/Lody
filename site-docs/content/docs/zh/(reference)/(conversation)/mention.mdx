# 提及

Lody 对输入框进行了增强。输入 `@` 可打开提及菜单，选择对话、文件、Issues、Pull Requests、Skills 或 Agent 角色；`$` 仍是 Skill 的直接快捷入口。

## 对话提及

在对话中输入 `@`，选择 **会话**，再选择另一条对话即可引用它。你可以让当前 Agent 联系该会话、读取相关上下文、交流调查结果，或请求审查。例如，提及实现会话，让当前 Agent 审查它的最新提交，并把发现的问题发回去。

被引用的会话可以使用其他 Agent，也可以运行在另一台已连接的机器上。访问仍遵循工作区权限，目标机器需要在线才能执行任务。会话引用明确了对象，请在指令中说明需要交换什么上下文或完成什么工作。

可用操作见 [Agent 对话控制](/zh/docs/session-orchestration/)。要通过会话引用交流上下文、请求审查，并跨 Agent 和机器协调任务，参见[多 Agent 协作指南](/zh/docs/agent-collaboration/)。

## 文件提及

在输入框输入 `@` 并选择 **文件**，然后继续输入即可按文件名或文件路径进行模糊匹配。通过 ↑ ↓ 上下方向键进行选择，使用回车来确认选择。提及的文件会将完整路径作为 Prompt 上下文给到 Code Agent。

## Issue 或 Pull Request 提及

在主页选中仓库之后，输入 `@` 打开提及菜单，然后选择 **Issues** 或 **Pull Requests**，即可提及当前仓库中的 Issue 或 PR。

<MentionPreview locale="zh" kind="issue" />

可以使用 ↑ ↓ 方向键进行选择，使用回车选中。Lody 会把选中的条目以 `#编号` 写入输入框，并把对应的 Issue 或 PR 上下文加入 Prompt，Agent 就可以完成类似 `修复 #12 的问题`、`review #56 PR 的功能实现` 的工作。

## Skill 提及

输入 `$` 可以浏览当前项目和 Agent 所在机器提供的 Skills。继续输入名称进行筛选，再使用方向键和
`Enter` 选择目标 Skill。

输入框中会保留易读的 `$skill-name`。发送消息时，Lody 会附上对应的 `SKILL.md` 路径，让 Agent
加载并遵循其中的指令。

关于发现目录、项目与全局作用域以及离线行为，参见 [Skills](/zh/docs/skills)。
