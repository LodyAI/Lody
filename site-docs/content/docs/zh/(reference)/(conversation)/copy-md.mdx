# 复制对话

## 复制单个对话

在对话界面，每个对话气泡下方都有一个复制按钮，点击按钮后会复制对应的气泡内容。

## 复制完整对话

打开 Session 的 `...` 菜单，展开 **复制**，再选择 **复制为 Markdown**。Lody 会把当前可见的完整
对话历史复制为可复用的 Markdown。

同一个子菜单还可以复制 Session 工作目录路径或会话链接，具体可用项取决于当前会话。

复制成 Markdown 是一份记录，不是现场交接。复制会话 URL 也不会授予团队访问权限。要把同事请进同一个会话，见[共享并交接 Agent 会话](/zh/docs/session-handoff)。分享链接和交接的对比见 [分享链接 vs 现场交接](/zh/docs/compare/share-link-vs-live-handoff)。
