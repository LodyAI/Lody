# 图像输出

Lody 已支持在会话中返回你指定的至多 8 张图像。你可以向 Agent 描述类似 `启动前端开发服务器，加载完成后截图主页给我` 的任务。Lody 会自动将图像发送到聊天窗口中。

当所选运行时支持图像生成时，例如 Codex Image Gen，生成的图片也可以直接回到当前会话中。

<img src="/_docs-assets/20260317-lody-image-back.png" alt="" />

## 生成图片

对于 Codex 图像生成，Lody 会把生成结果保留在同一个对话里，和提示词及后续修改请求放在一起。这样你可以继续要求调整、对比不同版本，或在之后回到这张生成图。

## 适用场景

- 使用移动端快速查看 UI 结果。
- 快速查看本机生成或截取的图像。
- 将生成图片与上下文、提示词和实现过程放在同一会话中审阅。

## 使用方式

1. 打开会话聊天窗口。
2. 向 Agent 描述截图、生成图片或上传图像的相关动作，Agent 会自动将图像上传到对话中。
