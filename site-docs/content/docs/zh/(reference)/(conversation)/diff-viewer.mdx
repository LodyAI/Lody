# 差异查看

Lody 支持在每次对话结束后实时地同步当轮对话 Code Agent 造成的文件更新。

## 当轮对话差异

当你让 AI 进行一些代码编辑和文件改动时，Lody 会对比此次对话之前的文件状态和对话后的文件状态，结束时在 Code Agent 的对话气泡下方将展示此次对话产生的所有文件改动以及改动行数。

<img src="/_docs-assets/conversation-diff.png" alt="" />

你可以点击想要查看的文件，这会打开 diff 查看标签，并跳转到你希望查看的文件。第一次点击时，同步和加载可能需要一点时间。

<img src="/_docs-assets/diff-viewer.png" alt="" />

你也可以点击面板中的展开按钮，查看文件未改动的部分。

## 行级评论

在 diff 中把鼠标悬停到可评论的行上，会出现 `+` 按钮。点击后可以添加 Markdown 评论、回复线程、解决或重新打开评论。移动端可以直接点击可评论的 diff 行来添加评论。

如果当前 session 已关联 GitHub PR，评论可以同步为 GitHub PR Review 的行评论。Lody 也会把 GitHub 上已有的 review 线程显示在对应 diff 行下，方便直接在 Lody 中回复。

更多操作见 [Diff 行评论](/zh/docs/diff-comments)。

## 所有对话差异

除了当前轮次造成的修改之外，你可以点击对话界面右上角的侧边栏展开按钮，这将展开文件和差异侧边栏。

你可以在 `Changes` 的标签页中看到当前对话的所有文件变更。

## 远端审阅

当 session 所在机器在线时，远端设备也可以通过同一套 session 文件 provider 打开改动文件和 diff。如果 diff 或文件仍在同步中，Lody 会显示当前的加载或不可用状态，而不是从最新工作区快照里猜测差异。
