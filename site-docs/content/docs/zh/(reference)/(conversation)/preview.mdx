# Lody Preview

Lody Preview 可以把会话里的本地开发服务器以实时预览的方式打开在 Lody 中。Agent 修改 UI 代码时，你可以直接在桌面、平板、手机等视口下检查效果，不需要手动复制 localhost 地址。

<img src="/_docs-assets/20260507-preview.png" alt="" />

## 启动预览

你可以让 Agent 启动开发服务器并使用 Lody Preview，例如：

```text
启动 Vite 开发服务器，并使用 Lody Preview 检查页面。
```

当 Lody 在当前会话中检测到可预览的服务后，打开 **Preview** 标签。本地桌面端会话可以开启 **Design mode**，直接打开本机预览，无需建立隧道或生成可分享的远程链接。远程会话或需要分享预览时，点击 **Preview Remote** 后再点击 **Create connection**。需要停止预览时，可以点击预览标题栏里的电源按钮。

## 检查布局

预览工具栏支持：

- 桌面、平板、手机视口预设
- 横屏和竖屏旋转
- 缩放、适应窗口和重置缩放
- 手型模式，用于拖拽平移和双指 / Ctrl 滚轮缩放
- 外部打开，适合必须在独立浏览器标签中查看的页面
- 复制 Preview 分享链接的按钮

这些控制项适合用来检查响应式断点、溢出、点击区域和布局变化，同时保留会话和 diff 上下文。

## 视觉标注

打开标注模式后，点击预览中的页面元素并写下评论。Lody 会把评论锚定到对应元素，并可将引用发送回聊天，让 Agent 同时拿到视觉目标和你的修改要求。

视觉标注适合描述具体 UI 问题，例如间距、对齐、文案、颜色或移动端布局问题。

## 注意事项

- 本地 Design mode 预览需要本地开发服务器持续运行；远程预览还要求会话所在机器在线。
- 部分应用可能会限制嵌入式预览，或需要在外部浏览器标签中才能完整工作。
- 如果预览内容过旧，可以刷新预览，或让 Agent 重启开发服务器。
