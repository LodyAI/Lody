# 斜杠命令

在输入框开头输入 `/`，会弹出当前 Agent 暴露的命令和工作区内可用的 Prompt Shortcuts。
连接的 Agent 支持时，可以看到 `/review`、`/compact`、`/undo` 等 Agent 命令。

<SlashCommandsPreview locale="zh" />

Agent 命令由 **Agent 提供**，不是 Lody 内置。每个 Agent Config 在能力发现阶段会上报自己的命令列表，
所以具体可用项取决于 CLI 类型（Claude Code、Codex、Kimi、OpenCode 或任意 ACP Registry runtime）以及
该机器上安装的版本。Prompt Shortcuts 由工作区定义，受各自的可见性与作用域规则限制。

## 打开菜单

- 在新一轮对话的第一个字符输入 `/`。
- 继续输入后，两个来源的可用候选按相关度排列：先是完全匹配，再是开头匹配、
  词首匹配、中间包含和更宽松的匹配。每行标明来源。只输入 `/` 时仍按来源分组。
- 按 `↑` / `↓` 移动高亮项，按 `Home` / `End` 跳到首项或末项。
- 按 `Enter` 插入当前高亮的命令，按 `Tab` 或 `Escape` 则关闭菜单而不插入。

没有命中结果时，菜单会显示提示；输入内容仍作为普通文本保留。

## 命令的含义

因为命令由 Agent 提供，具体行为以各 Agent 自身文档为准。常见命令举例：

| 命令       | 常见行为                                      |
| ---------- | --------------------------------------------- |
| `/review`  | 让 Agent 审查当前 diff 或最近的改动           |
| `/compact` | 对当前对话做总结并压缩上下文，释放 token 额度 |
| `/undo`    | 回退 Agent 最近一次产出的改动                 |

完整的命令和含义请查阅对应 Agent 自己的文档。

## 刷新命令列表

命令列表按 Agent Config 在每台机器上本地缓存。当你升级 CLI 版本或修改了 Agent Config 的环境变量后，
需要刷新缓存，新的命令才会出现：

- Web 端：进入 **Agent Config**，选择对应配置并刷新选项。
- CLI 端：在目标机器上运行 `lody agent-config refresh-capabilities <idOrName>`。

更多说明见 [Agent Config](/zh/docs/agents) 和 [CLI 命令](/zh/docs/cli#agent-config-refresh-capabilities)。
