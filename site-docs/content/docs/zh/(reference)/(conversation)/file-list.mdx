# 文件列表

Lody 有两类文件入口：

- **项目文件**：无需先创建 session，也可以查看本地项目或 GitHub 仓库。
- **会话文件**：查看当前 session 的 worktree 文件，包括 Agent 修改过的文件。

## 浏览项目文件

在移动端，从 **Projects** 标签进入一个项目，然后切换到 **Files**。你可以逐级进入文件夹，并直接打开文本文件。
当项目所属机器或仓库 provider 可用时，本地项目和 GitHub 仓库都支持这个入口。

这个入口适合在创建新对话前先检查仓库，也适合离开桌面时快速查文件。

## 浏览会话文件

你可以点击对话界面右上角的侧边栏展开按钮，这将展开文件和差异侧边栏。

你可以在 `Files` 的标签页中看到当前对话的所有文件列表。其中当前对话有变动的文件将被高亮，以便你更好地查找。

<img src="/_docs-assets/file-list.png" width="300px" />

点击文本文件可以在会话内打开文件预览。文件预览会自动换行，查看日志、生成文件或长行代码时更容易阅读。

## 快速打开与搜索

在 session 文件查看器中，可以使用文件搜索入口查找已索引文件，不必手动滚动文件树。打开文本文件后，点击文件工具栏里的搜索图标，可以打开文件内搜索。

## Markdown 预览

Markdown 文件默认以源码模式打开。点击文件工具栏里的眼睛图标，可以切换到渲染预览；再次点击会回到源码。将鼠标悬停在图标上时，可以临时预览渲染结果而不离开编辑器。

## 实时编辑

当 session 文件来自实时协作 provider、文件是文本文件、并且你拥有写权限时，文件查看器会变为可编辑状态。你的修改会保存回 session worktree，并实时同步给协作者。

如果文件是只读、历史快照、过大、二进制文件，或宿主机器离线，Lody 会保持只读，并在文件状态栏显示当前可用状态。
