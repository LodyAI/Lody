# 文件附件

Lody 在新建会话和已有会话中都支持任意类型的文件附件。附件会随 Prompt 一起发送，Agent 可以从
Session 工作目录读取原始文件，不需要把完整内容粘贴到消息中。

## 添加附件

1. 打开输入框中的附件 `+` 菜单。
2. 选择 **上传文件**，再选择一个或多个文件。
3. 等待正在进行的上传完成，填写指令后发送。

你也可以把文件直接拖入会话界面。新建会话时，待发送附件会与即将创建的 Session 保持关联。

## 预览与下载

支持文本预览的文件会打开预览窗口，你可以：

- 在 Markdown 渲染结果与原始文本之间切换
- 复制原始文本
- 下载完整文件

其他文件类型以下载为主要操作。原生移动端会通过系统分享菜单打开下载结果，方便保存文件或发送到其他
App。

## Agent 如何读取文件

在 Turn 开始前，Lody 会把附件写入 Session 工作目录下的 `.lody/attachments/`，并把文件引用交给
Agent。文件正文不会直接插入文本 Prompt。

Agent 也可以回传文件和图片。兼容的 ACP 输出和 Lody 上传工具会把结果作为普通附件卡片加入对话。

## 限制与保留时间

- 每条消息最多附加 8 个文件。
- 单个文件最大 100 MiB。
- 不限制文件类型。
- 通过中转存储的文件会保留 90 天。

图片使用独立的图片处理流程：每条消息最多 8 张，单张最大 5 MiB。更大的图片可以作为普通文件发送。
参见[图像输入](/zh/docs/image-input)和[图像输出](/zh/docs/image-output)。

## 可用性

Agent 开始读取前，Session 所在机器必须能够取得附件。如果某个附件上传失败，可以重试或移除它；其他已
成功上传的附件仍然可以正常发送。
