# Lody

Lody.ai 让你可以在手机或电脑上并行使用你的 Coding Agents 并与团队共享。

- 当前支持 Claude Code、Codex、Grok、OpenCode、Kimi、自定义 ACP Agent，以及所有支持 [ACP Registry](https://agentclientprotocol.com/get-started/registry) 的 CLI，几乎涵盖了市面上所有的 Agent。
- iOS 与 Android 原生应用，[手机](/zh/docs/mobile)也可以随时 vibe coding
- 通过 Worktree 和多标签会话让 Coding 任务高效并行
- 更好的 [GitHub 集成](/zh/docs/github)，自动绑定 PR，同步 CI 状态和 review 评论
- 支持项目和会话文件浏览，并可在实时协作文件中直接编辑
- 内置实时 UI [预览](/zh/docs/preview)，支持响应式视口和可发送给 Agent 的视觉标注
- 对话完成时发送推送通知，不用担心忘记
- [团队共享](/zh/docs/team) agent 设置和所有对话上下文，时刻保持信息一致，包括[现场会话交接](/zh/docs/session-handoff)

## 最新能力

- [共享并交接 Agent 会话](/zh/docs/session-handoff)：邀请同事进入已有会话，接着同一段对话、差异和工作树继续做。
- [对话 fork 支持](/zh/docs/session#fork-%E4%BC%9A%E8%AF%9D)：在同一个会话中 fork 出多个子对话，独立运行不同的任务。
- [多标签会话](/zh/docs/session-tabs)：在同一个 session 中打开主对话、子对话、文件和 diff 标签。
- [文件列表](/zh/docs/file-list)：浏览项目文件、打开会话文件、文件内搜索、预览 Markdown，并编辑实时协作文本文件。
- [Diff 行评论](/zh/docs/diff-comments)：在差异行上添加 Markdown 评论，并同步到 GitHub PR Review。
- [会话内搜索](/zh/docs/session-search)：搜索消息、工具调用、终端输出和 diff 内容。
- [Daemon 模式](/zh/docs/cli#daemon-模式)：让 CLI 在后台常驻并自动恢复。
- [图像输入](/zh/docs/image-input)：将图片作为会话上下文的一部分发送给 AI。
- [Lody Preview](/zh/docs/preview)：打开实时 UI 预览，切换不同设备视口，并把视觉标注发送给 Agent。
- [Claude & Codex 能力](/zh/docs/claude-codex-capabilities)：Steer 运行中的任务，并使用运行时提供的斜杠命令、提问、Fast Mode、图像生成和 Goal。
- [CLI 类型支持](/zh/docs/cli-runtimes)：使用 ACP Registry 运行时，或填写你自己的 ACP 兼容启动命令。
- [工作树](/zh/docs/worktrees)：隔离并行任务，并为项目配置 setup / cleanup 脚本。
- [上下文、Token 与额度](/zh/docs/usage-and-quota)：在设置页查看上下文窗口余量、Token 花费和订阅额度。
