# Lody

Lody 可以让你在手机或电脑上和团队一起使用 coding agents。如果你现在在使用 codex、claude code、deepseek harness 等等将很容易理解。你可以在[下载](https://lody.ai/download)桌面端、移动端或者直接使用 web 端。Lody 会使用你自己设备上的各种 Agents，当前内置支持 

- codex
- claude code
- grok build
- kimi code
- deepseek harness
- Pi
- Dimcode
- Bub

这意味着你在 Lody 中使用这些 Agent 的时候有着最完整的功能集。除此以外，Lody 通过 [ACP](https://agentclientprotocol.com/get-started/registry) 将最大程度兼容市面上各类 Agent。

Lody 是基于 [Loro](https://loro.dev) 的整个技术栈构建的，我们的团队一直专注于 local-first 的基础建设，致力于解决本地优先场景下的多端同步和多人协作的体验问题。依托于前几年的技术积累，我们有着当下最稳定和快速的同步服务。打开移动端就会在几秒内同步完成你在桌面端的对话历史。在同步的流畅和丝滑上面，我们有着大量的好评。

Lody 第一天的架构就是面向团队的 local-first 架构，所以我们不单单是想解决怎么让 coding agent 随时随地更好用的问题。我们更想解决的是 AI 能力足够的这样的背景下，我们该怎么让数据、让 context 让 human 加倍地发挥作用的问题。

现在大家使用 vibe coding 几乎都是每个人处理着各自自己的对话，整体团队只有最终的代码、最终的 artifacts 会通过 PR 文档等工具进行共享，实现得怎么样，实现过程的思考，spec 的边界范围都是隐藏在最终产物之外的。语言和代码的关系在如今也是已经颠倒了，code is cheap, show me chat!  我们就希望能够通过 Lody 这样的工具来为团队解决 项目进度管理、Context 共享、Agent 间协作等问题。
