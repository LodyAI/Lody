# Lody

Lody.ai 让你在桌面端、移动端和浏览器里并行运行 coding agents，并与团队共享上下文。你可以使用
Lody 内置的全部 Provider：Claude Code、Codex、Grok、Kimi Code、Devin、Pi、DeepSeek Harness、
Bub、Dimcode；也可以使用自定义 ACP Agent 和
[ACP Registry](https://agentclientprotocol.com/get-started/registry) 中的任意 CLI。

Lody 从第一天起就是面向团队的 local-first 架构：不仅让 coding agent 随时随地更好用，也让数据、
context 和协作过程在团队里真正流动起来。

## Lody 擅长什么

- **并行推进工作。** 每个会话都有自己的 Git 工作树，Agent 之间不会互相覆盖文件。见[并行 Coding Agents](/zh/docs/parallel-agents)。
- **使用你信任的 Agent。** Lody 内置多种 Provider，不止 Claude Code 和 Codex；ACP Registry 中的运行时和自定义 ACP 命令也都能用。见 [Agent Config](/zh/docs/agents) 和 [CLI 运行时类型](/zh/docs/cli-runtimes)。
- **边跑边审阅。** 当轮 diff、行级评论，以及 GitHub PR review 同步。见[差异查看](/zh/docs/diff-viewer)和 [Diff 行评论](/zh/docs/diff-comments)。
- **让一个 Agent 协调其他 Agent。** 用 [Agent 对话控制](/zh/docs/session-orchestration)和[多 Agent 协作](/zh/docs/agent-collaboration)拆分任务、委派工作并收集结果。
- **让团队保持同步。** 用[会话交接](/zh/docs/session-handoff)把同事请进实时会话，而不是发一份聊天记录；团队能力见[团队功能](/zh/docs/team)。
- **离开工位也能工作。** 在 iOS、Android 或任意浏览器里查看和指挥会话，见[移动端](/zh/docs/mobile)。
