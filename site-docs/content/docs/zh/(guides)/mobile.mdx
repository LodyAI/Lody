# 移动端访问

Lody 提供 iOS 与 Android 原生应用，让你随时随地都能继续编码。

## 安装应用

### iOS

在 iPhone / iPad 上安装 Lody：

- [在 App Store 下载](https://apps.apple.com/cn/app/lody-%E9%9A%8F%E6%97%B6%E9%9A%8F%E5%9C%B0%E8%BF%90%E8%A1%8C-code-agent/id6761373528)
- [在 TestFlight 中打开](https://testflight.apple.com/join/cUcDcVFa)（尝鲜版）

### Android

从[下载页面](/zh/download)获取最新签名的 APK 安装包。

## 功能

### iOS 实时活动

在 iPhone 上，Lody 可以把正在运行的 Agent 状态显示在锁屏和灵动岛中。你不需要重新打开 App，也能跟踪任务进度。

当 Agent 请求权限时，Lody 也可以发送可直接操作的实时活动提醒，方便你从 iOS 快速处理。

### 推送通知

在以下情况获得通知：

- 任务完成
- Agent 需要权限批准
- PR 准备好审查

在 设置 > 通用 > 推送通知 中启用通知。

### 监控进度

实时观看代理工作：

- 实时终端输出
- 文件更改
- 会话 diff 和 Review 评论
- 图片预览，支持长按系统分享和保存

### 浏览项目文件

在移动端从 **Projects** 标签打开一个项目，然后切换到 **Files**，即可浏览目录树并预览文本文件。这个流程不需要先创建对话。

当项目所属机器或仓库 provider 可用时，本地项目和 GitHub 仓库都支持项目文件浏览。实时文件编辑目前可在桌面端使用，移动端编辑即将支持。

## 离线支持

Lody 移动端离线支持：

- 查看缓存的对话
- 审查保存的差异

重新联网后更改自动同步。
