# 命令面板与键盘快捷键

Lody 提供用于查找操作和会话的命令面板，并提供设置页来自定义应用内与系统级键盘快捷键。

## 打开命令面板

macOS 按 `Cmd+K`，其他平台按 `Ctrl+K`。也可以使用 `Cmd/Ctrl+Shift+P`。

命令面板可以：

- 搜索当前界面可用的命令
- 搜索会话，不打开侧边栏也能快速切换
- 在命令旁显示当前快捷键
- 使用方向键移动，按 `Enter` 执行，按 `Escape` 关闭

不适用于当前界面的命令会自动隐藏。

## 自定义快捷键

打开 **设置** -> **键盘快捷键**，点击某一行，再按下新的组合键。

你可以：

- 重新绑定命令
- 解除已有绑定
- 为默认未绑定的命令添加快捷键
- 将所有应用内快捷键恢复为默认值
- 在保存前发现并拒绝冲突

应用内快捷键保存在当前设备，不会同步到其他设备。Web 端无法拦截一部分被浏览器保留的组合键。

## 切换会话标签页

桌面端中，`Cmd/Ctrl+1` 到 `Cmd/Ctrl+8` 直接切换到对应的会话标签页，`Cmd/Ctrl+9` 切换到最后
一个标签页——与浏览器标签页的惯例一致。`Cmd/Ctrl+Shift+,` 和 `Cmd/Ctrl+Shift+.` 切换到上一个
和下一个标签页，`Cmd/Ctrl+T` 新建标签页。

## 桌面端全局快捷键

桌面端还支持 Lody 未聚焦时也能触发的系统级快捷键。它们显示在 **全局快捷键** 分组中，可以单独
重新绑定。

Quick Session 的默认快捷键是 `Cmd/Ctrl+Shift+N`。它会显示或隐藏一个独立的小型输入窗口，让你无需
先把 Lody 主窗口切到前台就能创建会话。

全局绑定必须包含 `Command`、`Control` 或 `Alt`。如果组合键已经被操作系统或其他应用占用，Lody 会
保留原绑定并提示冲突。
