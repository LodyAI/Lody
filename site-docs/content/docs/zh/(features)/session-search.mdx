# 会话内搜索

会话内搜索用于在长对话里快速定位上下文。它只搜索对话正文：你的消息、Agent 的回复、思考内容
和提案计划，其中也包括已完成回合折叠起来的工作区里的进度文本与思考。

工具调用不参与搜索：其中的标题、文件路径、JSON 入参/出参、终端命令及输出和 diff 都不会
进入索引。结构化计划清单、目标和 worktree 脚本输出也不参与搜索。写在消息或提案计划正文
里的文件路径、代码片段仍可以作为对话文本被搜到。

这与[全局会话导航搜索](/zh/docs/keyboard-shortcuts#打开命令面板)不同：侧边栏的 **搜索**
和 `Cmd/Ctrl+K` 打开命令面板，通过会话标题、项目或仓库名称、分支名查找并切换会话，
不会搜索这些会话的正文。

## 打开搜索

- 在会话右上角菜单中选择 **在对话中查找**。
- 桌面端可以直接按 `Ctrl+F`，macOS 使用 `Cmd+F`。

搜索框会浮在对话右上角，不会打断当前输入框里的内容。

## 浏览结果

- 输入关键词后，匹配内容会高亮。
- 右侧计数显示当前命中位置和总数。
- 按 `Enter` 跳到下一个结果。
- 按 `Shift+Enter` 或点击上箭头跳到上一个结果。
- 没有命中时会显示 `0 / 0`。

当前命中的消息会自动滚动到可见位置。命中落在折叠的工作区或思考卡片里时，Lody 会自动展开它。

## 关闭或清空

按 `Escape` 时，如果搜索框里有内容，会先清空关键词；再次按 `Escape` 会关闭搜索。
