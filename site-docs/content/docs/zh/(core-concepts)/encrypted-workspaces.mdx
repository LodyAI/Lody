# 端到端加密工作区

端到端加密工作区里的对话、文件和 Agent 输出，只在你们授权过的设备上解密。Lody 服务器负责转发和保存数据，但拿到的只是看不懂的密文。

<Callout type="warn">
如果你所有已授权的设备都丢了，又没有恢复文件或 passkey，这个工作区就再也打不开，Lody 也无法帮你找回。创建后请尽快在加密控制台里设置恢复文件。
</Callout>

## 内容怎么加密

- 每个工作区有一把**工作区密钥**。内容在你的设备上用它加密后才发出去。
- 每台授权设备有自己的设备钥匙，保存在系统的安全存储里（例如 macOS 钥匙串）。工作区密钥只会加密后发给授权设备。
- 服务器从来拿不到工作区密钥，所以它能转发和保存内容，但读不了内容。

## 谁能加入，由签名记录决定

邀请成员、批准新设备、移除成员、转移所有权，每一次变更都会写成一条**带签名的记录**，由有权限的成员在自己的设备上签名。所有设备都会自己检查这些记录：

- 签名不对、顺序被篡改，或者有人越权，设备会拒绝这条记录，并暂停邀请和授权。
- 服务器只负责传递记录，不能替任何人签名，所以它不能偷偷加人，也不能偷偷加设备。

你在加密控制台的「安全码与记录」里能看到这些记录，例如「Jordan Lee 加入了工作区（Alex Chen 批准）」。

## 新设备怎么加入

新设备打开加密工作区时会自动发出申请。你已授权的电脑或手机会弹出审批窗口，核对两边显示的数字一样后点「授权」，新设备就会收到密钥并自动打开工作区。服务器只转发申请，无法替你批准。

## 移除成员和更换密钥

移除成员后，他的设备立刻失去访问，之后的新内容也看不到。移除时建议同时**更换工作区密钥**，这样即使旧设备还留着旧密钥，也解不开新内容。已经下载到对方设备上的历史无法收回。

## 安全码 [#security-code]

安全码是根据当前的成员信息和授权信息算出来的一串数字。它可以帮你确认：你看到的成员和设备，和其他人看到的完全一样。

- 如果你和工作区其他成员、你在其他设备上看到的安全码**一致**，说明工作区成员信息和授权信息是一致的，没有人被服务器单独展示了一份不同的记录。
- 如果**不一致**，先两边都刷新再对一次（有一方没更新时，安全码也会不同）。还是不一致的话，先不要邀请或批准任何人，并告诉工作区负责人。

核对的方法：在加密控制台打开「安全码与记录」→「和同事核对」，扫对方屏幕上的二维码；扫不了就直接逐组对数字。当面、视频或打电话都可以，最好不要只通过 Lody 本身来传安全码。

<Callout type="info">
安全码只证明大家看到的是同一份成员和授权记录，不证明某个人就是他声称的那个人。核对时请确认对方确实是你认识的同事。
</Callout>

## 恢复

在加密控制台的「恢复」里，你可以保存恢复文件，或添加支持的 passkey。设备全部丢失时，可以用它们在新设备上重新打开工作区。恢复文件要离线保存：同时拿到这个文件和你的账号的人，可以读取你的加密工作区。

## 已知限制

- 网页版的安全性依赖 Lody 网站下发的代码没有被篡改；更看重这一点时，请使用桌面版或手机 App。
- 服务器暂时连不上时，你的机器在有限时间内仍可以用本机已确认的成员信息继续工作；邀请、授权新设备和更换密钥需要等连上后再做。
