# 端到端加密工作区

端到端加密工作区里的对话、文件和 Agent 输出，**只有你们授权过的设备能看**。Lody 的服务器负责转发和保存，但它拿到的只是一堆看不懂的数据。

<Callout type="warn">
如果你所有已授权的设备都丢了，又没有恢复文件，这个工作区就再也打不开，Lody 也无法帮你找回。创建后请尽快设置恢复文件。
</Callout>

## 它和普通工作区有什么不同

| | 普通工作区 | 端到端加密工作区 |
| --- | --- | --- |
| 谁能看到内容 | 有权限的成员，以及 Lody 服务器 | 只有授权过的设备 |
| 换一台新设备 | 登录即可 | 登录后，还要用一台已授权的设备批准 |
| 网页版 | 直接可用 | 浏览器要先被授权 |
| 丢了所有设备 | 登录即可找回 | 要靠恢复文件或 passkey |

## 日常会遇到的几件事

<Steps>
<Step>

**认出加密工作区**：工作区名字旁边有一把锁。鼠标停在锁上会显示说明。

</Step>
<Step>

**邀请同事**：在「设置 › 通用 › 打开加密控制台 › 成员与邀请」里发邀请。管理员批准后，同事的设备会收到密钥。

</Step>
<Step>

**在新设备上打开**：新设备打开工作区时会自动发出申请；你已授权的电脑或手机会弹出审批窗口，核对两边数字一样后点「授权」。

</Step>
<Step>

**和同事核对**：在「安全码与记录」里和同事对一下安全码，确认大家看到的成员和设备是同一份。

</Step>
<Step>

**设置恢复**：在「恢复」里保存恢复文件，或添加 passkey，防止设备全丢后打不开。

</Step>
</Steps>

## 已知限制

- 网页版的安全性依赖 Lody 网站下发的代码没有被篡改；更在意这一点时，请使用桌面版或手机 App。
- 服务器暂时连不上时，你的机器在有限时间内仍可以继续工作；邀请、授权新设备和更换密钥要等连上后再做。
