# 会话

会话（Session）是 Lody 中的最基本的概念，通过主页的对话框来启动一个新的会话。这相当于 Claude Code / Codex CLI 的一次对话。

对话前你可以通过对话框周围的菜单进行多种配置的选择

- 对话的仓库、分支
- 对话使用的代理配置
- 对话使用的模型
- 对话的权限范围

Lody 会根据选中项来启动此次对话。

一个会话还可以包含多个标签：主对话、子对话、文件预览和 diff 视图都可以放在同一个 session 里管理。需要边聊天边看文件，或让多个子对话围绕同一项任务并行协作时，可以继续阅读[多标签会话](/zh/docs/session-tabs)。

要把同事请进已经在跑的会话，让对方接着同一段对话、差异和工作树继续做，见[共享并交接 Agent 会话](/zh/docs/session-handoff)。下方的 Fork 是另开一条你自己的对话，不会把人加进原来的会话。

## Fork 会话

当 Agent 支持原生会话 Fork 时，最新一条已完成的 Agent 回复下方会显示**分叉会话**按钮。Fork 会新建一个会话，保留截至该回复的对话历史；之后你可以沿着不同方向继续对话，而不会影响原会话。

Codex 和 Claude Code 还可以从更早的任意一条已完成 Agent 回复处 Fork。

在已启用 Worktree Fork 的 Git 会话上，**分叉会话**会提供两个目标：

- **当前工作区** — 新标签页，与源会话共用文件和未提交改动
- **新 Worktree** — 从最新已提交的 `HEAD` 开一条独立会话；未提交和未跟踪的文件仍留在源会话

如果没有 **新 Worktree** 选项，Fork 会留在当前工作区。侧边对话始终走共用目录这条路径。

只有当前 Agent 声明支持原生 Fork 时才会显示该功能。

## 右侧栏：浏览器和侧边对话

右侧栏可以在主对话旁保留常用工具。通过会话工具栏打开**浏览器**，或在右侧栏的 `+` 菜单中添加面板。

**侧边对话（Side Chat）**会从最新一条可 Fork 的 Agent 回复创建分叉会话，并将其打开在右侧栏。它适合在不离开主会话的情况下追问或进行审查。你可以创建多个侧边对话，在右侧栏中切换，并在不再需要时点击对应的 `X` 关闭。侧边对话仅在当前 Agent 支持原生 Fork 时可用。

URL 与远程端口访问方式请参阅 [Lody Preview](/zh/docs/preview)。

## 会话列表

Lody 在左侧 sidebar 中展示 Chat、GitHub Worktree 和本地项目里的所有会话。你可以使用默认的工作区组织方式，也可以切换到 **Updated** 模式，按 Today / This week / Older 将所有任务按最近更新时间聚合。

其中每个会话都会带有 AI 自动根据 Prompt 生成的语义化的标题，当前分支名和分支状态，相比于基础分支此对话的文件行数变更等信息，便于查看。

<img src="/_docs-assets/session-list.png" width="200px" />

你可以通过鼠标移动到仓库列表上，右边显示的拖动按钮来自定义更改多个仓库项目的顺序。

## 会话操作

在侧边栏中右键点击会话可以打开上下文菜单。你可以在这里重命名、置顶、归档、复制会话 URL，或复制当前分支名。

置顶后的会话会固定显示在列表顶部，方便持续跟进重点任务。在 Web 端，中键点击或 Cmd / Ctrl 点击侧边栏任务，可以在新的浏览器标签页中打开。

对话底部操作栏和会话信息控制区会集中展示当前任务可用的项目、分支、预览、PR 和代码变更操作，无需切换到单独页面即可完成常用的 GitHub 和项目操作。

## 桌面端 Quick Session

按 `Cmd/Ctrl+Shift+N` 可以打开独立的 Quick Session 窗口。这是系统级桌面快捷键，因此即使 Lody
没有聚焦也能使用。你可以在紧凑输入框中选择项目、Agent 和模型，无需先打开主窗口即可创建 Session。

快捷键可以在 **设置** -> **键盘快捷键** 中修改。参见[命令面板与键盘快捷键](/zh/docs/keyboard-shortcuts)。

## 在编辑器中打开工作目录

桌面端 Session Header 的 **在…中打开** 可以启动当前 Worktree 或项目目录。内置启动方式包括 VS
Code、Xcode 和 Sublime Text 等受支持编辑器。

进入 **设置** -> **通用** -> **路径启动方式**，可以选择默认启动方式，或添加自定义 Shell 命令。
自定义模板必须使用 `{path}` 作为 Session 目录参数，并且只保存在当前桌面端。

如果项目已经在编辑器中打开，再次打开时会聚焦已有窗口，而不是新开一个（例如在 Zed 中）。

## 归档会话

鼠标移动（移动端点击）到对应会话列表上时，右下角会显示归档按钮，你可以点击按钮来归档会话。

会话归档后会被放入归档列表中，但并不会被真正删除——对话内容和会话所在的 Git 分支都会保留，你可以随时恢复归档的会话并继续之前的工作。对于带有 worktree 的会话，归档本身就会移除该 worktree 的工作目录，从而释放 CLI 机器上的磁盘空间；移除前会先把未提交的改动自动提交到分支，因此不会丢失任何内容，恢复并继续对话时 worktree 会被自动重新创建。如果还要删除对话历史、回收其余的磁盘空间，请使用**删除会话**。

## 取消归档

在左侧 sidebar 的最下方右侧有归档列表按钮，点击后会展示所有归档会话。你可以使用搜索和排序找到目标会话，再点击右侧的撤销按钮将其恢复到对话列表，随时继续对话。

<img src="/_docs-assets/cancel-archive.png" alt="" />

## 删除会话

在左侧 sidebar 的最下方右侧有归档列表按钮，点击后会展示所有归档会话。你可以点击对应会话右方的删除按钮，点击后会话会被彻底删除，包括其对话历史，并回收 CLI 侧剩余的磁盘空间。此操作无法撤销。

<img src="/_docs-assets/delete-archive.png" alt="" />

## 批量恢复和删除

鼠标移动到对应对话时，可以点击前方的选择框进入多选模式。之后可以点击更多进行批量的选中，在右上角选择批量恢复或者删除。
