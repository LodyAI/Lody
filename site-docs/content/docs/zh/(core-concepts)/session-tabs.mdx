# 多标签会话

多标签会话让一个任务不再只能有一条线索。一个 session 里可以打开和关闭主对话及子对话标签，也可以使用文件预览和 diff 视图，在同一个任务上下文里并行审阅、追问和修复。

## 适合的场景

- 主标签继续让 Agent 实现功能，同时新建一个子标签让另一个 Agent 审查当前改动。
- 打开文件或 diff 标签后，把对话留在左侧，边看代码边继续追问。
- 对同一条分支上的不同方向分别提问，例如“总结这次改动”“检查潜在风险”“根据 PR 评论修复”。

## 新建子对话标签

1. 进入一个 session，点击标签栏上的 `+`。
2. 新标签会继承主标签的机器、项目或仓库、分支、Agent 配置、模型和权限模式默认值。发送前可以选择绑定在这台机器上的任意 Agent 角色，角色也可以把 draft 切换到另一种 Agent。
3. 在新标签里输入消息并发送，Lody 会使用所选角色的运行配置和默认指令创建一个子 session。标题默认取第一行 prompt，之后可以双击标签名重命名。

子标签和主标签共享同一个工作目录上下文，但对话历史彼此独立，适合把同一项任务拆成多个协作视角。

## 文件和 diff 标签

- 点击对话中的文件路径，会打开文件查看标签。
- 点击对话下方的当轮 diff 文件，会打开 diff 标签。
- 在右侧 `Files` 或 `Changes` 面板里点击文件，也会作为查看标签打开。

桌面端有文件或 diff 标签时，会自动形成左右分栏：左侧继续聊天，右侧查看文件或差异。移动端会把文件和 diff 作为当前查看面板打开，方便在小屏上集中阅读。

## 管理标签

- 拖动标签可以调整顺序，顺序会在当前浏览器中保留。
- 双击对话标签可以重命名。
- 主对话和子对话标签均可关闭。关闭状态在工作区内共享，不会停止 Agent、归档会话或清理 worktree。
- 关闭当前对话后切换到相邻标签；全部关闭时在同一工作区进入本地新对话草稿，已有草稿保留输入。首次发送才创建真实会话，已关闭对话仍可重新打开。
- 历史按钮统一列出已关闭对话，包括过去已归档的标签。重新打开已归档对话时也会取消其归档状态。
- 重新打开后所有人都能看到标签，但只在操作方主动选中。文件和 diff 标签保持原有本地行为。
