# 本地工作目录

Lody 支持添加本地任意工作目录，推荐使用桌面端进行使用。添加后对于本机的项目 Lody 也可以支持所有内容的多端
实时同步，包括对话记录、文件差异查看、Git 分支以及每个会话独立的工作树。

## 添加工作目录

Lody 支持多种方式进行添加：

- 桌面端点击 `我的项目` 旁的 `添加图标`，这将弹出本机的文件浏览器，你可以选择目录进行添加。
- 如果非桌面工作环境，例如服务器等，你可以使用 [CLI 命令](/zh/docs/cli/#project-%E5%91%BD%E4%BB%A4)
  `npx lody project add [path]` 进行添加。

## 本地优先与离线使用

在桌面端，已经保存在本机的项目和会话即使暂时无法联网也仍可使用。你可以从本地工作区目录打开它们、查看历史并继续工作；本地修改会被保留，并在网络恢复后继续同步。

仅依赖云端的操作仍需联网，例如打开其他机器上的项目或获取新的 GitHub 数据。从其他设备移除项目时，项目所属机器也仍需在线。

## 本地项目的工作树

本地项目现在也支持与 GitHub 项目一致的工作树流程：

- 每个会话都会按需自动创建独立的工作树。
- 会话归档时，对应的工作树会被自动回收。

完整的工作树说明可参考 [工作树](/zh/docs/worktrees)。

## 同步代码 Agent 历史（Codex、Claude Code 等）

如果你此前直接用 Codex 或 Claude Code 操作过这个本地项目，Lody 可以把已有的对话历史导入进来，并在任意
设备上继续。

- 在 **设置 → 项目** 中选择对应的本地项目，可以手动触发一次同步，导入 Lody 在该机器上检测到的 Agent
  的历史对话。
- 完成同步后，在 Lody 中新创建的对话也会回写到对应 CLI（Claude Code、Codex 以及其他基于 ACP 的支持
  agent），双向保持同步。
- 打开导入进来的对话时，Lody 会自动拉取最新内容，确保展示的是底层 CLI 的最新状态。

## 团队可见性（非 GitHub 项目也能协作）

本地项目默认是私有的，即使加入了别人的工作空间，团队成员也看不到这些项目。

如果你希望团队能够协作一个不在 GitHub 上的项目：

1. 打开 **设置 → 项目**。
2. 选择对应的本地项目。
3. 打开团队可见性开关。

团队成员就能在侧边栏看到这个项目并在上面发起会话。与 [共享机器](/zh/docs/team#团队机器可见性) 类似，只有
项目的拥有者能修改可见性设置，关闭后这个项目会立刻从其他成员的视图中消失。

## 远端访问本地项目

在其他设备上（Web、移动端，或另一台桌面端）你也可以直接查看本地项目所在机器上的状态，不必本人坐到那
台机器前：

- 查看项目当前的 Git 分支状态。
- 直接在远端机器上启动一个工作树，然后在任意设备继续工作。

这让本地项目也能像 GitHub 项目一样支持手机协作和"不在工位时"的工作流。

## 删除其他设备上的项目

即使本地项目属于另一台设备，你也可以从桌面端或移动端将自己的项目从 Lody 中移除。

所属设备必须在线，因为 Lody 需要把删除请求发送到那台机器。移除项目前，Lody 会先归档其中的
Sessions，并让所属机器清理项目的 Worktree 配置。从 Lody 中移除项目不会删除磁盘上的原始项目目录。

## 当前限制

- 当前本机项目无法在远端直接推送分支（但你可以让 agent 帮你完成相关 Git 操作）。
