版本 0.89.0

### ✨ 新功能

- 全新新手引导支持选择或跳过首个 Agent，通过只读示例项目完成第一次任务，并为同步中或待配置状态提供明确指引。
- 计划模式采用统一的会话面板，让主 Agent 与子 Agent 的计划更容易查看和跟进。
- 项目设置支持按运行设备管理文件夹，并新增更便捷的本地项目操作菜单。
- 桌面端新增开机自动启动选项。
- 新增作用域明确的键盘导航，改善侧边栏、菜单和对话区域的键盘操作体验。
- 文档站新增完全在浏览器本地运行的中英文搜索。
- 新增统一的社区加入入口与飞书交流群二维码。
- 注册表 Agent 支持标准 ACP 身份验证，并升级内置 Claude、Codex、Kimi 和 Grok 运行时。

### 🐛 修复与改进

- 修复已移除的内置 Agent 在重启后重新出现的问题。
- 修复从侧边栏进入项目时选择状态丢失，并改善项目设置弹窗布局。
- 改善协作会话中的 Agent 配置同步和子标签页 Agent Role 选择。
- 修复排队消息调度及 MCP 子会话完成通知，并兼容旧版客户端的任务完成通知。
- 修复会话标签页重新选择、路由同步和长标题重命名问题。
- 修复快捷键提示、子会话模型搜索和消息发送后的输入焦点问题。
- 修复会话路径打开方式检测及 Agent 文件链接可能消失的问题。
- 修复移动端会话认证恢复、工作区设置间距、安全区域适配和后台授权状态提示。
- 改善设置页面的圆角裁切、状态标记、嵌套弹窗遮罩和链接行为。
- 修复首次启动语言检测及中文文档链接。
- 修复桌面窗口拖动区域与面板交互冲突。
- 改善本地会话的 GitHub 项目关联，并避免预览代理因异常关闭码中断。
- 恢复被阻塞目标的继续执行操作。
- 本次范围还包含公开仓库的构建一致性与贡献流程维护。
