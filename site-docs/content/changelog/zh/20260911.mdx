版本 0.93.0

### ✨ 新功能

- 支持安全转移工作区所有权，并保持现有订阅与计费连续
- 桌面端支持在独立窗口中打开会话和工作区
- 支持选择多条聊天消息导出为 PNG，并可直接复制已生成的聊天分享图片
- 支持跨机器提及 Agent Role，并在列表中显示暂不可用的 Role
- 聊天消息新增发送者身份显示，便于多人协作时辨认消息来源
- 用量页面新增分享图片，可将 Token 用量、活跃趋势和模型占比导出为横版或竖版报告
- 可从会话分支菜单将完整上下文复制为 Markdown，并改进会话导出格式
- 完善 Codex 目标的暂停、恢复和清除控制
- Codex 和 Grok 可直接使用 Agent 生成的会话标题，减少重复等待
- 优化首次启动流程，提前准备 Agent 运行环境并更清楚地展示等待状态
- 创建本地项目时优先使用机器所有者的 Git 身份

### 🐛 修复与改进

- 修复目标暂停后无法直接恢复、操作按钮可能持续不可用的问题
- 修复 Codex 分支会话首次提示可能卡住，以及取消请求后可能出现提示冲突的问题
- 凭证过期或身份变化时保留 Agent 上下文，减少会话中断和重复启动
- 改进 Plan 模式兼容性、DeepSeek Harness 设置及 ACP 能力缓存恢复
- 提高会话历史写入、流式更新、机器访问重试和长异步任务链的可靠性
- 改进本地文件链接、系统打开操作及文件夹拖放体验
- 改进 Mermaid 图表交互：消息内滚动不再被图表截获，全屏查看支持缩放和拖动
- 修复上下文压缩结束后会话状态未正确收尾的问题
- 改进子会话归属、侧边栏折叠入口和加载期间的分支操作显示
- 统一桌面快捷键生命周期，提高窗口切换和快捷键管理的稳定性
- 修复 Windows Agent 升级和生命周期确认失败，并改善移动端键盘收起后的布局
- 优化移动端同步节奏、机器状态加载和官网移动端首屏性能
- 修复成员身份刷新时偶发的权限错误
- 感谢外部贡献者 @EYHN、@slashdevcorpse、@ladydd、@hqhq1025 和 @nzhl，他们改进了文件夹拖放、移动端同步、工作时长统计、减少动态效果体验、Codex 分支会话和终端显示
