版本 0.117.0

- 新增繁体中文、日语、韩语、西班牙语、法语和俄语 6 种界面语言。
- 支持跨会话记住权限授权并新增可同步的默认权限设置；侧边栏任务支持按团队成员筛选，团队成员添加菜单显示头像，工作组摘要标题支持滚动吸顶。
- 桌面端 Today 独立窗口支持记忆窗口尺寸与位置，并新增全局开关快捷键。
- 移动端支持将对话分享为图片、在 Markdown 表格/代码块/卡片中快速引用，以及以本地草稿打开当前目录新标签页；修复 iOS 菜单闪烁、前台恢复与分享扩展体验问题。
- 隐私设置支持即时退出遥测并统一使用情况共享开关，新增分地区 Cookie 提示。
- 修复邮箱登录切换动画抢占密码框焦点、已验证邮箱误跳验证页等登录问题。
- 全面加固加密工作区的创建、设备配对、密钥恢复与成员密钥投递流程，并优化错误提示与引导文案。
- 升级 Loro 至 1.19.1 并优化守护进程与渲染进程内存占用；支持通过工作区 WebSocket 承载守护进程持久化 Streams 房间，新增 CLI `restore-id` 命令并优化多 Agent 委派链提示。
