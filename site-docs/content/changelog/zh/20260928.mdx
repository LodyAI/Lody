版本 0.101.0

### ✨ 新功能

- 全新的 UI 设计，更新侧边栏、设置页、PR 面板、工具调用详情和输入框菜单，统一明暗主题与交互体验。
- 新增定时任务，可设置单次或重复执行、选择运行机器与 Agent，并查看执行历史；也可以让 Agent 提出计划，确认后创建。
- Codex 支持配置多个独立账号，以及使用自定义 API 地址和密钥。
- 新增子代理活动详情，可查看支持的 Agent 提供的任务状态、执行过程和结果。
- Agent Role 新增描述字段，方便说明角色的用途与职责。
- Agent 可以查询工作区中的 Agent Role、机器和项目，找到合适的执行配置与位置。
- 全新的 Lody Preview 方案，支持本地预览和按需开启远程预览，并改进连接状态与失败恢复提示。
- 本地项目支持 PR 关联，可使用所在机器的 GitHub 凭据获取 PR 信息。
- Markdown 支持查看图片，包括本地图片和按需加载的远程图片。
- 支持查看单轮 Token 用量。
- 支持从会话信息栏打开关联对话树。
- Pi 支持扫描和选择本机扩展，并导入历史会话；Grok 支持完整会话及历史轮次分叉。
- 新增会话全宽显示、字体连字和可选的行内数学公式渲染。
- 新增头像裁剪；macOS 支持切换应用图标并保留选择。

### 🐛 修复与改进

- 改进流式回复渲染，让 Markdown 内容随回复逐步呈现，减少闪烁与重复动画。
- 优化长会话滚动和会话切换，减少内容跳动与空白。
- 改进附件上传与待发送消息的状态展示、失败重试和中断恢复；超长粘贴文本可自动转为文本附件。
- 编辑并重新发送消息时，支持与输入框一致的引用选择。
- 修复导入会话后续聊或分叉时可能使用错误 Agent 配置的问题，恢复 GPT-6 Sol 和 Luna 的扩展推理选项。
- 改进 GitHub 凭据选择，以及仓库改名、转移后的 PR 关联；CI 状态按最新检查结果判断。
- 修复刷新后未保存的编辑内容丢失、归档与关闭标签相互影响，以及重复历史修复的问题。
- 改进侧边栏分组状态、待发送提示和 macOS Dock 角标，修复移动端附件菜单、折叠状态与文件跳转交互。
- Agent 登录时显示运行时下载进度并支持取消；优化首次连接机器的引导和初始化失败提示。
