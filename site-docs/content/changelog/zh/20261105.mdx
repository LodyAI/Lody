版本 0.110.0

### ✨ 新功能

- 图片标注：支持在图片预览中绘制、添加文字和备注，标注结果可作为附件发送给 Agent。
- 会话自动继续：支持等待条件满足后继续任务，并可按会话启用额度恢复、PR 合并后归档和空闲压缩。
- Android 模拟器预览：新增预览与控制入口，支持触控、文字粘贴、旋转、截图、深浅色切换及画质选择。
- Agent 登录方式展示：登录前即可查看 Agent 支持的登录方式。
- Pi 更新：内置 Pi 升级至 1.4.0，新增 Streamable HTTP MCP 支持。
- iOS 与 Android 并排预览：将一个设备预览标签拖到另一个上，即可同时查看两个屏幕；支持拖动分隔线调整宽度，双击恢复默认比例。
- 对话文字引用：可将选中的消息片段加入输入框，引用原文继续提问。
- PR 堆叠展示：PR 面板展示 GitHub 登记的堆叠顺序、状态和当前所在层；侧栏新增关联 PR 展示。
- 定时任务更灵活：提示词支持提及，执行间隔支持自定义分钟数或小时数。
- 直接恢复归档对话：输入区新增恢复按钮，恢复时保留已有草稿。
- 跨机器 Agent 引导：可向其他机器上正在执行的对话追加指令，不支持即时引导时转入队列。
- Claude 支持按会话发现 Anthropic 兼容网关提供的模型。
- Agent 队列管理：Agent 可查看目标对话尚未开始的消息，撤回或替换自己发送的排队指令。
- 更完整的协作状态：Agent 可查询对话正在执行的工具、最近输出时间、排队数量，以及机器磁盘和可用额度信息。
- 带来源的消息引用：Agent 转发指令时可引用原始消息，并附上记录中的作者信息。
- 设备配对入口默认开放：账号级设备配对不再需要开启开发者模式或测试开关。
- 批量归档对话：Agent 可通过 MCP 一次归档多个会话。
- 首页双周期额度展示：同时查看短周期和周额度的使用比例及重置时间。
- 对话组独立命名：侧栏对话组与各标签页可分别改名，不再互相影响。
- 更明确的协作失败信息：MCP 返回具体失败原因、额度重置时间等信息，成功重试后不再保留旧的失败状态。


### 🐛 修复与改进

- Claude 额度耗尽提示改为开启会话自动恢复；额度恢复或到达重置时间后重新检查并继续。
- 定时消息直接展示正文，支持在当前对话内编辑，并按查看者本地时区显示发送时间。
- 修复对话等待委派任务、消息收件箱启动异常时，定时消息无法继续投递的问题。
- 改善后台服务、消息队列及 MCP 列表在短暂连接失败后的恢复，减少对话卡住。
- 修复模型与思考强度等会话设置被历史输入或草稿覆盖的问题。
- 改善 Pi 会话分叉和斜杠命令加载，避免不同会话的命令列表相互影响。
- 修复 DeepSeek 历史记录的图片导入、列表信息和启动错误展示。
- 兼容缺少输入能力描述的 Magpie 模型。
- 改善 iOS 对话滚动惯性，以及历史页按钮点击、侧栏缩放和桌面页面对齐。
- 优化默认字体，在可用时优先使用 SF Pro Display。
- 修复套餐信息加载失败导致整个工作区异常的问题，并改善主屏幕小组件缓存恢复。
- 内置 Claude Code 升级至 2.1.316。
- 恢复此前的会话配置与发送行为，修复旧版后台服务可能无法发送消息的问题。上一轮“会话设置不再被历史输入或草稿覆盖”条目需移除。
- 会话自动继续控件按目标机器的实际支持情况显示，避免旧版后台服务出现不可用操作。
- Android 预览画质选项移入“更多”菜单，减少工具栏占用。
- 修复登录状态尚未就绪时提前加载组织信息导致的异常。
- 改善多 Agent 协作：返回消息投递状态和具体失败原因，标明 Agent 消息来源，并等待引导后的最终回复，避免只收到中途结果。
- MCP 支持使用唯一的短会话 ID，并按角色、时间和方向读取历史，减少不必要的上下文。
- 降低长对话历史读取及内部 MCP 进程的内存占用，改善流式输出期间的历史访问。
- 修复自动继续队列未及时唤醒的问题，并明确显示连接中、离线和不可用状态。
- 修复计划模式退出状态被历史加载覆盖，以及信息栏和侧栏 PR 状态不同步的问题。
- 同一对话的多个标签页共享模拟器绑定，减少重复选择。
- 改善提问卡片标题与 Markdown 显示，并兼容 Droid 问题表单。
- 修复标注后的图片超过附件限制、PDF 面板缩放适配及 WebKit 分享卡片布局问题。
- PR 图片改为按需加载；修复侧边栏标签滚动条无法拖动，以及消息编辑器和队列文字对齐问题。
- 定时任务检测到额度耗尽且重置时间明确时，会延后执行，避免反复失败或恢复后集中触发。
- 对话完成后只折叠思考和工具过程，所有回复正文保持可见；展开的过程按原顺序展示。
- 发送消息后隐藏已使用的消息建议，避免旧建议再次出现。
- 修复手机登录输入框被键盘遮挡，以及部分页面返回按钮被状态栏遮挡的问题。
- 修复项目记录缺少路径时，文件夹浏览器无法打开的问题。
- 修复 CLI 快照上传可能一直等待的问题，改善初始化失败后的重试。
- 统一输入框、发送按钮和附件标签的字重。
- 侧栏 PR 展示调整：恢复原有单个 PR 状态图标；上一轮“侧栏新增关联 PR 展示”条目需移除，PR 面板的堆叠展示保留。
- 首页根据任务状态调整卡片排列；卡片加载异常时，新建对话输入框仍可使用。
- 修复置顶对话的关联层级被拆散，以及 PR 显示“可合并”时侧栏图标跳动的问题。
- 改善 Agent 登录方式兼容性和认证进度提示，补全自定义 ACP Agent 的用量统计。
- 修复短暂同步异常时，健康机器被误判为离线的问题。
- 优化大型项目的文件索引，跳过忽略目录和缓存，减少 CLI 卡顿及文件误标删除。
- 修复未记录比较基准时的 Git 差异计算，改用远端默认分支。
- 移动端可直接打开浏览器预览，不再要求手动输入地址；修复 iOS 模拟器边框内的主题接缝。
- 回复折叠规则修订：Agent 明确标记的进度说明会归入过程折叠，最终回复保留可见；替换此前“所有正文保持可见”的表述。
