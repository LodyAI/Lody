版本 0.101.1

### ✨ 新功能

- 远程网页预览支持提前加载，打开 Browser 面板更快。

### 🐛 修复与改进

- 修复消息发送被网络同步阻塞的问题，改善弱网下的发送与重连恢复体验。
- 修复待发送消息阻止会话归档或删除的问题。
- 更新内置 Claude，修复工具调用状态、输出和文件改动信息显示不完整的问题。
- 加快桌面端本地文件预览。
- 点击文件改动时聚焦所选文件，并在改动列表中显示目录路径，方便区分同名文件。
- 为本地 worktree 选项增加 Git 状态加载提示。
- 改善并发更新时的数据同步稳定性。
