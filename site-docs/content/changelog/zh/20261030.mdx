版本 0.109.0

### ✨ 新功能

- 多仓库项目：将多个 Git 仓库、子模块和本地文件夹组织为一个项目，在同一对话中协作处理跨仓库任务。可以在设置--项目中添加，或者桌面端侧边栏右键已有项目添加   （iOS 最好等移动端 tf 发布，不然看不到多项目的对话
- 按仓库查看 PR：在多仓库对话中切换当前仓库显示，查看对应的 PR、CI 状态和操作入口；子模块按层级展示。
- Magpie 命令行导入：支持通过 CLI 导入 Magpie 服务商配置，方便在无桌面环境的机器上使用。
- 下一条消息建议：claude code 支持在空输入框中展示 Agent 返回的建议；桌面端按 Tab、手机端点“应用”即可填入。
- MCP 本机登录：支持浏览器授权、退出登录及手动配置凭据；凭据保存在本机系统凭据库，不随工作区配置同步。
- 定时任务页改版：新增项目与状态筛选、排序，以及设置和运行历史视图；支持批量清理已结束的定时消息。
- 任务面板分类展示：子 Agent 与后台任务分别显示在独立标签页中，方便查看执行进度。
- 跨机器 Role 协作：从本地项目调用远程 Role 时，可使用项目关联且已接入工作区的 GitHub 仓库；关联对话在列表中保持嵌套。
- iPhone Duo 适配：移动端布局随可用屏幕空间调整，改善折叠、展开和分屏体验。
- 定时发送消息：支持预约消息、附件和引用，并可修改或取消；目标机器离线时，恢复后会在有效期内补发。
- Claude 额度重置后继续：可一键预约在额度重置后发送 `continue`，接着完成任务。
- DeepSeek Harness 插件管理：支持通过本机 CLI 管理服务商插件，同时保留已有用户配置。
- 用量重置时间切换：可在“多久后重置”和本地时区的具体日期时间之间切换。
- 更大的远程文件下载：付费工作区支持下载最大 100 MiB 的文件，文件所在机器的 CLI 需同步更新。

### 🐛 修复与改进

- 修复对话内容更新时已有文本可能被错误覆盖的问题。
- 改善跨仓库 PR 关联与状态同步，避免状态更新影响已有的 PR 关联。
- 修复连接短暂重连时，侧栏机器在线状态反复闪动的问题。
- 修复添加普通环境变量后，部分服务商的订阅用量信息不再显示的问题。
- DeepSeek 对话完成后自动折叠过程输出，让最终回复更易阅读。
- 优化移动端消息队列操作按钮布局、记忆列表角色标签对齐和桌面登录页图标显示。
- agent 创建子对话倾向优先使用新对话，除非指定 tab 对话
- 改善桌面端登录恢复，避免启动时网络响应较慢导致意外退出登录。
- 修复消息队列在同步顺序变化时可能无法继续发送，以及异常结束的任务仍显示运行中的问题。
- 创建新对话不再等待远程 MCP 默认配置同步；批量创建对话时保留所选 MCP。
- 修复后台任务运行中消失、Claude 任务完成后执行者信息丢失的问题。
- Kimi 在请求计划审批前显示完整计划内容。
- 修复 Pi 切换模型后，思考强度选项与模型能力不匹配的问题。
- 更新 Codex 运行时，改善技能列表刷新、上下文压缩完成判断和切换服务商后的错误提示。
- 修复多仓库项目在子模块检出不完整时的启动问题，并改善文件夹路径展示和侧栏归档、折叠行为。
- 修复 PR 冲突解决操作未进入当前对话，以及移动端重命名误作用于其他对话的问题。
- 修复 Nowledge Mem 正常连接被误判为异常的问题。
- 改善移动端机器管理按钮的返回手势冲突，以及终端标签、登录文字和首页状态显示。
- Claude 达到额度限制时，可直接从提示卡片预约重置后继续；预约时间与界面显示保持一致。
- 定时发送不可用时，悬停可查看具体原因。
- 改善手机端首次发送消息时的界面与键盘衔接，新建对话会恢复上次使用的项目。
- 手机端消息队列改为紧凑的单行布局。
- 改善多个 Lody 版本共存时的链接打开行为，将对话、新建对话和服务商导入链接交给正在运行的版本。
- 优化 Agent 提示卡片及思考内容的对齐、配色和行内代码样式，减少视觉干扰。
- 定时消息管理更直观：预约时间显示在发送按钮旁，已预约消息统一收进消息队列，可直接修改发送时间、编辑内容或取消。
- 优化消息队列布局：手机和窄窗口下采用紧凑单行展示，操作集中到“更多”菜单；已结束的一次性定时消息记录保留七天后自动清理。
- 修复新手引导中输入框消息建议相关的兼容问题。
- 修复“中断并发送”后新消息被一并取消的问题；停止任务失败时，会在对话中显示原因。
- 同机 Agent 通过 MCP 向正在执行的对话发送消息时，支持直接引导当前任务。
- 移除定时任务额外的执行槽位限制，减少任务相互等待。
- 创建项目后自动选中新项目，并支持从项目选择器直接编辑项目组。
- 项目子模块准备时复用本地 Git 数据，减少重复下载。
- 修复应用预览中的 Cookie 传递，改善需要登录的页面预览。
- 修复浏览器登录页异常，以及无效邀请链接的错误处理。
- 修复手机端提及菜单无法滚动，以及中文环境下消息队列时间格式异常的问题。
- 优化消息建议换行与光标显示，使用输入法组合输入时暂时隐藏建议。
- 修复 WebKit 滚动阅读时的位置跳动，并改善分享图片清晰度。
- 改善文件链接识别与路径复制，减少相对路径误跳转。
- 清理已删除对话的专用工作目录；归档时仅清理空目录，保留已有文件。
- 修复短暂网络延迟导致在线机器被误判为离线、对话操作被拒绝的问题。
- 改善定时任务加载失败后的恢复，保留本地修改，并支持手动重试。
- 修复部分模型的思考强度选项和模型列表不匹配，以及 Pi 启动时模型与思考强度设置顺序错误的问题。
- 改善 DeepSeek Harness 启动兼容性；缺少受支持的 Node.js 时提供明确安装提示。
- 修复桌面窗口拖拽区域上的通知按钮无法点击的问题。
- 支持使用 macOS Emacs 风格快捷键，在输入框中的文件引用前后移动光标。
