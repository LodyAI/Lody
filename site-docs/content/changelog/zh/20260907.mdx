版本 0.92.0

### ✨ 新功能

- Agent 创建新会话时，即时显示可打开的会话卡片，并持续更新执行状态
- 项目 Skills 支持按名称、描述、作者和路径搜索
- HTML 附件和预览界面新增下载入口，方便保存源文件

### 🐛 修复与改进

- 改进本机文件预览，大文件支持分页读取，图片和文件加载更加高效
- 修复 Factory Droid 连接，并让推理强度选项随所选模型正确变化
- 改善 Grok 工具权限行为，优化本地大量分片数据的处理效率
- 修复新聊天附件在切换标签后丢失，以及旧消息未送达提示消失的问题
- 修复会话工作时长被错误延长，以及标题生成受先前输出干扰的问题
- 修复 Linux .deb 更新安装导致应用卡住的问题，支持取消授权或安装失败后重试
- 修复已执行的一次性定时任务错误显示为下一年执行的问题
- 改进桌面输入框焦点、侧边栏会话层级显示和移动端滚动体验
- 改善多人协作中 Agent 会话委派与完成通知的可靠性
