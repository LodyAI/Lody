版本 0.97.1

### 🐛 修复与改进

- 修复向内置 Claude 发送引导消息后，Agent 约 5 秒被强制终止的问题。
- 修复 Windows 上系统凭据存储无法解密（例如机器恢复到新账户后）导致桌面端无法完成登录的问题：现在会自动恢复，并在失败时给出更明确的原因。
- 恢复 Devin 内置运行时。
- 连续关闭多个标签页时，剩余标签的宽度会暂时固定，下一个关闭按钮始终停在光标下方（与 Chromium 一致）。
- 关闭从未发送过消息的空标签页时会直接删除，不再残留不可见的会话；关闭标签页不再弹出提示，只剩一个标签时不再显示关闭按钮。
- Agent 工作时，对话中以流光标签显示当前活动和已用时长。
- 消息 Operation 完成后会显示它送达了哪个 Session，并以「收到回复」卡片展示结果，可在弹窗中查看完整回复。
- 后台任务的完整命令可在弹窗中查看。
- 工作区切换器顶部显示当前工作区。
- 排队消息紧贴输入框显示，其中的图片可在图片查看器中打开。
- 编辑文件没有行数统计时，改为显示文件标签，不再显示空白统计。
- 打磨桌面端界面：macOS 顶栏与红绿灯对齐、浅色模式下的代码块对比度、悬停与设置页层次、侧栏项目分组布局、对话内搜索栏，以及多行代码字号与对话正文的协调。
