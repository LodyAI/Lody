版本 0.77.0

### ✨ 新功能

- 聊天输入支持粘贴文件和拖拽上传。
- 聊天图片和文件图片现在都可以点击放大、缩放和平移；桌面端还支持右键复制图片或另存为。
- Agent 登录失效时支持在 Lody 内重新认证，不必重新创建会话。
- Agent 报错现在可点击查看完整详情，并一键复制诊断信息；移动端也能正常查看。
- 改进 workspace 邀请、加入审批和私有资源分享引导，缺少可共享机器或项目时会给出更明确的提示。
- 本地项目导入完成后会自动进入项目。
- 移动端 Web 现在可以进入账单设置。

### 🐛 修复与改进

- 大幅减少文件树滚动和会话切换时的主线程工作，打开大型项目、切换会话和恢复右侧面板更流畅。
- 降低后台同步、持久化和异常重连带来的 CPU 与内存压力；网络波动或单个同步房间异常时，不再触发全 workspace 的高频重连风暴。
- 修复本地会话闲置后偶发不同步、Agent 回复延迟，以及恢复会话时分支丢失的问题。
- 修复向运行中的 Agent 发送指导消息失败后消息可能一直卡住的问题；无法即时插入时会自动排到下一个普通回合。
- 修复多 workspace 环境下 Git 操作可能使用错误账号凭据的问题，以及旧会话中本地分支与远程分支同名时无法恢复的问题。
- 移动端 Plan Mode 开关恢复正常。
- 修复消息复制按钮无反应的问题。
- 手机横屏时继续使用手机布局；网页不会再未经用户操作自动尝试唤起 App。
- 修复移动抽屉内下拉菜单可能报错、统计数字被裁切、Agent 名称被截断和超长项目路径撑破对话框的问题。
- 应用崩溃页现在会显示可读错误并支持复制报告；反复恢复失败时，可在确认后清除本地数据并重新登录。
