版本 0.115.0

### ✨ 新功能

- 加密工作区现在可以连接 GitHub，并支持推送通知、实时动态和收件箱客户端；加密会话也支持 Prompt 快捷短语。
- Roost 会话历史可保存在加密工作区中，包括由机器持有的历史记录，并可在工作区客户端间访问。支持将现有 OSS 快照迁移到加密工作区，也可以为远程 CLI 配对加密工作区。
- 查看加密工作区的用量和数据传输费用提示。

### 🐛 修复与改进

- 恢复文件现在绑定到规范站点来源；发送邮件邀请需要明确批准；只有加密工作区会显示恢复入口。
- Auto delivery 现在只会依据可信的 PR 与检查结果执行操作。
- 修复按模型读取智能体配置的问题，并改进 Today、侧栏、稍后处理和移动端显示。
