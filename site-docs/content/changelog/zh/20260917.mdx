版本 0.95.0

### ✨ 新功能

- 新增内置 Pi agent，支持托管运行时；升级现有 Pi provider 前会请求确认，并保留原有设置与已存历史；迁移后无法续聊旧 Pi 会话，请新建对话。
- 支持将已获授权的会话分享结果直接返回给 MCP agent。
- 支持从本地 CLI 启动 Devin。
- 支持更可靠地关闭和恢复工作区共享会话。

### 🐛 修复与改进

- 修复 DeepSeek Harness 在部分 Node 版本下无法启动的问题，改由 Lody 内置 Node 运行。
- 修复 iOS 应用从后台恢复后偶发白屏的问题。
- 改进会话中断、恢复、后台预取和流式内容处理，减少草稿丢失和整段会话失效。
- 改进分享请求、provider 设置、错误恢复和归档行为。
- 修复工具输入中的 JSON 被误识别为 Markdown 数学公式的问题。
