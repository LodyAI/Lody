版本 0.107.2

### 🐛 修复与改进

- 修复 GitHub 与 Lody 邮箱不同时无法完成个人 GitHub 授权的问题，并改善授权完成后返回设置页的体验。原有用户需在 GitHub 设置中重新授权一次。
- 支持绑定使用不同邮箱的登录账号，包括使用 Apple 隐藏邮箱的账号。
- 修复 Claude 子代理读取图片时，会话数据持续膨胀、导致加载缓慢或同步失败的问题。
- 改善 MCP 资源列表在启动、重连和同步异常后的恢复，减少资源缺失或同步状态长期不更新的问题。
