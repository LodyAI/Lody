版本 0.110.1

### ✨ 新功能

- 在设置中统一管理 Lody Agent 的账号与自定义模型服务连接，支持配置接口地址、协议和 API Key。
- Lody MCP 新增命令按需帮助，Agent 可查询具体命令的用法和参数，减少工具列表中的重复说明。

### 🐛 修复与改进

- 优化远程代码差异加载，减少重复传输，大文件按需加载，刷新时保留阅读位置和展开状态。
- 修复机器连接状态刷新时，已选远程机器意外切换的问题，并改善离线状态显示。
- 修复编辑项目时未保留所选机器的问题，隐藏桌面端空项目分组。
- 改进对话引用，支持连续选择同一轮回复中的多段文字，并保留链接、列表、代码等格式。
- 恢复已完成回复末尾内容的折叠行为。
- 修复对话组重命名后侧栏未及时更新的问题。
- 改善输入框提及的显示，修复光标位于提及边界时颜色异常，以及发送后旧提及状态残留的问题。
- 完善加密会话中排队消息的校验，修复共享权限状态尚未就绪时消息被错误阻止的问题，并改善命令行配对与密钥状态提示。
- 修复 Android 安装包可能缺少推送配置的问题，避免因此无法接收通知。
