版本 0.104.0

### ✨ 新功能

- 新增 iOS 模拟器预览，可在会话中查看和操作 Mac 上的模拟器，也可让 Agent 启动预览。
- Agent Role 支持关联 Nowledge Mem 记忆身份，并可在设置中管理。
- 新增内置 Devin 支持。
- Pi 支持使用自定义可执行文件。
- DeepSeek Harness 支持从已完成的对话轮次创建分支，继续探索不同方案。
- PR 面板新增代码变更查看，支持按单个提交或提交区间筛选，并搜索变更文件。
- MCP 设置支持查看服务器提供的工具列表。
- Agent 通过 MCP 创建会话时，可以指定权限模式及目标 Agent 支持的配置选项。
- 支持输入 `￥` 打开技能选择菜单，方便使用中文输入法调用技能。
- Agent 委派到其他会话的消息会显示发送方的 Agent 或角色身份，并可查看来源会话。
- 新增可选代码语言扩展包，可按需启用更多编程语言的高亮。
- 启用扩展语言后，文件预览支持 Coq、Rocq 和 Lean 代码高亮。

- 修复切换会话标签后，尚未发送的 Fast 设置丢失的问题。
