版本 0.113.0

### ✨ 新功能

- 新增内置 Antigravity 和 DeepSeek Harness，并升级 Codex、Claude Code、Kimi、Grok、Devin 和 Pi。
- 支持扫码与批量配对设备，优化设备名称展示，新增恢复保险箱和 iOS 恢复备份导出。
- 定时任务支持每隔指定分钟或小时重复执行。
- 桌面和移动端支持预览本地 HTML 文件；移动端支持打开 Markdown 文件并查看 Plan Mode 计划。
- 新增会话状态视图、对话大纲及隐藏空项目选项，按本地时区展示每小时 AI 用量。

### 🐛 修复与改进

- 改进加密工作区的配对、密钥更新和恢复流程，减少等待并展示恢复进度。
- 修复认证恢复和网络切换时的重复请求、同步等待及会话打开问题。
- 后台任务运行和完成状态更准确，任务完成后可继续唤醒会话。
- 修复移动端登录返回、长会话、iPad 导航和草稿保留问题。
- 优化引用插入、提及编辑、思考与工具折叠，以及变更文件统计。
