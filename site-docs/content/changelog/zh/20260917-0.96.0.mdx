版本 0.96.0

### ✨ 新功能

- 桌面端 Markdown 文件链接新增右键菜单，可复制路径、打开文件、使用指定应用打开，或在 Finder 中显示。
- 桌面端新增开发者诊断面板，可查看运行状态和性能指标。

### 🐛 修复与改进

- 本地项目侧栏默认显示有限数量的会话预览，并支持展开查看全部会话。
- 修复分享发布后请求卡片仍然显示的问题。
- 修复公共浏览器在重定向、历史导航和页面内跳转时重复加载的问题。
- 从 Word、PowerPoint 等应用粘贴内容时优先保留复制的文字。
- 仅在设备支持时显示 Pi 迁移选项。
- 未完成回复时不再显示 Fork 操作。
- 修复 macOS 上部分 Agent 原生扩展无法加载的问题。
- 改进本地 Loro 会话加入失败后的恢复与重试。
- 改进深色主题下归档多选控件的可读性。
- 修复从创建卡片打开已关闭子会话时无法准确恢复的问题。
- 展开或收起已完成内容时保持阅读位置。
- 改进 Devin 子 Agent 在会话中的展示。
- 后续消息会继承目标会话的模型和运行配置。
- 改进桌面端浏览器登录流程，避免重复回调导致登录状态异常。
- 更新内置 Agent 运行时版本。
