版本 0.114.1

### ✨ 新功能

- 新增账户级 EverMe 记忆服务，支持一键下载或手动安装。
- 新增实验性 Today 大纲，可记笔记、勾选待办、引用会话或把条目转成任务。支持聚焦某一条及其子项、逐级全选和批量操作；桌面端可以单独打开 Today 窗口，边看计划边处理会话。
- 新的状态视图按 Focus、Later、Settled 整理会话。可以把会话延后 1 小时或 3 小时再处理，也可以拖回 Focus。
- 置顶会话支持分组和手动排序。每台设备可选择显示哪些分组，也能在分组里直接新建会话。拖动会话到列表边缘时，侧栏会自动滚动。
- 用 ⌘/Ctrl + 1–9 可切换到侧栏前九个可见会话；长列表可以逐页展开。
- 会话可以关联或解除关联 GitHub PR，也可以把关联的 PR 交给 Auto delivery，并在侧栏查看合并反馈。
- 会话菜单可直接在 Finder 或文件资源管理器中打开工作目录。按住修饰键点击终端里的网址，即可在浏览器中打开。
- 附件可直接在会话侧栏预览，视频支持倍速播放。
- 在空输入框中按上下方向键可找回已发送的消息。新增可自定义的快捷键，用于搜索模型、切换思考强度和打开附件菜单。
- Codex 新增 Ultrafast 速度选项。Antigravity 支持在 Lody 中远程登录。
- Lody Agent 设置可查看、刷新自定义服务端点提供的模型，并为新会话设置默认模型、思考强度和自主程度。Prompt 和 Agent Role 编辑器也已重新设计。
- 长命令可以交给 Lody 在后台运行。命令退出后，会话会收到结果并继续。拥有会话编辑权限的成员也能在共享机器上管理自动化。
- 桌面端「设置 → 数据」和 CLI 都支持导出、导入工作区。导入其他工作区的内容时，目标工作区成员可只读查看。

### 🐛 修复与改进

- 修复会话引用操作的显示层级，打开弹窗时不再遮挡弹窗。

- 修复 Windows 和 Linux 正式版安装包的生产环境打包参数。

- 归档页默认将会话放在同一个列表中，查找旧会话时不用逐组展开。
- 消息输入框会跟随界面字号。编辑已经发送的消息时，也可以使用 Prompt 快捷短语。
- 点击已发送消息中的会话提及，可直接打开对应会话。当前工作区的 Markdown 会话链接也会在 Lody 内打开。
- 窄窗口中的输入子菜单会留在屏幕内。项目未关联 GitHub 仓库时，提及菜单会隐藏 Issue 和 PR 分类。
- 修复后台窗口把会话意外标成已读的问题。在 Focus 中调整顺序时，刚从稍后列表返回的未读会话也能保留未读状态。
- 多个窗口同时打开时，在其中一个窗口折叠侧栏分组或更改筛选条件，其他窗口会保留各自的视图。
- 停止发送后，队列里的消息会保留为草稿，可以再编辑并手动发送。重启前被打断的会话可用一次「继续」恢复。
- 修复意外退出时刚创建的会话可能丢失，以及打开工作区变更列表时文件显示不全的问题。
- 切换会话再回来时，之前打开的预览仍会保留。修复大型本地 HTML 文件无法预览，以及项目资源和重定向在预览中加载失败的问题。
- 远程文件搜索在文件所在机器上执行，GitHub 分支列表改为按页加载，减少浏览大型项目时的等待。
- 修复 Antigravity 的命令和技能菜单显示为空，以及后台任务结束后会话仍显示工作中的问题。
- 修复部分 Magpie 模型使用厂商自定义思考强度或较长输入类型列表时，整个模型目录无法加载的问题。
- 配置代理后，智能体连接、Claude 用量查询、桌面端连接和自动化任务会使用该代理。桌面登录也可以转到浏览器继续完成。
- 修复独立安装后终端找不到 lody 命令的问题。显式重新安装时，会启用刚安装的后台服务版本。
- 缩短桌面首屏加载时间，减少 CLI 后台进程内存占用，并改善长会话重新打开时的历史消息加载。
