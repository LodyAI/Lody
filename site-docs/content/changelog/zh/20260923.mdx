版本 0.100.0

### ✨ 新功能

- 新增对 Opus 5.5、GPT-6-Sol 和 GPT-6-Luna 的支持。
- 新增 Dimcode 内置 Agent，可直接在 Lody 中完成配置并创建会话。

### 🐛 修复与改进

- 升级内置 Claude Code、Codex、Grok、Kimi 和 Pi，提升 Agent 运行与会话启动的可靠性。
- 改进桌面窗口预热与内容加载，减少打开会话时出现空白、错误页面或短暂加载状态的问题。
- 优化长会话的后台加载，避免内容闪烁、消息错位或选中文本丢失。
- 改进侧边栏筛选器的布局，并确保任务列表为空时仍可切换筛选范围。
- 修复从会话打开其他本地工作树文件时可能定位到错误文件的问题。
- 修复 Windows 上 DeepSeek Harness 子进程可能反复弹出控制台窗口的问题。
- Machine Flock 远程同步失败后会自动重试，并提供清晰的失败状态。
- 修复 Code Collab 保存文本后可能丢失文件执行权限或私有权限的问题。
- 优化分享入口和会话标题栏的界面细节。

### 🙏 感谢外部贡献者

- 感谢 ladydd 修复 Code Collab 保存文件时的 POSIX 权限保留问题。
