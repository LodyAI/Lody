版本 0.109.0

### ✨ 新功能

- 一个项目可以组合多个仓库和本地文件夹。创建向导帮助你选择机器和项目成员，也可以直接在对话的项目选择器中创建或编辑项目。
- 在输入框中预约发送完整消息，保留附件。定时消息会显示在队列中，无需离开对话即可编辑。
- 定时任务页面将任务与一次性消息分开展示，提供更清晰的状态、筛选、运行历史和已完成消息清理操作。
- 选中对话文字即可在输入框中引用，支持将多段摘录与问题穿插编写，并在发送前预览或移除引用。需要执行机器支持消息引用。
- 在全窗口编辑器中为图片添加文字、画笔、矩形和箭头，也可以为文字或矩形标记附上备注，再将标注后的图片与备注一起发送给 Agent。
- 在已配置 Android SDK 和 AVD 的机器上，可以从对话中预览并操作 Android 模拟器，支持调整预览画质、旋转设备、粘贴文字和截图。
- 将 iOS 与 Android 预览标签拖到一起，即可并排查看两台设备；支持调整两侧宽度，也可以拖出标签恢复独立预览。
- 在 MCP 设置中登录支持授权的 HTTP MCP 服务。每个账号在各自机器上单独授权，新的登录凭据保存在本机系统凭据库中，不写入工作区共享配置。
- ACP Agent 设置会在开始认证前显示 Agent 提供的登录方式。
- 在云工作区中，可以通过 `lody agent-config import-magpie` 在无桌面界面的服务器上导入 Magpie 服务商配置。
- 同一轮对话中同时存在子 Agent 和后台命令时，任务面板会将它们分别放入「子 Agent」与「任务」标签页。

### 🐛 修复与改进

- 修复桌面端启动时登录检查缓慢，导致被误判为退出登录、需要重新打开浏览器登录的问题。
- Inbox 数据库启动失败时，普通对话仍可继续使用。临时故障会自动重试，受影响的操作会明确提示暂不可用。
- 修复同步更新到达顺序变化时，排队消息可能一直无法发送的问题。
- Agent 主回复结束后，仍在运行的后台任务会继续显示。
- Kimi 提出的计划现在可以在批准前查看。
- 修复 Agent 已报告退出 Plan 模式后，加载较早消息时对话又恢复为 Plan 模式的问题。
- 改善 DeepSeek 历史导入：保留已存储的标题与活动时间，从当前及旧版存储中读取图片；图片缺失或损坏时显示占位提示，让其余历史仍可加载。
- 改善 iOS 对话滚动，减少加载较早消息时惯性滚动被打断的情况。
- 将托管的 Claude Code 更新至 2.1.316。
