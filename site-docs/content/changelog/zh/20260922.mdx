版本 0.98.0

### ✨ 新功能

- 提升从移动端分享内容并创建 Agent 任务的可靠性；即使目标机器暂时离线，任务也可以在恢复连接后继续送达。
- DeepSeek Harness 的提问现在接入 Lody 的 Ask Question 界面，并支持为答案添加独立备注；同时完善 Kimi Plan 的交互卡片。
- 优化侧边栏项目组织：显示项目上下文、改进本地项目排序，并提供“最近更新项目”的展示设置。
- 新增会话实际模型信息，帮助更准确地识别每个任务使用的模型。
- 改进桌面多窗口、归档列表和大型项目文件搜索性能，减少开窗、滚动和搜索时的卡顿。
- 长会话中跨屏选择文本时，不再因列表虚拟化而丢失选区。

### 🐛 修复与改进

- 修复部分安装中 Devframe 与 Devbar 无法启动的问题。
- 修复 Windows 上启动 DeepSeek Harness 时可能超过命令行长度限制的问题。
- 修复 Astro 托管预览可能返回纯文本 403，以及预览导航异常的问题。
- 修复消息、权限请求和上下文压缩状态可能乱序或残留的问题。
- 改进通知跳转、未读状态、最后一个标签页关闭、Zen 模式、Mermaid、数学公式、弹窗层级和输入焦点等细节。
- 修复 Kimi Plan 缺失文件错误、模型与项目搜索焦点、用量详情缓存，以及已关闭会话的未读输出处理。
