版本 0.102.0

### ✨ 新功能

- 会话中的 PDF 文件支持直接预览，可翻页、缩放和搜索文字。
- 设置页中新增提示词快捷指令。
- 消息中的会话链接显示为可点击的会话卡片，方便跳转到相关对话。

### 🐛 修复与改进

- 改善消息发送响应，减少等待同步造成的延迟；图片消息发送时保留原位预览，减少界面跳动。
- 桌面端和移动端启动时遵循已保存的主题，减少深浅色切换闪烁。
- 从默认入口打开应用时进入聊天首页，方便直接开始新对话。
- 输入框中的提及和命令菜单跟随光标位置，改善换行、滚动和移动端键盘弹出时的显示。
- 优化斜杠命令搜索，统一排列快捷指令与 Agent 命令，让名称匹配的结果更容易找到。
- 改善 Agent Role 菜单、侧边栏与下拉选项的对齐，修复文字裁切和按钮遮挡。
- 修复对话 Markdown 对齐、行内数学公式显示，以及部分工具调用命令重复显示的问题。
- 修复 Linux 无可用系统钥匙串时无法登录新建 Codex 账号配置的问题。
- 本地项目保留原有 Git 和 GitHub 登录配置，改善 Agent Roles 跨机器任务派发。
