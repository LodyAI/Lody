版本 0.94.0

### ✨ 新功能

- 支持通过只读链接分享会话，并提供快速加载的静态阅读页
- 支持通过窗口化历史加载和压缩传输阅读更长的分享会话
- 新增云端提示词快捷方式，更快访问常用指令

### 🐛 修复与改进

- 改进分享会话的导航体验，明确当前选中项、侧边栏控制和已加载历史的复用
- 减少分享上传过程中的重复工作，提升静态分享可靠性
- 改进 Streams Token 刷新，并按工作区隔离缓存
- 恢复编辑器底部的间距
- 简化分享对话框文案，让分享阅读页更加紧凑
- 感谢外部贡献者 Wibus Wu 带来的编辑器间距改进
