版本 0.94.0

### ✨ 新功能

- 新增会话分享，可将会话及已选择的子会话发布为无需登录即可查看的只读链接。
- 完善分享管理：支持查看分享状态、浏览分享中的子会话、调整分享页面侧栏，并从分享记录返回来源会话。
- 新增 Prompt Shortcuts，可创建、编辑、删除和共享提示模板，并通过 `/` 菜单、变量和上下文范围快速调用。
- 新增 Bub 作为内置 ACP provider。
- 长对话支持按窗口读取和恢复，减少打开大型会话时的等待。
- CLI 新增从终端重置桌面应用本地缓存的功能。
- 支持通过系统原生分享功能发送会话中的文件。

### 🐛 修复与改进

- 改进分享页面的加载、压缩历史读取、导航和错误恢复，单个请求失败时不会导致整个会话崩溃。
- 修复分享页面的登录提示、会话树连接线、标题层级和侧栏布局问题。
- 改进会话恢复、历史同步、压缩中断恢复和归档会话处理。
- 修复 Windows 会话路径、归档 worktree、共享机器项目导航和桌面登录账号确认问题。
- 改进 Prompt 输入体验，包括工作区草稿隔离、排队消息编辑焦点、终端标签状态和超大文本粘贴提示。
- 改进 ACP 兼容性、Grok 默认模式、DeepSeek Harness 和内置 Agent 用量统计。
- 移动端显示运行中的 Agent 时长，并改进文字大小调节和多图片附件布局。
- 修复礼物订阅到期后的结算恢复问题。
- 修复未提供可选标注信息时预览页面无法加载的问题。
- 改进菜单在小窗口和安全区域内的显示，修复 macOS 归档入口遮挡问题。
- 感谢外部贡献者 @gu18168、@EYHN、@UniversePeak、@Astro-Han、@lawvs、@VeraPyuyi 和 @liuxiaocs7 对 ACP、会话恢复、任务控制、输入体验、运行环境兼容性及桌面端界面的改进。
