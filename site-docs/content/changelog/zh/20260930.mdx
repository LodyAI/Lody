版本 0.103.0

### ✨ 新功能

- 支持 Codex GPT-6.1-Sol 模型。
- 会话内支持预览 Word（DOCX）、Excel（XLSX）和 PowerPoint（PPTX）文档。
- 新增 CSV／TSV 表格预览、单元格搜索和缩放，并保留源码编辑。
- PDF 预览新增缩略图导航、旋转和多种缩放方式，改善文档内搜索。

### 🐛 修复与改进

- 修复切换模型或应用角色后，推理强度与 Fast 选项显示或生效不正确的问题。
- 修复切换会话标签时可能出现的消息区域崩溃，改善阅读位置恢复。
- 改善输入框 @ 菜单定位，使其跟随光标并适应可用空间。
- 改善 GitHub 授权失效提示，修复部分 Git 提交作者身份不正确的问题。
- 更新内置 Codex，补充新模型的用量费用估算。
- 修复官网部分页面导航与链接跳转问题。

感谢所有为 Lody 提供反馈与贡献的社区朋友。
