版本 0.111.0

### ✨ 新功能

- 会话自动继续支持外部条件检查：Agent 可检查网址或运行本地命令，等待条件满足后继续任务。
- Agent 可跨会话管理自动继续任务，为目标会话注册、检查或取消等待条件。
- Mermaid 图表直接显示在对话正文中。
- 同机附件优先在本地使用：Agent 可直接读取原始文件，图片发送不再要求先等待远程上传。
- 本地图片可在原电脑直接预览；在其他设备查看本地附件时，可从原电脑下载，并显示原电脑离线或文件不可用的原因。
- Agent 可获取自己所在的会话、Role、父会话和发起会话信息，便于准确定位协作关系。
- Claude、Kimi、Pi 和 DeepSeek Harness 适配器支持标准 ACP 会话系统提示词，兼容追加和覆盖指令。

### 🐛 修复与改进

- Role 固定的模型或权限模式被 Provider 移除时，显示不可用原因，避免选中后才执行失败。
- Role 摘要补充能力标签，选择协作对象时更容易辨认其支持的能力。
- 恢复本地 Provider 登录，以及自定义服务地址的密钥输入。
- 完善 Lody Agent 的配置流程：登录方式选择能够正确传递到目标机器，自定义服务地址可在配置完成前设置，取消登录后及时结束等待。
- 模型列表意外为空时重新探测，保留当前已选模型，并明确提示没有可用模型，避免错误显示验证通过。
- 修复机器在线状态尚未更新时，新标签页中的已知 Agent 无法选择的问题。
- 修复 Claude advisor 工具结果未正确结束的问题。
- 内置 Codex 更新至 0.166.0，Claude Code 更新至 2.1.321。
- 内置 Devin 更新至 3000.12.28；DeepSeek Harness 更新至 0.2.2-rc.1。
- DeepSeek 思考过程默认折叠，长回复更便于阅读。
- Agent 后台任务仍在运行时，保持正确的会话活动状态，减少过早显示完成的情况。
- 会话启动失败后保留原有上下文，便于重试。
- Agent 会话结束时，不再关闭用户手动打开的终端。
- 修复旧桌面同步快照覆盖当前状态，以及对话更新过程中状态反复变化的问题。
- 首页将已完成但未阅读的会话明确标为“未读”，并使用专用图标区分草稿 PR。
- 侧栏显示本地会话分支；共享目录会话不再显示误导性的独立分支信息。
- 关联会话中的多个标签支持横向滚动，避免较多标签被挤压。
- 改善桌面退出确认和取消操作，减少等待；修复侧面板和终端关闭后部分资源未及时释放的问题。
