版本 0.105.0

### ✨ 新功能

- 新增视频文件预览支持。
- 全屏图片预览新增触屏长按菜单，可按设备支持情况复制、保存或分享图片。
- CSV、TSV 和 XLSX 预览支持调整列宽、选择并复制单元格或矩形区域；XLSX 还支持调整预览行高。
- 移动端 HTML 文件及聊天附件默认进入预览模式，并可切换查看源码。
- 新增 iOS 主屏幕小组件，可查看会话进度及工作区 Token 用量。
- 记忆导入支持勾选多个身份并批量添加。
- DeepSeek 支持加载和继续原生历史会话，保留已有上下文及模型、权限和预设配置。
- DeepSeek 支持在执行过程中追加指令，以及设置、暂停和恢复 Goal 目标任务。
- DeepSeek 新增子 Agent 查询与取消能力，并支持展示后台任务状态、重试活动和当前上下文用量；取消能力取决于执行方式。
- Pi 的子 Agent 工具支持指定可用模型，方便为不同子任务选择模型。
- 升级 Claude Code，支持 Haiku 5.5；升级 Codex，支持更大的上下文长度。
- Codex 支持在 `/plan` 命令后直接附带任务描述，自动标题支持使用 Lody 中配置的标题模型及参数。
- CLI 和 MCP 创建、继续会话时支持携带文件与图片附件，包括向远端机器上的会话发送附件。
- CLI 创建会话支持 `--agent-role <名称或 ID>`，直接使用工作区角色配置的机器、Agent、模型及提示词。
- Cloud CLI 新增 `migrate --from-oss`，可将 OSS 版的 Loro 会话记录及历史附件导入已有云端工作区。
- 新建独立工作树后，Agent 会在首次任务中收到按任务内容命名分支的提示，方便识别并行任务。
- 关联对话面板新增“停止协作”和恢复操作，可停止主会话及其子会话，防止晚到的 Agent 结果再次触发执行。停止后需手动恢复协作；离线机器将在同步后生效。
- 连续创建的子对话合并为紧凑任务面板，支持展开、收起和内部滚动，避免大量卡片占满会话。
- 消息队列支持折叠，收起后保留编辑草稿，并继续显示待准备和失败消息数量。
- 输入框新增执行机器详情入口：桌面显示机器名称，悬停或点击可查看所属成员和连接状态；手机通过图标按钮打开详情卡。
- 远程目录选择器支持新建文件夹，桌面和移动端均可直接创建并进入新目录，再添加为项目；需要目标机器更新到支持此功能的 CLI。
- 侧边栏长会话标题支持悬停或键盘聚焦时自动滚动，也可通过拖动、触控板或滚轮查看完整标题，并遵循系统“减少动态效果”设置。
- 支持主动查询额度的 Provider，可在切换输入框配置、打开额度面板或返回应用时按需刷新订阅额度。
- 账单新增详情查看，展示费用原因、席位变化、明细、待付余额及付款入口。
- 新增本地 Magpie 配置导入接收入口，完整导入流程仍待 Magpie 端配套支持。

### 🐛 修复与改进

- 修复 Codex 新建或恢复会话时，未及时应用所选模型的问题。
- 模型选择被 Agent 拒绝时，界面会显示警告，避免误以为切换成功。
- 修复部分 ACP Agent 应用模型配置的顺序，避免角色设置的推理强度等选项在切换模型后被重置。
- 修复继承模型配置时，推理强度、Fast 等选项可能按错误模型校验的问题。
- 保存 Agent Role 时清理已失效的配置选项，保留有效选择，减少反复保存后仍出现兼容性警告的问题。
- 修复消息在继续执行、追加指令或恢复过程中，实际发送给 Agent 的提示词与提交时内容不一致的问题，包括 Agent Role 提示词。
- 修复 Agent Role 引用菜单在详情变化时丢失选择或定位异常的问题，并修正 Agent 配置对话框的焦点边框。
- 修复移动端 Dimcode 配置选项相互干扰、权限选择在松手后无法保留的问题。
- Dimcode 改为使用机器上已安装的命令及现有配置；未安装时提供可复制的安装命令。
- 修复 Amp 适配器长期复用旧缓存、实际版本与目录显示不一致的问题，改为使用对应版本的二进制。
- 修复部分 Node.js 版本下，安装以 ZIP 分发的 Agent 时解压卡住、安装无法完成的问题。
- 修复 Pi 命令输出的换行被合并成一段的问题，已有会话中的输出也能正确显示。
- Pi 扩展尚未完成扫描时，优先使用已保存的包名显示；扩展加载失败也会明确报告。
- Codex 导入历史时保留附件，并改善会话被其他客户端占用、服务异常、启动失败及工作目录相关错误的提示。
- 修复 Codex 服务重启后无法恢复空会话，以及历史会话标题选择不准确的问题。
- Codex 在打开会话前保存实际执行目录的信任状态，改善项目级技能和 MCP 配置的发现；保留用户明确设置的不信任状态。
- Claude 后台 Bash 任务可显示关联的实际命令，支持高亮和复制，并与任务说明分开展示。
- 改善 Claude 历史中后台任务停止记录的展示，减少其被误显示为用户提示词的情况。
- 修复 Agent 完成消息在断线恢复或延迟重试后被重复处理、触发重复执行的问题。
- 多 Agent 返回的任务结果改为合批处理，忙碌中的会话会等当前轮次结束后再接收，减少逐条结果反复触发续跑。
- 将 Agent 连续委派链上限调整为 16 层，并优化协作指令，减少无意义的确认回复和重复结果回传。
- 修复连续编辑排队消息时，上一条保存确认清空下一条草稿的问题。
- 切换待回答问题时保留已选答案、自定义输入和备注；提交失败会显示提示，并保留内容供重试。
- 修复中文输入法确认候选词时，意外提前提交自定义答案的问题。
- 修复 Codex 等 Agent 的单题表单只显示“Input requested”，而未显示完整问题的问题。
- 修复聊天失败详情重复显示的问题。
- 优化长会话中的流式输出写入，减少大量工具调用导致的 CLI 卡顿，以及其他设备长时间收不到新消息的问题。
- 修复包含超长命令、内嵌图片等内容时，对话界面可能长时间卡住的问题。
- 减少会话历史中未使用的工具图片、内嵌资源字节和重复数据，并限制命令摘要与工具标题长度，降低存储与同步负担；保留普通附件、可读输出、代码差异和审批内容。权限确认界面会明确提示命令内容已被截断。
- 优化打开引用菜单时的页面渲染，减少输入框交互卡顿。
- 粘贴文本达到 50,000 字符时自动转为文本附件，完整保留原始内容。
- 修复移动端粘贴长文本编辑面板无法充分展示内容的问题，支持在面板内滚动查看全文，并统一与输入框的字体样式。
- 修复触屏向上浏览对话时，延迟到达的滚动事件打断惯性滚动或重新拉回底部的问题。
- 修复移动端快速滚动到底部时反复抖动、回弹，以及输入框高度变化或编辑草稿时意外恢复跟随最新消息的问题。
- 修复鼠标位于 Mermaid 图表预览上方时无法正常滚动对话的问题，并减少连续布局更新引发的页面异常。
- 发送新消息后保留部分上文，方便衔接阅读上一条回复。
- 修复“滚动到最新消息”按钮在鼠标悬停或键盘聚焦时箭头不显示的问题。
- 优化移动端对话排版，统一正文、执行步骤和操作栏的对齐及轮次间距。旧消息的操作按钮改为点按显示，最新助手回复保留常用操作。
- 调整粘贴文本标签、GitHub Issue 和 PR 引用标签与正文的对齐，改善任务回复卡片间距，并统一回复耗时与底部文字的字体。
- 修复中文、日文和韩文 Markdown 中，紧邻标点的加粗或斜体无法正确渲染的问题。
- 修复长用户消息收起时从文字中间裁切的问题，按完整行截断并渐隐提示剩余内容。
- 桌面输入框底部显示完整模型名称，减少模型识别歧义。
- 修复窄窗口下会话信息栏的按钮和变更统计溢出问题，空间不足时自动收缩文字与机器名称。
- 移动端 HTML、Markdown 和纯文本附件改用接近全屏的底部面板，提供更大的阅读区域，并改善预览空状态提示。
- 修复移动端抽屉内弹窗无法正常点击、输入或滚动，以及触摸穿透到底层界面的问题。
- 禁用 iOS 消息链接的长按系统预览，避免返回应用后点击其他位置仍反复打开同一链接；保留轻点打开和文本选择。
- 增大触屏设备上的消息队列操作按钮，减少误触。
- 修复移动端底部导航收起、展开时图标被拉伸的问题，并改善向上滚动时的导航显示及焦点衔接。
- 统一会话链接的打开、粘贴和导出行为，更准确地定位工作区及目标会话，并兼容旧链接。
- 修复粘贴子会话链接时，引用目标错误地变成父会话的问题；改善链接无法打开时的提示，区分会话已归档、工作区不可访问等情况。
- 本机会话尚无可用工作目录时，也能预览绝对路径及 `~/` 路径指向的文件；修复 `~/` 路径可预览但无法打开或在文件管理器中显示的问题。
- 修复带行号的文件链接首次点击时停在文件顶部的问题，并恢复目标行范围高亮。
- 恢复定时任务页面在侧边栏隐藏时的展开按钮，并修正 macOS 窗口控制按钮附近的布局。
- 修复手机定时任务列表被顶部状态栏遮挡的问题；保存或关闭任务后，返回带工作区切换、搜索、设置和底部导航的首页定时任务页。
- 登录状态恢复连续失败后停止无限加载，提供重试和重新登录入口，并保留当前页面。
- 登录、切换或打开工作区等待超过 30 秒后，提供恢复页面，可重新加载、清理缓存和复制诊断信息；连接长时间卡住时，也可从提示横幅进入。
- iOS 启动故障恢复支持原生完整本地数据重置，可在应用无法正常加载时清理本地数据并重新进入登录流程。
- 修复桌面端在部分代理或证书环境下无法完成登录的问题，并为证书验证失败提供更明确的排查提示。
- 云端查询遇到临时服务端错误时自动进行有限重试，减少偶发错误直接打断整个页面的情况。
- CLI 读取机器信息时，临时同步失败可回退到本地已有数据；修复机器配置尚未同步完整时，将暂时不可用的项目、Agent 或模型误判为无效配置的问题。
- 改善切换工作区、账号及连接失败后的清理，避免旧连接和迟到请求干扰新连接，并补充同步失败的错误详情。
- 改善同步凭据刷新、终端环境查询的共享与取消处理，避免单个请求超时或取消影响其他请求。
- 修复多个 CLI 或 MCP 命令同时访问同一工作区时，因重复初始化而报错的问题，以及旧会话准备尚未结束时复用工作区干扰后续会话的问题。
- 修复 stdio MCP 服务连接后过早释放运行环境，导致后续工具调用失败的问题。
- 改善 Agent 退出、会话终止和启动失败时的进程清理，减少残留进程；取消任务仍在收尾时继续显示活动状态。
- 恢复桌面和移动客户端中的 GitHub 个人身份授权入口，可跳转浏览器完成授权。
- 即使工作区尚未关联仓库，也可只读查看公开 GitHub PR 的详情、审查和代码变更。
- 限制 GitHub PR 关联失败后的重复重试，补充权限修复提示，同时继续更新 GitHub PR 状态。
- 修复会话准备与重新启动过程中，GitHub 凭据状态残留导致后续消息无法执行的问题。
- 修复 GitHub 只读凭据在 HTTPS 克隆及递归子模块拉取时被错误拒绝的问题，以及部分非交互 PR 创建流程丢失 GitHub App 来源标识的问题。
- 为 Git 身份查询和凭据助手探测增加超时限制；减少重复环境探测，并重试临时进程启动失败，避免 Agent 长时间停留在初始化阶段。
- 修复读取 Git 提交身份时遗漏 XDG 全局配置的问题，以及文件索引回退时另一项 Git 查询尚未结束的问题。
- 改善本地项目和工作树的 Git 错误处理，避免将启动失败、超时或权限错误误判为仓库或分支不存在。
- 改善并发操作的文件锁排队与异常退出后的清理，减少遗留锁造成的阻塞；Git 操作或清理失败时保留错误，避免错误触发强制删除工作目录。
- 完善工作树分支命名前的检查，避免向已有分支或不适合改名的工作区发送命名提示。
- 重新整理 Provider 设置中的额度展示，明确区分剩余额度与重置预测，并完整显示各额度窗口。
- Codex“重置预测”支持一键打开；刷新和删除操作收纳到独立管理菜单，避免悬停时遮挡预测入口。
- 本地 Agent 短暂不可用时保持侧边栏机器分组顺序，减少设备列表来回跳动。
- 更新个人头像后同步刷新工作区成员信息，避免成员列表继续显示旧头像。
- 移动端运行配置和 Agent Role 设置更准确地区分“模式”与“权限”；文件夹共享开关统一使用“与团队共享项目”等明确的动作标签。
- 修复 Windows 打开弹窗后，右上角窗口控制按钮背景出现突兀色块的问题。
- 精简桌面安装包中的重复运行时文件，压缩桌面界面资源，并减少 Linux 上重复检查 Claude 运行环境造成的后台开销。
- 改善新手引导对话在调整界面字号后的间距，并修复归档列表出现“0 分钟前”等不合理相对时间的问题。
- 修复文档标题锚点，并避免页面出现重复的一级标题。
