版本 0.108.1

### ✨ 新功能

- 全新对话首页，支持切换「现在」与「这一周」：集中查看待处理、运行中和刚完成的会话，以及近期工作概览和 Agent 套餐用量。
- 项目支持设置默认 MCP，新建对话自动采用项目配置，也可在发送前单独调整。
- All Changes 新增「仅未提交修改」视图，可与分支累计修改切换，并显示比较基准。
- 新增工作区推荐奖励：分享推荐链接、查看奖励余额与明细，并将符合条件的余额用于订阅抵扣；支持限时推荐活动。
- Agent 完成通知新增回复摘录，无需打开会话即可预览结果。
- 新增 OpenCode V2，并更新多款 ACP Agent 版本。
- 定时任务的提示词编辑框可随内容扩展至约半个窗口，方便编辑长指令。
- 归档会话时，若仍有活跃的子会话，会提示其数量与运行状态，可选择一并归档或仅归档当前会话。
- 更新浅色主题、侧栏和登录页设计，统一邀请、设备授权等页面的布局，改善启动与页面切换体验，并标记本机上次成功使用的登录方式。

### 🐛 修复与改进

- 优化会话与标签页切换，减少长对话、持续输出和历史加载造成的卡顿。
- 优化包含大量子 Agent 工具输出的会话加载，任务详情按需读取，减少不必要的处理开销。
- 优化历史消息同步，减少重复传输与存储，修复部分场景下消息内容重复的问题。
- 修复部分已接收的同步更新在重启后丢失的问题，提高本地数据保存与恢复的可靠性。
- 改善存储异常后的同步恢复，减少重复下载和异常流量，并修复部分本地数据库连接无法恢复的问题。
- 改善断网后的连接恢复，修复会话停止同步、需要手动刷新才能更新的问题。
- 修复桌面端网络异常时会话状态丢失的问题。
- 桌面端因磁盘空间不足而写入失败时，显示明确提示并阻止继续操作，引导清理空间后重启或退出。
- 修复 CLI 异常退出时反复报错、日志大量增长且无法正常退出的问题。
- 修复 Windows 本地 Agent 因权限问题一直停留在「连接中」的情况，并提供恢复提示。
- 修复通过 Lody MCP 创建会话时，因响应缓慢、重试而生成重复会话的问题。
- 修复 Agent 已回复完成，却因文件变更刷新而持续显示收尾状态、停止操作迟迟不结束的问题。
- 修复历史消息尚未完全加载时，Agent 的提问卡片可能不显示的问题；等待回答时不再持续累加工作时长。
- 拒绝执行 Claude 的计划后，仍可查看原计划内容。
- 会话因异常执行状态而无法继续接收输入时，提供更明确的错误提示与 CLI 人工恢复路径，并保留排队中的输入。
- 修复自定义 ACP Agent 的历史同步、导入和冲突处理被拒绝的问题。
- PR 合并或关闭后不再自动归档会话，避免意外中断后续工作。
- 会话标题根据用户实际输入生成，避免混入 Agent 配置或角色指令；派生会话的标题不再自动添加前缀。
- 通过 CLI 或 Lody MCP 使用 Agent Role 创建会话时，角色提示词不再混入用户消息和会话标题。
- DSH 的文字与工具调用独立展示，折叠工具时不再连带隐藏文字；改善思考文字排版，并移除过时的委派模型警告。
- Markdown 文件预览中的会话链接现在可以正确打开。
- 修复嵌套 Git worktree 中相对文件链接的打开位置；存在多个匹配文件时可选择目标。
- 优化代码高亮与滚动条体验，改善首页在较矮窗口中的布局、折叠操作和切换动画。
- 优化会话分享入口，集中展示访问范围、链接发布与管理操作。
- 改善成员头像、Skill 详情和用量视图，修复头像闪烁、菜单焦点异常及 Windows 定时任务按钮被遮挡等问题。
- 收窄工作区边框，改善 macOS 标题栏与窗口按钮的对齐。
- 修复 Web 启动异常及 iOS 16.4 上代码差异视图的主题颜色问题。
- 更新 DimCode 图标，并隐藏没有实际内容的操作成功回执。
