版本 0.111.1

### ✨ 新功能

- **单会话只读共享**：支持将指定会话分享给团队或个别成员查看，无需开放整台电脑的访问权限。
- **定时任务归属与筛选**：任务列表显示所有者，并支持按“我的”“其他人的”和“全部”筛选，方便查找团队任务。

### 🐛 修复与改进

- 修复会话中部分消息处理失败后，后续消息可能无法正常显示的问题。
- 修复桌面端部分本地图片无法正常加载的问题。
