版本 0.116.0

### ✨ 新功能

- 可在原生客户端编辑计划提案，并在 Web 版查看系统通知。
- 可将 Today 提及拖到会话中；生成式界面支持更多受限的 SVG 图表。

### 🛠️ 改进

- 输入框附件改用更清晰紧凑的卡片，显示上传进度，并提供重试和移除操作。
- 长期使用的工作区会自动回收 SQLite 未使用空间。
- 支持通过 WebSocket 追加内容，改善 Streams 实时更新。

### 🐛 问题修复

- 修复打包后的 macOS 版本无法启动内置 JavaScript ACP Agent 的问题。
- 修复附件回填、分享请求、侧边栏和 Markdown 任务列表的边缘问题。
