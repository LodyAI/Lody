バージョン 0.110.0

### ✨ 新機能

- 画像アノテーション: 画像プレビュー上で描画、テキストの追加、メモの記入を行い、注釈付きの画像を添付ファイルとしてエージェントに送信できるようになりました。
- 会話の自動継続: 指定した条件を満たしたときにタスクを再開できるようになりました。会話ごとに、クォータ回復後の再開、PR マージ後のアーカイブ、アイドル時のコンテキスト圧縮を設定できます。
- Android エミュレータープレビュー: タッチ入力、テキスト貼り付け、画面回転、スクリーンショット、ライト/ダークモード切り替え、画質オプションを備えた新しいプレビューおよび操作パネルを追加しました。
- エージェントのサインイン方法表示: サインイン前にエージェントが対応しているサインイン方法を確認できるようになりました。
- Pi のアップデート: 同梱の Pi を 1.4.0 にアップグレードし、Streamable HTTP MCP に対応しました。
- iOS と Android の並列プレビュー: 一方のデバイスプレビュータブをもう一方にドラッグすると、両方の画面を同時に並べて表示できます。境界線をドラッグして幅を調整でき、ダブルクリックで初期の分割比率に戻ります。
- 会話テキストの引用: 選択したメッセージの一部をコンポーザーに追加し、元の文章をコンテキストとして追加の質問を行えるようになりました。
- スタック PR: PR パネルに GitHub に記録されているスタック順、各 PR のステータス、および現在の PR のスタック内での位置が表示されるようになりました。関連付けられた PR はサイドバーにも表示されます。
- より柔軟なスケジュールタスク: プロンプト内でメンションが使えるようになり、繰り返し間隔を任意の分数または時間数で設定できるようになりました。
- アーカイブ済み会話の直接復元: コンポーザーに新しく追加された復元ボタンから、入力中の下書きを保持したまま会話を元に戻せるようになりました。
- マシン横断のエージェントステアリング: 別のマシンで実行中の会話に追加の指示を送信できるようになりました。ライブステアリングが利用できない場合、指示はキューに追加されます。
- Claude が、Anthropic 互換ゲートウェイから提供されるモデルを会話ごとに検出できるようになりました。
- エージェントのキュー管理: エージェントが対象会話の待機中メッセージを確認し、自身が送信してキューに入っている指示を取り消したり差し替えたりできるようになりました。
- より充実した連携ステータス: エージェントが会話のアクティブなツール、最終出力時刻、キュー長、さらにマシンのディスク情報や残りのクォータを照会できるようになりました。
- 帰属情報付きメッセージ参照: エージェントが指示を転送する際、記録されている作成者情報を含めて元のメッセージを参照できるようになりました。
- デバイスペアリングの標準提供: アカウント単位のデバイスペアリングで開発者モードやテスト用フラグが不要になりました。
- 会話の一括アーカイブ: エージェントが 1 回の MCP 呼び出しで複数の会話をアーカイブできるようになりました。
- ホームページに 2 つのクォータ枠を表示: 短期クォータと週間クォータの両方について、使用率とリセット時刻を確認できるようになりました。
- 独立した会話グループ名: サイドバーの会話グループと各タブの名前を、お互いに影響を与えることなく個別に変更できるようになりました。
- 連携失敗時の理由を明確化: MCP が具体的な失敗理由やクォータリセット時刻などの詳細を返すようになり、リトライに成功すると前回の失敗状態がクリアされるようになりました。

### 🐛 修正と改善

- Claude のクォータ上限到達時のプロンプトで、会話の自動再開を有効にできるようになりました。Lody が定期的に確認し、クォータが回復するかリセット時刻に達すると処理を再開します。
- スケジュールメッセージの全文が表示されるようになり、現在の会話内から編集できるほか、送信時刻も閲覧者のローカルタイムゾーンで表示されるようになりました。
- 会話が委任タスクの完了を待っている間やメッセージ受信ボックスの起動に失敗した際に、スケジュールメッセージの配信が詰まってしまう問題を修正しました。
- 短時間の接続障害後のバックグラウンドサービス、メッセージキュー、MCP 一覧の復旧処理を改善し、会話が停止したままになるケースを減らしました。
- モデルや推論レベルなどの会話設定が、以前の入力や下書きによって上書きされてしまう問題を修正しました。
- Pi の会話フォークとスラッシュコマンドの読み込みを改善し、コマンド一覧が会話間で混ざるのを防ぎました。
- DeepSeek 履歴の画像インポート、一覧詳細、および起動時エラー表示を修正しました。
- 入力機能が宣言されていない Magpie モデルとの互換性を追加しました。
- iOS の会話画面でのスクロール慣性、履歴ページのボタンタップ反応、サイドバーのサイズ変更、デスクトップページの配置を改善しました。
- デフォルトフォントの選択を改善し、利用可能な場合は SF Pro Display を優先するようにしました。
- サブスクリプション情報の読み込み失敗によってワークスペース全体が利用できなくなる問題を修正し、ホーム画面ウィジェットのキャッシュ復旧を改善しました。
- 同梱の Claude Code を 2.1.316 にアップグレードしました。
- 以前の会話設定およびメッセージ送信の挙動を復元し、古いバックグラウンドサービスでのメッセージ配信失敗を修正しました（会話設定が以前の入力や下書きで上書きされなくなったという先の記載は取り下げます）。
- 自動継続のコントロールに対象マシンの実際の対応状況が反映されるようになり、古いバックグラウンドサービスで利用できない操作が表示されないようになりました。
- ツールバーのスペースを確保するため、Android プレビューの画質オプションを「More」メニュー内に移動しました。
- 認証の準備が完了する前に組織情報を読み込むことで発生していたエラーを修正しました。
- マルチエージェント連携を改善しました。レスポンスにメッセージの配信ステータスと具体的な失敗理由が含まれるようになり、エージェントメッセージの送信元を識別し、ステアリング後は中間結果だけでなく最終的な返信を待つようになりました。
- MCP が一意に特定できる短い会話 ID を受け付けるようになり、ロール・時刻・方向を指定した履歴の読み取りにも対応したことで、不要なコンテキストを削減しました。
- 長い会話履歴の読み取りや内部 MCP プロセス実行時のメモリ使用量を削減し、ストリーミング出力中の履歴アクセスを改善しました。
- 自動継続キューが速やかに起動しない問題を修正し、接続中・オフライン・利用不可の各状態を明確に表示するようにしました。
- プランモード終了後の状態が履歴の読み込みによって上書きされる問題と、情報バーとサイドバーで PR ステータスが同期しなくなる問題を修正しました。
- 同じ会話の複数タブ間でシミュレーターの紐付けを共有するようになり、デバイスを何度も選び直す手間を減らしました。
- 質問カードのタイトル表示と Markdown レンダリングを改善し、Droid の質問フォームとの互換性を追加しました。
- 注釈付き画像が添付サイズ制限を超える問題、PDF パネルのズームフィット、および WebKit での共有カードレイアウトを修正しました。
- PR 画像をオンデマンドで読み込むようにしました。また、サイドバータブのスクロールバーがドラッグできない問題と、メッセージエディターおよびキュー内のテキスト配置を修正しました。
- クォータが枯渇しておりリセット時刻が判明している場合、スケジュールタスクの実行を延期するようになり、失敗の繰り返しやクォータ回復時の集中実行を防ぐようにしました。
- 会話が完了した際、推論とツールアクティビティのみが折りたたまれ、すべての返信テキストは表示されたままになります。展開したアクティビティは元の順序で表示されます。
- 使用済みのプロンプト提案はメッセージ送信後に非表示になり、古い提案が再表示されるのを防ぎます。
- スマートフォンでキーボードがサインイン入力欄を覆ってしまう問題と、一部ページでステータスバーが戻るボタンに重なる問題を修正しました。
- プロジェクトレコードにパスがない場合にフォルダーブラウザーが開かない問題を修正しました。
- CLI のスナップショットアップロードが無限に待機し続ける可能性がある問題を修正し、初期化失敗後のリトライを改善しました。
- コンポーザー、送信ボタン、および添付ファイルラベルのフォントウェイトを統一しました。
- サイドバーの PR 表示: 元の単一 PR ステータスアイコンに戻しました（サイドバーに関連付けられた PR を表示するという先の記載は取り下げます。スタック PR は引き続き PR パネルで利用できます）。
- ホームページのカードがタスクのステータスに応じて並び替わるようになりました。また、カードの読み込みに失敗した場合でも新規会話のコンポーザーは引き続き利用できます。
- ピン留めした会話のリンク階層が失われる問題と、PR がマージ可能として表示される際にサイドバーアイコンがずれる問題を修正しました。
- エージェントのサインイン方法および認証進捗フィードバックの互換性を改善し、カスタム ACP エージェントで不足していた使用量トラッキングを追加しました。
- 短時間の同期失敗時に、正常なマシンが誤ってオフラインと判定される問題を修正しました。
- 除外ディレクトリやキャッシュをスキップすることで大規模プロジェクトのファイルインデックス作成を最適化し、CLI の停止やファイルが誤って削除済みとマークされる問題を減らしました。
- 比較ベースが記録されていない場合の Git diff 計算を修正し、代わりにリモートのデフォルトブランチを使用するようにしました。
- モバイルでアドレスを手動入力することなく、ブラウザープレビューを直接開けるようになりました。また、iOS シミュレーターフレームの内側の縁におけるテーマの不一致を修正しました。
- 返信の折りたたみ仕様を更新しました。エージェントによって明示的にマークされた進捗状況の更新は他のアクティビティと一緒に折りたたまれ、最終的な返信のみが表示されたままになります（すべての返信テキストが表示されたままになるという先の記載を置き換えます）。
