バージョン 0.84.0

### ✨ 新機能

- 長いセッションでも各ラウンドを素早く閲覧・移動できる、デスクトップ向けの会話ラウンドナビゲーションを追加しました。
- Google Antigravity のサポートを追加し、複数の ACP コーディングエージェントを更新しました。

### 🐛 修正・改善

- Codex 履歴のインポートを改善し、履歴を閲覧している際に古いスレッドが意図せず再開されるのを防ぎました。
- Kimi やその他の ACP エージェントが Windows でコマンドやツールを実行する際のパスと引数の処理を修正しました。
- 幅の狭いウィンドウでの環境設定のレイアウト、初回起動時のステータスインジケーター、および macOS の Dock アイコンを改善しました。
- Web サイトのライトモード表示と、一部ブラウザでの起動失敗を修正しました。
