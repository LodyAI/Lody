### 新機能

- デスクトップおよびモバイル全体の UI と UX を刷新しました。
- 各デバイスや Agent セッションの CPU およびメモリ使用率を確認できるデバイスリソース監視機能を追加しました。
- Codex および Claude Code 向けの steer サポートを追加しました。
- プロジェクト、ブランチ、コード変更、PR、ゴール、スケジュールタスク、プレビューの情報とクイックアクションをまとめたセッション情報バーを追加しました。
- プロフィール画像、ワークスペースロゴ、表示名、およびパスワード管理に対応しました。

<img src="/_docs-assets/20260716-new-ui.png" style={{ maxHeight: '400px' }} />

### 修正と改善

- デバイスのオンライン状態、再接続時の挙動、およびローカル Agent の安定性を改善しました。
- セッションを継続した際に、モデル、権限、または推論の設定が変わってしまうことがある問題を修正しました。
- インポートしたローカルプロジェクトがすぐに表示されない問題を修正しました。
- Codex の機能情報の更新、セッションタイトル、推論内容、および使用状況情報の表示を改善しました。
- Agent の応答、サブエージェントのタスク、編集済みファイル、および使用状況の詳細表示を改善しました。
