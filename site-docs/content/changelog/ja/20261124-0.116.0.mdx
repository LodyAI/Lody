バージョン 0.116.0

### ✨ 新機能

- ネイティブクライアントからスケジュール提案を編集できるようになり、Web アプリではシステム通知を確認できるようになりました。
- Today のメンションを会話にドラッグできるようになりました。また、生成されたインターフェース内で、より多くの安全な SVG 図表をレンダリングできるようになりました。

### 🛠️ 改善

- コンポーザーの添付ファイルが、アップロードの進捗状況・再試行・削除アクションを備えた分かりやすいコンパクトカード表示になりました。
- 長期間利用しているワークスペースで、未使用の SQLite ストレージが自動的に回収されるようになりました。
- WebSocket 追記（append）のサポートにより、Streams のリアルタイム更新が改善されました。

### 🐛 バグ修正

- パッケージ化された macOS ビルドで、組み込みの JavaScript ACP エージェントの起動に失敗する問題を修正しました。
- 添付ファイルのバックフィル、共有リクエスト、サイドバー、および Markdown タスクリストのエッジケースを修正しました。
