バージョン 0.107.2

### 🐛 修正と改善

- GitHub と Lody のメールアドレスが異なる場合に個人の GitHub 認証が失敗する問題を修正し、認証後の設定画面への戻り動作を改善しました。既存のユーザーは、GitHub 設定から一度再認証を行う必要があります。
- Apple の「メールを非公開」機能を使用しているアカウントを含め、異なるメールアドレスのサインインアカウントを連携できるようになりました。
- Claude サブエージェントによる画像読み込みでセッションデータが過度に肥大化し、読み込みの遅延や同期失敗が発生する問題を修正しました。
- 起動時、再接続時、および同期エラー発生後の MCP リソース一覧の復旧処理を改善し、リソースの欠落や同期状態が更新されなくなる問題を軽減しました。
