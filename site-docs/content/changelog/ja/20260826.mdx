バージョン 0.87.0

### ✨ 新機能

- 会話のカスタムフォントサイズを追加し、チャット本文、Markdown、ターミナルを読みやすいサイズに調整できるようになりました。
- HTML 添付ファイルをライブプレビューで直接開けるようになりました。Agent が報告したリモートポートに接続する前には、Lody が確認を求めます。

### 🐛 修正・改善

- メンションしたロールから会話を開始しようとすると失敗することがある問題を修正しました。
- キュー済みメッセージの編集を改善しました。Enter キーまたは確定ボタンで送信し、Shift+Enter で改行でき、IME 入力中の誤送信を防ぎます。
- Agent Role が選択されている際の重複した権限ボタンを削除し、設定の競合と画面の煩雑さを軽減しました。
- Windows で HTML 添付ファイルのパスを正しく開けない問題を修正しました。
- キュー済みメッセージエディターの周囲に二重の枠線が表示される問題を修正しました。
- セッションおよびファイル変更データの読み込みとキャッシュを最適化し、重複スキャンとリソース使用量を削減しました。
