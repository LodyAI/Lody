### 新機能

- Claude Code で高速モード（fast mode）に対応しました。
- Claude Code でバックグラウンドタスクおよびスケジュールタスクに対応しました。
- GLM の Claude Code プロバイダープリセットを追加しました。
- バージョン移行時に発生する可能性のあるローカルデータの不整合をリセットするため、Settings に「Clear Cache」オプションを追加しました。

### 修正と改善

- Codex および Claude 向けの新しいバイナリ管理方式を導入し、環境の違いによる利用上の問題を軽減しました。Settings → Agent から再度リフレッシュを実行してください。
- メッセージの送信および停止パイプラインを最適化し、より高速化しました。
- データ同期戦略を改善しました。
- 差分やファイルの表示に失敗することがある問題を修正しました。
- プロジェクトパスが長すぎる場合に Add ボタンをクリックできなくなる問題を修正しました。
- Windows でアプリのタイトルバーの色がテーマに追従するようになりました。
- モバイル Web 版でキーボードを閉じられない問題を修正しました。
- 会話内の画像が開けないことがある問題を修正しました。
- モバイルの Settings ページにバグ報告の項目を追加しました。
- Linux でのサインイン時にリダイレクトが失敗する問題を修正しました。
- すでに Zed で開いているプロジェクトを開く際、新しいウィンドウを開くのではなく既存のウィンドウにフォーカスするようにしました。
