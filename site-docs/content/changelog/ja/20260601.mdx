### 新機能

- Grok Build をはじめとする ACP エージェントと MiniMax プリセットを追加しました。
- 履歴が競合した場合に、ACP 側の履歴を優先して再インポートできるようになりました。
- 会話で正しいモデル名と思考レベルが表示されるようになりました。
- feedback.lody.ai でメールサインインに対応しました。

### 修正と改善

- 古い npx キャッシュが原因で codex および Claude Code の初回起動に失敗する問題を修正しました。
- モバイルで接続が切れた後の再接続時の引っかかりを軽減しました。
- ローカルプロジェクトのブランチ情報が過度に頻繁に更新されないようにしました。
- モバイルでユーザーメッセージが画面からはみ出す問題を修正しました。
- GitHub プロジェクトのアバターキャッシュを改善しました。
- モバイルの戻るジェスチャーのトリガー判定を改善しました。
- モバイルで戻るナビゲーションのアニメーションが崩れる問題を修正しました。
- モバイルでアーカイブ済み会話の復元および完全削除が正しく動作するよう修正しました。
- テーマピッカーの操作性を改善しました。
