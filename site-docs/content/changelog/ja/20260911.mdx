Version 0.93.3

### ✨ 新機能

- 既存のサブスクリプションと請求を継続したまま、ワークスペースの所有権を安全に移譲できるようになりました
- セッションやワークスペースを独立したデスクトップウィンドウで開けるようになりました
- 複数のチャットメッセージを選択して PNG 画像としてエクスポートしたり、生成されたチャット画像を直接コピーしたりできるようになりました
- マシンをまたいで Agent Role をメンションでき、一時的に利用できないロールも確認できるようになりました
- チャット内に送信者 ID が表示されるようになり、共同作業中にメッセージを見分けやすくなりました
- Usage ページからトークン使用量、アクティビティの推移、モデル別シェアを縦向きまたは横向きのレポートとしてエクスポートできるようになりました
- セッションのフォークメニューから完全なコンテキストを Markdown としてコピーできるようになり、会話のエクスポートも改善されました
- 専用コントロールから Codex のゴールを一時停止、再開、クリアできるようになりました
- Codex と Grok が独自のセッションタイトルを提供できるようになり、重複作業や待ち時間を削減しました
- オンボーディング中にエージェントランタイムを早い段階で準備し、待機状態をより分かりやすく表示するようにしました
- ローカルプロジェクト作成時にマシン所有者の Git ID を優先して使用するようにしました

### 🐛 修正と改善

- 一時停止した後にゴールを再開できない問題や、コントロールが無効のままになる問題を修正しました
- フォークした Codex セッションが最初のプロンプトでハングする問題と、キャンセル後のプロンプト競合を修正しました
- 認証情報の期限切れや ID 変更時にもエージェントのコンテキストを保持し、中断や重複した再起動を削減しました
- Plan モードの互換性、DeepSeek Harness の設定、ACP 機能キャッシュの復旧を改善しました
- 履歴の書き込み、ストリーミング更新、マシンアクセスのリトライ、および長時間の非同期タスクチェーンの信頼性を向上させました
- ローカルファイルリンク、システムでの開く操作、フォルダーのドラッグ＆ドロップを改善しました
- Mermaid の操作性を改善し、インライン図がスクロールを奪わないようにするとともに、全画面図でズームとドラッグに対応しました
- コンテキストの圧縮（コンパクション）完了後にセッション状態が確定しない問題を修正しました
- 子セッションの親子関係、サイドバーの折りたたみ操作、読み込み中のフォーク操作を改善しました
- デスクトップのショートカットライフサイクルを統合し、ウィンドウとキーボードショートカットの処理をより安定させました
- Windows 版エージェントのアップグレードとライフサイクルの確認応答を修正し、キーボードを閉じた後にモバイルのレイアウトが正しく復元されるようにしました
- モバイルの同期ペース、マシンステータスの読み込み、および Web サイトのモバイル初回読み込みパフォーマンスを改善しました
- メンバーシップの更新時にまれに発生していた権限エラーを修正しました
- フォルダーのドロップ、モバイル同期、作業時間のレポート、視差効果を減らす設定時の動作、フォークされた Codex セッション、およびターミナル描画の改善に貢献いただいた外部コントリビューターの @EYHN、@slashdevcorpse、@ladydd、@hqhq1025、@nzhl の皆さまに感謝いたします
