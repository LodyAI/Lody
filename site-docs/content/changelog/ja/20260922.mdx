バージョン 0.98.0

### ✨ 新機能

- モバイルの共有機能からエージェントタスクを作成する際の信頼性を向上させました。対象のマシンがオンラインに復帰した後でもタスクを配信できます。
- DeepSeek Harness からの質問を Lody の Ask Question UI に接続し、個別の回答メモに対応するとともに、Kimi Plan のインタラクションカードを改善しました。
- プロジェクトコンテキストの追加、ローカルプロジェクトの並び順の改善、最近更新されたプロジェクトの表示コントロールにより、サイドバーのプロジェクト整理機能を強化しました。
- セッションで実際に使用されたモデルを表示するようにし、各タスクのモデルを正確に識別しやすくしました。
- デスクトップのマルチウィンドウ、アーカイブ一覧、大規模プロジェクトでのファイル検索のパフォーマンスを改善し、ウィンドウを開く際やスクロール・検索時の引っかかりを軽減しました。
- 長い会話において、仮想化された行が再利用される際にも画面をまたぐテキスト選択が保持されるようになりました。

### 🐛 修正と改善

- 一部のパッケージ版インストール環境で Devframe および Devbar の起動に失敗する不具合を修正しました。
- Windows でコマンドがシェルの長さ制限を超えた際に DeepSeek Harness の起動に失敗する不具合を修正しました。
- ホストされた Astro プレビューがプレーンテキストの 403 を返したり、ナビゲーション中に失敗したりする不具合を修正しました。
- メッセージ、権限リクエスト、コンテキスト圧縮の状態が順序どおりに書き込まれなかったり、未完了のまま残ったりする不具合を修正しました。
- 通知からのナビゲーション、未読状態、最後のタブを閉じた際のウィンドウ終了、Zen モード、Mermaid、数式レンダリング、ダイアログの重なり順、入力フォーカスを改善しました。
- Kimi Plan のファイル欠落エラー、モデルおよびプロジェクト検索のフォーカス、使用量詳細のキャッシュ、閉じた会話からの未読出力に関する不具合を修正しました。
