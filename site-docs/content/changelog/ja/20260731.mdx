### ✨ 新機能

- セッションのフォーク機能を追加しました。Agent の返信の下にある Fork ボタンを使うと、その返信からセッションを分岐できます。Codex と Claude Code では、セッション内の任意の時点からのフォークにも対応しています。
- 右サイドバーを刷新し、Browser と Side Chat を追加しました。
- Browser では、ローカルセッションの場合は任意の URL を開くことができ、リモートセッションの場合はそのセッションを実行しているマシン上のポートにアクセスできます。なお、Agent による Browser の操作はまだサポートされていません。
- 動的に作成した Lody セッションで、チャット中にモデルや推論レベル（reasoning effort）などの設定を変更できるようになりました。
- アーカイブ済みセッションに検索機能と並び替え機能を追加しました。

### 🐛 修正と改善

- ライトモードの背景色を純白（ピュアホワイト）に更新しました。
- モバイル UI の一部をブラッシュアップしました。
- モバイル環境でメッセージを送信した後もキーボードが開いたままになることがある不具合を修正しました。
- ローカルファーストモードでセッションの同期に失敗することがある不具合を修正しました。
- 新規セッション作成フローのプロジェクト一覧が最後までスクロールできず、すべてのプロジェクトが表示されない不具合を修正しました。
- CLI の CPU およびメモリ使用量を削減しました。
- マシンのオンラインステータスの安定性を向上させました。
- セッション検索の仕様を見直し、ツール呼び出しとその結果を除外してメッセージ本文のみを検索対象にするよう改善しました。
