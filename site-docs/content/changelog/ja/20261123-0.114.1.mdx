バージョン 0.114.1

### ✨ 新機能

- EverMe をアカウント全体で使えるメモリプロバイダーとして利用できるようになりました。ワンクリックでのインストール、または手動でのセットアップが可能です。
- 実験的機能の Today アウトラインでは、メモ、To-Do、セッションメンションを 1 つのページにまとめられます。項目をタスクに変換したり、特定のブランチにフォーカスしたり、選択範囲を段階的に広げたり、複数項目をまとめて編集したりできます。デスクトップ版では、セッションの横に Today を別ウィンドウで開くこともできます。
- 新しいステータス（Status）ビューで、セッションを「Focus」「Later」「Settled」に整理できるようになりました。セッションを 1 時間または 3 時間スヌーズしたり、ドラッグして「Focus」に戻したりできます。
- ピン留めしたセッションをグループ化し、手動で並べ替えられるようになりました。デバイスごとに表示するグループを選択したり、グループ内で直接セッションを開始したりできます。セッションを端付近へドラッグするとサイドバーが自動でスクロールします。
- ⌘/Ctrl + 1–9 を押すと、表示されている先頭 9 件のセッションを切り替えられます。長い一覧は 1 ページずつ展開できるようになりました。
- セッションに GitHub PR を紐付けたり解除したりできるようになりました。紐付けた PR を Auto delivery に引き継いだり、サイドバーでマージのフィードバックを確認したりできます。
- セッションメニューから、そのセッションの作業ディレクトリを Finder またはエクスプローラーで開けるようになりました。ターミナル内の URL を修飾キーを押しながらクリックすると、ブラウザーで開けます。
- セッションのサイドパネルで添付ファイルをプレビューし、動画の再生速度を調整できるようになりました。
- 空のコンポーザーで上下矢印キーを押すと、送信済みメッセージを呼び出せるようになりました。モデル検索、思考レベル（thinking effort）、添付メニューのショートカットもカスタマイズできます。
- Codex に Ultrafast 速度オプションが追加されました。また、Lody から Antigravity へリモートでサインインできるようになりました。
- Lody Agent の設定で、カスタムエンドポイントから利用可能なモデルの一覧表示と更新、および新規セッションのデフォルトモデル、思考レベル、自律度（autonomy）の設定ができるようになりました。Prompt エディターと Agent Role エディターも刷新されています。
- 時間のかかるコマンドを Lody のバックグラウンドで実行できるようになりました。コマンドが終了するとセッションが結果を受け取り、処理を再開します。セッションの編集者は共有マシン上のオートメーションも管理できます。
- デスクトップの Settings → Data または CLI から、ワークスペースをエクスポートおよびインポートできるようになりました。移行先ワークスペースのメンバーには、別ワークスペースからインポートされたコンテンツへの読み取り専用アクセス権が付与されます。

### 🐛 修正・改善

- 会話の引用アクションがモーダルダイアログの上に表示されてしまう問題を修正しました。

- Windows および Linux 安定版インストーラーの本番パッケージング引数を修正しました。

- アーカイブが単一の一覧として開くようになり、グループを展開せずに古いセッションを閲覧できるようになりました。
- コンポーザーがインターフェースのフォントサイズに従うようになりました。送信済みメッセージの編集中にもプロンプトのショートカットが機能します。
- 送信済みメッセージ内のセッションメンションをクリックしてそのセッションを開けるようになりました。現在のワークスペース内のセッションへの Markdown リンクも Lody 内で開きます。
- 狭いウィンドウでもコンポーザーのサブメニューが画面内に収まるようになりました。GitHub リポジトリが連携されていないプロジェクトでは、メンションメニューに Issue と PR のカテゴリが表示されなくなります。
- バックグラウンドウィンドウによってセッションが意図せず既読になることがなくなりました。また、「Focus」を並べ替えても、「Later」から戻ったばかりのセッションの未読状態が保持されます。
- 別のウィンドウでグループを折りたたんだりフィルターを変更したりしても、開いている各ウィンドウのサイドバー表示が維持されるようになりました。
- 送信を停止すると、キューに入っていたメッセージが編集・手動送信できる下書きとして保持されるようになりました。再起動によって中断されたターンは、1 回の「continue」で再開できます。
- クラッシュ後に新規作成したセッションが失われる問題と、ワークスペースの変更一覧からファイルが欠落する問題を修正しました。
- 別のセッションに切り替えてから戻ってもプレビューが開いたまま維持されるようになりました。サイズの大きいローカル HTML プレビューや、プレビュー内でプロジェクトのアセット・リダイレクトが読み込めない問題も修正しています。
- リモートファイルの検索が、ファイルをホストしているマシン上で実行されるようになりました。大規模なプロジェクトでの待ち時間を減らすため、GitHub ブランチは 1 ページずつ読み込まれます。
- Antigravity でコマンドやスキルメニューが空になる問題と、バックグラウンドタスク終了後もセッションが実行中（working）と表示され続ける問題を修正しました。
- モデルがカスタムの推論レベル（reasoning-effort）値や長い入力タイプ一覧を含む場合に、Magpie モデルカタログ全体の読み込みに失敗する問題を修正しました。
- エージェント接続、Claude の使用量照会、デスクトップ接続、およびオートメーションで、設定済みのプロキシが使用されるようになりました。デスクトップのサインインをブラウザー上で続行することもできます。
- スタンドアロンインストール後にターミナルで lody コマンドが利用できない問題を修正しました。明示的な再インストールを行うと、新しくインストールされたデーモンバージョンが有効になります。
- デスクトップの起動が高速化され、CLI デーモンのメモリ使用量が削減されました。また、長いセッションを再度開く際の履歴読み込みも効率化されています。
