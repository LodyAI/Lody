### エージェントワークフロー

- Codex Goals が Lody 上に表示されるようになりました。あらかじめ Codex 側で `codex features enable goals` を実行して機能を有効にしてください。
  <img src="/_docs-assets/20260507-goal.png" alt="" />
- Codex の画像生成出力がアクティブな会話に直接返されるようになり、生成された画像をプロンプトや後続の指示と並べて確認できるようになりました。
  <img src="/_docs-assets/20260507-codex-image-gen.png" alt="" />
- Claude Code の AskUserQuestion プロンプトがネイティブのインタラクションカードとして表示されるようになり、単一選択、複数選択、自由記述の回答フローに対応しました。
  <img src="/_docs-assets/20260507-ask-question.png" alt="" />
- Claude Code 向けに、Token Plan 設定を含む Xiaomi MiMo プリセットを追加しました。

### リモートプレビューとビジュアルフィードバック

<img src="/_docs-assets/20260507-preview.png" alt="" />

- ローカル開発サーバー向けのセッション単位のライブプレビュー機能「Lody Preview」を追加しました。たとえば、エージェントに「`Start the Vite dev server and use Lody Preview`」のように指示して利用できます。
- プレビューパネルでは、デスクトップ、タブレット、モバイルのビューポート切り替え、画面の回転、ズーム、パン操作が可能で、必要に応じて外部ブラウザーでページを開くこともできます。
- ビジュアルアノテーションを使うと、プレビュー内の要素をクリックしてコメントを残し、その要素を参照したフィードバックを会話へ送り返すことができます。

### サイドバーとタスク管理

- 更新順（Updated）のサイドバー整理モードを追加し、Chat、GitHub Worktree、Local Project の各セッションを「Today」「This week」「Older」の新しい順でグループ分けできるようになりました。
- セッションのコンテキストメニューに、名前の変更、ピン留め、アーカイブ、セッション URL のコピー、現在のブランチのコピーを追加しました。
- ピン留めしたセッションはリストの上部に固定されるため、長時間の作業や重要なタスクにすぐ戻れるようになりました。
- Web 版では、サイドバーのタスクを中クリックまたは Cmd/Ctrl+クリックすることで新しいタブで開けるようになりました。

### 会話と入力

- 長文を貼り付けた際、入力欄を埋め尽くす代わりにインラインのプレースホルダーに折りたたまれるようになりました。プレースホルダーをクリックすると、貼り付けた内容を確認または編集できます。
- 画像を入力欄へ直接ドラッグしてアップロードできるようになりました。
- モバイルでは、画像プレビューを長押しするとネイティブの共有・保存アクションが開きます。
- ファイルプレビューで長い行が自動的に折り返されるようになり、ログや密な生成出力が読みやすくなりました。

### GitHub とプルリクエスト

- ドラフト PR を PR パネルから直接「Ready for review」に切り替えられるようになりました。
- PR に紐づいたセッションについて、PR がマージまたはクローズされた際に自動でアーカイブできるようになりました。
- PR のコメント、レビュー操作、マージにご自身の個人 GitHub アカウントを使用できるようになり、接続中のアカウントが Settings に表示されるようになりました。

### 修正と安定性

- ローカルプロジェクトのインポートが成功した後に誤って失敗トーストが表示される不具合を修正しました。
- プリセットエージェントの初回ターンでタイトル生成設定が抜けることがあった不具合を修正しました。
- サイドバーの表示に関する複数の不具合を修正しました。
- モバイルでドロップダウンメニューが画面外にはみ出すことがあった不具合を修正しました。
