バージョン 0.92.0

### ✨ 新機能

- エージェントが新しいセッションを作成すると即座にカードが表示され、そのまま開いて実行状況を確認できるようになりました
- プロジェクトの Skills を名前、説明、作成者、またはパスで検索できるようになりました
- 添付ファイルやプレビューから HTML ソースファイルを直接ダウンロードできるようになりました

### 🐛 修正と改善

- 大きなファイルのページ分割読み込みと画像・ファイルのより効率的な読み込みにより、ローカルファイルプレビューを改善しました
- Factory Droid の接続を修正し、選択したモデルに応じた正しい推論オプションが表示されるようにしました
- Grok ツールの権限動作と、高度に断片化されたローカルデータの処理を改善しました
- タブ切り替え後に新規チャットの添付ファイルが消える問題と、以前のメッセージから未配信インジケーターが消える問題を修正しました
- セッションの作業時間が誤って延長される問題と、以前の出力がタイトル生成に干渉する問題を修正しました
- Linux の .deb アップデートインストール時にアプリがフリーズする問題を修正し、認証のキャンセルやインストール失敗後に再試行できるようにしました
- 完了済みの1回限りのタスクで、次回実行時刻が誤って翌年と表示される問題を修正しました
- デスクトップ版入力欄のフォーカス、サイドバーでのセッション階層表示、およびモバイルのスクロールを改善しました
- チームワークフローにおけるエージェントのセッション委譲および完了通知の信頼性を改善しました
