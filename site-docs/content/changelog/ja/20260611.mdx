### 新機能

- **iOS Live Activities と Dynamic Island**: Lody を開かなくても、iPhone のロック画面や Dynamic Island からエージェントの進捗を確認できます。エージェントが承認を必要としている場合、Lody から操作可能な Live Activity アラートを送信することもできます。

  <img src="/_docs-assets/20260611-island.png" alt="Dynamic Island 上の Lody Live Activity" />

- **ワークツリーのセットアップおよびクリーンアップスクリプト**: ワークツリーの作成後かつエージェントの起動前に実行されるプロジェクトレベルのスクリプトと、セッションがアーカイブされてワークツリーが削除される際に実行されるクリーンアップスクリプトを設定できます。
- **モバイルでのプロジェクトファイル閲覧**: セッションを先に開始しなくても、ローカルプロジェクトや GitHub プロジェクトのディレクトリを閲覧し、モバイルのプロジェクト画面から直接ファイルを開けます。
- **リアルタイムでのプロジェクトファイル編集**: ローカルまたはリモートのセッションで、現在の作業ディレクトリ内のテキストファイルをチームと共同で編集できます。モバイルでの編集機能も近日公開予定です。
- **ファイルビューアーでの Markdown プレビューと検索**: Markdown ファイルではワンクリックでソース表示とレンダリングプレビューを切り替えられるようになり、テキストファイルではビュー内検索コントロールを開けるようになりました。
- **Turn Diff と All Changes の信頼性向上**: 差分の読み込みがより安定し、リモートデバイスからもファイルや差分を一貫して確認できるようになりました。
- **カスタム ACP エージェント**: 起動コマンドと引数を入力するだけで、任意の ACP 互換エージェントを追加できます。

### 改善

- Proposed Plan カード（メッセージ末尾のプランのみの応答を含む）にコピーボタンを追加しました。
- ローカルプロジェクトピッカーをマシン優先の選択方式に改善し、安定性を向上させました。
- 新しい会話のプロジェクト一覧を最近のアクティビティ順で並べ替えるようにしました。
- プレビューに共有リンクのコピーボタンを追加しました。
- 非常に長いユーザーメッセージがチャットバブルからはみ出したり途切れたりしないようにしました。
- 切り替え時に右サイドバーの折りたたみボタンが横にずれる問題を修正しました。
- 接続が不安定な間も、共有されたマシンやプロジェクトがより確実に保持されるようにしました。
- マシンがオフラインのときに、会話作成画面でページが繰り返し移動する問題を修正しました。

### 削除

- Lody の PWA サポートを終了しました。
