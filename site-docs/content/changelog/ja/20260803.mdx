### ✨ 新機能

- 最新のユーザーメッセージを編集して再送信する機能に対応しました。
- モバイル環境でファイルアップロードの進捗表示を追加しました。
- ⌘W を押して、セッションタブまたは右サイドバーのアクティブなビューを閉じられるようになりました。

### 🐛 修正と改善

- セッションの起動時間を短縮しました。
- 接続失敗時に Codex のネットワーク警告が会話内に表示されないようにしました。
- メモリ不足が発生した後に Agent が再起動を繰り返すことがある不具合を修正しました。
- CLI の `--auth` オプションの不具合を修正しました。
- ローカルプロジェクトのブランチが正しく検出されないことがある不具合を修正しました。
- ローカルからクラウドへの同期を改善し、他のデバイスで最新のメッセージを受信できないことがある不具合を修正しました。
