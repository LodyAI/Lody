### 新機能

- Codex Plan Mode のフローに対応しました。

### 修正と改善

- 会話におけるストリーミング中の Markdown レンダリングパフォーマンスを改善しました。
- ネイティブモバイルアプリで、初回サインイン成功後に画面が真っ白になる問題を修正しました。
- オンボーディングフローでエージェント接続をスキップし、後から設定画面で構成できるようになりました。
- Claude 設定の更新時に失敗する問題を修正しました。
- Android でフォントのレンダリングが異常になる問題を修正しました。
- 個人の GitHub 権限を付与した後も、操作時に誤ったアカウント情報が使用され続ける場合がある問題を修正しました。
- 古い状態の PR ページが自動的に更新されない問題を修正しました。
- 貼り付けた長文テキストがコンパクトなプレビューに折りたたまれるまでのしきい値を引き上げました。
- ローカルプロジェクトのブランチ情報の読み込み中にタイムアウトが発生する問題を修正し、手動更新の項目を追加しました。
