Version 0.97.0

### ✨ 新機能

- セッションリンクをコンポーザーに貼り付けるとセッションメンションに変換されるようになりました。プレーンなリンクとして貼り付ける場合は Cmd/Ctrl+Shift+V を使用してください。
- デスクトップの「Settings > Projects」が 2 ペインのカタログになりました。左側に GitHub / マシン、右側に選択したソースのフォルダーが表示され、フォルダーをクリックして編集できます。
- キュー内のメッセージを直接ステアリング（進行方向修正）できるようになりました（エージェントが確認応答付きステアリングに対応している場合、先頭項目以外も対象になります）。Cmd/Ctrl+Shift+Enter を押すと、その送信に限りキュー追加とステアリングを一時的に切り替えられます。

### 🐛 修正と改善

- 署名済みの macOS デスクトップアプリ上で、DeepSeek Harness や未署名のネイティブアドオンを読み込むその他のエージェントが起動に失敗する問題を修正しました。
- モバイルのセッションメニューから会話を画像として共有できるようになりました。
- 会話カラムの幅が狭い場合、IDE 操作と共有アクションが ⋯ メニュー内に移動するようになりました。
