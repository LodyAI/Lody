バージョン 0.97.1

### 🐛 修正と改善

- 内蔵 Claude にガイドメッセージを送信してから約 5 秒後に、エージェントが強制終了される不具合を修正しました。
- Windows でシステムの資格情報ストアを復号できなくなった場合（新しいアカウントでマシンを復元した後など）にデスクトップのサインインが失敗する不具合を修正しました。現在は自動的に復旧し、失敗時にはより明確な理由を表示します。
- 内蔵 Devin ランタイムを復元しました。
- 複数のタブを連続して閉じる際、残りのタブの幅が維持されるようになり、次の閉じるボタンがカーソル位置にとどまります（Chromium と同様の挙動）。
- メッセージを一度も送信していないタブを閉じた際、見えないセッションが残るのではなく削除されるようになりました。また、タブを閉じた際のトースト表示をなくし、タブが 1 つだけのときは閉じるボタンを表示しないようにしました。
- エージェントの作業中、会話内に経過時間付きのシマー表示によるアクティビティラベルが表示されるようになりました。
- メッセージの Operation が完了すると、到達した Session を表示し、結果を受信済み返信カードとして提示します。返信の全文はダイアログで開けます。
- バックグラウンドタスクの完全なコマンドをダイアログで開けるようになりました。
- ワークスペーススイッチャーのヘッダーに現在のワークスペースを表示するようにしました。
- キューに入ったメッセージを入力欄にぴったり接して表示し、含まれる画像を画像ビューアーで開けるようにしました。
- 行数の統計情報がない編集済みファイルについて、空の統計を表示する代わりにラベルを付けるようにしました。
- デスクトップ画面のブラッシュアップ：macOS トップバーとトラフィックライト（信号ボタン）の位置合わせ、ライトモードにおけるコードブロックのコントラスト、ホバーおよび設定画面のサーフェス階層、サイドバーのプロジェクトグループレイアウト、会話内検索バー、会話本文に揃えた複数行コードの文字サイズを調整しました。
