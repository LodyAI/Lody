Version 0.103.0

### ✨ 新機能

- Codex GPT-6.1-Solモデルに対応しました。
- セッション内でWord（DOCX）、Excel（XLSX）、PowerPoint（PPTX）ドキュメントを直接プレビューできるようになりました。
- ソース編集機能はそのままに、セル検索とズームに対応した新しいCSVおよびTSVのテーブルプレビューを追加しました。
- PDFプレビューにサムネイルナビゲーション、回転、追加のズームオプションを搭載し、ドキュメント検索も改善しました。

### 🐛 修正と改善

- モデルの切り替えやロールの適用後に、推論量（reasoning effort）やFastオプションが正しく表示または適用されない問題を修正しました。
- セッションタブの切り替え時に発生することがあったメッセージ領域のクラッシュを修正し、閲覧位置の復元を改善しました。
- コンポーザーの `@` メニューの位置調整を改善し、入力カーソルに追従して利用可能なスペースに適応するようにしました。
- GitHub認証の期限切れや取り消し時のメッセージを改善し、一部のGitコミットで作成者情報が誤って付与される問題を修正しました。
- 組み込みのCodexランタイムを更新し、新しいモデルの使用コスト見積もりを追加しました。
- 一部の公開Webサイトページにおけるナビゲーションとリンク先を修正しました。

フィードバックの共有やLodyへの貢献をいただいているコミュニティの皆様に感謝いたします。
