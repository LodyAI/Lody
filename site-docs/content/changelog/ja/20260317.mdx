### 新機能と機能強化

- デスクトップアプリを正式リリースしました（[こちら](/ja/download)から入手できます）
- 画像入力およびスクリーンショット応答に対応しました
<img src="/_docs-assets/20260317-lody-image-back.png" alt="" />
- すべての ACP Registry 設定オプションに対応しました
- [CLI コマンド一式](/ja/docs/cli)（`session`、`workspace`、`history`、`agent-config`、`machine`）を追加しました

### プラットフォームと UI 体験

- サイドバーを折りたたんだ状態でグループ件数を表示し、PR セッション上に PR 番号を直接表示するようにしました
- デスクトップ版のバージョン表示とアップデート確認機能を追加しました
- CLI を再起動する「Restart CLI」ボタンを追加しました
- セッション実行中のシステムスリープを防止するようにしました（無効にする設定も用意しています）
- デスクトップウィンドウのサイズと位置を記憶するようにしました

### 修正と安定性の向上

- トークン使用量に負の差分が表示されることがある不具合を修正しました
- Changes タブで変更件数が過大に表示される不具合を修正しました
- モバイルの画面向き変更時の不具合、Settings および Integrations ページのスクロール不具合、画像プレビューの閉じるボタンの位置を修正しました
