### ファイル / 差分ビュー

- ワークスペースのファイル一覧をリアルタイムで表示できるようになりました
- 各チャットの最後に、Lodyがすべてのファイル変更と行数の増減を要約し、クリックして差分を表示できるようになりました。
  <img src="/_docs-assets/20260112-changelog.png" alt="" />

### GitHub連携

- PR作成時にユーザー自身のIDを優先して使用するようになりました

### プッシュ通知

- 設定で通知が有効になっている場合、チャット完了時に通知が送信されます
- エージェントが権限を必要とする際に通知が送信されます
- エージェントの最初の返信時に、プッシュ通知を有効にするかどうかを確認します
- チームにメンバーを招待するとメールが送信されます

### その他

- プロキシ対応：CLIでHTTPプロキシ経由のWebSocket接続に対応しました
- GitHub連携に検索・フィルターボックスを追加しました
- チャットへのオフラインアクセスに対応しました

## 修正

- 修正：Claude Code ACPの互換性の問題により、セッションの更新（プランやツール呼び出し）が正しく描画または永続化されない場合がある不具合を修正しました
- GitHub連携の有効期限が切れる問題を修正しました
- 言語切り替えがリフレッシュ後に反映されない問題を修正しました
- いくつかのUI上の問題を修正しました
