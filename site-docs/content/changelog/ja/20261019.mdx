バージョン 0.107.0

### ✨ 新機能

- エージェントの完了時に、現在の作業コンテキストに即したメッセージでネイティブの結果通知が届くようになりました。
- ターンごとの推定コストを表示できるようになりました。
- 同じエージェントロールを複数のマシンで実行できるようになりました。また、MCP / CLI 経由でロールの作成や更新を提案できるようになりました。
- Pele によりチャット内で Mermaid 図を描画できるようになりました。また、Markdown プレビューで埋め込み画像を表示できるようになりました。
- 「Open with Delta」ランチャーを追加し、マシン設定画面に接続済みエージェントのアイコンを表示するようにしました。
- モバイル版の変更（Changes）ナビゲーションをデスクトップ版と統一しました。
- 安定版および Nightly 版の両方で Linux ARM64 インストーラーを提供開始しました。
- 問題の切り分けを容易にするため、バグ報告にクライアントの診断情報および環境詳細が含まれるようになりました。

### 🐛 修正と改善

- セッションとデーモンの信頼性を向上させました。エージェントが作業中のセッションをアイドル GC が回収しなくなり、一時的な起動失敗時はリトライが可能になり、停止後もチャットを継続できるようになりました。
- 同期エンジンの各種最適化と修正を行いました。
- デーモンを起動せずにローカルファイルをプレビューできるようになりました。また、Codex の引用がファイルカードとして表示されるようになり、同梱の Codex 履歴インポート機能も復元されました。
- iOS 16.4 以降のランタイム互換性を改善し、Windows のキャプションボタンがオーバーレイを覆ってしまう問題を修正しました。
