Version 0.101.1

### ✨ 新機能

- リモートWebプレビューが事前読み込みされるようになり、ブラウザパネルがより速く開くようになりました。

### 🐛 修正と改善

- ネットワーク同期がメッセージ送信をブロックする問題を修正し、不安定な接続環境での送信と復旧を改善しました。
- 送信待ちメッセージがある場合に会話をアーカイブまたは削除できない問題を修正しました。
- 組み込みのClaudeを更新し、ツール呼び出しのステータス、出力、ファイル変更情報が不完全になる問題を修正しました。
- デスクトップ版でのローカルファイルプレビューを高速化しました。
- ファイル変更を選択すると該当ファイルにフォーカスが移動するようになりました。また、変更一覧にディレクトリパスも表示され、同名ファイルを区別しやすくなりました。
- ローカルワークツリーオプションにGitステータスの読み込み中インジケーターを追加しました。
- 同時更新時のデータ同期の安定性を向上させました。
