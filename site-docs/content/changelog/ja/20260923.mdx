バージョン 0.100.0

### ✨ 新機能

- Opus 5.5、GPT-6-Sol、GPT-6-Luna に対応しました。
- Lody 内で直接設定してセッションを作成できる内蔵エージェントとして Dimcode を追加しました。

### 🐛 修正と改善

- 内蔵の Claude Code、Codex、Grok、Kimi、Pi ランタイムをアップグレードし、エージェントの信頼性とセッションの起動を改善しました。
- デスクトップウィンドウのウォームアップとコンテンツ読み込みを改善し、セッションを開く際の空白画面、エラーページ、一瞬の読み込み状態の表示を減らしました。
- 長い会話のバックグラウンド読み込みを改善し、コンテンツのちらつき、メッセージの配置ずれ、テキスト選択の解除を防ぎました。
- サイドバーのフィルターレイアウトを改善し、タスクリストが空のときでもフィルター操作を利用できるようにしました。
- セッションから別のローカル worktree ファイルを開く際に、誤ったファイルが対象になる場合がある不具合を修正しました。
- Windows で DeepSeek Harness の子プロセスがコンソールウィンドウを繰り返し開かないようにしました。
- Machine Flock のリモート同期が失敗した際に自動的に再試行し、明確な失敗状態を通知するようにしました。
- Code Collab でテキストファイルを保存する際に、実行権限および非公開の POSIX ファイルパーミッションを保持するようにしました。
- 共有のエントリーポイントとセッションヘッダーのインターフェースを洗練しました。

### 🙏 外部コントリビューターへの感謝

- Code Collab でのファイル保存時に POSIX パーミッションを保持する修正をしてくださった ladydd さんに感謝します。
