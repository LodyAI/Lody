バージョン 0.109.0

### ✨ 新機能

- マルチリポジトリプロジェクト: 複数の Git リポジトリ、サブモジュール、ローカルフォルダーを 1 つのプロジェクトにまとめ、同じ会話内でリポジトリ横断の作業を行えます。Settings → Projects から追加するか、デスクトップのサイドバーで既存のプロジェクトを右クリックして設定できます。（iOS では次のモバイル TestFlight ビルドをお待ちください。それまではマルチリポジトリの会話は表示されません。）
- リポジトリ別 PR ビュー: マルチリポジトリの会話で表示するリポジトリを切り替えて、各リポジトリの PR、CI ステータス、およびアクションを確認できます。サブモジュールは階層構造で表示されます。
- Magpie CLI インポート: CLI 経由で Magpie プロバイダー設定をインポートできるようになり、デスクトップ環境のないマシンでも利用可能になりました。
- 次のプロンプト提案: 空のコンポーザーに Claude Code のエージェントが返した提案を表示できるようになりました。デスクトップでは Tab キーを押すか、モバイルでは「Apply」をタップすると入力欄に反映されます。
- ローカル MCP サインイン: ブラウザー認証、サインアウト、および手動での認証情報入力に対応しました。認証情報はローカルシステムの認証情報ストアに保存され、ワークスペース設定とは同期されません。
- Schedules ページを刷新: プロジェクトおよびステータスによるフィルター、並び替え、設定（Settings）ビューと実行履歴（Run history）ビュー、完了済みスケジュールメッセージの一括整理機能を追加しました。
- 分類されたタスクタブ: サブエージェントとバックグラウンドタスクが別々のタブに表示されるようになり、実行の進捗を追いやすくなりました。
- マシン横断のロール連携: ローカルプロジェクトからリモートのロールを呼び出す際、プロジェクトに紐付けられワークスペースに接続された GitHub リポジトリを利用できるようになりました。関連する会話は一覧上でネスト表示されます。
- iPhone Duo 対応: モバイルレイアウトが利用可能な画面領域に追従するようになり、折りたたみ・展開・分割画面での操作性が向上しました。
- スケジュールメッセージ: メッセージ、添付ファイル、参照情報を予約送信し、後から編集やキャンセルを行えます。対象マシンがオフラインの場合は、有効期間内であればマシン復帰時にキャッチアップ送信されます。
- Claude クォータリセット後の続行: ワンクリックでクォータリセット後に `continue` を送信するよう予約でき、タスクを最後まで完了させられます。
- DeepSeek Harness プラグイン管理: 既存のユーザー設定を保持したまま、ローカル CLI からプロバイダープラグインを管理できるようになりました。
- 使用量リセット時刻の表示切り替え: 「resets in…」の相対時間表示と、ローカルタイムゾーンでの絶対日時表示を切り替えられるようになりました。
- より大きなリモートファイルのダウンロード: 有料ワークスペースでは最大 100 MiB のファイルをダウンロードできるようになりました（ファイルをホストしているマシン側の CLI も更新する必要があります）。

### 🐛 修正と改善

- 会話内容の更新時に、既存のテキストが誤って上書きされることがある問題を修正しました。
- リポジトリ横断の PR リンク付けとステータス同期を改善し、ステータス更新によって既存の PR リンクが影響を受けないようになりました。
- 短時間の再接続時にサイドバーのマシンのオンライン状態がちらつく問題を修正しました。
- 通常の環境変数を追加した後、一部プロバイダーのサブスクリプション使用状況が表示されなくなる問題を修正しました。
- DeepSeek の会話では完了後にプロセス出力が自動で折りたたまれるようになり、最終的な返信が読みやすくなりました。
- モバイル版のメッセージキュー操作ボタン、メモリ一覧におけるロールラベルの配置、およびデスクトップ版サインインページのアイコン表示を改善しました。
- エージェントが子会話を作成する際、タブ会話が指定されていない限り、新しい会話を優先して作成するようになりました。
- デスクトップ版のサインイン復旧処理を改善し、起動時のネットワーク応答が遅い場合に予期せずサインアウトされてしまうのを防ぎました。
- 同期順序が変わった際にメッセージキューが送信を続行できなくなることがある問題や、異常終了したタスクが実行中のまま表示される問題を修正しました。
- 新しい会話の作成時にリモート MCP デフォルト設定の同期待ちが発生しなくなり、一括で会話を作成する際も選択した MCP が保持されるようになりました。
- バックグラウンドタスクが実行中に消えてしまう問題と、Claude タスクの完了後に実行者情報が失われる問題を修正しました。
- Kimi がプラン承認を求める前にプラン全体を表示するようになりました。
- Pi でモデルを切り替えた後に、推論レベル（reasoning-effort）の選択肢がモデル機能と一致しない問題を修正しました。
- Codex ランタイムを更新し、スキル一覧の更新、コンテキスト圧縮の完了検知、およびプロバイダー切り替え後のエラーメッセージを改善しました。
- サブモジュールのチェックアウトが不完全な場合にマルチリポジトリプロジェクトの起動に失敗する問題を修正し、フォルダーパス表示やサイドバーのアーカイブ・折りたたみ動作を改善しました。
- PR のコンフリクト解消アクションが現在の会話で開かない問題と、モバイルでの名前変更が誤って他の会話に影響する問題を修正しました。
- 正常な Nowledge Mem 接続が誤って失敗として報告される問題を修正しました。
- モバイルのマシン管理ボタンと戻るジェスチャーの競合を改善し、ターミナルタブ、サインインテキスト、およびホームのステータス表示も改善しました。
- Claude がクォータ上限に達した際、プロンプトカードから直接リセット後の `continue` メッセージを予約できるようになり、予約時刻が画面上の表示と一致するようになりました。
- 予約送信が利用できない場合、ホバーすることで具体的な理由を確認できるようになりました。
- モバイルで最初のメッセージを送信する際の画面とキーボードの連携を改善し、新しい会話では最後に使用したプロジェクトが復元されるようになりました。
- モバイル版のメッセージキューがコンパクトな 1 行レイアウトになりました。
- 複数のバージョンの Lody がインストールされている場合のリンクの開き方を改善し、会話・新規会話・プロバイダーインポートの各リンクが実行中のバージョンへ引き継がれるようになりました。
- エージェントのプロンプトカードや推論コンテンツの配置、配色、インラインコードのスタイルを改善し、視覚的なノイズを軽減しました。
- スケジュールメッセージの管理がより簡単になりました。送信ボタンの横に予約時刻が表示され、スケジュールメッセージはメッセージキューにまとめられ、時刻の変更、内容の編集、キャンセルを直接行えます。
- メッセージキューのレイアウトを改善しました。スマートフォンや幅の狭いウィンドウではコンパクトな 1 行表示となり、操作は「More」メニューにまとめられます。完了した 1 回限りのスケジュールメッセージの記録は 7 日間保持された後に自動削除されます。
- オンボーディング中にコンポーザーのプロンプト提案で発生していた互換性の問題を修正しました。
- 実行中のタスクを停止した直後に送信したメッセージまでキャンセルされてしまう問題を修正しました。また、タスクの停止に失敗した場合はその理由が会話内に表示されるようになりました。
- 同じマシン上のエージェントが MCP 経由で実行中の会話にメッセージを送信した際、アクティブなタスクを直接ステアリング（軌道修正）できるようになりました。
- スケジュールタスクの追加の実行スロット制限を撤廃し、タスク同士の待ち時間が減るようにしました。
- 新しく作成したプロジェクトが自動的に選択されるようになり、プロジェクトピッカーからプロジェクトグループを直接編集できるようになりました。
- プロジェクトのサブモジュールを準備する際、ローカルの Git データを再利用するようになり、重複ダウンロードを削減しました。
- アプリプレビューにおける Cookie の受け渡しを修正し、サインインが必要なページのプレビューを改善しました。
- ブラウザーサインインページのエラーと、無効な招待リンクに対するエラー処理を修正しました。
- モバイルでメンションメニューがスクロールしない問題と、中国語表示におけるメッセージキューの時刻フォーマットの誤りを修正しました。
- プロンプト提案の折り返しとカーソル表示を改善し、IME での入力変換中は一時的に非表示にするようにしました。
- WebKit で閲覧中にスクロール位置が飛ぶ問題を修正し、共有画像の鮮明度を向上させました。
- ファイルリンクの検出とパスコピーを改善し、相対パスによる誤ったジャンプを減らしました。
- 削除された会話の専用作業ディレクトリをクリーンアップするようにし、アーカイブ時は空のディレクトリのみを削除して既存ファイルは保持するようにしました。
- 一時的なネットワーク遅延によってオンラインのマシンがオフラインと判定され、会話の操作が拒否されてしまう問題を修正しました。
- スケジュールタスクの読み込み失敗時の復旧処理を改善し、ローカルの編集内容を保持したまま手動リトライできるようにしました。
- 一部モデルで推論レベルの選択肢がモデル一覧と一致しない問題と、Pi の起動時にモデルと推論レベルの設定が誤った順序で適用される問題を修正しました。
- DeepSeek Harness の起動互換性を改善し、対応するバージョンの Node.js が見つからない場合に分かりやすいインストール案内を表示するようにしました。
- デスクトップウィンドウのドラッグ領域上にある通知ボタンがクリックできない問題を修正しました。
- コンポーザー内でファイル参照の前後にカーソルを移動する macOS の Emacs 風キーバインドに対応しました。
