### 🧠 Claude Opus 4.7 対応

### 👥 より安全なチームコラボレーション

- 新しいチーム向けマシン公開範囲の制御を導入しました。ご自身のマシンはデフォルトで他のメンバーに対して**完全に非公開**となり、他の人のワークスペースに参加しても、自分の開発マシンが公開されたり利用されたりする心配がなくなりました
- マシンをチームと共有するには、Settings から明示的に共有を有効にします。共有されていないマシンは他のメンバーのマシン一覧に表示されず、そのマシン上の会話が他のメンバーのサイドバーに表示されることもありません
- 「他の人のワークスペースに参加すること」と「自分のマシンを使うこと」が完全に切り離されたため、迷うことなくチームメンバーを招待できます

### 🔐 1 つのコマンドでどのマシンからでもサインイン

- 非対話型の CLI 認証に対応しました。どのマシンでも `lody login --auth <api-key>` で接続できるほか、`lody start --auth <api-key>` でログインと起動を 1 ステップで行えます
- Electron デスクトップアプリに、CLI API キーを生成・コピーできるアカウント設定パネルを追加しました

### 🆕 Full Access モード

- ネイティブのフルアクセスモードを持たないエージェント（Kimi や OpenCode など）向けに、権限リクエストを自動承認する新しい「Lody Full Access」モードを追加しました

### 🤖 エージェント連携の拡充

- OpenCode および Kimi との連携を強化しました
- Kimi のターミナル実行、ファイル読み取り、編集通知に関する履歴の解析と表示を修正しました

### 📱 モバイル体験

- ソフトウェアキーボードの挙動を刷新し、キーボード表示時に UI 全体が押し上げられるのではなく、入力エリアのみが滑らかなトランジションで上に浮かぶようになりました
- モバイルキーボードのチャット入力欄に、メッセージを送信できる「送信（Send）」キーが表示されるようになりました
- iOS Safari で下部のコントロールが見切れる不具合、およびトースト通知と招待ページのセーフエリアに関する不具合を修正しました

### 🚀 パフォーマンスと起動

- 再訪ユーザーの起動時に画面が真っ白になる現象を解消し、ネットワーククエリによって UI がブロックされなくなりました
- 長い会話の検索インデックス作成を遅延かつインクリメンタル実行に変更し、会話終了時のカクつきを解消しました
- コールドスタートのコストを削減するため、同期サービスのキャッシュを追加しました

### 🌐 ブラウザー互換性

- サポート対象を Safari 14+ / Chrome 80+ / Firefox 78+ に拡大し、古いブラウザーで正規表現や ESM の読み込みエラーにより画面が真っ白になる問題を解消しました

### 🛠️ その他の修正

- Docker コンテナーがホストのマシン ID を再利用してイベントストリームが競合する不具合を修正しました
- Worktree の作成時に、選択した非デフォルトブランチを再利用するようにしました
- デスクトップアプリで GitHub インストールリンクを外部ブラウザーで開くようにしました
- Electron 版で再サインインした際にワークスペースが 404 になる不具合を修正しました
- セッションサイドバーの切り替えボタンの位置をヘッダーと揃えました
- 各 VS Code テーマにおける Switch トグルのコントラストを改善しました
