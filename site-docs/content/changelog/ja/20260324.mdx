### 新機能と機能強化

- JSON、Markdown、添付ファイル、使用量統計を含むセッションデータをエクスポートできる新しい `lody export` CLI コマンドを追加しました。**来週、新しい同期バックエンドへ切り替える予定であり、従来の履歴データは互換性がなくなるため、残しておきたいデータは事前にエクスポートしてください**
- すべての ACP エージェントで、カスタムのタイトル生成モデルに対応しました
- セッションが承認待ちの間、権限リクエストバナーが入力欄の上に固定表示されるようになり、スクロールしても見失わなくなりました
- マシン選択（Machine Picker）を Agent Config ドロップダウンから分離し、マシン単体で選びやすくなりました
- チャット内のファイルパスをクリックした際、ファイル全体が正しく開くようになりました

### プラットフォームと UI 体験

- 狭い画面でもセッション設定ボタンが押しつぶされたり見切れたりしなくなりました
- モバイル環境で、チャット入力下部のエリアがボタンを押しつぶさずに適切に折り返されるようになりました
- モバイル環境の使用量グラフと統計カードが、横スクロールやはみ出しなしで小さな画面に収まるようになりました

### 修正と安定性の向上

- ACP エラー発生時に、具体的な根本原因を表示するようになりました
- 利用可能なキーリングバックエンドを自動検出することで、Sway、Hyprland、Niri などの GNOME 以外の Linux 環境におけるデスクトップ認証の失敗を修正しました
- 空のリモートリポジトリで worktree の作成に失敗する不具合を修正しました
- 大量のファイルが変更された際に `git show` が同時に多数実行されて CPU がスタックする不具合を修正しました
- `#` メンションでキャッシュの更新に失敗した際、古い Issue や PR のメタデータが再利用されてしまう不具合を修正しました
