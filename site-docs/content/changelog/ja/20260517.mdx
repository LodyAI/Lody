### 新機能

- リモートデバイスからローカルプロジェクトの Git ブランチを確認し、直接ワークツリーを起動できるようになりました。

### 修正と改善

- 外部の ACP エージェントからインポートしたセッションのアバターが正しく表示されない問題を修正しました。
- Claude セッションがアイドル状態のまま動かなくなることがある問題を修正しました。
- スラッシュコマンドの検索結果の並び順が正しくない問題を修正しました。
- セッション履歴のインポート時に重複したエントリが作成されることがある問題を修正しました。
- モバイルアプリでのメールログイン中に意図しないリダイレクトが発生する問題を修正しました。
