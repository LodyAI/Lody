### 新機能

- Codex 5.6 に対応し、更新された推論負荷（reasoning effort）オプションを追加しました。
- デバイスがオフラインの状態でもローカルプロジェクトを削除できるようになりました。

### 修正と改善

- セッションが無効な状態になることがある問題を修正しました。
- サブエージェントのタスクリスト表示を改善しました。
- GitHub PR 操作の信頼性を改善しました。
