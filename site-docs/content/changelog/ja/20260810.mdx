Version 0.77.2

### ✨ 新機能

- 入力欄（コンポーザー）へのファイルの貼り付け、およびドラッグ＆ドロップによるアップロードに対応しました。
- チャット内の画像と単体の画像ファイルの両方を、開いて拡大・縮小およびパン操作できるようになりました。デスクトップ版では、コンテキストメニューからコピーや保存も行えます。
- Agent の認証が期限切れになった際、セッションを作り直すことなく Lody アプリ内で再認証できるようになりました。
- Agent のエラーを展開して詳細全体を表示し、ワンクリックで診断情報をコピーできるようになりました。モバイルでもエラー詳細をすべて確認できます。
- ワークスペースへの招待、参加承認、プライベートリソースの共有フローを改善し、共有可能なマシンやプロジェクトがない場合により分かりやすいメッセージを表示するようにしました。
- ローカルプロジェクトをインポートした後、Lody がそのプロジェクトを自動的に開くようになりました。
- モバイル Web でも課金設定にアクセスできるようになりました。

### 🐛 修正と改善

- ファイルツリーのスクロール時やセッション切り替え時におけるメインスレッドの負荷を大幅に削減し、大規模なプロジェクトでの操作、セッションの切り替え、右サイドバーの再表示がよりスムーズになりました。
- バックグラウンド同期、永続化、再接続による CPU およびメモリへの負荷を軽減しました。ネットワークの不安定さや単一の同期ルームの問題によって、ワークスペース全体で高頻度の再接続が連鎖的に発生する現象が起きなくなりました。
- ローカルセッションがアイドル状態になった後に同期失敗や Agent の返信遅延が発生することがある不具合、およびセッション復元時にブランチ情報が失われる不具合を修正しました。
- 実行中の Agent への送信に失敗したステアリング（割り込み指示）メッセージが滞留してしまう不具合を修正しました。即時に挿入できない場合、次の通常ターン向けにキューへ追加されるようになりました。
- マルチワークスペース環境で Git 操作が別アカウントの認証情報を使用してしまう不具合と、ローカルブランチとリモートブランチが同名の場合に古いセッションの復元に失敗する不具合を修正しました。
- モバイル環境で Plan Mode の切り替えトグルが再び正常に動作するようになりました。
- メッセージのコピーボタンが反応しない不具合を修正しました。
- スマートフォンを横向きにした際もモバイルレイアウトを維持するようになり、ユーザーの操作なしに Web アプリがネイティブアプリを開こうとしないようにしました。
- モバイルドロワー内のドロップダウンエラー、統計表示の見切れ、Agent 名の途切れ、長すぎるプロジェクトパスがダイアログからはみ出す問題を修正しました。
- アプリのクラッシュ画面に読みやすいエラー内容が表示され、レポートをコピーできるようになりました。復旧に繰り返し失敗する場合は、確認ダイアログのうえでローカルデータを消去して再サインインできます。
