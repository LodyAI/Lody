Version 0.96.0

### ✨ 新機能

- デスクトップ上の Markdown ファイルリンクにコンテキストメニューを追加し、パスのコピー、ファイルを開く、アプリケーションの選択、Finder で表示する操作に対応しました。
- ランタイムとパフォーマンスの指標を確認できるデスクトップ向け開発者診断パネルを追加しました。

### 🐛 修正と改善

- ローカルプロジェクトのセッションプレビュー表示数をデフォルトで制限し、すべてのセッションを表示するオプションを追加しました。
- 公開後に共有リクエストカードを非表示にするようにしました。
- パブリックブラウザーにおいて、リダイレクト、履歴ナビゲーション、同一ドキュメント内ナビゲーション時に重複読み込みが発生する問題を修正しました。
- Word や PowerPoint などのアプリケーションからコピーした内容を貼り付ける際に、テキストが保持されるようにしました。
- Pi の移行案内を対応マシンでのみ表示するようにしました。
- 返信が完了するまでフォーク操作を非表示にするようにしました。
- 一部のエージェントのネイティブアドオンが macOS で読み込めない問題を修正しました。
- ローカルの Loro セッションへの参加に失敗した後の復旧とリトライ処理を改善しました。
- ダークテーマにおけるアーカイブ複数選択コントロールのコントラストを改善しました。
- タブを閉じた後に作成カードから開いた場合でも、該当の子セッションを正確に開き直すようにしました。
- 完了済みコンテンツを展開または折りたたむ際、閲覧位置を維持するようにしました。
- 会話内での Devin サブエージェントの表示方法を改善しました。
- フォローアップメッセージで対象セッションのモデルと実行設定を引き継ぐようにしました。
- 重複コールバックによる不正な状態を防ぐため、デスクトップのブラウザーログインを改善しました。
- 同梱されているエージェントランタイムのバージョンを更新しました。
