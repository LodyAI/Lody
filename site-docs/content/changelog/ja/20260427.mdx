### エージェント体験

- GPT-5.5 に対応しました
- Agent 設定ページを再設計し、新しいカテゴリーサイドバーと機能更新フローを追加しました
- DeepSeek プリセットを追加し、トークンを貼り付けるだけで素早くセットアップを完了できるようになりました
- Claude Code や Codex などのエージェントにおける接続の安定性と機能検出を改善しました
- macOS で Codex を使用した際に `ComputerUse` エラーのポップアップが表示されることがある不具合を修正しました

### デスクトップ体験

- 左サイドバーの折りたたみ、ドラッグによるサイズ変更、キーボードショートカットでの切り替えに対応しました
- ローカルプロジェクト、GitHub Worktrees、Chat セクションの表示を分かりやすく整理し、サイドバーの操作感をより一貫したものにしました
- セッション内のローカルファイル一覧が自動的に更新されるようになり、変更内容をリアルタイムで確認しやすくなりました

### 会話体験

- ストリーミング中のコードブロックで、シンタックスハイライト表示とプレーンテキスト表示がちらつく現象を解消しました
- セッションの初期化および切り替えの安定性を向上させ、まれに発生していた読み込み状態の取り違えを軽減しました

### その他の修正

- リモートプロジェクトでローカル検出が誤ってトリガーされなくなりました
- マシンのオンライン状態とリアルタイム同期の精度を向上させました
- Electron 内の CLI 出力エリアにおける下部の余白を修正しました
