バージョン 0.115.0

### ✨ 新機能

- 暗号化ワークスペースで GitHub への接続が可能になり、プッシュ通知、ライブアクティビティ（Live Activities）、受信トレイ（inbox）クライアントに対応しました。暗号化セッションでもプロンプトのショートカットを利用できます。
- マシンが所有する履歴を含め、Roost の会話履歴を暗号化ワークスペースに保存し、ワークスペースの各クライアントからアクセスできるようになりました。既存の OSS スナップショットを移行できるほか、リモート CLI を暗号化ワークスペースとペアリングすることも可能です。
- 暗号化ワークスペースの使用量および転送課金に関するガイドを確認できるようになりました。

### 🐛 修正・改善

- リカバリーファイルが正規のサイトオリジンに紐付けられるようになりました。メール招待には明示的な承認が必要となり、リカバリーの導線は暗号化ワークスペースにのみ表示されます。
- Auto delivery が信頼できるプルリクエストとチェック結果（check evidence）に基づいてのみ動作するようになりました。
- モデル固有のエージェント設定の読み込みと、Today、サイドバー、スヌーズ、モバイル表示に関する複数の問題を修正しました。
