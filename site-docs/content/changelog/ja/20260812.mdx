Version 0.78.0

### ✨ 新機能

- 公式の Grok ランタイムに対応し、Lody 内での対話や権限制御、コンテキスト使用量、レート制限の表示をサポートしました。
- 新しい 2 階層の `@` メニューにより、ファイル、Issue、プルリクエスト、スキル、セッション、コマンドを 1 か所に統合し、他のセッションへの直接参照も可能になりました。

### 🐛 修正と改善

- macOS および Linux でのメモリプレッシャーチェックを改善し、システムにまだ利用可能なリソースがあるにもかかわらずセッションの起動が誤ってブロックされるケースを減らしました。
- Electron デクトップアプリでズームアウトのショートカットが再び動作するようにしました。
- プルリクエストの説明を展開表示できるようになり、Agent の応答のレイアウト整列もより一貫したものになりました。
- 中国語などのマルチバイト文字がローカル接続のデータチャンクをまたぐ際に文字化けする不具合を修正しました。
- 依存関係のバージョンが正しく解決されない場合に、npm または npx 経由での Lody CLI のインストールが失敗する不具合を修正しました。
- Web サイトのランディングページの読み込み速度、アセットサイズ、アクセシビリティを改善しました。
