Version 0.94.0

### ✨ 新機能

- サインインなしで閲覧できる読み取り専用リンクを使って、セッションおよび選択した子セッションを共有できるようになりました。
- 公開済みの共有をより簡単に管理できるようになりました。共有ステータスの確認、共有された子セッションの閲覧、共有サイドバーのサイズ変更、元の会話への移動が可能です。
- プロンプトショートカットの作成、編集、削除、共有が可能になり、`/` メニューから変数やコンテキストスコープ付きで呼び出せるようになりました。
- Bub を組み込みの ACP プロバイダーとして追加しました。
- 長い会話をウィンドウ単位で読み込み・復元するようにし、大規模なセッションを開く際の待ち時間を短縮しました。
- デスクトップアプリを正常に開けない場合に、CLI からアプリのローカルキャッシュをリセットできるようになりました。
- 会話内のファイルをシステムのネイティブ共有フローから共有できるようになりました。

### 🐛 修正と改善

- 共有ページの読み込み、圧縮履歴の読み取り、ナビゲーション、復旧処理を改善し、1 つのリクエストが失敗しても会話全体がクラッシュしないようにしました。
- 共有ページのサインインメッセージ、会話ツリーの接続線、タイトルの階層構造、サイドバーのレイアウトを修正しました。
- セッション復旧、履歴同期、中断されたコンパクションからの復旧、アーカイブ済みセッションの扱いを改善しました。
- Windows のセッションパス、アーカイブされた worktree、共有マシンのプロジェクトナビゲーション、デスクトップでのサインインアカウント確認を修正しました。
- ワークスペース単位の下書き保存、キュー内メッセージ編集時のフォーカス、ターミナルタブの状態管理、大きすぎる貼り付けに対する分かりやすいフィードバックにより、プロンプト入力を改善しました。
- ACP 互換性、Grok のデフォルト設定、DeepSeek Harness の動作、組み込みエージェントの使用量集計を改善しました。
- モバイルで実行中エージェントの経過時間を表示するようにし、フォントサイズ設定と複数画像添付のレイアウトを改善しました。
- ギフトサブスクリプションの期限切れ後のチェックアウト復旧を修正しました。
- 任意の注釈データが存在しない場合にプレビューページの読み込みに失敗する問題を修正しました。
- 小さなウィンドウやセーフエリア内にメニューが収まるようにし、macOS でのアーカイブ項目の重なりを修正しました。
- ACP の動作、セッション復旧、タスク制御、入力処理、ランタイム互換性、デスクトップインターフェースの改善に貢献いただいた外部コントリビューターの @gu18168、@EYHN、@UniversePeak、@Astro-Han、@lawvs、@VeraPyuyi、@liuxiaocs7 の皆さまに感謝いたします。
