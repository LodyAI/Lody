### 破壊的変更と移行について

- アップデート後、再度サインインが必要になる場合があります。
- GitHub Worktree を使用している場合、エージェントを実行するマシンに（`gh auth` 経由で）ご自身の GitHub アカウントが設定されている必要があります。設定されていない場合は、デフォルトで `lody` アカウントを使用して Pull Request が作成されます。
- Lody は新しい同期エンジンおよびデータ構造へ移行しました。これまでのワークスペースは利用できなくなるため、新しくワークスペースを作成して Lody をご利用ください。
- Lody はユーザーの GitHub 個人 ID 権限を要求しなくなりました。それに伴い、同じ GitHub リポジトリを一度承認して複数のワークスペース間で共有する機能は終了し、1 つのリポジトリは 1 つのワークスペースにのみ紐付けられるようになりました。

### ✨ マルチタブセッション

1 つのセッション内で複数の会話タブやファイルビューアーを開けるようになりました。VS Code のタブバーのように、左側でエージェントとチャットしながら右側でファイルや差分を閲覧でき、互いの作業を妨げません。子タブは親タブの作業ディレクトリを引き継ぎ、ドラッグによる並び替えや名前の変更にも対応しています。

### 💬 行単位の差分コメント

Diff Viewer 内で直接コメントを追加できるようになりました。Markdown 記法、スレッド返信、スレッドの解決済みマーク、GitHub との同期、会話ウィンドウへのワンクリック送信に対応しています。

### 🎨 UI 改善と VS Code テーマ対応

- VS Code テーマとの互換性を追加し、優れたオープンソーステーマ（Vitesse、Gruvbox Material、Tokyo Night、One Dark Pro など）を標準で複数組み込みました。素晴らしいテーマを公開されているオープンソース開発者の皆さまに心より感謝いたします！

- Markdown のレンダリングおよび差分の読み込み体験を改善しました
- 会話内検索を追加しました

### 🖥️ デーモンモード

CLI がデーモンモードに対応し、自動再起動付きで Lody をバックグラウンドで常駐実行できるようになりました。

```bash
lody daemon start     # バックグラウンドデーモンを起動
lody daemon status    # ステータスを確認
lody daemon logs      # ログを表示
lody daemon stop      # デーモンを停止
```

### 🔗 GitHub 連携の改善

- PR の CI チェックステータスがセッション UI へリアルタイムに同期されるようになり、ビルド結果を確認するために GitHub へ切り替える必要がなくなりました
- PR に紐付いたセッションで、自動コミットおよび自動プッシュに対応しました

### 🌐 同期と安定性

- 信頼性向上のため、同期エンジンを刷新しました
- Linux コンテナー環境でのロックアップを防ぐため、cgroup を考慮した CLI リソース制限を導入しました
- リソース節約のため、ACP のアイドルタイムアウトを 30 分に短縮しました
- メモリ逼迫時にセッションを自動的に退避（エビクション）する仕組みを追加しました

### 🛠️ 修正と改善

- Google、Apple、Discord によるサードパーティサインインを追加しました
- 差分の読み込みおよび同期に関する不具合を修正しました
- GitHub 認証トークンの更新タイミングを修正しました
- Safari 16.4 未満での起動時クラッシュを修正しました
- モバイル UI の各種レイアウト不具合を修正しました
- CLI の不要なログ出力とディスク使用量を削減しました
- セッションの初期タイトルとして「Untitled」ではなくプロンプトの冒頭部分を使用するようにしました
