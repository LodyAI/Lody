### エージェント体験

- Codex Fast Mode のクイックトグルを追加しました
- Claude Think Level の選択機能を追加しました
  <img src="/_docs-assets/fast-think.png" alt="" />
- 権限リクエストカードを改善しました。長いボタンが折り返せるようになり、長いコマンドも展開して全文を確認できるため、承認前にエージェントが実行しようとしている内容を把握しやすくなりました

### 新しいマシンおよびエージェント設定

- エージェント設定をマシンごとに管理するようにしました。マシンを切り替えると、そのマシンで利用可能なエージェントのみが表示されるため、実行できない設定を誤って選択するのを防げます
- Settings がマシン一覧＋マシン詳細のレイアウトになり、オンライン状態、CLI バージョン、共有状態を確認できるようになりました

### 組み込みの GitHub PR ワークフロー

- セッション上部の PR バッジをクリックすると Lody 内で PR パネルが開き、タイトル、説明、ブランチ、CI、コメント、レビューを確認できます
- Lody 内で直接、PR へのコメント、PR のマージ、マージ後のブランチ削除を行えます
  <img src="/_docs-assets/PR-panel.png" alt="" />

### モバイル体験

- モバイルキーボードで Enter キーを押したときの動作（「メッセージを送信」または「改行を挿入」）を設定できるようになりました
  <img width="400px" src="/_docs-assets/20260422-keyboard-option.png" />
- セッション一覧で左スワイプによるアーカイブに対応し、アーカイブ一覧では左スワイプによる復元または完全削除に対応しました
- アーカイブ済みのセッションを開いた際、上部メニューに再度「Archive」ではなく「Restore」と「Permanently Delete」が正しく表示されるようになりました
  <img width="400px" src="/_docs-assets/mobile-swipe.png" />

### 会話内検索とキュー内のメッセージ

- 会話内検索バーのデザインを刷新し、ヒット件数、該当なしの状態、前へ／次への操作をより分かりやすくしました
- 長いセッションで検索結果へのジャンプが動かなくなることがある不具合を修正しました
- キューに溜まった複数のメッセージが画面全体を占有しないよう、高さを制限してリストをスクロールできるようにしました

### チームと招待の管理

- ワークスペースを切り替えた後、保留中の招待一覧が正しく更新されるようになりました
- 管理者が保留中のチーム招待を取り消せるようになりました

### その他の修正

- フロントエンドで生成した CLI トークンでサインインに失敗することがある不具合を修正しました
- マシンの公開状態の変化や同期の揺らぎによってサイドバーのリポジトリ順がばらつく不具合を修正しました
- バックグラウンドからの復帰時、ウィンドウへの再フォーカス時、またはオンライン復帰時に、ブラウザーがサインイン状態を再検証するようになりました
- 同期が一時的に遅れている場合にセッション作成とタスク送信が自動的にリトライされるようになり、新しいタスクが詰まるケースを減らしました
