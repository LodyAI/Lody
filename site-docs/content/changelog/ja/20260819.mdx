バージョン 0.83.0

### ✨ 新機能

- Kimi Code を改善し、バックグラウンドタスク、サブエージェント、トークン使用量のトラッキングに対応しました。
- デスクトップのオンボーディングフローを刷新しました。初回起動時にイントロシーケンスとプロダクトツアーが表示され、テーマや言語の選択、マシンにインストール済みのエージェントの検出、最初のセッションの案内を行います。
- エージェントがワークスペースの MCP サーバーを代わりに設定できるようになりました。

### 🐛 修正・改善

- オフライン時やリモートリポジトリに到達できない場合に、セッションのワークツリー復元に失敗する問題を修正しました。
- CLI がリリースされたバージョンと一致しないバージョンを報告する問題を修正しました。
- dsh の互換性に関する問題を修正しました。
- dsh エージェントの思考プロセスの表示方法を改善しました。
