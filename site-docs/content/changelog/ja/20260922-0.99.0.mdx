バージョン 0.99.0

### ✨ 新機能

- iOS の外観（Appearance）設定で Aqua アプリアイコンを選択したり、デフォルトのアイコンに戻したりできるようになりました。

### 🐛 修正と改善

- アップグレード後に古いランタイムキャッシュが原因で起動に失敗する不具合を修正しました。必要に応じて対象のランタイムを再ダウンロードして検証します。
- ランタイムキャッシュのクリーンアップやアップデート確認が失敗した場合でも、他のランタイムを中断することなくアプリを起動できるようにしました。
