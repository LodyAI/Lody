### 修正と改善

- モバイルの入力欄でメンション候補を正しく選択できるようになりました。
- GitHub リポジトリの連携に失敗する問題を修正しました。
- モバイルでローカルプロジェクトのフルネームが表示されるようになりました。
- ACP エージェントの起動時に環境変数 PATH が欠落していた問題を修正しました。
- フォントの読み込みに関する問題を修正しました。
- iPad のソフトウェアキーボードが入力欄を覆い隠してしまう問題を修正しました。
- モバイルのサブタブスライダーの位置がずれる問題を修正しました。
- 起動時の接続速度を改善しました。
- Pull Request ビューで認可の有効期限が切れてしまう問題を修正しました。
