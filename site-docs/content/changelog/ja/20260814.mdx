Version 0.81.0

### ✨ 新機能

- DeepSeek Harness の組み込みサポートを追加し、DeepSeek API キーの直接設定、Agent プリセット、セッション内での Lody MCP アクセスに対応しました。
- Agent によって作成された独立セッションや子セッションが、作成元のセッション配下にグループ化されるようになり、双方向の関係性の詳細確認やクイック移動が可能になりました。

### 🐛 修正と改善

- 長い会話やストリーミング応答時のスクロール追従を改善し、少し上にスクロールした後に意図せずジャンプしてしまう現象を軽減しました。
- 狭画面モバイルにおける設定画面のレイアウト、区切り線、アクションボタンの視認性を改善しました。
- パスの大文字・小文字や Unicode 正規化の違いがある場合、またはファイル名に特殊文字が含まれている場合に、ワークスペースファイルのプレビューや保存に失敗することがある不具合を修正しました。
- Linux KDE デスクトップ環境でタスクバーアイコンが正常に表示されるようにしました。
