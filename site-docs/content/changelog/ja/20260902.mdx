バージョン 0.89.4

### ✨ 新機能

- カスタムACPプロバイダー向けの対話型認証フローを改善しました。
- セットアップ中に問題が発生した際の状態表示と復旧手順をわかりやすくし、デスクトップ版の初回起動体験を改善しました。

### 🐛 修正と改善

- 複数ターンのセッションにおいて、エージェントのロール、設定、状態に不整合が生じる問題を修正しました。
- 「All Changes」に現在のローカルワークツリー外のコンテンツが含まれてしまう問題を修正しました。
- インストールに失敗したにもかかわらずデスクトップ版のアップデーターが成功と報告する問題を修正しました。
- セッションおよびタスク一覧のローディングスケルトンを改善し、プルリクエスト修復プロンプトをローカライズしました。
- 本番プレビューの接続で誤った環境ドメインが使用される問題を修正しました。
- 内蔵の Claude Code ランタイムを更新しました。
- 外部コントリビューターの audichuang と ImSingee に感謝します。
