Version 0.95.0

### ✨ 新機能

- マネージドな組み込み Pi エージェントを追加しました。既存の Pi プロバイダーを移行する際は確認が表示され、設定と保存済みの履歴が保持されます。移行後は以前の Pi セッションを再開できないため、新しいチャットを開始してください。
- 承認されたセッション共有の結果を MCP エージェントへ直接返すようにしました。
- ローカル CLI から Devin を起動できるようになりました。
- ワークスペース共有セッションの終了と復旧をより確実に行えるようにしました。

### 🐛 修正と改善

- Lody に同梱された Node で実行することで、一部の Node バージョンにおいて DeepSeek Harness が起動しない問題を修正しました。
- アプリがバックグラウンドから復帰した際に、iOS の画面がまれに真っ白になる問題を修正しました。
- 中断、復旧、バックグラウンドプリフェッチ、ストリーミングの動作を改善し、下書きの消失や会話全体の失敗を減らしました。
- 共有リクエスト、プロバイダー設定、エラー復旧、アーカイブの動作を改善しました。
- ツール入力の JSON が Markdown の数式として誤認識される問題を修正しました。
