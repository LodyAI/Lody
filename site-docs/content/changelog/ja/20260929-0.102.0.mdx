Version 0.102.0

### ✨ 新機能

- 会話内でPDFファイルを直接プレビューできるようになり、ページ移動、ズーム、テキスト検索に対応しました。
- 設定にプロンプトショートカット（Prompt Shortcuts）を追加しました。
- メッセージ内の会話リンクがクリック可能な会話チップとして表示されるようになり、関連する会話へ移動しやすくなりました。

### 🐛 修正と改善

- 同期遅延を減らすことでメッセージ送信の応答性を向上させました。画像メッセージの送信時もプレビュー位置が維持され、レイアウトのずれを抑えています。
- デスクトップ版とモバイル版で保存済みのテーマを適用した状態で起動するようになり、ライトテーマとダークテーマの切り替え時のちらつきを減らしました。
- デフォルトのエントリからアプリを開くと、すぐに新しい会話を始められるチャットランディングページが表示されるようになりました。
- メンションメニューとコマンドメニューが入力カーソル（キャレット）に追従するようになり、テキストの折り返し、コンポーザーのスクロール、モバイルキーボードの表示時の配置を改善しました。
- スラッシュコマンド検索を改善し、プロンプトショートカットとエージェントコマンドに共通のランキングを適用して、名前が一致する項目を見つけやすくしました。
- Agentロールメニュー、サイドバー、選択オプションの配置を整え、テキストの見切れやボタンの重なりを修正しました。
- 会話内のMarkdownの配置、インライン数式のレンダリング、一部のツール呼び出しでコマンドが重複表示される問題を修正しました。
- システムキーリングが利用できないLinuxマシンで、新規作成したCodexアカウントプロファイルにサインインできない問題を修正しました。
- ローカルプロジェクトが既存のGitおよびGitHub認証設定を保持するようになり、Agentロールを通じたマシン間のタスク振り分けも改善しました。
