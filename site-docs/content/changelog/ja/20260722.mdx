### 新機能

- ローカルファーストのアーキテクチャをアップグレードしました。デスクトップ版ではオフライン時でも、既存のローカルプロジェクトやセッションを起動・閲覧し、そのまま利用を続けられます。
- ローカルの会話では、トンネルを設定することなく Design モードで Web ページを直接プレビューできます。
- 他の Lody 会話の作成、読み取り、管理を行う Agent による操作機能を追加しました。
- Kimi Code プロバイダーの組み込みサポートを追加しました。
- 会話の初期化速度を向上させました（特にローカルプロジェクトで高速化しています）。
- GitHub プロジェクトの UI と UX を改善し、会話アクションバーのアクションを拡充しました。
- インターフェースおよびターミナルのフォントをカスタマイズできるようになりました。

### 修正と改善

- 使用状況チャートの表示を改善しました。
- オフライン使用時、接続が不安定な状態、およびネットワーク復旧時に、ローカルセッションが停止したり、再接続を繰り返したり、思考中のまま固まったりする不具合を修正しました。
- Lody を長時間起動したままにした後、ログインセッションが期限切れになることがある不具合を修正しました。
- 入力欄（コンポーザー）での元に戻す（Undo）とやり直し（Redo）が機能しないことがある不具合を修正しました。
- 全体的なインターフェースとユーザー体験をブラッシュアップしました。
