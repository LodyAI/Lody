バージョン 0.82.0

### ✨ 新機能

- ローカルプロジェクト向けの Git ワークフローを追加しました。承認済みの Lody GitHub 連携がある場合は、GitHub PR ワークフローも利用できます。
- サイドバーからコンポーザーへセッションをドラッグして、自動的に @ メンションを挿入できるようになりました。
- 並行したアプローチを試せるよう、セッションを新しいワークツリーにフォークできるようになりました。
- グローバル MCP 設定を追加し、会話の作成時にプラスボタンのメニューから選択できるようになりました。
- コンポーザー内の @ メンションがチップとして表示されるようになり、セッションやスキルを参照しやすくなりました。
- diff ファイルのタイトルに「パスをコピー」と「ファイルを開く」アクションを追加しました。
- 期間を選択できる使用状況トレンドビューを追加しました。
- サブスクリプションと引き換えコードを併用して適用できるようになりました。

### 🐛 修正・改善

- ストリーミング中の会話におけるスクロール追従、ターミナルのコピー/ペースト、テキスト選択を改善しました。
- モバイルの階層リストを含め、子セッションのナビゲーションと表示を改善しました。
- ワークスペースのクリーンアップ、セッションの起動、接続復旧におけるいくつかの信頼性の問題を修正しました。
- サイドバーとページ遷移のパフォーマンスを最適化し、不要な UI 更新を削減しました。
