バージョン 0.106.0

### ✨ 新機能

- ターンのポップオーバーに所要時間と稼働状態を表示できるようになりました。
- 選択した数式を LaTeX 形式でコピーできるようになりました。
- モバイル版のサブスクリプション利用枠ウィジェットを追加しました。

### 🐛 修正と改善

- セッションリソースが解放されていない場合に自動リトライするようになり、ターン全体の失敗を減らしました。
- GitHub 認証情報の取得タイムアウトをより現実的な値に調整し、断続的な失敗を減らしました。
- 一時的なアクセス失敗によってセッションのディスパッチが停止してしまう問題を修正しました。
- メッセージのフェーズメタデータがない Codex タイトルを受け入れるようにしました。
- 権限オプションをよりコンパクトで読みやすい表示に改善しました。
- 確認前に Roost メッセージの表示位置を固定し、画面がガタつくのを防ぐようにしました。
- スキルをトリガーする記号として半角の円記号（¥）に対応しました。
- オープンソースライセンス表記ダイアログのスクロール機能を修正しました。
- チェンジログの箇条書きスタイルを修正しました。
