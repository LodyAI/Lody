バージョン 0.111.0

### ✨ 新機能

- セッションの自動化機能で URL の確認やローカルコマンドの実行ができるようになり、外部条件が満たされたときにタスクを続行できるようになりました。
- エージェントが対象セッションでの待機を登録、確認、またはキャンセルすることで、セッションをまたいだ自動化を管理できるようになりました。
- 会話内に Mermaid 図がインラインで表示されるようになりました。
- 同じマシン上で使用する添付ファイルがローカルに保持されるようになり、エージェントが元のファイルを直接読み取れるほか、画像の送信時にリモートアップロードの完了を待つ必要がなくなりました。
- 元のコンピューター上ではローカル画像を直接プレビューできます。別のデバイスでは、そのコンピューターからローカル添付ファイルをダウンロードでき、コンピューターがオフラインの場合を含め、ファイルが利用できない理由も確認できるようになりました。
- エージェントが現在のセッション、ロール（Role）、親セッション、および起点セッションを識別できるようになり、より正確に連携を進められるようになりました。
- Claude、Kimi、Pi、および DeepSeek Harness アダプターが、追加指示や上書きを含む標準の ACP セッションシステムプロンプトに対応しました。

### 🐛 修正・改善

- プロバイダーによってロール（Role）に固定されたモデルまたは権限モードが削除された場合、選択後にエラーになるのではなく、利用できない理由がロールに表示されるようになりました。
- ロール（Role）の概要に機能ラベルが表示されるようになり、対応している機能をより簡単に把握できるようになりました。
- カスタムサービスエンドポイント向けのローカルプロバイダーサインインおよび API キー入力を復元しました。
- Lody Agent のセットアップを改善しました。選択したサインイン方法が対象マシンに正しく届き、セットアップ完了前にカスタムエンドポイントを設定できるようになったほか、サインインをキャンセルすると待機が速やかに終了します。
- モデルカタログが予期せず空になった場合に再プローブを実行し、選択中のモデルを保持したうえで、検証を誤って通過させるのではなく利用可能なモデルがないことを報告するようにしました。
- マシンのプレゼンス情報が更新中のとき、新しいタブで既知のエージェントが利用不可になる不具合を修正しました。
- Claude advisor ツールの実行結果が正しく完了しない不具合を修正しました。
- 組み込みの Codex ランタイムを 0.166.0 に、Claude Code を 2.1.321 にアップデートしました。
- 組み込みの Devin ランタイムを 3000.12.28 に、DeepSeek Harness を 0.2.2-rc.1 にアップデートしました。
- 長い返答を読みやすくするため、DeepSeek の思考プロセスをデフォルトで折りたたむようにしました。
- エージェントのバックグラウンドタスクが実行中の間もセッションのアクティビティ状態が正確に保たれるようになり、完了と早まって表示されるケースを減らしました。
- 起動に失敗した後もセッションコンテキストが保持されるようになり、再試行しやすくなりました。
- エージェントセッションを終了しても、手動で開いたターミナルが閉じられないようになりました。
- 古いデスクトップスナップショットが現在の状態を上書きしてしまう問題と、会話の更新中に状態変更が繰り返される不具合を修正しました。
- ホーム画面で、完了済みの未読セッションが未読として明確に表示され、ドラフトプルリクエストには専用のアイコンが使用されるようになりました。
- サイドバーにローカルセッションのブランチを表示し、ディレクトリを共有するセッションについては誤解を招く独立したブランチ情報を非表示にするようにしました。
- 関連する会話のタブが多数ある場合、タブが押し潰されるのではなく横スクロールするようにしました。
- デスクトップ版の終了確認とキャンセル処理を改善して待ち時間を短縮し、サイドパネルやターミナルを閉じた後にリソースが速やかに解放されない不具合を修正しました。
