### 新機能

- Lody が Codex および Claude Code のローカルプロジェクト会話履歴を同期できるようになりました。Settings → Projects から同期の実行や既存履歴のインポートを行えます。
- Lody で開始した新しいローカルプロジェクトの会話も Claude Code や Codex へミラーリングされるため、履歴を双方向で一致した状態に保てます。
- デスクトップに実行中の CLI を終了できる Stop ボタンを追加しました。

### 修正と改善

- モバイル画面で UI の一部がビューポート外にはみ出す不具合を修正しました。
