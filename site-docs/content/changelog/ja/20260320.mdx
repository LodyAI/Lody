### 新機能と機能強化

- チャット入力でスラッシュコマンドに対応しました。`/` を入力すると、`review`、`compact`、`undo` などエージェントが公開しているコマンドを一覧表示して挿入できます
<img src="/_docs-assets/slash.png" alt="" />
- エージェント設定オプションを動的に読み込むようになり、利用可能なすべてのモードとモデルオプションを表示できるようになりました。アップグレード後は Agent Config ページでオプションを更新（リフレッシュ）してください

### 修正と安定性の向上

- Windows デスクトップアプリでメールアドレスを入力した際に画面が真っ白になる不具合を修正しました
- 期限切れになったローカル CLI サーバー接続が回復できなくなる不具合を修正しました
