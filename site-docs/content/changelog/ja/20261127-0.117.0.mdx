バージョン 0.117.0

- 繁体字中国語・日本語・韓国語・スペイン語・フランス語・ロシア語の 6 つの UI 言語を追加しました。
- セッションをまたいだ権限記憶と同期可能なデフォルト権限設定を追加しました。サイドバーのタスクをチームメンバー別に絞り込めるようになり、メンバー追加メニューのアバター表示やスクロール時のワークグループ要約ヘッダー固定にも対応しました。
- デスクトップ版 Today ウィンドウのサイズ・位置を記憶するになり、グローバル表示切り替えショートカットに対応しました。
- モバイル版で会話の画像共有、Markdown テーブル・コードブロック・チャットカードからの引用、現在ディレクトリの新規タブをローカル下書きとして開く操作に対応しました。また iOS のメニューちらつき、フォアグラウンド復帰、Share Extension の入力挙動を修正しました。
- プライバシー設定でテレメトリの即時オプトアウトと統合された利用状況共有スイッチ、地域別の Cookie 通知に対応しました。
- メールサインインの画面遷移時にフォーカスが奪われる問題と、認証済みメールでのサインイン時に認証ページへ自動リダイレクトされる不具合を修正しました。
- 暗号化ワークスペース作成、デバイスペアリング、鍵リカバリ、メンバーへの鍵配送を強化し、より分かりやすい案内とエラーメッセージを追加しました。
- Loro を 1.19.1 にアップグレードしてデーモンおよびレンダラーのメモリ予算を改善。永続デーモン Streams ルーム用のワークスペース WebSocket トランスポート、CLI `restore-id` コマンド、委任チェーン上限の表示を追加しました。
