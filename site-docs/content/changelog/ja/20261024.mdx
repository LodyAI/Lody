バージョン 0.108.1

### ✨ 新機能

- 「Now」と「This Week」ビューを備えた新しい会話ホームを導入しました。対応待ち・実行中・最近完了した会話を、最近の作業やエージェントプランの使用状況とあわせて確認できます。
- プロジェクトごとにデフォルトの MCP ツールを設定できるようになりました。新しい会話ではプロジェクトの設定が引き継がれ、送信前に調整できます。
- All Changes で、ブランチの累積変更に加えて「Uncommitted（未コミット）」ビューを利用できるようになり、比較ベースも表示されるようになりました。
- ワークスペース紹介報酬機能を追加しました。紹介リンクの共有、報酬残高と履歴の確認、対象クレジットのサブスクリプションへの適用が可能です。期間限定の紹介キャンペーンにも対応しています。
- エージェントの完了通知に返信の抜粋が含まれるようになり、会話を開かずに結果をプレビューできるようになりました。
- OpenCode V2 を追加し、複数の ACP エージェントを更新しました。
- スケジュールタスクのプロンプト入力欄が内容に応じてウィンドウの高さの約半分まで自動で広がるようになり、長い指示を編集しやすくなりました。
- アクティブな子会話がある会話をアーカイブする際、子会話の数と実行状況を確認したうえで、子会話も同時にアーカイブするか現在の会話のみをアーカイブするか選択できるようになりました。
- ライトテーマ、サイドバー、ログインページを刷新し、招待・デバイス認証などの関連ページのレイアウトを統一しました。また、起動時やページ遷移を改善し、このデバイスで最後に成功したサインイン方法を示すインジケーターを追加しました。

### 🐛 修正と改善

- 会話とタブの切り替え処理を改善し、長い会話・ストリーミング出力・履歴読み込み時の引っかかりを軽減しました。
- サブエージェントのツール出力が大量にある会話の読み込みを改善しました。タスクの詳細はオンデマンドで読み込まれるようになり、不要な処理を回避します。
- 履歴の同期処理を改善して重複転送や不要な保存を削減し、特定の状況でメッセージ内容が重複する問題を修正しました。
- 再起動後に受信済みの同期更新の一部が失われる問題を修正し、ローカルデータの永続性と復旧性を向上させました。
- ストレージ障害発生後の同期復旧を改善して重複ダウンロードや過剰な通信量を抑え、ローカルデータベース接続が復旧できなくなるケースを修正しました。
- ネットワーク切断後の再接続処理を改善し、手動で再読み込みするまで会話の同期が止まってしまう問題を修正しました。
- ネットワーク障害時にデスクトップのセッション状態が失われる問題を修正しました。
- ディスク容量不足によりデスクトップの書き込みが失敗した場合、明確なメッセージを表示してそれ以上の UI 操作をブロックし、再起動または終了する前に空き容量を確保するよう案内するようにしました。
- CLI の異常終了時にエラーが繰り返されたり、ログが肥大化したり、終了できなくなったりする問題を修正しました。
- Windows 上のローカルエージェントが権限エラー後に「Connecting」のまま停止する問題を修正し、復旧ガイダンスを追加しました。
- 応答の遅延によってリトライが発生した際に、Lody MCP が重複した会話を作成してしまう問題を修正しました。
- エージェントがすでに返信した後もファイル変更の更新処理が続くことで、会話が完了処理中のまま残ったり、停止操作に時間がかかりすぎたりする問題を修正しました。
- 履歴の読み込み中にエージェントの質問カードが表示されないことがある問題を修正しました。また、回答待ちの間は作業時間がカウントされ続けないようになりました。
- 実行を辞退した後も、Claude の元のプランが引き続き表示されるようになりました。
- 異常な実行状態のために新しい入力を受け付けられない会話について、より明確なエラーメッセージと手動 CLI での復旧手順を追加し、キューに積まれた入力は保持されるようにしました。
- カスタム ACP エージェントの履歴同期、インポート、および競合処理が拒否される問題を修正しました。
- PR をマージまたはクローズしても会話が自動アーカイブされなくなり、後続作業が中断されるのを防げるようになりました。
- 会話のタイトルにエージェント設定やロールの指示を含めず、ユーザーの実際の入力内容のみを使用するようになりました。また、フォークした会話のタイトルに自動でプレフィックスが付かなくなりました。
- CLI または Lody MCP を通じてエージェントロール付きで会話を作成する際、表示されるユーザーメッセージや会話タイトルにロールの指示が含まれなくなりました。
- DSH のテキストとツール呼び出しが独立して表示されるようになり、ツールを折りたたんでも付随するテキストが隠れなくなりました。また、思考プロセスのタイポグラフィを改善し、古くなった委任モデルの警告を削除しました。
- Markdown ファイルプレビュー内の会話リンクが正しく開くようになりました。
- ネストされた Git ワークツリー内の相対ファイルリンクを修正しました。複数のファイルが一致した場合は、開くファイルを選択できます。
- シンタックスハイライトやスクロールバーの表示に加え、高さの低いウィンドウでのホームページのレイアウト、折りたたみコントロール、画面遷移を改善しました。
- 会話の共有コントロールを改善し、アクセス範囲、リンク公開、リンク管理を 1 つのパネルにまとめました。
- メンバーのアバター、スキル詳細、使用状況ビューを改善し、アバターのちらつき、メニューのフォーカス問題、および Windows のキャプションボタンによってスケジュールタスクの操作ボタンが隠れてしまう問題を修正しました。
- ワークスペースの境界線をスリムにし、macOS のタイトルバーとウィンドウボタンの配置を改善しました。
- iOS 16.4 における Web 起動エラーと diff ビューのテーマカラーを修正しました。
- DimCode アイコンを更新し、意味のある内容を含まない操作成功レシートを非表示にしました。
