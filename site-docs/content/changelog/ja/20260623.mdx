### 新機能

- サインインなしでレビューレポートを閲覧できるローカルコードレビューツール `lody review` を追加しました。
- セッションでプレビュー表示を含むあらゆるファイル形式の添付に対応しました。エージェントも添付ファイルを読み取ったり、ファイルを返送したりできます。
- コマンドの検索やセッションの素早い切り替えができる新しいコマンドパレット（⌘K）を追加しました。
- キーボードショートカット設定を追加しました。すべてのショートカットを競合検出付きでカスタマイズおよび再割り当てできます。
- キーボードのみで完全に操作できるデスクトップの Quick Session ウィンドウ（⌘⇧N）を追加しました。
- デスクトップのターミナルがアプリテーマに追従するようになり、VS Code 風の下部ステータスバーを備えました。
- セッションの「Open in」メニューで Xcode、Sublime Text、およびカスタムランチャーに対応しました。
- コンポーザーで `$` を使ってプロジェクトの Skill をメンションでき、新しい Skills ページから利用可能な Skills を一覧表示できます。
- ローカルプロジェクトを他のデバイスから削除できるようになりました。
- 会話の文字サイズ設定を追加しました。
- DeepSeek Reasonix プロバイダーを追加しました。
- デスクトップユーザーは CLI の自動起動を無効にし、Lody を純粋なリモートコントロールとして使用できるようになりました。

### 修正と改善

- All Changes 一覧のパフォーマンスを改善しました。
- プルリクエストに Draft ステータスバッジを表示するようにしました。
- 会話インターフェース全体で画像のアップロードが動作するようになりました。
- ワークツリースクリプトの読み込み待ちをなくすためキャッシュを追加しました。
- モバイルで AI の質問に回答する際、キーボードが回答 UI に重なって隠れてしまう問題を修正しました。
- モバイルでの長いモデル名の表示を改善しました。
- ストリーミング応答時の引っかかりとデバイスの発熱を軽減しました。
- macOS のフルスクリーンモードで Cmd+W を押した後に画面が黒くなる問題を修正しました。
- サイドバーの選択枠が途切れる問題と、タイムスタンプの前の余分な空白を修正しました。
- macOS におけるセッション内検索のショートカットを ⌘F に変更しました。
- モバイルのモデルピッカーで長いモデル名が読みやすくなり、メニューがキーボードに隠れないようになりました。
- タスクを手動で停止した際に、誤って「完了」通知が送信されないようにしました。
