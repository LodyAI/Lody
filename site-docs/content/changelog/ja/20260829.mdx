バージョン 0.88.1

### ✨ 新機能

- `@` メンションメニューのセッション候補がデフォルトで現在のプロジェクトに絞り込まれるようになり、必要に応じて全プロジェクトへ一時的に切り替えられるようにして、関連セッションを見つけやすくしました ([#109](https://github.com/LodyAI/Lody/pull/109))。
- デスクトップ版では、エージェントを選択する前にマシンの選択が必須となり、フロー全体でより分かりやすいガイダンスを表示するようにしました ([#151](https://github.com/LodyAI/Lody/pull/151))。

### 🐛 修正と改善

- 子タブの最初のメッセージが欠落したり、「同期中」のまま止まったり、タブを閉じられなくなったりする問題を修正しました ([#141](https://github.com/LodyAI/Lody/pull/141))。
- サイド会話とファイルまたは差分プレビューが重なって表示される問題を修正しました ([#135](https://github.com/LodyAI/Lody/pull/135))。
- デスクトップ版のオンボーディングツアーにおけるデータ分離を強化し、デモが誤って実際のワークスペースデータにアクセスしないようにしました ([#136](https://github.com/LodyAI/Lody/pull/136))。
- プロジェクトのターミナルが、Electron の起動や認証情報プロキシで使用される内部環境変数を継承しないようにしました ([#122](https://github.com/LodyAI/Lody/pull/122))。
- ターゲットステータス、タスク保存、Windows Git 診断に関する英語・中国語翻訳を補完し、欠落していたエージェント名を復元しました ([#59](https://github.com/LodyAI/Lody/pull/59))。
- このリリースへの公開コントリビューションについて、[@27Aaron](https://github.com/27Aaron)、[@ImSingee](https://github.com/ImSingee)、および [@natsustan](https://github.com/natsustan) の皆さんに感謝いたします。
