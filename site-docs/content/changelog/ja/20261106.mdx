バージョン 0.110.1

### ✨ 新機能

- Lody MCP がオンデマンドのコマンドヘルプを提供するようになり、ツール一覧に詳細な説明を繰り返さなくても、エージェントが使い方やパラメーターを調べられるようになりました。

### 🐛 修正・改善

- リモートコード diff の読み込みを改善し、重複する転送を減らすとともに大きなファイルをオンデマンドで読み込むようにしました。更新後も閲覧位置と展開したセクションが維持されます。
- 接続ステータスの更新時に選択中のリモートマシンが意図せず切り替わってしまう不具合を修正し、オフライン状態の表示を改善しました。
- プロジェクト編集中に選択したマシンが失われる不具合を修正し、デスクトップ版では空のプロジェクトグループを非表示にするようにしました。
- 会話の引用を改善し、同じ返答内の連続した箇所を選択する際にリンク、リスト、コードなどの書式が保持されるようになりました。
- 完了した返答の末尾コンテンツに対する折りたたみ表示を復元しました。
- 会話グループ名を変更した後、サイドバーが速やかに更新されない不具合を修正しました。
- コンポーザーでのメンション表示を改善し、キャレット境界での色の不具合や送信後にメンション状態が残る問題を修正しました。
- 暗号化セッションにおけるキュー送信メッセージの検証を改善し、共有権限の読み込み中にメッセージが誤ってブロックされる不具合を修正しました。また、CLI のペアリングおよび鍵状態に関するメッセージをより分かりやすくしました。
- Android パッケージでプッシュ設定が欠落し、通知が届かなくなる可能性があった不具合を修正しました。
