### Sonnet 4.6およびgpt-5.3-code-sparkへの対応

### ローカルプロジェクトへの対応

- 任意のローカルディレクトリをインポートし、リアルタイムで同期できるようになりました

<img src="/_docs-assets/20260223-local-project.png" width="300px" />

### CLIの起動とログイン体験の改善

- ワンクリックで起動できるようCLIの起動手順を簡素化しました
- Dockerモードを削除しました
- ローカルプロジェクトを管理するための `project` コマンドグループを追加しました
  - `npx lody project add [path]` lodyにローカルプロジェクトを追加します
  - `npx lody project list` ローカルプロジェクトの一覧を表示します
  - `npx lody project delete` ローカルプロジェクトを対話形式で削除します

### パフォーマンスと信頼性の修正

- ファイルの差分を開く際のUIの遅延を修正しました
- 一部のシナリオで発生する認証フローの問題を修正しました
