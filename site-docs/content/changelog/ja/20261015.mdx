Version 0.105.0

### ✨ 新機能

- 動画ファイルのプレビューを追加しました。
- 全画面画像プレビューで、対応デバイスにおいて長押しメニューから画像のコピー、保存、共有ができるようになりました。
- CSV、TSV、XLSXのプレビューで、列幅の調整およびセルや矩形範囲の選択・コピーに対応しました。XLSXプレビューでは行の高さの調整も可能です。
- モバイル版でHTMLファイルやチャット添付ファイルをデフォルトでプレビューモードで開くようになり、ソースを表示するオプションも用意しました。
- 会話の進捗状況とワークスペースのトークン使用量を確認できるiOSホーム画面ウィジェットを追加しました。
- メモリのインポートで、複数のIDを一度に選択して追加できるようになりました。
- DeepSeekでコンテキスト、モデル、権限、プリセット設定を保持したまま、ネイティブのセッション履歴を読み込んで再開できるようになりました。
- DeepSeekで実行中のステアリング（軌道修正）およびGoalsの設定、一時停止、再開に対応しました。
- DeepSeekでサブエージェントの照会・キャンセル、およびバックグラウンドタスクのステータス、再試行状況、現在のコンテキスト使用量の表示に対応しました。キャンセル可否は実行方法によって異なります。
- Piのサブエージェントツールで、サブタスクごとに利用可能なモデルを選択できるようになりました。
- Claude Codeを更新してHaiku 5.5に対応し、Codexではより大きなコンテキストウィンドウに対応しました。
- Codexで `/plan` の直後にタスクの説明を入力できるようになり、自動タイトル生成にはLodyで設定したタイトル用モデルとパラメータを使用できるようになりました。
- CLIおよびMCPによるセッションの作成と継続で、リモートマシン上のセッションへの送信を含め、ファイルおよび画像の添付に対応しました。
- CLIのセッション作成で `--agent-role <name or ID>` に対応し、ワークスペースロールのマシン、エージェント、モデル、プロンプト設定を使用できるようになりました。
- Cloud CLIに `migrate --from-oss` を追加し、OSS版のLoroセッション記録と過去の添付ファイルを既存のクラウドワークスペースへインポートできるようになりました。
- 分離されたワークツリーの作成後、最初のタスクでタスク内容に沿ったブランチ名を付けるようエージェントに指示が届くようになり、並行作業を識別しやすくなりました。
- 関連会話パネルにコラボレーションの停止および再開アクションを追加しました。メインセッションと子セッションを停止すると、後から返ってきたエージェント結果によって実行が再開されるのを防げます。コラボレーションの再開は手動で行う必要があり、オフラインのマシンには同期後に変更が適用されます。
- 連続して作成された子会話が、展開・折りたたみ・内部スクロール可能なコンパクトなタスクパネルにまとめられるようになりました。
- メッセージキューを折りたためるようになり、下書きを保持したまま準備中や送信失敗のメッセージ件数を表示できるようになりました。
- コンポーザーで実行マシンの詳細を確認できるようになりました。デスクトップ版ではマシン名にカーソルを合わせるかクリックすると所有者と接続ステータスが表示され、スマートフォン版ではアイコンボタンから詳細カードを開けます。
- デスクトップ版およびモバイル版のリモートディレクトリピッカーで、プロジェクトとして追加する前にフォルダーを作成して中へ移動できるようになりました。対象マシン側でこの機能に対応したバージョンのCLIが必要です。
- サイドバーの長いセッションタイトルが、ホバー時またはキーボードフォーカス時にスクロールするようになりました。ドラッグやトラックパッド、マウスホイールでタイトル全文を読むこともでき、アニメーションはシステムの「視差効果を減らす」設定に従います。
- クォータ照会に対応しているプロバイダーで、コンポーザー設定の切り替え時、クォータパネルを開いたとき、またはアプリに戻ったときに、必要に応じてサブスクリプションクォータを更新できるようになりました。
- 請求書の詳細に、請求理由、シート数の変更、明細項目、未払い残高、支払いへの導線が表示されるようになりました。
- ローカルのMagpie設定インポートを受け取るレシーバーを追加しました。完全なインポートフローにはMagpie側の対応も必要です。

### 🐛 修正と改善

- Codexセッションの作成または再開時に、選択したモデルの適用が間に合わない問題を修正しました。
- エージェントがモデル選択を拒否した場合に画面上で警告が表示されるようになり、切り替えの失敗を成功と誤認しなくなりました。
- 一部のACPエージェントにおけるモデル設定の適用順序を修正し、モデル切り替え後に推論量（reasoning effort）などのロールオプションがリセットされないようにしました。
- 継承された推論量やFastなどのオプションが誤ったモデルに対して検証される問題を修正しました。
- Agentロールを保存する際、有効な選択を保持したまま不要になった古い設定オプションをクリアするようになり、互換性に関する警告が残り続ける問題を減らしました。
- 継続、ステアリング、または復旧処理において、Agentロールのプロンプトを含むプロンプト内容が送信から配信の間に変化してしまう問題を修正しました。
- 詳細情報の変更時にAgentロールのメンションメニューで選択状態や表示位置が失われる問題を修正し、エージェント設定ダイアログのフォーカス枠表示を整えました。
- モバイル版でDimcodeの設定オプション同士が干渉する問題や、指を離した後に権限選択が失われる問題を修正しました。
- Dimcodeがマシンにインストール済みのコマンドと設定を使用するようになり、未インストールの場合はコピー可能なインストールコマンドを表示するようにしました。
- Ampアダプターが古いキャッシュ済みバージョンを繰り返し使用していた問題を修正し、対応するバージョンのバイナリを使用するようにしました。
- 一部のNode.jsバージョンでZIP配布エージェントのインストールが展開中に停止する問題を修正しました。
- 既存セッションの出力を含め、Piのコマンド出力で改行が欠落する問題を修正しました。
- Pi拡張機能で、スキャン完了前に保存済みのパッケージ名が表示されるようになり、読み込み失敗も分かりやすく報告されるようになりました。
- Codex履歴のインポートで添付ファイルが保持されるようになりました。他クライアントが保持中のセッション、サービスエラー、起動失敗、作業ディレクトリの問題に関するエラーメッセージも分かりやすくなりました。
- サービス再起動後に空のCodexセッションを再開できない問題や、過去のセッションのタイトル選択が不正確になる問題を修正しました。
- Codexがセッションを開く前に実際の実行ディレクトリに対する信頼設定を保存するようになり、明示的に信頼しないディレクトリを保護しつつ、プロジェクトのスキルやMCP設定の検出を改善しました。
- ClaudeのバックグラウンドBashタスクで、実際のコマンドがタスク説明と分けて表示されるようになり、シンタックスハイライトとコピーにも対応しました。
- 停止したバックグラウンドタスクのClaude履歴での表示方法を改善し、ユーザープロンプトとして誤表示されにくくしました。
- 再接続や遅延リトライの後にエージェントの完了メッセージが二重に処理され、重複実行が引き起こされる問題を修正しました。
- 複数のエージェントからの結果がバッチ処理されるようになりました。処理中のセッションは現在のターン終了後にまとめて受け取るため、個々の結果ごとの不要な継続実行が減ります。
- エージェントの連続委譲の上限を16階層に設定し、不要な応答や結果の重複を減らすようコラボレーション指示を改善しました。
- キュー内のあるメッセージの保存確認によって、次に編集中のメッセージの下書きが消えてしまう問題を修正しました。
- 保留中の質問を切り替えても、選択した回答、自由入力、メモが保持されるようになりました。送信に失敗した場合はエラーを表示し、再試行できるよう回答内容を保持します。

- Codexなどのエージェントからの単一質問フォームで、質問全文ではなく「Input requested」のみが表示される問題を修正しました。
- チャットエラーの詳細が重複表示される問題を修正しました。
