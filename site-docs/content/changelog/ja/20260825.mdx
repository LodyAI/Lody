バージョン 0.86.2

### ✨ 新機能

- よく使うエージェント、モデル、権限などの実行設定を保存・共有し、新規および既存のセッションで素早く選択またはメンションできる Agent Roles を追加しました。
- モデル一覧にあいまい検索を追加し、ファイルと画像の添付をより分かりやすい統合ピッカーにまとめました。
- 自己完結型 HTML ファイルのプレビューと、Markdown メッセージの全文コピーアクションを追加しました。
- Codex の使用量リセット予測を追加しました。
- 組み込みエージェントランタイムのバックグラウンド更新を追加しました。

### 🐛 修正・改善

- セッションの作成、復元、タスクディスパッチの信頼性を改善し、ローカルへの直接セッションで意図しないブランチが作成されないようにするとともに、新しいワークツリーのブランチ名競合を自動処理するようにしました。
- 保存が確認される前にタスク本文が消えてしまう問題を修正し、親セッションをアーカイブすると子セッションも同時にアーカイブされるようにしました。
- ローカルファイルの読み取りをデバイス内に留めたまま、Electron でのローカルファイル閲覧とプレビューを改善しました。
- コンポーザーのサイズ変更時にチャットコンテンツがずれる問題を修正しました。
- Claude と Grok のモデルフォールバック、従来のランタイムキャッシュとの互換性、および使用量チャートのラベルを改善しました。
- Linux デスクトップのアイコン関連付けを修正し、Web およびモバイルでの絵文字ピッカーのオフライン利用性を改善しました。
