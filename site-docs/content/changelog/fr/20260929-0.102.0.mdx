Version 0.102.0

### ✨ Nouvelles fonctionnalités

- Prévisualisez les fichiers PDF directement dans les conversations, avec navigation par page, zoom et recherche de texte.
- Ajout des Raccourcis de prompt dans les paramètres.
- Les liens vers des conversations dans les messages s'affichent désormais sous forme de vignettes de conversation cliquables, facilitant l'accès aux discussions associées.

### 🐛 Correctifs et améliorations

- Amélioration de la réactivité lors de l'envoi de messages en réduisant les délais de synchronisation. Les messages contenant des images conservent leur aperçu en place lors de l'envoi, réduisant ainsi les décalages de mise en page.
- Les applications de bureau et mobile démarrent désormais avec votre thème enregistré, réduisant les flashs entre les apparences claire et sombre.
- L'ouverture de l'application depuis son point d'entrée par défaut vous amène désormais sur la page d'accueil du chat, prête pour une nouvelle conversation.
- Les menus de mentions et de commandes suivent le curseur de saisie, avec un meilleur positionnement lorsque le texte passe à la ligne, que le compositeur défile ou que le clavier mobile s'ouvre.
- Amélioration de la recherche de commandes slash grâce à un classement commun pour les Raccourcis de prompt et les commandes d'agent, rendant les correspondances par nom plus faciles à trouver.
- Amélioration de l'alignement dans les menus des Rôles d'agent, les barres latérales et les listes de sélection, et correction des textes tronqués et des boutons qui se chevauchent.
- Correction de l'alignement Markdown dans les conversations, du rendu mathématique en ligne et de l'affichage en double de certaines commandes dans les appels d'outils.
- Correction de la connexion aux profils de compte Codex nouvellement créés sur les machines Linux ne disposant pas de trousseau système.
- Les projets locaux conservent leurs paramètres d'authentification Git et GitHub existants, avec une meilleure répartition des tâches entre machines via les Rôles d'agent.
