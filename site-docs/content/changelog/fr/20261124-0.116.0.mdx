Version 0.116.0

### ✨ Nouveautés

- Modifiez les propositions de planification depuis les clients natifs et consultez les notifications système dans l'application Web.
- Faites glisser des mentions Today vers les conversations et affichez un plus large éventail de diagrammes SVG sécurisés dans les interfaces générées.

### 🛠️ Améliorations

- Les pièces jointes de la zone de saisie utilisent des cartes compactes plus lisibles avec progression de téléversement, nouvel essai et suppression.
- Les espaces de travail de longue durée récupèrent automatiquement l'espace de stockage SQLite inutilisé.
- La prise en charge de l'ajout via WebSocket améliore les mises à jour en direct de Streams.

### 🐛 Correctifs

- Correction d'un problème empêchant le démarrage des agents ACP JavaScript intégrés dans les builds macOS empaquetées.
- Correction de cas limites concernant le rattrapage des pièces jointes, les demandes de partage, la barre latérale et les listes de tâches Markdown.
