### Nouveautés

- Lody synchronise désormais l'historique des conversations des projets locaux depuis Codex et Claude Code. Déclenchez une synchronisation ou importez un historique existant depuis Paramètres → Projets.
- Les nouvelles conversations de projets locaux lancées dans Lody sont répliquées dans Claude Code et Codex, afin que l'historique reste synchronisé dans les deux sens.
- Ajout d'un bouton Arrêter sur ordinateur pour mettre fin à une CLI en cours d'exécution.

### Correctifs et améliorations

- Correction d'écrans sur mobile où certains éléments de l'interface dépassaient de la zone d'affichage.
