### Nouveautés

- Ajout d'un parcours d'accueil sur ordinateur pour démarrer plus facilement votre première conversation.
- Vous pouvez désormais vous connecter avec votre adresse e-mail et votre mot de passe.
- Les projets locaux peuvent provisionner un worktree à la demande, qui est automatiquement libéré lorsque la session est archivée.
- Paramètres → Projets vous permet désormais de rendre un projet local visible par votre équipe, afin de collaborer sur des projets hors GitHub au même titre que les autres.
