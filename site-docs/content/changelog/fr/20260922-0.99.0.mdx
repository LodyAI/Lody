Version 0.99.0

### ✨ Nouvelles fonctionnalités

- Sur iOS, vous pouvez choisir l'icône d'application Aqua dans les paramètres d'Apparence ou revenir à l'icône par défaut.

### 🐛 Correctifs et améliorations

- Correction des échecs de démarrage après mise à niveau causés par des caches de runtime obsolètes. Le runtime concerné est de nouveau téléchargé et vérifié si nécessaire.
- Maintien du démarrage de l'application lorsque le nettoyage du cache de runtime ou les vérifications de mise à jour échouent, sans interrompre les autres runtimes.
