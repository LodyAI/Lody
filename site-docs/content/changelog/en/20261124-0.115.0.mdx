Version 0.115.0

### ✨ New features

- Encrypted workspaces now connect to GitHub and support push notifications, Live Activities, and inbox clients. Prompt shortcuts are available in encrypted sessions.
- Keep Roost conversation history in encrypted workspaces, including history owned by a machine, and access it across workspace clients. Existing OSS snapshots can be migrated, and remote CLIs can pair with encrypted workspaces.
- See usage and transfer billing guidance for encrypted workspaces.

### 🐛 Fixes and improvements

- Recovery files are bound to the canonical site origin. Email invitations require explicit approval, and recovery entry points appear only for encrypted workspaces.
- Auto delivery now acts only on trusted pull request and check evidence.
- Fixed model-specific agent configuration reads and several Today, sidebar, snooze, and mobile display issues.
