Version 0.116.0

### ✨ Features

- Edit schedule proposals from native clients, and see system notices in the Web app.
- Drag Today mentions onto conversations, and render a broader set of safe SVG diagrams in generated interfaces.

### 🛠️ Improvements

- Composer attachments use clearer compact cards with upload progress, retry, and remove actions.
- Long-lived workspaces reclaim unused SQLite storage automatically.
- WebSocket append support improves live Streams updates.

### 🐛 Bug Fixes

- Fix built-in JavaScript ACP agents failing to start in packaged macOS builds.
- Fix attachment backfill, share request, sidebar, and Markdown task-list edge cases.
