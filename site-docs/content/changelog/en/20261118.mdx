Version 0.113.0

### ✨ New

- Added built-in Antigravity and DeepSeek Harness, and updated Codex, Claude Code, Kimi, Grok, Devin, and Pi.
- Added QR-code and batch device pairing, improved device names, and added recovery vaults and iOS recovery backup export.
- Schedules can now repeat every specified number of minutes or hours.
- Preview local HTML files on desktop and mobile. Mobile also supports opening Markdown files and viewing Plan Mode plans.
- Added a session status view, conversation outlines, and an option to hide empty projects. Hourly AI usage now follows your local time zone.

### 🐛 Fixes and Improvements

- Improved encrypted workspace pairing, key updates, and recovery, with less waiting and visible recovery progress.
- Fixed duplicate requests, sync delays, and problems opening sessions when authentication recovers or the network changes.
- Made background task running and completion states more accurate, and allowed completed tasks to wake sessions again.
- Fixed mobile sign-in return flows, long conversations, iPad navigation, and draft retention.
- Improved quote insertion, mention editing, thought and tool folding, and changed-file statistics.
