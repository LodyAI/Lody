Version 0.112.0

### ✨ New

- **Update multiple computers at once**: Update your eligible computers together from Settings, view each computer's version and update progress, and choose to update when idle or immediately.
- **Antigravity subscription quotas**: View usage and reset times for weekly and five-hour quota windows.

### 🐛 Fixes and Improvements

- **Better message editing**: Fixed misaligned cursors, text selections, and Chinese input method candidate windows when long messages wrap or a scrollbar appears.
- **More accurate My Tasks filtering**: Show only tasks assigned to you, excluding other members' tasks running on your computers.
- **Clearer sending errors**: When attachment preparation fails for a queued message, show the reason and suggested next steps. Retrying with Continue sending now shows a loading state.
- Fixed incorrect conversation creation or machine unavailable errors when starting a conversation with attachments that are still being prepared.
- Keep the sidebar name and the first conversation tab's name in sync when either is renamed.
- The web app on tablets and other wide-screen touch devices now supports dragging to resize the sidebar and remembers the chosen width.
- Fixed a sidebar overlay that could remain in narrow desktop browser windows and prevent interaction with the page.
- Simplified Agent action prompts to reduce unnecessary repeated reviews and extra actions when delegated results return.
