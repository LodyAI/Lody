Version 0.108.1

### ✨ New

- A redesigned conversation home with “Now” and “This Week” views: see conversations awaiting attention, running, or recently completed, alongside recent work and Agent plan usage.
- Set default MCP tools for each project. New conversations use the project configuration, which you can adjust before sending.
- All Changes now offers an “Uncommitted” view alongside cumulative branch changes and shows the comparison base.
- Workspace referral rewards: share referral links, view your reward balance and history, and apply eligible credit toward subscriptions. Limited-time referral campaigns are also supported.
- Agent completion notifications now include a reply excerpt, so you can preview results without opening the conversation.
- Added OpenCode V2 and updated several ACP Agents.
- Scheduled-task prompt fields now expand with their content to roughly half the window height, making long instructions easier to edit.
- When archiving a conversation with active child conversations, see their count and running status, then choose whether to archive them too or only archive the current conversation.
- Refreshed the light theme, sidebar, and login page; unified layouts for invitations, device authorization, and related pages; improved startup and page transitions; and added an indicator for the last successful sign-in method on this device.

### 🐛 Fixes and Improvements

- Improved conversation and tab switching, reducing stalls during long conversations, streaming output, and history loading.
- Improved loading for conversations with large amounts of sub-agent tool output. Task details are read on demand to avoid unnecessary processing.
- Improved history synchronization to reduce repeated transfers and storage, and fixed duplicate message content in some scenarios.
- Fixed an issue where some received sync updates could be lost after a restart, improving local data persistence and recovery.
- Improved sync recovery after storage failures, reducing repeated downloads and excessive traffic, and fixed cases where local database connections could not recover.
- Improved reconnection after network outages and fixed conversations that stopped syncing until manually refreshed.
- Fixed desktop session state being lost during network failures.
- When desktop writes fail because disk space is low, a clear message blocks further UI interaction and guides you to free space before restarting or quitting.
- Fixed repeated errors, excessive log growth, and failure to exit during abnormal CLI shutdown.
- Fixed local Agents on Windows remaining stuck on “Connecting” after a permission error, and added recovery guidance.
- Fixed duplicate conversations created by Lody MCP when slow responses triggered retries.
- Fixed conversations remaining in a finishing state, and stop operations taking too long, when file-change refreshes continued after the Agent had already replied.
- Fixed Agent question cards sometimes missing while history was still loading. Work duration no longer keeps increasing while waiting for an answer.
- Claude's original plan remains visible after you decline to execute it.
- Added clearer errors and a manual CLI recovery path for conversations that cannot accept input because of an abnormal execution state, while preserving queued input.
- Fixed custom ACP Agent history sync, imports, and conflict handling being rejected.
- Merging or closing a PR no longer automatically archives its conversation, avoiding interruptions to follow-up work.
- Conversation titles now use the user's actual input without Agent configuration or Role instructions. Forked conversation titles no longer receive an automatic prefix.
- When creating conversations with an Agent Role through the CLI or Lody MCP, Role instructions no longer appear in the visible user message or conversation title.
- DSH text and tool calls are displayed independently, so collapsing tools no longer hides accompanying text. Improved thought typography and removed an outdated delegation-model warning.
- Conversation links in Markdown file previews now open correctly.
- Fixed relative file links in nested Git worktrees. When several files match, you can choose which one to open.
- Improved syntax highlighting and scrollbars, along with home-page layout, collapsing controls, and transitions in shorter windows.
- Improved conversation sharing controls, bringing access scope, link publishing, and link management into one panel.
- Improved member avatars, Skill details, and usage views; fixed flickering avatars, menu focus issues, and scheduled-task controls obscured by Windows caption buttons.
- Slimmed down workspace borders and improved macOS title-bar and window-button alignment.
- Fixed Web startup errors and diff-view theme colors on iOS 16.4.
- Updated the DimCode icon and hid operation-success receipts with no meaningful content.

Thanks to Lampese, liyown, samzong, eric8810, vuuihc, and UniversePeak for contributing to this release!
