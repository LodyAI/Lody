Version 0.92.0

### ✨ New Features

- When an agent creates a new session, a card appears immediately so you can open it and follow its execution status
- Search project Skills by name, description, author, or path
- Download HTML source files directly from attachments and previews

### 🐛 Fixes & Improvements

- Improve local file previews with paged reading for large files and more efficient image and file loading
- Fix Factory Droid connections and show the correct reasoning options for the selected model
- Improve Grok tool permission behavior and the handling of heavily fragmented local data
- Fix new-chat attachments disappearing after switching tabs and undelivered indicators disappearing from earlier messages
- Fix session work durations being incorrectly extended and earlier output interfering with title generation
- Fix Linux .deb update installation freezing the app, and allow retries after authorization is cancelled or installation fails
- Fix completed one-time tasks incorrectly showing their next execution time as the following year
- Improve desktop composer focus, session hierarchy display in the sidebar, and mobile scrolling
- Improve the reliability of agent session delegation and completion notifications in team workflows
