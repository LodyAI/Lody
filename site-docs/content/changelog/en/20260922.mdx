Version 0.98.0

### ✨ New Features

- Improve the reliability of creating Agent tasks from mobile shares; tasks can still be delivered after the target machine comes back online.
- Connect DeepSeek Harness questions to Lody's Ask Question UI, support separate answer notes, and improve Kimi Plan interaction cards.
- Improve sidebar project organization with project context, better local project ordering, and display controls for recently updated projects.
- Show the actual model used by a session so each task's model is easier to identify accurately.
- Improve desktop multi-window, archive list, and large-project file search performance to reduce stalls while opening windows, scrolling, and searching.
- Preserve cross-screen text selections in long conversations when virtualized rows are recycled.

### 🐛 Fixes & Improvements

- Fix Devframe and Devbar startup failures in some packaged installations.
- Fix DeepSeek Harness startup on Windows when the command exceeds the shell length limit.
- Fix hosted Astro previews that could return a plain-text 403 or fail during navigation.
- Fix message, permission request, and context compaction state that could be written out of order or remain unfinished.
- Improve notification navigation, unread state, last-tab window closing, Zen mode, Mermaid, math rendering, dialog layering, and input focus.
- Fix Kimi Plan missing-file errors, model and project search focus, usage detail caching, and unread output from closed conversations.
