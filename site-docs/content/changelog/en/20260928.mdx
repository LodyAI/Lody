Version 0.101.0

### ✨ New Features

- A new UI design refreshes the sidebar, settings, PR panel, tool call details, and composer menus, with consistent light and dark themes and interactions.
- Scheduled tasks support one-time or recurring runs, a choice of machine and Agent, and run history. Agents can also propose schedules for you to confirm and create.
- Codex supports multiple independent accounts, as well as custom API endpoints and keys.
- New subagent activity details show task status, execution history, and results provided by supported Agents.
- Agent Roles now have a description field to explain their purpose and responsibilities.
- Agents can look up Agent Roles, machines, and projects in the workspace to find the right configuration and execution location.
- The new Lody Preview supports local previews and remote previews on demand, with clearer connection status and recovery guidance.
- Local projects can associate conversations with PRs and use the machine's GitHub credentials to retrieve PR information.
- View images in Markdown, including local images and remote images loaded on demand.
- View token usage for each turn.
- Open the related conversation tree from the conversation info bar.
- Pi can scan and select local extensions and import conversation history. Grok supports forking entire conversations or from earlier turns.
- New options for full-width conversations, font ligatures, and inline math rendering.
- Crop your avatar, and choose an app icon on macOS with your selection preserved.

### 🐛 Fixes & Improvements

- Improved streaming reply rendering displays Markdown progressively, with less flickering and fewer repeated animations.
- Smoother scrolling in long conversations and switching between conversations, with fewer content jumps and blank views.
- Clearer attachment upload and pending message states, with better retries and recovery after interruptions. Oversized pasted text can automatically become a text attachment.
- Editing and resending a message now supports the same mention selection as the composer.
- Fixed imported conversations using the wrong Agent configuration when resuming or forking, and restored extended reasoning options for GPT-6 Sol and Luna.
- Improved GitHub credential selection and PR associations after repository renames or transfers. CI status now reflects the latest check results.
- Fixed unsaved editor changes being lost after refresh, unwanted interactions between archiving and closing tabs, and repeated history repair.
- Improved sidebar group status, pending send indicators, and macOS Dock badges. Fixed mobile attachment menus, collapsed group state, and navigation from diffs to source files.
- Agent sign-in now shows runtime download progress and supports cancellation. Improved first-time machine connection guidance and initialization failure messages.
