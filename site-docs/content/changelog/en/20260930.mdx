Version 0.103.0

### ✨ New Features

- Support for the Codex GPT-6.1-Sol model.
- Preview Word (DOCX), Excel (XLSX), and PowerPoint (PPTX) documents directly in sessions.
- New CSV and TSV table previews with cell search and zoom, while keeping source editing available.
- PDF previews now include thumbnail navigation, rotation, and additional zoom options, with improved document search.

### 🐛 Fixes & Improvements

- Fixed reasoning effort and Fast options displaying or applying incorrectly after switching models or applying a role.
- Fixed message area crashes that could occur when switching session tabs, and improved reading position restoration.
- Improved the composer’s @ menu positioning so it follows the caret and adapts to the available space.
- Improved messages for expired or revoked GitHub authorization and fixed incorrect author attribution on some Git commits.
- Updated the built-in Codex runtime and added usage cost estimates for new models.
- Fixed navigation and link destinations on some public website pages.

Thank you to everyone in the community who shares feedback and contributes to Lody.
