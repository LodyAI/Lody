Version 0.93.3

### ✨ New Features

- Transfer workspace ownership safely while keeping existing subscriptions and billing continuous
- Open sessions and workspaces in independent desktop windows
- Select multiple chat messages and export them as PNG images, or copy generated chat images directly
- Mention Agent Roles across machines and see Roles that are temporarily unavailable
- See sender identities in chat so messages are easier to distinguish during collaboration
- Export Token usage, activity trends, and model shares from the Usage page as portrait or landscape reports
- Copy complete context as Markdown from session fork menus, with improved conversation exports
- Pause, resume, and clear Codex goals through dedicated controls
- Let Codex and Grok provide their own session titles, reducing duplicate work and waiting
- Prepare Agent runtimes earlier during onboarding and show waiting states more clearly
- Prefer the machine owner's Git identity when creating local projects

### 🐛 Fixes & Improvements

- Fixed goals that could not resume after being paused and controls that could remain disabled
- Fixed forked Codex sessions hanging on their first prompt and prompt conflicts after cancellation
- Preserve Agent context when credentials expire or identity changes, reducing interruptions and duplicate restarts
- Improved Plan mode compatibility, DeepSeek Harness settings, and ACP capability cache recovery
- Improved the reliability of history writes, streaming updates, machine-access retries, and long asynchronous task chains
- Improved local file links, system open actions, and folder drag-and-drop
- Improved Mermaid interactions so inline diagrams no longer capture scrolling, while full-screen diagrams support zooming and dragging
- Fixed session state not settling after context compaction finishes
- Improved child-session relationships, sidebar collapse controls, and fork actions while loading
- Unified the desktop shortcut lifecycle for more reliable window and keyboard-shortcut handling
- Fixed Windows Agent upgrades and lifecycle acknowledgements, and restored mobile layouts after dismissing the keyboard
- Improved mobile synchronization pacing, machine-status loading, and mobile first-load performance on the website
- Fixed occasional permission errors during membership refresh
- Thanks to external contributors @EYHN, @slashdevcorpse, @ladydd, @hqhq1025, and @nzhl for improvements to folder drops, mobile synchronization, work-duration reporting, reduced-motion behavior, forked Codex sessions, and terminal rendering
