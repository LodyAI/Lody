Version 0.95.0

### ✨ New Features

- Add a managed built-in Pi agent. Migrating an existing Pi provider asks for confirmation and preserves its settings and stored history; previous Pi sessions cannot be resumed after migration, so start a new chat.
- Return approved session-share results directly to MCP agents.
- Launch Devin from the local CLI.
- Close and recover workspace-shared sessions more reliably.

### 🐛 Fixes & Improvements

- Fix DeepSeek Harness startup with some Node versions by running it with Lody's bundled Node.
- Fix an occasional blank iOS screen after the app resumes from the background.
- Improve interruption, recovery, background prefetch, and streaming behavior to reduce lost drafts and whole-conversation failures.
- Improve share requests, provider settings, error recovery, and archive behavior.
- Fix tool-input JSON being misread as Markdown math.
