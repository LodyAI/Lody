Version 0.101.1

### ✨ New Features

- Remote web previews now preload so the Browser panel opens faster.

### 🐛 Fixes & Improvements

- Fixed network synchronization blocking message sending, with better sending and recovery on unreliable connections.
- Fixed pending messages preventing conversations from being archived or deleted.
- Updated the built-in Claude and fixed incomplete tool call status, output, and file change information.
- Faster local file previews on desktop.
- Selecting a file change now focuses that file. The changes list also shows directory paths to help distinguish files with the same name.
- Added a Git status loading indicator to the local worktree option.
- Improved data synchronization stability during concurrent updates.
