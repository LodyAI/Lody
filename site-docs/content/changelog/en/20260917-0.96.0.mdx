Version 0.96.0

### ✨ New Features

- Add a context menu for Markdown file links on desktop, with actions to copy the path, open the file, choose an application, or reveal it in Finder.
- Add a desktop developer diagnostics panel for runtime and performance metrics.

### 🐛 Fixes & Improvements

- Limit the number of local project session previews by default, with an option to show all sessions.
- Hide sharing request cards after publication.
- Fix repeated loads in the public browser during redirects, history navigation, and same-document navigation.
- Preserve text when pasting content copied from Word, PowerPoint, and similar applications.
- Show Pi migration only on supported machines.
- Hide the Fork action until a reply is complete.
- Fix some Agent native addons failing to load on macOS.
- Improve recovery and retry after a local Loro session fails to join.
- Improve the contrast of archive multi-select controls in dark themes.
- Reopen the exact child session when opening it from a creation card after its tab was closed.
- Keep the reading position when expanding or collapsing completed content.
- Improve how Devin subagents appear in conversations.
- Inherit the target session's model and run configuration for follow-up messages.
- Improve desktop browser login to avoid invalid states caused by duplicate callbacks.
- Update the bundled agent runtime versions.

### 🤝 Community Contributions
