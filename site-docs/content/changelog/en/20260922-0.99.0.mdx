Version 0.99.0

### ✨ New Features

- On iOS, choose the Aqua app icon in Appearance settings or switch back to the default icon.

### 🐛 Fixes & Improvements

- Fix startup failures after upgrades caused by outdated runtime caches. The affected runtime is downloaded and verified again when needed.
- Keep the app starting when runtime cache cleanup or update checks fail, without interrupting other runtimes.
