Version 0.99.1

### 🐛 Fixes & Improvements

- Fix new windows that could briefly show “Loading” or “Session Not Found,” return to an empty page after recovery, or behave incorrectly after another window closes. New windows now wait for the target content before appearing and recover to the correct page.
- Fix the desktop sidebar filter button drifting out of alignment in project or conversation section headers. It now stays aligned and remains open if the leading section changes.
- Shorten “Share conversation” to “Share” across desktop and mobile.
