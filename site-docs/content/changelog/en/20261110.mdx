Version 0.111.0

### ✨ New

- Session automations can check URLs or run local commands, then continue a task when an external condition is met.
- Agents can manage automations across sessions by registering, inspecting, or cancelling a wait in the target session.
- Mermaid diagrams now appear inline in the conversation.
- Attachments used on the same machine stay local: agents can read the original files, and sending images no longer requires waiting for a remote upload first.
- Preview local images directly on the original computer. On another device, download local attachments from that computer and see why a file is unavailable, including when the computer is offline.
- Agents can identify their current session, Role, parent session, and originating session to navigate collaboration more accurately.
- The Claude, Kimi, Pi, and DeepSeek Harness adapters support standard ACP session system prompts, including appended instructions and overrides.

### 🐛 Fixes and Improvements

- When a provider removes a Role's pinned model or permission mode, the Role shows why it is unavailable instead of failing only after selection.
- Role summaries now include capability labels to make supported features easier to identify.
- Restored local provider sign-in and API key entry for custom service endpoints.
- Improved Lody Agent setup: selected sign-in methods reach the target machine, custom endpoints can be configured before setup completes, and cancelling sign-in promptly ends the wait.
- Unexpectedly empty model catalogs trigger a fresh probe, preserve the selected model, and report that no usable models are available instead of incorrectly passing verification.
- Fixed known agents becoming unavailable in a new tab while machine presence information is still updating.
- Fixed Claude advisor tool results not completing correctly.
- Updated the built-in Codex runtime to 0.166.0 and Claude Code to 2.1.321.
- Updated the built-in Devin runtime to 3000.12.28 and DeepSeek Harness to 0.2.2-rc.1.
- DeepSeek thoughts are collapsed by default to make long responses easier to read.
- Session activity stays accurate while an agent's background tasks are still running, reducing premature completion indicators.
- Session context is preserved after startup fails, making retries easier.
- Ending an agent session no longer closes terminals you opened manually.
- Fixed stale desktop snapshots overwriting current state and repeated state changes during conversation updates.
- The home screen explicitly marks completed, unread sessions as unread and uses a distinct icon for draft pull requests.
- The sidebar shows local session branches and hides misleading independent branch information for sessions that share a directory.
- Tabs in related conversations scroll horizontally instead of being squeezed when there are many tabs.
- Improved desktop quit confirmation and cancellation to reduce waiting, and fixed resources not being released promptly after side panels and terminals close.
