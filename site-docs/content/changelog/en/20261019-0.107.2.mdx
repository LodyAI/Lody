Version 0.107.2

### 🐛 Fixes & Improvements

- Fix personal GitHub authorization failing when your GitHub and Lody email addresses differ, and improve the return to settings after authorization. Existing users need to authorize again once in GitHub settings.
- Support linking sign-in accounts with different email addresses, including accounts using Apple's Hide My Email.
- Fix Claude subagent image reads causing session data to grow excessively, leading to slow loading or failed synchronization.
- Improve MCP resource list recovery during startup, reconnection, and after synchronization errors, reducing missing resources and synchronization states that stop updating.

Thanks to external contributor demystify0137 for contributing to this release!
