Version 0.106.0

### ✨ New Features

- The turn popover can show timing and liveness.
- Selected math can be copied as LaTeX.
- Mobile subscription allowance widgets.

### 🐛 Fixes & Improvements

- Automatically retry when session resources are not released, reducing whole-turn failures.
- Give GitHub credential acquisition more realistic deadlines to reduce intermittent failures.
- Transient access failures no longer wedge Session dispatch.
- Accept Codex titles that lack message phase metadata.
- Keep permission options more compact and readable.
- Anchor Roost messages before confirmation to avoid jumping.
- Support the halfwidth yen symbol for skill triggers.
- Restore scrolling in the open-source notices dialog.
- Fix changelog list bullet styling.
