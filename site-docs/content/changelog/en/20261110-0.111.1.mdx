Version 0.111.1

### ✨ New

- **Read-only conversation sharing**: Share an individual conversation with your team or selected members without granting access to the entire computer.
- **Scheduled task ownership and filters**: Task lists now show each task's owner. Filter by yours, others', or all tasks to find team tasks more easily.

### 🐛 Fixes and Improvements

- Fixed an issue where a failure to process some messages could prevent later messages in the conversation from displaying correctly.
- Fixed an issue where some local images could fail to load in the desktop app.
