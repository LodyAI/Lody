### ✨ New

- Added support for editing and resending the latest user message.
- Added file upload progress on mobile.
- Press ⌘W to close a session tab or the active view in the right sidebar.

### 🐛 Fixes and Improvements

- Reduced session startup time.
- Codex network warnings no longer appear in the conversation when a connection fails.
- Fixed an issue that could cause an Agent to restart repeatedly after running out of memory.
- Fixed the CLI `--auth` option.
- Fixed local project branches not always being detected correctly.
- Improved local-to-cloud sync, fixing an issue that could prevent other devices from receiving the latest messages.
