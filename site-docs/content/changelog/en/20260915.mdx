Version 0.94.0

### ✨ New Features

- Share sessions and selected child sessions through read-only links that can be viewed without signing in.
- Manage published shares more easily: see sharing status, browse shared child sessions, resize the share sidebar, and return to the source conversation.
- Create, edit, delete, and share Prompt Shortcuts, then invoke them from the `/` menu with variables and context scopes.
- Add Bub as a built-in ACP provider.
- Read and restore long conversations in windows to reduce waiting when opening large sessions.
- Reset the desktop app's local cache from the CLI when the app cannot be opened normally.
- Share files from a conversation through the system's native sharing flow.

### 🐛 Fixes & Improvements

- Improve share-page loading, compressed-history reads, navigation, and recovery so one failed request no longer crashes the whole conversation.
- Fix share-page sign-in messaging, conversation-tree connectors, title hierarchy, and sidebar layout.
- Improve session recovery, history synchronization, interrupted compaction recovery, and archived-session handling.
- Fix Windows session paths, archived worktrees, shared-machine project navigation, and desktop sign-in account confirmation.
- Improve prompt input with workspace-scoped drafts, focus for queued-message editing, terminal-tab state, and clear feedback for oversized pastes.
- Improve ACP compatibility, Grok defaults, DeepSeek Harness behavior, and built-in Agent usage accounting.
- Show running Agent duration on mobile, and improve font-size controls and multi-image attachment layout.
- Fix checkout recovery after gift subscriptions expire.
- Fix preview pages that failed to load when optional annotation data was absent.
- Keep menus inside small windows and safe areas, and fix the macOS archive entry overlap.
- Thanks to external contributors @gu18168, @EYHN, @UniversePeak, @Astro-Han, @lawvs, @VeraPyuyi, and @liuxiaocs7 for improvements to ACP behavior, session recovery, task controls, input handling, runtime compatibility, and the desktop interface.
