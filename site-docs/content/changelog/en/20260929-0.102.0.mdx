Version 0.102.0

### ✨ New Features

- Preview PDF files directly in conversations, with page navigation, zoom, and text search.
- Added Prompt Shortcuts to settings.
- Conversation links in messages now appear as clickable conversation chips, making it easier to jump to related discussions.

### 🐛 Fixes & Improvements

- Improved message sending responsiveness by reducing synchronization delays. Image messages keep their previews in place when sent, reducing layout shifts.
- Desktop and mobile now start with your saved theme, reducing flashes between light and dark appearances.
- Opening the app from its default entry now takes you to the chat landing page, ready for a new conversation.
- Mention and command menus follow the caret, with better placement when text wraps, the composer scrolls, or the mobile keyboard opens.
- Improved slash-command search with a shared ranking for Prompt Shortcuts and agent commands, making name matches easier to find.
- Improved alignment in Agent Role menus, sidebars, and select options, and fixed clipped text and overlapping buttons.
- Fixed conversation Markdown alignment, inline math rendering, and duplicate command displays in some tool calls.
- Fixed signing in to newly created Codex account profiles on Linux machines without an available system keyring.
- Local projects retain their existing Git and GitHub authentication settings, with improved cross-machine task dispatch through Agent Roles.
