### 새로운 기능

- 이제 Goal 모드에서 각 실행의 소요 시간과 토큰 사용량을 표시합니다.
- 모바일 세션 헤더 메뉴에 이름 변경(Rename) 동작을 추가했습니다.

### 수정 및 개선 사항

- Goal 모드 UI를 정리하여 레이아웃 순서가 어긋나 렌더링되던 문제를 해결했습니다.
- Goal 모드에서 간헐적으로 멈추던 문제를 수정했습니다.
- Codex 이미지 생성 시 간헐적으로 이미지가 반환되지 않던 문제를 수정했습니다.
- Agent 구성을 기다리는 동안 온보딩이 멈추던 문제를 수정했습니다.
- 모델 선택기에서 모델 이름이 잘리던 문제를 수정했습니다.
- 이제 메시지 대기열의 삽입 및 취소 버튼이 마우스를 올렸을 때뿐만 아니라 항상 표시됩니다.
