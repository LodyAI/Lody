### 새로운 기능

- 로그인 없이 리뷰 리포트를 확인할 수 있는 로컬 코드 리뷰 도구 `lody review`를 추가했습니다.
- 이제 세션에서 미리보기를 포함해 모든 형식의 파일 첨부를 지원합니다. 에이전트도 첨부 파일을 읽고 파일을 다시 보낼 수 있습니다.
- 명령어를 검색하고 세션을 빠르게 전환할 수 있는 새로운 명령 팔레트(⌘K)를 추가했습니다.
- 키보드 단축키 설정을 추가하여 충돌 감지 기능과 함께 모든 단축키를 사용자 지정하거나 다시 매핑할 수 있습니다.
- 키보드로 모든 조작이 가능한 데스크톱 빠른 세션(Quick Session) 창(⌘⇧N)을 추가했습니다.
- 데스크톱 터미널이 이제 앱 테마를 따르며, VS Code 스타일의 하단 상태 표시줄이 포함됩니다.
- 세션의 “Open in” 메뉴가 이제 Xcode, Sublime Text 및 커스텀 실행기(런처)를 지원합니다.
- 입력창에서 `$`를 사용해 프로젝트 Skill을 멘션하고, 새로 추가된 Skills 페이지에서 사용 가능한 Skills를 탐색할 수 있습니다.
- 이제 다른 기기에서도 로컬 프로젝트를 삭제할 수 있습니다.
- 대화 글꼴 크기 설정을 추가했습니다.
- DeepSeek Reasonix 프로바이더를 추가했습니다.
- 데스크톱 사용자는 자동 CLI 시작을 비활성화하고 Lody를 순수 원격 제어 도구로 사용할 수 있습니다.

### 수정 및 개선 사항

- All Changes 목록의 성능을 개선했습니다.
- Pull Request에 이제 Draft 상태 배지가 표시됩니다.
- 대화 인터페이스 전반에서 이미지 업로드가 정상 작동하도록 개선했습니다.
- 워크트리 스크립트 로딩 대기 시간을 줄이기 위해 캐싱을 추가했습니다.
- 모바일에서 AI 질문에 답변할 때 키보드가 응답 UI를 가리던 문제를 수정했습니다.
- 모바일에서 긴 모델 이름이 표시되는 방식을 개선했습니다.
- 응답 스트리밍 중의 버벅거림과 기기 발열을 줄였습니다.
- macOS 전체 화면 모드에서 Cmd+W를 눌렀을 때 검은 화면이 나타나던 문제를 수정했습니다.
- 사이드바 선택 외곽선이 잘리던 문제와 타임스탬프 앞의 불필요한 여백을 수정했습니다.
- macOS에서 세션 검색 단축키를 ⌘F로 변경했습니다.
- 모바일 모델 선택기에서 긴 모델 이름을 더 쉽게 읽을 수 있도록 개선했으며, 메뉴가 더 이상 키보드에 가려지지 않습니다.
- 작업을 수동으로 중지했을 때 잘못된 “완료” 알림이 발생하지 않도록 수정했습니다.
