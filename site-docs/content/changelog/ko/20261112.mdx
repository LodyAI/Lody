버전 0.112.0

### ✨ 새로운 기능

- **여러 컴퓨터 한 번에 업데이트**: Settings에서 업데이트 가능한 컴퓨터들을 한꺼번에 업데이트하고, 각 컴퓨터의 버전과 진행 상황을 확인하며, 유휴 상태일 때 업데이트할지 즉시 업데이트할지 선택할 수 있습니다.
- **Antigravity 구독 할당량**: 주간 및 5시간 단위 할당량 구간의 사용량과 초기화 시간을 확인할 수 있습니다.

### 🐛 수정 및 개선

- **메시지 편집 개선**: 긴 메시지가 줄바꿈되거나 스크롤바가 나타날 때 커서 위치, 텍스트 선택 영역, 중국어 입력기 후보 창이 어긋나던 문제를 수정했습니다.
- **더 정확한 My Tasks 필터링**: 내 컴퓨터에서 실행 중인 다른 멤버의 작업을 제외하고, 본인에게 할당된 작업만 표시합니다.
- **더 명확한 전송 오류 안내**: 대기 중인 메시지의 첨부 파일 준비에 실패하면 원인과 권장 다음 단계를 표시합니다. 이제 Continue sending으로 다시 시도할 때 로딩 상태가 표시됩니다.
- 아직 준비 중인 첨부 파일과 함께 대화를 시작할 때 잘못된 대화 생성 오류나 머신 사용 불가 오류가 발생하던 문제를 수정했습니다.
- 사이드바 이름이나 첫 번째 대화 탭 이름 중 어느 쪽을 변경하든 두 이름이 서로 동기화되도록 했습니다.
- 태블릿 등 대화면 터치 기기의 웹 앱에서도 이제 드래그로 사이드바 크기를 조절할 수 있으며, 선택한 너비가 기억됩니다.
- 좁은 데스크톱 브라우저 창에서 사이드바 오버레이가 남아 페이지 조작을 방해하던 문제를 수정했습니다.
- 위임된 작업 결과가 돌아왔을 때 불필요한 반복 리뷰와 추가 동작이 줄어들도록 에이전트 작업 프롬프트를 간소화했습니다.
