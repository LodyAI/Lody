버전 0.83.0

### ✨ 새로운 기능

- Kimi Code를 개선하여 백그라운드 작업, 서브 에이전트 및 토큰 사용량 추적을 지원합니다.
- 완전히 새로운 데스크톱 온보딩 흐름을 추가했습니다. 처음 실행 시 인트로 시퀀스와 제품 둘러보기를 제공하며, 테마와 언어를 선택하고 머신에 이미 설치된 에이전트를 감지한 뒤 첫 세션을 시작할 수 있도록 안내합니다.
- 이제 에이전트가 워크스페이스의 MCP 서버를 대신 설정할 수 있습니다.

### 🐛 수정 및 개선

- 오프라인 상태이거나 원격 리포지토리에 연결할 수 없을 때 세션 워크트리 복원이 실패하던 문제를 수정했습니다.
- CLI가 실제 릴리스된 버전과 다른 버전을 보고하던 문제를 수정했습니다.
- dsh 호환성 문제를 수정했습니다.
- dsh 에이전트가 사고 과정을 표시하는 방식을 개선했습니다.
