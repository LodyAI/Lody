버전 0.114.1

### ✨ 새로운 기능

- 이제 EverMe를 계정 전체 메모리 프로바이더로 사용할 수 있습니다. 원클릭으로 설치하거나 수동으로 설정할 수 있습니다.
- 실험적 기능인 Today 아웃라인에서 메모, 할 일, 세션 멘션을 한 페이지에 모아 볼 수 있습니다. 항목을 작업으로 전환하거나, 특정 브랜치에 집중하고, 선택 영역을 단계별로 확장하거나, 여러 항목을 한 번에 편집할 수 있습니다. 데스크톱에서는 세션과 나란히 별도 창으로 Today를 열 수 있습니다.
- 새로운 상태(Status) 보기에서 세션을 Focus, Later, Settled로 정리할 수 있습니다. 세션을 1시간 또는 3시간 동안 스누즈하거나, 다시 Focus로 드래그해 옮길 수 있습니다.
- 고정된 세션을 그룹으로 묶고 직접 순서를 배치할 수 있습니다. 기기별로 표시할 그룹을 선택하거나 그룹 내부에서 바로 세션을 시작할 수 있습니다. 세션을 가장자리 근처로 드래그하면 사이드바가 자동으로 스크롤됩니다.
- ⌘/Ctrl + 1–9를 눌러 화면에 표시된 처음 9개의 세션 간에 빠르게 전환할 수 있습니다. 긴 목록은 한 페이지씩 펼쳐 볼 수 있습니다.
- 세션에 GitHub PR을 연결하거나 연결을 해제하고, 연결된 PR을 Auto delivery로 넘기며, 사이드바에서 병합 피드백을 확인할 수 있습니다.
- 세션 메뉴에서 Finder 또는 파일 탐색기(File Explorer)로 세션의 작업 디렉터리를 열 수 있습니다. 터미널에서 보조 키를 누른 채 URL을 클릭하면 브라우저에서 열립니다.
- 세션 사이드 패널에서 첨부 파일을 미리 보고 동영상 재생 속도를 조절할 수 있습니다.
- 빈 입력창(composer)에서 위(Up) 또는 아래(Down) 키를 눌러 보낸 메시지를 다시 불러올 수 있습니다. 모델 검색, 사고 강도(thinking effort), 첨부 메뉴의 단축키도 사용자 지정할 수 있습니다.
- Codex에 Ultrafast 속도 옵션이 추가되었습니다. 이제 Lody에서 원격으로 Antigravity에 로그인할 수 있습니다.
- Lody Agent 설정에서 사용자 지정 엔드포인트에서 사용 가능한 모델을 확인하고 새로 고칠 수 있으며, 새 세션의 기본 모델, 사고 강도(thinking effort), 자율성 수준을 설정할 수 있습니다. 프롬프트(Prompt) 및 에이전트 역할(Agent Role) 편집기도 새롭게 개편되었습니다.
- Lody가 긴 명령을 백그라운드에서 실행하도록 맡길 수 있습니다. 명령이 종료되면 세션이 결과를 전달받아 작업을 이어갑니다. 세션 편집자(editor)도 공유 머신에서 자동화(automations)를 관리할 수 있습니다.
- 데스크톱 설정(Settings) → 데이터(Data) 또는 CLI에서 워크스페이스를 내보내고 가져올 수 있습니다. 대상 워크스페이스의 멤버는 다른 워크스페이스에서 가져온 콘텐츠에 대해 읽기 전용 액세스 권한을 갖습니다.

### 🐛 버그 수정 및 개선 사항

- 대화 인용(quote) 작업이 모달 대화 상자 위에 표시되던 문제를 수정했습니다.

- Windows 및 Linux 안정(Stable) 버전 설치 프로그램의 프로덕션 패키징 인수를 수정했습니다.

- 이제 아카이브가 단일 목록으로 열려, 그룹을 펼치지 않고도 이전 세션을 탐색할 수 있습니다.
- 입력창(composer)이 인터페이스 글꼴 크기를 따르도록 개선했습니다. 보낸 메시지를 수정할 때도 프롬프트 단축키가 동작합니다.
- 보낸 메시지에 포함된 세션 멘션을 클릭하면 해당 세션이 열립니다. 현재 워크스페이스의 세션을 가리키는 Markdown 링크도 Lody 내부에서 열립니다.
- 좁은 창에서도 입력창(composer) 하위 메뉴가 화면 밖으로 벗어나지 않도록 수정했습니다. 연결된 GitHub 저장소가 없는 프로젝트에서는 멘션 메뉴의 Issue 및 PR 카테고리가 숨겨집니다.
- 백그라운드 창이 의도치 않게 세션을 읽음 상태로 표시하던 문제를 수정했습니다. Focus 목록의 순서를 변경해도 Later에서 방금 돌아온 세션의 읽지 않음 상태가 유지됩니다.
- 다른 창에서 그룹을 접거나 필터를 변경해도 열려 있는 각 창은 자체 사이드바 보기를 유지합니다.
- 전송을 중지하면 대기 중이던 메시지가 초안으로 남아 직접 수정하고 다시 보낼 수 있습니다. 재시작으로 중단된 턴은 “continue” 한 번으로 재개할 수 있습니다.
- 비정상 종료(crash) 후 새로 생성된 세션이 유실되거나 워크스페이스 변경 목록에서 파일이 누락되던 문제를 수정했습니다.
- 다른 세션으로 이동했다가 돌아와도 미리보기가 열린 상태로 유지됩니다. 크기가 큰 로컬 HTML 미리보기나 프로젝트 에셋 및 리디렉션이 미리보기에서 로드되지 않던 문제를 수정했습니다.
- 원격 파일 검색이 해당 파일을 호스팅하는 머신에서 직접 실행됩니다. 대규모 프로젝트에서 대기 시간을 줄이기 위해 GitHub 브랜치를 한 페이지씩 불러옵니다.
- Antigravity에서 명령어 및 스킬 메뉴가 비어 보이던 문제와, 백그라운드 작업이 끝난 후에도 세션이 작업 중으로 표시되던 문제를 수정했습니다.
- 특정 모델이 사용자 지정 reasoning-effort 값이나 긴 입력 타입 목록을 제공할 때 전체 Magpie 모델 카탈로그가 로드되지 않던 문제를 수정했습니다.
- 에이전트 연결, Claude 사용량 조회, 데스크톱 연결 및 자동화가 설정된 프록시를 사용합니다. 데스크톱 로그인을 브라우저에서 이어서 진행할 수도 있습니다.
- 독립 실행형(standalone) 설치 후 터미널에서 lody 명령을 사용할 수 없던 문제를 수정했습니다. 명시적 재설치를 실행하면 새로 설치된 데몬 버전이 활성화됩니다.
- 데스크톱 시작 속도가 빨라졌고, CLI 데몬의 메모리 사용량이 줄었으며, 긴 세션을 다시 열 때 기록을 더 효율적으로 불러옵니다.
