버전 0.89.4

### ✨ 새로운 기능

- 커스텀 ACP 제공자의 대화형 인증 흐름을 개선했습니다.
- 데스크톱 첫 실행 시 설정 중 문제가 발생했을 때 상태와 복구 경로를 더 명확하게 안내하도록 개선했습니다.

### 🐛 수정 및 개선 사항

- 여러 세션 턴에 걸쳐 에이전트 역할, 설정 및 상태가 일관되지 않던 문제를 수정했습니다.
- 전체 변경 사항(All Changes)에 현재 로컬 워크트리 외부의 콘텐츠가 포함되던 문제를 수정했습니다.
- 데스크톱 업데이터가 설치에 실패했을 때도 성공으로 보고하던 문제를 수정했습니다.
- 세션 및 작업 목록 로딩 스켈레톤을 개선하고 풀 리퀘스트 복구 프롬프트를 현지화했습니다.
- 프로덕션 미리보기 연결이 잘못된 환경 도메인을 사용하던 문제를 수정했습니다.
- 내장 Claude Code 런타임을 업데이트했습니다.
- 기여해 주신 외부 기여자 audichuang 님과 ImSingee 님께 감사드립니다.
