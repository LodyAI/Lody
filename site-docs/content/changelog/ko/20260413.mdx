### 주요 변경 사항 및 마이그레이션

- 업데이트 후 다시 로그인해야 할 수 있습니다.
- GitHub Worktree를 사용하는 경우, 에이전트를 실행하는 머신에 본인의 GitHub 신원이 (`gh auth`를 통해) 구성되어 있어야 합니다. 그렇지 않으면 기본적으로 `lody` 신원을 사용하여 Pull Request를 생성합니다.
- Lody가 새로운 동기화 엔진과 데이터 구조로 전환되었습니다. 이전 워크스페이스는 더 이상 사용할 수 없으므로 Lody를 사용하려면 새 워크스페이스를 생성해야 합니다.
- Lody는 더 이상 사용자의 GitHub 개인 신원 권한을 요청하지 않습니다. 이에 따라 동일한 GitHub 저장소를 한 번만 인증하여 여러 워크스페이스에서 공유하는 기능은 더 이상 제공되지 않습니다. 이제 하나의 저장소는 하나의 워크스페이스에만 연결됩니다.

### ✨ 멀티 탭 세션

이제 단일 세션 내에서 여러 개의 대화 탭과 파일 뷰어를 열 수 있습니다. VSCode의 탭 바와 마찬가지로 왼쪽에서 에이전트와 채팅하는 동시에 오른쪽에서 파일과 diff를 방해받지 않고 볼 수 있습니다. 하위 탭은 상위 탭의 작업 디렉터리를 상속하며, 드래그하여 순서를 바꾸거나 이름을 변경할 수 있습니다.

### 🖥️ 데몬 모드

이제 CLI가 데몬(Daemon) 모드를 지원하여 자동 재시작과 함께 Lody를 백그라운드에서 계속 실행할 수 있습니다:

```bash
lody daemon start     # 백그라운드 데몬 시작
lody daemon status    # 상태 확인
lody daemon logs      # 로그 보기
lody daemon stop      # 데몬 중지
```

### 🔗 GitHub 연동 개선

- PR CI 체크 상태가 세션 UI에 실시간으로 동기화되어 빌드 결과를 보기 위해 GitHub로 이동할 필요가 없습니다
- PR과 연결된 세션에서 자동 커밋 및 푸시 지원

### 🌐 동기화 및 안정성

- 안정성 향상을 위해 동기화 엔진 교체
- Linux 컨테이너 환경에서 멈춤 현상을 방지하기 위한 cgroup 인식 CLI 리소스 제한 적용
- 리소스 절약을 위해 ACP 유휴 타임아웃을 30분으로 단축
- 메모리 압박 시 자동 세션 메모리 해제(eviction)
