버전 0.105.0

### ✨ 새로운 기능

- 비디오 파일 미리보기를 추가했습니다.
- 이제 기기에서 지원하는 경우 전체 화면 이미지 미리보기에서 길게 눌러 이미지를 복사, 저장 또는 공유할 수 있는 메뉴를 제공합니다.
- 이제 CSV, TSV, XLSX 미리보기에서 열 크기 조정과 셀 또는 직사각형 범위 선택 및 복사를 지원합니다. XLSX 미리보기에서는 행 크기 조정도 지원합니다.
- 이제 모바일에서 HTML 파일과 채팅 첨부파일이 기본적으로 미리보기 모드로 열리며, 소스 보기 옵션도 함께 제공합니다.
- 대화 진행 상황과 워크스페이스 토큰 사용량을 확인할 수 있는 iOS 홈 화면 위젯을 추가했습니다.
- 이제 메모리 가져오기에서 여러 ID를 한 번에 선택하고 추가할 수 있습니다.
- 이제 DeepSeek이 컨텍스트, 모델, 권한 및 프리셋 구성을 유지한 채 네이티브 세션 기록을 불러와 재개할 수 있습니다.
- 이제 DeepSeek에서 실행 중 방향 조정(steering)과 Goal 설정, 일시 중지 및 재개를 지원합니다.
- 이제 DeepSeek에서 서브에이전트 조회 및 취소를 지원하며, 백그라운드 작업 상태, 재시도 활동 및 현재 컨텍스트 사용량을 표시합니다. 취소 가능 여부는 실행 방식에 따라 다릅니다.
- 이제 Pi의 서브에이전트 도구에서 각 하위 작업별로 사용 가능한 모델을 선택할 수 있습니다.
- Claude Code에 Haiku 5.5 지원을 추가하고, Codex에서 더 큰 컨텍스트 창을 지원하도록 업데이트했습니다.
- 이제 Codex에서 `/plan` 뒤에 바로 작업 설명을 입력할 수 있으며, 자동 제목 생성 시 Lody에 설정된 제목 모델과 매개변수를 사용할 수 있습니다.
- 이제 CLI 및 MCP 세션 생성과 이어가기에서 원격 머신의 세션으로 보내는 첨부파일을 포함해 파일 및 이미지 첨부파일을 지원합니다.
- 이제 CLI 세션 생성 시 `--agent-role <name or ID>`를 지원하여 워크스페이스 역할의 머신, 에이전트, 모델 및 프롬프트 구성을 사용할 수 있습니다.
- Cloud CLI에 `migrate --from-oss`가 추가되어 OSS 에디션의 Loro 세션 기록과 이전 첨부파일을 기존 클라우드 워크스페이스로 가져올 수 있습니다.
- 격리된 워크트리를 생성한 후 첫 번째 작업에서 에이전트가 작업 내용에 맞춰 브랜치 이름을 짓도록 프롬프트를 전달받아 병렬 작업을 더 쉽게 구분할 수 있습니다.
- 관련 대화 패널에서 협업 중지 및 재개 동작을 제공합니다. 기본 세션과 하위 세션을 중지하면 뒤늦게 도착한 에이전트 결과로 실행이 다시 시작되는 것을 방지합니다. 협업은 수동으로 재개해야 하며, 오프라인 머신은 동기화 후 변경 사항을 적용합니다.
- 연속으로 생성된 하위 대화는 펼치기, 접기 및 내부 스크롤을 지원하는 간결한 작업 패널로 그룹화됩니다.
- 이제 초안을 유지하고 준비 중이거나 실패한 메시지 수를 표시한 상태로 메시지 대기열을 접을 수 있습니다.
- 이제 컴포저에서 실행 머신 상세 정보를 제공합니다. 데스크톱에서는 머신 이름에 마우스를 올리거나 클릭해 소유자와 연결 상태를 확인할 수 있으며, 휴대폰에서는 아이콘 버튼으로 상세 정보 카드를 열 수 있습니다.
- 이제 데스크톱과 모바일의 원격 디렉터리 선택기에서 프로젝트로 추가하기 전에 폴더를 새로 만들고 진입할 수 있습니다. 대상 머신에는 이 기능을 지원하는 CLI 버전이 필요합니다.
- 긴 사이드바 세션 제목은 마우스를 올리거나 키보드 포커스가 이동하면 스크롤됩니다. 드래그하거나 트랙패드 또는 마우스 휠을 사용해 전체 제목을 읽을 수도 있으며, 애니메이션은 시스템의 동작 줄이기 설정을 따릅니다.
- 할당량 조회를 지원하는 제공업체의 경우, 컴포저 구성을 전환하거나 할당량 패널을 열거나 앱으로 돌아올 때 필요에 따라 구독 할당량을 새로고침할 수 있습니다.
- 이제 청구서 상세 정보에 청구 사유, 시트 변경 내역, 세부 항목, 미결제 잔액 및 결제 진입점이 표시됩니다.
- 로컬 Magpie 구성 가져오기를 위한 수신기를 추가했습니다. 전체 가져오기 흐름을 완료하려면 Magpie 측의 해당 지원이 여전히 필요합니다.

### 🐛 버그 수정 및 개선 사항

- Codex 세션을 생성하거나 재개할 때 선택한 모델이 제때 적용되지 않던 문제를 수정했습니다.
- 이제 에이전트가 모델 선택을 거부하면 인터페이스에서 경고를 표시하므로 실패한 전환을 성공으로 오인하지 않습니다.
- 일부 ACP 에이전트의 모델 구성 순서를 수정하여 모델 전환 후에도 추론 강도와 같은 역할 옵션이 초기화되지 않도록 했습니다.
- 추론 강도 및 Fast와 같은 상속된 옵션이 잘못된 모델을 기준으로 검증되던 문제를 수정했습니다.
- 이제 에이전트 역할을 저장할 때 유효한 선택 사항은 유지하면서 더 이상 사용되지 않는 구성 옵션을 정리하여 지속적인 호환성 경고를 줄입니다.
- 대화 이어가기, 방향 조정 또는 복구 중 에이전트 역할 프롬프트를 포함한 프롬프트가 제출 시점과 전달 시점 사이에 변경되던 문제를 수정했습니다.
- 세부 정보가 변경될 때 에이전트 역할 멘션 메뉴의 선택 상태나 위치가 유실되던 문제를 수정하고, 에이전트 구성 대화상자의 포커스 윤곽선을 바로잡았습니다.
- 모바일 Dimcode 구성 옵션이 서로 간섭하던 문제와 터치를 뗀 후 권한 선택이 사라지던 문제를 수정했습니다.
- 이제 Dimcode가 머신에 이미 설치된 명령어와 구성을 사용하며, 설치되어 있지 않을 때는 복사 가능한 설치 명령어를 제공합니다.
- Amp 어댑터가 이전 캐시 버전을 반복적으로 사용하던 문제를 수정했습니다. 이제 해당 버전에 맞는 바이너리를 사용합니다.
- 일부 Node.js 버전에서 ZIP으로 배포되는 에이전트 설치 시 압축 해제 중 멈추던 문제를 수정했습니다.
- 기존 세션의 출력을 포함해 Pi 명령 출력에서 줄 바꿈이 누락되던 문제를 수정했습니다.
- 이제 스캔이 완료되기 전에 Pi 확장의 저장된 패키지 이름이 표시되며, 확장 로드 실패 시 명확하게 보고됩니다.
- 이제 Codex 기록 가져오기 시 첨부파일이 보존됩니다. 다른 클라이언트가 점유한 세션, 서비스 오류, 시작 실패 및 작업 디렉터리 문제에 대한 오류 메시지가 더욱 명확해졌습니다.
- 서비스 재시작 후 빈 Codex 세션을 재개하지 못하던 문제와 이전 세션의 제목이 부정확하게 선택되던 문제를 수정했습니다.
- 이제 Codex가 세션을 열기 전에 실제 실행 디렉터리에 대한 신뢰 설정을 저장하여, 명시적으로 신뢰하지 않은 디렉터리는 그대로 유지하면서도 프로젝트 스킬과 MCP 구성 탐색을 개선합니다.
- 이제 Claude 백그라운드 Bash 작업에서 작업 설명과 별도로 실제 명령어를 표시하며, 구문 강조와 복사 기능을 지원합니다.
- 중지된 백그라운드 작업이 Claude 기록에 표시되는 방식을 개선하여 사용자 프롬프트로 잘못 표시될 가능성을 줄였습니다.
- 재연결이나 지연된 재시도 후 에이전트 완료 메시지가 두 번 처리되어 중복 실행을 유발하던 문제를 수정했습니다.
- 이제 여러 에이전트의 결과가 일괄 처리됩니다. 작업 중인 세션은 현재 턴이 끝난 후 결과를 수신하므로 개별 결과마다 반복적으로 이어 실행되는 현상을 줄입니다.
- 연속 에이전트 위임 제한을 16단계로 설정하고 협업 지침을 개선하여 불필요한 응답 확인과 중복 결과를 줄였습니다.
- 대기열에 추가된 한 메시지의 저장 확인 응답이 편집 중인 다음 메시지의 초안을 지우던 문제를 수정했습니다.
- 이제 대기 중인 질문 간에 전환할 때도 선택한 답변, 사용자 지정 입력 및 메모가 유지됩니다. 제출에 실패하면 오류를 표시하고 재시도할 수 있도록 답변을 보존합니다.
- 중국어 입력기에서 후보 단어를 확정할 때 사용자 지정 답변이 실수로 제출되던 문제를 수정했습니다.
- Codex 및 기타 에이전트의 단일 질문 양식에서 전체 질문 대신 “Input requested”만 표시되던 문제를 수정했습니다.
- 채팅 실패 상세 정보가 중복 표시되던 문제를 수정했습니다.
- 긴 대화에서 스트리밍 출력 쓰기를 최적화하여 도구를 집중적으로 사용할 때의 CLI 멈춤 현상과 다른 기기로의 메시지 전달 지연을 줄였습니다.
- 매우 긴 명령어나 인라인 이미지가 포함된 대화에서 인터페이스가 오랫동안 멈추던 문제를 수정했습니다.
- 세션 기록에서 사용되지 않는 도구 이미지, 임베디드 리소스 바이트 및 중복 데이터를 줄이고 명령 요약과 도구 제목의 길이를 제한하여 저장 및 동기화 부하를 낮췄습니다. 일반 첨부파일, 읽기 가능한 출력, 코드 diff 및 승인 내용은 그대로 유지되며, 권한 프롬프트에서는 잘린 명령어를 명확하게 표시합니다.
- 멘션 메뉴를 열 때의 렌더링을 최적화하여 컴포저 지연을 줄였습니다.
- 이제 50,000자 이상의 텍스트를 붙여넣으면 전체 원본 내용을 유지한 채 텍스트 첨부파일로 변환됩니다.
- 모바일 붙여넣기 텍스트 편집기가 사용 가능한 공간을 활용하지 못하던 문제를 수정했습니다. 이제 컴포저와 동일한 타이포그래피로 패널 내에서 전체 텍스트를 스크롤할 수 있습니다.
- 터치 기기 사용자가 이전 메시지를 읽는 동안 지연된 스크롤 이벤트가 관성 스크롤을 방해하거나 하단으로 다시 끌어내리던 문제를 수정했습니다.
- 모바일에서 하단으로 빠르게 스크롤할 때 떨림과 튕김이 발생하던 문제와, 컴포저 높이가 바뀌거나 초안을 편집할 때 의도치 않게 새 메시지를 따라 스크롤되던 문제를 수정했습니다.
- Mermaid 미리보기 위에서 대화 스크롤이 원활하지 않던 문제를 수정하고 반복적인 레이아웃 업데이트로 인한 페이지 오류를 줄였습니다.
- 이제 새 메시지를 보낼 때 더 읽기 쉽도록 앞선 맥락의 일부를 화면에 유지합니다.
- 마우스를 올리거나 키보드 포커스가 이동할 때 최신 메시지로 이동 화살표가 가려지던 문제를 수정했습니다.
- 본문, 실행 단계 및 작업 표시줄 전반에 걸쳐 모바일 대화 정렬과 턴 간격을 개선했습니다. 이전 메시지는 탭하면 작업 메뉴가 표시되며, 최신 어시스턴트 응답에서는 자주 쓰는 작업이 계속 표시됩니다.
- 붙여넣은 텍스트 칩과 GitHub Issue 및 PR 참조를 주변 텍스트와 정렬하고, 작업 응답 카드 간격을 개선했으며, 경과 시간 타이포그래피를 하단 푸터와 맞췄습니다.
- 한국어, 중국어, 일본어 텍스트에서 문장 부호 옆의 굵게 및 기울임꼴 Markdown이 올바르게 적용되지 않던 문제를 수정했습니다.
- 접힌 긴 사용자 메시지가 텍스트 중간에서 잘리는 대신 온전한 줄 사이에서 끝나며 더 많은 내용이 있음을 알리는 페이드 효과를 표시합니다.
- 이제 데스크톱 컴포저 하단 푸터에 전체 모델 이름이 표시됩니다.
- 좁은 창에서 버튼과 변경 통계가 세션 정보 표시줄을 넘치던 문제를 수정했습니다. 공간이 제한될 때는 텍스트와 머신 이름이 자동으로 축소됩니다.
- 이제 모바일의 HTML, Markdown 및 일반 텍스트 첨부파일이 더 넓은 읽기 공간을 확보하기 위해 거의 전체 화면 크기의 시트를 사용하며, 미리보기 빈 상태 메시지도 개선했습니다.

- 줄 번호가 포함된 파일 링크를 처음 클릭할 때 파일 맨 위가 열리던 문제를 수정하고, 대상 줄 범위 하이라이트를 복원했습니다.
- 사이드바가 숨겨져 있을 때 예약 작업 페이지의 사이드바 펼치기 버튼을 복원하고, macOS 창 제어 버튼 주변의 레이아웃을 바로잡았습니다.
