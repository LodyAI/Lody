### 새로운 기능

- 이제 원격 기기에서도 로컬 프로젝트의 Git 브랜치를 확인하고 워크트리를 바로 시작할 수 있습니다.

### 수정 및 개선 사항

- 외부 ACP 에이전트에서 가져온 세션의 아바타가 잘못 표시되던 문제를 수정했습니다.
- Claude 세션이 간헐적으로 유휴 상태에 멈추던 문제를 수정했습니다.
- 슬래시 명령어 검색 결과의 정렬 순서가 잘못되던 문제를 수정했습니다.
- 세션 기록을 가져올 때 간헐적으로 중복 항목이 생성되던 문제를 수정했습니다.
- 모바일 앱에서 이메일 로그인 중 예기치 않은 리디렉션이 발생하던 문제를 수정했습니다.
