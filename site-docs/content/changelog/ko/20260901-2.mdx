### 🐛 수정 및 개선

- 비동기 데이터나 대기 중인 하위 세션이 도착하거나, 빠른 전환이 발생하거나, 세션을 복원하는 상황에서도 세션 탭이 의도한 대화에 머무르고 올바르게 복구되도록 수정했습니다.
- 빠른 탐색 이벤트를 병합하고 백그라운드 작업을 입력 경로에서 분리하여 세션 전환 시 입력 지연을 줄였습니다.
- 잘못된 상위-하위 세션 관계로 인해 리다이렉트 루프나 렌더러 충돌이 발생하지 않도록 방지했습니다.
