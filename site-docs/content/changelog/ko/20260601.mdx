### 새로운 기능

- Grok Build를 비롯한 더 많은 ACP 에이전트와 MiniMax 프리셋을 추가했습니다.
- 기록 충돌이 발생할 때 ACP 측 기록을 우선으로 하여 다시 가져올 수 있습니다.
- 이제 대화에 정확한 모델 이름과 사고 수준이 표시됩니다.
- 이제 feedback.lody.ai에서 이메일 로그인을 지원합니다.

### 수정 및 개선 사항

- 오래된 npx 캐시로 인해 codex 및 Claude Code가 처음 실행 시 실패하던 문제를 수정했습니다.
- 모바일에서 연결이 끊긴 후 다시 연결할 때의 버벅거림을 줄였습니다.
- 로컬 프로젝트 브랜치 정보가 지나치게 자주 새로고침되지 않도록 개선했습니다.
- 모바일에서 사용자 메시지가 화면 밖으로 넘치던 문제를 수정했습니다.
- GitHub 프로젝트 아바타 캐싱을 개선했습니다.
- 모바일 뒤로 가기 제스처 인식 동작을 개선했습니다.
- 모바일에서 뒤로 가기 탐색 애니메이션이 깨지던 문제를 수정했습니다.
- 모바일에서 아카이브된 대화의 복원 및 영구 삭제가 작동하지 않던 문제를 수정했습니다.
- 테마 선택기 인터랙션을 개선했습니다.
