### 에이전트 경험

- Codex Fast Mode를 위한 빠른 토글 추가
- Claude Think Level 선택 기능 추가
  <img src="/_docs-assets/fast-think.png" alt="" />
- 권한 요청 카드 개선: 긴 버튼이 줄바꿈되고, 긴 명령어를 펼쳐서 전체 내용을 볼 수 있으며, 승인하기 전에 에이전트가 실행하려는 작업을 더 쉽게 검토할 수 있습니다

### 새로운 머신 및 에이전트 설정

- 이제 에이전트 구성을 머신별로 관리합니다. 머신을 전환하면 Lody가 해당 머신에서 사용 가능한 에이전트만 표시하므로 실행할 수 없는 구성을 선택하는 일을 방지합니다
- 설정 화면이 머신 목록 + 머신 상세 레이아웃을 사용하여 온라인 상태, CLI 버전 및 공유 상태를 확인할 수 있습니다

### 내장 GitHub PR 워크플로우

- 세션 상단의 PR 배지를 클릭해 Lody 안에서 PR 패널을 열고 제목, 설명, 브랜치, CI, 댓글 및 리뷰를 확인할 수 있습니다
- Lody에서 직접 PR에 댓글을 달고, PR을 병합하며, 병합 후 브랜치를 삭제할 수 있습니다
  <img src="/_docs-assets/PR-panel.png" alt="" />

### 모바일 경험

- 모바일 키보드에서 Enter 키의 동작을 설정할 수 있습니다: 메시지 전송 또는 줄바꿈 삽입
  <img width="400px" src="/_docs-assets/20260422-keyboard-option.png" />
- 세션 목록에서 왼쪽으로 스와이프하여 보관(archive)할 수 있으며, 보관 목록에서 왼쪽으로 스와이프하여 복원하거나 영구 삭제할 수 있습니다
- 보관된 세션을 열었을 때 상단 메뉴에 다시 보관 대신 복원(Restore)과 영구 삭제(Permanently Delete)가 올바르게 표시됩니다
  <img width="400px" src="/_docs-assets/mobile-swipe.png" />

### 대화 검색 및 대기 중인 메시지

- 더 명확한 결과 개수, 빈 상태 표시 및 이전/다음 이동 기능을 갖추도록 대화 내 검색 바를 새롭게 디자인했습니다
- 긴 세션에서 검색 결과 이동이 간헐적으로 멈추던 문제 수정
- 대기 중인 여러 메시지가 전체 화면을 차지하지 않도록 높이를 제한하고 목록을 스크롤할 수 있게 개선했습니다

### 팀 및 초대 관리

- Workspace 전환 후 대기 중인 초대가 올바르게 새로고침됩니다
- 이제 관리자가 대기 중인 팀 초대를 취소할 수 있습니다

### 기타 수정 사항

- 프론트엔드에서 생성한 CLI 토큰으로 가끔 로그인에 실패하던 문제 수정
- 머신 공개 범위 변경이나 동기화 지터(jitter)로 인해 사이드바 저장소 순서가 뒤바뀌지 않도록 개선
- 브라우저가 백그라운드에서 복귀하거나, 다시 포커스를 받거나, 온라인으로 돌아올 때 로그인 상태를 재검증합니다
- 동기화가 잠시 뒤처질 때 세션 생성 및 작업 전달이 자동으로 재시도되어 새 작업이 멈추는 사례를 줄였습니다
