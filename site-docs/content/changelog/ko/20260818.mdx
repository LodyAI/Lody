버전 0.82.0

### ✨ 새로운 기능

- 로컬 프로젝트용 Git 워크플로우를 추가했습니다. 인증된 Lody GitHub 연동이 있는 경우 GitHub PR 워크플로우도 함께 사용할 수 있습니다.
- 사이드바에서 세션을 입력창으로 드래그해 자동으로 @ 멘션할 수 있도록 지원합니다.
- 여러 접근 방식을 병행할 수 있도록 세션을 새 워크트리로 포크하는 기능을 추가했습니다.
- 전역 MCP 설정을 추가했으며, 대화를 생성할 때 플러스(+) 버튼 메뉴에서 선택할 수 있습니다.
- 입력창의 @ 멘션이 칩(chip) 형태로 표시되어 세션과 Skill을 더 쉽게 참조할 수 있습니다.
- diff 파일 제목에서 경로 복사 및 파일 열기 작업을 바로 실행할 수 있습니다.
- 기간을 선택해 확인할 수 있는 사용량 추세 보기를 추가했습니다.
- 이제 구독과 리딤 코드를 함께 적용할 수 있습니다.

### 🐛 수정 및 개선

- 스트리밍 대화의 스크롤 따라가기, 터미널 복사/붙여넣기 및 텍스트 선택 동작을 개선했습니다.
- 모바일의 계층형 목록을 포함해 하위 세션 탐색 및 표시 방식을 개선했습니다.
- 워크스페이스 정리, 세션 시작, 연결 복구 과정에서 발생하던 여러 안정성 문제를 수정했습니다.
- 불필요한 UI 업데이트를 줄이기 위해 사이드바 및 페이지 이동 성능을 최적화했습니다.
