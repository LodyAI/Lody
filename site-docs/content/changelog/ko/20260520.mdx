### 새로운 기능

- Codex Plan Mode 플로우에 대한 지원이 추가되었습니다.

### 수정 및 개선 사항

- 대화 중 스트리밍 마크다운 렌더링 성능을 개선했습니다.
- 네이티브 모바일 앱에서 첫 로그인 성공 후 빈 화면이 표시되던 문제를 수정했습니다.
- 이제 온보딩 과정에서 에이전트 연결을 건너뛰고 나중에 설정에서 구성할 수 있습니다.
- Claude 구성을 새로고침할 때 실패하던 문제를 수정했습니다.
- Android에서 글꼴이 비정상적으로 렌더링되던 문제를 수정했습니다.
- 개인 GitHub 권한을 부여한 후에도 작업에 여전히 잘못된 계정이 사용되던 문제를 수정했습니다.
- 오래된 PR 페이지가 자동으로 새로고침되지 않던 문제를 수정했습니다.
- 길게 붙여넣은 텍스트가 간단한 미리보기로 접히기 전의 임계값을 높였습니다.
- 로컬 프로젝트의 브랜치 정보를 불러올 때 시간 초과가 발생하던 문제를 수정하고 수동 새로고침 항목을 추가했습니다.
