### 새로운 기능 및 역량

- 채팅 입력창에 슬래시 명령어 지원을 추가했습니다. `/`를 입력해 `review`, `compact`, `undo` 등 에이전트가 제공하는 명령어를 탐색하고 삽입할 수 있습니다
<img src="/_docs-assets/slash.png" alt="" />
- 이제 에이전트 구성 옵션을 동적으로 불러오며, 사용 가능한 모든 모드와 모델 옵션 표시를 지원합니다. 업그레이드 후 Agent Config 페이지에서 옵션을 새로고침하세요

### 수정 사항 및 안정성

- Windows 데스크톱 앱에서 이메일 주소를 입력할 때 빈 화면이 나타나던 문제 수정
- 만료된 로컬 CLI 서버 연결이 복구되지 않던 문제 수정
