버전 0.117.0

- 중국어 번체, 일본어, 한국어, 스페인어, 프랑스어, 러시아어 등 6개 인터페이스 언어를 추가했습니다.
- 동기화되는 기본 권한 설정과 세션 간 권한 기억 기능을 추가했으며, 사이드바 작업 팀원별 필터링, 팀원 추가 메뉴의 아바타 표시, 스크롤 시 펼쳐진 워크그룹 요약 헤더 고정을 지원합니다.
- 데스크톱 Today 창이 크기와 위치를 기억하며 전역 토글 단축키를 지원합니다.
- 모바일에서 대화를 이미지로 공유하기, Markdown 표·코드 블록·채팅 카드 인용하기, 현재 디렉터리의 새 탭을 로컬 초안으로 열기를 지원하며, iOS 메뉴 깜빡임, 포그라운드 복구 및 Share Extension 입력 문제를 수정했습니다.
- 개인정보 설정에서 텔레메트리 즉시 옵트아웃, 통합 사용량 공유 스위치 및 지역별 쿠키 안내를 지원합니다.
- 이메일 로그인 화면 전환 중 포커스가 빼앗기는 문제와 인증된 이메일 로그인 시 인증 페이지로 자동 리디렉션되는 문제를 수정했습니다.
- 암호화 워크스페이스 생성, 기기 페어링, 키 복구 및 멤버 키 전달 절차를 강화하고 더 명확한 안내와 오류 메시지를 제공합니다.
- Loro를 1.19.1로 업그레이드하여 데몬 및 렌더러 메모리 예산을 개선하고, 영속 데몬 Streams 룸용 워크스페이스 WebSocket 전송, CLI `restore-id` 명령 및 위임 체인 한도 표시를 추가했습니다.
