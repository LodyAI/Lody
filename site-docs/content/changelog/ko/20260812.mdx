Version 0.78.0

### ✨ 새로운 기능

- Lody 내 상호작용 및 권한 제어, 컨텍스트 사용량, 사용량 제한(rate limits)을 포함해 공식 Grok 런타임 지원을 추가했습니다.
- 새로운 2단계 `@` 메뉴를 통해 파일, 이슈, 풀 리퀘스트, 스킬, 세션 및 명령어를 한곳에서 사용할 수 있으며, 다른 세션을 직접 참조하는 기능도 지원합니다.

### 🐛 버그 수정 및 개선 사항

- macOS 및 Linux에서 메모리 압박 상태 확인 로직을 개선하여, 시스템에 사용 가능한 리소스가 남아 있는데도 세션 시작이 잘못 차단되는 경우를 줄였습니다.
- Electron 데스크톱 앱에서 축소(zoom-out) 단축키를 복원했습니다.
- 이제 풀 리퀘스트 설명을 펼칠 수 있으며, 에이전트 응답의 정렬이 더욱 일관되게 표시됩니다.
- 중국어 문자를 포함한 멀티바이트 텍스트가 로컬 연결 데이터 청크 경계를 넘을 때 손상되던 문제를 수정했습니다.
- 의존성 버전이 올바르게 확인되지 않을 때 npm 또는 npx를 통한 Lody CLI 설치가 실패하던 문제를 수정했습니다.
- 웹사이트 랜딩 페이지의 로딩 속도, 에셋 크기 및 접근성을 개선했습니다.
