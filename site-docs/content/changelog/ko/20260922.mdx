버전 0.98.0

### ✨ 새로운 기능

- 모바일 공유에서 Agent 작업을 생성할 때의 안정성을 개선하여, 대상 머신이 다시 온라인 상태가 된 후에도 작업이 정상적으로 전달될 수 있도록 했습니다.
- DeepSeek Harness 질문을 Lody의 Ask Question UI에 연결하고, 별도의 답변 메모를 지원하며, Kimi Plan 상호작용 카드를 개선했습니다.
- 프로젝트 컨텍스트 추가, 로컬 프로젝트 정렬 개선, 최근 업데이트된 프로젝트 표시 제어 기능을 통해 사이드바 프로젝트 정리를 개선했습니다.
- 각 작업에 사용된 모델을 정확하게 파악할 수 있도록 세션에서 실제로 사용한 모델을 표시합니다.
- 데스크톱 멀티 윈도우, 보관함 목록, 대규모 프로젝트 파일 검색 성능을 개선하여 창 열기, 스크롤, 검색 시 발생하는 멈춤 현상을 줄였습니다.
- 긴 대화에서 가상화된 행이 재사용될 때도 화면을 가로지르는 텍스트 선택 영역이 유지되도록 개선했습니다.

### 🐛 수정 및 개선

- 일부 패키지 설치 환경에서 Devframe 및 Devbar가 시작되지 않던 문제를 수정했습니다.
- Windows에서 명령어가 셸 길이 제한을 초과할 때 DeepSeek Harness가 시작되지 않던 문제를 수정했습니다.
- 호스팅된 Astro 미리보기에서 일반 텍스트 403 오류를 반환하거나 탐색 중 실패하던 문제를 수정했습니다.
- 메시지, 권한 요청, 컨텍스트 압축 상태가 순서와 다르게 기록되거나 완료되지 않은 상태로 남던 문제를 수정했습니다.
- 알림 이동, 읽지 않은 상태 표시, 마지막 탭 창 닫기, Zen 모드, Mermaid 및 수식 렌더링, 대화 상자 레이어링, 입력 포커스를 개선했습니다.
- Kimi Plan 파일 누락 오류, 모델 및 프로젝트 검색 포커스, 사용량 세부 정보 캐싱, 닫힌 대화의 읽지 않은 출력 문제를 수정했습니다.
