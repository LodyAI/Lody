버전 0.100.0

### ✨ 새로운 기능

- Opus 5.5, GPT-6-Sol, GPT-6-Luna 지원을 추가했습니다.
- Lody에서 직접 설정하고 세션을 생성할 수 있는 내장 에이전트로 Dimcode를 추가했습니다.

### 🐛 수정 및 개선

- 내장 Claude Code, Codex, Grok, Kimi, Pi 런타임을 업그레이드하여 에이전트 안정성과 세션 시작 속도를 개선했습니다.
- 데스크톱 창 예열(warmup) 및 콘텐츠 로딩을 개선하여 세션을 열 때 발생하는 빈 화면, 오류 페이지, 짧은 로딩 상태 표시를 줄였습니다.
- 긴 대화의 백그라운드 로딩을 개선하여 콘텐츠 깜박임, 메시지 위치 어긋남, 텍스트 선택 유실 현상을 방지했습니다.
- 사이드바 필터 레이아웃을 개선하고 작업 목록이 비어 있을 때도 필터 컨트롤을 계속 사용할 수 있도록 했습니다.
- 세션에서 다른 로컬 워크트리(worktree) 파일을 열 때 잘못된 파일이 지정되던 문제를 수정했습니다.
- Windows에서 DeepSeek Harness 하위 프로세스가 콘솔 창을 반복적으로 여는 현상을 방지했습니다.
- Machine Flock 원격 동기화 실패 시 자동으로 재시도하고 명확한 실패 상태를 보고하도록 개선했습니다.
- Code Collab이 텍스트 파일을 저장할 때 실행 권한 및 비공개 POSIX 파일 권한을 유지하도록 수정했습니다.
- 공유 진입점과 세션 헤더 인터페이스를 다듬었습니다.

### 🙏 외부 기여자 감사

- Code Collab이 파일을 저장할 때 POSIX 권한을 유지하도록 기여해 주신 ladydd님께 감사드립니다.
