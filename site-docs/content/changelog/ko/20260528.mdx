### 새로운 기능

- 이제 세션 변경 사항 사이드바에서 파일을 접을 수 있는 아코디언 섹션으로 그룹화합니다.

### 수정 및 개선 사항

- 데스크톱 및 다크 모드에서 Mermaid 다이어그램 렌더링을 개선했습니다.
- 이제 메시지를 전송한 후 탭의 임시 입력 내용이 지워집니다.
- 워크스페이스 시작 중에 세션 작업을 사용할 수 없던 문제를 수정했습니다.
