버전 0.107.0

### ✨ 새로운 기능

- 에이전트가 작업을 마쳤을 때 현재 작업 맥락에 더 가까운 문구로 네이티브 완료 알림을 보냅니다.
- 턴별 예상 비용 표시를 추가했습니다.
- 여러 머신에서 동일한 에이전트 역할(Role)을 실행할 수 있으며, MCP / CLI를 통해 역할 생성 또는 업데이트를 제안할 수 있습니다.
- Pele를 사용해 채팅에서 Mermaid 다이어그램을 렌더링하며, Markdown 미리보기에서 삽입된 이미지를 표시할 수 있습니다.
- “Delta로 열기” 실행기와 머신 설정 내 연결된 에이전트 아이콘 표시를 추가했습니다.
- 모바일의 변경 사항(Changes) 탐색 방식을 데스크톱과 동일하게 맞췄습니다.
- 안정(Stable) 버전과 Nightly 버전 모두에 대한 Linux ARM64 설치 프로그램을 제공합니다.
- 버그 리포트에 클라이언트 진단 정보 및 환경 세부 정보가 포함되어 문제 분류가 더욱 쉬워졌습니다.

### 🐛 수정 및 개선

- 세션과 데몬의 안정성을 높였습니다. 유휴 가비지 컬렉션(GC)이 아직 에이전트가 작업 중인 세션을 회수하지 않도록 하고, 일시적인 시작 실패 시 재시도할 수 있으며, 중단 후에도 대화를 이어갈 수 있습니다.
- 동기화 엔진의 다양한 최적화 및 버그 수정을 반영했습니다.
- 실행 중인 데몬 없이도 로컬 파일을 미리 볼 수 있으며, Codex 인용이 파일 카드로 렌더링되고 번들된 Codex 기록 가져오기 기능이 복구되었습니다.
- iOS 16.4 이상 런타임 호환성을 개선하고, Windows 창 제목 표시줄 버튼이 오버레이를 가리지 않도록 수정했습니다.
