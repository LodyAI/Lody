버전 0.90.1

### ✨ 새로운 기능

- 더욱 집중된 워크스페이스 경험을 위한 Zen 레이아웃 모드를 추가했습니다([#341](https://github.com/LodyAI/Lody/pull/341)).
- 증분 업데이트, 네이티브 진행률 표시 및 더욱 안정적인 설치 검증 기능으로 macOS 자동 업데이트를 업그레이드했습니다([#173](https://github.com/LodyAI/Lody/pull/173)).
- 세션 이름 변경 도구를 추가했습니다([#337](https://github.com/LodyAI/Lody/pull/337)).
- 커스텀 DeepSeek Harness 서비스 엔드포인트 지원을 추가했습니다([#293](https://github.com/LodyAI/Lody/pull/293)).
- 에이전트(Agent) 및 제공자(Provider) 설정에서 구성, 상태 및 사용 불가 사유를 더 명확하게 표시하도록 개선했습니다([#257](https://github.com/LodyAI/Lody/pull/257)).

### 🐛 수정 및 개선 사항

- CLI 데몬 시작 복구, 상태 진단 및 오류 메시지를 개선했습니다([#287](https://github.com/LodyAI/Lody/pull/287)).
- 에이전트 기능(capability) 새로고침 실패 및 멀티턴 작업 간 설정 상태 불일치 문제를 수정했습니다.
- Markdown 링크, 굵은 글씨 URL, CJK 입력기(IME) 및 멘션 입력 동작을 개선했습니다([#274](https://github.com/LodyAI/Lody/pull/274), [#309](https://github.com/LodyAI/Lody/pull/309), [#294](https://github.com/LodyAI/Lody/pull/294)).
- 세션 탭, 계획 승인, 설정 탐색 및 컴팩트 모바일 레이아웃을 개선했습니다([#326](https://github.com/LodyAI/Lody/pull/326), [#315](https://github.com/LodyAI/Lody/pull/315), [#334](https://github.com/LodyAI/Lody/pull/334), [#285](https://github.com/LodyAI/Lody/pull/285)).
- 로컬 프로젝트 폴더 선택, SVG 파일 첨부 및 데스크톱 Cmd+W 동작을 개선했습니다([#291](https://github.com/LodyAI/Lody/pull/291), [#173](https://github.com/LodyAI/Lody/pull/173)).
- 일부 프록시 네트워크 환경에서 내장 브라우저가 연결되지 않던 문제를 수정했습니다([#299](https://github.com/LodyAI/Lody/pull/299)).
- Codex goal 명령 제어 및 하위 세션 워크스페이스 안내를 개선했습니다([#144](https://github.com/LodyAI/Lody/pull/144), [#225](https://github.com/LodyAI/Lody/pull/225)).
- 기여해 주신 외부 기여자 [@jeffwcx](https://github.com/jeffwcx), [@EYHN](https://github.com/EYHN), [@Innei](https://github.com/Innei), [@MichaelYuhe](https://github.com/MichaelYuhe), [@sinxy-sai](https://github.com/sinxy-sai), [@natsustan](https://github.com/natsustan), [@slashdevcorpse](https://github.com/slashdevcorpse), [@ImSingee](https://github.com/ImSingee) 님께 감사드립니다.
