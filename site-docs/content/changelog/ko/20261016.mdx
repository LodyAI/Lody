버전 0.106.0

### ✨ 새로운 기능

- 턴 팝오버에서 소요 시간과 활성 상태를 확인할 수 있습니다.
- 선택한 수식을 LaTeX 형식으로 복사할 수 있습니다.
- 모바일 구독 사용량 위젯을 추가했습니다.

### 🐛 수정 및 개선

- 세션 리소스가 해제되지 않았을 때 자동으로 재시도하여 전체 턴이 실패하는 문제를 줄였습니다.
- GitHub 자격 증명 획득 제한 시간을 현실적으로 조정하여 간헐적인 실패를 줄였습니다.
- 일시적인 접근 실패로 인해 세션 작업 전달(dispatch)이 멈추지 않도록 수정했습니다.
- 메시지 단계(phase) 메타데이터가 없는 Codex 제목도 정상적으로 처리하도록 수정했습니다.
- 권한 옵션을 더욱 간결하고 읽기 쉽게 개선했습니다.
- 확인 전 Roost 메시지 위치를 고정하여 화면이 튀는 현상을 방지했습니다.
- 스킬 트리거에서 반각 엔(¥) 기호를 지원합니다.
- 오픈소스 고지 대화상자의 스크롤 기능을 복구했습니다.
- 변경 로그 목록의 글머리 기호 스타일을 수정했습니다.
