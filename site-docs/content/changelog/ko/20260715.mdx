### 새로운 기능

- 데스크톱 및 모바일 전반의 UI/UX를 새롭게 개편했습니다.
- 기기 및 Agent 세션의 CPU와 메모리 사용량을 확인할 수 있는 기기 리소스 모니터링 기능을 추가했습니다.
- Codex 및 Claude Code에 방향 조정(steer) 지원을 추가했습니다.
- 프로젝트, 브랜치, 코드 변경 사항, PR, 목표, 예약 작업, 미리보기 정보와 빠른 작업을 한데 모아 볼 수 있는 세션 정보 표시줄을 추가했습니다.
- 프로필 사진, 워크스페이스 로고, 표시 이름 및 비밀번호 관리 지원을 추가했습니다.

### 수정 및 개선 사항

- 기기 온라인 상태, 재연결 동작 및 로컬 Agent 안정성을 개선했습니다.
- 세션을 이어서 진행할 때 모델, 권한 또는 추론 설정이 변경될 수 있던 문제를 수정했습니다.
- 가져온 로컬 프로젝트가 즉시 표시되지 않던 문제를 수정했습니다.
- Codex 기능 새로고침, 세션 제목, 추론 내용 및 사용량 정보 표시를 개선했습니다.
- Agent 응답, 하위 에이전트 작업, 편집된 파일 및 사용량 세부 정보의 표시 방식을 개선했습니다.
