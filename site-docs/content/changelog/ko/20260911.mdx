버전 0.93.3

### ✨ 새로운 기능

- 기존 구독과 결제를 중단 없이 유지하면서 워크스페이스 소유권을 안전하게 이전할 수 있습니다
- 세션과 워크스페이스를 독립적인 데스크톱 창으로 열 수 있습니다
- 여러 채팅 메시지를 선택해 PNG 이미지로 내보내거나, 생성된 채팅 이미지를 바로 복사할 수 있습니다
- 다른 머신에 있는 에이전트 역할(Agent Role)을 멘션하고 일시적으로 사용할 수 없는 역할도 확인할 수 있습니다
- 협업 시 메시지를 더 쉽게 구분할 수 있도록 채팅에 발신자 신원을 표시합니다
- 사용량(Usage) 페이지에서 토큰 사용량, 활동 추이, 모델별 점유율을 세로 또는 가로 방향 리포트로 내보낼 수 있습니다
- 세션 포크 메뉴에서 전체 컨텍스트를 Markdown으로 복사할 수 있으며, 대화 내보내기 기능을 개선했습니다
- 전용 컨트롤을 통해 Codex 목표(goal)를 일시 중지, 재개 및 초기화할 수 있습니다
- Codex와 Grok이 자체적으로 세션 제목을 생성하도록 하여 중복 작업과 대기 시간을 줄였습니다
- 온보딩 과정에서 에이전트 런타임을 더 일찍 준비하고 대기 상태를 더욱 명확하게 표시합니다
- 로컬 프로젝트를 생성할 때 머신 소유자의 Git 신원을 우선 사용합니다

### 🐛 버그 수정 및 개선

- 일시 중지된 목표를 재개할 수 없거나 컨트롤이 비활성화 상태로 남아 있던 문제를 수정했습니다
- 포크된 Codex 세션이 첫 번째 프롬프트에서 멈추는 문제와 취소 후 프롬프트 충돌이 발생하던 문제를 수정했습니다
- 자격 증명이 만료되거나 신원이 변경될 때 에이전트 컨텍스트를 보존하여 중단 및 중복 재시작을 줄였습니다
- Plan 모드 호환성, DeepSeek Harness 설정, ACP 기능(capability) 캐시 복구를 개선했습니다
- 기록 저장, 스트리밍 업데이트, 머신 접근 재시도, 긴 비동기 작업 체인의 안정성을 개선했습니다
- 로컬 파일 링크, 시스템에서 열기 작업 및 폴더 드래그 앤 드롭을 개선했습니다
- 인라인 Mermaid 다이어그램이 스크롤을 가로채지 않도록 개선하고, 전체 화면 다이어그램에서 확대/축소 및 드래그를 지원하도록 개선했습니다
- 컨텍스트 압축(compaction)이 완료된 후 세션 상태가 안정화되지 않던 문제를 수정했습니다
- 하위 세션 관계, 사이드바 접기 컨트롤 및 로딩 중 포크 동작을 개선했습니다
- 데스크톱 단축키 수명 주기를 통합하여 창과 키보드 단축키 처리를 더욱 안정화했습니다
- Windows 에이전트 업그레이드 및 수명 주기 응답 처리를 수정하고, 모바일에서 키보드를 닫은 후 레이아웃이 정상 복원되도록 수정했습니다
- 모바일 동기화 속도 조절, 머신 상태 로딩 및 웹사이트 모바일 초기 로딩 성능을 개선했습니다
- 멤버십 새로고침 중 간헐적으로 발생하던 권한 오류를 수정했습니다
- 폴더 드롭, 모바일 동기화, 작업 시간 보고, 동작 줄이기(reduced-motion) 처리, 포크된 Codex 세션 및 터미널 렌더링 개선에 기여해 주신 외부 기여자 @EYHN, @slashdevcorpse, @ladydd, @hqhq1025, @nzhl 님께 감사드립니다
