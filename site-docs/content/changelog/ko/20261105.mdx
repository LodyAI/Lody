버전 0.110.0

### ✨ 새로운 기능

- 이미지 주석: 이미지 미리보기에서 그림을 그리고, 텍스트를 추가하고, 메모를 남긴 뒤 주석이 달린 이미지를 첨부 파일로 에이전트에 보낼 수 있습니다.
- 대화 자동 이어서 실행: 지정한 조건이 충족되면 작업을 재개합니다. 대화별로 할당량 회복 후 재개, PR 병합 후 보관, 유휴 상태 시 컨텍스트 압축 옵션을 설정할 수 있습니다.
- Android 에뮬레이터 미리보기: 터치 입력, 텍스트 붙여넣기, 화면 회전, 스크린샷, 라이트/다크 모드 전환, 화질 옵션을 갖춘 새로운 미리보기 및 제어 패널을 추가했습니다.
- 에이전트 로그인 방식 표시: 로그인하기 전에 에이전트가 지원하는 로그인 방식을 확인할 수 있습니다.
- Pi 업데이트: 내장 Pi를 1.4.0으로 업그레이드하고 Streamable HTTP MCP 지원을 추가했습니다.
- iOS 및 Android 나란히 미리보기: 한 기기 미리보기 탭을 다른 탭 위로 드래그해 두 화면을 동시에 볼 수 있습니다. 구분선을 드래그해 너비를 조절하거나 더블클릭해 기본 분할 비율로 되돌릴 수 있습니다.
- 대화 텍스트 인용: 선택한 메시지 일부를 입력창에 추가하여 원문을 맥락으로 삼아 후속 질문을 할 수 있습니다.
- 스택 PR(Stacked PR): PR 패널에 GitHub에 기록된 스택 순서, 각 PR의 상태 및 현재 PR의 스택 내 위치가 표시됩니다. 연결된 PR은 사이드바에도 표시됩니다.
- 더욱 유연해진 예약 작업: 프롬프트에서 멘션을 지원하며 반복 주기를 원하는 분 또는 시간 단위로 직접 설정할 수 있습니다.
- 보관된 대화 바로 복원: 입력창에 새로 추가된 복원 버튼을 통해 작성 중이던 초안을 유지한 채 대화를 되돌릴 수 있습니다.
- 머신 간 에이전트 작업 제어(Steering): 다른 머신에서 실행 중인 대화로 후속 지시를 보낼 수 있습니다. 실시간 제어가 불가능한 경우 지시는 대기열에 추가됩니다.
- 이제 Claude가 대화별로 Anthropic 호환 게이트웨이에서 제공하는 모델을 검색할 수 있습니다.
- 에이전트 대기열 관리: 에이전트가 대상 대화의 대기 중인 메시지를 확인하고 자신이 보낸 대기 지시를 철회하거나 교체할 수 있습니다.
- 더욱 상세해진 협업 상태 조회: 에이전트가 대화의 활성 도구, 마지막 출력 시간, 대기열 길이뿐만 아니라 머신 디스크 정보와 남은 할당량까지 조회할 수 있습니다.
- 작성자 정보가 포함된 메시지 참조: 에이전트가 지시를 전달할 때 기록된 작성자 정보를 포함해 원본 메시지를 참조할 수 있습니다.
- 기기 페어링 기본 활성화: 계정 단위 기기 페어링에 더 이상 개발자 모드나 테스트 플래그가 필요하지 않습니다.
- 대화 일괄 보관: 에이전트가 단 한 번의 MCP 호출로 여러 대화를 보관할 수 있습니다.
- 홈 페이지의 두 가지 할당량 창: 단기 할당량과 주간 할당량 각각의 사용률과 초기화 시간을 확인할 수 있습니다.
- 독립적인 대화 그룹 이름: 사이드바 대화 그룹과 개별 탭의 이름을 서로 영향을 주지 않고 별도로 변경할 수 있습니다.
- 더욱 명확해진 협업 실패 안내: MCP가 구체적인 실패 사유, 할당량 초기화 시간 등의 세부 정보를 반환합니다. 재시도가 성공하면 이전 실패 상태가 해제됩니다.

### 🐛 수정 및 개선

- Claude 할당량 소진 안내에서 대화 자동 재개 활성화 옵션을 제공합니다. 할당량이 회복되거나 초기화 시간에 도달하면 Lody가 다시 확인하고 작업을 이어서 실행합니다.
- 예약 메시지의 전체 텍스트가 표시되며, 현재 대화 내에서 수정할 수 있고, 전송 시간이 보는 사람의 로컬 시간대로 표시됩니다.
- 대화가 위임된 작업을 기다리거나 메시지 수신함 시작에 실패했을 때 예약 메시지 전달이 멈추던 문제를 수정했습니다.
- 일시적인 연결 실패 후 백그라운드 서비스, 메시지 대기열 및 MCP 목록의 복구 동작을 개선하여 대화가 멈추는 현상을 줄였습니다.
- 모델 및 추론 강도 같은 대화 설정이 이전 입력이나 초안에 의해 덮어써지던 문제를 수정했습니다.
- Pi 대화 분기(포크) 및 슬래시 명령어 로딩을 개선하여 대화 간에 명령어 목록이 섞이지 않도록 방지했습니다.
- DeepSeek 기록의 이미지 가져오기, 목록 세부 정보 및 시작 오류 표시를 수정했습니다.
- 입력 기능을 명시하지 않은 Magpie 모델과의 호환성을 추가했습니다.
- iOS 대화의 스크롤 관성, 기록 페이지 버튼 탭 인식, 사이드바 크기 조절 및 데스크톱 페이지 정렬을 개선했습니다.
- 기본 글꼴 선택을 개선하여 가능한 경우 SF Pro Display를 우선 사용하도록 했습니다.
- 구독 정보를 불러오지 못했을 때 전체 워크스페이스가 실패하던 문제를 수정하고, 홈 화면 위젯 캐시 복구 동작을 개선했습니다.
- 내장 Claude Code를 2.1.316으로 업그레이드했습니다.
- 이전의 대화 설정 및 메시지 전송 동작을 복원하여 구버전 백그라운드 서비스에서 발생하던 메시지 전달 실패 문제를 수정했습니다. (대화 설정이 이전 입력이나 초안에 의해 덮어써지지 않는다는 이전 항목은 제거합니다.)
- 자동 이어서 실행 컨트롤이 대상 머신의 실제 지원 기능을 반영하도록 하여 구버전 백그라운드 서비스에서 사용할 수 없는 동작이 노출되지 않도록 했습니다.
- 도구 모음 공간을 확보하기 위해 Android 미리보기 화질 옵션을 “더 보기(More)” 메뉴로 옮겼습니다.
- 인증이 완료되기 전에 조직 정보를 불러오면서 발생하던 오류를 수정했습니다.
- 멀티 에이전트 협업을 개선했습니다. 이제 응답에 메시지 전달 상태와 구체적인 실패 사유가 포함되고, 에이전트 메시지의 출처를 식별하며, 작업 제어(steering) 후 중간 결과만 반환하지 않고 최종 답변을 기다립니다.
- 이제 MCP가 모호하지 않은 짧은 대화 ID를 지원하며 역할, 시간, 방향별로 기록을 읽어 불필요한 컨텍스트를 줄일 수 있습니다.
- 긴 대화 기록을 읽거나 내부 MCP 프로세스를 실행할 때의 메모리 사용량을 줄이고, 스트리밍 출력 중 기록 접근 성능을 개선했습니다.
- 자동 이어서 실행 대기열이 즉시 깨어나지 않던 문제를 수정하고, 연결 중·오프라인·사용 불가 상태를 명확하게 표시하도록 추가했습니다.
- 플랜 모드를 종료한 후 기록 로딩이 상태를 덮어쓰던 문제와 정보 표시줄 및 사이드바 간의 PR 상태가 어긋나던 문제를 수정했습니다.
- 같은 대화의 여러 탭이 동일한 시뮬레이터 연결을 공유하여 기기를 반복해서 선택하는 번거로움을 줄였습니다.
- 질문 카드 제목과 Markdown 렌더링을 개선하고, Droid 질문 양식과의 호환성을 추가했습니다.
- 주석이 추가된 이미지가 첨부 파일 제한을 초과하던 문제, PDF 패널 확대/축소 맞춤 및 WebKit에서의 공유 카드 레이아웃을 수정했습니다.
- PR 이미지를 필요할 때만 불러오도록 변경했습니다. 사이드바 탭 스크롤바를 드래그할 수 없던 문제와 메시지 편집기 및 대기열의 텍스트 정렬을 수정했습니다.
- 할당량이 소진되고 초기화 시간이 알려진 경우 예약 작업 실행을 연기하여, 반복적인 실패나 할당량 회복 시 한꺼번에 실행이 몰리는 현상을 방지했습니다.
- 대화가 끝나면 추론과 도구 활동만 접히고 모든 답변 텍스트는 계속 표시됩니다. 펼친 활동 내역은 원래 순서대로 표시됩니다.
- 메시지를 보낸 후 사용한 프롬프트 추천을 숨겨 이전 추천이 다시 나타나지 않도록 했습니다.
- 휴대폰에서 키보드가 로그인 입력란을 가리던 문제와 일부 페이지에서 상태 표시줄이 뒤로 가기 버튼을 가리던 문제를 수정했습니다.
- 프로젝트 기록에 경로가 없을 때 폴더 브라우저가 열리지 않던 문제를 수정했습니다.
- CLI 스냅샷 업로드가 무한정 대기할 수 있던 문제를 수정하고 초기화 실패 후 재시도 동작을 개선했습니다.
- 입력창, 전송 버튼 및 첨부 파일 레이블의 글꼴 두께를 통일했습니다.
- 사이드바 PR 표시: 기존 단일 PR 상태 아이콘을 복원했습니다. (사이드바의 연결된 PR 표시에 관한 이전 항목은 제거하며, 스택 PR은 PR 패널에서 계속 이용할 수 있습니다.)
- 이제 홈 페이지 카드가 작업 상태에 따라 재정렬됩니다. 카드를 불러오지 못하더라도 새 대화 입력창은 계속 사용할 수 있습니다.
- 고정된 대화에서 연결된 계층 구조가 사라지던 문제와 PR이 병합 가능 상태로 표시될 때 사이드바 아이콘 위치가 밀리던 문제를 수정했습니다.
- 에이전트 로그인 방식 및 인증 진행 상황 피드백과의 호환성을 개선하고, 누락되었던 커스텀 ACP 에이전트 사용량 추적을 추가했습니다.
- 일시적인 동기화 실패 중 정상 상태의 머신이 오프라인으로 잘못 표시되던 문제를 수정했습니다.
- 무시된 디렉터리와 캐시를 건너뛰어 대규모 프로젝트의 파일 색인 작업을 최적화함으로써 CLI 멈춤 현상과 파일이 삭제로 잘못 표시되는 문제를 줄였습니다.
- 기록된 비교 기준이 없을 때 원격 저장소의 기본 브랜치를 대신 사용하도록 Git diff 계산을 수정했습니다.
- 이제 모바일에서 주소를 직접 입력하지 않고도 브라우저 미리보기를 바로 열 수 있습니다. iOS 시뮬레이터 프레임 안쪽 가장자리의 테마 불일치도 수정했습니다.
- 답변 접기 동작을 업데이트했습니다. 에이전트가 명시적으로 표시한 진행 상황 업데이트는 이제 다른 활동과 함께 접히며, 최종 답변은 계속 표시됩니다. (모든 답변 텍스트가 계속 표시된다는 이전 설명은 이로 대체됩니다.)
