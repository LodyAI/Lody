### 새로운 기능

- 로컬 퍼스트 아키텍처를 업그레이드했습니다. 이제 데스크톱 앱이 오프라인 상태에서도 기존 로컬 프로젝트와 세션을 시작하고 탐색하며 계속 사용할 수 있습니다.
- 로컬 대화에서는 터널을 설정하지 않고도 Design 모드에서 웹 페이지를 바로 미리 볼 수 있습니다.
- 다른 Lody 대화를 생성, 조회 및 관리할 수 있는 에이전트 기반 제어 기능을 추가했습니다.
- Kimi Code 프로바이더에 대한 기본 지원을 추가했습니다.
- 특히 로컬 프로젝트를 중심으로 대화 초기화 속도를 개선했습니다.
- GitHub 프로젝트 UI 및 UX를 개선하고, 대화 작업 표시줄에서 사용할 수 있는 액션을 확장했습니다.
- 인터페이스 및 터미널 글꼴을 사용자 지정할 수 있는 기능을 추가했습니다.

### 버그 수정 및 개선 사항

- 사용량 차트 표시 방식을 개선했습니다.
- 오프라인 사용, 불안정한 연결 또는 네트워크 복구 중에 로컬 세션이 멈추거나, 재연결을 반복하거나, 생각하는 상태에 머무르는 문제를 수정했습니다.
- Lody를 오랫동안 실행해 두었을 때 로그인 세션이 만료될 수 있던 문제를 수정했습니다.
- 입력창에서 실행 취소(Undo) 및 다시 실행(Redo)이 간헐적으로 동작하지 않던 문제를 수정했습니다.
- 전반적인 인터페이스와 사용자 경험을 다듬었습니다.
