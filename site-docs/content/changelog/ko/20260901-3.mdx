버전 0.89.3

### ✨ 새로운 기능

- Codex 용량 부족으로 실패할 경우 명시적인 재시도에 이어 카운트다운과 취소 제어 기능이 포함된 제한된 횟수의 자동 재시도를 지원합니다.
- 전체 애플리케이션 셸을 로드하지 않고 참여(join) 흐름을 처리하는 경량 참여 진입점을 추가했습니다.

### 🐛 수정 및 개선

- 세션 설정, 세션 탭, 워크스페이스 접근 폴백(fallback), 브라우저 가시성 동기화에서 발생하던 반복 업데이트 및 렌더링 루프를 수정했습니다.
- 비동기 데이터 및 빠른 사용자 조작 상황에서 발생하던 세션 전환, 딥링크 복원, 대기 상태 문제를 수정했습니다.
- 잘못된 세션 상위-하위 관계와 렌더링 오류에 대한 복원력을 높여 리다이렉트 루프 및 렌더러 충돌을 방지했습니다.
- Codex 재시도 기능과 경량 참여 진입점 기능을 기여해 주신 외부 기여자 Wibus Wu님께 감사드립니다.
