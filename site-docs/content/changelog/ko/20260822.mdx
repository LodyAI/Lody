버전 0.85.0

### ✨ 새로운 기능

- 기기의 라이트/다크 화면 설정을 따르는 시스템 테마 모드를 추가했습니다.
- DeepSeek Harness 에이전트에 이미지 입력 지원을 추가했습니다.

### 🐛 수정 및 개선

- IME 사용 중 Esc 키를 누르면 포커스를 잃을 수 있던 문제를 수정했습니다.
- 대화 멘션의 드래그 앤 드롭 상호작용을 개선했습니다.
- 세션을 시작하거나 재개할 때 Grok 권한 설정이 올바르게 적용되도록 개선했습니다.
- DeepSeek Harness의 시작 호환성과 안정성을 개선했습니다.
