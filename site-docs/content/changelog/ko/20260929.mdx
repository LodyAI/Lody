버전 0.101.1

### ✨ 새로운 기능

- 이제 원격 웹 미리보기를 미리 불러와 Browser 패널이 더 빠르게 열립니다.

### 🐛 버그 수정 및 개선 사항

- 네트워크 동기화가 메시지 전송을 차단하던 문제를 수정하고, 불안정한 연결에서의 전송 및 복구 성능을 개선했습니다.
- 대기 중인 메시지로 인해 대화를 보관하거나 삭제할 수 없던 문제를 수정했습니다.
- 내장 Claude를 업데이트하고 도구 호출 상태, 출력 및 파일 변경 정보가 불완전하게 표시되던 문제를 수정했습니다.
- 데스크톱에서 로컬 파일 미리보기 속도가 더 빨라졌습니다.
- 이제 파일 변경 항목을 선택하면 해당 파일에 포커스됩니다. 또한 이름이 같은 파일을 구분할 수 있도록 변경 목록에 디렉터리 경로를 표시합니다.
- 로컬 워크트리 옵션에 Git 상태 로딩 표시기를 추가했습니다.
- 동시 업데이트 중 데이터 동기화 안정성을 개선했습니다.
