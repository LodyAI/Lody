### ✨ 새로운 기능

- 마지막 사용자 메시지를 수정하여 다시 전송할 수 있는 기능을 추가했습니다.
- 모바일에서 파일 업로드 진행률 표시를 추가했습니다.
- ⌘W를 눌러 세션 탭이나 오른쪽 사이드바에서 활성화된 뷰를 닫을 수 있습니다.

### 🐛 버그 수정 및 개선 사항

- 세션 시작 시간을 단축했습니다.
- 연결이 실패할 때 Codex 네트워크 경고가 대화창에 더 이상 표시되지 않습니다.
- 메모리 부족으로 인해 에이전트가 반복적으로 재시작될 수 있던 문제를 수정했습니다.
- CLI `--auth` 옵션을 수정했습니다.
- 로컬 프로젝트 브랜치가 항상 올바르게 감지되지 않던 문제를 수정했습니다.
- 로컬-클라우드 간 동기화를 개선하여 다른 기기에서 최신 메시지를 수신하지 못할 수 있던 문제를 수정했습니다.
