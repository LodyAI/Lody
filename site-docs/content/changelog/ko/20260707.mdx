### 새로운 기능

- 이제 Claude Code에서 고속 모드(fast mode)를 지원합니다.
- 이제 Claude Code에서 백그라운드 작업 및 예약 작업(scheduled tasks)을 지원합니다.
- GLM Claude Code 프로바이더 프리셋을 추가했습니다.
- 버전 마이그레이션 중 발생할 수 있는 로컬 데이터 이상을 초기화할 수 있도록 설정(Settings)에 Clear Cache 옵션을 추가했습니다.

### 수정 및 개선 사항

- Codex와 Claude의 새로운 바이너리 관리 방식을 도입하여 환경 차이로 인해 발생하는 사용 문제를 줄였습니다. Settings → Agent에서 다시 새로고침해 주세요.
- 메시지 전송 및 중지 파이프라인을 최적화하여 속도가 더욱 빨라졌습니다.
- 데이터 동기화 전략을 개선했습니다.
- diff 또는 파일 보기가 간헐적으로 실패하던 문제를 수정했습니다.
- 프로젝트 경로가 지나치게 길 때 추가(Add) 버튼을 클릭할 수 없던 문제를 수정했습니다.
- Windows에서 앱 제목 표시줄 색상이 이제 테마를 따릅니다.
- 모바일 웹 버전에서 키보드를 닫을 수 없던 문제를 수정했습니다.
- 대화 속 이미지가 간헐적으로 열리지 않던 문제를 수정했습니다.
- 모바일 설정(Settings) 페이지에 버그 신고 메뉴를 추가했습니다.
- Linux에서 로그인 시 리디렉션이 실패하던 문제를 수정했습니다.
- Zed에서 이미 열려 있는 프로젝트를 열 때 새 창을 여는 대신 기존 창에 포커스를 맞추도록 개선했습니다.
