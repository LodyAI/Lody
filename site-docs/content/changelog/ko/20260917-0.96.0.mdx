버전 0.96.0

### ✨ 새로운 기능

- 데스크톱의 Markdown 파일 링크에 경로 복사, 파일 열기, 연결 프로그램 선택 또는 Finder에서 보기 작업을 제공하는 컨텍스트 메뉴를 추가했습니다.
- 런타임 및 성능 지표를 확인할 수 있는 데스크톱 개발자 진단 패널을 추가했습니다.

### 🐛 버그 수정 및 개선

- 기본적으로 로컬 프로젝트 세션 미리보기 개수를 제한하며, 모든 세션을 표시하는 옵션을 제공합니다.
- 게시 완료 후 공유 요청 카드를 숨기도록 했습니다.
- 공개 브라우저에서 리디렉션, 방문 기록 탐색 및 동일 문서 내 이동 시 반복 로드되던 문제를 수정했습니다.
- Word, PowerPoint 등 유사한 애플리케이션에서 복사한 콘텐츠를 붙여넣을 때 텍스트가 보존되도록 수정했습니다.
- 지원되는 머신에서만 Pi 마이그레이션이 표시되도록 했습니다.
- 응답이 완료될 때까지 포크(Fork) 작업을 숨기도록 했습니다.
- macOS에서 일부 에이전트 네이티브 애드온이 로드되지 않던 문제를 수정했습니다.
- 로컬 Loro 세션 참여 실패 후 복구 및 재시도 동작을 개선했습니다.
- 다크 테마에서 보관함 다중 선택 컨트롤의 명암비를 개선했습니다.
- 하위 세션 탭을 닫은 뒤 생성 카드에서 다시 열 때 정확한 해당 하위 세션이 열리도록 수정했습니다.
- 완료된 콘텐츠를 펼치거나 접을 때 현재 읽기 위치가 유지되도록 했습니다.
- 대화에서 Devin 하위 에이전트(subagent)가 표시되는 방식을 개선했습니다.
- 후속 메시지가 대상 세션의 모델 및 실행 구성을 상속하도록 했습니다.
- 중복 콜백으로 인한 잘못된 상태가 발생하지 않도록 데스크톱 브라우저 로그인을 개선했습니다.
- 번들된 에이전트 런타임 버전을 업데이트했습니다.
