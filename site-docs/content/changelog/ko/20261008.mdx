버전 0.104.0

### ✨ 새로운 기능

- Mac에서 실행 중인 iOS 시뮬레이터를 세션에서 직접 미리 보고 제어하거나, 에이전트에게 미리보기 시작을 요청할 수 있습니다.
- 에이전트 역할을 Nowledge Mem 메모리 ID와 연결하고 설정에서 관리할 수 있습니다.
- 내장 Devin 지원을 추가했습니다.
- 이제 Pi에서 사용자 지정 실행 파일을 사용할 수 있습니다.
- 완료된 대화 턴에서 DeepSeek Harness 세션을 포크하여 다른 접근 방식을 탐색할 수 있습니다.
- PR 패널에서 코드 변경 사항을 확인하고, 단일 커밋 또는 커밋 범위별로 필터링하며, 변경된 파일을 검색할 수 있습니다.
- MCP 설정에서 서버가 제공하는 도구를 확인할 수 있습니다.
- MCP를 통해 세션을 생성하는 에이전트가 대상 에이전트에서 지원하는 권한 모드와 구성 옵션을 지정할 수 있습니다.
- 중국어 입력기 사용 시 스킬을 더 쉽게 호출할 수 있도록 `￥`를 입력해 스킬 선택기를 열 수 있습니다.
- 에이전트가 다른 세션으로 위임한 메시지에서 발신 에이전트 또는 역할 ID를 표시하고 원본 세션으로 이동할 수 있습니다.
- 더 많은 프로그래밍 언어의 구문 강조를 활성화할 수 있는 선택적 코드 언어 팩을 추가했습니다.
- 확장 언어를 활성화하면 파일 미리보기에서 Coq, Rocq, Lean 구문 강조를 지원합니다.

### 🐛 버그 수정 및 개선 사항

- 세션 탭을 전환할 때 전송되지 않은 Fast 설정이 유실되던 문제를 수정했습니다.
- 역할의 모델을 변경한 후 호환되지 않는 옵션이 남아 역할이 올바르게 선택되지 않던 문제를 수정했습니다.
- 첨부파일을 준비하거나 메시지를 전송하는 동안 선택한 모델, 역할 및 기타 설정이 되돌아가던 문제를 수정했습니다.
- 내장 Pi 확장 지원을 복원하여 설정 페이지에서 사용자에게 반복적으로 업데이트를 요청하던 문제를 수정했습니다.
- Pi 확장을 선택한 후 모델 목록을 사용할 수 없게 되던 문제를 수정했습니다.
- Pi 확장을 구분할 수 있도록 패키지 또는 디렉터리 이름을 사용해 확장 이름을 개선했습니다.
- 자격 증명 정리 실패가 원래의 Codex 인증 오류를 가리던 문제를 수정했습니다.
- 프롬프트 단축키 로딩 속도를 높여 처음 선택할 때의 대기 시간을 줄였습니다.
- 터치 기기에서 컴포저가 다시 포커스를 받을 때 프롬프트 단축키 선택이 사라지던 문제를 수정했습니다.
- 모델 및 역할 하위 메뉴의 위치를 바로잡고 긴 모델 목록에서의 검색 및 스크롤을 개선했습니다.
- 세션 검색에서 Markdown, 코드 및 밑줄과 같은 문자의 처리를 수정하여 결과 수와 하이라이트가 일치하도록 했습니다.
- 세션 멘션 검색의 빈 상태를 개선하여 세션이 없는 경우와 일치하는 결과가 없는 경우를 구분했습니다.
- 응답 생성이 완료된 후에도 “Thinking”이 계속 표시되는 대신 “Finalizing”을 표시하도록 변경했습니다.
- 스트리밍 응답 중 아래로 빠르게 스크롤할 때 이전 하단 위치에서 멈추고 새 콘텐츠를 따라가지 못하던 문제를 수정했습니다.
- 대화를 스크롤하는 동안 반복적인 업데이트로 인해 페이지 오류가 발생할 수 있던 문제를 수정했습니다.
- 긴 경로나 텍스트가 다른 열을 압축하지 않도록 Markdown 표 열 크기 조정을 개선했습니다.
- 메시지 텍스트와 도구 요약 사이의 간격을 개선했습니다.
- 서브에이전트 대화상자의 콘텐츠 렌더링을 기본 대화와 일관되게 맞췄습니다.
- 업로드 중 상태에서 전송 완료 상태로 전환될 때 첨부파일 미리보기가 사라지거나 깜빡이던 문제를 수정했습니다.
- 이제 업로드가 완료되기 전에도 컴포저의 이미지 썸네일이 원래 색상을 유지합니다.
- 일부 브랜치에서 All Changes가 잘못된 비교 기준을 사용하던 문제를 수정하여 파일 목록, 통계, diff가 일관되게 유지되도록 했습니다.
- 실행 취소로 저장된 내용을 복원한 후에도 파일 편집기에 저장되지 않은 변경 사항이 표시되고 종료 시 경고가 뜨던 문제를 수정했습니다.
- 모바일 키보드가 파일 편집기를 가리거나 닫은 후 레이아웃이 올바르지 않게 남던 문제를 수정했습니다.
- 모바일 diff 뷰어의 인터랙션 및 포커스 문제를 수정했습니다.
- 이미지 미리보기의 포커스 격리 및 키보드 제어 문제를 수정했습니다.
- 이제 모바일에서 공유 이미지를 내보낼 때 시스템 공유 시트를 사용합니다.
- 채팅 및 사용량 공유 이미지의 색상이 앱 테마의 영향을 받던 문제를 수정했습니다.
- 이미지 크기 등의 제한 사항을 설명하도록 공유 오류 메시지를 개선했습니다.
- 일회성 예약 작업의 입력과 미리보기가 서로 다른 시간대를 사용하던 문제를 수정했습니다.
- 서머타임 전환 시점 전후의 예약 작업 처리를 개선했습니다.
- Fast 및 Plan 같은 스위치가 포함된 예약 작업을 저장하거나 실행할 때 구성 값이 잘못 변환되던 문제를 수정했습니다.
- 모바일 예약 작업 편집기가 화면 안전 영역(safe area)을 반영하지 않던 문제를 수정했습니다.
- 동일한 에이전트 제공업체를 사용하는 계정 간에 할당량 정보가 덮어써지거나 섞이던 문제를 수정했습니다.
- 이제 컴포저의 할당량 표시기가 5시간 사용량 구간을 우선으로 표시합니다.
- Codex 초기화 알림에 데이터 소스에서 제공한 예정 초기화 시간을 표시하여, 미정 시간과 아직 확정되지 않은 초기화를 구분할 수 있습니다.
- 사용량 차트에서 여러 날에 걸친 UTC 경계와 레이블을 바로잡았습니다.
- 사용량 날짜 범위를 변경한 후 이전 날짜의 상세 정보가 예기치 않게 다시 열리거나 새 선택을 덮어쓰던 문제를 수정했습니다.
- PR 연결에 실패했을 때 검색된 GitHub PR이 표시되지 않던 문제를 수정했습니다.
- 일시적인 GitHub 조회 실패 후 재시도 방식을 개선하고, 지속적인 실패 시 반복 요청을 줄였습니다.
- 업그레이드 후 백그라운드 서비스가 간혹 이전 CLI 버전을 다시 시작하던 문제를 수정했습니다.
- UDP를 제한하는 네트워크에서 미리보기 공유 터널 호환성을 개선했습니다.
- 앱 시작 및 화면 이동 시 빈 화면이 깜빡이는 현상을 줄였습니다.
- 좁은 창에서의 설정 탐색 및 버튼 레이아웃을 개선했습니다.
- 글꼴 크기와 줄 높이 배율을 통일하여 텍스트, 코드, 도구 출력 및 설정 컨트롤이 글꼴 크기 설정을 더욱 일관되게 따르도록 했습니다.
- macOS 창 제어 버튼을 사이드바와 정렬했습니다.
- 스킬 상세 정보 내의 페이지 내 링크를 클릭하면 현재 문서에서 벗어나던 문제를 수정했습니다.
- 웹사이트 문서 링크에서 섹션 앵커가 유실되던 문제를 수정했습니다.
- 구독 확인이 진행 중인 상태에서 결제 후 돌아왔을 때 웹 앱에 무료 플랜으로 표시되던 문제를 수정했습니다.
- Homebrew 설치 안내를 추가했습니다.
- 세션 보관 후 작업 디렉터리 정리, 백업 및 브랜치 유지에 대한 안내를 명확하게 개선했습니다.
