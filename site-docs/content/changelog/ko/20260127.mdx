### 세션 관리

- 보관된 세션 페이지를 추가했습니다: 저장소별로 그룹화된 보관 세션을 탐색하고 복원하거나 영구
  삭제할 수 있습니다

### 컨텍스트 윈도우 및 구독 할당량

- 컨텍스트 윈도우 사용량 표시기: 각 AI 응답 옆에 남은 컨텍스트 비율을 표시합니다
- 이제 설정의 머신 관리에서 5시간 및 7일 잔여 할당량과 갱신 시간을 확인할 수 있습니다

### 머신 런타임

- 이제 설정에서 머신 상태(메모리/CPU 사용량)를 확인할 수 있습니다

### Windows 호환성 개선

- Windows에서 프로세스 시작이 실패하던 문제(ENOENT)를 수정했습니다
- 터미널 출력 인코딩을 수정했습니다: 멀티바이트 문자와 Windows 코드 페이지를 올바르게 처리합니다

## 수정 사항

- 다양한 UI 및 안정성 문제를 수정했습니다
