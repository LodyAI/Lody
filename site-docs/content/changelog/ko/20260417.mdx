### 🧠 Claude Opus 4.7 지원

### 👥 더욱 안전한 팀 협업

- 새로운 팀 머신 공개 범위 제어: 내 머신은 다른 멤버에게 **기본적으로 완전히 비공개**로 설정됩니다 — 다른 사람의 Workspace에 참여하더라도 내 개발 머신이 노출되거나 사용될까 걱정할 필요가 없습니다
- 설정에서 팀과 머신을 명시적으로 공유할 수 있으며, 공유되지 않은 머신은 다른 멤버의 머신 목록에 절대 나타나지 않고 해당 머신의 대화도 다른 멤버의 사이드바에 전달되지 않습니다
- "다른 사람의 Workspace 참여"와 "내 머신 사용"이 이제 완전히 분리되었습니다 — 망설임 없이 팀원을 초대하세요

### 🔐 명령어 하나로 모든 머신에서 로그인

- 비대화형 CLI 인증: `lody login --auth <api-key>`로 어떤 머신에서든 연결하거나, `lody start --auth <api-key>`로 로그인과 시작을 한 번에 처리할 수 있습니다
- Electron 데스크톱에 CLI API 키를 생성하고 복사할 수 있는 계정 설정 패널이 추가되었습니다

### 🆕 Full Access 모드

- 자체 전체 액세스 모드가 없는 에이전트(예: Kimi, OpenCode)의 권한 요청을 자동으로 승인하는 새로운 Lody Full Access 모드가 추가되었습니다

### 🤖 더 많은 에이전트 연동

- OpenCode 및 Kimi와의 연동 개선
- 기록에서 Kimi 터미널, 파일 읽기 및 편집 알림의 파싱과 표시 문제 수정

### 📱 모바일 경험

- 소프트 키보드 처리 방식 재설계: 키보드가 전체 UI를 위로 밀어 올리지 않고 입력 영역만 부드러운 전환 효과와 함께 떠오릅니다
- 모바일 키보드의 채팅 입력창에 메시지를 전송하는 "전송(Send)" 키가 표시됩니다
- iOS Safari에서 하단 컨트롤, 토스트(toast) safe-area, 초대 페이지 safe-area가 잘리던 문제 수정

### 🚀 성능 및 시작 속도

- 기존 사용자의 앱 시작 시 나타나던 흰 화면 문제 해결; UI가 더 이상 네트워크 쿼리에 의해 차단되지 않습니다
- 긴 대화의 검색 인덱싱이 이제 지연(lazy) + 점진적(incremental) 방식으로 동작하여 대화가 끝날 때 끊김 현상이 발생하지 않습니다
- 콜드 스타트 비용을 줄이기 위해 동기화 서비스 캐싱 추가

### 🌐 브라우저 호환성

- Safari 14+ / Chrome 80+ / Firefox 78+까지 지원 확대; 구형 브라우저에서 정규식 또는 ESM 로딩 실패로 인해 흰 화면이 표시되던 문제가 더 이상 발생하지 않습니다

### 🛠️ 기타 수정 사항

- Docker 컨테이너가 호스트 머신 ID를 재사용해 이벤트 스트림 충돌을 일으키던 문제 수정
- Worktree 생성 시 이제 선택한 비기본(non-default) 브랜치를 재사용합니다
- 데스크톱에서 GitHub 설치 링크를 외부 브라우저로 엽니다
- Electron에서 다시 로그인할 때 발생하던 워크스페이스 404 오류 수정
- 세션 사이드바 토글을 헤더와 정렬
- VS Code 테마 전반에서 Switch 토글 대비 개선
