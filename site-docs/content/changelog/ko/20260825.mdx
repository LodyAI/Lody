버전 0.86.2

### ✨ 새로운 기능

- 자주 사용하는 에이전트, 모델, 권한 및 기타 실행 설정을 저장하고 공유하여 새 세션과 기존 세션에서 빠르게 선택하거나 멘션할 수 있는 Agent Role을 추가했습니다.
- 모델 목록에 퍼지 검색을 추가하고, 파일 및 이미지 첨부 기능을 더 명확한 통합 선택기로 합쳤습니다.
- 독립 실행형 HTML 파일 미리보기와 Markdown 메시지 전체 복사 기능을 추가했습니다.
- Codex 사용량 초기화 예측 기능을 추가했습니다.
- 내장 에이전트 런타임의 백그라운드 업데이트 기능을 추가했습니다.

### 🐛 수정 및 개선

- 세션 생성, 복원 및 작업 전달의 안정성을 개선하고, 직접 연결된 로컬 세션에서 예기치 않은 브랜치가 생성되지 않도록 했으며, 새 워크트리의 브랜치 이름 충돌을 자동으로 처리하도록 했습니다.
- 저장 확인 전에 작업 본문이 사라지던 문제를 수정하고, 상위 세션을 보관할 때 하위 세션도 함께 보관되도록 변경했습니다.
- 로컬 파일 읽기를 기기 내에 유지하면서도 Electron의 로컬 파일 탐색 및 미리보기 경험을 개선했습니다.
- 입력창 크기를 조절할 때 대화 내용이 밀리던 문제를 수정했습니다.
- Claude 및 Grok 모델 폴백, 레거시 런타임 캐시 호환성, 사용량 차트 레이블을 개선했습니다.
- Linux 데스크톱 아이콘 연결 문제를 수정하고, 웹과 모바일에서 이모지 선택기의 오프라인 사용성을 개선했습니다.
