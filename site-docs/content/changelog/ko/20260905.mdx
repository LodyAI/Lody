버전 0.91.0

### ✨ 새로운 기능

- GPT-6 Astra를 지원합니다.
- 직접 미리보기할 수 없는 파일을 시스템 앱으로 열거나, 파일 관리자에서 표시하거나, 다운로드할 수 있도록 세션 파일 작업을 추가했습니다([#375](https://github.com/LodyAI/Lody/pull/375)).
- 이제 Markdown에서 시맨틱 diff 코드 블록을 렌더링할 수 있습니다([#373](https://github.com/LodyAI/Lody/pull/373)).
- 이제 세션 사이드바와 데스크톱 하위 세션 탭에 읽지 않음 상태가 표시됩니다([#332](https://github.com/LodyAI/Lody/pull/332), [#384](https://github.com/LodyAI/Lody/pull/384)).
- 파일, 이슈 및 PR 멘션에 VS Code 스타일의 퍼지 매칭을 적용하여 대상을 더 쉽게 찾을 수 있습니다([#378](https://github.com/LodyAI/Lody/pull/378)).
- 공유 세션 핸드오프, 병렬 에이전트 및 에이전트 팀에 대한 이중 언어 가이드를 추가했습니다([#387](https://github.com/LodyAI/Lody/pull/387), [#389](https://github.com/LodyAI/Lody/pull/389), [#390](https://github.com/LodyAI/Lody/pull/390), [#393](https://github.com/LodyAI/Lody/pull/393), [#394](https://github.com/LodyAI/Lody/pull/394)).

### 🐛 수정 및 개선 사항

- 더욱 안전하고 안정적인 액세스를 위해 팀 미리보기 및 로컬 브라우저 연결 검사를 강화했습니다([#374](https://github.com/LodyAI/Lody/pull/374)).
- 이제 DeepSeek Harness가 커스텀 서비스에서 모델을 검색하고 활성 런타임의 모델, 추론 및 권한 옵션을 노출합니다([#380](https://github.com/LodyAI/Lody/pull/380), [#395](https://github.com/LodyAI/Lody/pull/395), [DeepSeek ACP #10](https://github.com/LodyAI/acp-extension-dsh/pull/10), [#11](https://github.com/LodyAI/acp-extension-dsh/pull/11)).
- 이제 Kimi 모델 선택기에서 모델 제공자를 표시하고 검색할 수 있어 이름이 같은 모델을 더 쉽게 구분할 수 있습니다([Kimi ACP #7](https://github.com/LodyAI/acp-extension-kimi/pull/7)).
- TeX 대괄호 구분자 지원, 비ASCII 구두점 주변의 올바른 자동 링크 경계 처리, 최종 텍스트 출력 보존 및 터치로 닫을 수 있는 Mermaid 전체 화면 뷰어를 통해 Markdown 및 스트리밍 메시지 렌더링을 개선했습니다([#336](https://github.com/LodyAI/Lody/pull/336), [#370](https://github.com/LodyAI/Lody/pull/370), [#388](https://github.com/LodyAI/Lody/pull/388), [#396](https://github.com/LodyAI/Lody/pull/396)).
- 사이드바 크기 조절 시 채팅 화면이 떨리던 문제를 수정하고 결제 정보가 더 빠르게 로드되도록 개선했습니다([#368](https://github.com/LodyAI/Lody/pull/368), [#371](https://github.com/LodyAI/Lody/pull/371)).
- 실시간 현황(Live Activity) 업데이트 오버헤드를 줄이고 모바일 세션 그룹 미리보기 개수를 제한하여 긴 목록을 더 부드럽게 표시하도록 개선했습니다([#319](https://github.com/LodyAI/Lody/pull/319), [#323](https://github.com/LodyAI/Lody/pull/323)).
- App Store 리뷰 요청 프롬프트의 표시 시점과 상태 처리 방식을 개선했습니다([#310](https://github.com/LodyAI/Lody/pull/310)).
- ACP 제공자 아이콘 및 런타임 레지스트리 정보를 업데이트했습니다([#369](https://github.com/LodyAI/Lody/pull/369)).
- 공개 웹사이트 페이지 제목, 검색 노출성 및 알 수 없는 페이지에 대한 404 처리를 개선했습니다([#379](https://github.com/LodyAI/Lody/pull/379), [#383](https://github.com/LodyAI/Lody/pull/383), [#391](https://github.com/LodyAI/Lody/pull/391)).
- Kimi 모델 선택기에서 제공자 표시 및 검색 기능을 개선해 주신 외부 기여자 [@nokizw](https://github.com/nokizw) 님께 감사드립니다([Kimi ACP #7](https://github.com/LodyAI/acp-extension-kimi/pull/7)).
