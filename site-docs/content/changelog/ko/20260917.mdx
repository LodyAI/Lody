버전 0.95.0

### ✨ 새로운 기능

- 관리형 기본 제공 Pi 에이전트를 추가했습니다. 기존 Pi 프로바이더를 마이그레이션할 때는 확인을 요청하며 설정과 저장된 기록이 보존됩니다. 마이그레이션 이후에는 이전 Pi 세션을 재개할 수 없으므로 새 채팅을 시작하세요.
- 승인된 세션 공유 결과를 MCP 에이전트에 직접 반환합니다.
- 로컬 CLI에서 Devin을 실행할 수 있습니다.
- 워크스페이스 공유 세션을 더욱 안정적으로 닫고 복구할 수 있습니다.

### 🐛 버그 수정 및 개선

- Lody에 번들된 Node로 실행하도록 하여 일부 Node 버전에서 DeepSeek Harness가 시작되지 않던 문제를 수정했습니다.
- 앱이 백그라운드에서 복귀한 후 iOS 화면이 간헐적으로 빈 화면으로 표시되던 문제를 수정했습니다.
- 중단 처리, 복구, 백그라운드 프리페치(prefetch) 및 스트리밍 동작을 개선하여 임시 저장 유실과 전체 대화 오류를 줄였습니다.
- 공유 요청, 프로바이더 설정, 오류 복구 및 보관 동작을 개선했습니다.
- 도구 입력 JSON이 Markdown 수식으로 잘못 해석되던 문제를 수정했습니다.
