Version 0.77.2

### ✨ 새로운 기능

- 입력창에 파일을 붙여넣거나 드래그 앤 드롭으로 업로드할 수 있는 기능을 추가했습니다.
- 대화창의 이미지와 단독 이미지 파일을 모두 열고 확대/축소 및 이동(팬)할 수 있습니다. 데스크톱에서는 컨텍스트 메뉴에서 복사하거나 저장할 수도 있습니다.
- 에이전트 인증이 만료되었을 때 세션을 다시 만들지 않고도 Lody 앱 내에서 에이전트를 재인증할 수 있습니다.
- 에이전트 오류를 펼쳐 전체 세부 정보를 확인하고, 한 번의 클릭으로 진단 정보를 복사할 수 있습니다. 모바일에서도 오류 세부 정보를 모두 확인할 수 있습니다.
- 워크스페이스 초대, 참여 승인 및 비공개 리소스 공유 흐름을 개선하고, 공유 가능한 머신이나 프로젝트가 없을 때 더 명확한 안내 메시지를 표시합니다.
- 이제 로컬 프로젝트를 가져온 후 자동으로 해당 프로젝트를 엽니다.
- 모바일 웹에서도 결제 설정에 접근할 수 있습니다.

### 🐛 버그 수정 및 개선 사항

- 파일 트리를 스크롤하거나 세션을 전환할 때 메인 스레드 작업량을 크게 줄여, 대규모 프로젝트, 세션 전환 및 오른쪽 사이드바 재열기 동작이 훨씬 부드러워졌습니다.
- 백그라운드 동기화, 데이터 영속성 및 재연결로 인한 CPU 및 메모리 부하를 줄였습니다. 네트워크가 불안정하거나 단일 동기화 룸에 문제가 발생하더라도 더 이상 전체 워크스페이스에 고빈도 재연결 폭주가 발생하지 않습니다.
- 로컬 세션이 유휴 상태였던 후 간헐적으로 발생하던 동기화 실패 및 에이전트 응답 지연과, 세션 복원 시 브랜치가 유실되던 문제를 수정했습니다.
- 실행 중인 에이전트에 전달되지 못한 스티어링 메시지가 멈춘 채 남아 있을 수 있던 문제를 수정했습니다. 메시지를 즉시 삽입할 수 없는 경우, 이제 다음 일반 턴을 위해 대기열에 추가됩니다.
- 멀티 워크스페이스 환경에서 Git 작업 시 잘못된 계정의 자격 증명을 사용하던 문제와, 로컬 브랜치와 원격 브랜치의 이름이 같을 때 이전 세션이 복원되지 않던 문제를 수정했습니다.
- 모바일에서 Plan Mode 토글이 다시 정상 작동합니다.
- 메시지 복사 버튼이 반응하지 않던 문제를 수정했습니다.
- 이제 스마트폰을 가로 모드로 전환해도 모바일 레이아웃을 유지하며, 웹 앱이 사용자 상호작용 없이 네이티브 앱을 열려고 시도하지 않습니다.
- 모바일 서랍(drawer)의 드롭다운 오류, 잘린 통계 표시, 잘린 에이전트 이름, 그리고 너무 긴 프로젝트 경로가 대화상자 밖으로 넘치던 문제를 수정했습니다.
- 이제 앱 충돌 페이지에 읽기 쉬운 오류 내용이 표시되며 리포트를 복사할 수 있습니다. 복구가 반복적으로 실패할 경우 사용자가 확인 후 로컬 데이터를 지우고 다시 로그인할 수 있습니다.
