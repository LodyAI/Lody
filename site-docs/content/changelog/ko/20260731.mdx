### ✨ 새로운 기능

- 세션 포크 기능을 추가했습니다. 에이전트 응답 아래의 Fork 버튼을 사용하면 해당 응답 시점부터 세션을 분기할 수 있으며, Codex와 Claude Code에서는 세션의 어느 지점에서든 포크할 수 있습니다.
- 오른쪽 사이드바를 새롭게 디자인하고 Browser와 Side Chat을 추가했습니다.
- Browser에서는 로컬 세션의 모든 URL을 열 수 있으며, 원격 세션의 경우 해당 세션이 실행 중인 머신의 포트에 접근할 수 있습니다. 에이전트의 Browser 제어는 아직 지원되지 않습니다.
- 동적으로 생성된 Lody 세션에서도 대화 도중 모델 및 추론 강도(reasoning effort)를 설정할 수 있습니다.
- 보관된 세션에 검색 및 정렬 기능을 추가했습니다.

### 🐛 버그 수정 및 개선 사항

- 라이트 모드에서 순수 흰색 배경을 사용하도록 업데이트했습니다.
- 모바일 UI의 일부를 다듬었습니다.
- 모바일에서 메시지를 보낸 후 키보드가 간헐적으로 닫히지 않고 남아 있던 문제를 수정했습니다.
- 로컬 퍼스트 모드에서 세션 동기화가 실패할 수 있던 문제를 수정했습니다.
- 새 세션 생성 흐름에서 프로젝트 목록이 끝까지 스크롤되지 않아 모든 프로젝트가 표시되지 않던 문제를 수정했습니다.
- CLI의 CPU 및 메모리 사용량을 줄였습니다.
- 머신 온라인 상태 표시의 안정성을 개선했습니다.
- 세션 검색 시 도구 호출과 그 결과를 제외하고 메시지 내용만 검색하도록 개선했습니다.
