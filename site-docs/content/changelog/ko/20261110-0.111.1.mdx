버전 0.111.1

### ✨ 새로운 기능

- **읽기 전용 대화 공유**: 전체 컴퓨터에 대한 접근 권한을 부여하지 않고도 팀 전체나 선택한 멤버에게 개별 대화를 공유할 수 있습니다.
- **예약된 작업 소유자 표시 및 필터**: 이제 작업 목록에 각 작업의 소유자가 표시됩니다. 내 작업, 다른 사람의 작업, 전체 작업으로 필터링해 팀 작업을 더 쉽게 찾을 수 있습니다.

### 🐛 수정 및 개선

- 일부 메시지 처리 실패로 인해 대화의 이후 메시지가 정상적으로 표시되지 않던 문제를 수정했습니다.
- 데스크톱 앱에서 일부 로컬 이미지를 불러오지 못하던 문제를 수정했습니다.
