버전 0.108.1

### ✨ 새로운 기능

- “지금(Now)” 및 “이번 주(This Week)” 보기를 갖춘 새로운 대화 홈을 선보입니다. 확인이 필요하거나 실행 중이거나 최근 완료된 대화를 최근 작업 및 에이전트 요금제 사용량과 함께 한눈에 볼 수 있습니다.
- 프로젝트별로 기본 MCP 도구를 설정할 수 있습니다. 새 대화는 프로젝트 설정을 따르며, 메시지를 보내기 전에 이를 조정할 수 있습니다.
- 전체 변경 사항(All Changes)에서 누적 브랜치 변경 사항과 함께 “커밋되지 않은 변경 사항(Uncommitted)” 보기를 제공하며 비교 기준(base)을 표시합니다.
- 워크스페이스 추천 리워드를 추가했습니다. 추천 링크를 공유하고 리워드 잔액 및 내역을 확인하며, 사용 가능한 크레딧을 구독 결제에 적용할 수 있습니다. 기간 한정 추천 캠페인도 지원합니다.
- 에이전트 작업 완료 알림에 답변 발췌문이 포함되어 대화를 열지 않고도 결과를 미리 확인할 수 있습니다.
- OpenCode V2를 추가하고 여러 ACP 에이전트를 업데이트했습니다.
- 예약 작업의 프롬프트 입력란이 내용 길이에 따라 창 높이의 약 절반까지 자동으로 확장되어 긴 지시문을 더 쉽게 편집할 수 있습니다.
- 활성 하위 대화가 있는 대화를 보관할 때 하위 대화 수와 실행 상태를 확인한 뒤, 함께 보관할지 현재 대화만 보관할지 선택할 수 있습니다.
- 라이트 테마, 사이드바 및 로그인 페이지를 새롭게 단장하고 초대, 기기 인증 및 관련 페이지 레이아웃을 통일했습니다. 또한 시작 속도 및 페이지 전환을 개선하고 이 기기에서 마지막으로 성공한 로그인 방식을 표시하는 안내를 추가했습니다.

### 🐛 수정 및 개선

- 대화 및 탭 전환 속도를 개선하여 긴 대화, 스트리밍 출력, 기록 로딩 중 발생하는 멈춤 현상을 줄였습니다.
- 서브에이전트 도구 출력이 많은 대화의 로딩 성능을 개선했습니다. 불필요한 처리를 피하기 위해 작업 세부 정보는 필요할 때만 읽어옵니다.
- 기록 동기화를 개선하여 중복 전송 및 저장을 줄이고, 일부 상황에서 메시지 내용이 중복되던 문제를 수정했습니다.
- 재시작 후 수신된 일부 동기화 업데이트가 유실될 수 있던 문제를 수정하여 로컬 데이터 유지력과 복구 성능을 높였습니다.
- 저장소 오류 후 동기화 복구 방식을 개선하여 반복 다운로드와 과도한 트래픽을 줄이고, 로컬 데이터베이스 연결이 복구되지 않던 문제를 수정했습니다.
- 네트워크 중단 후 재연결 동작을 개선하고, 수동으로 새로고침할 때까지 대화 동기화가 멈추던 문제를 수정했습니다.
- 네트워크 오류 발생 시 데스크톱 세션 상태가 유실되던 문제를 수정했습니다.
- 디스크 공간 부족으로 데스크톱 쓰기 작업이 실패할 때 명확한 안내 메시지로 추가 UI 조작을 차단하고, 재시작하거나 종료하기 전에 공간을 확보하도록 안내합니다.
- CLI가 비정상적으로 종료될 때 오류가 반복되고 로그가 과도하게 커지며 프로세스가 종료되지 않던 문제를 수정했습니다.
- Windows에서 권한 오류 후 로컬 에이전트가 “연결 중(Connecting)” 상태에 멈춰 있던 문제를 수정하고 복구 안내를 추가했습니다.
- 응답 지연으로 재시도가 발생할 때 Lody MCP가 대화를 중복 생성하던 문제를 수정했습니다.
- 에이전트가 이미 답변을 마친 후에도 파일 변경 새로고침이 계속되어 대화가 종료 중 상태에 머물거나 중단 작업이 오래 걸리던 문제를 수정했습니다.
- 기록을 불러오는 도중 에이전트 질문 카드가 가끔 표시되지 않던 문제를 수정했으며, 답변을 기다리는 동안에는 작업 시간이 계속 늘어나지 않도록 변경했습니다.
- Claude의 실행 제안을 거절한 후에도 기존 계획(plan)이 계속 표시되도록 유지합니다.
- 비정상적인 실행 상태로 인해 입력을 받을 수 없는 대화에 대해 더 명확한 오류 메시지와 수동 CLI 복구 경로를 추가했으며, 대기 중인 입력도 보존합니다.
- 커스텀 ACP 에이전트 기록 동기화, 가져오기 및 충돌 처리가 거부되던 문제를 수정했습니다.
- PR을 병합하거나 닫아도 해당 대화가 자동으로 보관되지 않아 후속 작업이 중단되지 않습니다.
- 이제 대화 제목은 에이전트 설정이나 역할 지침 없이 사용자의 실제 입력을 기반으로 생성됩니다. 분기(포크)된 대화 제목에도 자동 접두사가 붙지 않습니다.
- CLI 또는 Lody MCP를 통해 에이전트 역할로 대화를 생성할 때, 역할 지침이 표시되는 사용자 메시지나 대화 제목에 노출되지 않도록 수정했습니다.
- DSH 텍스트와 도구 호출이 독립적으로 표시되어 도구를 접어도 함께 출력된 텍스트가 숨겨지지 않습니다. 또한 생각(thought) 과정의 타이포그래피를 개선하고 오래된 위임 모델 경고를 제거했습니다.
- Markdown 파일 미리보기 내의 대화 링크가 정상적으로 열리도록 수정했습니다.
- 중첩된 Git 워크트리에서의 상대 파일 링크 처리를 수정했습니다. 일치하는 파일이 여러 개인 경우 열 파일을 선택할 수 있습니다.
- 구문 강조와 스크롤바를 개선하고, 높이가 낮은 창에서의 홈 페이지 레이아웃, 접기 컨트롤 및 전환 애니메이션을 다듬었습니다.
- 대화 공유 컨트롤을 개선하여 접근 범위, 링크 게시 및 링크 관리를 하나의 패널로 통합했습니다.
- 멤버 아바타, 스킬 세부 정보 및 사용량 보기를 개선하고, 아바타 깜빡임, 메뉴 포커스 문제, Windows 창 버튼에 예약 작업 컨트롤이 가려지던 문제를 수정했습니다.
- 워크스페이스 테두리를 더 얇게 다듬고 macOS 제목 표시줄 및 창 버튼 정렬을 개선했습니다.
- iOS 16.4에서의 웹 시작 오류와 diff 보기 테마 색상을 수정했습니다.
- DimCode 아이콘을 업데이트하고 유의미한 내용이 없는 작업 성공 확인(receipt) 표시를 숨겼습니다.
