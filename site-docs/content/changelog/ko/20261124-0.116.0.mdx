버전 0.116.0

### ✨ 새로운 기능

- 네이티브 클라이언트에서 일정(schedule) 제안을 편집하고, 웹 앱에서 시스템 공지를 확인할 수 있습니다.
- Today 멘션을 대화로 드래그할 수 있으며, 생성된 인터페이스에서 더 다양한 안전한 SVG 다이어그램을 렌더링할 수 있습니다.

### 🛠️ 개선 사항

- 입력창(composer) 첨부 파일이 업로드 진행률, 재시도, 삭제 동작을 포함한 더 명확한 컴팩트 카드로 표시됩니다.
- 오래 사용된 워크스페이스에서 미사용 SQLite 저장 공간을 자동으로 회수합니다.
- WebSocket append 지원으로 실시간 Streams 업데이트가 개선되었습니다.

### 🐛 버그 수정

- 패키징된 macOS 빌드에서 내장 JavaScript ACP 에이전트가 시작되지 않던 문제를 수정했습니다.
- 첨부 파일 백필(backfill), 공유 요청, 사이드바 및 Markdown 작업 목록의 엣지 케이스를 수정했습니다.
