버전 0.113.0

### ✨ 새로운 기능

- Antigravity와 DeepSeek Harness를 기본 내장으로 추가하고, Codex, Claude Code, Kimi, Grok, Devin, Pi를 업데이트했습니다.
- QR 코드 및 일괄 기기 페어링, 복구 볼트(recovery vault), iOS 복구 백업 내보내기 기능을 추가하고 기기 이름을 개선했습니다.
- 이제 일정을 지정한 분 또는 시간 간격마다 반복하도록 설정할 수 있습니다.
- 데스크톱과 모바일에서 로컬 HTML 파일을 미리 볼 수 있습니다. 모바일에서는 Markdown 파일 열기와 Plan Mode 계획 보기도 지원합니다.
- 세션 상태 보기, 대화 개요(outline), 빈 프로젝트 숨기기 옵션을 추가했습니다. 시간대별 AI 사용량은 이제 현지 시간대를 따릅니다.

### 🐛 수정 및 개선

- 암호화 워크스페이스 페어링, 키 업데이트, 복구 과정을 개선하여 대기 시간을 줄이고 복구 진행 상황을 확인할 수 있도록 했습니다.
- 인증이 복구되거나 네트워크가 변경될 때 발생하던 중복 요청, 동기화 지연, 세션 열기 문제를 수정했습니다.
- 백그라운드 작업의 실행 중 및 완료 상태를 더 정확하게 개선하고, 완료된 작업이 세션을 다시 깨울 수 있도록 했습니다.
- 모바일 로그인 복귀 흐름, 긴 대화, iPad 내비게이션, 초안(draft) 유지 관련 문제를 수정했습니다.
- 인용 삽입, 멘션 편집, 사고 과정 및 도구 접기, 변경된 파일 통계 표시를 개선했습니다.
