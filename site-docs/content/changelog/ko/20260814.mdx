Version 0.81.0

### ✨ 새로운 기능

- 직접 DeepSeek API 키 설정, 에이전트 프리셋, 세션 내 Lody MCP 접근을 포함한 기본 DeepSeek Harness 지원을 추가했습니다.
- 에이전트가 생성한 독립 세션이나 하위 세션이 이제 원래 세션 아래에 그룹화되어 표시되며, 양방향 관계 정보와 빠른 이동을 지원합니다.

### 🐛 버그 수정 및 개선 사항

- 긴 대화와 스트리밍 응답에서 스크롤 추적 동작을 개선하여, 위로 살짝 스크롤한 뒤 예기치 않게 화면이 튀는 현상을 줄였습니다.
- 좁은 화면의 모바일 설정 레이아웃, 구분선 및 작업 버튼의 가독성을 개선했습니다.
- 경로의 대소문자 또는 유니코드 정규화 방식이 다르거나 파일 이름에 특수 문자가 포함된 경우 워크스페이스 파일의 미리 보기나 저장이 가끔 실패하던 문제를 수정했습니다.
- Linux KDE 데스크톱 환경에서 작업 표시줄 아이콘을 복원했습니다.
