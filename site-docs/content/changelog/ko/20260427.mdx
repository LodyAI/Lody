### 에이전트 경험

- GPT-5.5 지원을 추가했습니다.
- 새로운 카테고리 사이드바와 지원 기능 새로고침 흐름을 도입해 Agent 설정 페이지를 새롭게 개편했습니다.
- 토큰만 붙여 넣어 빠르게 설정을 마칠 수 있는 DeepSeek 프리셋을 추가했습니다.
- Claude Code 및 Codex와 같은 에이전트의 연결 안정성과 기능 감지 정확도를 개선했습니다.
- macOS에서 Codex 사용 시 `ComputerUse` 오류 팝업이 표시되던 문제를 수정했습니다.

### 데스크톱 경험

- 이제 왼쪽 사이드바를 접거나, 드래그하여 크기를 조절하고, 키보드 단축키로 전환할 수 있습니다.
- 로컬 프로젝트, GitHub Worktrees, Chat 섹션이 더욱 명확해졌으며, 사이드바 상호작용이 한층 일관되게 개선되었습니다.
- 이제 세션 내 로컬 파일 목록이 자동으로 새로고침되어 변경 사항을 실시간으로 더 쉽게 확인할 수 있습니다.

### 대화 경험

- 스트리밍 중인 코드 블록이 구문 강조 렌더링과 일반 텍스트 렌더링 사이에서 깜빡이던 현상을 해결했습니다.
- 세션 초기화와 전환이 더욱 안정화되어 간헐적으로 발생하던 로딩 혼선을 줄였습니다.

### 기타 수정 사항

- 원격 프로젝트에서 로컬 감지가 잘못 실행되던 문제를 수정했습니다.
- 머신 온라인 상태와 실시간 동기화가 더욱 정확해졌습니다.
- Electron 내부 CLI 출력 영역의 하단 여백 문제를 수정했습니다.
