### 새로운 기능 및 역량

- JSON, Markdown, 첨부 파일, 사용량 통계를 포함한 세션 데이터를 내보낼 수 있는 새로운 `lody export` CLI 명령어를 추가했습니다. **다음 주에 새로운 동기화 백엔드로 전환될 예정이며 이전 기록 데이터는 호환되지 않으므로, 보관하려는 데이터는 미리 내보내 두시기 바랍니다**
- 모든 ACP 에이전트에 대해 사용자 지정 제목 생성 모델 지원 추가
- 이제 세션이 승인을 기다리는 동안 권한 요청 배너가 입력창 위에 고정되어 스크롤해도 사라지지 않습니다
- 머신 선택기가 Agent Config 드롭다운에서 분리되어 머신을 단독으로 선택하기가 더욱 쉬워졌습니다
- 이제 채팅에서 파일 경로를 클릭하면 전체 파일이 올바르게 열립니다

### 플랫폼 및 UI 경험

- 좁은 화면에서도 세션 구성 버튼이 찌그러지거나 잘리지 않습니다
- 모바일에서 채팅 입력창 하단 영역이 버튼을 뭉개지 않고 적절히 줄바꿈됩니다
- 모바일의 사용량 차트와 통계 카드가 가로로 넘치지 않고 작은 화면에 맞게 표시됩니다

### 수정 사항 및 안정성

- 이제 ACP 오류가 구체적인 근본 원인을 표시합니다
- 사용 가능한 키링(keyring) 백엔드를 자동으로 감지하여 Sway, Hyprland, Niri를 포함한 GNOME 이외의 Linux 환경에서 발생하던 데스크톱 인증 실패 문제 수정
- 비어 있는 원격 저장소에 대한 worktree 생성 실패 문제 수정
- 대량의 파일이 변경될 때 너무 많은 동시 `git show` 작업으로 인해 발생하던 CPU 멈춤 현상 수정
- `#` 멘션이 캐시를 새로고침하지 못했을 때 오래된 Issue 및 PR 메타데이터가 재사용되던 문제 수정
