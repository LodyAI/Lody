버전 0.109.0

### ✨ 새로운 기능

- 다중 저장소(Multi-repository) 프로젝트: 여러 Git 저장소, 서브모듈 및 로컬 폴더를 하나의 프로젝트로 묶어 같은 대화에서 저장소를 넘나드는 작업을 수행할 수 있습니다. 설정 → 프로젝트에서 추가하거나 데스크톱 사이드바에서 기존 프로젝트를 마우스 오른쪽 버튼으로 클릭해 추가하세요. (iOS에서는 다음 모바일 TestFlight 빌드가 나올 때까지 다중 저장소 대화가 표시되지 않습니다.)
- 저장소별 PR 보기: 다중 저장소 대화에서 표시할 저장소를 전환하여 해당 저장소의 PR, CI 상태 및 작업을 확인할 수 있으며, 서브모듈은 계층 구조로 표시됩니다.
- Magpie CLI 가져오기: CLI를 통해 Magpie 공급자 설정을 가져올 수 있어 데스크톱 환경이 없는 머신에서도 사용할 수 있습니다.
- 다음 프롬프트 추천: Claude Code가 비어 있는 입력창에 에이전트가 반환한 추천 프롬프트를 표시합니다. 데스크톱에서는 Tab 키를 누르고, 모바일에서는 “적용(Apply)”을 탭해 입력할 수 있습니다.
- 로컬 MCP 로그인: 브라우저 인증, 로그아웃 및 수동 자격 증명 입력을 지원합니다. 자격 증명은 로컬 시스템 자격 증명 저장소에 보관되며 워크스페이스 설정과 동기화되지 않습니다.
- 개편된 예약(Schedules) 페이지: 프로젝트 및 상태 필터, 정렬, 설정 및 실행 기록 보기, 완료된 예약 메시지 일괄 정리 기능을 제공합니다.
- 분류된 작업 탭: 서브에이전트와 백그라운드 작업이 별도의 탭으로 나뉘어 표시되어 실행 진행 상황을 더 쉽게 파악할 수 있습니다.
- 머신 간 역할(Role) 협업: 로컬 프로젝트에서 원격 역할을 호출할 때 프로젝트에 연결되고 워크스페이스에 연동된 GitHub 저장소를 사용할 수 있으며, 연결된 대화는 목록에 중첩되어 표시됩니다.
- iPhone Duo 지원: 모바일 레이아웃이 사용 가능한 화면 공간에 맞춰 유동적으로 조정되어 화면을 접거나 펼칠 때와 분할 화면 경험이 개선되었습니다.
- 예약 메시지: 메시지, 첨부 파일 및 참조를 예약하고 이후 수정하거나 취소할 수 있습니다. 대상 머신이 오프라인 상태라면 유효 기간 내에 머신이 다시 온라인으로 복귀하는 즉시 보충 전송됩니다.
- Claude 할당량 초기화 후 계속 실행: 한 번의 클릭으로 할당량이 초기화된 후 `continue` 메시지가 전송되도록 예약해 작업이 마저 완료될 수 있게 합니다.
- DeepSeek Harness 플러그인 관리: 기존 사용자 설정을 유지하면서 로컬 CLI를 통해 공급자 플러그인을 관리할 수 있습니다.
- 사용량 초기화 시간: 상대 시간(“… 후 초기화”) 표시와 사용자의 로컬 시간대 기준 절대 날짜/시간 표시 간에 전환할 수 있습니다.
- 더 큰 원격 파일 다운로드: 유료 워크스페이스에서는 최대 100 MiB 크기의 파일을 다운로드할 수 있습니다. 파일이 있는 머신의 CLI도 함께 업데이트해야 합니다.

### 🐛 수정 및 개선

- 대화 내용이 업데이트될 때 기존 텍스트가 잘못 덮어써지던 문제를 수정했습니다.
- 저장소 간 PR 연결 및 상태 동기화를 개선하여 상태 업데이트가 기존 PR 링크에 영향을 주지 않도록 했습니다.
- 짧은 재연결 중 사이드바의 머신 온라인 상태 표시가 깜빡이던 문제를 수정했습니다.
- 일반 환경 변수를 추가한 후 일부 공급자의 구독 사용량 정보가 사라지던 문제를 수정했습니다.
- DeepSeek 대화가 완료된 후 과정 출력을 자동으로 접어 최종 답변을 더 읽기 쉽게 개선했습니다.
- 모바일 메시지 대기열 작업 버튼, 메모리 목록의 역할 레이블 정렬, 데스크톱 로그인 페이지의 아이콘 표시를 개선했습니다.
- 탭 대화가 지정되지 않은 한, 에이전트가 하위 대화를 생성할 때 기본적으로 새 대화를 우선 사용하도록 변경했습니다.
- 데스크톱 로그인 복구 동작을 개선하여 시작 시 네트워크 응답이 느릴 때 의도치 않게 로그아웃되는 현상을 방지했습니다.
- 동기화 순서가 바뀔 때 메시지 대기열이 이어서 전송되지 않던 문제와 비정상 종료된 작업이 여전히 실행 중으로 표시되던 문제를 수정했습니다.
- 새 대화를 만들 때 원격 MCP 기본값 동기화를 기다리지 않도록 개선했으며, 대량 대화 생성 시에도 선택한 MCP 설정이 유지됩니다.
- 실행 중인 백그라운드 작업이 사라지던 문제와 Claude 작업 완료 후 실행자(executor) 정보가 유실되던 문제를 수정했습니다.
- Kimi가 계획 승인을 요청하기 전에 전체 계획을 먼저 표시하도록 수정했습니다.
- Pi에서 모델을 전환한 후 추론 강도 옵션이 모델 기능과 일치하지 않던 문제를 수정했습니다.
- Codex 런타임을 업데이트하여 스킬 목록 새로고침, 컨텍스트 압축 완료 감지, 공급자 전환 후 오류 메시지를 개선했습니다.
- 서브모듈 체크아웃이 불완전할 때 다중 저장소 프로젝트 시작이 실패하던 문제를 수정하고, 폴더 경로 표시 및 사이드바 보관·접기 동작을 개선했습니다.
- PR 충돌 해결 작업이 현재 대화에서 열리지 않던 문제와 모바일에서 이름 변경 시 다른 대화에 잘못 영향을 주던 문제를 수정했습니다.
- 정상적인 Nowledge Mem 연결이 실패로 잘못 보고되던 문제를 수정했습니다.
- 모바일 머신 관리 버튼과 뒤로 가기 제스처 간의 충돌을 개선하고, 터미널 탭, 로그인 텍스트 및 홈 상태 표시를 다듬었습니다.
- Claude가 할당량 한도에 도달했을 때 프롬프트 카드에서 바로 초기화 이후 `continue` 메시지 전송을 예약할 수 있으며, 예약 시간은 인터페이스에 표시된 시간과 일관되게 유지됩니다.
- 예약 전송을 사용할 수 없을 때 마우스를 올리면 구체적인 사유를 확인할 수 있습니다.
- 모바일에서 첫 메시지를 보낼 때 인터페이스와 키보드 간의 전환을 개선했으며, 새 대화 시작 시 마지막으로 사용한 프로젝트를 복원합니다.
- 모바일 메시지 대기열에 간결한 한 줄 레이아웃을 적용했습니다.
- 여러 버전의 Lody가 설치되어 있을 때의 링크 열기 동작을 개선하여 대화, 새 대화 및 공급자 가져오기 링크를 현재 실행 중인 버전에 전달합니다.
- 에이전트 프롬프트 카드와 추론 내용의 정렬, 색상 및 인라인 코드 스타일을 개선하여 시각적 복잡도를 낮췄습니다.
- 예약 메시지를 더욱 쉽게 관리할 수 있습니다. 전송 버튼 옆에 예약 시간이 표시되고 예약 메시지가 메시지 대기열에 모아지며, 시간 변경, 내용 편집, 취소를 바로 수행할 수 있습니다.
- 메시지 대기열 레이아웃을 개선했습니다. 휴대폰과 좁은 창에서는 간결한 한 줄로 표시되고 작업은 “더 보기(More)” 메뉴로 묶이며, 완료된 일회성 예약 메시지 기록은 7일간 보관된 후 자동으로 정리됩니다.
- 온보딩 중 입력창 프롬프트 추천과 관련된 호환성 문제를 수정했습니다.
- 실행 중인 작업을 중단한 직후 보낸 메시지까지 함께 취소되던 문제를 수정했으며, 작업 중단에 실패할 경우 그 사유가 대화에 표시됩니다.
- 같은 머신의 에이전트가 MCP를 통해 실행 중인 대화로 메시지를 보낼 때 활성 작업의 방향을 직접 제어(steer)할 수 있습니다.
- 예약 작업의 추가 실행 슬롯 제한을 제거하여 작업 간 대기 시간을 줄였습니다.
- 새로 만든 프로젝트가 자동으로 선택되며, 프로젝트 선택기에서 프로젝트 그룹을 바로 편집할 수 있습니다.
- 프로젝트 서브모듈을 준비할 때 로컬 Git 데이터를 재사용하여 반복 다운로드를 줄였습니다.
- 앱 미리보기의 쿠키 전달 문제를 수정하여 로그인이 필요한 페이지의 미리보기 동작을 개선했습니다.
- 브라우저 로그인 페이지 오류와 잘못된 초대 링크에 대한 오류 처리를 수정했습니다.
- 모바일에서 멘션 메뉴가 스크롤되지 않던 문제와 중국어 환경에서 메시지 대기열 시간 형식이 잘못 표시되던 문제를 수정했습니다.
- 프롬프트 추천의 줄바꿈과 커서 표시를 개선했으며, 입력기(IME)로 조합 입력 중일 때는 추천을 일시적으로 숨깁니다.
- WebKit에서 내용을 읽는 중 스크롤 위치가 튀던 문제를 수정하고 공유 이미지의 선명도를 개선했습니다.
- 파일 링크 감지 및 경로 복사 기능을 개선하여 상대 경로로 인해 잘못된 위치로 이동하는 경우를 줄였습니다.
- 삭제된 대화의 전용 작업 디렉터리를 정리하도록 개선했으며, 보관 시에는 빈 디렉터리만 삭제하고 기존 파일은 유지합니다.
- 짧은 네트워크 지연으로 인해 온라인 머신이 오프라인으로 표시되고 대화 작업이 거부되던 문제를 수정했습니다.
- 예약 작업을 불러오지 못했을 때의 복구 동작을 개선하여 로컬 편집 내용을 보존하고 수동 재시도를 지원합니다.
- 일부 모델에서 추론 강도 옵션이 모델 목록과 맞지 않던 문제와 Pi 시작 시 모델 및 추론 강도 설정이 잘못된 순서로 적용되던 문제를 수정했습니다.
- DeepSeek Harness 시작 호환성을 개선하여 지원되는 Node.js가 없을 때 명확한 설치 안내를 표시합니다.
- 데스크톱 창 드래그 영역에 위치한 알림 버튼을 클릭할 수 없던 문제를 수정했습니다.
- 입력창에서 macOS Emacs 스타일 단축키로 커서를 파일 참조 앞뒤로 이동할 수 있도록 지원합니다.
