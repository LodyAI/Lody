버전 0.102.0

### ✨ 새로운 기능

- 페이지 이동, 확대/축소, 텍스트 검색 기능을 포함해 대화에서 PDF 파일을 직접 미리 볼 수 있습니다.
- 설정에 프롬프트 단축키(Prompt Shortcuts)를 추가했습니다.
- 이제 메시지 내 대화 링크가 클릭 가능한 대화 칩으로 표시되어 관련 논의로 쉽게 이동할 수 있습니다.

### 🐛 버그 수정 및 개선 사항

- 동기화 지연을 줄여 메시지 전송 응답성을 개선했습니다. 이미지 메시지를 보낼 때 미리보기가 제자리에 유지되어 레이아웃 이동을 줄입니다.
- 이제 데스크톱과 모바일 앱이 저장된 테마로 시작하여 라이트/다크 화면 전환 시 깜빡임을 줄입니다.
- 기본 진입 경로로 앱을 열면 바로 새 대화를 시작할 수 있는 채팅 랜딩 페이지로 이동합니다.
- 멘션 및 명령 메뉴가 커서를 따라가며, 줄 바꿈, 컴포저 스크롤, 모바일 키보드 표시 시 배치 위치를 개선했습니다.
- 프롬프트 단축키와 에이전트 명령어에 공통 순위 정렬을 적용해 슬래시 커맨드 검색을 개선함으로써 이름으로 항목을 더 쉽게 찾을 수 있습니다.
- 에이전트 역할 메뉴, 사이드바, 선택 옵션의 정렬을 개선하고, 텍스트 잘림 및 버튼 겹침 문제를 수정했습니다.
- 대화 Markdown 정렬, 인라인 수식 렌더링, 일부 도구 호출에서의 중복 명령어 표시 문제를 수정했습니다.
- 사용 가능한 시스템 키링이 없는 Linux 머신에서 새로 생성한 Codex 계정 프로필에 로그인할 때 발생하던 문제를 수정했습니다.
- 로컬 프로젝트가 기존 Git 및 GitHub 인증 설정을 유지하며, 에이전트 역할을 통한 크로스 머신 작업 전달을 개선했습니다.
