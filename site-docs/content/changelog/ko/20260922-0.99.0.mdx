버전 0.99.0

### ✨ 새로운 기능

- iOS의 화면(Appearance) 설정에서 Aqua 앱 아이콘을 선택하거나 기본 아이콘으로 다시 전환할 수 있습니다.

### 🐛 수정 및 개선

- 업그레이드 후 오래된 런타임 캐시로 인해 앱 시작이 실패하던 문제를 수정했습니다. 이제 필요한 경우 해당 런타임을 다시 다운로드하고 검증합니다.
- 런타임 캐시 정리나 업데이트 확인이 실패하더라도 다른 런타임을 중단시키지 않고 앱이 계속 시작되도록 개선했습니다.
