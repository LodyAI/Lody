### 원격 Preview 및 시각적 피드백

<img src="/_docs-assets/20260507-preview.png" alt="" />

- 로컬 개발 서버를 위한 세션 단위 실시간 미리보기인 Lody Preview를 추가했습니다. 예를 들어 에이전트에게 `Start the Vite dev server and use Lody Preview`처럼 요청해 보세요.
- 미리보기 패널에서 데스크톱, 태블릿, 모바일 뷰포트 간 전환, 화면 회전, 확대/축소, 화면 이동을 수행하거나 필요할 때 외부 브라우저에서 페이지를 열 수 있습니다.
- 시각적 주석 기능을 통해 미리보기에서 요소를 클릭해 코멘트를 남기고, 해당 요소가 참조된 피드백을 대화로 바로 보낼 수 있습니다.

### 사이드바 및 작업 관리

- Chat, GitHub Worktree, Local Project 세션을 최신순(Today, This week, Older)으로 묶어 보여주는 Updated 사이드바 정렬 모드를 추가했습니다.
- 세션 컨텍스트 메뉴에 이름 변경, 고정, 보관, 세션 URL 복사, 현재 브랜치 복사 기능을 추가했습니다.
- 고정된 세션은 목록 상단에 유지되어 오래 진행 중인 작업이나 중요한 작업을 쉽게 다시 찾을 수 있습니다.
- 웹 버전에서는 사이드바 작업을 가운데 클릭하거나 Cmd/Ctrl+클릭하여 새 탭으로 열 수 있습니다.

### 대화 및 입력

- 긴 텍스트를 붙여 넣으면 입력창을 가득 채우는 대신 인라인 플레이스홀더로 접힙니다. 플레이스홀더를 클릭하면 붙여 넣은 내용을 확인하거나 편집할 수 있습니다.
- 이미지를 입력창으로 바로 드래그하여 업로드할 수 있습니다.
- 모바일에서 이미지 미리보기를 길게 누르면 네이티브 공유 및 저장 메뉴가 열립니다.
- 파일 미리보기에서 긴 줄이 자동으로 줄바꿈되어 로그나 밀도 높은 생성 결과를 더 쉽게 읽을 수 있습니다.

### GitHub 및 Pull Request

- PR 패널에서 Draft PR을 바로 Ready for review 상태로 전환할 수 있습니다.
- PR이 병합되거나 닫힐 때 연결된 세션을 자동으로 보관할 수 있습니다.
- PR 코멘트, 리뷰 작업, 병합 시 개인 GitHub 계정을 사용할 수 있으며, 설정에서 연결된 계정을 확인할 수 있습니다.

### 수정 및 안정성 개선

- 로컬 프로젝트 가져오기에 성공한 뒤에도 실패 토스트 알림이 잘못 표시되던 문제를 수정했습니다.
- 프리셋 에이전트의 첫 번째 턴 대화에서 제목 생성 설정이 간헐적으로 누락되던 문제를 수정했습니다.
- 여러 사이드바 표시 오류를 수정했습니다.
- 모바일에서 드롭다운 메뉴가 화면 밖으로 벗어나던 문제를 수정했습니다.
