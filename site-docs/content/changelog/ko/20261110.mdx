버전 0.111.0

### ✨ 새로운 기능

- 세션 자동화가 URL을 확인하거나 로컬 명령어를 실행한 뒤 외부 조건이 충족되면 작업을 이어서 진행할 수 있습니다.
- 에이전트가 대상 세션에서 대기를 등록, 조회 또는 취소하여 여러 세션에 걸친 자동화를 관리할 수 있습니다.
- 이제 Mermaid 다이어그램이 대화 내에 인라인으로 표시됩니다.
- 같은 머신에서 사용하는 첨부 파일은 로컬에 그대로 유지됩니다. 에이전트가 원본 파일을 직접 읽을 수 있으며, 이미지를 보낼 때 원격 업로드를 먼저 기다릴 필요가 없습니다.
- 원본 컴퓨터에서는 로컬 이미지를 바로 미리 볼 수 있습니다. 다른 기기에서는 해당 컴퓨터의 로컬 첨부 파일을 다운로드할 수 있으며, 컴퓨터가 오프라인인 경우를 포함해 파일을 사용할 수 없는 이유도 확인할 수 있습니다.
- 에이전트가 현재 세션, Role, 상위 세션, 최초 시작 세션을 식별하여 협업을 더 정확하게 이어갈 수 있습니다.
- Claude, Kimi, Pi, DeepSeek Harness 어댑터가 추가 지침 및 재정의(override)를 포함한 표준 ACP 세션 시스템 프롬프트를 지원합니다.

### 🐛 수정 및 개선

- 프로바이더가 Role에 고정된 모델이나 권한 모드를 제거한 경우, 선택한 뒤에야 실패하는 대신 해당 Role을 사용할 수 없는 이유를 미리 표시합니다.
- Role 요약에 지원 기능 레이블이 포함되어 어떤 기능을 지원하는지 더 쉽게 파악할 수 있습니다.
- 커스텀 서비스 엔드포인트에 대한 로컬 프로바이더 로그인 및 API 키 입력 기능을 복원했습니다.
- Lody Agent 설정을 개선했습니다. 선택한 로그인 방식이 대상 머신에 정상 전달되고, 설정이 완료되기 전에도 커스텀 엔드포인트를 구성할 수 있으며, 로그인을 취소하면 대기가 즉시 종료됩니다.
- 모델 카탈로그가 예기치 않게 비어 있는 경우 새로 탐색(probe)을 실행하고 선택한 모델을 유지하며, 검증을 잘못 통과하는 대신 사용 가능한 모델이 없음을 보고합니다.
- 머신 상태 정보가 아직 업데이트되는 동안 새 탭에서 기존 에이전트를 사용할 수 없게 되던 문제를 수정했습니다.
- Claude 어드바이저 도구 결과가 정상적으로 완료되지 않던 문제를 수정했습니다.
- 내장 Codex 런타임을 0.166.0으로, Claude Code를 2.1.321로 업데이트했습니다.
- 내장 Devin 런타임을 3000.12.28로, DeepSeek Harness를 0.2.2-rc.1로 업데이트했습니다.
- 긴 응답을 더 읽기 쉽도록 DeepSeek의 사고 과정(thoughts)이 기본적으로 접힌 상태로 표시됩니다.
- 에이전트의 백그라운드 작업이 아직 실행 중일 때 세션 활성 상태가 정확하게 유지되어 작업이 일찍 완료된 것처럼 표시되는 경우를 줄였습니다.
- 시작에 실패한 후에도 세션 컨텍스트가 유지되어 더 쉽게 다시 시도할 수 있습니다.
- 에이전트 세션을 종료해도 사용자가 직접 연 터미널이 닫히지 않습니다.
- 오래된 데스크톱 스냅샷이 현재 상태를 덮어쓰거나 대화 업데이트 중 상태 변경이 반복되던 문제를 수정했습니다.
- 홈 화면에서 완료되었지만 읽지 않은 세션을 읽지 않음으로 명확히 표시하고, 초안(draft) Pull Request에는 구분되는 아이콘을 사용합니다.
- 사이드바에 로컬 세션 브랜치를 표시하고, 디렉터리를 공유하는 세션에 대해서는 오해를 부를 수 있는 독립 브랜치 정보를 숨겼습니다.
- 관련 대화의 탭이 많아질 때 좁게 눌리지 않고 가로로 스크롤되도록 개선했습니다.
- 데스크톱 종료 확인 및 취소 동작을 개선해 대기 시간을 줄였으며, 사이드 패널과 터미널을 닫은 후 리소스가 즉시 해제되지 않던 문제를 수정했습니다.
