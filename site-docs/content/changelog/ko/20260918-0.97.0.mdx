버전 0.97.0

### ✨ 새로운 기능

- 입력창(composer)에 세션 링크를 붙여넣으면 세션 멘션으로 자동 변환됩니다. 일반 링크 그대로 붙여넣으려면 Cmd/Ctrl+Shift+V를 사용하세요.
- 데스크톱의 Settings > Projects가 2단 카탈로그로 개편되었습니다. 왼쪽에 GitHub / 머신 목록이, 오른쪽에 선택한 소스의 폴더가 표시되며 폴더를 클릭해 편집할 수 있습니다.
- 대기열에 있는 메시지를 직접 스티어(steer)할 수 있습니다(에이전트가 확인 응답 기반 스티어링을 지원하는 경우 첫 번째 항목뿐만 아니라 모든 항목 가능). Cmd/Ctrl+Shift+Enter를 누르면 해당 전송에 한해 대기열 추가와 스티어 동작을 일시적으로 전환합니다.

### 🐛 버그 수정 및 개선

- 서명된 macOS 데스크톱에서 서명되지 않은 네이티브 애드온을 로드하는 DeepSeek Harness 및 기타 에이전트가 시작되지 않던 문제를 수정했습니다.
- 모바일 세션 메뉴에서 대화를 이미지로 공유할 수 있습니다.
- 대화 영역의 너비가 좁을 때 IDE 및 공유 작업이 ⋯ 메뉴로 이동합니다.
