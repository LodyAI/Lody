### 🐛 수정 및 개선

- GitHub와 Lody의 이메일 주소가 다를 때 개인 GitHub 인증이 실패하던 문제를 수정하고, 인증 후 설정 화면으로 돌아오는 흐름을 개선했습니다. 기존 사용자는 GitHub 설정에서 한 번 다시 인증해야 합니다.

- 앱 시작, 재연결 및 동기화 오류 이후 MCP 리소스 목록 복구 동작을 개선하여 리소스가 누락되거나 동기화 상태 업데이트가 멈추는 문제를 줄였습니다.
