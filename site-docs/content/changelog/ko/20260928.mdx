버전 0.101.0

### ✨ 새로운 기능

- 새로운 UI 디자인으로 사이드바, 설정, PR 패널, 도구 호출 상세 정보, 컴포저 메뉴를 새롭게 단장하고 일관된 라이트/다크 테마와 인터랙션을 제공합니다.
- 예약 작업에서 일회성 또는 반복 실행, 머신 및 에이전트 선택, 실행 기록 확인을 지원합니다. 에이전트가 일정을 제안하면 사용자가 확인한 뒤 생성할 수도 있습니다.
- Codex에서 여러 독립 계정은 물론 사용자 지정 API 엔드포인트와 키를 지원합니다.
- 새로운 서브에이전트 활동 상세 정보에서 지원되는 에이전트가 제공하는 작업 상태, 실행 기록 및 결과를 확인할 수 있습니다.
- 이제 에이전트 역할에 목적과 책임을 설명하는 설명 필드가 포함됩니다.
- 에이전트가 워크스페이스 내의 에이전트 역할, 머신, 프로젝트를 조회하여 적절한 구성과 실행 위치를 찾을 수 있습니다.
- 새로운 Lody Preview는 로컬 미리보기와 온디맨드 원격 미리보기를 지원하며, 더욱 명확한 연결 상태와 복구 안내를 제공합니다.
- 로컬 프로젝트에서 대화를 PR과 연결하고 머신의 GitHub 자격 증명을 사용해 PR 정보를 가져올 수 있습니다.
- 로컬 이미지와 온디맨드로 불러오는 원격 이미지를 포함해 Markdown 내 이미지를 볼 수 있습니다.
- 각 턴별 토큰 사용량을 확인할 수 있습니다.
- 대화 정보 표시줄에서 관련 대화 트리를 열 수 있습니다.
- Pi에서 로컬 확장을 스캔 및 선택하고 대화 기록을 가져올 수 있습니다. Grok은 전체 대화 또는 이전 턴에서의 포크를 지원합니다.
- 전체 너비 대화, 폰트 합자(ligatures), 인라인 수식 렌더링 옵션이 새로 추가되었습니다.
- 아바타를 자르고, macOS에서 선택한 앱 아이콘이 유지되도록 앱 아이콘을 선택할 수 있습니다.

### 🐛 버그 수정 및 개선 사항

- 스트리밍 응답 렌더링을 개선하여 Markdown을 점진적으로 표시하고, 깜빡임과 반복 애니메이션을 줄였습니다.
- 긴 대화에서의 스크롤과 대화 간 전환이 더욱 부드러워졌으며, 콘텐츠 튐과 빈 화면 현상이 줄어들었습니다.
- 첨부파일 업로드 및 대기 중 메시지 상태를 더욱 명확하게 표시하고, 중단 후 재시도 및 복구 기능을 개선했습니다. 크기가 큰 텍스트를 붙여넣으면 자동으로 텍스트 첨부파일로 변환할 수 있습니다.
- 메시지 편집 및 재전송 시에도 컴포저와 동일한 멘션 선택 기능을 지원합니다.
- 가져온 대화를 재개하거나 포크할 때 잘못된 에이전트 구성을 사용하던 문제를 수정하고, GPT-6 Sol 및 Luna의 확장 추론 옵션을 복원했습니다.
- 리포지토리 이름 변경 또는 이전 후 GitHub 자격 증명 선택 및 PR 연결을 개선했습니다. 이제 CI 상태에 최신 검사 결과가 반영됩니다.
- 새로고침 후 저장되지 않은 편집기 변경 사항이 유실되던 문제, 탭 보관과 닫기 간의 의도치 않은 상호작용, 반복적인 기록 복구 문제를 수정했습니다.
- 사이드바 그룹 상태, 전송 대기 표시기, macOS Dock 배지를 개선했습니다. 모바일 첨부파일 메뉴, 접힌 그룹 상태, diff에서 소스 파일로의 이동 문제를 수정했습니다.
- 이제 에이전트 로그인 시 런타임 다운로드 진행률이 표시되며 취소를 지원합니다. 최초 머신 연결 안내와 초기화 실패 메시지를 개선했습니다.
