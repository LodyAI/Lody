### 새로운 기능

- 완전히 새로운 모바일 UI 디자인을 적용했습니다.
- 에이전트가 질문할 때 입력창이 숨겨지며, 질문 카드 스타일이 더욱 깔끔하게 다듬어졌습니다.

### 수정 및 개선 사항

- 에이전트 질문에 대한 데이터 동기화 전략을 개선했습니다.
- 클라이언트에 오류가 발생했을 때 흰 화면으로 멈추지 않도록 복구 가능한 화면을 추가했습니다.
- 여러 이미지가 렌더링되지 않던 문제를 수정했습니다.
- 동기화 엔진을 개선했습니다.
