### 파일 / diff 보기

- 이제 워크스페이스 파일 목록을 실시간으로 확인할 수 있습니다
- 각 채팅이 끝나면 Lody가 모든 파일 변경 사항과 라인 증감을 요약해 주며, 클릭해서 diff를 확인할 수 있습니다.
  <img src="/_docs-assets/20260112-changelog.png" alt="" />

### GitHub 연동

- PR 생성 시 사용자 본인의 계정을 우선 사용하도록 개선했습니다

### 푸시 알림

- 설정에서 알림이 켜져 있으면 채팅이 완료될 때 알림을 보냅니다
- 에이전트가 권한을 필요로 할 때 알림을 보냅니다
- 에이전트의 첫 번째 응답 시 Lody가 푸시 알림 활성화 여부를 묻습니다
- 팀에 멤버를 초대하면 이메일을 발송합니다

### 기타

- 프록시 지원: CLI에서 HTTP 프록시를 통한 WebSocket 연결을 지원합니다
- GitHub 연동에 검색/필터 입력란을 추가했습니다
- 채팅 오프라인 접근을 지원합니다

## 수정 사항

- 수정: 세션 업데이트(계획/도구 호출)가 잘못 렌더링되거나 저장될 수 있던 Claude Code ACP 호환성 문제를 해결했습니다
- GitHub 연동이 만료되던 문제를 수정했습니다
- 새로고침 후 언어 전환이 적용되지 않던 문제를 수정했습니다
- 여러 UI 문제를 수정했습니다
