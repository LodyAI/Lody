버전 0.87.0

### ✨ 새로운 기능

- 대화 내용, Markdown 및 터미널을 읽기 선호도에 맞게 조정할 수 있도록 사용자 지정 대화 글꼴 크기 설정을 추가했습니다.
- 이제 HTML 첨부 파일을 실시간 미리보기로 바로 열 수 있습니다. 에이전트가 보고한 원격 포트에 연결하기 전에는 Lody가 먼저 확인을 요청합니다.

### 🐛 수정 및 개선

- 멘션된 Role을 통해 대화를 시작할 때 실패할 수 있던 문제를 수정했습니다.
- 대기 중인 메시지 편집 기능을 개선했습니다. Enter 키나 확인 버튼으로 제출하고 Shift+Enter로 줄바꿈할 수 있으며, IME 조합 중 의도치 않게 제출되지 않도록 방지합니다.
- Agent Role이 선택된 경우 중복되는 권한 버튼을 제거하여 설정 충돌과 화면의 복잡함을 줄였습니다.
- Windows에서 HTML 첨부 파일 경로가 올바르게 열리지 않던 문제를 수정했습니다.
- 대기 중인 메시지 편집기 주변에 테두리가 중복으로 표시되던 문제를 수정했습니다.
- 반복적인 스캔과 리소스 사용량을 줄이기 위해 세션 및 파일 변경 데이터 로딩과 캐싱을 최적화했습니다.
