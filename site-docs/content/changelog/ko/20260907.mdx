버전 0.92.0

### ✨ 새로운 기능

- 에이전트가 새 세션을 생성하면 카드가 즉시 표시되어 세션을 열고 실행 상태를 추적할 수 있습니다
- 이름, 설명, 작성자 또는 경로로 프로젝트 Skills를 검색할 수 있습니다
- 첨부 파일 및 미리보기에서 HTML 소스 파일을 직접 다운로드할 수 있습니다

### 🐛 수정 및 개선 사항

- 대용량 파일의 페이지 단위 읽기 및 더욱 효율적인 이미지·파일 로딩으로 로컬 파일 미리보기를 개선했습니다
- Factory Droid 연결 문제를 수정하고 선택한 모델에 맞는 올바른 추론 옵션을 표시하도록 개선했습니다
- Grok 도구 권한 동작과 심하게 단편화된 로컬 데이터 처리를 개선했습니다
- 탭 전환 후 새 채팅 첨부 파일이 사라지거나 이전 메시지에서 미전송 표시가 사라지던 문제를 수정했습니다
- 세션 작업 기간이 잘못 연장되거나 이전 출력이 제목 생성에 간섭하던 문제를 수정했습니다
- Linux .deb 업데이트 설치 시 앱이 멈추던 문제를 수정하고, 권한 부여가 취소되거나 설치가 실패한 후 재시도할 수 있도록 개선했습니다
- 완료된 일회성 작업의 다음 실행 시간이 다음 해로 잘못 표시되던 문제를 수정했습니다
- 데스크톱 입력창(composer) 포커스, 사이드바의 세션 계층 구조 표시 및 모바일 스크롤을 개선했습니다
- 팀 워크플로우에서 에이전트 세션 위임 및 완료 알림의 안정성을 개선했습니다
