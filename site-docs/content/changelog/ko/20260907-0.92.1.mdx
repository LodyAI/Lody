버전 0.92.1

### ✨ 새로운 기능

- 장기 실행 작업을 더욱 안정적으로 처리할 수 있도록 세션 실행 복구 및 피드백을 개선했습니다.

### 🐛 수정 및 개선 사항

- 관련 없는 이전 데이터의 유효성 검사 실패로 인해 세션 쓰기가 차단되던 문제를 수정했습니다.
- 완료된 작업이 다시 재생되지 않도록 방지하고 변경 사항이 없는 진행 상태 업데이트를 억제했습니다.
- 연결 실패 후 반복적인 재시도를 방지하도록 메타데이터 재연결 복구 기능을 개선했습니다.
- 읽을 수 없는 글꼴이 적용되지 않도록 모양 설정에서 기호 글꼴(symbol fonts)을 제외했습니다.
- 기호 글꼴 필터링 수정에 기여해 주신 외부 기여자 @Pleasure1234 님께 감사드립니다.
