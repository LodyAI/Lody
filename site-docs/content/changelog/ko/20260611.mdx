### 새로운 기능

- **iOS 실시간 현황(Live Activities) 및 Dynamic Island**: Lody를 열지 않고도 iPhone 잠금 화면과 Dynamic Island에서 에이전트 진행 상황을 추적할 수 있습니다. 에이전트의 승인이 필요할 때는 바로 응답할 수 있는 실시간 현황(Live Activity) 알림도 보냅니다.

  <img src="/_docs-assets/20260611-island.png" alt="Dynamic Island의 Lody 실시간 현황" />

- **워크트리 설정 및 정리 스크립트**: 워크트리가 생성된 후 에이전트가 시작되기 전에 실행되는 프로젝트 단위 스크립트와, 세션이 아카이브되고 워크트리가 제거될 때 실행되는 정리 스크립트를 설정할 수 있습니다.
- **모바일에서 프로젝트 파일 탐색**: 세션을 먼저 시작하지 않고도 모바일 프로젝트 화면에서 로컬 및 GitHub 프로젝트 디렉터리를 탐색하고 파일을 바로 열 수 있습니다.
- **실시간 프로젝트 파일 편집**: 로컬 또는 원격 세션에서 팀원들과 함께 현재 작업 디렉터리의 텍스트 파일을 실시간으로 공동 편집할 수 있습니다. 모바일 편집 기능도 곧 지원될 예정입니다.
- **파일 뷰어 내 Markdown 미리보기 및 검색**: 이제 Markdown 파일에서 클릭 한 번으로 원본 소스와 렌더링된 미리보기를 전환할 수 있으며, 텍스트 파일에서는 뷰어 내 검색 기능을 열 수 있습니다.
- **더욱 안정적인 Turn Diff 및 All Changes**: Diff 로딩이 한층 안정화되었으며, 이제 원격 기기에서도 파일과 diff를 더욱 일관되게 확인할 수 있습니다.
- **커스텀 ACP 에이전트**: 실행 명령어와 인자를 입력하여 ACP 호환 에이전트를 자유롭게 추가할 수 있습니다.

### 개선 사항

- 메시지 하단의 계획 전용 응답을 포함하여 Proposed Plan 카드에 복사 버튼을 추가했습니다.
- 로컬 프로젝트 선택기가 이제 머신 우선 방식으로 동작하며 더욱 안정적으로 개선되었습니다.
- 새 대화의 프로젝트 목록이 최근 활동 순으로 정렬됩니다.
- 미리보기(Preview)에 공유 링크 복사 버튼을 추가했습니다.
- 매우 긴 사용자 메시지가 채팅 말풍선 밖으로 넘치거나 잘리지 않도록 수정했습니다.
- 오른쪽 사이드바 접기 버튼이 전환 중에 옆으로 튀는 현상을 수정했습니다.
- 연결 상태가 불안정할 때도 공유된 머신과 프로젝트가 더욱 안정적으로 유지됩니다.
- 머신이 오프라인 상태일 때 대화 생성 화면에서 페이지가 반복해서 움직이던 문제를 수정했습니다.

### 제거된 기능

- Lody는 더 이상 PWA 지원을 제공하지 않습니다.
