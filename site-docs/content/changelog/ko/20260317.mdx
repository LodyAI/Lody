### 새로운 기능 및 역량

- [여기](/ko/download)에서 이용할 수 있는 데스크톱 앱 공식 출시
- 이미지 입력 지원 및 스크린샷 응답 기능 추가
<img src="/_docs-assets/20260317-lody-image-back.png" alt="" />
- 모든 ACP Registry 구성 옵션 지원 추가
- 전체 [CLI 명령어 세트](/ko/docs/cli) 추가: `session`, `workspace`, `history`, `agent-config`, `machine`

### 플랫폼 및 UI 경험

- 사이드바가 접혀 있을 때 그룹 개수를 표시하고, PR 세션에 PR 번호를 직접 표시
- 데스크톱 버전 표시 및 업데이트 확인 기능 추가
- Restart CLI 버튼 추가
- 세션이 실행 중일 때 시스템 절전 모드를 방지하며, 이를 비활성화할 수 있는 설정 제공
- 데스크톱 창 크기 및 위치 기억

### 수정 사항 및 안정성

- 토큰 사용량에 음수 델타(delta)가 표시될 수 있던 문제 수정
- Changes 탭에서 변경 횟수가 실제보다 부풀려져 표시되던 문제 수정
- 모바일 화면 방향 전환, Settings 및 Integrations 페이지 스크롤, 이미지 미리보기의 닫기 버튼 위치 관련 문제 수정
