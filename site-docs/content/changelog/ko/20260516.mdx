### 새로운 기능

- 이제 로컬 프로젝트 대화 기록 동기화가 더 많은 코드 에이전트를 지원합니다.
- 동기화 파이프라인과 상태 표시를 개선했습니다. 이제 대화를 열면 해당 스레드의 최신 내용을 필요에 따라 바로 가져오며, 상태를 한눈에 파악하기 쉬워졌습니다.

### 수정 및 개선 사항

- 모바일에서 입력창 아래에 콘텐츠가 많을 때 입력창이 겹치던 문제에 대한 임시 해결책을 적용했습니다.
- Codex Goal 실행 중 간헐적으로 비정상 상태에 빠지던 문제를 수정했습니다.
