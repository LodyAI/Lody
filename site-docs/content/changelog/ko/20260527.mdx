### 새로운 기능

- 이제 변경 사항(Changes) 보기에서 변경된 파일을 유형별로 그룹화할 수 있으며, 세션 사이드바에서는 코드 변경 사항만 집계할 수 있습니다.
- 대기열에 있는 메시지를 제자리에서 바로 편집하고 드래그 앤 드롭으로 순서를 변경할 수 있습니다.
- 이제 설정에서 워크스페이스 이름을 변경할 수 있습니다.

### 수정 및 개선 사항

- 새로 연 탭 대화 페이지에서 이미지 업로드가 작동하지 않던 문제를 수정했습니다.
- iOS Safari 16.0과 같은 구형 브라우저에서 지원되지 않는 정규식 후방 탐색(lookbehind)으로 인해 앱 초기화가 중단되어 시작 시 흰 화면이 표시되던 문제를 수정했습니다. 이제 Lody가 해당 사용자에게 브라우저 업그레이드를 안내합니다.
- 데스크톱 및 모바일 앱 시작 시 흰 화면이 나타나던 문제를 수정했습니다.
- 페이지 간 이동 중에 진행 중인 메시지 전송이 중단되던 문제를 수정했습니다.
- 미리보기 세션 상태가 동기화되지 않던 문제를 수정했습니다.
- 하위 탭의 활동이 상위 세션에 반영되지 않아 상위 세션 정렬 및 읽지 않음 상태가 부정확하던 문제를 수정했습니다.
- 앱이 시스템 테마 설정을 따르지 않던 문제를 수정했습니다.
- 마크다운 렌더링을 다듬었습니다. 한 줄짜리 코드 블록이 세로 중앙에 정렬되고, 블록 간격과 제목 크기가 유지되며, 목록 항목 간 간격이 뚜렷하게 표시되고, 가로 구분선이 다시 정상적으로 보입니다.
