버전 0.103.0

### ✨ 새로운 기능

- Codex GPT-6.1-Sol 모델을 지원합니다.
- 세션에서 Word(DOCX), Excel(XLSX), PowerPoint(PPTX) 문서를 직접 미리 볼 수 있습니다.
- 소스 편집 기능을 유지하면서 셀 검색 및 확대/축소를 지원하는 새로운 CSV 및 TSV 표 미리보기를 추가했습니다.
- PDF 미리보기에 썸네일 탐색, 회전, 추가 확대/축소 옵션을 포함했으며 문서 검색 기능을 개선했습니다.

### 🐛 버그 수정 및 개선 사항

- 모델을 전환하거나 역할을 적용한 후 추론 강도(reasoning effort)와 Fast 옵션이 잘못 표시되거나 적용되던 문제를 수정했습니다.
- 세션 탭을 전환할 때 발생할 수 있던 메시지 영역 충돌을 수정하고 읽기 위치 복원 기능을 개선했습니다.
- 컴포저의 @ 메뉴가 커서를 따라가고 사용 가능한 공간에 맞게 조정되도록 위치 지정을 개선했습니다.
- 만료되거나 취소된 GitHub 권한에 대한 안내 메시지를 개선하고, 일부 Git 커밋에서 작성자가 잘못 표시되던 문제를 수정했습니다.
- 내장 Codex 런타임을 업데이트하고 새 모델의 사용 비용 추정치를 추가했습니다.
- 일부 공개 웹사이트 페이지의 탐색 및 링크 대상 오류를 수정했습니다.

피드백을 공유하고 Lody에 기여해 주신 커뮤니티의 모든 분들께 감사드립니다.
