### 새로운 기능

- 업데이트된 추론 강도(reasoning effort) 옵션을 포함한 Codex 5.6 지원을 추가했습니다.
- 이제 기기가 오프라인 상태일 때도 로컬 프로젝트를 삭제할 수 있습니다.

### 수정 및 개선 사항

- 세션이 유효하지 않은 상태에 빠질 수 있던 문제를 수정했습니다.
- 하위 에이전트(subagent) 작업 목록 표시 방식을 개선했습니다.
- GitHub PR 작업의 안정성을 개선했습니다.
