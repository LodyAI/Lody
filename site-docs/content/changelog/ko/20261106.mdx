버전 0.110.1

### ✨ 새로운 기능

- 이제 Lody MCP가 온디맨드 명령어 도움말을 제공하여, 에이전트가 도구 목록에 상세 지침을 반복해서 포함하지 않고도 사용법과 매개변수를 조회할 수 있습니다.

### 🐛 수정 및 개선

- 원격 코드 diff 로딩을 개선하여 반복 전송을 줄이고 대용량 파일은 필요할 때 불러오도록 했습니다. 새로고침해도 읽던 위치와 펼쳐 둔 섹션이 유지됩니다.
- 연결 상태가 새로고침될 때 선택한 원격 머신이 예기치 않게 바뀌던 문제를 수정하고 오프라인 상태 표시를 개선했습니다.
- 프로젝트를 편집할 때 선택한 머신이 사라지던 문제를 수정하고 데스크톱에서 빈 프로젝트 그룹을 숨겼습니다.
- 대화 인용 기능을 개선했습니다. 같은 응답 내의 연속된 구절을 선택할 때 링크, 목록, 코드 등의 서식이 그대로 유지됩니다.
- 완료된 응답의 뒷부분 내용을 접는 기능을 복원했습니다.
- 대화 그룹 이름을 변경한 뒤 사이드바가 즉시 업데이트되지 않던 문제를 수정했습니다.
- 입력창(composer)의 멘션 표시를 개선하여 캐럿 경계에서 색상이 잘못 표시되거나 전송 후에도 멘션 상태가 남아 있던 문제를 수정했습니다.
- 암호화 세션에서 대기열 메시지(queued-message) 검증을 개선하고, 공유 권한이 아직 로딩 중일 때 메시지가 잘못 차단되던 문제를 수정했으며, CLI 페어링 및 키 상태 안내 메시지를 명확하게 다듬었습니다.
- Android 패키지에 푸시 설정이 누락되어 알림이 도착하지 않을 수 있던 문제를 수정했습니다.
