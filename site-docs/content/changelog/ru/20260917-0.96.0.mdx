Версия 0.96.0

### ✨ Новое

- Добавлено контекстное меню для ссылок на файлы в Markdown в десктопном приложении с действиями копирования пути, открытия файла, выбора приложения или показа файла в Finder.
- Добавлена панель диагностики разработчика в десктопном приложении для просмотра метрик среды выполнения и производительности.

### 🐛 Исправления и улучшения

- Количество предпросмотров сессий локального проекта теперь ограничено по умолчанию, с возможностью показать все сессии.
- Карточки запросов на публикацию общего доступа теперь скрываются после публикации.
- Исправлены повторные загрузки в публичном браузере при перенаправлениях, навигации по истории и переходах внутри одного документа.
- Сохраняется текст при вставке содержимого, скопированного из Word, PowerPoint и аналогичных приложений.
- Миграция Pi теперь отображается только на поддерживаемых машинах.
- Действие Fork скрывается до завершения ответа.
- Исправлен сбой загрузки некоторых нативных аддонов агентов на macOS.
- Улучшены восстановление и повторные попытки после сбоя подключения к локальной сессии Loro.
- Повышена контрастность элементов множественного выбора в архиве в тёмных темах.
- При переходе из карточки создания после закрытия вкладки теперь повторно открывается именно соответствующая дочерняя сессия.
- Позиция чтения сохраняется при разворачивании или сворачивании завершённого содержимого.
- Улучшено отображение субагентов Devin в диалогах.
- Последующие сообщения теперь наследуют модель и конфигурацию запуска целевой сессии.
- Улучшен вход через браузер в десктопном приложении во избежание некорректных состояний из-за дублирующихся обратных вызовов (callback).
- Обновлены версии встроенных сред выполнения агентов.
