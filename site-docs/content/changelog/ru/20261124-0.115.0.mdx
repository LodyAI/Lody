Версия 0.115.0

### ✨ Новое

- Зашифрованные рабочие пространства теперь подключаются к GitHub и поддерживают push-уведомления, Live Activities и клиенты входящих сообщений (inbox). В зашифрованных сессиях доступны быстрые команды промптов (Prompt shortcuts).
- Сохраняйте историю бесед Roost в зашифрованных рабочих пространствах, включая историю, принадлежащую конкретной машине, и открывайте к ней доступ с разных клиентов рабочего пространства. Существующие снимки OSS можно перенести, а удалённые CLI могут выполнять сопряжение с зашифрованными рабочими пространствами.
- Добавлена справка по тарификации использования и передачи данных для зашифрованных рабочих пространств.

### 🐛 Исправления и улучшения

- Файлы восстановления привязаны к каноническому источнику сайта (origin). Приглашения по электронной почте требуют явного подтверждения, а точки входа для восстановления отображаются только для зашифрованных рабочих пространств.
- Auto delivery теперь срабатывает только на основании доверенных данных о pull request и проверках.
- Исправлено чтение конфигурации агента для конкретных моделей, а также ряд ошибок отображения в Today, боковой панели, функции откладывания (snooze) и мобильной версии.
