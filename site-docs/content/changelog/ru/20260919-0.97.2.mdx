Версия 0.97.2

### 🐛 Исправления и улучшения

- Структура переписки теперь отображается только в длинных диалогах, чтобы не отвлекать внимание в коротких.
- Возвращён фирменный фиолетовый цвет GitHub для значков объединённых pull request.
- В режиме организации боковой панели теперь единообразно используется термин «Проект» (Project), чтобы избежать путаницы в терминологии.
