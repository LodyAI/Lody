Версия 0.89.4

### ✨ Новое

- Улучшен интерактивный процесс аутентификации для пользовательских провайдеров ACP.
- Улучшен первый запуск десктопного приложения: добавлены более понятные статусы и сценарии восстановления при возникновении проблем с настройкой.

### 🐛 Исправления и улучшения

- Исправлена несогласованность ролей агента, конфигурации и состояния между несколькими ходами сессии.
- Исправлена ошибка, из-за которой раздел «All Changes» включал содержимое из-за пределов текущего локального worktree.
- Исправлена ошибка, из-за которой средство обновления десктопного приложения сообщало об успехе при сбое установки.
- Улучшены скелетоны загрузки списков сессий и задач, а также локализованы подсказки по исправлению pull request.
- Исправлена ошибка, из-за которой подключения предпросмотра в продакшене использовали неверный домен окружения.
- Обновлена встроенная среда выполнения Claude Code.
- Благодарим внешних участников audichuang и ImSingee.
