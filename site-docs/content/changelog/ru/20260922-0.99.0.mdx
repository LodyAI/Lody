Версия 0.99.0

### ✨ Новые возможности

- На iOS в настройках внешнего вида теперь можно выбрать иконку приложения Aqua или переключиться обратно на стандартную иконку.

### 🐛 Исправления и улучшения

- Исправлены сбои запуска после обновлений, вызванные устаревшим кэшем сред выполнения. При необходимости затронутая среда выполнения загружается и проверяется заново.
- Приложение продолжает запускаться, даже если очистка кэша сред выполнения или проверка обновлений завершаются ошибкой, не нарушая работу других сред выполнения.
