Версия 0.97.1

### 🐛 Исправления и улучшения

- Исправлена ошибка, из-за которой агент принудительно останавливался примерно через 5 секунд после отправки направляющего сообщения встроенному Claude.
- Исправлен сбой входа в десктопном приложении на Windows, когда системное хранилище учётных данных больше не удаётся расшифровать (например, после восстановления машины под новой учётной записью): теперь вход восстанавливается автоматически, а при ошибке выводится более понятная причина.
- Восстановлена встроенная среда выполнения Devin.
- При закрытии нескольких вкладок подряд оставшиеся вкладки сохраняют свою ширину, чтобы следующая кнопка закрытия оставалась под курсором (как в Chromium).
- Закрытие вкладки, в которой не было ни одного сообщения, теперь удаляет её вместо того, чтобы оставлять невидимую сессию; при закрытии вкладки больше не появляется всплывающее уведомление, а у единственной вкладки больше не отображается кнопка закрытия.
- Пока агент работает, в переписке отображается мерцающий индикатор активности с прошедшим временем.
- После завершения операции (Operation) отправки сообщения отображается, до какой сессии (Session) оно дошло, а результат выводится в виде карточки полученного ответа; полный текст ответа можно открыть в диалоговом окне.
- Полную команду фоновой задачи можно открыть в диалоговом окне.
- В заголовке переключателя рабочих пространств отображается текущее рабочее пространство.
- Сообщения в очереди вплотную примыкают к полю ввода, а прикреплённые к ним изображения открываются во встроенном просмотрщике изображений.
- Изменённые файлы без статистики по строкам теперь помечаются соответствующей подписью вместо пустого значения.
- Доработка десктопного приложения: верхняя панель на macOS выровнена по кнопкам управления окном, повышена контрастность блоков кода в светлой теме, улучшено наложение поверхностей при наведении и в настройках, доработаны макет групп проектов в боковой панели и панель поиска по переписке, а размер шрифта многострочного кода приведён в соответствие с основным текстом переписки.
