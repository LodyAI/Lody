### 🧠 Поддержка Claude Opus 4.7

### 👥 Более безопасная совместная работа в команде

- Новые настройки видимости машин в команде: ваши машины **по умолчанию полностью приватны** для других участников — присоединяясь к чужому Workspace, больше не нужно беспокоиться, что ваша личная рабочая машина станет доступна или будет использована другими
- Открывайте доступ к машине для команды явным образом в разделе Settings; машины без общего доступа никогда не появляются в списках машин других участников, а диалоги на них никогда не попадают на их боковую панель
- «Присоединение к чужому Workspace» и «использование собственных машин» теперь полностью разделены — приглашайте коллег без лишних сомнений

### 🔐 Вход на любой машине одной командой

- Неинтерактивная аутентификация CLI: `lody login --auth <api-key>` подключает любую машину, а `lody start --auth <api-key>` позволяет войти и сразу запуститься в один шаг
- В десктопном приложении Electron добавлена панель настроек аккаунта для генерации и копирования API-ключа CLI

### 🆕 Режим Full Access

- Новый режим Lody Full Access автоматически одобряет запросы разрешений для агентов без встроенного режима полного доступа (например, Kimi, OpenCode)

### 🤖 Больше интеграций с агентами

- Улучшена интеграция с OpenCode и Kimi
- Исправлен разбор и отображение уведомлений Kimi о работе в терминале, чтении и редактировании файлов в истории

### 📱 Мобильная версия

- Переработана обработка экранной клавиатуры: клавиатура больше не сдвигает вверх весь интерфейс — плавно поднимается только область ввода
- На мобильных клавиатурах в поле ввода чата отображается клавиша «Отправить», по нажатию на которую отправляется сообщение
- Исправлено обрезание нижних элементов управления в iOS Safari, а также отступы safe-area для всплывающих уведомлений (toast) и страницы приглашений

### 🚀 Производительность и запуск

- Устранён белый экран при запуске для вернувшихся пользователей; интерфейс больше не блокируется сетевыми запросами
- Индексация поиска для длинных диалогов теперь ленивая и инкрементальная — больше никаких подвисаний при завершении диалога
- Добавлено кэширование сервиса синхронизации для ускорения холодного старта

### 🌐 Совместимость с браузерами

- Расширена поддержка до Safari 14+ / Chrome 80+ / Firefox 78+; старые браузеры больше не показывают белый экран из-за ошибок регулярных выражений или загрузки ESM

### 🛠️ Прочие исправления

- Исправлена проблема, при которой Docker-контейнеры повторно использовали ID хост-машины, что приводило к конфликтам потока событий
- При создании worktree теперь повторно используется выбранная ветка, отличная от ветки по умолчанию
- Десктопное приложение открывает ссылку на установку GitHub во внешнем браузере
- Исправлена ошибка 404 для Workspace при повторном входе в Electron
- Переключатель боковой панели сессий выровнен по заголовку
- Улучшена контрастность переключателя (Switch) в темах VS Code
