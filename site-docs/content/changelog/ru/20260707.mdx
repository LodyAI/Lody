### Новое

- В Claude Code теперь поддерживается быстрый режим (fast mode).
- В Claude Code теперь поддерживаются фоновые и запланированные задачи.
- Добавлен пресет провайдера GLM для Claude Code.
- В настройки добавлена опция «Очистить кэш» (Clear Cache) для сброса аномалий локальных данных, которые могут возникать при миграциях версий.

### Исправления и улучшения

- Внедрена новая схема управления бинарными файлами Codex и Claude, снижающая количество проблем из-за различий окружения. Пожалуйста, выполните повторное обновление в разделе Настройки → Агент (Settings → Agent).
- Оптимизирован конвейер отправки и остановки сообщений — теперь он работает быстрее.
- Улучшена стратегия синхронизации данных.
- Исправлена ошибка, из-за которой просмотр diff или файла иногда завершался сбоем.
- Исправлена проблема, при которой кнопка добавления становилась недоступной для нажатия при слишком длинных путях к проекту.
- На Windows цвет строки заголовка окна приложения теперь следует выбранной теме.
- Исправлена проблема в мобильной веб-версии, при которой не удавалось скрыть экранную клавиатуру.
- Исправлена ошибка, из-за которой изображения в диалогах иногда не открывались.
- На страницу настроек в мобильной версии добавлен пункт для отправки отчёта об ошибке.
- Исправлено некорректное перенаправление при входе на Linux.
- Открытие уже открытого проекта в Zed теперь переводит фокус на существующее окно вместо открытия нового.
