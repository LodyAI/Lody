Версия 0.114.1

### ✨ Новое

- EverMe теперь доступен как провайдер памяти на уровне всего аккаунта. Установите его в один клик или настройте вручную.
- Экспериментальный аутлайнер Today («Сегодня») объединяет заметки, задачи и упоминания сессий на одной странице. Вы можете превратить любой пункт в задачу, сфокусироваться на отдельной ветке, поэтапно расширять выделение или редактировать несколько пунктов сразу. В настольном приложении Today можно открыть в отдельном окне рядом с сессией.
- Организуйте сессии по группам Focus («В фокусе»), Later («Позже») и Settled («Завершено») в новом представлении Status («Статус»). Сессию можно отложить на один или три часа либо перетащить обратно в Focus.
- Группируйте закреплённые сессии и упорядочивайте их вручную. Выбирайте, какие группы отображать на каждом устройстве, или запускайте сессию прямо внутри группы. При перетаскивании сессии к краю боковая панель прокручивается автоматически.
- Нажмите ⌘/Ctrl + 1–9 для переключения между первыми девятью видимыми сессиями. Длинные списки можно разворачивать постранично.
- Привязывайте и отвязывайте GitHub PR от сессии, передавайте привязанный PR в Auto delivery и просматривайте статус слияния в боковой панели.
- Открывайте рабочий каталог сессии в Finder или Проводнике через меню сессии. Клик с клавишей-модификатором по URL-адресу в терминале открывает его в браузере.
- Просматривайте вложения в боковой панели сессии и регулируйте скорость воспроизведения видео.
- Нажимайте клавиши «Вверх» или «Вниз» в пустом поле ввода, чтобы вызывать ранее отправленные сообщения. Настраивайте горячие клавиши для поиска моделей, уровня размышлений и меню вложений.
- В Codex добавлен режим скорости Ultrafast. Теперь вы можете войти в Antigravity удалённо из Lody.
- В настройках Lody Agent можно просматривать и обновлять модели, доступные через пользовательский эндпоинт, а также задавать модель по умолчанию, уровень размышлений и степень автономности для новых сессий. Редакторы промптов (Prompt) и ролей агентов (Agent Role) также были переработаны.
- Поручите Lody выполнение длительной команды в фоновом режиме: по завершении сессия получит результат и продолжит работу. Редакторы сессий также могут управлять автоматизациями на общих машинах.
- Экспортируйте и импортируйте рабочие пространства через настройки настольного приложения («Настройки → Данные» / Settings → Data) или через CLI. Участники целевого рабочего пространства получают доступ только на чтение к содержимому, импортированному из другого рабочего пространства.

### 🐛 Исправления и улучшения

- Исправлена ошибка, из-за которой действия цитирования в беседе отображались поверх модальных окон.

- Исправлены аргументы продакшен-сборки для стабильных установщиков Windows и Linux.

- Архив теперь открывается единым списком, поэтому старые сессии можно просматривать без разворачивания групп.
- Поле ввода учитывает выбранный размер шрифта интерфейса. Быстрые команды промптов (Prompt shortcuts) теперь работают и при редактировании отправленного сообщения.
- Нажатие на упоминание сессии в отправленном сообщении открывает эту сессию. Markdown-ссылки на сессии в текущем рабочем пространстве также открываются внутри Lody.
- Подменю поля ввода остаются в пределах экрана в узких окнах. Меню упоминаний скрывает категории Issue и PR для проектов без привязанного репозитория GitHub.
- Фоновые окна больше не отмечают сессии как прочитанные без вашего действия. Изменение порядка в Focus также сохраняет статус непрочитанной для сессии, только что вернувшейся из Later.
- Открытые окна сохраняют собственное состояние боковой панели, когда вы сворачиваете группу или меняете фильтр в другом окне.
- При остановке отправки сообщения из очереди сохраняются как черновики, которые можно отредактировать и отправить самостоятельно. Одно слово «continue» возобновляет ход, прерванный перезапуском.
- Исправлена потеря недавно созданных сессий после сбоя и отсутствие файлов в списке изменений рабочего пространства.
- Предпросмотры остаются открытыми при переключении на другую сессию и возвращении обратно. Исправлены проблемы с крупными локальными HTML-предпросмотрами и сбои загрузки ресурсов проекта или перенаправлений в предпросмотре.
- Удалённый поиск файлов выполняется на машине, где хранятся файлы. Ветки GitHub загружаются постранично, чтобы сократить время ожидания в крупных проектах.
- Исправлены пустые меню команд и навыков (skills) в Antigravity, а также отображение сессий как работающих после завершения фоновых задач.
- Исправлена ошибка, из-за которой весь каталог моделей Magpie не загружался, если у одной из моделей были указаны нестандартные значения уровня размышлений или длинный список типов входных данных.
- Подключения агентов, запросы статистики использования Claude, подключения настольного приложения и автоматизации теперь используют настроенный прокси. Вход в настольное приложение также можно продолжить в браузере.
- Исправлена недоступность команды lody в терминале после автономной установки. Явная переустановка активирует только что установленную версию демона.
- Ускорен запуск настольного приложения, демон CLI потребляет меньше памяти, а длинные сессии эффективнее загружают историю при повторном открытии.
