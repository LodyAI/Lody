### Улучшенный запуск и вход в CLI

- Упрощённый запуск CLI в один клик
- Удалён режим Docker
- Добавлена группа команд `project` для управления локальными проектами
  - `npx lody project add [path]` Добавить локальный проект в lody
  - `npx lody project list` Вывести список локальных проектов
  - `npx lody project delete` Интерактивно удалить локальный проект

### Исправления производительности и надёжности

- Исправлены задержки интерфейса при открытии diff файлов
- Исправлены ошибки в сценарии аутентификации в некоторых ситуациях
