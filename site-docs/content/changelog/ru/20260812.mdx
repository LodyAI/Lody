Версия 0.78.0

### ✨ Новое

- Добавлена поддержка официальной среды выполнения Grok, включая управление взаимодействием и разрешениями, отслеживание использования контекста и отображение лимитов запросов в Lody.
- Новое двухуровневое меню `@` объединяет в одном месте файлы, задачи (issues), pull request'ы, навыки (skills), сессии и команды, включая прямые ссылки на другие сессии.

### 🐛 Исправления и улучшения

- Улучшены проверки нехватки памяти в macOS и Linux — теперь запуск сессий реже блокируется ошибочно, когда у системы ещё есть доступные ресурсы.
- Восстановлено сочетание клавиш для уменьшения масштаба в настольном приложении Electron.
- Описания pull request'ов теперь можно разворачивать, а выравнивание ответов Агента стало более единообразным.
- Исправлено искажение многобайтового текста (включая китайские иероглифы) на стыках фрагментов данных при локальном подключении.
- Исправлена ошибка установки Lody CLI через npm или npx при некорректном разрешении версий зависимостей.
- Увеличена скорость загрузки главной страницы сайта, уменьшен размер ресурсов и улучшена доступность.
