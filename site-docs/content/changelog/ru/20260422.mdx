### Работа с агентами

- Добавлен быстрый переключатель для Codex Fast Mode
- Добавлен выбор уровня размышлений Claude (Think Level)
  <img src="/_docs-assets/fast-think.png" alt="" />
- Улучшены карточки запросов разрешений: длинные кнопки переносятся, длинные команды можно развернуть для просмотра полного содержимого, а перед подтверждением стало проще проверить, что именно собирается выполнить агент

### Новые настройки машин и агентов

- Конфигурации агентов теперь управляются отдельно для каждой машины. При переключении между машинами Lody отображает только агентов, доступных на выбранной машине, предотвращая выбор конфигурации, которую невозможно запустить
- В настройках теперь используется макет «список машин + подробности о машине», где можно просмотреть статус подключения, версию CLI и состояние общего доступа

### Встроенный рабочий процесс GitHub PR

- Нажмите на значок PR в верхней части сессии, чтобы открыть панель PR в Lody и просмотреть заголовок, описание, ветку, статусы CI, комментарии и ревью
- Оставляйте комментарии к PR, выполняйте слияние (merge) PR и удаляйте ветки после слияния прямо в Lody
  <img src="/_docs-assets/PR-panel.png" alt="" />

### Мобильная версия

- Настройка действия клавиши Enter на мобильной клавиатуре: отправка сообщения или перенос строки
  <img width="400px" src="/_docs-assets/20260422-keyboard-option.png" />
- Список сессий поддерживает свайп влево для архивирования; список архива поддерживает свайп влево для восстановления или окончательного удаления
- При открытии архивированной сессии в верхнем меню теперь корректно отображаются пункты Restore и Permanently Delete вместо повторного Archive
  <img width="400px" src="/_docs-assets/mobile-swipe.png" />

### Поиск по диалогу и очередь сообщений

- Обновлён дизайн панели поиска по диалогу: добавлены более наглядные счётчики результатов, пустые состояния и кнопки перехода к предыдущему/следующему совпадению
- Исправлена проблема, из-за которой переход по результатам поиска иногда зависал в длинных сессиях
- Несколько сообщений в очереди больше не занимают весь экран: их высота ограничена, а список прокручивается

### Управление командой и приглашениями

- Ожидающие приглашения теперь корректно обновляются после переключения Workspace
- Администраторы теперь могут отменять ожидающие приглашения в команду

### Прочие исправления

- Исправлена ошибка, из-за которой сгенерированные на фронтенде токены CLI иногда не позволяли войти в систему
- Порядок репозиториев на боковой панели больше не скачет из-за изменений видимости машин или колебаний синхронизации
- Браузер повторно проверяет состояние входа при возвращении из фонового режима, восстановлении фокуса или восстановлении подключения к сети
- Создание сессии и отправка задач теперь автоматически повторяются при кратковременном отставании синхронизации, что снижает число случаев зависания новых задач
