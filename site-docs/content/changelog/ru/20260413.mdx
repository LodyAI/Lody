### Критические изменения и миграция

- После обновления вам может потребоваться войти в систему заново.
- Если вы используете GitHub Worktree, на машине, где запущен агент, должна быть настроена ваша учётная запись GitHub (через `gh auth`); в противном случае для создания Pull Request по умолчанию будет использоваться учётная запись `lody`.
- Lody перешёл на новый движок синхронизации и новую структуру данных. Прежние Workspace больше не будут доступны, поэтому для работы с Lody необходимо создать новый Workspace.
- Lody больше не запрашивает у пользователей права доступа к личной учётной записи GitHub. В связи с этим больше не поддерживается однократная авторизация одного и того же репозитория GitHub с общим доступом для нескольких Workspace. Теперь репозиторий привязывается только к одному Workspace.

### ✨ Многовкладочные сессии

Теперь в рамках одной сессии можно открывать несколько вкладок диалогов и просмотрщиков файлов. Как и на панели вкладок VSCode, вы можете общаться с агентом слева и просматривать файлы и diff справа, не прерывая ни один из процессов. Дочерние вкладки наследуют рабочий каталог родительской вкладки и поддерживают изменение порядка перетаскиванием и переименование.

### 💬 Построчные комментарии к diff

Теперь вы можете добавлять комментарии прямо в просмотрщике diff. Поддерживаются Markdown, ветки ответов, отметка веток как решённых, синхронизация с GitHub и отправка в окно диалога в один клик.

### 🖥️ Режим демона

CLI теперь поддерживает режим демона, позволяя Lody работать в фоновом режиме с автоматическим перезапуском:

```bash
lody daemon start     # Запустить фонового демона
lody daemon status    # Проверить статус
lody daemon logs      # Просмотреть логи
lody daemon stop      # Остановить демона
```

### 🔗 Улучшения интеграции с GitHub

- Статус проверок CI для PR синхронизируется с интерфейсом сессии в реальном времени, поэтому вам не нужно переключаться на GitHub, чтобы увидеть результаты сборки
- Сессии, привязанные к PR, поддерживают автоматический commit и push
