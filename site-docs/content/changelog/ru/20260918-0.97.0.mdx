Версия 0.97.0

### ✨ Новое

- Вставка ссылки на сессию в поле ввода автоматически преобразует её в упоминание сессии; используйте Cmd/Ctrl+Shift+V, чтобы вставить обычную ссылку.
- Раздел Settings > Projects в десктопном приложении теперь представляет собой двухпанельный каталог: слева — GitHub / машины, справа — папки для выбранного источника; нажмите на папку, чтобы отредактировать её.
- Сообщения в очереди теперь можно сразу отправлять как корректировку (steer) — не только первый элемент, если агент поддерживает подтверждённую корректировку (acknowledged steering); сочетание Cmd/Ctrl+Shift+Enter временно переключает режим между постановкой в очередь и корректировкой для текущей отправки.

### 🐛 Исправления и улучшения

- Исправлен сбой запуска DeepSeek Harness и других агентов, загружающих неподписанные нативные аддоны, в подписанном десктопном приложении для macOS.
- В меню сессии на мобильных устройствах появилась возможность поделиться диалогом в виде изображения.
- При узкой колонке диалога действия IDE и «Поделиться» перемещаются в меню ⋯.
