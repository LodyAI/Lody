### Рабочий процесс агентов

- В Lody теперь поддерживается Codex Goals. Сначала включите эту функцию в Codex командой `codex features enable goals`.
  <img src="/_docs-assets/20260507-goal.png" alt="" />
- Результаты генерации изображений в Codex теперь возвращаются в активный диалог, поэтому сгенерированные изображения остаются рядом с промптом и последующими инструкциями.
  <img src="/_docs-assets/20260507-codex-image-gen.png" alt="" />
- Запросы AskUserQuestion от Claude Code теперь отображаются в виде нативных карточек взаимодействия с выбором одного или нескольких вариантов, а также со свободным вводом ответа.
  <img src="/_docs-assets/20260507-ask-question.png" alt="" />
- Добавлен пресет Xiaomi MiMo для Claude Code, включая конфигурацию Token Plan.

### Удалённый Preview и визуальная обратная связь

<img src="/_docs-assets/20260507-preview.png" alt="" />

- Добавлен Lody Preview — интерактивный предпросмотр для локальных серверов разработки в рамках сессии. Например, попросите агента: `Start the Vite dev server and use Lody Preview`.
- На панели предпросмотра можно переключаться между экранами компьютера, планшета и смартфона, поворачивать экран, масштабировать, перемещать область просмотра или при необходимости открывать страницу во внешнем браузере.
- Визуальные аннотации позволяют нажать на элемент в области предпросмотра, оставить комментарий и отправить отзыв с привязкой к этому элементу обратно в диалог.

### Боковая панель и управление задачами

- Добавлен режим группировки боковой панели Updated, который распределяет сессии чатов, GitHub Worktree и локальных проектов по времени: «Сегодня», «На этой неделе» и «Ранее».
- В контекстном меню сессии теперь доступны переименование, закрепление, архивация, копирование URL сессии и копирование текущей ветки.
- Закреплённые сессии остаются в верхней части списка, чтобы к длительным или важным задачам было проще вернуться.
- В веб-версии задачи в боковой панели теперь можно открывать в новой вкладке средней кнопкой мыши или сочетанием Cmd/Ctrl + клик.

### Диалог и ввод

- Длинный вставленный текст теперь сворачивается во встроенный заполнитель, не перегружая поле ввода. Нажмите на него, чтобы просмотреть или отредактировать вставленный фрагмент.
- Изображения можно загружать простым перетаскиванием прямо в поле ввода.
- В мобильном приложении долгое нажатие на превью изображения открывает системное меню отправки и сохранения.
- В окне предпросмотра файлов длинные строки теперь переносятся автоматически, что упрощает чтение логов и плотного сгенерированного вывода.

### GitHub и Pull Request

- Черновики PR можно перевести в статус «Готово к ревью» (Ready for review) прямо из панели PR.
- Сессии, связанные с PR, могут автоматически архивироваться при слиянии или закрытии PR.
- Комментарии к PR, действия ревью и слияния могут выполняться от имени вашего личного аккаунта GitHub, а в настройках теперь отображается подключённая учётная запись.
