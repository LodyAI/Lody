Версия 0.91.0

### ✨ Новое

- Добавлена поддержка GPT-6 Astra.
- Добавлены действия с файлами в сессии: файлы, для которых недоступен прямой предпросмотр, теперь можно открыть в системном приложении, показать в файловом менеджере или скачать ([#375](https://github.com/LodyAI/Lody/pull/375)).
- В Markdown теперь поддерживается рендеринг блоков кода с семантическим диффом ([#373](https://github.com/LodyAI/Lody/pull/373)).
- На боковых панелях сессий и во вкладках дочерних сессий десктопного приложения теперь отображается статус непрочитанного ([#332](https://github.com/LodyAI/Lody/pull/332), [#384](https://github.com/LodyAI/Lody/pull/384)).
- В упоминаниях файлов, Issue и PR теперь используется нечёткий поиск в стиле VS Code, что упрощает поиск нужных объектов ([#378](https://github.com/LodyAI/Lody/pull/378)).
- Добавлены двуязычные руководства по передаче общих сессий, параллельным агентам и командам агентов ([#387](https://github.com/LodyAI/Lody/pull/387), [#389](https://github.com/LodyAI/Lody/pull/389), [#390](https://github.com/LodyAI/Lody/pull/390), [#393](https://github.com/LodyAI/Lody/pull/393), [#394](https://github.com/LodyAI/Lody/pull/394)).

### 🐛 Исправления и улучшения

- Усилены проверки подключений командного предпросмотра и локального браузера для более безопасного и надёжного доступа ([#374](https://github.com/LodyAI/Lody/pull/374)).
- DeepSeek Harness теперь обнаруживает модели из пользовательских сервисов и предоставляет параметры моделей, рассуждения и разрешений из активной среды выполнения ([#380](https://github.com/LodyAI/Lody/pull/380), [#395](https://github.com/LodyAI/Lody/pull/395), [DeepSeek ACP #10](https://github.com/LodyAI/acp-extension-dsh/pull/10), [#11](https://github.com/LodyAI/acp-extension-dsh/pull/11)).
- В селекторах моделей Kimi теперь отображаются провайдеры моделей и доступен поиск по ним, что упрощает различение моделей с одинаковыми названиями ([Kimi ACP #7](https://github.com/LodyAI/acp-extension-kimi/pull/7)).
- Улучшен рендеринг Markdown и потоковых сообщений: добавлена поддержка разделителей TeX в виде скобок, исправлены границы автоссылок рядом с не-ASCII пунктуацией, обеспечено сохранение итогового текстового вывода и добавлена возможность закрывать полноэкранный просмотрщик Mermaid касанием ([#336](https://github.com/LodyAI/Lody/pull/336), [#370](https://github.com/LodyAI/Lody/pull/370), [#388](https://github.com/LodyAI/Lody/pull/388), [#396](https://github.com/LodyAI/Lody/pull/396)).
- Исправлено подёргивание чата при изменении размера боковой панели и ускорена загрузка информации о биллинге ([#368](https://github.com/LodyAI/Lody/pull/368), [#371](https://github.com/LodyAI/Lody/pull/371)).
- Снижены накладные расходы на обновление Live Activity и ограничено количество предпросмотров групп сессий на мобильных устройствах для более плавной прокрутки длинных списков ([#319](https://github.com/LodyAI/Lody/pull/319), [#323](https://github.com/LodyAI/Lody/pull/323)).
- Улучшены логика показа запросов на отзыв в App Store и обработка их состояния ([#310](https://github.com/LodyAI/Lody/pull/310)).
- Обновлены значки провайдеров ACP и сведения в реестре сред выполнения ([#369](https://github.com/LodyAI/Lody/pull/369)).
- Улучшены заголовки страниц публичного сайта, индексируемость для поиска и обработка ошибки 404 для неизвестных страниц ([#379](https://github.com/LodyAI/Lody/pull/379), [#383](https://github.com/LodyAI/Lody/pull/383), [#391](https://github.com/LodyAI/Lody/pull/391)).
- Благодарим внешнего участника [@nokizw](https://github.com/nokizw) за улучшение отображения провайдеров и поиска в селекторах моделей Kimi ([Kimi ACP #7](https://github.com/LodyAI/acp-extension-kimi/pull/7)).
