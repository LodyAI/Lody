### Новые функции и возможности

- Добавлена новая CLI-команда `lody export` для экспорта данных сессий, включая JSON, Markdown, вложения и статистику использования. **На следующей неделе мы переходим на новый бэкенд синхронизации, и прежние исторические данные будут с ним несовместимы — экспортируйте заранее всё, что хотите сохранить**
- Добавлена поддержка пользовательских моделей генерации заголовков для всех ACP-агентов
- Баннеры запросов разрешений теперь закреплены над полем ввода, пока сессия ожидает подтверждения, поэтому они не теряются при прокрутке
- Выбор машины теперь отделён от выпадающего списка Agent Config, чтобы машину было проще выбирать отдельно
- Клик по пути к файлу в чате теперь корректно открывает файл целиком

### Платформа и интерфейс

- Кнопки настройки сессии больше не сжимаются и не обрезаются на узких экранах
- На мобильных устройствах нижняя область поля ввода чата теперь корректно переносится на новую строку вместо того, чтобы сжимать кнопки вплотную
- Графики использования и карточки статистики на мобильных устройствах теперь помещаются на небольших экранах без горизонтального переполнения

### Исправления и стабильность

- Ошибки ACP теперь отображают конкретную первопричину
- Исправлены сбои аутентификации в десктопном приложении в окружениях Linux помимо GNOME (включая Sway, Hyprland и Niri) за счёт автоматического определения доступного бэкенда связки ключей (keyring)
- Исправлены ошибки создания worktree для пустых удалённых репозиториев
- Исправлены зависания ЦП, вызванные слишком большим числом одновременных операций `git show` при изменении большого количества файлов
- Исправлено повторное использование устаревших метаданных Issue и PR при сбое обновления кэша для упоминаний через `#`
