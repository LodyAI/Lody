Версия 0.95.0

### ✨ Новое

- Добавлен управляемый встроенный агент Pi. При миграции существующего провайдера Pi запрашивается подтверждение, а его настройки и сохранённая история переносятся; прежние сессии Pi нельзя возобновить после миграции, поэтому начните новый чат.
- Результаты одобренного общего доступа к сессии теперь возвращаются напрямую MCP-агентам.
- Запуск Devin из локального CLI.
- Более надёжное закрытие и восстановление сессий с общим доступом в рамках рабочего пространства.

### 🐛 Исправления и улучшения

- Исправлен запуск DeepSeek Harness на некоторых версиях Node за счёт запуска с помощью встроенного в Lody Node.
- Исправлен периодический пустой экран на iOS после возвращения приложения из фонового режима.
- Улучшены прерывание работы, восстановление, фоновая предзагрузка и потоковый вывод, чтобы снизить риск потери черновиков и сбоев всего диалога.
- Улучшены запросы на общий доступ, настройки провайдеров, восстановление после ошибок и работа архива.
- Исправлена ошибка, из-за которой JSON во входных данных инструментов ошибочно распознавался как математические формулы Markdown.
