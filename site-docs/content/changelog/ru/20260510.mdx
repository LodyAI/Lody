### Новое

- Добавлен сценарий онбординга в настольном приложении, упрощающий запуск первого диалога.
- Теперь можно входить в систему с помощью электронной почты и пароля.
- Для локальных проектов теперь можно создавать worktree по требованию, и они автоматически удаляются при архивации сессии.
- В разделе «Настройки → Проекты» (Settings → Projects) теперь можно открыть доступ к локальному проекту для вашей команды, чтобы работать над проектами вне GitHub наравне с остальными.
