### Просмотр файлов и diff

- Теперь вы можете просматривать список файлов рабочего пространства в реальном времени
- В конце каждого чата Lody подводит итог всех изменений в файлах и разницы в строках, и вы можете нажать, чтобы открыть diff.
  <img src="/_docs-assets/20260112-changelog.png" alt="" />

### Интеграция с GitHub

- При создании PR теперь предпочтительно используется учётная запись пользователя

### Push-уведомления

- Если уведомления включены в настройках, уведомление отправляется по завершении чата
- Уведомление отправляется, когда агенту требуются разрешения
- При первом ответе агента Lody спрашивает, нужно ли включить push-уведомления
- При приглашении участников в команду отправляется письмо на электронную почту

### Прочее

- Поддержка прокси: CLI теперь поддерживает WebSocket-подключения через HTTP-прокси
- Добавлено поле поиска и фильтрации в интеграцию с GitHub
- Поддержка офлайн-доступа к чатам

- Исправлено истечение срока действия интеграции с GitHub
- Исправлена ошибка, из-за которой переключение языка не применялось после обновления страницы
