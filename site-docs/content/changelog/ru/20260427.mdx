### Работа с агентами

- Добавлена поддержка GPT-5.5
- Обновлён дизайн страницы настроек агентов: добавлена новая боковая панель категорий и обновлён процесс обновления возможностей
- Добавлен пресет DeepSeek: достаточно вставить токен, чтобы быстро завершить настройку
- Повышена стабильность подключения и точность определения возможностей для таких агентов, как Claude Code и Codex
- Исправлена ошибка в macOS, из-за которой при использовании Codex могло появляться всплывающее окно с ошибкой `ComputerUse`

### Настольное приложение

- Левую боковую панель теперь можно сворачивать, изменять её ширину перетаскиванием и переключать с помощью горячих клавиш
- Разделы локальных проектов, GitHub Worktrees и чатов стали нагляднее, а взаимодействие с боковой панелью — более единообразным
- Списки локальных файлов в сессиях теперь обновляются автоматически, что позволяет удобнее отслеживать изменения по мере их появления

### Диалоги

- Блоки кода при потоковой генерации больше не мерцают при переключении между обычным текстом и подсветкой синтаксиса
- Повышена стабильность инициализации и переключения сессий, что устраняет редкие сбои при загрузке

### Прочие исправления

- Удалённые проекты больше не запускают ошибочное определение локального окружения
- Повышена точность отображения онлайн-статуса машин и синхронизации в реальном времени
- Исправлен нижний отступ в области вывода CLI внутри Electron
