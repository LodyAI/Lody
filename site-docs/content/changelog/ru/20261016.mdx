Версия 0.106.0

### ✨ Новые возможности

- Во всплывающем окне хода теперь можно просматривать время выполнения и статус активности.
- Выделенные математические формулы теперь можно копировать в формате LaTeX.
- Виджеты лимитов подписки для мобильной версии.

### 🐛 Исправления и улучшения

- Автоматический повтор при невысвобожденных ресурсах сессии, что снижает количество сбоев всего хода.
- Установлены более реалистичные таймауты для получения учётных данных GitHub, чтобы сократить число периодических сбоев.
- Временные сбои доступа больше не блокируют диспетчеризацию сессий.
- Добавлена поддержка заголовков Codex без метаданных фазы сообщения.
- Варианты разрешений стали компактнее и удобнее для чтения.
- Сообщения Roost фиксируются до подтверждения, чтобы интерфейс не дёргался.
- Добавлена поддержка полуширинного символа иены для триггеров навыков.
- Восстановлена прокрутка в диалоге уведомлений об открытом исходном коде.
- Исправлено оформление маркеров списков в журнале изменений.
