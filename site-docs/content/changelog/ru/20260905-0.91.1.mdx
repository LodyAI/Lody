Версия 0.91.1

### ✨ Новое

- На панелях использования Claude отдельная недельная квота Fable теперь отображается отдельно от общих недельной и пятичасовой квот ([#407](https://github.com/LodyAI/Lody/pull/407), [Claude ACP #25](https://github.com/LodyAI/acp-extension-claude/pull/25), [Core #3](https://github.com/LodyAI/acp-extension-core/pull/3)).

### 🐛 Исправления и улучшения

- Исправлено отсутствие уровней рассуждения Max и Ultra для GPT-6 Astra. Доступные уровни рассуждения теперь соответствуют возможностям каждой модели, поэтому для Luna больше не предлагается неподдерживаемый вариант Ultra ([#406](https://github.com/LodyAI/Lody/pull/406)).
