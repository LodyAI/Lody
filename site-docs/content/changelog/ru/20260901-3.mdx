Версия 0.89.3

### ✨ Новое

- При сбоях из-за нехватки мощностей Codex теперь поддерживается явная повторная попытка с последующими ограниченными автоматическими повторами, таймером обратного отсчёта и кнопкой отмены.
- Добавлена облегчённая точка входа для подключения, обрабатывающая сценарии присоединения без загрузки всей оболочки приложения.

### 🐛 Исправления и улучшения

- Исправлены повторные обновления и циклы перерисовки в конфигурации сессии, вкладках сессий, резервном механизме доступа к рабочему пространству и синхронизации видимости браузера.
- Исправлены переключение сессий, восстановление по глубоким ссылкам и состояния ожидания при поступлении асинхронных данных и быстрых действиях пользователя.
- Повышена устойчивость к некорректным связям между родительскими и дочерними сессиями и ошибкам отрисовки, что предотвращает циклические перенаправления и сбои рендерера.
- Благодарим внешнего контрибьютора Wibus Wu за реализацию повторных попыток для Codex и облегчённой точки входа для подключения.
