Версия 0.82.0

### ✨ Новое

- Добавлены сценарии работы с Git для локальных проектов; при подключённой интеграции Lody с GitHub также доступны сценарии работы с GitHub PR.
- Добавлена поддержка перетаскивания сессий с боковой панели в поле ввода для автоматического добавления @-упоминаний.
- Сессии теперь можно ответвлять в новые worktree для параллельной проработки подходов.
- Добавлена глобальная настройка MCP, которую можно выбрать в меню кнопки «+» при создании диалога.
- Упоминания через @ в поле ввода теперь отображаются в виде плашек, что упрощает ссылки на сессии и навыки.
- В заголовках файлов в diff появились действия копирования пути и открытия файла.
- Добавлен экран трендов использования с выбором временных интервалов.
- Подписки и коды активации теперь можно применять вместе.

### 🐛 Исправления и улучшения

- Улучшены автопрокрутка в потоковых диалогах, копирование и вставка в терминале, а также выделение текста.
- Улучшены навигация и отображение дочерних сессий, включая иерархический список на мобильных устройствах.
- Исправлено несколько проблем надёжности при очистке рабочего пространства, запуске сессий и восстановлении соединения.
- Оптимизирована производительность боковой панели и навигации по страницам для сокращения лишних обновлений интерфейса.
