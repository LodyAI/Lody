### Новое

- Lody теперь синхронизирует историю диалогов локальных проектов из Codex и Claude Code. Запустить синхронизацию или импортировать существующую историю можно в разделе «Настройки → Проекты» (Settings → Projects).
- Новые диалоги локальных проектов, начатые в Lody, зеркалируются обратно в Claude Code и Codex, поэтому история остаётся актуальной в обоих направлениях.
- В настольное приложение добавлена кнопка «Stop» для принудительного завершения работы запущенного CLI.

### Исправления и улучшения

- Исправлена ошибка на мобильных экранах, из-за которой части интерфейса выходили за границы области просмотра.
