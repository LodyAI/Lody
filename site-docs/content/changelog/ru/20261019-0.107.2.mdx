Версия 0.107.2

### 🐛 Исправления и улучшения

- Исправлена ошибка персональной авторизации GitHub при несовпадении email-адресов в GitHub и Lody, а также улучшен возврат к настройкам после авторизации. Существующим пользователям необходимо один раз пройти авторизацию повторно в настройках GitHub.
- Добавлена поддержка привязки аккаунтов для входа с разными email-адресами, включая аккаунты с функцией Apple «Скрыть e-mail».
- Исправлена проблема, при которой чтение изображений субагентами Claude приводило к чрезмерному росту данных сессии, замедлению загрузки или сбоям синхронизации.
- Улучшено восстановление списка ресурсов MCP при запуске, переподключении и после ошибок синхронизации, что снижает число пропавших ресурсов и зависаний статуса синхронизации.
