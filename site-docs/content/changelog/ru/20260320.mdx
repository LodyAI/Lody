### Новые функции и возможности

- Добавлена поддержка слэш-команд в поле ввода чата. Введите `/`, чтобы просмотреть и вставить команды, предоставляемые агентом, например `review`, `compact` и `undo`
<img src="/_docs-assets/slash.png" alt="" />
- Параметры конфигурации агента теперь загружаются динамически с поддержкой отображения всех доступных режимов и моделей. После обновления обновите список параметров на странице Agent Config

### Исправления и стабильность

- Исправлена проблема с пустым экраном при вводе адреса электронной почты в десктопном приложении для Windows
- Исправлена проблема, из-за которой устаревшие подключения к локальному серверу CLI не восстанавливались
