Версия 0.107.0

### ✨ Новые возможности

- Нативные уведомления о результатах после завершения работы агента с текстом, ближе отражающим текущий рабочий контекст.
- Оценка стоимости каждого хода.
- Запуск одной и той же роли агента на нескольких машинах; возможность предлагать создание или обновление ролей через MCP / CLI.
- Отображение диаграмм Mermaid в чате с помощью Pele; предпросмотр Markdown теперь поддерживает встроенные изображения.
- Запуск «Открыть с помощью Delta»; значки подключённых агентов в настройках машины.
- Навигация на вкладке «Изменения» в мобильной версии приведена в соответствие с десктопной.
- Установщики для Linux ARM64 для стабильной и Nightly-версий.
- Отчёты об ошибках теперь включают диагностику клиента и сведения об окружении для более быстрой сортировки и разбора.

### 🐛 Исправления и улучшения

- Повышена надёжность сессий и демона: сборщик неактивных сессий больше не завершает сессии, в которых агент ещё работает, временные сбои запуска повторяются автоматически, а диалог можно продолжить после остановки.
- Различные оптимизации и исправления в движке синхронизации.
- Предпросмотр локальных файлов без запущенного демона; ссылки на файлы из Codex отображаются в виде карточек файлов, а также восстановлен импорт встроенной истории Codex.
- Совместимость со средой выполнения iOS 16.4+; кнопки заголовка окна в Windows больше не перекрывают оверлеи.
