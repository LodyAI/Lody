### Новое

- Добавлен инструмент локального ревью кода `lody review`, позволяющий просматривать отчёты ревью без входа в аккаунт.
- В сессиях теперь поддерживаются вложения любых типов файлов, включая предпросмотр. Агенты также могут читать вложения и отправлять файлы обратно.
- Добавлена новая палитра команд (⌘K) для поиска команд и быстрого переключения между сессиями.
- Добавлены настройки горячих клавиш, где каждую комбинацию можно настроить или переназначить с проверкой конфликтов.
- В десктопной версии добавлено окно быстрой сессии (⌘⇧N) с полным управлением с клавиатуры.
- Терминал в десктопной версии теперь следует теме приложения и получил нижнюю строку состояния в стиле VS Code.
- Меню сессии «Открыть в» теперь поддерживает Xcode, Sublime Text и пользовательские программы запуска.
- Используйте `$` в поле ввода, чтобы упомянуть навык (Skill) проекта, и просматривайте доступные навыки на новой странице Skills.
- Локальные проекты теперь можно удалять с других устройств.
- Добавлена настройка размера шрифта в диалогах.
- Добавлен провайдер DeepSeek Reasonix.
- Пользователи десктопной версии могут отключить автоматический запуск CLI и использовать Lody исключительно как пульт удалённого управления.

### Исправления и улучшения

- Повышена производительность списка All Changes.
- Для pull request-ов теперь отображается значок статуса Draft.
- Загрузка изображений теперь работает во всём интерфейсе диалогов.
- Добавлено кэширование скриптов worktree, чтобы не ждать их загрузки.
- Исправлена проблема, при которой экранная клавиатура на мобильных устройствах перекрывала интерфейс ответа на вопрос ИИ.
- Улучшено отображение длинных названий моделей в мобильной версии.
- Уменьшены подвисания и нагрев устройства во время потоковой передачи ответов.
- Исправлен чёрный экран после нажатия Cmd+W в полноэкранном режиме на macOS.
- Исправлены обрезанные контуры выделения в боковой панели и лишний отступ перед временными метками.
- Горячая клавиша поиска по сессии на macOS изменена на ⌘F.
- Длинные названия моделей стало проще читать в списке выбора модели на мобильных устройствах, а само меню больше не перекрывается клавиатурой.
- Ручная остановка задачи больше не вызывает некорректное уведомление о завершении.
