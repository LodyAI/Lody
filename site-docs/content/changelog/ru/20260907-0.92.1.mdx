Версия 0.92.1

### ✨ Новое

- Улучшены восстановление выполнения сессий и обратная связь для повышения надёжности длительных задач.

### 🐛 Исправления и улучшения

- Исправлена ошибка, из-за которой запись в сессию блокировалась сбоями валидации в несвязанных исторических данных.
- Исключено повторное воспроизведение завершённых операций и подавлены обновления прогресса без изменений.
- Улучшено восстановление метаданных при переподключении, чтобы избежать многократных повторных попыток после сбоев соединения.
- Символьные шрифты исключены из настроек внешнего вида, чтобы предотвратить применение нечитаемых шрифтов.
- Благодарим внешнего участника @Pleasure1234 за исправление фильтрации символьных шрифтов.
