Версия 0.100.0

### ✨ Новые возможности

- Добавлена поддержка моделей Opus 5.5, GPT-6-Sol и GPT-6-Luna.
- Добавлен встроенный агент Dimcode, который можно настраивать и использовать для создания сессий непосредственно в Lody.

### 🐛 Исправления и улучшения

- Обновлены встроенные среды выполнения Claude Code, Codex, Grok, Kimi и Pi для повышения надёжности агентов и стабильности запуска сессий.
- Улучшены прогрев окон десктопного приложения и загрузка содержимого, чтобы уменьшить появление пустых экранов, страниц с ошибками и кратковременных состояний загрузки при открытии сессий.
- Улучшена фоновая загрузка длинных переписок для предотвращения мерцания содержимого, смещения сообщений и потери выделения текста.
- Улучшен макет фильтра в боковой панели: элементы управления фильтрацией остаются доступными, даже когда список задач пуст.
- Исправлены случаи, когда открытие файла из другого локального worktree внутри сессии могло указывать на неверный файл.
- Устранено многократное открытие консольных окон дочерними процессами DeepSeek Harness на Windows.
- Добавлены автоматические повторные попытки при сбоях удалённой синхронизации Machine Flock с выводом понятного статуса ошибки.
- Сохраняются права доступа POSIX на исполнение и приватность файлов при сохранении текстовых файлов в Code Collab.
- Доработаны точка входа функции «Поделиться» и интерфейс заголовка сессии.
