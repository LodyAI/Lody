### Новое

- Добавлена поддержка сценария работы в режиме планирования Codex (Plan Mode).

### Исправления и улучшения

- Повышена производительность потокового рендеринга Markdown в диалогах.
- Исправлен пустой экран после первого успешного входа в нативном мобильном приложении.
- При онбординге теперь можно пропустить подключение агента и настроить его позже в «Настройках».
- Исправлены сбои при обновлении конфигурации Claude.
- Исправлено некорректное отображение шрифтов на Android.
- Исправлены случаи, когда после предоставления персональных разрешений GitHub для действий по-прежнему использовалась неверная учётная запись.
- Исправлена проблема, из-за которой устаревшие страницы PR не обновлялись автоматически.
- Увеличен порог длины вставленного текста, при превышении которого он сворачивается в компактный блок предпросмотра.
- Исправлены тайм-ауты при загрузке информации о ветках для локальных проектов и добавлена кнопка ручного обновления.
