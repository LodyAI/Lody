### Управление сессиями

- Добавлена страница архивных сессий: просматривайте архивные сессии, сгруппированные по репозиторию, с возможностью восстановления и окончательного
  удаления

### Контекстное окно и квоты подписки

- Индикатор использования контекстного окна: показывает процент оставшегося контекста рядом с каждым ответом ИИ
- В разделе управления машинами в Настройках теперь отображаются оставшиеся 5-часовые и 7-дневные квоты, а также время их обновления

### Среда выполнения машины

- Состояние машины теперь отображается в Настройках (использование памяти/CPU)

### Улучшения совместимости с Windows

- Исправлены сбои запуска процессов в Windows (ENOENT)
- Исправлена кодировка вывода терминала: корректная обработка многобайтовых символов и кодовых страниц Windows
