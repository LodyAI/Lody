### Novedades

- Claude Code ahora admite el modo rápido.
- Claude Code ahora admite tareas en segundo plano y tareas programadas.
- Se añadió un preajuste de proveedor GLM para Claude Code.
- Se añadió la opción Borrar caché en Ajustes para restablecer anomalías en los datos locales que puedan producirse durante las migraciones de versión.

### Correcciones y mejoras

- Nuevo esquema de gestión de binarios para Codex y Claude, que reduce los problemas de uso causados por diferencias de entorno. Vuelve a actualizar en Ajustes → Agente.
- Se optimizó el flujo de envío y detención de mensajes; ahora es más rápido.
- Se mejoró la estrategia de sincronización de datos.
- Se corrigió un problema por el que a veces fallaba la visualización de un diff o un archivo.
- Se corrigió que el botón Añadir no se pudiera pulsar en rutas de proyecto demasiado largas.
- En Windows, el color de la barra de título de la aplicación ahora sigue el tema.
- Se corrigió que el teclado no se pudiera cerrar en la versión web móvil.
- Se corrigió un problema por el que algunas imágenes en las conversaciones a veces no se podían abrir.
- Se añadió una entrada para reportar errores en la página de Ajustes móvil.
- Se corrigió una redirección fallida al iniciar sesión en Linux.
- Abrir un proyecto que ya está abierto en Zed ahora enfoca la ventana existente en lugar de abrir una nueva.
