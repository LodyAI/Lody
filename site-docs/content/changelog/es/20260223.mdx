### Compatibilidad con proyectos locales

- Importa cualquier directorio local y mantenlo sincronizado en tiempo real

<img src="/_docs-assets/20260223-local-project.png" width="300px" />

### Experiencia mejorada de inicio de sesión y arranque de la CLI

- Arranque de la CLI simplificado para iniciar con un solo clic
- Se eliminó el modo Docker
- Se añadió un grupo de comandos `project` para gestionar proyectos locales
  - `npx lody project add [path]` Añade un proyecto local a lody
  - `npx lody project list` Lista los proyectos locales
  - `npx lody project delete` Elimina un proyecto local de forma interactiva

### Correcciones de rendimiento y fiabilidad

- Se corrigió la lentitud de la interfaz al abrir diffs de archivos
- Se corrigieron problemas en el flujo de autenticación en ciertos escenarios
