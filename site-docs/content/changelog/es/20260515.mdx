### Novedades

- Lody ahora sincroniza el historial de conversaciones de proyectos locales desde Codex y Claude Code. Inicia una sincronización o importa el historial existente desde Configuración → Proyectos.
- Las nuevas conversaciones de proyectos locales iniciadas en Lody se replican en Claude Code y Codex, de modo que el historial se mantiene sincronizado en ambos sentidos.
- Se añadió un botón Detener en el escritorio para finalizar una CLI en ejecución.

### Correcciones y mejoras

- Se corrigieron las pantallas móviles donde partes de la interfaz se extendían más allá del viewport.
