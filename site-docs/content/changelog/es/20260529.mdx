### Novedades

- Un diseño de interfaz móvil totalmente nuevo.
- Cuando un agente hace una pregunta, ahora se oculta el compositor y se refina el estilo de la tarjeta.

### Correcciones y mejoras

- Se mejoró la estrategia de sincronización de datos para las preguntas de los agentes.
- Se añadió una pantalla de recuperación cuando el cliente falla, evitando bloqueos con pantalla en blanco.
- Se corrigió un problema por el que no se renderizaban múltiples imágenes.
- Se mejoró el motor de sincronización.
