### ✨ Novedades

- Se agregó compatibilidad para editar y reenviar el último mensaje del usuario.
- Se agregó el progreso de carga de archivos en dispositivos móviles.
- Presiona ⌘W para cerrar una pestaña de sesión o la vista activa en la barra lateral derecha.

### 🐛 Correcciones y mejoras

- Se redujo el tiempo de inicio de las sesiones.
- Las advertencias de red de Codex ya no aparecen en la conversación cuando falla una conexión.
- Se corrigió un problema que podía hacer que un Agente se reiniciara repetidamente tras quedarse sin memoria.
- Se corrigió la opción `--auth` de la CLI.
- Se corrigió un problema por el que las ramas de proyectos locales no siempre se detectaban correctamente.
- Se mejoró la sincronización de local a la nube, corrigiendo un problema que podía impedir que otros dispositivos recibieran los mensajes más recientes.
