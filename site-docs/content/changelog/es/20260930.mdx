Versión 0.103.0

### ✨ Nuevas funciones

- Compatibilidad con el modelo Codex GPT-6.1-Sol.
- Previsualiza documentos de Word (DOCX), Excel (XLSX) y PowerPoint (PPTX) directamente en las sesiones.
- Nuevas vistas previas de tablas CSV y TSV con búsqueda de celdas y zoom, manteniendo disponible la edición del archivo fuente.
- Las vistas previas de PDF ahora incluyen navegación por miniaturas, rotación y opciones de zoom adicionales, con una búsqueda de documentos mejorada.

### 🐛 Correcciones y mejoras

- Se corrigió que las opciones de esfuerzo de razonamiento y Fast se mostraran o aplicaran de forma incorrecta después de cambiar de modelo o aplicar un rol.
- Se corrigieron bloqueos en el área de mensajes que podían ocurrir al cambiar de pestaña de sesión y se mejoró la restauración de la posición de lectura.
- Se mejoró el posicionamiento del menú @ del compositor para que siga al cursor de texto y se adapte al espacio disponible.
- Se mejoraron los mensajes cuando la autorización de GitHub caduca o es revocada, y se corrigió la atribución incorrecta de autor en algunos commits de Git.
- Se actualizó el runtime integrado de Codex y se agregaron estimaciones de costo de uso para nuevos modelos.
- Se corrigieron la navegación y los destinos de enlaces en algunas páginas del sitio web público.

Gracias a todas las personas de la comunidad que comparten sus comentarios y contribuyen a Lody.
