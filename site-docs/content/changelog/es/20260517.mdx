### Novedades

- Ahora puedes inspeccionar las ramas de Git de un proyecto local e iniciar un worktree directamente desde un dispositivo remoto.

### Correcciones y mejoras

- Se corrigieron los avatares incorrectos en sesiones importadas desde agentes ACP externos.
- Se corrigió un problema por el que las sesiones de Claude quedaban ocasionalmente bloqueadas en estado inactivo.
- Se corrigió el orden incorrecto en los resultados de búsqueda de comandos slash.
- Se corrigió un problema por el que las importaciones del historial de sesiones producían entradas duplicadas ocasionalmente.
- Se corrigió una redirección inesperada durante el inicio de sesión por correo electrónico en la aplicación móvil.
