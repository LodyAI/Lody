Versión 0.101.1

### ✨ Nuevas funciones

- Las vistas previas web remotas ahora se precargan para que el panel del navegador se abra más rápido.

### 🐛 Correcciones y mejoras

- Se corrigió que la sincronización de red bloqueara el envío de mensajes, mejorando el envío y la recuperación en conexiones inestables.
- Se corrigió que los mensajes pendientes impidieran archivar o eliminar conversaciones.
- Se actualizó el Claude integrado y se corrigió la información incompleta de estado de llamadas a herramientas, salidas y cambios en archivos.
- Vistas previas de archivos locales más rápidas en escritorio.
- Al seleccionar un cambio de archivo ahora se enfoca ese archivo. La lista de cambios también muestra las rutas de directorio para ayudar a distinguir archivos con el mismo nombre.
- Se agregó un indicador de carga del estado de Git a la opción de worktree local.
- Se mejoró la estabilidad de la sincronización de datos durante actualizaciones concurrentes.
