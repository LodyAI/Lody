### Novedades

- Se rediseñaron la interfaz y la experiencia de usuario en escritorio y móvil.
- Se añadió supervisión de recursos del dispositivo para consultar el uso de CPU y memoria en dispositivos y sesiones de agente.
- Se añadió compatibilidad con steer para Codex y Claude Code.
- Se añadió una barra de información de sesión que reúne información sobre proyecto, rama, cambios de código, PR, objetivo, tarea programada y vista previa con acciones rápidas.
- Se añadió compatibilidad con fotos de perfil, logotipos de espacios de trabajo, nombres para mostrar y gestión de contraseñas.

<img src="/_docs-assets/20260716-new-ui.png" style={{ maxHeight: '400px' }} />

### Correcciones y mejoras

- Se mejoraron el estado en línea del dispositivo, el comportamiento de reconexión y la estabilidad del agente local.
- Se corrigió un problema por el que los ajustes de modelo, permisos o razonamiento podían cambiar al continuar una sesión.
- Se corrigió que los proyectos locales importados no aparecieran de inmediato.
- Se mejoraron las actualizaciones de capacidades de Codex, los títulos de sesión, el contenido de razonamiento y la información de uso.
- Se mejoró la presentación de las respuestas del agente, las tareas de subagentes, los archivos editados y los detalles de uso.
