Versión 0.82.0

### ✨ Novedades

- Se añadieron flujos de trabajo de Git para proyectos locales; con una integración autorizada de Lody con GitHub, también están disponibles los flujos de trabajo de PR de GitHub.
- Se admite arrastrar sesiones desde la barra lateral al editor para crear menciones @ automáticamente.
- Ahora las sesiones se pueden bifurcar en nuevos worktrees para trabajar con enfoques en paralelo.
- Se añadió la configuración global de MCP, seleccionable desde el menú del botón + al crear una conversación.
- Las menciones @ en el editor ahora aparecen como chips, lo que facilita referenciar sesiones y skills.
- Los títulos de archivos en el diff ahora ofrecen acciones para copiar la ruta y abrir el archivo.
- Se añadió una vista de tendencias de uso con intervalos de tiempo seleccionables.
- Las suscripciones y los códigos de canje ahora se pueden aplicar juntos.

### 🐛 Correcciones y mejoras

- Se mejoró el seguimiento del desplazamiento en conversaciones en streaming, el copiado y pegado en la terminal y la selección de texto.
- Se mejoraron la navegación y la presentación de las sesiones secundarias, incluida la lista jerárquica en dispositivos móviles.
- Se corrigieron varios problemas de confiabilidad en la limpieza del espacio de trabajo, el inicio de sesiones y la recuperación de conexiones.
- Se optimizó el rendimiento de la barra lateral y de la navegación entre páginas para reducir actualizaciones innecesarias de la interfaz.
