Versión 0.89.4

### ✨ Novedades

- Se mejoró el flujo de autenticación interactivo para proveedores ACP personalizados.
- Se mejoró la experiencia de primer inicio en escritorio con estados más claros y rutas de recuperación cuando la configuración encuentra un problema.

### 🐛 Correcciones y mejoras

- Se corrigieron inconsistencias en los roles, la configuración y el estado del agente a lo largo de múltiples turnos de sesión.
- Se corrigió que «Todos los cambios» incluyera contenido externo al worktree local actual.
- Se corrigió que el actualizador de escritorio informara éxito cuando la instalación fallaba.
- Se mejoraron los esqueletos de carga de las listas de sesiones y tareas, y se localizaron los avisos de reparación de pull requests.
- Se corrigió el uso de un dominio de entorno incorrecto en las conexiones de vista previa de producción.
- Se actualizó el entorno de ejecución integrado de Claude Code.
- Agradecimientos a los colaboradores externos audichuang e ImSingee.
