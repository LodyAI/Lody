### Novedades

- Se actualizó la arquitectura local-first. La aplicación de escritorio ahora puede iniciar, explorar y seguir usando proyectos y sesiones locales existentes incluso sin conexión.
- Las conversaciones locales pueden previsualizar páginas web directamente en el modo Design sin necesidad de configurar un túnel.
- Se agregaron controles impulsados por el Agente para crear, leer y administrar otras conversaciones de Lody.
- Se agregó compatibilidad integrada con el proveedor Kimi Code.
- Se mejoró la velocidad de inicialización de las conversaciones, especialmente en proyectos locales.
- Se mejoraron la interfaz y la experiencia de usuario para proyectos de GitHub, con más acciones en la barra de acciones de la conversación.
- Se agregaron fuentes personalizables para la interfaz y la terminal.

### Correcciones y mejoras

- Se mejoró la presentación del gráfico de uso.
- Se corrigió un problema por el que las sesiones locales quedaban bloqueadas, se reconectaban repetidamente o permanecían en estado «pensando» durante el uso sin conexión, con conexiones débiles o al recuperarse la red.
- Se corrigió un problema por el que las sesiones de inicio de sesión podían expirar después de dejar Lody en ejecución durante un tiempo prolongado.
- Se corrigió un fallo ocasional al deshacer y rehacer en el editor de mensajes.
- Se pulieron la interfaz general y la experiencia de usuario.
