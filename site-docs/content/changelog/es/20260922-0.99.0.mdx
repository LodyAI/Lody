Versión 0.99.0

### ✨ Nuevas funciones

- En iOS, elige el icono de aplicación Aqua en los ajustes de Apariencia o vuelve al icono predeterminado.

### 🐛 Correcciones y mejoras

- Corrige fallos de inicio tras actualizaciones provocados por cachés de entornos de ejecución desactualizadas. El entorno de ejecución afectado se vuelve a descargar y verificar cuando es necesario.
- Permite que la aplicación siga iniciándose cuando falla la limpieza de caché de un entorno de ejecución o la comprobación de actualizaciones, sin interrumpir otros entornos de ejecución.
