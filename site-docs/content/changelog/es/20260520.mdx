### Novedades

- Se añadió compatibilidad con el flujo de Codex Plan Mode.

### Correcciones y mejoras

- Se mejoró el rendimiento del renderizado de Markdown en streaming dentro de las conversaciones.
- Se corrigió una pantalla en blanco tras el primer inicio de sesión correcto en la aplicación móvil nativa.
- El flujo de configuración inicial ahora permite omitir la conexión del agente y configurarla más tarde desde Configuración.
- Se corrigieron fallos al actualizar la configuración de Claude.
- Se corrigió un renderizado anómalo de fuentes en Android.
- Se corrigieron casos en los que las acciones seguían utilizando la identidad incorrecta después de haber concedido permisos personales de GitHub.
- Se corrigió que las páginas de PR desactualizadas no se actualizaran automáticamente.
- Se aumentó el umbral antes de que un texto largo pegado se contraiga en una vista previa compacta.
- Se corrigieron los tiempos de espera agotados al cargar la información de ramas de proyectos locales y se añadió una opción de actualización manual.
