### Novedades

- Se añadió un flujo de incorporación en escritorio que facilita iniciar tu primera conversación.
- Ahora puedes iniciar sesión con correo electrónico y contraseña.
- Los proyectos locales pueden aprovisionar un worktree bajo demanda, el cual se recupera automáticamente cuando se archiva la sesión.
- Configuración → Proyectos ahora te permite hacer visible un proyecto local para tu equipo, de modo que se pueda colaborar en proyectos que no están en GitHub junto con el resto.
