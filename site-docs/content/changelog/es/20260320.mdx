### Nuevas funciones y capacidades

- Se añadieron comandos de barra en el campo de entrada del chat. Escribe `/` para explorar e insertar comandos expuestos por el agente, como `review`, `compact` y `undo`
<img src="/_docs-assets/slash.png" alt="" />
- Las opciones de configuración del agente ahora se cargan dinámicamente y admiten mostrar todos los modos y opciones de modelos disponibles. Después de actualizar, recarga las opciones en la página de Configuración del agente

### Correcciones y estabilidad

- Se corrigió un problema de pantalla en blanco al introducir una dirección de correo electrónico en la aplicación de escritorio para Windows
- Se corrigió un problema por el que las conexiones locales caducadas del servidor de la CLI no podían recuperarse
