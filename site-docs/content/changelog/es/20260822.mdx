Versión 0.85.0

### ✨ Novedades

- Se añadió un modo de tema del sistema que sigue la apariencia clara u oscura del dispositivo.
- Se añadió compatibilidad con entrada de imágenes para el agente DeepSeek Harness.

### 🐛 Correcciones y mejoras

- Se corrigió un problema por el cual presionar Esc mientras se usaba un IME podía hacer que se perdiera el foco.
- Se mejoraron las interacciones de arrastrar y soltar para las menciones de conversaciones.
- Se aseguró que la configuración de permisos de Grok se aplique al iniciar y reanudar sesiones.
- Se mejoraron la compatibilidad y la estabilidad de inicio de DeepSeek Harness.
