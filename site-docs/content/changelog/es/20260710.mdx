### Novedades

- Se añadió compatibilidad con Codex 5.6 con opciones actualizadas de esfuerzo de razonamiento.
- Ahora se pueden eliminar proyectos locales mientras el dispositivo está sin conexión.

### Correcciones y mejoras

- Se corrigió un problema por el que las sesiones podían entrar en un estado no válido.
- Se mejoró la visualización de la lista de tareas de subagentes.
- Se mejoró la fiabilidad de las operaciones con PR de GitHub.
