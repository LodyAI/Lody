Versión 0.88.1

### ✨ Novedades

- Los resultados de sesiones en el menú de menciones `@` ahora se limitan de forma predeterminada al proyecto actual, con un cambio temporal a todos los proyectos cuando sea necesario, lo que facilita encontrar las sesiones relevantes ([#109](https://github.com/LodyAI/Lody/pull/109)).
- En escritorio ahora se requiere seleccionar una máquina antes de poder elegir un agente, con indicaciones más claras durante todo el flujo ([#151](https://github.com/LodyAI/Lody/pull/151)).

### 🐛 Correcciones y mejoras

- Se corrigió un problema por el cual el primer mensaje en una pestaña hija podía descartarse, quedarse bloqueado en "Sincronizando" o impedir que se cerrara la pestaña ([#141](https://github.com/LodyAI/Lody/pull/141)).
- Se corrigió la superposición entre las conversaciones laterales y las vistas previas de archivos o diferencias (diffs) ([#135](https://github.com/LodyAI/Lody/pull/135)).
- Se mejoró el aislamiento de datos en el recorrido de incorporación de escritorio para que la demostración no pueda acceder accidentalmente a datos reales del espacio de trabajo ([#136](https://github.com/LodyAI/Lody/pull/136)).
- Las terminales de proyecto ya no heredan las variables de entorno internas utilizadas por el inicio de Electron y el proxy de credenciales ([#122](https://github.com/LodyAI/Lody/pull/122)).
- Se completaron las traducciones al inglés y al chino para el estado del objetivo, el guardado de tareas y los diagnósticos de Git en Windows, y se restauró el nombre faltante del agente ([#59](https://github.com/LodyAI/Lody/pull/59)).
- Agradecemos a [@27Aaron](https://github.com/27Aaron), [@ImSingee](https://github.com/ImSingee) y [@natsustan](https://github.com/natsustan) por sus contribuciones públicas a esta versión.
