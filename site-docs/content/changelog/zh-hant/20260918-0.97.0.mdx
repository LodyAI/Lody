版本 0.97.0

### ✨ 新功能

- 將工作階段連結貼入輸入框時會自動轉換為工作階段提及（session mention）；若要貼上純文字連結，請使用 Cmd/Ctrl+Shift+V。
- 桌面端「設定 > 專案」現改為雙欄式目錄：左側顯示 GitHub / 機器，右側顯示所選來源下的資料夾，點擊資料夾即可進行編輯。
- 排隊中的訊息現可直接進行引導（Steer）（當 Agent 支援 acknowledged steering 時，不再僅限於第一則）；傳送時按下 Cmd/Ctrl+Shift+Enter 可暫時切換該次傳送的「排隊／引導」行為。

### 🐛 修正與改進

- 修正已簽署的 macOS 桌面應用程式中，DeepSeek Harness 及其他載入未簽署原生擴充模組的 Agent 無法啟動的問題。
- 行動端工作階段選單現支援將對話分享為圖片。
- 當對話欄位較窄時，IDE 與分享操作會收納至「⋯」選單中。
