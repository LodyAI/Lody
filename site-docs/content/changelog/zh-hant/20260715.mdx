### 新增功能

- 全新設計桌面端與行動端的 UI 與 UX 體驗。
- 新增裝置資源監控功能，可檢視各裝置與 Agent 工作階段的 CPU 與記憶體使用量。
- 為 Codex 與 Claude Code 新增 steer 支援。
- 新增工作階段資訊列，整合顯示專案、分支、程式碼變更、PR、目標、排程任務及預覽資訊，並提供快速操作。
- 新增支援個人頭像、工作區 Logo、顯示名稱與密碼管理。

### 修復與改進

- 提升裝置線上狀態、重新連線機制與本地 Agent 的穩定性。
- 修復繼續工作階段時，模型、權限或推理設定可能遭到變更的問題。
- 修復匯入本地專案後未能立即顯示的問題。
- 改進 Codex 能力重新整理、工作階段標題、推理內容與用量資訊的呈現。
- 改進 Agent 回覆、子代理任務、已編輯檔案與用量詳情的顯示方式。
