版本 0.111.0

### ✨ 新功能

- 工作階段自動化現可檢查網址或執行本機指令，並在滿足外部條件時自動繼續任務。
- Agent 可跨工作階段管理自動化流程，在目標工作階段中註冊、檢查或取消等待條件。
- Mermaid 圖表現已支援直接內嵌顯示於對話內容中。
- 同機器上的附件將保留於本機：Agent 可直接讀取原始檔案，傳送圖片時也無需先等待遠端上傳完成。
- 可直接在原電腦上預覽本機圖片；在其他裝置上檢視時，可從該電腦下載本機附件，並顯示檔案無法使用的原因（包含原電腦離線的情況）。
- Agent 可辨識目前的工作階段、Role、父工作階段及起始工作階段資訊，藉此更準確地進行協作。
- Claude、Kimi、Pi 與 DeepSeek Harness 配接器現已支援標準 ACP 工作階段系統提示詞，包含附加指令與覆寫設定。

### 🐛 修正與改善

- 當 Provider 移除某個 Role 所指定的模型或權限模式時，Role 會直接顯示無法使用的原因，避免在選取後執行時才發生失敗。
- Role 摘要現已加入功能標籤，方便辨識其支援的各項功能。
- 恢復本機 Provider 登入功能，以及自訂服務端點的 API 金鑰輸入支援。
- 改善 Lody Agent 設定流程：所選的登入方式能正確傳遞至目標機器，設定完成前即可配置自訂端點，且取消登入時會立即結束等待。
- 當模型目錄意外為空時會自動重新探測、保留已選取的模型，並回報目前沒有可用模型，而非錯誤顯示驗證通過。
- 修正機器在線狀態仍在更新時，新分頁中的已知 Agent 無法選用的問題。
- 修正 Claude advisor 工具結果未能正確完成的問題。
- 內建 Codex 執行環境更新至 0.166.0，Claude Code 更新至 2.1.321。
- 內建 Devin 執行環境更新至 3000.12.28，DeepSeek Harness 更新至 0.2.2-rc.1。
- DeepSeek 思考過程預設為收合狀態，讓長篇回覆更易於閱讀。
- 當 Agent 的背景任務仍在執行時，工作階段活動狀態會維持準確，減少過早顯示已完成的情況。
- 工作階段啟動失敗後仍會保留原有的上下文資訊，方便重新嘗試。
- 結束 Agent 工作階段時，不再關閉使用者手動開啟的終端機。
- 修正過時的桌面快照覆蓋目前狀態，以及對話更新過程中狀態反覆變動的問題。
- 首頁會將已完成但尚未閱讀的工作階段明確標示為未讀，並為草稿 Pull Request 使用專屬圖示。
- 側邊欄會顯示本機工作階段分支，並針對共用目錄的工作階段隱藏易生誤解的獨立分支資訊。
- 關聯對話中的分頁數量較多時支援水平捲動，避免分頁遭到擠壓。
- 改善桌面版結束程式的確認與取消流程以減少等待時間，並修正關閉側邊面板與終端機後資源未即時釋放的問題。
