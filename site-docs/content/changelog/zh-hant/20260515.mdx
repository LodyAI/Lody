### 新功能

- Lody 現在支援從 Codex 與 Claude Code 同步本機專案的對話紀錄，可前往「設定 → 專案」手動觸發同步或匯入現有紀錄。
- 在 Lody 中啟動的新本機專案對話會鏡像回寫至 Claude Code 與 Codex，讓雙向對話紀錄保持同步。
- 桌面端新增「停止」按鈕，可終止執行中的 CLI。

### 修復與改善

- 修復行動端畫面中部分介面元素超出可視區域的問題。
