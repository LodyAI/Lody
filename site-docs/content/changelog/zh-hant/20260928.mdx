版本 0.101.0

### ✨ 新功能

- 全新的 UI 設計翻新側邊欄、設定、PR 面板、工具呼叫詳情與輸入框選單，統一淺色與深色主題及互動體驗。
- 排程任務支援單次或重複執行、選擇執行機器與 Agent，以及檢視執行歷史；Agent 也能為您提議排程，經確認後建立。
- Codex 支援多個獨立帳號，以及自訂 API 端點與金鑰。
- 新增子代理活動詳情，顯示由支援的 Agent 提供的任務狀態、執行歷程與結果。
- Agent Role 新增描述欄位，方便說明其用途與職責。
- Agent 可查詢工作區中的 Agent Role、機器與專案，找出合適的設定與執行位置。
- 全新的 Lody Preview 支援本機預覽與依需求開啟的遠端預覽，並提供更清楚的連線狀態與恢復指引。
- 本機專案可將對話與 PR 建立關聯，並使用該機器的 GitHub 憑證擷取 PR 資訊。
- 支援在 Markdown 中檢視圖片，包含本機圖片與依需求載入的遠端圖片。
- 支援檢視每一輪的 Token 用量。
- 支援從對話資訊列開啟關聯對話樹。
- Pi 支援掃描與選取本機擴充功能，並匯入對話歷史；Grok 支援從完整對話或早期輪次建立分支。
- 新增對話全寬顯示、字體連字與行內數學公式渲染選項。
- 新增頭像裁切功能；macOS 支援選擇應用程式圖示並保留您的設定。

### 🐛 修正與改進

- 改善串流回覆的渲染方式，讓 Markdown 內容隨回覆逐步顯示，減少閃爍與重複動畫。
- 讓長對話捲動與對話切換更加流暢，減少內容跳動與畫面空白。
- 更清楚呈現附件上傳與待發送訊息狀態，改善重試與中斷後的恢復機制；過長的貼上文字可自動轉換為文字附件。
- 編輯並重新發送訊息時，現已支援與輸入框相同的提及選取功能。
- 修正匯入的對話在繼續或建立分支時可能套用錯誤 Agent 設定的問題，並恢復 GPT-6 Sol 與 Luna 的擴充推理選項。
- 改善 GitHub 憑證選取，以及儲存庫更名或轉移後的 PR 關聯；CI 狀態現已依據最新檢查結果顯示。
- 修正重新整理後遺失未儲存的編輯器變更、封存與關閉分頁相互干擾，以及重複修復歷史紀錄的問題。
- 改善側邊欄群組狀態、待發送指示器與 macOS Dock 標記；修正行動端附件選單、群組收合狀態，以及從差異檢視跳轉至原始檔案的互動問題。
- Agent 登入時會顯示執行階段下載進度並支援取消；改善首次連線機器的引導與初始化失敗提示訊息。
