版本 0.115.0

### ✨ 新功能

- 加密工作區現已支援連接 GitHub，並支援推播通知、即時動態（Live Activities）與收件匣用戶端；加密工作階段中也支援使用 Prompt 快捷短語。
- 可將 Roost 對話歷史紀錄（包含由特定主機持有的歷史紀錄）儲存在加密工作區中，並在工作區各用戶端之間存取。現有的 OSS 快照支援遷移，遠端 CLI 也能與加密工作區配對。
- 新增加密工作區的用量與資料傳輸計費說明。

### 🐛 修復與改進

- 復原檔案現已綁定至標準站台來源（canonical site origin）。電子郵件邀請需經過明確核准，且僅有加密工作區會顯示復原入口。
- Auto delivery 現僅會依據受信任的 Pull Request 與檢查結果執行操作。
- 修復依模型讀取 Agent 設定的問題，以及多項 Today、側邊欄、延後處理（Snooze）與行動端顯示問題。
