版本 0.81.0

### ✨ 新功能

- 新增內建 DeepSeek Harness 支援，包含直接設定 DeepSeek API Key、Agent 預設組，以及在工作階段中使用 Lody MCP。
- 由 Agent 或子工作階段建立的獨立工作階段，現在會群組化顯示於其來源工作階段底下，並提供雙向關聯詳情與快速導覽。

### 🐛 修正與改進

- 改進長對話與串流回覆時的捲動跟隨效果，減少輕微向上捲動後出現意外跳動的情況。
- 改善窄螢幕行動裝置上的設定頁面版面配置、分隔線與操作按鈕的可讀性。
- 修正當路徑大小寫或 Unicode 正規化形式不同，或檔案名稱包含特殊字元時，工作區檔案偶爾無法預覽或儲存的問題。
- 恢復 Linux KDE 桌面環境中的工作列圖示。
