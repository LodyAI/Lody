版本 0.102.0

### ✨ 新功能

- 可直接在對話中預覽 PDF 檔案，支援翻頁導覽、縮放與文字搜尋。
- 設定頁新增「提示詞快速指令」。
- 訊息中的對話連結現以可點擊的對話標籤呈現，方便跳轉至相關討論。

### 🐛 修正與改進

- 減少同步造成的延遲，提升訊息發送的反應速度；圖片訊息發送時會將預覽保留在原位，減少版面跳動。
- 桌面版與行動版啟動時會套用已儲存的主題，減少淺色與深色外觀之間的閃爍。
- 從預設入口開啟應用程式時，會直接進入聊天首頁，方便立即開始新對話。
- 提及與指令選單會跟隨輸入游標位置，改善文字換行、輸入框捲動及行動端鍵盤彈出時的顯示位置。
- 最佳化斜線指令搜尋，為提示詞快速指令與 Agent 指令採用統一排序，讓名稱相符的結果更容易找到。
- 改善 Agent Role 選單、側邊欄與下拉選項的對齊，並修正文字裁切與按鈕重疊的問題。
- 修正對話 Markdown 對齊、行內數學公式顯示，以及部分工具呼叫指令重複顯示的問題。
- 修正 Linux 機器在沒有可用系統鑰匙圈的情況下，無法登入新建 Codex 帳號設定檔的問題。
- 本機專案會保留原有的 Git 與 GitHub 驗證設定，並改善透過 Agent Role 進行的跨機器任務派送。
