版本 0.93.3

### ✨ 新功能

- 安全轉移工作區擁有權，同時維持現有訂閱與帳務計費的連續性
- 支援在獨立桌面視窗中開啟工作階段與工作區
- 支援選取多則聊天訊息並匯出為 PNG 圖片，或直接複製已產生的聊天圖片
- 支援跨機器提及 Agent Role，並顯示暫時無法使用的 Role
- 在聊天中顯示傳送者身分，讓協作時更容易區分訊息來源
- 支援從用量頁面將 Token 用量、活躍趨勢與模型佔比匯出為直向或橫向報告
- 支援從工作階段分支選單將完整上下文複製為 Markdown，並改善對話匯出效果
- 透過專屬控制項暫停、繼續與清除 Codex 目標
- 讓 Codex 與 Grok 自行提供工作階段標題，減少重複作業與等待時間
- 在新手引導階段提前準備 Agent 執行環境，並更清楚地顯示等待狀態
- 建立本機專案時優先使用機器擁有者的 Git 身分

### 🐛 修正與改進

- 修正目標在暫停後無法繼續，以及控制項可能持續處於停用狀態的問題
- 修正分支的 Codex 工作階段在首次提示詞時卡住，以及取消後可能發生提示詞衝突的問題
- 在憑證過期或身分變更時保留 Agent 上下文，減少中斷與重複重啟
- 改善 Plan 模式相容性、DeepSeek Harness 設定，以及 ACP 能力快取復原
- 提升歷史紀錄寫入、串流更新、機器存取重試與長非同步任務鏈的可靠性
- 改善本機檔案連結、系統開啟操作與資料夾拖放體驗
- 改善 Mermaid 圖表互動：內嵌圖表不再攔截捲動操作，全螢幕檢視則支援縮放與拖曳
- 修正上下文壓縮完成後工作階段狀態未正確收尾的問題
- 改善子工作階段關聯、側邊欄收合控制項，以及載入期間的分支操作顯示
- 統一桌面端快捷鍵生命週期，使視窗與鍵盤快捷鍵處理更可靠
- 修正 Windows Agent 升級與生命週期確認問題，並修復收起鍵盤後的行動端版面配置
- 改善行動端同步節奏、機器狀態載入，以及官網行動端首次載入效能
- 修正重新整理成員身分時偶發的權限錯誤
- 感謝外部貢獻者 @EYHN、@slashdevcorpse、@ladydd、@hqhq1025 與 @nzhl 在資料夾拖放、行動端同步、工作時長回報、減少動態效果行為、分支 Codex 工作階段與終端機顯示方面的改進
