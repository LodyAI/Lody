版本 0.85.0

### ✨ 新功能

- 新增系統佈景主題模式，可自動跟隨裝置的淺色或深色外觀。
- 為 DeepSeek Harness Agent 新增圖片輸入支援。

### 🐛 修正與改進

- 修正使用輸入法時按下 Esc 可能導致焦點遺失的問題。
- 改進對話提及的拖放互動體驗。
- 確保在啟動與恢復工作階段時，正確套用 Grok 權限設定。
- 提升 DeepSeek Harness 的啟動相容性與穩定性。
