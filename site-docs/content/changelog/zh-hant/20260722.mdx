### 新功能

- 升級本機優先架構。桌面版現在即使處於離線狀態，也能啟動、瀏覽並繼續使用現有的本機專案與工作階段。
- 本機對話可在 Design mode 中直接預覽網頁，無須建立通道（tunnel）。
- 新增由 Agent 驅動的控制功能，可用於建立、讀取與管理其他 Lody 對話。
- 新增內建 Kimi Code 供應商支援。
- 提升對話初始化速度，本機專案的改善尤其顯著。
- 改善 GitHub 專案的介面與使用體驗，並在對話操作列中擴充更多操作選項。
- 新增可自訂的介面字體與終端機字體。

### 修正與改進

- 改善用量圖表的呈現方式。
- 修正離線使用、網路訊號不穩及網路恢復時，本機工作階段可能卡住、反覆重新連線或持續停留在思考中狀態的問題。
- 修正 Lody 長時間執行後，登入工作階段可能過期失效的問題。
- 修正輸入框中的復原與重做功能偶爾無效的問題。
- 最佳化整體介面設計與使用體驗。
