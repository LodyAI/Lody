### 新功能與能力

- 聊天輸入框新增斜線指令支援。輸入 `/` 即可瀏覽並插入由 Agent 提供的指令，例如 `review`、`compact` 與 `undo`
<img src="/_docs-assets/slash.png" alt="" />
- Agent 設定選項改為動態載入，支援顯示所有可用的模式與模型選項。升級後請至 Agent Config 頁面重新整理選項

### 修正與穩定性

- 修正 Windows 桌面應用程式中輸入電子郵件地址時出現空白畫面的問題
- 修正本機 CLI 伺服器連線過期後無法恢復的問題
