版本 0.90.1

### ✨ 新功能

- 新增 Zen 版面配置模式，提供更專注的工作區體驗（[#341](https://github.com/LodyAI/Lody/pull/341)）。
- 升級 macOS 自動更新體驗，支援增量更新、原生進度回報與更可靠的安裝驗證（[#173](https://github.com/LodyAI/Lody/pull/173)）。
- 新增工作階段重新命名工具（[#337](https://github.com/LodyAI/Lody/pull/337)）。
- 新增支援自訂 DeepSeek Harness 服務端點（[#293](https://github.com/LodyAI/Lody/pull/293)）。
- 改善 Agent 與 Provider 設定介面，提供更清晰的設定資訊、狀態與無法使用原因說明（[#257](https://github.com/LodyAI/Lody/pull/257)）。

### 🐛 修復與改進

- 改善 CLI 背景服務的啟動復原、狀態診斷與錯誤訊息（[#287](https://github.com/LodyAI/Lody/pull/287)）。
- 修復 Agent 能力重新整理失敗，以及多回合操作中設定狀態不一致的問題。
- 改善 Markdown 連結、粗體網址、中日韓輸入法（CJK）與提及輸入行為（[#274](https://github.com/LodyAI/Lody/pull/274)、[#309](https://github.com/LodyAI/Lody/pull/309)、[#294](https://github.com/LodyAI/Lody/pull/294)）。
- 改善工作階段分頁、計畫核准、設定導覽與行動端精簡版面配置（[#326](https://github.com/LodyAI/Lody/pull/326)、[#315](https://github.com/LodyAI/Lody/pull/315)、[#334](https://github.com/LodyAI/Lody/pull/334)、[#285](https://github.com/LodyAI/Lody/pull/285)）。
- 改善本機專案資料夾選擇、SVG 檔案附件與桌面端 Cmd+W 行為（[#291](https://github.com/LodyAI/Lody/pull/291)、[#173](https://github.com/LodyAI/Lody/pull/173)）。
- 修復內建瀏覽器在部分代理伺服器網路環境下無法連線的問題（[#299](https://github.com/LodyAI/Lody/pull/299)）。
- 改善 Codex 目標指令控制與子工作階段工作區引導提示（[#144](https://github.com/LodyAI/Lody/pull/144)、[#225](https://github.com/LodyAI/Lody/pull/225)）。
