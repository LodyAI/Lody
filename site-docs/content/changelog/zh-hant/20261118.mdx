版本 0.113.0

### ✨ 新功能

- 新增內建 Antigravity 與 DeepSeek Harness，並更新 Codex、Claude Code、Kimi、Grok、Devin 與 Pi。
- 新增 QR Code 掃碼與批次裝置配對功能、改善裝置名稱顯示，並新增復原保存庫與 iOS 復原備份匯出功能。
- 排程現已支援每隔指定分鐘數或小時數重複執行。
- 桌面端與行動端皆支援預覽本機 HTML 檔案；行動端亦支援開啟 Markdown 檔案與檢視 Plan Mode 計畫。
- 新增工作階段狀態檢視、對話大綱，以及隱藏空專案的選項；每小時 AI 使用量現已依照您的本機時區顯示。

### 🐛 修正與改善

- 改善加密工作區的配對、金鑰更新與復原流程，縮短等待時間並顯示復原進度。
- 修正驗證恢復或網路切換時產生的重複請求、同步延遲與工作階段開啟問題。
- 提升背景任務執行中與完成狀態的準確度，並允許已完成的任務再次喚醒工作階段。
- 修正行動端登入返回流程、長對話顯示、iPad 導覽與草稿保留問題。
- 改善引用插入、提及編輯、思考過程與工具呼叫的收合功能，以及變更檔案統計顯示。
