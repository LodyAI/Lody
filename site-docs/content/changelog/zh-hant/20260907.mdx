版本 0.92.0

### ✨ 新功能

- 當 Agent 建立新工作階段時，會立即顯示卡片方便你直接開啟並追蹤執行狀態
- 支援依名稱、描述、作者或路徑搜尋專案 Skills
- 支援直接從附件與預覽介面下載 HTML 原始碼檔案

### 🐛 修復與改進

- 改善本機檔案預覽，支援大型檔案分頁讀取，並提升圖片與檔案載入效率
- 修復 Factory Droid 連線問題，並依所選模型顯示正確的推理選項
- 改善 Grok 工具權限行為與大量碎裂本機資料的處理效率
- 修復切換分頁後新聊天附件消失，以及早期訊息的未送達提示消失的問題
- 修復工作階段工作時長被錯誤延長，以及先前輸出干擾標題產生的問題
- 修復 Linux .deb 更新安裝導致應用程式凍結的問題，並支援在取消授權或安裝失敗後重試
- 修復已完成的一次性任務錯誤顯示隔年執行時間的問題
- 改善桌面端輸入框焦點、側邊欄工作階段階層顯示與行動端捲動體驗
- 改善團隊工作流程中 Agent 工作階段委派與完成通知的可靠性
