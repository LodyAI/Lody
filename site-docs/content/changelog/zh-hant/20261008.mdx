版本 0.104.0

### ✨ 新功能

- 可直接在工作階段中預覽與操作 Mac 上執行的 iOS 模擬器，或請 Agent 啟動預覽。
- Agent Role 支援關聯 Nowledge Mem 記憶身分，並可在設定中進行管理。
- 新增內建 Devin 支援。
- Pi 現已支援使用自訂可執行檔。
- 支援從已完成的對話輪次建立 DeepSeek Harness 工作階段分支，以探索不同方案。
- 在 PR 面板中檢視程式碼變更，支援依單一提交或提交範圍篩選，並搜尋變更檔案。
- 可在 MCP 設定中檢視伺服器所提供的工具清單。
- Agent 透過 MCP 建立工作階段時，可指定權限模式及目標 Agent 支援的設定選項。
- 支援輸入 `￥` 開啟技能選取器，方便使用中文輸入法呼叫技能。
- 由 Agent 委派至其他工作階段的訊息會顯示發送方的 Agent 或角色身分，並提供前往來源工作階段的入口。
- 新增選用的程式碼語言套件，可依需求啟用更多程式語言的語法突顯。
- 啟用擴充語言後，檔案預覽支援 Coq、Rocq 與 Lean 語法突顯。

### 🐛 修正與改進

- 修正切換工作階段分頁後，尚未發送的 Fast 設定遺失的問題。
- 修正變更角色模型後殘留不相容選項，導致無法正確選取該角色的問題。
- 修正準備附件或發送訊息期間，已選取的模型、角色與其他設定跳回原值的問題。
- 恢復內建 Pi 擴充功能支援，修正設定頁持續提示需要更新的問題。
- 修正選取 Pi 擴充功能後模型清單無法使用的問題。
- 改善 Pi 擴充功能名稱顯示，使用所屬套件或目錄名稱協助區分。
- 修正憑證清理失敗時遮蔽原本 Codex 驗證錯誤訊息的問題。
- 加快提示詞快速指令的載入速度，減少首次選取時的等待時間。
- 修正觸控裝置上因輸入框重新取得焦點而遺失提示詞快速指令選取的問題。
- 修正模型與角色子選單定位，並改善長模型清單的搜尋與捲動體驗。
- 修正工作階段搜尋對 Markdown、程式碼及底線等字元的處理，使結果數量與醒目提示保持一致。
- 改善工作階段提及搜尋的空狀態提示，區分「沒有工作階段」與「沒有相符結果」。
- 回覆產生結束後改為顯示「正在收尾」，而非持續顯示「正在思考」。
- 修正串流回覆期間快速向下捲動時，停在舊的底部位置而無法繼續跟隨新內容的問題。
- 修正捲動對話時因重複更新而可能導致頁面發生錯誤的問題。
- 改善 Markdown 表格的欄寬配置，避免過長的路徑或文字擠壓其他欄位。
- 改善訊息本文與工具摘要之間的間距。
- 統一子代理對話框與主對話的內容呈現方式。
- 修正附件從上傳中切換為已發送狀態時，預覽消失或閃爍的問題。
- 輸入框中的圖片縮圖在上傳完成前亦保留原始色彩。
- 修正「全部變更」在部分分支下使用錯誤比較基準的問題，使檔案清單、統計數據與差異內容保持一致。
- 修正檔案編輯器在復原至已儲存內容後，仍顯示未儲存變更並在離開時發出警告的問題。
- 修正行動端鍵盤遮蔽檔案編輯器，或於收起後版面配置無法恢復正確的問題。
- 修正行動端差異檢視器的互動與焦點問題。
- 修正圖片預覽的焦點隔離與鍵盤操作問題。
- 行動端匯出分享圖片時改為呼叫系統分享選單。
- 修正聊天與用量分享圖片的配色受應用程式主題影響的問題。
- 改善分享失敗時的錯誤提示，說明圖片大小等限制條件。
- 修正單次排程任務的輸入時間與預覽時區不一致的問題。
- 改善排程任務在日光節約時間轉換期間的處理邏輯。
- 修正儲存或執行包含 Fast、Plan 等開關的排程任務時，設定值被錯誤轉換的問題。
- 修正行動端排程任務編輯器未正確避開螢幕安全區域的問題。
- 修正使用相同 Agent Provider 的多個帳號之間，額度資訊相互覆寫或混淆的問題。
- 輸入框的額度指示器現會優先顯示五小時用量區間。
- Codex 重設提示可顯示資料來源公布的預定重設時間，並區分時間未定與尚未確認的重設狀態。
- 修正用量圖表的 UTC 時間邊界與跨日標籤。
- 修正變更用量統計日期範圍後，舊日期詳情意外重新開啟或覆蓋新選取項目的問題。
- 修正 GitHub PR 關聯失敗時，已偵測到的 PR 無法顯示的問題。
- 改善 GitHub 暫時性查詢失敗後的重試機制，並減少持續失敗時的重複請求。
- 修正升級後背景服務有時仍重新啟動舊版 CLI 的問題。
- 改善預覽分享通道在限制 UDP 網路環境下的連線相容性。
- 減少應用程式啟動與頁面切換期間的畫面空白閃爍。
- 改善窄視窗中的設定導覽與按鈕版面配置。
- 統一字型大小與行高縮放比例，使正文、程式碼、工具輸出與設定控制項更一致地跟隨字型大小設定。
- 調整 macOS 視窗控制按鈕與側邊欄的對齊位置。
- 修正技能詳情中的頁內連結跳離目前文件的問題。
- 修正官網文件連結遺失章節錨點的問題。
- 修正網頁版在付款返回後、訂閱仍在確認期間誤顯示為免費方案的問題。
- 補充 Homebrew 安裝說明。
- 明確說明封存工作階段後的工作目錄清理、備份與分支保留規則。
