### 新增功能

- Claude Code 現已支援 fast 模式。
- Claude Code 現已支援背景任務與排程任務。
- 新增 GLM Claude Code Provider 預設配置。
- 在「設定」中新增「清除快取」選項，用於重設版本遷移期間可能發生的本地資料異常。

### 修復與改進

- 全新的 Codex 與 Claude 二進位檔管理機制，減少因環境差異導致的使用問題。請前往「設定 → Agent」重新整理。
- 最佳化傳送與停止訊息的處理流程，現在反應速度更快。
- 改進資料同步策略。
- 修復有時無法檢視 Diff 或檔案的問題。
- 修復專案路徑過長時無法點擊「新增」按鈕的問題。
- 在 Windows 上，應用程式標題列顏色現會跟隨主題變化。
- 修復行動版網頁中鍵盤無法收起的問題。
- 修復對話中的圖片有時無法開啟的問題。
- 在行動端「設定」頁面新增錯誤回報入口。
- 修復 Linux 上登入時重新導向失敗的問題。
- 在 Zed 中開啟已開啟的專案時，現在會聚焦至現有視窗，而非開啟新視窗。
