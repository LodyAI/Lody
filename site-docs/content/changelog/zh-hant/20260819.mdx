版本 0.83.0

### ✨ 新功能

- 改進 Kimi Code，支援背景任務、子代理與 Token 用量追蹤。
- 全新桌面版引導流程：首次啟動現包含開場動畫與產品導覽，可讓您選擇佈景主題與語言、自動偵測本機已安裝的 Agent，並引導您完成第一個工作階段。
- Agent 現在可以直接為您設定工作區的 MCP 伺服器。

### 🐛 修正與改進

- 修正離線或遠端儲存庫無法連線時，工作階段 worktree 還原失敗的問題。
- 修正 CLI 回報的版本號與實際發布版本不符的問題。
- 修正 dsh 相容性問題。
- 改善 dsh Agent 呈現思考過程的方式。
