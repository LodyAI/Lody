### 新功能與能力

- 新增 `lody export` CLI 指令，可匯出工作階段資料，包含 JSON、Markdown、附件與用量統計。**我們將於下週切換至全新的同步後端服務，舊有的歷史資料將不再相容，請提前匯出並保存您需要保留的資料**
- 支援為所有 ACP Agent 自訂標題生成模型
- 當工作階段等待核准時，權限請求橫幅會固定顯示於輸入框上方，不會因捲動頁面而找不到
- 機器選擇器已從 Agent Config 下拉選單中獨立出來，方便單獨選擇目標機器
- 點擊對話中的檔案路徑現在可正確開啟完整檔案

### 平台與介面體驗

- 窄螢幕下工作階段設定按鈕不再遭到擠壓或裁切
- 行動裝置上的聊天輸入區底部會自動換行，不再將按鈕擠成一團
- 行動裝置上的用量圖表與統計卡片已針對小螢幕最佳化，不再出現水平溢出

### 修正與穩定性

- ACP 錯誤訊息現在會顯示具體的底層原因
- 透過自動偵測可用的 keyring 後端，修正桌面版在非 GNOME 的 Linux 環境（包含 Sway、Hyprland 與 Niri）下的驗證失敗問題
- 修正空遠端儲存庫建立 worktree 時發生失敗的問題
- 修正大量檔案變更時，因過多同時執行的 `git show` 操作導致 CPU 阻塞的問題
- 修正使用 `#` 提及 Issue 與 PR 且快取重新整理失敗時，誤用過期中繼資料的問題
