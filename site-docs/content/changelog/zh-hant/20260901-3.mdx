版本 0.89.3

### ✨ 新功能

- 當 Codex 遇到容量不足錯誤時，現在支援明確的手動重試，並接續有限次數的自動重試，同時提供倒數計時與取消控制項。
- 新增輕量級加入入口，無需載入完整應用程式外殼即可處理加入流程。

### 🐛 修復與改進

- 修復工作階段設定、工作階段分頁、工作區存取備援以及瀏覽器可見性同步中的重複更新與渲染迴圈問題。
- 修復在非同步資料載入與使用者快速操作下，工作階段切換、深層連結還原以及待處理狀態可能發生的異常。
- 提升對異常工作階段父子關係與渲染錯誤的容錯能力，防止重新導向迴圈與渲染器當機。
- 感謝外部貢獻者 Wibus Wu 貢獻 Codex 重試與輕量級加入入口功能。
