### Agent 使用體驗

- 新增 Codex Fast Mode 快速切換開關
- 新增 Claude Think Level 選擇
  <img src="/_docs-assets/fast-think.png" alt="" />
- 最佳化權限請求卡片：過長的按鈕支援自動換行，長指令可展開檢視完整內容，讓您在核准前更容易確認 Agent 即將執行的操作

### 全新機器與 Agent 設定

- Agent 設定改為依機器分別管理。切換機器時，Lody 只會顯示該機器上可用的 Agent，避免誤選無法執行的設定
- 設定頁面改為「機器清單 + 機器詳情」版面配置，可直接檢視線上狀態、CLI 版本與共享狀態

### 內建 GitHub PR 工作流程

- 點擊工作階段頂部的 PR 徽章，即可在 Lody 內開啟 PR 面板，檢視標題、描述、分支、CI、留言與 Review
- 支援直接在 Lody 內於 PR 留言、合併 PR，並在合併後刪除分支
  <img src="/_docs-assets/PR-panel.png" alt="" />

### 行動裝置體驗

- 行動裝置上可設定鍵盤 Enter 鍵的行為：送出訊息或插入換行
  <img width="400px" src="/_docs-assets/20260422-keyboard-option.png" />
- 工作階段清單支援左滑封存；封存清單支援左滑還原或永久刪除
- 開啟已封存的工作階段時，頂部選單現在會正確顯示「還原」與「永久刪除」，而非再次顯示「封存」
  <img width="400px" src="/_docs-assets/mobile-swipe.png" />

### 對話搜尋與佇列訊息

- 重新設計對話內搜尋列，結果數量、無結果狀態與上／下一筆操作更加清晰
- 修正長工作階段中跳轉搜尋結果有時會卡住的問題
- 多則排隊等待執行的訊息不再佔滿整個畫面，現在會限制高度並支援捲動檢視

### 團隊與邀請管理

- 切換 Workspace 後，待處理邀請現在會正確重新整理
- 管理員現在可以取消待處理的團隊邀請

### 其他修正

- 修正前端產生的 CLI Token 有時會登入失敗的問題
- 側邊欄儲存庫順序不再因機器可見性變更或同步抖動而來回跳動
- 當瀏覽器從背景切回、重新取得焦點或恢復網路連線時，會自動重新驗證登入狀態
- 當同步短暫落後時，建立工作階段與派發任務現在會自動重試，減少新任務卡住的情況
