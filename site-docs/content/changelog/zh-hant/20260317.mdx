### 新功能與能力

- 桌面應用程式正式發布，可前往[此處下載](/zh-hant/download)
- 新增圖片輸入與截圖回傳支援
<img src="/_docs-assets/20260317-lody-image-back.png" alt="" />
- 支援所有 ACP Registry 設定選項
- 新增完整的 [CLI 指令集](/zh-hant/docs/cli)：`session`、`workspace`、`history`、`agent-config` 與 `machine`

### 平台與介面體驗

- 收合側邊欄時顯示分組數量，並在 PR 工作階段上直接顯示 PR 編號
- 新增桌面版版本顯示與更新檢查功能
- 新增「重新啟動 CLI」按鈕
- 工作階段執行期間可防止系統進入休眠，並提供設定選項可將其關閉
- 記住桌面版視窗大小與位置

### 修正與穩定性

- 修正 Token 用量可能顯示負增量的問題
- 修正 Changes 分頁中變更數量高估的問題
- 修正行動裝置橫直向切換、Settings 與 Integrations 頁面捲動，以及圖片預覽關閉按鈕位置等問題
