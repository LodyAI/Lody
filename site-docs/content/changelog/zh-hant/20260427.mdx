### Agent 體驗

- 新增對 GPT-5.5 的支援
- 重新設計 Agent 設定頁面，加入全新分類側邊欄與能力重新整理流程
- 新增 DeepSeek 預設組態，貼上 Token 即可快速完成設定
- 提升 Claude Code、Codex 等 Agent 的連線穩定性與能力偵測準確度
- 修復在 macOS 上使用 Codex 時可能觸發 `ComputerUse` 錯誤彈窗的問題

### 桌面端體驗

- 左側邊欄現在支援摺疊、拖曳調整寬度，以及使用快捷鍵展開／收合
- 本機專案、GitHub Worktrees 與 Chat 區塊的劃分更清晰，側邊欄互動體驗更一致
- 工作階段中的本機檔案清單現在會自動重新整理，方便即時檢視變更

### 對話體驗

- 串流輸出的程式碼區塊不再於語法高亮與純文字呈現之間來回閃爍
- 工作階段初始化與切換更穩定，減少偶發的載入錯亂問題

### 其他修復

- 遠端專案不再誤觸發本機偵測
- 機器上線狀態與即時同步現在更加準確
- 修復 Electron 內 CLI 輸出區域底部的間距問題
