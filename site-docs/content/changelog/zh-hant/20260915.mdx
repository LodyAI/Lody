版本 0.94.0

### ✨ 新功能

- 透過無需登入即可檢視的唯讀連結，分享工作階段與選定的子工作階段。
- 更輕鬆地管理已發佈的分享內容：檢視分享狀態、瀏覽分享中的子工作階段、調整分享側邊欄寬度，以及返回來源對話。
- 建立、編輯、刪除與分享 Prompt Shortcuts，並可搭配變數與上下文作用域從 `/` 選單快速呼叫。
- 新增 Bub 作為內建 ACP Provider。
- 支援以分區視窗方式讀取並還原長對話，減少開啟大型工作階段時的等待時間。
- 當桌面應用程式無法正常開啟時，可透過 CLI 重設其本機快取。
- 支援透過系統原生的分享流程，直接從對話中分享檔案。

### 🐛 修正與改進

- 改善分享頁面的載入、壓縮歷史紀錄讀取、導覽與復原機制，避免單一請求失敗導致整個對話崩潰。
- 修正分享頁面的登入提示訊息、對話樹連接線、標題層級與側邊欄版面配置問題。
- 改善工作階段復原、歷史紀錄同步、壓縮中斷復原，以及已封存工作階段的處理。
- 修正 Windows 工作階段路徑、已封存的 Worktree、共享機器專案導覽，以及桌面端登入帳號確認問題。
- 改善提示詞輸入體驗，包含依工作區隔離的草稿、編輯排隊訊息時的焦點處理、終端機分頁狀態，以及貼上過大內容時的明確提示。
- 改善 ACP 相容性、Grok 預設設定、DeepSeek Harness 行為，以及內建 Agent 的用量統計。
- 在行動端顯示執行中的 Agent 時長，並改善字型大小控制與多圖片附件排版。
- 修正禮品訂閱到期後的結帳復原問題。
- 修正缺少選填標註資料時預覽頁面無法載入的問題。
- 確保選單保持在小視窗與安全區域範圍內，並修正 macOS 封存項目的重疊遮擋問題。
- 感謝外部貢獻者 @gu18168、@EYHN、@UniversePeak、@Astro-Han、@lawvs、@VeraPyuyi 與 @liuxiaocs7 在 ACP 行為、工作階段復原、任務控制、輸入處理、執行環境相容性與桌面端介面方面的改進。
