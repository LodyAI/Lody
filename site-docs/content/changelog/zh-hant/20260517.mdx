### 新功能

- 現在可從遠端裝置檢視本機專案的 Git 分支，並直接啟動 worktree。

### 修正與改進

- 修正從外部 ACP Agent 匯入的工作階段頭像顯示不正確的問題。
- 修正 Claude 工作階段偶爾卡在閒置狀態的問題。
- 修正斜線指令搜尋結果排序錯誤的問題。
- 修正匯入工作階段紀錄時偶爾產生重複項目的問題。
- 修正行動應用程式在電子郵件登入過程中發生非預期重新導向的問題。
