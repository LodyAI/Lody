### 改善 CLI 啟動與登入體驗

- 精簡 CLI 啟動流程，實現一鍵啟動
- 移除 Docker 模式
- 新增 `project` 指令群組以管理本機專案
  - `npx lody project add [path]` 將本機專案新增至 lody
  - `npx lody project list` 列出本機專案
  - `npx lody project delete` 以互動方式刪除本機專案

- 修復開啟檔案差異時介面卡頓的問題
- 修復部分情境下的身分驗證流程異常問題
