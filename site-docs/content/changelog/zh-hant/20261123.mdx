版本 0.114.0

### ✨ 新功能

- EverMe 現已作為帳號層級的記憶提供者登場，支援一鍵安裝或手動設定。
- 實驗性的 Today 大綱將筆記、待辦事項與工作階段提及整合在同一頁面。你可以將項目轉換為任務、聚焦單一分支、分段擴展選取範圍，或一次編輯多個項目。在桌面端，還能將 Today 開啟為獨立視窗，與工作階段並排檢視。
- 在全新的狀態檢視中，將工作階段整理為 Focus、Later 與 Settled。你可以將工作階段延後 1 小時或 3 小時處理，或拖回 Focus。
- 可將釘選的工作階段分組並手動調整排序。你可以為每台裝置選擇要顯示的群組，或直接在群組內啟動新工作階段。將工作階段拖曳至側邊欄邊緣時，列表會自動捲動。
- 按下 ⌘/Ctrl + 1–9 即可切換側邊欄前九個可見的工作階段；較長的列表支援逐頁展開。
- 可從工作階段連結或取消連結 GitHub PR、將已連結的 PR 交由 Auto delivery 處理，並在側邊欄查看合併回饋。
- 可從工作階段選單直接在 Finder 或檔案總管中開啟工作目錄。在終端機中按住修飾鍵點擊網址，即可在瀏覽器中開啟。
- 可在工作階段側邊面板預覽附件，並調整影片播放速度。
- 在空白輸入框中按上／下方向鍵可叫回已發送的訊息。支援自訂模型搜尋、思考強度與附件選單的快捷鍵。
- Codex 新增 Ultrafast 速度選項。現在也可以直接從 Lody 遠端登入 Antigravity。
- 在 Lody Agent 設定中，可檢視並重新整理自訂端點提供的可用模型，並為新工作階段設定預設模型、思考強度與自主程度。Prompt 與 Agent Role 編輯器也已重新設計。
- 可讓 Lody 在背景執行長時間執行的指令；指令結束後，工作階段會接收結果並繼續執行。工作階段編輯者也能在共享主機上管理自動化任務。
- 支援透過桌面端的「設定 → 資料」或 CLI 匯出與匯入工作區。匯入來自其他工作區的內容時，目標工作區成員將獲得唯讀存取權限。

### 🐛 修復與改進

- 封存頁面現預設以單一列表開啟，無需逐一展開群組即可瀏覽較舊的工作階段。
- 輸入框會套用你的介面字體大小設定。編輯已發送的訊息時，同樣可使用 Prompt 快捷短語。
- 點擊已發送訊息中的工作階段提及即可開啟該工作階段；指向目前工作區內工作階段的 Markdown 連結也會直接在 Lody 內開啟。
- 在較窄的視窗中，輸入框子選單會保持在螢幕可視範圍內。若專案未連結 GitHub 儲存庫，提及選單會隱藏 Issue 與 PR 分類。
- 背景視窗不再意外將工作階段標記為已讀。調整 Focus 排序時，剛從 Later 返回的工作階段也會保留未讀狀態。
- 當你在其中一個視窗收合群組或變更篩選條件時，其他開啟的視窗會保留各自的側邊欄檢視狀態。
- 停止發送時，佇列中的訊息會保留為草稿，方便你自行編輯後重新發送。重啟前遭到中斷的輪次，只需一次「continue」即可恢復。
- 修復發生當機後新建的工作階段可能遺失，以及工作區變更列表中缺少檔案的問題。
- 切換離開工作階段再返回時，先前開啟的預覽會維持開啟狀態。修復大型本機 HTML 無法預覽，以及預覽中專案資源或重新導向載入失敗的問題。
- 遠端檔案搜尋會在存放檔案的主機上執行。GitHub 分支改為逐頁載入，以減少大型專案中的等待時間。
- 修復 Antigravity 的指令與技能選單顯示為空，以及背景任務結束後工作階段仍顯示為執行中的問題。
- 修復當模型提供自訂推理強度值或較長的輸入類型列表時，整個 Magpie 模型目錄載入失敗的問題。
- Agent 連線、Claude 用量查詢、桌面端連線與自動化任務都會套用你設定的 Proxy。現在也可以轉往瀏覽器繼續完成桌面端登入。
- 修復獨立安裝後在終端機中無法使用 lody 指令的問題。明確執行重新安裝時，會啟用新安裝的守護行程（daemon）版本。
- 桌面端啟動速度更快、CLI 守護行程佔用更少記憶體，且重新開啟長工作階段時載入歷史紀錄的效率更高。
