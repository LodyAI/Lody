版本 0.98.0

### ✨ 新功能

- 提升從行動端分享內容建立 Agent 任務的可靠性；即使目標機器暫時離線，待其重新上線後仍可繼續送達任務。
- 將 DeepSeek Harness 的提問串接至 Lody 的 Ask Question 介面，支援獨立的回答備註，並改進 Kimi Plan 互動卡片。
- 改進側邊欄專案整理功能，新增專案上下文資訊、最佳化本地專案排序，並提供最近更新專案的顯示控制選項。
- 顯示工作階段實際使用的模型，讓每個任務所使用的模型更容易準確辨識。
- 提升桌面端多視窗、封存清單與大型專案檔案搜尋的效能，減少開啟視窗、捲動及搜尋時的卡頓。
- 在長對話中進行跨螢幕選取文字時，即使虛擬化列被回收，仍可保留選取範圍。

### 🐛 修復與改進

- 修復部分封裝安裝環境中 Devframe 與 Devbar 啟動失敗的問題。
- 修復 Windows 上指令超過 Shell 長度限制時導致 DeepSeek Harness 無法啟動的問題。
- 修復代管的 Astro 預覽可能回傳純文字 403 或在導覽期間失敗的問題。
- 修復訊息、權限請求與上下文壓縮狀態可能寫入亂序或維持未完成狀態的問題。
- 改進通知跳轉、未讀狀態、最後一個分頁的視窗關閉行為、Zen 模式、Mermaid、數學公式渲染、對話框層級與輸入焦點等細節。
- 修復 Kimi Plan 找不到檔案的錯誤、模型與專案搜尋焦點、用量詳情快取，以及已關閉對話的未讀輸出問題。
