版本 0.82.0

### ✨ 新功能

- 新增本機專案的 Git 工作流程；完成 Lody GitHub 整合授權後，亦可使用 GitHub PR 工作流程。
- 支援將工作階段從側邊欄拖曳至輸入框，自動建立 @ 提及。
- 工作階段現可分叉至新的 worktree，方便平行推進不同方案。
- 新增全域 MCP 設定，建立對話時可從加號按鈕選單中選取。
- 輸入框中的 @ 提及現會以標籤形式顯示，讓引用工作階段與技能更加方便。
- 差異檔案標題列現提供「複製路徑」與「開啟檔案」操作。
- 新增可自選時間範圍的用量趨勢檢視。
- 訂閱方案與兌換碼現可同時套用。

### 🐛 修正與改進

- 改善串流對話的捲動跟隨、終端機複製貼上與文字選取體驗。
- 改善子工作階段的導覽與呈現方式，包含行動版的階層式清單。
- 修正工作區清理、工作階段啟動及連線復原的多項穩定性問題。
- 最佳化側邊欄與頁面導覽效能，減少不必要的介面更新。
