### 新功能

- Goal 模式現在會回報每次執行的耗時與 Token 用量。
- 行動端工作階段頂部選單現在新增「重新命名」操作。

### 修復與改善

- 整理並修復 Goal 模式介面，解決版面顯示順序錯亂的問題。
- 修復 Goal 模式偶發凍結無回應的問題。
- 修復 Codex 圖片生成偶爾未回傳圖片的問題。
- 修復新手引導流程在等待 Agent 設定時停滯無回應的問題。
- 修復模型選擇器中模型名稱遭到截斷的問題。
- 訊息佇列中的插入與取消控制項現在會常駐顯示，不再僅於滑鼠懸停時才出現。
