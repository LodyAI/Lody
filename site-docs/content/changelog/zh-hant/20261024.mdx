版本 0.108.1

### ✨ 新功能

- 全新設計的對話首頁，提供「現在」與「本週」檢視：查看等待處理、執行中或最近完成的對話，並同步顯示近期工作與 Agent 方案用量。
- 可為每個專案設定預設 MCP 工具。新對話會套用專案設定，您也可以在傳送前進行調整。
- 「All Changes」除了累積分支變更外，現在也提供「未提交」檢視，並顯示比較基準。
- 工作區推薦獎勵：分享推薦連結、查看獎勵餘額與紀錄，並將符合條件的額度折抵訂閱費用；同時支援限時推薦活動。
- Agent 完成通知現已包含回覆節錄，無需開啟對話即可預覽結果。
- 新增 OpenCode V2，並更新多款 ACP Agent。
- 排程任務提示詞欄位現會隨內容自動擴展至約半個視窗高度，方便編輯長篇指令。
- 封存含有進行中子對話的對話時，系統會顯示子對話數量與執行狀態，讓您選擇是否一併封存或僅封存目前對話。
- 翻新淺色主題、側邊欄與登入頁面；統一邀請、裝置授權及相關頁面的版面配置；改善啟動與頁面切換流暢度；並新增本裝置上次成功登入方式的指示標記。

### 🐛 修復與改進

- 最佳化對話與分頁切換效能，減少長對話、串流輸出與歷史紀錄載入時的卡頓。
- 最佳化包含大量子 Agent 工具輸出的對話載入效能，改為按需讀取任務詳細資料以避免不必要的處理。
- 改進歷史紀錄同步機制以減少重複傳輸與儲存，並修復部分情境下訊息內容重複的問題。
- 修復部分已接收的同步更新在重新啟動後可能遺失的問題，提升本機資料保存與恢復的可靠性。
- 改進儲存失敗後的同步恢復機制，減少重複下載與過高流量，並修復本機資料庫連線無法恢復的情況。
- 改進網路中斷後的重新連線機制，修復對話停止同步且必須手動重新整理才會更新的問題。
- 修復桌面端在網路異常時遺失工作階段狀態的問題。
- 當桌面端因磁碟空間不足導致寫入失敗時，會顯示明確提示並鎖定進一步的介面操作，引導您釋放空間後再重新啟動或結束程式。
- 修復 CLI 異常關閉時出現重複錯誤、日誌過度增長及無法正常結束的問題。
- 修復 Windows 上的本機 Agent 在發生權限錯誤後持續停留在「連線中」的問題，並新增恢復指引。
- 修復透過 Lody MCP 建立對話時因回應過慢觸發重試而產生重複對話的問題。
- 修復當 Agent 已回覆後檔案變更重新整理仍在進行，導致對話停留在收尾狀態及停止操作耗時過長的問題。
- 修復歷史紀錄仍在載入時 Agent 提問卡片偶爾遺失的問題；等待使用者回答期間不再持續累計工作時間。
- 拒絕執行 Claude 的計畫後，原本的計畫內容仍會保留可見。
- 針對因異常執行狀態而無法接收輸入的對話，新增更清楚的錯誤訊息與手動 CLI 恢復路徑，同時保留佇列中的輸入內容。
- 修復自訂 ACP Agent 歷史紀錄同步、匯入與衝突處理遭拒絕的問題。
- 合併或關閉 PR 不再自動封存其對應對話，避免中斷後續工作。
- 對話標題現直接採用使用者的實際輸入，不包含 Agent 設定或 Role 指令；分支對話標題不再自動加上前綴。
- 透過 CLI 或 Lody MCP 使用 Agent Role 建立對話時，Role 指令不再顯示於可見的使用者訊息或對話標題中。
- DSH 文字與工具呼叫改為獨立顯示，摺疊工具時不再連帶隱藏隨附文字；改進思考內容排版並移除過時的委派模型警告。
- Markdown 檔案預覽中的對話連結現可正常開啟。
- 修復巢狀 Git worktree 中的相對檔案連結；當有多個符合的檔案時，您可選擇要開啟哪一個。
- 改進語法突顯與捲軸樣式，並最佳化較矮視窗下的首頁版面、摺疊控制項與轉場效果。
- 改進對話分享控制項，將存取範圍、連結發佈與連結管理整合至單一面板。
- 改進成員頭像、Skill 詳細資訊與用量檢視；修復頭像閃爍、選單焦點異常及排程任務控制項被 Windows 標題列按鈕遮擋的問題。
- 縮減工作區邊框寬度，並改進 macOS 標題列與視窗按鈕的對齊效果。
- 修復 iOS 16.4 上的網頁啟動錯誤及差異檢視主題色彩問題。
- 更新 DimCode 圖示，並隱藏無實質內容的操作成功回執。
