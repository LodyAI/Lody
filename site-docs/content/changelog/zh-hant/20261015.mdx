版本 0.105.0

### ✨ 新功能

- 新增影片檔案預覽支援。
- 全螢幕圖片預覽新增長按選單，可依裝置支援情況複製、儲存或分享圖片。
- CSV、TSV 與 XLSX 預覽支援調整欄寬、選取並複製儲存格或矩形範圍；XLSX 預覽亦支援調整列高。
- 行動端上的 HTML 檔案與聊天附件現預設以預覽模式開啟，並提供切換檢視原始碼的選項。
- 新增 iOS 主畫面小工具，可檢視對話進度與工作區 Token 用量。
- 記憶匯入現支援一次選取並批次新增多個身分。
- DeepSeek 現支援載入並繼續原生歷史工作階段，同時保留上下文、模型、權限與預設組態。
- DeepSeek 現支援在執行過程中追加引導指令，以及設定、暫停與恢復 Goal 目標任務。
- DeepSeek 現支援查詢與取消子代理，並顯示背景任務狀態、重試活動與目前上下文用量；是否可取消取決於執行方式。
- Pi 的子代理工具現可為每個子任務選取可用的模型。
- 更新 Claude Code 以支援 Haiku 5.5，並更新 Codex 以支援更大的上下文長度。
- Codex 現可在 `/plan` 指令後直接附帶任務描述，自動標題亦可使用 Lody 中設定的標題模型與參數。
- CLI 與 MCP 建立及繼續工作階段時，現支援夾帶檔案與圖片附件，包含發送至遠端機器工作階段的附件。
- CLI 建立工作階段現支援 `--agent-role <名稱或 ID>`，直接套用工作區角色的機器、Agent、模型與提示詞設定。
- Cloud CLI 新增 `migrate --from-oss`，可將 OSS 版的 Loro 工作階段紀錄與歷史附件匯入現有的雲端工作區。
- 建立獨立工作樹後，Agent 會在首次任務中收到依任務內容命名分支的提示，方便識別並行作業。
- 關聯對話面板新增「停止協作」與「恢復協作」操作。停止主工作階段及其子工作階段可防止延遲送達的 Agent 結果再次觸發執行。協作需手動恢復；離線機器會在同步後套用變更。
- 連續建立的子對話會整併為精簡的任務面板，支援展開、收合與內部捲動。
- 訊息佇列現支援收合，收合後仍會保留草稿，並顯示仍在準備中或發送失敗的訊息數量。
- 輸入框現提供執行機器詳情：桌面版可將滑鼠懸停於機器名稱上或點擊檢視其擁有者與連線狀態；手機版可透過圖示按鈕開啟詳情卡片。
- 遠端目錄選取器現支援在桌面端與行動端建立並進入新資料夾，再將其新增為專案；目標機器需更新至支援此功能的 CLI 版本。
- 側邊欄較長的工作階段標題會在滑鼠懸停或鍵盤聚焦時自動捲動，也可透過拖曳、觸控板或滑鼠滾輪檢視完整標題，動畫效果會遵循系統的「減少動態效果」設定。
- 支援額度查詢的 Provider 現可在切換輸入框設定、開啟額度面板或返回應用程式時，依需求重新整理訂閱額度。
- 帳單詳情現會顯示收費原因、席位變更、明細項目、未付餘額及付款入口。
- 新增本機 Magpie 設定匯入接收端；完整匯入流程仍需待 Magpie 端配合支援。

### 🐛 修正與改進

- 修正建立或繼續 Codex 工作階段時，所選模型未及時套用的問題。
- 當 Agent 拒絕模型選取時，介面會顯示警告提示，避免將切換失敗誤認為成功。
- 修正部分 ACP Agent 套用模型設定的順序，避免切換模型後重設角色的推理強度等選項。
- 修正繼承的選項（如推理強度與 Fast）依據錯誤模型進行驗證的問題。
- 儲存 Agent Role 時會清除已過時的設定選項並保留有效選取，減少持續出現相容性警告的情況。
- 修正提示詞（包含 Agent Role 提示詞）在繼續執行、引導或恢復過程中，於提交與送達之間內容發生變動的問題。
- 修正 Agent Role 提及選單在詳情變更時遺失選取或定位異常的問題，並修正 Agent 設定對話框中的焦點外框顯示。
- 修正行動端 Dimcode 設定選項相互干擾，以及鬆開觸控後權限選取遺失的問題。
- Dimcode 現改用機器上已安裝的指令與現有設定；若尚未安裝，則提供可複製的安裝指令。
- 修正 Amp 轉接器重複使用舊版快取的問題，現改為使用對應版本的二進位執行檔。
- 修正部分 Node.js 版本下，以 ZIP 散布的 Agent 在安裝解壓縮期間停滯不前的問題。
- 修正 Pi 指令輸出遺失換行的問題，包含既有工作階段中的輸出。
- Pi 擴充功能在掃描完成前會先顯示已儲存的套件名稱，並清楚回報擴充功能載入失敗的資訊。
- 匯入 Codex 歷史紀錄時會保留附件，並為工作階段遭其他用戶端佔用、服務異常、啟動失敗及工作目錄相關錯誤提供更明確的提示訊息。
- 修正服務重新啟動後無法恢復空白 Codex 工作階段，以及歷史工作階段標題選取不準確的問題。
- Codex 會在開啟工作階段前儲存實際執行目錄的信任狀態，改善專案技能與 MCP 設定的探索，同時保留明確設為不信任的目錄。
- Claude 背景 Bash 任務現會將實際指令與任務說明分開顯示，並支援語法突顯與複製。
- 改善已停止的背景任務在 Claude 歷史紀錄中的呈現方式，降低被誤顯示為使用者提示詞的情況。
- 修正斷線重連或延遲重試後，Agent 完成訊息被重複處理而觸發重複執行的問題。
- 多個 Agent 回傳的結果現會整批處理；忙碌中的工作階段會在目前輪次結束後才接收，減少因逐筆結果反覆觸發續跑的情況。
- 將 Agent 連續委派上限設為 16 層，並最佳化協作指示，減少不必要的確認回覆與重複結果回傳。
- 修正佇列中某一則訊息的儲存確認意外清除下一則正在編輯訊息草稿的問題。
- 在待回答問題之間切換時會保留已選答案、自訂輸入與備註；提交失敗時會顯示錯誤訊息並保留答案供重試。
- 修正中文輸入法確認候選字時意外送出自訂答案的問題。
- 修正 Codex 等 Agent 的單題表單僅顯示「Input requested」，而未顯示完整問題的問題。
- 修正聊天失敗詳情重複顯示的問題。
- 最佳化長對話中的串流輸出寫入效能，減少大量工具呼叫時的 CLI 停頓，以及訊息送達其他裝置的長時間延遲。
- 修正包含超長指令或內嵌圖片的對話導致介面長時間凍結的問題。
- 減少工作階段歷史中未使用的工具圖片、內嵌資源位元組與重複資料，並限制指令摘要與工具標題長度，降低儲存與同步負擔；一般附件、可讀輸出、程式碼差異與審批內容皆會保留。權限確認提示會清楚標示已截斷的指令。
- 最佳化開啟提及選單時的頁面渲染效能，減少輸入框操作延遲。
- 貼上達 50,000 字元以上的文字時會自動轉換為文字附件，同時完整保留原始內容。
- 修正行動端貼上文字編輯器未充分利用可用空間的問題；現可在面板內捲動檢視全文，且字體排版與輸入框一致。
- 修正延遲抵達的捲動事件打斷慣性捲動，或在觸控使用者閱讀早期訊息時將畫面拉回底部的問題。
- 修正行動端快速捲動至底部時的抖動與回彈，以及輸入框高度變化或編輯草稿時意外重新跟隨新訊息的問題。
- 修正滑鼠位於 Mermaid 預覽上方時無法捲動對話的問題，並減少因重複版面更新引發的頁面錯誤。
- 發送新訊息時會保留部分前文內容，方便銜接閱讀。
- 修正「捲動至最新訊息」箭頭在滑鼠懸停或鍵盤聚焦時遭隱藏的問題。
- 改善行動端對話在內文、執行步驟與動作列之間的對齊與輪次間距；較早的訊息於輕觸時顯示操作按鈕，最新一則助理回覆則維持常用操作可見。
- 調整貼上文字標籤、GitHub Issue 與 PR 參照標籤與周圍文字的對齊，改善任務回覆卡片間距，並統一耗時顯示與頁尾文字的字體樣式。
- 修正中文、日文與韓文內容中緊鄰標點符號的 Markdown 粗體與斜體無法正確渲染的問題。
- 收合較長的使用者訊息時，現會於完整行之間結束並以漸層淡出提示尚有內容，避免從文字中間截斷。
- 桌面版輸入框頁尾現會顯示完整的模型名稱。
- 修正窄視窗下按鈕與變更統計溢出工作階段資訊列的問題；空間受限時，文字與機器名稱會自動縮減寬度。
- 行動端 HTML、Markdown 與純文字附件改用接近全螢幕的底部面板，提供更充裕的閱讀空間，並改善預覽空狀態提示訊息。
- 修正行動端抽屜內對話框的點擊、輸入與捲動問題，並防止觸控穿透至底層介面。
- 停用 iOS 訊息連結的系統長按預覽，避免之後輕觸其他位置時反覆重新開啟同一連結；輕觸開啟與文字選取功能仍維持可用。
- 放大觸控裝置上的訊息佇列操作按鈕，減少誤觸機率。
- 修正行動端底部導覽列收合或展開時圖示被拉伸的問題，並改善向上捲動時的導覽列顯示與焦點處理。
- 統一工作階段連結的開啟、貼上與匯出行為，更精確地定位工作區與目標工作階段，同時保留對舊連結的相容性。
- 修正貼上子工作階段連結時錯誤指向父工作階段的問題；連結錯誤提示現可區分已封存的工作階段、無法存取的工作區及其他情況。
- 尚無可用工作目錄的本機工作階段現已支援預覽絕對路徑與 `~/` 檔案路徑；修正 `~/` 路徑可預覽卻無法開啟或在檔案管理員中顯示的問題。
- 修正帶有行號的檔案連結首次點擊時停在檔案頂部的問題，並恢復目標行範圍的醒目提示。
- 恢復排程任務頁面在側邊欄隱藏時的展開按鈕，並修正 macOS 視窗控制按鈕附近的版面配置。
- 修正手機排程清單遭狀態列遮蔽的問題；儲存或關閉任務後，會返回具備工作區切換、搜尋、設定與底部導覽列的首頁排程分頁。
- 登入狀態恢復連續失敗後會停止無限載入，並在保留目前頁面的情況下提供重試與重新登入選項。
- 登入、切換工作區或開啟工作區等待超過 30 秒後，會顯示提供重新載入、清除快取與複製診斷資訊的恢復頁面；連線停滯提示橫幅亦可開啟此頁面。
- iOS 啟動恢復現支援原生完整本機資料重設，可在應用程式無法正常載入時清除本機資料並返回登入流程。
- 修正桌面端在部分 Proxy 或憑證環境下無法登入的問題，並為憑證驗證錯誤提供更清楚的疑難排解指引。
- 雲端查詢在遇到暫時性伺服器錯誤時會進行有限次數的重試，減少暫時故障導致頁面中斷的情況。
- CLI 讀取機器資訊時，若遇暫時性同步失敗可回退使用既有的本機資料；未同步完整的機器設定不再將暫時無法使用的專案、Agent 或模型誤判為無效。
- 改善切換工作區、帳號及連線失敗後的清理機制，避免舊連線與延遲請求干擾新連線，並在同步錯誤中提供更多詳細資訊。
- 改善同步憑證重新整理與 Shell 環境查詢的共用及取消處理，避免單一請求逾時或遭取消時影響其他請求。
- 修正多個 CLI 或 MCP 指令同時存取同一工作區時出現重複初始化錯誤的問題，以及先前的準備尚未完成即重用工作區而干擾後續工作階段的問題。
- 修正 stdio MCP 服務在連線後過早釋放執行環境，導致後續工具呼叫失敗的問題。
- 改善 Agent 結束、工作階段終止與啟動失敗時的程序清理；已取消的任務在完成清理前仍會標示為進行中狀態。
- 恢復桌面端與行動端用戶端的個人 GitHub 授權入口，可開啟瀏覽器完成授權。
- 即使工作區尚未關聯儲存庫，亦可以唯讀方式檢視公開 GitHub PR 的詳情、審查意見與程式碼變更。
- 限制 GitHub PR 關聯失敗後的重試次數並補充權限修復指引，同時持續更新 PR 狀態。
- 修正工作階段準備與重新啟動期間，過時的 GitHub 憑證狀態導致後續訊息無法執行的問題。
- 修正唯讀 GitHub 憑證在 HTTPS 複製與遞迴擷取子模組時遭拒絕的問題，並在非互動式 PR 建立流程中保留 GitHub App 來源歸屬資訊。
- 為 Git 身分查詢與憑證助手探測加入逾時限制、減少重複的環境探測，並重試暫時性的程序啟動失敗，避免 Agent 長時間停留在初始化階段。
- 修正讀取 Git 身分時遺漏 XDG 全域設定，以及檔案索引在並行 Git 查詢完成前過早回退的問題。
- 改善本機專案與工作樹的 Git 錯誤處理，避免將啟動失敗、逾時與權限錯誤誤判為缺少儲存庫或分支。
- 改善檔案鎖定排隊與異常結束後的清理機制，減少殘留鎖定造成的阻塞；Git 與清理錯誤將予以保留，避免誤觸強制移除工作目錄。
- 改善工作樹分支命名前的檢查機制，避免對既有分支或不適合的工作區發送重新命名提示。
- 重新整理 Provider 設定中的額度資訊，明確區分剩餘額度與重設預測，並顯示每一個額度區間。
- Codex 重設預測現可一鍵開啟；重新整理與刪除操作移至獨立的管理選單，避免滑鼠懸停時遮擋預測入口。
- 當本機 Agent 暫時無法使用時，側邊欄機器群組仍維持原有排序，減少清單跳動。
- 更新個人頭像時會同步重新整理工作區成員資訊，避免成員清單持續顯示舊頭像。
- 行動端執行設定與 Agent Role 設定更清楚區分「模式」與「權限」；資料夾分享開關改用「與團隊共享專案」等明確的動作標籤。
- 修正 Windows 開啟對話框後，右上角視窗控制按鈕後方出現非預期背景色塊的問題。
- 移除桌面端安裝程式中重複的執行階段檔案、壓縮桌面介面資源，並減少 Linux 上重複檢查 Claude 執行環境的負荷。
- 改善變更介面字型大小後的新手引導對話間距，並修正封存清單出現「0 分鐘前」等時間戳記的問題。
- 修正文件標題錨點與頁面出現重複第一層標題的問題。
