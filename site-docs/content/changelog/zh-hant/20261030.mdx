版本 0.109.0

### ✨ 新功能

- 多儲存庫專案：將多個 Git 儲存庫、子模組與本機資料夾整合至單一專案中，並在同一對話內處理跨儲存庫任務。可於「設定 → 專案」新增，或在桌面端側邊欄於現有專案上按右鍵新增。（在 iOS 上需等待下一個行動端 TestFlight 版本，否則將無法顯示多儲存庫對話。）
- 依儲存庫檢視 PR：在多儲存庫對話中可切換要顯示的儲存庫，查看其 PR、CI 狀態與相關操作；子模組會以階層式呈現。
- Magpie CLI 匯入：透過 CLI 匯入 Magpie 供應商設定，方便在無桌面環境的機器上使用。
- 下一條提示詞建議：Claude Code 現可在空白輸入框中顯示 Agent 回傳的建議；在桌面端按 Tab 或在行動端點選「套用」即可填入。
- 本機 MCP 登入：支援瀏覽器授權、登出與手動輸入憑證；憑證儲存於本機系統憑證庫，不會隨工作區設定同步。
- 全新設計的排程頁面：新增專案與狀態篩選、排序、「設定」與「執行紀錄」檢視，以及批次清理已完成的排程訊息。
- 分類任務分頁：子 Agent 與背景任務現分別顯示於不同分頁，方便追蹤執行進度。
- 跨機器 Role 協作：從本機專案呼叫遠端 Role 時，可使用已連結至專案並連線至工作區的 GitHub 儲存庫；關聯對話在清單中會保持巢狀排列。
- iPhone Duo 支援：行動端版面配置現可隨可用螢幕空間自動調整，改進摺疊、展開與分割畫面體驗。
- 排程訊息：支援排程傳送訊息、附件與參照內容，並可進行編輯或取消；若目標機器處於離線狀態，訊息會在機器恢復連線後於有效期間內補發。
- Claude 額度重設後繼續執行：一鍵排程於額度重設後自動傳送 `continue`，讓任務得以順利完成。
- DeepSeek Harness 外掛程式管理：透過本機 CLI 管理供應商外掛程式，同時保留現有的使用者設定。
- 用量重設時間：支援在相對時間（「於⋯⋯後重設」）與本機時區的絕對日期時間之間切換顯示。
- 更大容量的遠端檔案下載：付費工作區支援下載最大 100 MiB 的檔案；託管檔案所在機器上的 CLI 也必須同步更新。

### 🐛 修復與改進

- 修復對話內容更新時偶爾錯誤覆寫現有文字的問題。
- 改進跨儲存庫 PR 連結與狀態同步，使狀態更新不再影響現有的 PR 連結。
- 修復短暫重新連線期間側邊欄中機器線上狀態閃爍的問題。
- 修復新增一般環境變數後部分供應商訂閱用量資訊消失的問題。
- DeepSeek 對話完成後現會自動摺疊過程輸出，讓最終回覆更易於閱讀。
- 改進行動端訊息佇列操作按鈕、記憶清單中的 Role 標籤對齊，以及桌面端登入頁面的圖示顯示。
- Agent 建立子對話時現會優先使用新對話，除非另有指定分頁對話。
- 改進桌面端登入恢復機制，避免啟動時因網路回應較慢而意外登出。
- 修復同步順序改變時訊息佇列偶爾無法繼續傳送，以及異常結束的任務仍顯示為執行中的問題。
- 建立新對話不再等待遠端 MCP 預設值同步完成；批次建立對話時會保留所選取的 MCP。
- 修復背景任務於執行中消失，以及 Claude 任務完成後執行者資訊遺失的問題。
- Kimi 現會在請求計畫核准前顯示完整計畫內容。
- 修復在 Pi 中切換模型後思考強度選項與模型能力不相符的問題。
- 更新 Codex 執行環境，改進 Skill 清單重新整理、上下文壓縮完成偵測，以及切換供應商後的錯誤訊息。
- 修復子模組簽出不完整時多儲存庫專案無法啟動的問題，並改進資料夾路徑顯示與側邊欄封存及摺疊行為。
- 修復 PR 衝突解決操作未在目前對話中開啟，以及行動端重新命名錯誤影響其他對話的問題。
- 修復健康的 Nowledge Mem 連線被誤報為失敗的問題。
- 改進行動端機器管理按鈕的返回手勢衝突，以及終端機分頁、登入文字與首頁狀態顯示。
- 當 Claude 達到額度上限時，可直接從提示卡片排程於重設後傳送 `continue` 訊息；排程時間與介面顯示保持一致。
- 當排程傳送無法使用時，將游標懸停即可查看具體原因。
- 改進在行動端傳送第一條訊息時介面與鍵盤之間的銜接體驗；新對話會自動恢復上次使用的專案。
- 行動端訊息佇列現採用精簡的單行版面配置。
- 改進安裝多個 Lody 版本時的連結開啟行為，將對話、新對話與供應商匯入連結交由執行中的版本處理。
- 改進 Agent 提示卡片與推理內容的對齊、配色及行內程式碼樣式，減少視覺干擾。
- 排程訊息管理更便利：傳送按鈕旁會顯示排程時間，排程訊息統一彙整於訊息佇列中，且可直接變更時間、編輯內容或取消。
- 改進訊息佇列版面配置：在手機與窄視窗下採用精簡單行顯示，操作選項收合至「更多」選單；已完成的一次性排程訊息紀錄將保留七天後自動清理。
- 修復新手引導期間輸入框提示詞建議的相容性問題。
- 修復停止執行中任務後立即傳送的訊息一併被取消的問題；當停止任務失敗時，對話中現會顯示失敗原因。
- 當同一台機器上的 Agent 透過 MCP 向執行中的對話傳送訊息時，現可直接引導進行中的任務。
- 移除排程任務額外的執行槽位限制，減少任務彼此等待的情況。
- 新建立的專案會自動選取，且可直接從專案選擇器編輯專案群組。
- 準備專案子模組時現會重複使用本機 Git 資料，減少重複下載。
- 修復應用程式預覽中的 Cookie 傳遞問題，改進需登入頁面的預覽體驗。
- 修復瀏覽器登入頁面錯誤，以及無效邀請連結的錯誤處理。
- 修復行動端提及選單無法捲動，以及中文環境下訊息佇列時間格式不正確的問題。
- 改進提示詞建議的換行與游標顯示，並在使用輸入法組字時暫時隱藏建議。
- 修復 WebKit 中閱讀時捲動位置跳動的問題，並提升分享圖片的清晰度。
- 改進檔案連結偵測與路徑複製，減少相對路徑造成的錯誤跳轉。
- 清理已刪除對話的專用工作目錄；封存操作現僅會移除空目錄並保留現有檔案。
- 修復短暫網路延遲導致線上機器被標記為離線並拒絕對話操作的問題。
- 改進排程任務載入失敗時的恢復機制，保留本機編輯內容並支援手動重試。
- 修復部分模型的思考強度選項與模型清單不相符，以及 Pi 啟動時模型與思考強度設定套用順序錯誤的問題。
- 改進 DeepSeek Harness 啟動相容性，當缺少受支援的 Node.js 時提供明確的安裝提示。
- 修復桌面端視窗拖曳區域上的通知按鈕無法點擊的問題。
- 新增對 macOS Emacs 風格快捷鍵的支援，可在輸入框中的檔案參照前後移動游標。
