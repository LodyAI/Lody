### ✨ 新功能

- 支援編輯並重新傳送最後一則使用者訊息。
- 行動端新增檔案上傳進度顯示。
- 按下 ⌘W 可關閉工作階段分頁或右側邊欄中目前開啟的檢視畫面。

### 🐛 修正與改進

- 縮短工作階段的啟動時間。
- 連線失敗時，Codex 的網路警告訊息不再顯示於對話內容中。
- 修正 Agent 在記憶體不足後可能反覆重新啟動的問題。
- 修正 CLI `--auth` 選項無法正常運作的問題。
- 修正本機專案分支偶爾無法正確偵測的問題。
- 改善本機至雲端的同步機制，修正其他裝置可能無法收到最新訊息的問題。
