### ✨ 新功能

- 遠端網頁預覽支援預先載入，讓 Browser 面板開啟更迅速。

### 🐛 修正與改進

- 修正網路同步阻塞訊息發送的問題，改善不穩定連線環境下的發送與恢復體驗。
- 修正待發送訊息導致對話無法封存或刪除的問題。
- 更新內建 Claude，修正工具呼叫狀態、輸出與檔案變更資訊顯示不完整的問題。
- 加快桌面版的本機檔案預覽速度。
- 選取檔案變更時會聚焦至該檔案，變更清單亦會顯示目錄路徑，方便區分同名檔案。
- 為本機 worktree 選項新增 Git 狀態載入指示器。
- 改善並行更新時的資料同步穩定性。
