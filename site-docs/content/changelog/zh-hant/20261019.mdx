版本 0.107.0

### ✨ 新功能

- Agent 完成任務時發送原生結果通知，文案更貼近目前的工作內容。
- 提供單回合預估費用。
- 支援在多台機器上執行相同的 Agent Role；可透過 MCP / CLI 提議建立或更新 Role。
- 在對話中使用 Pele 繪製 Mermaid 圖表；Markdown 預覽可顯示內嵌圖片。
- 新增「Open with Delta」啟動入口；機器設定中顯示已連線的 Agent 圖示。
- 行動端「變更」導覽與桌面端對齊。
- 正式版與 Nightly 版均提供 Linux ARM64 安裝程式。
- 問題回報隨附用戶端診斷與環境資訊，方便進行問題排查。

### 🐛 修復與改進

- 提升工作階段與 Daemon 的可靠性：閒置資源回收不再誤刪 Agent 仍在執行的工作階段、暫時性啟動失敗可進行重試，且停止後仍可繼續對話。
- 多項同步引擎最佳化與修復。
- 無需執行中的 Daemon 即可預覽本機檔案；Codex 引用會顯示為檔案卡片，並恢復內建 Codex 歷史紀錄匯入功能。
- 提升 iOS 16.4+ 執行環境相容性；Windows 標題列按鈕不再遮擋懸浮層。
