版本 0.96.0

### ✨ 新功能

- 為桌面端的 Markdown 檔案連結新增右鍵選單，支援複製路徑、開啟檔案、選擇開啟應用程式，或在 Finder 中顯示。
- 新增桌面端開發者診斷面板，用於檢視執行環境與效能指標。

### 🐛 修正與改進

- 預設限制本機專案的工作階段預覽顯示數量，並提供顯示全部工作階段的選項。
- 發佈後自動隱藏分享請求卡片。
- 修正公開瀏覽器在重新導向、歷史紀錄導覽與同文件內跳轉時重複載入的問題。
- 從 Word、PowerPoint 及類似應用程式複製內容並貼上時保留文字內容。
- 僅在支援的機器上顯示 Pi 遷移選項。
- 在回覆完成前隱藏 Fork 操作。
- 修正部分 Agent 原生擴充模組在 macOS 上無法載入的問題。
- 改善本機 Loro 工作階段加入失敗後的復原與重試機制。
- 改善深色佈景主題下封存多選控制項的對比度。
- 當子工作階段的分頁被關閉後，從建立卡片開啟時能準確重新開啟該子工作階段。
- 在展開或收合已完成內容時維持目前的閱讀位置。
- 改善 Devin 子 Agent 在對話中的呈現方式。
- 後續訊息會繼承目標工作階段的模型與執行設定。
- 改善桌面端瀏覽器登入流程，避免重複回呼導致無效狀態。
- 更新內建隨附的 Agent 執行環境版本。
