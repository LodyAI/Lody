版本 0.100.0

### ✨ 新功能

- 新增對 Opus 5.5、GPT-6-Sol 與 GPT-6-Luna 的支援。
- 新增 Dimcode 作為內建 Agent，可直接在 Lody 中進行設定並建立工作階段。

### 🐛 修復與改進

- 升級內建 Claude Code、Codex、Grok、Kimi 與 Pi 執行環境，提升 Agent 可靠性與工作階段啟動表現。
- 改進桌面端視窗預熱與內容載入機制，減少開啟工作階段時出現空白畫面、錯誤頁面或短暫載入狀態的情況。
- 改進長對話的背景載入機制，避免內容閃爍、訊息錯位以及選取文字遺失。
- 改進側邊欄篩選器版面配置，並確保在任務清單為空時仍可使用篩選控制項。
- 修復從工作階段開啟另一個本地工作樹檔案時，可能指向錯誤檔案的問題。
- 防止 Windows 上的 DeepSeek Harness 子處理程序反覆開啟主控台視窗。
- Machine Flock 遠端同步失敗時會自動重試，並回報明確的失敗狀態。
- 確保 Code Collab 儲存文字檔案時保留可執行與私有 POSIX 檔案權限。
- 最佳化分享入口與工作階段標題列介面。
