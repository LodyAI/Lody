### ✨ 新功能

- 新增工作階段分岔（Fork）功能。點擊 Agent 回覆下方的 Fork 按鈕即可從該則回覆建立分支工作階段；Codex 與 Claude Code 亦支援從工作階段中的任意位置進行 Fork。
- 重新設計右側邊欄，並新增瀏覽器與 Side Chat 功能。
- 瀏覽器在本機工作階段中可開啟任何網址；在遠端工作階段中，則可存取執行該工作階段的機器連接埠。目前尚未支援由 Agent 操作瀏覽器。
- 動態建立的 Lody 工作階段現在可在對話過程中進行設定，包括選擇模型與推理強度。
- 為已封存的工作階段新增搜尋與排序功能。

### 🐛 修正與改進

- 將淺色模式更新為純白背景。
- 最佳化部分行動版介面。
- 修正行動裝置在傳送訊息後，鍵盤偶爾未自動收起的問題。
- 修正本機優先模式下工作階段可能同步失敗的問題。
- 修正新建工作階段流程中，專案清單無法捲動到底以顯示所有專案的問題。
- 降低 CLI 的 CPU 與記憶體使用量。
- 提升機器上線狀態的穩定性。
- 最佳化工作階段搜尋功能，現在僅搜尋訊息內容，不再包含工具呼叫及其結果。
