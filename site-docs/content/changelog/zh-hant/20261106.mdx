版本 0.110.1

### ✨ 新功能

- Lody MCP 現已提供隨需指令說明，Agent 可直接查詢用法與參數，無需在工具清單中重複列出詳細說明。

### 🐛 修正與改善

- 改善遠端程式碼差異的載入效能，減少重複傳輸並支援大型檔案的隨需載入；重新整理時會保留目前的閱讀位置與展開狀態。
- 修正連線狀態重新整理時，已選取的遠端機器會意外變更的問題，並改善離線狀態的顯示方式。
- 修正編輯專案時遺失所選機器的問題，並在桌面版隱藏空的專案群組。
- 改善對話引用功能：可在同一則回覆中連續選取多個段落，並保留連結、清單與程式碼等格式。
- 恢復已完成回覆末尾內容的收合功能。
- 修正重新命名對話群組後，側邊欄未即時更新的問題。
- 改善輸入框中的提及顯示效果，修正游標位於邊界時的色彩異常，以及傳送後殘留舊提及狀態的問題。
- 強化加密工作階段中佇列訊息的驗證機制，修正共用權限仍在載入時訊息遭誤擋的問題，並讓 CLI 配對與金鑰狀態提示更明確。
- 修正 Android 安裝套件可能缺少推播設定而導致無法接收通知的問題。
