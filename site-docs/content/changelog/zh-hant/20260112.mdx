### 檔案與差異檢視

- 現在可即時檢視工作區檔案列表
- 每次對話結束時，Lody 會彙整所有檔案變更與行數增減，並可點擊檢視差異。
  <img src="/_docs-assets/20260112-changelog.png" alt="" />

### GitHub 整合

- 建立 PR 時現在會優先使用使用者身分

### 推播通知

- 若在設定中啟用通知，對話結束時會發送通知
- 當 Agent 需要權限時會發送通知
- 在 Agent 首次回覆時，Lody 會詢問是否啟用推播通知
- 邀請成員加入團隊時會發送電子郵件

### 其他

- 代理支援：CLI 現已支援透過 HTTP 代理進行 WebSocket 連線
- 在 GitHub 整合中新增搜尋與篩選框
- 支援離線存取對話

## 修復

- 修復：Claude Code ACP 相容性問題，避免工作階段更新（Plan/Tool Calls）渲染或儲存異常
- 修復 GitHub 整合憑證過期的問題
- 修復切換語言後重新整理未生效的問題
- 修復多項 UI 問題
