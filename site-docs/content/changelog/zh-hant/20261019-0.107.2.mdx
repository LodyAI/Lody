版本 0.107.2

### 🐛 修復與改進

- 修復當 GitHub 與 Lody 電子郵件地址不同時個人 GitHub 授權失敗的問題，並改進授權完成後返回設定頁面的體驗。現有使用者需在 GitHub 設定中重新授權一次。
- 支援連結使用不同電子郵件地址的登入帳號，包含使用 Apple「隱藏我的電子郵件」的帳號。
- 修復 Claude 子 Agent 讀取圖片時導致工作階段資料過度膨脹，進而造成載入緩慢或同步失敗的問題。
- 改進 MCP 資源清單在啟動、重新連線及同步錯誤後的恢復機制，減少資源遺失及同步狀態停止更新的情況。
