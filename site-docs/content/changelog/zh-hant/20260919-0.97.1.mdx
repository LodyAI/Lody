版本 0.97.1

### 🐛 修復與改進

- 修復向內建 Claude 傳送引導訊息約 5 秒後，Agent 被強制停止的問題。
- 修復 Windows 上因系統認證存放區無法解密（例如機器在新帳戶下還原後）而導致桌面端登入失敗的問題：現在會自動復原，並在失敗時回報更明確的原因。
- 恢復內建 Devin 執行環境。
- 連續關閉多個分頁時，剩餘分頁會暫時維持寬度，讓下一個關閉按鈕保持在游標下方（與 Chromium 一致）。
- 關閉從未傳送過訊息的分頁時會直接刪除，不再留下隱藏的工作階段；關閉分頁不再顯示提示訊息，且僅剩單一分頁時不再顯示關閉按鈕。
- Agent 運作期間，對話中會顯示帶有流光效果的活動標籤及經過時間。
- 訊息 Operation 完成後，會顯示它送達了哪個 Session，並以「收到回覆」卡片呈現結果；可在對話框中開啟完整回覆。
- 可在對話框中檢視背景任務的完整指令。
- 工作區切換器頂部會顯示目前的工作區。
- 佇列中的訊息緊貼輸入框顯示，其中的圖片可在圖片檢視器中開啟。
- 編輯過的檔案若無行數統計，現在會顯示標記，不再顯示空白統計。
- 桌面端介面細節最佳化：macOS 頂部列與視窗控制按鈕對齊、淺色模式下的程式碼區塊對比度、懸停與設定介面層次、側邊欄專案群組版面配置、對話內搜尋列，以及多行程式碼字體大小與對話內文的協調一致。
