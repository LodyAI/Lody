版本 0.110.0

### ✨ 新功能

- 圖片標註：支援在圖片預覽中繪圖、新增文字與留下備註，並可將標註後的圖片作為附件傳送給 Agent。
- 對話自動繼續：可在符合指定條件時恢復執行任務，並支援依個別對話設定額度恢復後繼續、PR 合併後封存，以及閒置時壓縮上下文。
- Android 模擬器預覽：全新的預覽與控制面板，支援觸控操作、文字貼上、旋轉畫面、螢幕截圖、淺色與深色模式切換，以及畫質選項。
- Agent 登入方式：登入前即可查看 Agent 支援的登入方式。
- Pi 更新：內建 Pi 升級至 1.4.0，新增對 Streamable HTTP MCP 的支援。
- 並排預覽 iOS 與 Android：將一個裝置預覽分頁拖曳至另一個分頁上，即可同時檢視兩個螢幕畫面。拖曳分隔線可調整兩側寬度，連按兩下分隔線則可恢復預設分割比例。
- 引用對話文字：將選取的訊息節錄加入輸入框，以原文作為上下文進行追問。
- 堆疊 PR（Stacked PRs）：PR 面板可顯示在 GitHub 上記錄的堆疊順序、各個 PR 的狀態，以及目前 PR 在堆疊中的位置；側邊欄也會顯示關聯的 PR。
- 更彈性的排程任務：提示詞現已支援提及功能，且重複間隔可自訂為指定的分鐘數或小時數。
- 直接恢復已封存對話：輸入框新增恢復按鈕，可在保留草稿內容的同時還原對話。
- 跨機器 Agent 引導：可向另一台機器上執行中的對話傳送後續指令；若無法即時引導，指令將會排入佇列。
- Claude 現可依個別對話探索與 Anthropic 相容閘道器所提供的模型。
- Agent 佇列管理：Agent 可檢視目標對話中的待處理訊息，並撤回或替換自己先前傳送的佇列指令。
- 更完整的協作狀態：Agent 可查詢對話目前作用中的工具、上次輸出時間與佇列長度，以及機器的磁碟資訊與剩餘額度。
- 附帶來源歸屬的訊息參照：Agent 在轉發指令時可參照原始訊息，並包含其所記錄的作者資訊。
- 預設開放裝置配對：帳號層級的裝置配對不再需要啟用開發者模式或測試旗標。
- 批次對話封存：Agent 可透過單次 MCP 呼叫封存多個對話。
- 首頁雙額度週期顯示：同時檢視短期額度與每週額度的使用百分比及重設時間。
- 獨立的對話群組名稱：可分別重新命名側邊欄對話群組與個別分頁，彼此互不影響。
- 更明確的協作失敗資訊：MCP 現會回傳具體失敗原因、額度重設時間等詳細資訊；重試成功後也會清除先前的失敗狀態。

### 🐛 修復與改進

- Claude 額度耗盡提示現提供啟用對話自動恢復的選項；當額度恢復或到達重設時間後，Lody 會重新檢查並繼續執行。
- 排程訊息現會顯示完整內容、支援於目前對話內編輯，並以檢視者的本機時區顯示傳送時間。
- 修復對話在等待委派任務期間或訊息收件匣啟動失敗時，排程訊息傳送卡住的問題。
- 改進背景服務、訊息佇列與 MCP 清單在短暫連線失敗後的恢復機制，減少對話停滯的情況。
- 修復模型與思考強度等對話設定被先前輸入或草稿覆寫的問題。
- 改進 Pi 對話分支與斜線命令載入機制，避免命令清單在不同對話之間外洩。
- 修復 DeepSeek 歷史紀錄的圖片匯入、清單詳細資訊與啟動錯誤顯示。
- 新增對未宣告輸入能力之 Magpie 模型的相容性支援。
- 改進 iOS 對話中的捲動慣性、歷史紀錄頁面的按鈕點擊反應、側邊欄大小調整，以及桌面端頁面排版對齊。
- 改進預設字體選擇，在系統支援時優先使用 SF Pro Display。
- 修復訂閱資訊載入失敗導致整個工作區異常的問題，並改進主畫面小工具的快取恢復機制。
- 內建 Claude Code 升級至 2.1.316。
- 恢復先前的對話設定與訊息傳送行為，修復舊版背景服務無法傳送訊息的問題。移除先前關於「對話設定不再被先前輸入或草稿覆寫」的項目。
- 自動繼續控制項現會反映目標機器的實際支援能力，避免在舊版背景服務上出現無法使用的操作。
- 將 Android 預覽畫質選項移至「更多」選單中，以釋出更多工具列空間。
- 修復在驗證就緒前載入組織資訊所引發的錯誤。
- 改進多 Agent 協作：回應現會包含訊息傳送狀態與具體失敗原因、標示 Agent 訊息來源，並在引導後等待最終回覆而非僅回傳中間結果。
- MCP 現可接受無歧義的短對話 ID，並支援依角色、時間與方向讀取歷史紀錄，減少不必要的上下文載入。
- 降低讀取長對話歷史紀錄及執行內部 MCP 程序時的記憶體佔用，並改進串流輸出期間的歷史紀錄存取。
- 修復自動繼續佇列未及時喚醒的問題，並新增明確的「連線中」、「離線」與「無法使用」狀態。
- 修復歷史紀錄載入覆寫退出計畫模式後的狀態，以及資訊列與側邊欄之間 PR 狀態不同步的問題。
- 同一對話的多個分頁現會共用相同的模擬器綁定，減少重複選擇裝置的動作。
- 改進提問卡片標題與 Markdown 繪製效果，並新增對 Droid 提問表單的相容性。
- 修復標註圖片超過附件大小限制、PDF 面板縮放比例調整，以及 WebKit 中分享卡片版面配置的問題。
- PR 圖片現改為按需載入。修復側邊欄分頁捲軸無法拖曳，以及訊息編輯器與佇列中的文字對齊問題。
- 當額度耗盡且已知重設時間時，排程任務現會延後執行，避免反覆失敗或在額度恢復時瞬間湧入大量執行。
- 對話結束時僅會摺疊推理與工具活動；所有回覆正文仍保持可見。展開後的活動將依原始順序顯示。
- 傳送訊息後會隱藏已使用的提示詞建議，避免舊建議再次出現。
- 修復手機上鍵盤遮擋登入欄位，以及部分頁面狀態列遮擋返回按鈕的問題。
- 修復專案紀錄沒有路徑時資料夾瀏覽器無法開啟的問題。
- 修復 CLI 快照上傳可能無限期等待的問題，並改進初始化失敗後的重試機制。
- 統一輸入框、傳送按鈕與附件標籤的字體粗細。
- 側邊欄 PR 顯示調整：恢復原有的單一 PR 狀態圖示。移除先前關於「側邊欄顯示關聯 PR」的項目；堆疊 PR 仍可在 PR 面板中使用。
- 首頁卡片現會依任務狀態重新排序；即使卡片載入失敗，新對話輸入框仍可正常使用。
- 修復釘選對話遺失關聯階層結構，以及 PR 顯示為可合併時側邊欄圖示位移的問題。
- 改進與 Agent 登入方式及驗證進度回饋的相容性，並補齊自訂 ACP Agent 缺少的用量追蹤。
- 修復短暫同步失敗期間健康機器被誤標記為離線的問題。
- 跳過忽略目錄與快取以最佳化大型專案的檔案索引效能，減少 CLI 卡頓及檔案被誤標為已刪除的情況。
- 修復未記錄比較基準時的 Git 差異計算，改為使用遠端的預設分支。
- 行動端現可直接開啟瀏覽器預覽，無需手動輸入網址；修復 iOS 模擬器外框內緣的主題色彩不一致問題。
- 更新回覆摺疊規則：由 Agent 明確標記的進度更新現會與其他活動一同摺疊，最終回覆則保持可見。此規則取代先前「所有回覆正文保持可見」的說明。
