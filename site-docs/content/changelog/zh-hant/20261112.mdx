版本 0.112.0

### ✨ 新功能

- **一次更新多台電腦**：可在「設定」中批次更新符合條件的電腦，檢視各台電腦的版本與更新進度，並選擇在閒置時更新或立即更新。
- **Antigravity 訂閱配額**：可檢視每週與五小時配額區間的使用量及重設時間。

### 🐛 修正與改善

- **更流暢的訊息編輯體驗**：修正長訊息換行或出現捲軸時，游標位置、文字選取範圍及中文輸入法選字框錯位的問題。
- **更精確的「我的任務」篩選**：僅顯示指派給您的任務，排除其他成員在您電腦上執行的任務。
- **更明確的傳送錯誤提示**：當佇列訊息的附件準備失敗時，會顯示失敗原因與建議後續操作；點擊「繼續傳送」重試時亦會顯示載入狀態。
- 修正攜帶仍在準備中的附件開始對話時，錯誤顯示「對話建立失敗」或「機器無法使用」的問題。
- 重新命名側邊欄或第一個對話分頁時，兩者的名稱會自動保持同步。
- 平板等寬螢幕觸控裝置上的網頁版現已支援拖曳調整側邊欄寬度，並會記住設定的寬度。
- 修正桌面瀏覽器視窗較窄時，側邊欄遮罩層可能殘留並導致無法操作頁面的問題。
- 精簡 Agent 動作提示詞，減少委派結果回傳後不必要的重複審查與額外操作。
