版本 0.87.0

### ✨ 新功能

- 新增自訂對話字體大小，讓聊天內容、Markdown 與終端機顯示更符合您的閱讀偏好。
- HTML 附件現可直接開啟即時預覽；連線至 Agent 回報的遠端連接埠前，Lody 會先請求確認。

### 🐛 修正與改進

- 修正透過提及 Role 啟動對話時可能失敗的問題。
- 改進佇列訊息編輯：可按 Enter 或使用確認按鈕送出、按 Shift+Enter 換行，並避免在使用輸入法組字時誤送出。
- 選取 Agent Role 後移除多餘的權限按鈕，減少設定衝突與介面干擾。
- 修正 HTML 附件路徑在 Windows 上無法正確開啟的問題。
- 修正佇列訊息編輯器周圍出現重複邊框的問題。
- 最佳化工作階段與檔案變更資料的載入及快取機制，減少重複掃描與資源佔用。
