版本 0.111.1

### ✨ 新功能

- **唯讀對話分享**：可將單一對話分享給團隊或特定成員檢視，無需開放整台電腦的存取權限。
- **排程任務擁有者與篩選**：任務清單現已顯示每項任務的擁有者，並可依「我的」、「其他人的」或「全部」進行篩選，更輕鬆尋找團隊任務。

### 🐛 修正與改善

- 修正部分訊息處理失敗時，可能導致對話中後續訊息無法正常顯示的問題。
- 修正部分本機圖片在桌面應用程式中無法正常載入的問題。
