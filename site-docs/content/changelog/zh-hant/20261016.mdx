版本 0.106.0

### ✨ 新功能

- 回合彈出氣泡可顯示耗時與活躍狀態。
- 選取數學公式後可複製為 LaTeX。
- 新增行動端訂閱額度小工具。

### 🐛 修復與改進

- 工作階段資源未釋放時自動重試，減少整個回合失敗的情況。
- 為 GitHub 憑證取得設定更合理的逾時時限，降低間歇性失敗。
- 短暫的存取失敗不再導致 Session 排程卡住。
- 相容於缺少訊息階段中繼資料的 Codex 標題。
- 讓權限選項更精簡且易於閱讀。
- 在確認前固定 Roost 訊息位置，避免畫面跳動。
- 支援使用半形日圓符號觸發 Skill。
- 恢復開放原始碼聲明對話框的捲動功能。
- 修復更新日誌清單項目標記樣式。
