### 新增功能

- 新增更多 ACP Agent，例如 Grok Build，以及 MiniMax 預設配置。
- 發生歷史紀錄衝突時，現在可以重新匯入並以 ACP 側的歷史紀錄為優先。
- 對話中現在會顯示正確的模型名稱與思考等級。
- feedback.lody.ai 現已支援電子郵件登入。

### 修復與改進

- 修復 codex 與 Claude Code 初次啟動時因過時的 npx 快取導致失敗的問題。
- 減少行動端斷線後重新連線時的卡頓感。
- 本地專案分支資訊不再過於頻繁地重新整理。
- 修復行動端使用者訊息超出螢幕範圍的問題。
- 改進 GitHub 專案頭像快取機制。
- 改進行動端返回手勢的觸發體驗。
- 修復行動端返回導覽動畫異常的問題。
- 修復行動端已封存對話的還原與永久刪除功能。
- 改進主題選擇器的互動體驗。
