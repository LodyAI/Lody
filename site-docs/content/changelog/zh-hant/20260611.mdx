### 新增功能

- **iOS 即時動態與動態島**：無須開啟 Lody，即可在 iPhone 鎖定畫面與動態島追蹤 Agent 進度。當 Agent 需要核准權限時，Lody 也能傳送可直接操作的即時動態通知。

  <img src="/_docs-assets/20260611-island.png" alt="Lody 動態島即時動態" />

- **Worktree 初始化與清理腳本**：可設定專案層級腳本，於建立 Worktree 後且 Agent 啟動前執行初始化，並在工作階段封存且移除 Worktree 時執行清理腳本。
- **行動端專案檔案瀏覽**：無須先啟動工作階段，即可在行動端專案檢視頁面中直接瀏覽本地與 GitHub 專案目錄並開啟檔案。
- **即時專案檔案編輯**：在本地或遠端工作階段中，與團隊成員即時協作編輯目前工作目錄內的文字檔案。行動端編輯功能即將推出。
- **檔案檢視器的 Markdown 預覽與搜尋**：Markdown 檔案現可一鍵切換原始碼與渲染預覽，文字檔案亦可開啟檢視內搜尋控制列。
- **更穩定的 Turn Diff 與 All Changes**：Diff 載入更加穩定，遠端裝置現在也能更一致地檢視檔案與 Diff。
- **自訂 ACP Agent**：只要輸入啟動指令與參數，即可新增任何相容 ACP 的 Agent。

### 體驗改進

- 為 Proposed Plan 卡片新增複製按鈕，僅包含方案的回覆亦可在訊息底部一鍵複製。
- 本地專案選擇器改為以機器優先，並提升了穩定性。
- 新建對話中的專案清單改為依近期活躍度排序。
- 預覽功能現已為分享連結新增複製按鈕。
- 超長的使用者訊息不再溢出或遭對話氣泡裁切。
- 切換展開／收合時，右側邊欄的收合按鈕不再左右跳動。
- 連線不穩時，共享的機器與專案能更可靠地保留。
- 修復機器離線時，建立對話畫面會反覆移動的問題。

### 移除功能

- Lody 不再提供 PWA 支援。
