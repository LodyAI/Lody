版本 0.77.2

### ✨ 新功能

- 支援在輸入框貼上檔案，以及透過拖放方式上傳檔案。
- 對話中的圖片與獨立圖片檔案現在皆可開啟、縮放與平移；在桌面版中，亦可透過右鍵選單複製或另存圖片。
- 當 Agent 驗證過期時，現在可直接於 Lody 內重新驗證，無須重新建立工作階段。
- Agent 錯誤訊息現在可展開檢視完整詳細內容，並支援一鍵複製診斷資訊；行動端亦可完整檢視錯誤詳情。
- 改善工作區邀請、加入審核與私人資源分享流程，當沒有可分享的機器或專案時會提供更明確的提示訊息。
- 匯入本機專案後，Lody 現在會自動開啟該專案。
- 行動版網頁現在可以存取帳單設定。

### 🐛 修正與改進

- 大幅減少捲動檔案樹或切換工作階段時的主執行緒工作量，讓大型專案瀏覽、切換工作階段及重新開啟右側邊欄更加流暢。
- 降低背景同步、資料持久化與重新連線所造成的 CPU 與記憶體壓力；網路不穩或單一同步房間發生異常時，不再觸發整個工作區的高頻率重連風暴。
- 修正本機工作階段閒置後偶發同步失敗、Agent 回覆延遲，以及還原工作階段時遺失分支的問題。
- 修正傳送給執行中 Agent 的引導訊息在失敗後可能卡住的問題；若訊息無法立即插入，現在會自動排入下一個一般回合。
- 修正多工作區環境中 Git 操作可能誤用錯誤帳號憑證的問題，以及舊版工作階段在本機與遠端分支同名時無法還原的問題。
- 行動端的 Plan Mode 切換開關現已恢復正常運作。
- 修正訊息複製按鈕無反應的問題。
- 手機在橫向模式下現在會繼續使用行動版版面配置，且網頁應用程式不再於未經使用者互動的情況下自動嘗試開啟原生應用程式。
- 修正行動端側邊抽屜中下拉式選單的錯誤、統計數據被裁切、Agent 名稱遭截斷，以及過長的專案路徑超出對話框邊界等問題。
- 應用程式當機頁面現在會顯示可讀的錯誤訊息並允許使用者複製報告；若反覆復原失敗，使用者可在確認後清除本機資料並重新登入。
