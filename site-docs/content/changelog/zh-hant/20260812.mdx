版本 0.78.0

### ✨ 新功能

- 新增支援官方 Grok 執行階段（Runtime），包含在 Lody 中進行互動與權限控制，以及檢視上下文用量與速率限制。
- 全新的兩層式 `@` 選單將檔案、Issue、Pull Request、Skill、工作階段與指令整合於同一處，並支援直接參照其他工作階段。

### 🐛 修正與改進

- 改進 macOS 與 Linux 上的記憶體壓力檢查機制，減少系統仍有可用資源時卻誤判並阻擋工作階段啟動的情況。
- 恢復 Electron 桌面應用程式中的縮小快捷鍵。
- Pull Request 描述現在可展開檢視，且 Agent 回覆的對齊方式更加一致。
- 修正包含中文在內的多位元組文字在跨越本機連線資料區塊時可能發生亂碼的問題。
- 修正透過 npm 或 npx 安裝 Lody CLI 時，因相依套件版本未正確解析而失敗的問題。
- 最佳化官網首頁的載入速度、資源檔案大小與無障礙體驗。
