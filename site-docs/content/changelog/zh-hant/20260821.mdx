版本 0.84.0

### ✨ 新功能

- 新增桌面版對話輪次導覽，方便在長工作階段中快速瀏覽並跳轉不同輪次。
- 新增 Google Antigravity 支援，並更新多款 ACP 程式設計 Agent。

### 🐛 修正與改進

- 改進 Codex 歷史紀錄匯入，避免在檢視歷史紀錄時意外恢復舊對話串。
- 修正 Kimi 與其他 ACP Agent 在 Windows 上執行命令與工具時的路徑及參數處理問題。
- 改善窄視窗下的偏好設定版面配置、首次執行狀態指示，以及 macOS Dock 圖示顯示。
- 修正網站淺色模式的畫面顯示，以及部分瀏覽器中的啟動失敗問題。
