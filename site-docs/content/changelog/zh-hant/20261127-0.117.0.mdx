版本 0.117.0

- 新增繁體中文、日語、韓語、西班牙語、法語與俄語 6 種介面語言。
- 支援跨工作階段記憶權限授權並提供可同步的預設權限設定；側邊欄任務支援依團隊成員篩選、團隊成員新增選單顯示頭像，以及捲動時固定展開的工作群組摘要標題。
- 桌面端 Today 視窗現在會記住視窗尺寸與位置，並支援全域切換快捷鍵。
- 行動端支援將對話分享為圖片、從 Markdown 表格、程式碼區塊與聊天卡片引用，以及將目前目錄的新分頁以本地草稿開啟；並修復 iOS 選單閃爍、前景恢復與 Share Extension 輸入行為。
- 隱私設定支援即時退出遙測並整合使用狀況共享開關，同時加入分區 Cookie 通知。
- 修復電子郵件登入在切換畫面時搶走焦點的問題，並避免已驗證的電子郵件登入自動跳轉回驗證頁。
- 全面強化加密工作區建立、裝置配對、金鑰恢復與成員金鑰傳遞流程，提供更清楚的引導與錯誤訊息。
- 將 Loro 升級至 1.19.1 並改善守護行程與渲染行程的記憶體預算；新增用於持久化守護行程 Streams 房間的工作區 WebSocket 傳輸、CLI `restore-id` 指令，以及委派鏈上限提示。
