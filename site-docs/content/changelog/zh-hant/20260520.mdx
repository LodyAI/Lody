### 新功能

- 新增對 Codex Plan Mode 流程的支援。

### 修正與改進

- 提升對話中串流 Markdown 的渲染效能。
- 修正原生行動應用程式在首次成功登入後出現白畫面的問題。
- 新手引導流程現可略過 Agent 連線步驟，稍後再於「設定」中進行設定。
- 修正重新整理 Claude 設定時失敗的問題。
- 修正 Android 上的字型渲染異常問題。
- 修正已授權個人 GitHub 權限後，部分操作仍使用錯誤身分的問題。
- 修正過時的 PR 頁面未能自動重新整理的問題。
- 調高長篇貼上文字自動摺疊為精簡預覽的字數門檻。
- 修正載入本機專案分支資訊時發生逾時的問題，並新增手動重新整理入口。
