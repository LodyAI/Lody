### 新增功能

- 新增本地程式碼審查工具 `lody review`，無須登入即可檢視審查報告。
- 工作階段現已支援任意類型的檔案附件並提供預覽功能，Agent 亦可讀取附件並回傳檔案。
- 新增命令面板（⌘K），可用於搜尋指令及快速切換工作階段。
- 新增鍵盤快捷鍵設定頁，每個快捷鍵皆可自訂或重新綁定，並支援衝突偵測。
- 新增桌面端快速工作階段視窗（⌘⇧N），支援全鍵盤操作。
- 桌面端終端機現會跟隨應用程式主題，並採用 VS Code 風格的底部狀態列。
- 工作階段的「開啟方式」選單現已支援 Xcode、Sublime Text 及自訂啟動器。
- 在輸入框中使用 `$` 即可提及專案 Skill，並可從全新的 Skills 頁面瀏覽可用 Skills。
- 現在可從其他裝置刪除本地專案。
- 新增對話字體大小設定。
- 新增 DeepSeek Reasonix Provider。
- 桌面端使用者可停用自動啟動 CLI，將 Lody 純粹作為遠端控制端使用。

### 修復與改進

- 提升 All Changes 清單的效能。
- Pull Request 現會顯示「草稿」狀態徽章。
- 圖片上傳現可在整個對話介面中正常運作。
- 為 Worktree 腳本新增快取，避免等待載入。
- 修復回覆 AI 提問時，行動端鍵盤遮擋回應介面的問題。
- 改進行動端過長模型名稱的顯示效果。
- 減少串流輸出時的卡頓與裝置發熱情況。
- 修復 macOS 全螢幕模式下按下 Cmd+W 後出現黑畫面的問題。
- 修復側邊欄選取外框遭到裁切以及時間戳記前出現多餘空白的問題。
- 將 macOS 上的工作階段搜尋快捷鍵變更為 ⌘F。
- 行動端模型選擇器中的長模型名稱更易閱讀，且選單不再被鍵盤遮擋。
- 手動停止任務後不再錯誤觸發「已完成」通知。
