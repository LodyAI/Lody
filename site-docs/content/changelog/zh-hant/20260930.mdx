版本 0.103.0

### ✨ 新功能

- 支援 Codex GPT-6.1-Sol 模型。
- 可直接在工作階段中預覽 Word（DOCX）、Excel（XLSX）與 PowerPoint（PPTX）文件。
- 新增 CSV 與 TSV 表格預覽，支援儲存格搜尋與縮放，同時保留原始碼編輯功能。
- PDF 預覽新增縮圖導覽、旋轉與更多縮放選項，並改善文件內搜尋體驗。

### 🐛 修正與改進

- 修正切換模型或套用角色後，推理強度與 Fast 選項顯示或套用不正確的問題。
- 修正切換工作階段分頁時可能發生的訊息區域當機問題，並改善閱讀位置恢復體驗。
- 改善輸入框 @ 選單定位，使其跟隨輸入游標並依可用空間自動調整。
- 改善 GitHub 授權過期或遭撤銷時的提示訊息，並修正部分 Git 提交作者身分不正確的問題。
- 更新內建 Codex 執行階段，並為新模型補充用量費用估算。
- 修正官網部分頁面的導覽與連結目標問題。
