版本 0.86.2

### ✨ 新功能

- 新增 Agent Roles，可用於儲存與分享常用的 Agent、模型、權限及其他執行設定，並在新建或現有工作階段中快速選取或透過提及呼叫。
- 模型清單新增模糊搜尋，並將檔案與圖片附件整合為更清晰的統一選擇器。
- 新增獨立 HTML 檔案預覽，以及 Markdown 訊息的完整複製操作。
- 新增 Codex 用量重設預測。
- 新增內建 Agent 執行階段的背景更新功能。

### 🐛 修正與改進

- 提升工作階段建立、還原與任務派送的穩定性，避免本機直接工作階段意外建立分支，並自動處理新 worktree 的分支名稱衝突。
- 修正任務內文在儲存確認前可能消失的問題，並讓封存父工作階段時一併封存其子工作階段。
- 改善 Electron 本機檔案瀏覽與預覽體驗，同時確保本機檔案僅在裝置上讀取。
- 修正調整輸入框大小時聊天內容發生位移的問題。
- 改進 Claude 與 Grok 模型備援機制、舊版執行階段快取相容性以及用量圖表標籤。
- 修正 Linux 桌面圖示關聯，並提升網頁版與行動版表情符號選擇器的離線可用性。
