### 🧠 支援 Claude Opus 4.7

### 👥 更安全的團隊協作

- 新增團隊機器可見性控制：您的機器對其他成員**預設完全私人**——加入他人的 Workspace 時，不再需要擔心自己的開發機器會被公開或使用
- 您可在 Settings 中明確將特定機器共享給團隊；未共享的機器絕不會出現在其他成員的機器清單中，該機器上的對話也不會出現在其他成員的側邊欄
- 將「加入他人的 Workspace」與「使用自己的機器」徹底解耦——邀請隊友協作時不再有任何顧慮

### 🔐 一行指令登入任意機器

- 新增非互動式 CLI 驗證：在任意機器上執行 `lody login --auth <api-key>` 即可完成連線，或使用 `lody start --auth <api-key>` 一步完成登入與啟動
- Electron 桌面版新增帳號設定面板，可一鍵產生並複製 CLI API key

### 🆕 Full Access 模式

- 新增 Lody Full Access 模式，為沒有原生 Full Access 模式的 Agent（如 Kimi、OpenCode）自動核准權限請求

### 🤖 更多 Agent 整合

- 提供對 OpenCode 與 Kimi 更完善的整合支援
- 修正 Kimi 終端機、檔案讀取與編輯通知在歷史紀錄中的解析與顯示問題

### 📱 行動裝置體驗

- 重構軟鍵盤處理機制：鍵盤彈出時不再將整個介面往上推移，僅輸入區域平滑上浮
- 行動裝置鍵盤在聊天輸入框上顯示「Send」按鍵，點擊即可直接送出訊息
- 修正 iOS Safari 裁切底部控制項、Toast 安全區域以及邀請頁面安全區域的問題

### 🚀 效能與啟動

- 消除既有使用者啟動時的白屏問題，介面不再遭到網路查詢阻塞
- 長對話搜尋索引改為延遲載入 + 增量更新，對話結束時不再出現卡頓
- 同步服務新增快取機制，降低冷啟動開銷

### 🌐 瀏覽器相容性

- 擴大支援範圍至 Safari 14+ / Chrome 80+ / Firefox 78+；舊版瀏覽器不再因正規表示式或 ESM 載入失敗而出現白屏

### 🛠️ 其他修正

- 修正 Docker 容器重複使用主機機器 ID 導致事件串流衝突的問題
- 建立 worktree 時現在會重複使用已選取的非預設分支
- 桌面版改為在外部瀏覽器中開啟 GitHub 安裝連結
- 修正 Electron 重新登入時出現工作區 404 的問題
- 工作階段側邊欄切換按鈕已與頁首對齊
- 最佳化各個 VS Code 主題下 Switch 切換開關的對比度
