版本 0.116.0

### ✨ 新功能

- 可直接在原生用戶端編輯排程提案，並在網頁應用程式中檢視系統通知。
- 可將 Today 提及拖曳至對話中，並在生成式介面中呈現更多安全受限的 SVG 圖表。

### 🛠️ 改進

- 輸入框附件改用更清晰精簡的卡片設計，並提供上傳進度、重試與移除操作。
- 長期使用的工作區會自動回收未使用的 SQLite 儲存空間。
- 支援透過 WebSocket 附加資料，進一步改善 Streams 即時更新體驗。

### 🐛 問題修復

- 修復打包後的 macOS 版本中內建 JavaScript ACP Agent 無法啟動的問題。
- 修復附件回填、分享請求、側邊欄與 Markdown 任務列表的邊界情況問題。
