# サポート

Lody についてお困りですか？サポートチームがお手伝いいたします。下記のいずれかの窓口からお問い合わせいただけます。お問い合わせにあたり、アプリをインストールしている必要はありません。

## お問い合わせ

- **メール:** [contact@lody.ai](mailto:contact@lody.ai?subject=Lody%20Support) — サポートに関するご質問、バグの報告、アカウントに関するお問い合わせを受け付けています。通常、数営業日以内にできる限り迅速にご返信いたします。
- **Discord:** [コミュニティに参加する](https://discord.gg/E8mZtMu38s) — 質問をしたり、チームや他のユーザーからサポートを受けたりできます。
- **X (Twitter):** [@lody_ai](https://x.com/lody_ai) — 製品のアップデートやお知らせを配信しています。

## 問題の報告

バグや問題を報告される際は、以下の情報をご記入ください：

- 実際に起きた事象と、本来期待していた動作の説明
- ご利用のプラットフォーム（Web、デスクトップ、iOS、または Android）
- 問題の再現手順（わかっている場合）

これらの情報をお知らせいただくことで、調査と対応をより迅速に行うことができます。
