# プライバシーポリシー

最終更新日: 2026年11月25日

本プライバシーポリシーは、お客様が当社のウェブサイト、Web アプリ、デスクトップアプリ、モバイルアプリ、および CLI を含む本サービスを利用される際に、LoroHub LLC（以下「Lody」または「当社」といいます）が情報をどのように収集、利用、保存、および保護するかについて説明するものです。

## 1. データ管理者および連絡先

- 会社名: LoroHub LLC
- メールアドレス: contact@lody.ai

## 2. 当社が収集する情報

現在の製品の動作に基づき、当社は以下のカテゴリのデータを収集します。

### 2.1 アカウントおよび認証データ

- GitHub OAuth またはメール認証を通じて提供されるアカウント識別子、基本プロフィール情報、およびメールアドレス
- 請求およびサブスクリプション状況に関するメタデータ（決済カードの詳細は Stripe によって直接処理され、Lody 側では保存されません）

### 2.2 デバイス、分析、および技術データ

- 「設定」→「このアプリについて」で使用状況の共有をオフにしない限り、クラウドクライアントは最小限の製品利用回数（サインアップ数、メッセージ送信数、おおまかなプラットフォーム／OS、組み込みエージェントプロバイダーのカテゴリなど）およびマスク処理されたエラーカテゴリを収集します。会話内容、リポジトリパス、URL、ページタイトル、カスタムエージェント名、および生のエラースタックは製品分析から除外されます。ローカルのオープンソースビルドでは、製品分析は完全に無効化されています。
- 製品分析では、保存前に生のクライアント IP アドレスを破棄したうえで、国レベルのおおまかな地域を判定します。
- 当社の公開ウェブサイトでは、欧州経済領域（EEA）、英国、およびスイスにおいて、Cookie 同意バナーで同意いただくまで、任意の分析 Cookie はデフォルトで無効になっています。その他の地域の訪問者は、ウェブサイトフッターの **Cookie 設定** からいつでも任意の分析 Cookie を無効にできます。

### 2.3 サービスログ

- 本サービスの運用、デバッグ、およびセキュリティ確保に必要な運用ログおよびセキュリティログ

### 2.4 ユーザーコンテンツ

- 本サービスを通じてお客様が送信する会話内容および関連するワークフローコンテキスト（エンドツーエンド暗号化が有効なワークスペースでは、会話内容はお客様のデバイス上で暗号化されたまま保持されます）

## 3. 処理の法的根拠（GDPR）

EU／英国の一般データ保護規則（GDPR）が適用される場合、当社は以下の法的根拠に基づいて個人データを処理します。

- **契約の履行（第6条第1項(b)）**: アカウントの認証、コアとなるワークスペースおよびコラボレーション機能の提供、ならびに有料サブスクリプションの管理
- **同意（第6条第1項(a)）**: EEA、英国、およびスイスにおける任意のウェブサイト分析 Cookie。同意はいつでも撤回でき、撤回前の適法な処理には影響しません
- **正当な利益（第6条第1項(f)）**: 本サービスのセキュリティ確保、不正利用の防止、運用上の障害の診断、ならびに Cookie を使用しない最小限の製品利用回数およびマスク処理されたエラーカテゴリの収集（統合アカウントスイッチからいつでもオフにできます）
- **法的義務（第6条第1項(c)）**: 法令により求められる税務、会計、およびコンプライアンス上の義務

## 4. Cookie およびローカルストレージ

- **必須の Cookie およびストレージ**: サインインセッション、テーマ／言語設定、およびアプリの基本状態の維持に必要です。
- **ウェブサイト分析 Cookie（任意）**: EEA、英国、およびスイスでは、Cookie 同意バナーで同意いただくまでデフォルトで無効になっています（広告および広告パーソナライズ用ストレージはすべての地域で常に無効です）。すべての地域の訪問者は、ウェブサイトフッターの **Cookie 設定** からいつでも任意の分析 Cookie を変更または無効にできます。
- **製品分析ストレージ**: Lody アプリは製品分析用の Cookie を設定せず、使用状況の共有をオフにするとローカルの分析状態を直ちに消去します。

## 5. 第三者サービスおよび処理

当社は、本サービスの一部を運用するために信頼できるサービスプロバイダー（サブプロセッサー）を利用しています。

- Cloudflare Pages および Cloudflare R2（ホスティングおよびストレージ）
- Convex（バックエンドインフラストラクチャ）
- GitHub（サードパーティログインおよびリポジトリ連携）
- Stripe（サブスクリプション請求および決済処理）
- Google Analytics（任意の公開ウェブサイト分析）
- PostHog（最小限の製品分析およびマスク処理されたエラー報告。「設定」→「このアプリについて」から設定可能）

これらのプロバイダーは、それぞれの利用規約、プライバシーポリシー、および該当するデータ処理契約（DPA）に基づいてデータを処理します。

## 6. 国境を越えたデータ移転

当社のクラウドインフラストラクチャおよびサービスプロバイダー（PostHog、Convex、Cloudflare、Stripe、Google を含みます）は、米国または各社が事業を展開するその他の法域においてデータを処理する場合があります。GDPR またはその他の適用法令で求められる場合、当社は標準契約条項（SCC）、EU-米国間データプライバシーフレームワーク（DPF）、ベンダーとの DPA、および厳格なデータ最小化管理などの認められた移転メカニズムに依拠します。

## 7. データの保持期間

- **アカウントおよびワークスペースデータ**: アカウントが有効である間保持され、削除リクエストの確認後 30 日以内に完全に消去されます。
- **製品分析（PostHog）**: 最小限の利用イベントは最大 12 か月間保持されます（アカウント削除リクエストがあった場合はそれより早く削除されます）。生のクライアント IP アドレスは保存前に破棄されます。
- **運用ログおよびセキュリティログ**: セキュリティ調査または法令遵守のために長期の保持が必要な場合を除き、最大 90 日間保持されます。
- **請求記録**: 適用される税法および会計法で義務付けられている期間保持されます。

## 8. お客様の選択と権利

お客様には以下の権利があります。

- **アカウント全体で使用状況データの共有を一括管理する**: 「設定」→「このアプリについて」→ **アプリの使用状況データを共有する** から、いつでも使用状況の共有をオフまたはオンにできます（デスクトップ、Web、モバイル、および同期された CLI に適用されます）。また、`LODY_DISABLE_USAGE_SHARING=1` または `DO_NOT_TRACK=1` を設定して CLI テレメトリを上書きすることもできます。
- **ウェブサイト Cookie を管理する**: Cookie 同意バナーまたはウェブサイトフッターの **Cookie 設定** から、任意の分析 Cookie を許可または拒否できます。
- 個人データのコピーへの**アクセスおよびエクスポート**（第15条および第20条のデータポータビリティ）
- 不正確な個人データの**訂正**（第16条）
- アカウントおよび個人データの**消去**（第17条）
- 正当な利益に基づく処理に対する**制限または異議申立て**（第18条および第21条）
- 同意に基づく処理について、いつでも**同意を撤回**すること（第7条第3項）
- お住まいの地域のデータ保護監督機関への**苦情申立て**（第77条）

プライバシーに関するリクエストを行う場合は、[アカウントとデータの削除ページ](/ja/account-deletion)をご利用いただくか、contact@lody.ai までメールでお問い合わせください。

## 9. セキュリティ

当社は、情報を保護するために合理的な技術的および組織的保護措置を講じています。
完全に安全なシステムは存在しませんが、リスクを軽減し、インシデントに迅速に対応できるよう努めています。

## 10. 児童および未成年者

本サービスは、16歳未満のお子様（またはお客様の法域で定められたデジタル同意の最低年齢がそれより高い場合はその年齢未満の方）を対象としておらず、当社が意図的に個人データを収集することはありません。保護者の有効な同意なくお子様が個人データを提供したと思われる場合は、削除できるよう contact@lody.ai までご連絡ください。

## 11. 本プライバシーポリシーの変更

当社は、本プライバシーポリシーを随時更新することがあります。
重要な変更を行う場合は、「最終更新日」を更新し、追加の通知を行うことがあります。
