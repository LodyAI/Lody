# 계정 및 데이터 삭제

이 페이지에서 Lody 계정 및 관련 데이터의 삭제를 요청할 수 있습니다.
요청을 위해 앱이 설치되어 있을 필요는 없습니다.

## 삭제 요청 방법

제목에 "Request account and data deletion"을 입력하여 [contact@lody.ai](mailto:contact@lody.ai?subject=Request%20account%20and%20data%20deletion)로
이메일을 보내 주세요.

계정을 식별하고 확인할 수 있도록 다음과 같은 충분한 정보를 함께 기재해 주세요.

- Lody 로그인에 사용한 이메일 주소
- 로그인에 사용한 경우 GitHub 사용자 이름, Google 계정 이메일, Apple 계정 이메일 또는 Discord 사용자 이름
- 확인이 필요한 워크스페이스 이름 또는 워크스페이스 URL

데이터를 삭제하기 전에 소유권 확인을 위해 회신을 드릴 수 있습니다.

## 삭제되는 데이터

요청이 확인되면 Lody 계정과 연결된 다음 항목을 포함한 계정 데이터를 삭제하거나
영구적으로 비식별화합니다.

- 계정 및 인증 기록
- 워크스페이스 멤버십 기록
- 삭제가 허용되는 경우 계정과 연결된 워크스페이스, 세션, 대화 및 워크플로우 데이터
- 계정과 연결된 CLI 토큰 및 연결된 연동 기록

## 보관될 수 있는 데이터

법적 의무, 보안, 사기 방지, 악용 방지, 회계 또는 운영 무결성 유지 등의 사유로 필요한 경우
일부 제한된 기록이 보관될 수 있습니다. 보관되는 기록은 해당 목적을 달성하는 데 필요한 범위로 제한됩니다.

## 처리 기간

삭제 요청을 접수하고 확인한 후, 위에 명시된 사유로 보관해야 하는 기록을 제외한 관련 데이터는
30일 이내에 영구적으로 삭제됩니다.

## 개인정보처리방침

자세한 내용은 [개인정보처리방침](/ko/privacy)을 참고해 주세요.
