# 支援

需要 Lody 的協助嗎？我們隨時樂意為您服務。您可以透過以下任一管道聯絡我們，無需安裝應用程式即可與我們聯繫。

## 聯絡我們

- **電子郵件：** [contact@lody.ai](mailto:contact@lody.ai?subject=Lody%20Support) —— 用於支援諮詢、錯誤回報及帳號協助。我們會盡快回覆，通常在數個工作天內。
- **Discord：** [加入我們的社群](https://discord.gg/E8mZtMu38s) —— 向團隊與其他使用者提問並取得協助。
- **X（Twitter）：** [@lody_ai](https://x.com/lody_ai) —— 產品更新與公告。

## 回報問題

回報 Bug 或問題時，請一併提供：

- 實際發生情況的說明，以及您預期的結果
- 您所使用的平台（網頁版、桌面版、iOS 或 Android）
- 重現問題的步驟（若已知）

這些資訊能幫助我們更快調查並回覆您的問題。
