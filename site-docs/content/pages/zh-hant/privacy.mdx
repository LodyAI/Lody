# 隱私權政策

最後更新日期：2026 年 11 月 25 日

本隱私權政策說明當您使用我們的服務（包含網站、網頁應用程式、桌面應用程式、行動應用程式及 CLI）時，LoroHub LLC（「Lody」、「我們」）如何蒐集、使用、儲存及保護相關資訊。

## 1. 資料控管者與聯絡方式

- 公司名稱：LoroHub LLC
- 電子郵件：contact@lody.ai

## 2. 我們蒐集的資訊

依據目前的產品運作方式，我們會蒐集以下類別的資料：

### 2.1 帳號與驗證資料

- 透過 GitHub OAuth 或電子郵件驗證所提供的帳號識別碼、基本個人資料及電子郵件地址
- 計費與訂閱狀態中繼資料（付款卡片詳細資訊由 Stripe 直接處理，Lody 不會儲存）

### 2.2 裝置、分析與技術資料

- 除非您在「設定 → 關於」中關閉使用資料分享，否則雲端用戶端會蒐集最少量的產品使用計數（例如註冊次數、訊息送出次數、粗略平台/作業系統與內建 Agent 供應商類別）以及去識別化的錯誤類別。對話內容、儲存庫路徑、URL、頁面標題、自訂 Agent 名稱及原始錯誤堆疊皆不會納入產品分析。本機開源建置版本則完全停用產品分析。
- 產品分析會在儲存前先解析粗略的國家/地區層級位置，隨後立即捨棄原始用戶端 IP 位址。
- 在我們的公開網站上，歐洲經濟區（EEA）、英國及瑞士的選用分析 Cookie 預設為停用，直到您透過 Cookie 同意橫幅接受為止。其他地區的訪客亦可隨時透過網站頁尾的 **Cookie 設定**停用選用分析 Cookie。

### 2.3 服務日誌

- 運作、除錯及維護服務安全所需的營運日誌與安全日誌

### 2.4 使用者內容

- 您透過服務提交的對話內容及相關工作流程上下文（啟用端對端加密的工作區會將對話內容加密保存於您的裝置上）

## 3. 處理個人資料的法律依據（GDPR）

在適用歐盟/英國《一般資料保護規則》（GDPR）的情況下，我們依據以下合法基礎處理個人資料：

- **履行契約（Art. 6(1)(b)）**：驗證您的帳號、提供核心工作區與協作功能，以及管理付費訂閱
- **當事人同意（Art. 6(1)(a)）**：歐洲經濟區、英國及瑞士地區的選用網站分析 Cookie；您可隨時撤回同意，且不影響撤回前基於同意所進行的合法處理
- **正當利益（Art. 6(1)(f)）**：維護服務安全、防止濫用、診斷營運異常，以及蒐集最少量且不使用 Cookie 的產品使用計數與去識別化錯誤類別（您可隨時透過統一的帳號開關關閉此項目）
- **法定義務（Art. 6(1)(c)）**：法律所要求的稅務、會計及法規遵循義務

## 4. Cookie 與本機儲存

- **必要 Cookie 與儲存空間**：維持登入工作階段、佈景主題/語言設定及核心應用程式狀態所必需。
- **網站分析 Cookie（選用）**：在歐洲經濟區（EEA）、英國及瑞士預設為停用，直到您在 Cookie 同意橫幅中接受為止（廣告及個人化廣告儲存功能在全球各地皆維持停用）。所有地區的訪客皆可隨時透過網站頁尾的 **Cookie 設定**變更或停用選用分析 Cookie。
- **產品分析儲存空間**：Lody 應用程式不會設定產品分析 Cookie，且當您關閉使用資料分享時，會立即清除本機分析狀態。

## 5. 第三方服務與資料處理

我們使用受信任的服務供應商（次處理者）來運作部分服務：

- Cloudflare Pages 與 Cloudflare R2（託管與儲存）
- Convex（後端基礎設施）
- GitHub（第三方登入與儲存庫整合）
- Stripe（訂閱計費與付款處理）
- Google Analytics（選用公開網站分析）
- PostHog（最少量產品分析與去識別化錯誤回報，可於「設定 → 關於」中設定）

這些供應商依據各自的使用條款、隱私權政策及適用的資料處理協議（DPA）處理資料。

## 6. 跨境傳輸

我們的雲端基礎設施與服務供應商（包含 PostHog、Convex、Cloudflare、Stripe 及 Google）可能會在美國或其營運所在的其他司法管轄區處理資料。在 GDPR 或其他適用法律要求的情況下，我們仰賴經認可的傳輸機制，例如標準契約條款（SCCs）、歐美資料隱私框架（DPF）、供應商資料處理協議（DPA）以及嚴格的資料最小化控制措施。

## 7. 資料保留期限

- **帳號與工作區資料**：於您的帳號維持有效期間內保留；在確認刪除請求後的 30 天內永久清除。
- **產品分析（PostHog）**：最少量使用事件最多保留 12 個月（或於提出帳號刪除請求時提前刪除）；原始用戶端 IP 位址在儲存前即會捨棄。
- **營運與安全日誌**：最多保留 90 天，除非因安全調查或法規遵循而需延長保留期限。
- **帳務紀錄**：依適用稅務及會計法規要求的期限保留。

## 8. 您的選擇與權利

您有權：

- **在您的帳號中統一控制使用資料分享**：隨時於「設定 → 關於 → **分享應用程式使用資料**」關閉或重新開啟使用資料分享（套用於桌面版、網頁版、行動版及已同步的 CLI），或透過 `LODY_DISABLE_USAGE_SHARING=1` 或 `DO_NOT_TRACK=1` 覆寫 CLI 遙測設定
- **管理網站 Cookie**：透過 Cookie 同意橫幅或網站頁尾的 **Cookie 設定**接受或拒絕選用分析 Cookie
- **存取並匯出**您的個人資料副本（Art. 15 與 Art. 20 資料可攜權）
- **更正**不正確的個人資料（Art. 16）
- **刪除**您的帳號與個人資料（Art. 17）
- **限制或反對**基於正當利益所進行的處理（Art. 18 與 Art. 21）
- **隨時撤回**基於同意所進行的資料處理（Art. 7(3)）
- 向您當地的資料保護主管機關**提出申訴**（Art. 77）

若要提出隱私權相關請求，請使用[帳號與資料刪除頁面](/zh-hant/account-deletion)或寄送電子郵件至 contact@lody.ai。

## 9. 安全性

我們採取合理的技術與組織防護措施來保護資訊。
沒有任何系統是百分之百安全的，但我們致力於降低風險並及時應對安全事件。

## 10. 兒童與未成年人

本服務並非針對未滿 16 歲（或您所在司法管轄區法律規定的較高數位同意最低年齡）的兒童，我們也不會在知情的情況下蒐集其個人資料。若您認為兒童在未經有效監護人同意的情況下提供了個人資料，請聯絡 contact@lody.ai，以便我們進行刪除。
