# 帳號與資料刪除

您可以透過此頁面申請刪除您的 Lody 帳號及相關資料。
即使尚未安裝應用程式，也能提出此申請。

## 如何申請刪除

請寄送電子郵件至 [contact@lody.ai](mailto:contact@lody.ai?subject=Request%20account%20and%20data%20deletion)，
信件主旨請填寫 "Request account and data deletion"。

請在信中提供足夠的資訊，以便我們識別並驗證您的帳號，例如：

- 用於登入 Lody 的電子郵件地址
- 如有用於登入，請提供您的 GitHub 使用者名稱、Google 帳號電子郵件、Apple 帳號電子郵件或 Discord 使用者名稱
- 您希望我們核對的任何工作區名稱或工作區 URL

在刪除資料之前，我們可能會回信向您確認帳號所有權。

## 將會刪除哪些資料

申請通過驗證後，我們將會刪除或永久去識別化與您的 Lody 帳號相關的帳號資料，包括：

- 帳號與驗證紀錄
- 工作區成員資格紀錄
- 在允許刪除的範圍內，與您帳號相關的工作區、工作階段、對話及工作流程資料
- 與您帳號關聯的 CLI Token 及已連結的整合服務紀錄

## 可能保留哪些資料

基於法律、安全、防範詐欺、防止濫用、會計或營運完整性等必要因素，我們可能會保留部分有限的紀錄。
所保留的紀錄僅限於達成上述目的所需的必要範圍。

## 處理時程

收到並確認刪除申請後，相關資料將在 30 天內永久清除，
但因上述原因而必須保留的紀錄除外。
