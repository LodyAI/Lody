# 隐私政策

最后更新：2026 年 11 月 25 日

本隐私政策用于说明 LoroHub LLC（以下简称"Lody"、"我们"）在你使用服务（包括网站、Web 应用、桌面应用、移动应用及 CLI）时如何收集、使用、存储和保护信息。

## 1. 信息控制方与联系方式

- 公司：LoroHub LLC
- 邮箱：contact@lody.ai

## 2. 我们收集的信息

根据当前产品形态，我们主要收集以下信息：

### 2.1 账号与认证信息

- 通过 GitHub 第三方登录或邮箱认证提供的账号标识、基础资料与邮箱地址
- 订阅与计费状态元数据（完整支付卡信息由 Stripe 直接处理，Lody 不存储）

### 2.2 设备、产品分析与技术信息

- 除非你在「设置 → 关于」中关闭使用数据分享，云版客户端默认收集最小化的产品使用计数（如注册数、消息提交次数、粗粒度平台/操作系统及内置 Agent 类型分类）与脱敏后的错误分类。对话内容、仓库路径、页面 URL 与标题、自定义 Agent 名称及原始错误堆栈均不会上报至产品分析；本地开源构建始终禁用产品分析。
- 产品分析在入库前仅解析粗粒度国家/地区信息，并丢弃原始客户端 IP 地址。
- 公开官网上的可选分析 Cookie 在欧洲经济区（EEA）、英国和瑞士默认关闭，仅在你通过 Cookie 同意横幅接受后才会启用；其他地区的访客也可随时通过页脚「Cookie 设置」管理或关闭。

### 2.3 服务日志

- 为保障服务运行、调试与安全所需的日志信息

### 2.4 用户内容

- 你在服务中提交的对话内容及相关工作流上下文（开启端到端加密的工作区仅在你的设备上保存明文内容）

## 3. 处理个人信息的法律依据（GDPR）

在适用欧盟/英国《通用数据保护条例》（GDPR）的情况下，我们依据以下合法性基础处理个人信息：

- **履行合同（Art. 6(1)(b)）**：用于账号认证、提供核心工作区与协作功能以及管理付费订阅
- **用户同意（Art. 6(1)(a)）**：用于欧洲经济区、英国与瑞士的官网可选分析 Cookie；你可随时撤回同意，且不影响撤回前基于同意进行的合法处理
- **合法利益（Art. 6(1)(f)）**：用于保障服务安全、识别与防范滥用、排查系统故障，以及收集最小化且无 Cookie 的产品使用计数与脱敏错误分类（你可随时通过账号级统一开关关闭）
- **履行法定义务（Art. 6(1)(c)）**：用于满足适用的税务、财务及合规要求

## 4. Cookie 与本地存储

- **必要 Cookie 与本地存储**：用于维持登录状态、语言/主题偏好和核心功能运行。
- **官网分析 Cookie（可选）**：在欧洲经济区（EEA）、英国和瑞士默认关闭，仅在你于 Cookie 同意横幅中点击接受后才会启用（广告追踪与个性化广告存储在全球范围内始终关闭）。所有地区的访客均可随时点击页脚「Cookie 设置」修改或关闭。
- **产品分析存储**：Lody 应用不设置产品分析 Cookie，且在你关闭使用数据分享后会立即清理本地分析状态。

## 5. 第三方服务与处理方

我们使用以下受信任的第三方服务处理方支持平台运行：

- Cloudflare Pages 与 Cloudflare R2（托管与存储）
- Convex（后端基础设施）
- GitHub（第三方登录与仓库集成）
- Stripe（订阅计费与支付处理）
- Google Analytics（经同意后的官网公开页面分析）
- PostHog（最小化产品分析与脱敏错误报告，可在「设置 → 关于」中随时关闭）

这些第三方依据其自身条款、隐私政策及适用的数据处理协议（DPA）处理相关数据。

## 6. 跨境传输

我们的云端基础设施与第三方服务处理方（包括 PostHog、Convex、Cloudflare、Stripe 与 Google）可能在美国或其运营所在的其他司法辖区处理数据。在 GDPR 或其他适用法律要求的情况下，我们依托标准合同条款（SCCs）、欧美数据隐私框架（DPF）、供应商数据处理协议（DPA）及严格的数据最小化控制来保障传输合规。

## 7. 数据保存期限

- **账号与工作区数据**：在账号有效期内保存；确认删除请求后将在 30 天内彻底清除。
- **产品分析数据（PostHog）**：最小化使用事件最长保存 12 个月（或在账号删除请求时提前清理）；原始客户端 IP 在入库前即被丢弃。
- **运营与安全日志**：最长保存 90 天，除非因安全调查或法律要求需延长保存。
- **计费与税务记录**：按适用财税法律要求的期限保存。

## 8. 你的权利与选择

你可以行使以下权利：

- **全端统一管理使用数据分享**：随时在「设置 → 关于 → 分享应用使用数据」关闭或重新开启（对你的账号在桌面端、Web 端、移动端与已登录 CLI 统一生效），或通过环境变量 `LODY_DISABLE_USAGE_SHARING=1` / `DO_NOT_TRACK=1` 强制关闭 CLI 统计
- **管理官网 Cookie**：通过首次弹出的 Cookie 横幅或页脚「Cookie 设置」随时接受或拒绝可选分析 Cookie
- **访问与导出**你的个人信息副本（含数据可携权，Art. 15 / Art. 20）
- **更正**不准确的个人信息（Art. 16）
- **删除**你的账号与个人信息（Art. 17）
- **限制或反对**基于合法利益的处理（Art. 18 / Art. 21）
- **随时撤回同意**（Art. 7(3)）
- **向当地数据保护监管机构投诉**（Art. 77）

如需行使上述权利，请访问[账户与数据删除页面](/zh/account-deletion)，或发送邮件至 contact@lody.ai。

## 9. 安全措施

我们采取合理的技术和组织措施保护信息安全。
尽管任何系统都无法保证绝对安全，我们会持续降低风险并及时响应安全事件。

## 10. 未成年人说明

本服务不面向 16 周岁以下（或你所在司法辖区法律规定的更高数字同意年龄以下）的未成年人，我们不会故意收集其个人信息。如你认为有未成年人在未获有效监护人同意的情况下向我们提供了个人信息，请联系 contact@lody.ai，我们将及时删除。
